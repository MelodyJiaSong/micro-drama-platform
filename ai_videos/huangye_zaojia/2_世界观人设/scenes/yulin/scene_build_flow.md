**主体（L3）＝ Place × State**，共 **11 个**（4 状态链 + 3 光变体 + 3 独立地点 + 1 待建）。

### 为什么不再有「按需」

原先按 rule 4f「用到才建」只做锚点、派生视图留到实拍漂了再补。**2026-09-06 用户定调改为
每个主体先出全景锚点、再补齐多角度**，理由是：

- **细节是本片的卖点**。这是建造片，观众就是来看木头、藤条、叶片、泥和水的。
  角度不够，中远景里这些材质全糊掉。
- **每多一个角度，就少一次实拍时现编的机会**。参考图不会自己转方向（rule 4e）——
  没有那个朝向的图，模型每镜都会重新编一遍，而且每次编得不一样。
- 代价是**主体几何一致性的检查面变大**（每个角度都是椽子对不上的一次机会）。
  对策：派生视图**一律挂本主体的全景锚点**，把误差圈在主体内，不跨主体传播。

## 固定视图集规格

沿用 entropy_city 的五类视图，**本片新增第六类「内视」**：

| 视图类型 | 机位 | 管什么 | 谁有 |
|---|---|---|---|
| **全景（锚点）** | 眼平广角。台地/棚屋系列**统一为 N1 机位** | **主 look**：材质·色板·光·氛围。它是本主体的权威长相 | **全部 10 个主体，一律是视图 1** |
| 反向 | 眼平广角，与全景严格 180° | 镜头背后是什么——反打与回程不必现编 | 全部 10 个 |
| 侧向 / 剖视 | 眼平，垂直主轴 90° | **结构层次**：斜度、层数、厚度、进深 | 除林冠外全部 |
| 斜瞰 | 高位俯角 | 平面关系：轮廓、占位、排布、走向 | 除林冠外全部 |
| 材质 | 表面近景，正对无透视 | 质感锚——远景里糊掉的材质靠它立住 | 全部 10 个 |
| **内视** | **机位在结构内部，由内向外** | **本项目新增**，见下 | `bg4` / `bg5` / `bg6` / `bg7` |

**编号规则**：视图 1 恒为全景锚点；2 号之后按本主体的信息优先级排，**编号是每主体独立的**
（`bg1-5` 是台地材质，`bg6-5` 是檐口滴水材质——不要跨主体套编号）。
逐主体的完整视图表见各主体 md 的「出图顺序」。

**每个主体的视图 1 一律是全景锚点，其余视图全部挂它**（主体内星形），可并行出。
林冠没有「平视正向」可言，它的全景就是仰视，也没有斜瞰与剖视，故只有 4 个视图。

### 为什么要加「内视」

entropy_city 的五类视图全部是「从外面看一个地方」。本片的核心卖点是
**「屋外倾盆 / 屋内干燥」的同框对比**——这个画面**只能从棚内往外拍**，
五类视图里没有一个能承载它。

而且它不能用剪辑对切替代：**对切只是信息，同框才是感受**。
观众要在**同一个画面里**同时看见暖橙的干与冷灰蓝的湿，中间隔着檐口滴水线。
所以「内视」不是一个可有可无的补充角度，它是本片赖以成立的机位。
四个有棚内空间的主体（`bg4` 建成日 / `bg5` 雨前 / `bg6` 暴雨夜 / `bg7` 雨歇夜）
**都出内视，且四张严格同机位**——它们构成一条「同一个位置、四种天气」的对照序列，
本身就是这部片最有说服力的一组画面。

## 继承拓扑：状态链走**链式**，独立地点走**星形**

**这是本片相对 entropy_city 规格唯一的实质改动，必须理解它为什么改。**

entropy_city 用的是**三层星形**——① 世界锚点 → ② 各地点锚点全挂它 → ③ 各地点派生全挂本地点锚点；
同层之间互不参考，理由是「误差不累积，某张歪了只重跑那一张」。

**这个理由在本片的状态链上不成立。** entropy_city 的「复原态」是**纯色彩事件、几何一寸不改**，
所以变体挂基线即可。本片是**几何在生长**：空台地 → 十一根椽子 → 盖到一半 → 盖满。
如果骨架图与建成图都各自挂世界锚点，两张图的椽子根数、斜度、间距**必然对不上**——
而观众恰恰会在三次进度对比帧里把它们并排看到。

所以：

```
bg1 台地原始（★零参考·世界锚点·1697 字）
  │
  ├─► bg1-2..5（反向/侧向/斜瞰/材质）             ref = bg1-1   （星形·同主体派生）
  │
  ├─► bg8 步道 / bg9 林冠 / bg10 旧屋架 / bg11 溪谷  ref = bg1-1   （星形·独立地点继承世界基调）
  │
  └─► bg2 台地骨架     ref = bg1-1   ┐
         └─► bg3 覆顶中  ref = bg2-1  ├ 链式：几何逐级累积
               └─► bg4 建成 ref = bg3-1 ┘  ← **几何冻结点**
                     ├─► bg5 雨前     ref = bg4-1   （只改光）
                     ├─► bg6 暴雨夜   ref = bg4-1   （只改天气与光源）
                     │     └─► bg7 雨歇夜 ref = bg6-1（只改雨量）
                     └─► bg4-2..6 派生视图 ref = bg4-1
```

**链式的代价与对策**：误差会累积——`bg2` 歪了，`bg3`/`bg4` 跟着歪。
对策是**每一环都必须过完验收再往下开**，验收里写死了「与上一张严格同机位、椽子逐根对得上」。
**宁可在 `bg2` 重跑五次，也不要带着错的骨架往下走三张图。**

**几何冻结点在 `bg4`**：从它开始，棚屋几何锁死，`bg5`/`bg6`/`bg7` 与系列后续短片
只允许改光、改天气、叠加新部件，不得改动既有几何。

## 出图顺序（图先行，严格串行）

**总原则：先出 10 张全景锚点（严格按依赖顺序），再补 43 张多角度（可大量并行）。**

```
第一轮 · 10 张全景锚点
  ① bg1-1 台地全景   ← 纯文字、**不挂任何参考图**   全片视觉源头，1697 字，反复重跑到过完验收
      │
      ├─► ② bg8-1 步道 / bg9-1 林冠 / bg10-1 旧屋架   ref = bg1-1   ← 三张可并行
      │
      └─► ③ bg2-1 骨架 ─► ④ bg3-1 覆顶中 ─► ⑤ bg4-1 建成   **严格串行，一环一环来**
                                              ├─► ⑥ bg5-1 雨前      ref = bg4-1
                                              └─► ⑦ bg6-1 暴雨夜    ref = bg4-1
                                                     └─► ⑧ bg7-1 雨歇夜  ref = bg6-1

第二轮 · 43 张多角度   每张 ref = 本主体的全景锚点，**主体内并行、主体间也并行**
  bg1-2..5(4) · bg2-2..5(4) · bg3-2..5(4) · bg4-2..6(5) · bg5-2..6(5)
  bg6-2..6(5) · bg7-2..6(5) · bg8-2..5(4) · bg9-2..4(3) · bg10-2..5(4)
```

**第一轮里 ③④⑤ 必须串行**（链式继承的必然后果，别图快跳步）；
**第二轮全部可以并行**——它们各挂各的主体锚点，互不依赖。

> **为什么第二轮不能提前开**：某个主体的全景锚点没定稿就出它的多角度，
> 等锚点重跑之后这些角度全部作废。**锚点是本主体所有派生视图的唯一真相。**

## 本片最大的一致性风险：椽子

三次进度对比帧会把 `bg1-1` / `bg2-1` / `bg3-1` / `bg4-1` 四张图并排放给观众看。
生成模型**数不准数量**——「十一根椽子」这种精确计数，它大概率给你十根或十三根。

**分级对策**（按严格度从高到低，达不到上一级就退到下一级）：

1. **首选：逐根对齐。** 链式继承 + 验收里逐条查。`bg3-1` 上半部露出的椽子可数，
   与 `bg2-1` 对得上才算过。
2. **退一步：不管根数，管观感。** 观众其实**数不清根数**，但**一眼看得出斜度和密度的突变**。
   若反复对不齐，把硬约束从「十一根」降级为「斜度约五十度 + 间距均匀 + 覆盖同样的范围」，
   在生成器里把根数从 `场景` 文字改成「十根上下」。
3. **兜底：靠剪辑回避。** 对比帧之间不做叠化、不做同框分屏，用硬切；
   人眼在硬切之间对数量的记忆很弱。

**不要为了根数一致把对比帧砍掉**——对比帧是本片无台词条件下唯一的「进度条」，
它的价值远大于椽子数的精确性。

## N1 机位（**全片最重要的一个约定**）

> 站在台地北缘土坎下、地面高度平视朝南。24mm，f8，全景深，地平线水平。

`bg1` / `bg2` / `bg3` / `bg4` / `bg5` / `bg6` / `bg7` 的**正向视图全部用这一个机位**，
同高度、同朝向、同焦段。七张图叠起来，地形、倒木、背景树应当逐处重合。

**这个机位一经确定，任何主体、任何视图、任何后续短片都不得更改。**
本片的三次进度对比帧（S08 / S16 / S28）与系列的跨片对比蒙太奇，全部建立在它之上。
