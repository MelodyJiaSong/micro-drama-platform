# 造家的人 · c1

## 角色定位

全片唯一的人。无名、无台词、不露正脸。他不是被展示的对象，而是**观众的替身**——镜头大部分时间站在他肩后或他手边，看他看的东西、做他做的事。

出场范围：全片几乎每一镜（除纯空镜与延时）。与"反派"雨林的关系见 `../../world.md` §3。

## 性格 / 动机

- **核心动机**：不是逃离什么，是**想亲手把"住下来"这件事从头做一遍**。
- **表层人设**：安静、耐心、手上有活的人。
- **反差点**：看着极稳，但雨来之前会明显加快——他也怕来不及。**这个"加速"是全片唯一的情绪外露方式**。
- **关键弱点**：容易一件事做过头（把屋顶叠得太密、把沟挖得太深），常常天黑了还在收尾。

---

## 人物灵魂（ongoing · 随集深化 · rule 12.11）

> 本片无台词，人物灵魂不通过语言外化，而是通过**他先做什么、后做什么、在什么地方停下来**外化。写透它，是为了让片里每一个行为选择都有依据，而不是"随便干点活"。

- **年龄 / 当下处境**：三十五岁上下。一个人在完全陌生的热带雨林里，装备只有背上那些，没有退路也没有期限。
- **前史（之前在干什么）**：`待深化`（本季刻意不交代来处——观众的投射空间比背景故事值钱。若后续需要，只用**画面**暗示，绝不用字幕解释）。
- **为什么在做现在做的事（根因）**：他要证明"安顿"这件事是可以靠自己完成的。城市里"住"是买来的、租来的、别人给的；这里的每一根梁都得自己扛。
- **目标（短期 / 长期）**：短期——天黑和暴雨前有个能挡雨、能生火、能睡觉的地方。长期——把这个地方从"庇护所"变成"家"，而且让雨林接受它的存在。
- **需求（needs）**：一个不必解释自己的地方；一件能看见结果的事。
- **内心欲望（desire）**：被自然接纳——**不是征服它**。这个欲望的兑现物就是那只犀鸟（`c2`）。
- **核心矛盾**：他越把这里造成"家"，就越是在雨林里制造一个不属于雨林的东西；而他真正想要的，是**属于这里**。
- **恐惧**：不是野兽，是**徒劳**——造好的东西被一场雨、一个雨季、几年藤蔓拆干净。`bg10` 旧屋架就是这份恐惧的具象。
- **最大创伤 + 致伤事件**：`待深化`（**本片完全不揭**；若系列后续要揭，安排在他拆旧屋架的那一部，用"他在旧屋架前坐了很久"这一个动作承载，不用闪回、不用字幕）。
- **此刻怎么 make decision**：**先看，再动**。到一处新地方，他会站着看很久；动手前会用手比一下、用脚踩一下、拿刀背敲一下听声音。决策依据永远是"雨会从哪来、水会往哪流、天什么时候黑"。
- **性格特点**：沉静 · 有序 · 手上有活 · 略微强迫 · 不表演。行为体现——他会把砍下的木料按长短码整齐再开始搭。
- **成长 / 变化轨迹**：**本片内**走完一条小弧——开场是敬畏与陌生，中段转为专注施工，转段被雨逼出全片唯一的加速，收尾坐在火边时是安定。**系列尺度上**，紧迫会逐步让位于从容与讲究（开始在乎顺手、在乎好看、在乎那只鸟会不会来），那是"庇护所 → 家"的内核，本片只走第一步。

## 行为声口（本片无台词，以"做事的口吻"代替说话风格）

> 声口模板在本项目**转译为行为节奏锚**（divergence #3：无台词）。它的职责与说话风格一致——**防止跨镜人物走样**。

- **节奏**：慢启动、匀速推进、收尾突然加快（雨要来了）。
- **典型"口吻"示范（动作版）**：走到一处，站定，抬头看树冠判断雨会从哪漏下来，蹲下抓一把土捏了捏，起身，从腰间抽刀——**整个过程不到 8 秒，没有一个多余动作，也没有一个着急的动作**。
- **禁忌（不许出现的"腔"）**：不许对镜头展示成果、不许比大拇指、不许擦汗后叉腰长叹这类表演性动作、不许在完成时张开双臂欢呼。**他的成就感只允许用"退后两步看一眼"表达。**

## turntable 说明（4s 建立视频 reference · rule 12.5 · 本项目变体）

> 本项目 turntable 的职责**不是锁脸**（本项目不锁脸，divergence #4），而是锁 **体型 + 服装 + 装备 + 站姿**，作为后续所有 shot 的造型 reference 上传源。

> **无统一声样台词**——本项目无台词、无配音（divergence #3），turntable 为纯视觉建立视频。

- **路由键**：`c1-1`
