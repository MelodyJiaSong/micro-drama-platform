# 风格指南 · 《荒野造家 · 雨林第一夜》

> 所有 shot 的 `光线/色调:` `渲染样式:` `负面词:` 三行都从本文件取值并 **byte-identical 复制**。
> 颜色一律用**自然中文色名，零 hex**（rule 1b）。画幅 **16:9**（per-project divergence）。
> 本片＝一部约四分钟的独立短片，多个 shot 拼接成一条成片。本文件的锁定串同样可供系列后续短片复用。

---

## 1. 影像基调（一句话锁定 · 复制到每个 shot 的 `渲染样式:`）

```
自然纪实影像，真实自然光，浅景深长焦与广角混用，高湿度空气感，冷绿环境与暖橙火光强色温对比，颗粒细腻，无风格化滤镜
```

## 2. 调色

| 层 | 色名 | 说明 |
|---|---|---|
| 环境主色 | **苔绿 / 墨绿 / 青灰** | 树冠、蕨类、湿岩。整体偏冷。 |
| 环境辅色 | **赭红 / 湿褐** | 红泥地面、湿木、板根。给冷绿垫一层暖底，避免全片发青。 |
| 高光 | **乳白雾光** | 透过树冠的天光与晨雾，永远是柔的、有体积的。 |
| 火与室内 | **暖橙 / 琥珀** | 唯一的暖源。**必须比环境亮 2 档、暖 2 档**，对比不够就等于没有这个卖点。 |
| 夜 | **近纯黑 + 一点暖橙** | 火光之外压到接近纯黑，不提黑位、不补光。 |

**冷暖对比是本片的签名**：任何同时出现"棚内"与"棚外"的镜头，**画面里必须同时看得见冷绿与暖橙**，交界线要清楚（屋檐线 / 门口 / 火光边缘）。

## 3. 情绪 → 光线映射

| 段落 | 光 | 用在 |
|---|---|---|
| 开场 · 敬畏 | 晨雾 + 斜射光柱，逆光，高对比 | `bg9` 林冠 · `bg8` 入林 |
| 施工 · 专注 | 顶光偏散射，正午高色温，阴影短而硬 | `bg1`→`bg2`→`bg3`→`bg4` 建造链 |
| 转折 · 压迫 | 光整体降一档转灰蓝，无方向感，风起 | `bg5` 雨前 |
| 暴雨 · 对抗 | 屋外冷灰高频雨丝，屋内暖橙火光 | `bg6` 核心对比镜（`bg6-2` 内视） |
| 安逸 · 收束 | 火光为唯一光源，暖橙从下往上打，环境压黑 | `bg7` 夜 · 屋内 |
| 签名定帧 | 极远景，画面 95% 是黑，只留一点暖橙 | `bg7-2` · 全片最后一镜 |

```
负面词: 第二个人, 人群, 路人, 远处人影, 村落, 房屋, 公路, 电线, 桥梁, 现代建筑, 塑料垃圾, 飞机尾迹, 路牌文字, 画面文字, 字幕, 水印, logo, 发光粒子, 神秘光效, 魔法雾, 幻想生物, 符文图腾, 镜头光晕特效, 补光痕迹, 来源不明的光, 悬浮物, 无支撑结构, 不受力的绳结, 塑料感材质, 卡通渲染, 插画风, 过饱和, HDR 假感, 人物看镜头, 摆拍姿势, 面部特写, 五官清晰, 畸形手指, 多余肢体, 变形人体
```

> **前 8 项是本片最高频的翻车点**：AI 极爱往雨林里加第二个人、村落与幻想光效。**每个 shot 都必须原样带上整段，不许精简。**

## 6. 遮脸约定（本项目不做人脸一致性锁定）

主角**不做面部锁定**。每个 shot 用下列手段之一让脸不成为焦点，从而绕开 AI 人脸漂移：

| 手段 | 用法 |
|---|---|
| 背影 | 默认首选。搬运、行走、观察都用背影。 |
| 帽檐压低 | 布帽檐在眼睛以下投出阴影，只见下半脸。 |
| 逆光剪影 | 光柱、雨幕、火光背后，人成剪影。 |
| 中远景 | 人在画面里占比 < 1/4，脸自然不可辨。 |
| 手部特写 | 只给手与工具，身体出画。 |

**负面词固定带 `面部特写, 五官清晰`**。本片正脸**一次都不给**；最多在暴雨夜火光边给一个逆光的半侧脸剪影。

## 7. 音轨约定（无人声）

- **无台词、无旁白、无 TTS、无字幕**。shot 不写 `台词:`，不生成 `## 台词配音 prompt`。
- 成片音轨 = **环境音为主**（刀声 / 雨声 / 火声 / 鸟声 / 风声 / 脚步与树叶摩擦）+ 可选极简 BGM，后期铺。
- 生成阶段：视频 prompt 里**不要求模型出声**，声音全部后期处理。

## 8. 画幅与时长

- 画幅：**16:9**（全片，含所有参考图与 turntable）。
- 单镜时长：3–15s。**环境长镜 8–15s，手部动作特写 3–5s**，混切。
- **全片总时长：235–250s（约 4 分钟）**，由 32–40 个 shot 拼接而成。`shotlist.md` 须带 `时长合计` 行证明落在区间内。
