# 配音 casting 表

## N/A —— 本项目无台词、无旁白、无 TTS

《荒野造家》为**纯环境音无人声**作品（`specs/ai_video/huangye_zaojia/divergence.md` #3）。因此：

- **不分配 voice_id**，各角色卡「配音参考」段统一记 N/A。
- shot 不写 `台词:` 字段，不生成 `## 台词配音 prompt` 块。
- `ai_videos__格式契约` 的 K7（voice_id 一致性）在本项目**显式跳过**，不视为 blocker。
- QC 关卡 `ai_videos__台词大师` / `ai_videos__白话大师` 在本项目 **N/A**。

## 声音设计表（代替 casting，供后期铺音轨）

| 层 | 内容 | 说明 |
|---|---|---|
| **动作音** | 砍刀入木、劈裂、拖拽木料、藤条摩擦收紧、叶片翻动、挖土、石块落定 | 本片的"台词"。每个手部特写都必须有对应的清晰动作音 |
| **环境底噪** | 蝉鸣与虫声（层次随时辰变）、远处鸟鸣、树叶风声、滴水 | 白天密、雨前突然变静、夜里换成另一套虫声 |
| **雨** | 雨落树冠（高频细密）／雨打棕榈叶顶（低频闷响）／檐下滴水（点状） | **三层必须分开铺**，"屋内 vs 屋外"的对比一半靠这个 |
| **火** | 起火时的轻爆、稳定燃烧的低频、添柴 | 夜段的唯一暖声 |
| **犀鸟** | 翅膀搏动声（低频、可闻）+ 短促叫声 | 出场标志音，先于画面 0.5s 出现效果最好 |
| **BGM** | 可选，极简。**只允许在开场大景与签名收尾帧铺**，中段施工全程不铺 | 中段留给动作音，这是 ASMR 卖点 |
