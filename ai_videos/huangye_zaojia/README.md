# 荒野造家 · 雨林第一夜（Wild Build — First Night in the Rainforest）

一个人带一把砍刀走进东南亚热带雨林，用一天时间，**抢在暴雨和天黑之前给自己造出一个家**。

> **本片＝一部约四分钟的独立短片**，由 32–40 个 shot 拼接成一条成片。**不是分集剧，没有 EP 结构。**
> 《荒野造家》是系列名，后续会有别的短片；本仓库目录只装本片，`2_世界观人设/` 的锁定资产可跨片复用。

## 项目概要

| 项 | 值 |
|---|---|
| 类型 | 野外生存建造纪实（Primitive Building / Bushcraft），**非剧情短剧** |
| 画幅 | **16:9**（不出竖版） |
| 片长 | **约 4 分钟**（235–250s），32–40 个 shot |
| 声音 | **纯环境音，全程无人声**（无台词 / 无旁白 / 无 TTS） |
| 平台 | YouTube（主）· TikTok · 抖音（同片横屏投放） |
| 结构 | **单片扁平**（`sub_type=short`），无 `episodes/` 分层 |
| 立意 | 人不是来征服荒野的，是来学会跟它相处的 |

> 本项目对仓库默认（9:16 / 180–195s / 台词驱动 / 人脸锁定 / 多集 novel 结构）有 **7 项 divergence**，
> 见 `specs/ai_video/huangye_zaojia/divergence.md`。

## 使用说明

1. **参考图**：主角轻描述符 + 场景锚点图走 Seedream 文生图，落各自资产目录。
2. **出片**：每个 `shotNN.md` 内的 `## 视频 prompt` 代码块整段复制进 Seedance / Kling。比例 **16:9**。
3. **无配音层**：本项目不生成 `台词配音 prompt`；成片音轨 = 环境音 + （可选）极简 BGM，后期铺。
4. **字幕**：全片零字幕；平台标题与描述见各集 `publish.md`。

## 出图顺序（阶段 2 资产 · **53 个场景视图，全部必做**）

**改 prompt ＝ 改生成器重跑**：`python tools/gen_scene_prompts_huangye_zaojia.py`。不手改主体 md。

**总原则：先出 10 张全景锚点（按依赖顺序），再补 43 张多角度（可大量并行）。**

```
第一轮 · 10 张全景锚点
  ① bg1-1 台地全景  ← 零参考自由生成，全片视觉源头，反复重跑到过完验收
      ├─► ② bg8-1 步道 / bg9-1 林冠 / bg10-1 旧屋架       ← 三张可并行
      └─► ③ bg2-1 骨架 ─► ④ bg3-1 覆顶中 ─► ⑤ bg4-1 建成  ← **严格串行**
                                   ├─► ⑥ bg5-1 雨前
                                   └─► ⑦ bg6-1 暴雨夜 ─► ⑧ bg7-1 雨歇夜

第二轮 · 43 张多角度   每张挂本主体的全景锚点，主体内外都可并行
  bg1-2..5 · bg2-2..5 · bg3-2..5 · bg4-2..6 · bg5-2..6
  bg6-2..6 · bg7-2..6 · bg8-2..5 · bg9-2..4 · bg10-2..5

另：c1 turntable / c2 犀鸟 / p1 砍刀 / p2 随身装备 —— 零参考，随时可并行
```

**三条铁律**：
1. `bg1-1` 是全项目**唯一一张零参考自由生成**的图，其余全部挂它或挂它的下游。
2. **建造状态链走链式继承（③④⑤ 必须串行）**——几何在生长，星形会让椽子对不上。
   一环没过完验收，不许往下开。详见 `scenes/yulin/scene_build_flow.md` §继承拓扑。
3. **第二轮不能提前开**——某个主体的全景锚点没定稿就出它的多角度，
   锚点重跑之后这些角度全部作废。锚点是本主体所有派生视图的唯一真相。
