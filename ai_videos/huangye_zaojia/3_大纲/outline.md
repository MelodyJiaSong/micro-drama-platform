# 全片段落结构 · 《荒野造家 · 雨林第一夜》

> **单片，无分集。** 40 个 shot 拼接成一条成片，**时长合计 245s（落在 235–250s）**。
> 上游：`1_立项/concept.md` · `2_世界观人设/`。下游：`5_6_分镜与prompt/shotlist.md`。
> 全片压在**一天之内**，时序＝`world.md` §4 的骨架：清晨薄雾 → 上午采集搬运 → 正午施工 → 午后转暗风起 → 暴雨 → 入夜 → 定帧。
>
> **场景列写的是主体 ID**（`2_世界观人设/scenes/yulin/`）。台地/棚屋随建造进度换主体，
> 不是同一个主体换光——`bg1` 原始 → `bg2` 骨架 → `bg3` 覆顶中 → `bg4` 建成 → `bg5` 雨前 → `bg6` 暴雨夜 → `bg7` 雨歇夜。

## 转 · 2:45–3:39（S29–S36 · 54s）

**任务**：**先给压力，再给安逸。** 没有前面的紧张，后面的安逸就不成立。
**全片唯一一次加速**在这一段（S32）——他也怕来不及，这是他唯一的情绪外露。

| 镜 | 时长 | 主体 | 视图 | 内容 | 备注 |
|---|---|---|---|---|---|

| S31 | 6s | `bg5` | `bg5-1` | 风先到：叶顶边缘被掀起一角，人抬头（背影仰视） | 屋顶第一次被质疑 |

> 白天看得清、动机合理，还白赚一个天气预兆。

## 主体覆盖核对（53 个视图 · 每个都有职责）

**2026-09-06 定调：每个主体先出全景锚点，再补齐多角度，确保细节被 capture。**

实拍真在该角度漂了时的替补、以及给生成模型多一份「这个地方长这样」的证据）。
**两类都必做**，不再有「按需」。

| 起 | 蝉鸣与虫声最密 → 脚步与落叶 → 抽刀的金属摩擦（第一个"人造"的声音） |
| 承 | **动作音全面接管**：劈砍、木屑、拖拽、藤条收紧、叶片翻动、挖土。**中段不铺 BGM**，这是 ASMR 卖点 |
| 转 | **虫声突然变静**（雨前征兆，最有效的紧张手段）→ 犀鸟振翅声 → 风 → 火的轻爆 → **雨的三层**（树冠高频 / 叶顶低频 / 檐下点状） |
| 合 | 雨渐弱 → 只剩檐下滴水与火的低频 → 另一套夜虫声起 → 签名定帧处**可铺极简 BGM** |
