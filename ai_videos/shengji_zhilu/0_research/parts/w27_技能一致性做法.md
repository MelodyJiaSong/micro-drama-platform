## R5 · 同一个技能每次都一样：怎么锁动作、口令、特效、声音

> 标记：【官】官方文档 ·【T1】行业访谈 ·【社】社区经验 ·【仓】本仓库已有规则或实测 ·【推】推断。置信度：高 / 中 / 低。
> 抓取日 2026-09-30；来源编号 [S#] 见文末。只读仓库，未改任何仓库文件。

### 0. 结论

1. **Seedance 官方给的答案是：特效用参考视频定义，不用文字。** 2.0 指南 FAQ「特效效果不符合预期」：文字指定特效「可能会出现特效效果与预期不符」→「建议采用参考视频定义特效」[S2]；2.5 把特效归进「运动参考（动作/表情/运镜/创意/特效）」，示例写法就是「参考视频 1 中施法的动作」[S1]。→ 每个技能做一条**自有、干净的技能样片**，每次施法镜都挂它。【官，高】
2. **Seedance 2.x 没有 seed，也没有 LoRA。** API 里 `seed` 只支持 1.0 pro / pro fast，且「相同的 seed 值，会生成类似的结果，但不保证完全一致」；参数表无 LoRA / 微调入口 [S3]。锁种子、训特效模型这两条路在 Seedance 上不存在。【官，高】
3. **声音是唯一能逐字节一致的一层。** ElevenLabs 音效 API 无 seed [S15]；Seedance 写了「禁止背景音乐」特效音仍可能变成 BGM，官方兜底是后期分离人声 [S1]。→ 技能音效、口令各**定稿一个文件**，后期每次贴同一个。【官+推，高】
4. **参考视频里的杂物会漏进成片。** 官方案例：参考视频自带字幕→成片跟着出字幕；白模里的轨迹线、坐标线会泄露 [S1]；含真人脸的参考直接拒收 [S3]。样片必须无字、无 UI、中性背景，最好不露脸；2.5 全部参考视频合计 ≤30 s [S3]，会和 previz 抢额度。【官，高】
5. **影视工业都是「先定规则表，再让表演驱动特效」。** ILM《魔兽》：按游戏截屏定型，让粉丝「一眼认出是哪个法术」，施法分多步，演员手上装 LED 给互动光 [S16]；《时光之轮》：五元素「图例」，光以白为主只带元素色，编织路径跟演员表演走 [S17][S18][S19]；WoW 客户端本身把施法动画、音效、挂点写在一条 SpellVisualKit 记录里 [S20]。→ 本剧技能写成一张**技能卡**，全剧一处定义。【T1+社，高】

#### 1.2 一键成片 / 特效模板

- 2.5「一键成片」＝多图 / 多视频拼短片，可加文字、贴纸、转场 [S1]，**不是技能特效模板**。
- 即梦「动作模仿」（2025-03-05）：一张人物图 + 一条参考视频 → 人物照做，最长 30 s，同步肢体与表情 [S28]；只锁动作。
- 即梦 app「AI 特效」模板（毛衣、剪纸、新春变身）只见于搜索摘要，未核；**没找到施法类技能模板**。【推】即便有，也是单图进、固定时长出，不能和 entity + 场景 + 台词同一次生成，本剧用不上。

### 5. 声音：同一技能同一套音

| 事实 | 来源 | 置信 |
|---|---|---|
| ElevenLabs 音效：0.5–30 s，可 loop；`prompt_influence` 越高「less variable」；API **无 seed** → 同 prompt 每次不同 | S15 | 高 |
| Seedance 可用音频参考定音效：2.0 案例「@音频 1：紧凑的鼓点或打斗音效……背景音效与 @音频 1 同步」 | S2 | 高 |
| 2.5 FAQ：写了禁 BGM，特效音仍可能被生成成 BGM；官方方案二是后期分离人声（会连音效一起去掉） | S1 | 高 |
| 文字台词与参考音频冲突时以文字为准，音频只给「音色、口音、语速和情绪」，除非明确要求复用音频台词 | S4 | 高 |
| 音色参考不准时，官方建议补细致的音色描述 | S2 | 高 |
| 可灵元素绑声只保证「sound the same」的音色 | S8 | 高 |
| 【仓】w19 §6 推荐四层声音全自制、去掉 Seedance 自生音（决策点 2）；本剧 `seedance.toml` 为 `audio_mode = "native"`，另有 `tts_first`（TTS 先生成、作 @音频 上传对口型） | 仓 | 高 |

**做法**【推，中】：每个技能两份定稿文件——`sfx.wav`（签名音）、`incant.wav`（口令，固定 voice_id、固定一次录音）。
- 口令镜：该句按 `tts_first` 例外处理，把 `incant.wav` 作 @音频 上传对口型，后期 mux 盖回同一文件。
- 施法瞬间：抹掉原生音效，贴 `sfx.wav`；同一 voice_id 只保证音色，不保证同一条。

### 6. 手段排序与无效做法

#### 6.1 按「效果 × 成本」排序

| # | 手段 | 管哪层 | 效果 | 成本 | 依据 |
|---|---|---|---|---|---|
| 1 | **声音资产化**：音效、口令各一个定稿文件，后期贴 | 声音 | 逐字节一致 | 低 | S15 S1 仓 |
| 2 | **技能样片作参考视频**：3–6 s、无脸无字中性背景；prompt 只写「参考@视频N 中施法的动作与光效，不采用视频中的人物和场景」 | 动作 + 特效 | 高（社区：约七八成） | 中：样片抽一次卡；每镜占 3–6 s 视频额度 | S1 S2 S4 S23 |
| 3 | **手势与时序确定化**：起手 / 释放写进 Cascadeur 共享姿势库；previz 放特效代理体（何时、挂哪、多大） | 动作 + 时序 | 高（确定性） | 中；要改 previz 合同 | 仓；S1（白模可带光影变化） |
| 4 | **技能卡一处定义 + 逐字锁定串**（颜色、挂点、秒级时序、代价） | 全部 | 必要不充分 | 低 | S2 S20 S17 |
| 5 | **定帧参考图**：峰值形态与颜色 1 张 | 特效形 / 色 | 中 | 低 | S1 S4（推） |
| 6 | **两步法**：先出无特效表演镜，再编辑加特效（参考样片） | 特效 | 中高，只给 hero 镜 | 高：两次生成；编辑 ≤20 s；短 0.33 s | S1 |
| 7 | **后期合成**同一特效素材（AE / 剪映） | 特效 | 像素一致，但写实融合难，需要互动光 | 高 | S16（LED 互动光同理） |
| 8 | Draft→正式 | 同一镜 | 只保同一镜 | 低 | S3 |

#### 6.2 对 Seedance 无效或不适用的做法

| 做法 | 为什么不行 | 证据 |
|---|---|---|
| 固定 seed | 2.x 不支持 seed；1.0 同 seed 也「不保证完全一致」；换 prompt / 参考即全变 | S3 |
| 只靠一段特效文字 | 官方 FAQ：文字描述特效会与预期不符 | S2 |
| 参考图上写「圣光术」之类的字 | 官方不建议只在图里标映射；字会进画面，中文易错字 | S1 |
| 用游戏录屏 / 带 UI、字幕的视频当样片 | 参考视频的字幕会被跟着生成，白模标记线会泄露；暴雪画面还有版权问题 | S1；仓 w19 / w25 |
| 用满素材上限 | 官方：特征优先级难判，风格冲突、主体识别模糊 | S2 |
| 一次生成同时参考 + 编辑 + 多特效 | 官方 FAQ：拆成多次简单任务 | S1 |
| 靠链式延长把特效带下去 | 多次续写叠加劣化 | S2 S26 |
| 平台特效模板 | 封闭；单图进、固定时长出，不能与 entity + 场景 + 台词同生成 | S9 S10（推） |
| 训特效 LoRA | Seedance API 无 LoRA / 微调入口；只有开源 Wan 路线可行 | S3 S13 S14 |
| 指望动作迁移工具把特效一起搬 | 可灵 Motion Control 只列动作、表情、运镜、朝向，背景等其他信息靠 prompt | S6 |
| 用强情绪词写施法（「狂热」「圣光从眼中迸发」） | 2.5 FAQ：情绪过度响应会让瞳孔发光；官方解法是写「人物为正常人眼、不发光」并换常规情绪词 | S1 |

### 7. 落地到本仓库（建议，待用户拍板）

1. **技能卡全剧一处**：`2_世界观人设/skills/{skill_id}/` 放 `skill.toml`（名称、学会等级、stance、hand、挂点〔照 SpellVisualKit〕、颜色、秒级时序〔起手 / 释放 / 生效 / 消散〕、代价、口令文本、voice_id）+ `ref.png` + `sample.mp4` + `sfx.wav` + `incant.wav`。
   - 现状问题【仓】：`[[casting]]` 在每集 `goals.toml` 各写一遍，ep01、ep02 都重新定义了亚伦的起手。这违反 rule 4i「一份东西一个出处」，跨集会漂。改成 goals.toml 只引用 `skill_id`。
2. **资料包自动挂样片并算额度**【推】：`casts` 里出现技能的镜，seedance_kit 自动挂 `sample.mp4` / `ref.png`；build 时核「previz 秒数 + 样片秒数 ≤30 s」，超了 raise（机制③：能量化的落成闸门）。
3. **挂了样片就少写**【官】：特效段只写指代句 + 锁定串里的颜色、挂点短语，不逐拍复述（官方：复述可能与素材冲突 [S4]）。现行 G7c 要求 prompt 写到 stance / hand / flow，短语级呼应不冲突，但不要扩成长描述。
4. **手势进姿势库**【推】：每个技能的起手 / 释放写成 `tools/cascadeur/poses.toml` 的命名部件（如 `cast_holy_gather`、`cast_holy_release`），各镜 choreo 只引用。
5. **previz 特效代理体要改合同**【仓 + 推】：`build_previz.py` 头注写着「特效形态一律不碰，交 Seedance」。若采用，只放「何时、挂哪、多大」的灰色体块，按 `ai_video_history.md` §G ID 色契约正反成对声明它是标记，外观仍交 Seedance。需用户决定。
6. **出片审片加一项**【推】：同一技能各镜抽峰值帧并排比颜色、挂点、形状。不一致就回到样片或锁定串去修，不在 prompt 里堆形容词碰运气。
