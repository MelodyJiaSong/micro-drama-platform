## 0. 结论

1. **一次生成里让多人各放不同特效、各归其主，目前没人能稳定做到。**
   - 论文：学界首个多特效空间可控方法 Omni-Effects，两种特效同屏时特效落对区域只有 0.41–0.50，超过两种还会下降 [M9]【论】。
   - 官方：Seedance 2.5 官方自评「极多主体交互场景的稳定性」仍待提升 [M5]【官】。
   - 公开示例：官方与社区都没找到「同段两人各放不同法术」的示例或对照实测。
   - 社区成片：三人同框那段，一人的紫光变成了另一人那样的蓝白电弧 [M33]【测】。
2. **所以业内一律靠「拆」，分四层：**
   - 时间上错开：一个 cut 一个主要出手、焦点施法满强度。
   - 空间上绑到人：特效挂在施法者或目标身上。
   - 外观用资产锁：技能卡、锁定图、bank 插入镜、定稿音。
   - 出错逐人修：一次只修一个人。
3. **Seedance 2.5 / 即梦现成可用的机制：**
   - 白模加按秒绑定的关键帧图（官方 30 s 例：1 条白模配 9 张图）[M1]。
   - 白模色块逐个映射到主体 [M1]。
   - 白模可以带光照 [M1][M5]。
   - 带时间戳的视频编辑，能「增加特效」；20 s 内较稳；两步法 [M1]。
   - 网页结果卡有「局部重拍」（截 4–30 s 窗口）和「视频帧标注」（在暂停帧上框人）[M7]【码】。
4. **逐帧实测官方样片，白模代理能定何时、何处，定不了长相**【测】：
   - 能定的：事件时刻误差约 ±0.35 s；不发光的黑色多边形也在同帧、同位渲成发光裂缝；硬切段之间特效不串。
   - 定不了的：同一代理、同一套参考，两次渲染一次冰蓝、一次紫色。
   - 分工因此是：代理管时空，锁定图加卡文字管外观，出片后回读核对。
5. **国内 AI 漫剧没有公开的技能特效资产化做法**【T1】。
   - 行业只把「道具与技能一致性」列为一类难题 [M35]；公开团队靠调关键词、抽卡、后期手修 [M35]。
   - 平台侧唯一先例是 Vidu 主体社区的「@剑圣 使用 @冰雨术 攻击 @苍玄」[M34]。
   - 本剧技能卡的方向领先于公开做法。

**本剧规模（机检，2026-09-30）**：
- ep01：原稿 5 镜施法全是单人。今天迁到技能卡后，S13 在同一连续段（16.3–22.5 s）里有三次施法：萨缪尔的力量祝福光带（黄→橙→红）、杜克的冲锋暗红拖光、亚伦的力量祝福。放段间隔 ≥ 1.7 s，但萨缪尔的光带与杜克的拖光重叠约 0.6 s，属同色相族撞车（冷眼观众也标了）。这是第一个试点镜。
- ep02：14 镜施法，其中 5 镜有两人以上。
  - S25：亚伦开光壳（3–8.5 s）后杜克才跺地（8.5–11.5 s），已经错开。
  - S33 / S35 / S37（拆镜前的 S32–S34）：苏伦娜的火与亚伦的圣光同框。橙与暖金色相相近，是第一批要按下文排的镜。
- 后续：ep07 组队打霍格、ep17–19 死亡矿井五人本，多人施法会成为常态；其中圣骑士与牧师同属圣光系。

## 1. 业内做法

| 做法 | 出处 | 管 | 对本剧 |
|---|---|---|---|
| 一个 cut 交代一个主要出手；出手与反应分镜；「停-爆-停」节奏 | 港片构成式剪辑，Bordwell [M24]（常用法，不是铁律：港片也用长镜头展示编舞） | 独立 | 一段一主施法者，放段错峰 |
| 焦点满强度，队友降级 | WoW 11.2 Spell Density：只降级队友特效（更淡、更小或换一套），自己、NPC、敌方永远满强度 [M17]；Riot 视觉层级表：每技能 1–10 重要度 [M20]；UE Niagara 按重要度只留前 N 个 [M23] | 独立 | 每段一个 full 串，其余用锁定的 reduced 串或只写动作 |
| 颜色撞了就改形状 | Overwatch 天使两道光束只差颜色，改「形状语言」[M22]；阿祖拉蓝火区别祖寇红火 [M28]；同一守护神咒每人一只动物核心 [M29] | 独立 | 圣骑与牧师同为圣光，靠方向、挂点、形状拉开（w26：圣光术自头顶罩下，牧师治疗从脚下往上冒） |
| 特效挂在人身上的固定挂点 | WoW SpellVisual：读条、出手段挂施法者，命中、状态段挂目标；挂点为头、胸、脚、左右手 [M18] | 独立 | 卡的每阶段写 anchor；命中与状态的主语一律是 target |
| 每人一层，分开合成 | 特摄《ミラクルちゅーんず！》五人合击：每人的光束与粒子单独成层，共 15 个 pass [M27] | 独立 + 一致 | 招牌大招可走后期合成 |
| 施法动作是封闭词表 | WoW 施法动画枚举：Ready / Cast / Channel × Directed / Omni [M18]；《降世神通》武术顾问按分镜机位录每一招 [M28] | 独立 + 一致 | Cascadeur 姿势库按职业分；同段两人同 pose 且时间窗重叠即拦 |

| 先定规则表，再照表演驱动 | 《时光之轮》postvis 按元素色编码并编舞化 [M29]；《权游》同一份预动画驱动灯光、火焰与爆点 [M29]；ILM《魔兽》见 w27 | 一致 | Cast.t 作唯一时间源，previz、prompt、sfx、后期共用 |

## 2. Seedance 2.5 / 即梦：官方机制、限额与实测

| 项 | 内容 | 出处 |
|---|---|---|
| 多主体写法 | 一行定义一个主体；写「两人的外貌、服装、动作、站位和台词不互相交换」；道具写「只属于<人物A>」（技能照道具槽写归属是推断） | [M2]【官】 |
| 主体数 | 主体图 1–8 个较好；有声主体（主体音视频）1–5 个较好；超过 5 个主体用单视图，多视角拆成多张 | [M1]【官】 |
| 编号 | 按人物首次出场顺序上传并同步编号；映射不要只写在图上，否则多人混淆或重复 | [M1]【官】 |
| 白模 | 色块逐个映射（「[图片1]…对应[视频1]中的红色模型」）；可带光影变化，写「参考[视频1]的光影变化」；每个几何体须单独映射；轨迹线、坐标线、相机锥会泄露；带四肢须补全动作序列 | [M1][M2]【官】 |
| 关键帧 | 30 s 例：1 条白模加 9 张按秒段绑定的图，「白模仅作为运镜、镜头运动和角色动画参考」；关键帧是语义锚，不逐像素对齐；全能参考里的首尾帧只能做到「相近」；严格首尾帧模式不收视频（三种任务互斥） | [M1][M2][M4]【官】 |
| 编辑 | 视频指令编辑可「增加特效」并限定时段；输入 20 s 内较稳；输出可能比输入短，≤ 0.4 s [M3]；两步法：先生成元素样片，再编辑原片（「形态与轨迹参考视频2，其余不变」）；API 无蒙版参数 | [M1][M3]【官】 |
| 网页额度 | 图 ≤ 30；视频 ≤ 10 段、合计 ≤ 30.2 s；音频同为 ≤ 10 段、合计 ≤ 30.2 s；素材总数 ≤ 50。主体按主图计 1 张，配音色另计 1 个音频，音色时长也计入 30.2 s；编辑时源片占 1 个视频名额并计入时长；生成提示词上限 15000 字，编辑 2000 字 | [M7]【码】 |
| 网页修复入口 | 结果卡「局部重拍」：截 4–30 s 窗口，按截取段计费。「视频帧标注」：在暂停帧上画矩形或箭头，带时间戳作图片参考。「重新编辑」回到原片，但不保留截取窗口。在 480P 样片上局部重拍的产物不能升正片 | [M7]【码】 |
| 反例：点名会配反 | 官方双人换装例写「深色衣服男子→图2、浅色→图3」，成片正好配反，按外观相似度分了。按衣色点名修人必须回读 | [M1]【测】 |
| 代理实测 | 时刻跟白模（±0.35 s）；位置大致跟；硬切隔开特效；外观不跟（同参考两次渲染，一次冰蓝一次紫）；同形代理不逐个映射时，一个实体被复制成两份（单样本） | [M1][M5][M30]【测】 |
| 社区 | 双人会被「合成一个人」：解法是强对比色、不同剪影、分站两侧、多次写「不合并」[M31]；模型会自己加光带、光环 [M31]；30 s 内换位常失败 [M31]；连续变形时前一状态残留（单例）[M32]；同一错误 4 批全中就别再抽 [M32] | 【社】 |

## 3. 推荐做法（按优先级）

| # | 做法 | 状态 |
|---|---|---|
| 1 | **排程先行**。规则：<br>① 一个硬切段只有一个主施法者；<br>② 异色施法之间必须有 previz 里定好的硬切；<br>③ 同段两人都出手先报 warning，等 A/B 定；<br>④ 放段错开 ≥ 1 s（整秒）；<br>⑤ 施法者一镜内不跨中线换边；<br>⑥ 同一人换技能前写明上一个的消散秒点；<br>⑦ 跨切的持续状态（光壳、燃烧）逐段重述 [M16] | 今天可用 |
| 2 | **prompt 绑定由卡生成**：<br>- 【人物】一行一人，不交换清单里加「技能特效」；<br>- 【技能】每个 Cast 一行：「{锁定串}只属于{who}，只在 a–b 秒」；施法句里不出现别的施法者名；<br>- 自动补「除{who}外，其他人手上、身上不发光」；<br>- 人数锁：「恰好 N 人，每人只出现一次，不合并」；<br>- 上传顺序按首次出场排；有声 entity ≤ 5 | 今天可用 |
| 3 | **视觉分离**：<br>- 每个技能有学派色（客户端七系学派色表 [M19]）加签名形；同学派同镜时，形状、方向、挂点至少一项不同；<br>- 每个特效都要有前兆和消散，残留尽量短 [M21]；<br>- previz ID 色避开同镜技能色（橙、红人偶对火球；紫人偶对暗影、奥术）；<br>- 非焦点施法用锁定的 reduced 串；<br>- 近景特效不上脸 | 今天可用；reduced 待 A/B |
| 4 | **外观走图，不走字**：<br>- 每个技能卡一张锁定峰值图，登记 sha256（Seedream 无 seed [M8]，只复用登记文件，不重抽）；<br>- 每个 Cast 从 previz 同机位、同一秒出一张峰值关键帧（施法者 entity 加锁定图，Seedream 可用涂色块定位 [M8]）；<br>- prompt 写「第 t 秒附近（参考图N）」，按点绑定，不绑一整段；<br>- 视频额度留给 previz；技能样片视频只在镜头拆成 ≤ 20 s 的段时挂 | 待 A/B（MC-C） |

| 6 | **招牌技能 bank 插入镜**：<br>- 每个（技能, 档位, 装备版本）一条 2–4 s 固定机位的手部或武器特写，单独生成（要严格一致就用首尾帧模式），定稿入库，在预留硬切处原样剪入；<br>- 做 2–3 个变体（镜像前看持锤手）；每集复用有上限 | 今天可做 |
| 7 | **修复单**（串了只修一个人，`tools/cast_repair.py` 生成）：<br>1. 在 1080P 底片的结果卡上点「局部重拍」，截 [起手前 2 s, 最后一个阶段结束后 0.5 s]（不足 4 s 补足）；<br>2. 用帧标注框住施法者、箭头指向目标；<br>3. 挂锁定图或样片；<br>4. prompt 写「其余人物与画面保持不变；标注线条不出现在画面中」，绑定句与原片精简稿同一函数（`skills_lib.binding_clause`，秒数换成窗口里的），窗口里别人的光写成保留项，同色分不开就整段重生；<br>5. 产物拼回（`--splice`，按帧对齐、声音保留底片）。<br>- 不在编辑产物上叠改，重试都回到底片；同一错误 4 次全中就停抽、回闸门。<br>- 兜底：SAM 3 按人出遮罩 [M15]，再用 Wan VACE 单人重绘 [M13] 或合成 | 入口已证实，行为待测（MC-E） |

| 9 | **中期，不当主路**：<br>- 高频技能在 Wan 2.x / LTX-2.x 上训特效 LoRA：社区先例用 13–32 段、25 s–2 min 素材，没有稳定性数据 [M14]；<br>- 招牌技能做 RGBA 元素后期合成，素材层逐字节一致（Wan-Alpha [M12]、Blender sprite 粒子、Seedream 5.0 透明图层 [M8]） | 观察 |

## 4. 不推荐 / 不适用

| 做法 | 原因 |
|---|---|
| 一次生成里让多人同一秒各放不同法术 | 学界最好的方法只有 0.41–0.50 [M9]；官方自评多主体一致性待优化 [M5][M6]；只做时间绑定时，动作仍会绑错人 [M11]；社区没有对照实测 |
| 用「左边 / 右边的人」指代施法者 | T2V-CompBench：左右常随机；两人常做成同一个动作，或漏掉一个 [M10] |
| 按衣色点名修人，不回读 | 官方例本身就配反了 |
| 多人动作迁移（可灵 Motion Control、Vidu 动作同步、Runway Act-Two） | 都只认一个人；Runway 官方做法是逐人裁切再合成 [M36][M37][M38] |
| 平台预设特效（Pika、Higgsfield Effects、可灵模板） | 不能定义本剧自己的技能 |
| Veo 3.1 / Sora 2 | Veo 参考只收单一主体；Sora 2 已于 2026-09-24 关停 |
| 把起手-释放-命中三拍拼进一张宫格图 | 官方：宫格只给大致剧情、不严格对齐；要严格对齐用多关键帧 [M1] |
