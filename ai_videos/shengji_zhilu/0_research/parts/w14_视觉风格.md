### 0.3 本路撞上的墙（和 sk2 撞的是同一堵）

**sk2 的结论「暴风城的长什么样主要存在于游戏资产里，不存在于文字里」，在野外区域上只会更严重。**

## 1. 魔兽美术方向：可指认特征清单

### 1.1 七条可指认特征（"一眼认出这是魔兽"的机制）

按「能不能写进 prompt」排序——**越靠上越可执行，越靠下越是审美总纲**。

| # | 特征 | 原文依据 | 可执行的中文写法 | 配对负向 |
|---|---|---|---|---|
| **F1** | **剪影优先**：角色靠轮廓辨识，不靠细节 | Chris Robinson「尊重原版**剪影**与风格」(`look.021`) | 「从任何角度、任何距离，人物的外轮廓单独抠出来仍能分辨是谁」——落实为**肩线宽于胯线、头小、手大、武器长** | `细碎剪影, 轮廓被披风吞掉, 头身比正常的写实人体` |
| **F2** | **夸张体格**：宽肩 / 大手 / 小头 / 厚甲 | 「Didier 的**极度夸张的体格**与鲜亮明快的色板主导了魔兽三代、魔兽世界……的美术风格」(`look.001`) | 见 §4 的三档比例方案——**不是一句「夸张比例」了事，要写死头身比与肩宽倍数** | `模特身材, 窄肩, 大长腿八头身, 纤细手腕` |
| **F3** | **鲜亮高饱和色板**，且**按区域分配** | 同 `look.001`；「为重要角色或物件选用**强色**：兽人用鲜绿，人类骑士用亮蓝」(`look.024`) | 每区锁一个**主色 + 一个补色**（§2.2），同区内所有镜共用 | `灰调写实, 低饱和纪实, 去色, 莫兰迪色` |
| **F4** | **手绘贴图的笔触感**（不是照片扫描材质） | 「模型与贴图**看上去是手工做的**，因为艺术家懂油画与泥塑」(`look.025`) | ⚠️ **这一条是四条路线的分水岭**：A/D 路线**要把它翻译掉**（改写成真实材质 + 做旧），B/C 路线要**保留**。不要两边都写 | 按路线相反，见 §3 |
| **F5** | **卡通化的解剖**：兽人肌肉变形、骑士甲过大 | 「**卡通化**的角色设计手法——兽人变形的肌肉组织、骑士身上过大的铠甲」(`look.023`) | 本剧主角是**人类**，兽人变形不适用；「过大的铠甲」**受版本与等级双重限制**，见 §4.3 | `巨型尖刺肩甲（低级阶段）, 发光的史诗套装（低级阶段）` |
| **F6** | **黑描边提高辨识度** | 「用**黑色描边**求清晰」(`look.023`) | ⚠️ **辨析**：魔兽**不用**赛璐璐式的后处理描边着色器；这个「描边」是**手绘贴图内部画出来的深色轮廓线**（甲片边缘、肌肉分块、布褶转折处的暗线）。当成「加一圈黑边」写进 prompt 会直接出动漫脸 | `赛璐璐描边, 动漫线稿, 卡通描边着色器, 漫画分镜感` |
| **F7** | **功能性起源**：夸张是为了俯视角的可读性 | 魔兽三代开发期试过写实风格但失败——写实比例在俯视视角下人物显小且混乱 (`look.039` ⚠️ 仅 T3 摘要) | 这条**不进 prompt**，但它是一条重要的裁决依据：**夸张的理由是「看得清」**。竖屏短剧的观看距离与画幅同样吃「看得清」，所以夸张**在本剧仍然有功能价值**，不是纯怀旧 | — |

### 1.2 版本分层：**Vanilla 的「夸张」比大众印象克制得多**（本路最反直觉的一条）

大众心里的「魔兽视觉」＝**资料片累积出来的**：发光的、带粒子的、肩甲比头大三倍的套装。
那是巫妖王之怒之后一路膨胀的结果。**经典旧世不是那个样子。**

| 层 | Vanilla 的实际口径 | 版本错置的典型表现 | 判据 |
|---|---|---|---|
| **装备体量** | 1–39 级几乎全是**素面甲片 / 布麻织物**；肩部多数槽位**空着**或只有一对小盖片 | 一上来就给主角一身尖刺肩甲 | `look.017` —— **「军团再临之前，战士与圣骑士 40 级才能装备板甲」**（原文引用，T1） |
| **起手装的真实样子** | 「侍从短裤」（Squire's Pants）＝**灰色（Poor）品质 · 布甲 · 物品等级 1 · 2 点护甲 · 卖价 1 铜**（⚠️ 国服 1.12 客户端串是**短裤**，不是长裤 # 核验修正（W14-V）） | 把主角画成「新手骑士锁甲」 | `look.018`（wowhead XML，T1） |
| **起手武器** | 「用旧的木槌」（Battleworn Hammer）＝**双手锤 · 物品等级 2 · 普通品质 · 3–5 点伤害 · 攻速 2.90**（⚠️ 国服 1.12 串是**木槌**，不是「久战之锤」，且「木」与本路写的铁锤头冲突 # 核验修正（W14-V）） | 给一把带圣光特效的长柄战锤 | `look.019`（wowhead XML，T1） |
| **发光特效** | ⚠️ Vanilla 的武器附魔光效**极少且暗**；角色**不会自带常驻辉光** | 主角浑身金光、眼睛发光 | `look.020` **只覆盖「眼睛」一半，且其原归因已被推翻（见 look.020 修正）**；「附魔光效极少且暗」「不自带常驻辉光」两句**本路无任何出处**，按 `ai_draft` 处理、须客户端截图升实后方可进 prompt ＋ 仓库既有纪律：`ai_videos__光线色调` L5「眼不发光」 # 核验修正（W14-V） |
| **饱和度** | 高，但是**颜料的高饱和**，不是**发光体的高饱和** | 把高饱和做成 HDR 过曝辉光 | 见 §3 的 D 路线参数 |

> **本条直接决定了本剧的一个核心机制**：**主角的视觉升级曲线＝观众的爽点曲线。**
> 从「灰品质布裤 + 破锤」走到「银亮锁甲 + 盾」再走到「40 级第一身板甲」——**如果第一集就给全套板甲，后面几十集就没有视觉爽点可发**。
> 这不是考据洁癖，这是**剧作资源管理**。见决策点 D3。

### 1.3 「魔兽味」的最小充分集（如果只能保三样）

给 style_guide 的一句话结论：

```
魔兽味 = ① 宽肩窄胯小头的剪影 + ② 每个区域一个高饱和主色 + ③ 蓝金狮纹 / 铁与皮革的装备形制
这三样保住，材质光线全部写实化，观众仍然认得出；
这三样丢掉，哪怕把手绘贴图照抄一遍，出来的也只是"某个欧美奇幻游戏"。
```

### 2.2 六区色板表（⚠️ 色值级一律待升实）

**读法**：`主色` 是该区最大面积的那一块；`阴影色` 是暗部往哪个色相偏（**不是「加黑」**，这是 sk1 §18.4 踩过的坑）；`光向 / 时段` 是该区的默认拍摄档；`介质` 是空气里必须有的那样东西（无介质＝渲染图的空气）。
**⚠️ 核验修正（W14-V）—— `hex` 一列全部降级 `ai_draft`，并撤销其原有用途。**
本次独立复核逐页实抓了六区的全部来源条目（Elwynn / Westfall / Redridge / Duskwood / Northshire Valley），**页面上不存在任何色值、色标、RGB 或 hex**；这一列 11 个 hex 是本路凭印象直接写下的数字，**零取数依据、无任何来源可对账**。
原写法「仅供调研对账与 Blender/previz 取色」给了它一个它不配有的用途——**没有出处的色值拿去 previz 取色，等于把编出来的颜色焊进全剧底座**，而色板一旦焊死，返工代价是全剧（§0.3 / D1 自己已经论证过这一点）。
**在 §2.3 两条路线之一取到真数之前，这一列不进 prompt、不进 Blender/previz、不进 style_guide、不作任何取色依据**，只作「待替换的占位」保留。下游若已引用，按 `ai_draft` 全部作废重取。

**四条跨区纪律**（比单区色板更重要，因为它们是**剧集推进的视觉证据**）：

1. **相邻两区必须在画面上一眼分得开。** 主角「升级换图」的叙事爽点，靠的就是**画面色相突变**。艾尔文（翠绿）→ 西部荒野（枯黄）是全剧最强的一次色相切换，应当当成**一个正经的 hero 镜**来拍（跨桥／出林／风车入画三选一），不要当过场。
2. **色板是条件化的，绝不写进全片共用 `渲染样式:` 串。** 这是 `ai_video.md` 16.9 已经用两部片的污染事故写死的规则：把「暮色森林的黑雾」写进共用串，艾尔文的白天镜就会被要求画黑雾。共用串只放**对每一镜都成立**的东西（影像质感 / 颗粒 / 镜头缺陷 / 零文字禁令）。
3. **没有该介质的镜要反向声明。** 例：艾尔文日景镜须写「本镜画面里没有任何雾、没有任何黑色烟霭」并挂灭雾负向组。
4. **暮色森林不是黑白片。** 「近黑」是**明度**低，不是**饱和度**为零。负向必挂 `黑白, 去色, 单色调`；正向必写「暗部仍保留蓝绿色相」。

### 2.3 色板取数的两条可执行路线（把 ⚠️ 升成 `human` 的办法）

> 这是本路给出的**方法论增量**——sk2 的解法是「看图写形制串」，本路发现色板还有**第二条更硬的路**。

**路线甲（数据层，最硬）：从游戏自己的光照表取。**
魔兽的天光 / 雾 / 水色不是美术在每张贴图上画的，而是**一张数据表**。`wowdev.wiki/DB/LightData` 的字段表（`look.032`，已抓到原文）逐字为：

```
m_ID / m_lightParamID / m_time / m_directColor / m_ambientColor /
m_skyTopColor / m_skyMiddleColor / m_skyBand1Color / m_skyBand2Color /
m_skySmogColor / m_skyFogColor / m_sunColor / m_cloudSunColor /
m_cloudEmissiveColor / m_cloudLayer1AmbientColor / m_cloudLayer2AmbientColor /
m_oceanCloseColor / m_oceanFarColor / m_riverCloseColor / m_riverFarColor /
m_shadowOpacity / m_fogEnd / m_fogScaler / m_cloudDensity / m_fogDensity
```

- `m_time` ＝ 一天内的时刻（半小时一档），所以**每个区域每个时段的天顶色、地平带色、雾色、雾距、阴影浓度全部是可查的数字**。
- 配套表 `Light.db2` 用「地图 + 世界坐标 + 半径」把某片区域指到某个 `LightParams`——**这正好能和 W01 已有的 GM 世界坐标锚点对上**。
- ⚠️ **色值编码（RGB 还是 BGR）字段表没写**，必须实测两张已知色（如暮色森林的黑雾）反推，不能想当然。
- ❌ **本次没取到数值**：`wago.tools/db2/LightData/csv?build=1.15.5.57638` WebFetch 60 秒超时、curl 返回 000（本机网络受限）。**要么由用户在浏览器打开导出 CSV，要么在本地客户端 `Data/` 里用 CASCExplorer + DBCD 导。构建号必须锁 Classic Era（sk2 在票价那条已经踩过「不锁构建就整段版本错置」的坑）。**

**路线乙（图进人眼，沿用 sk2 #108）：客户端截图 → 人读色 → 写中文色名串。**
- 优先级：① 艾尔文森林正午 + 黄昏 ② 西部荒野下午（要拍到风车与黄草的关系）③ 暮色森林（永夜，要拍到黑雾的两层）④ 赤脊山黄昏（要拍到红岩被打亮的那一刻）⑤ 北郡山谷上午。
- **每区 4 个时段（晨 / 正午 / 黄昏 / 夜）各 2–3 张**，落 `ai_videos/{drama}/0_research/ref/{zone}/`，`refs.md` 每条标「暴雪版权 · 只作色板依据 · 不入画 · 不上传给生成模型」。
- **铁律沿用 sk2 卫兵那次的教训**：**形制与色值都不能从远景图读**，要放大到部件级；**一张图得出的结论在被第二张印证之前只能算 ⚠️**。

**旁证（说明这条路线是对的）**：暴雪自己重做 Classic 光照时走的就是路线乙——「团队**拿原版 1.12 调试客户端当参考，逐个时段复核，重建光照与大气以匹配各区域原本的性格**」(`look.034`)；暮色森林的做法是「叠月光、局部光、间接照明与数层雾效，再**调弱较强的后期处理**以贴合该区域为人熟悉的氛围」(`look.035`)。**连原厂都认为「每区的光是它的身份」且必须逐时段对照原版重建**——我们没有理由用推测代替取样。

## 3. 四条渲染路线：逐条利弊与示例 prompt 片段

### 3.0 先把评判轴定下来

| 轴 | 含义 | 为什么它是轴 |
|---|---|---|
| **① 辨识度** | 老玩家能不能一眼认出「这是艾尔文森林/这是圣骑士」 | 本剧的观众基本盘就是玩过的人，认不出＝没有意义 |
| **② 生成稳定性** | Seedance 能不能在几十集里稳定复现 | 一条路线再好看，如果十镜出九镜废，成本不成立 |
| **③ 平台合规** | 会不会被判「游戏素材搬运 / IP 侵权」 | 见 §7 |
| **④ 与系列基调的一致性** | 与本仓库既有片（sk1 实拍感 / sk2 半写实）是否打架 | 本剧是**独立新剧**，可以不一致，但要**有意识地**不一致 |
| **⑤ 竖屏适配** | 9:16 里还成不成立 | 见 §5 |

### 3.1 路线 A · 影视级真人写实奇幻（对标 2016 年电影《魔兽》）

**是什么**：把魔兽当成一部真人奇幻电影来拍。真人比例、真实皮肤毛孔、实拍光学、脏旧材质。
**原厂旁证**：导演邓肯·琼斯把这部电影的定位描述为 **"somewhere between Planet of the Apes, Fellowship of the Ring and Avatar"**（`look.026`，T1）——即**猩球崛起的表演捕捉 + 魔戒的实景奇幻 + 阿凡达的世界构建**，而不是「把游戏画面提高分辨率」。VFX 总监 Bill Westenhofer 的工作方式是**把游戏当形制参考查**（「我可以登录游戏给邓肯看：喏，暴风城在游戏里长这样」`look.027`），而**实现手段是实拍**——「我们**真的把那些铠甲做出来**，穿在一个健美运动员身上，让他穿着走遍每一个实景」(`look.028`)。

| | 内容 |
|---|---|
| **利** | ① 与 sk1 的 GoT 实拍感资产**完全共用**（摄影事实串 / 做旧层 / 真实暗部三条直接搬）；② Seedance 对「真人写实」这一档的训练最厚、**出图稳定性最高**；③ 平台合规最安全（画面上没有任何游戏味）；④ 竖屏人物戏最好拍 |
| **弊** | ① **辨识度风险最大**——把夸张全部抹平之后，艾尔文森林会变成「一片欧洲阔叶林」，暴风城会变成「一座通用中世纪城」；② 写实化的人体**扛不住魔兽的装备体量**，到了后期套装会显得滑稽或者必须缩水；③ 高饱和色板与写实调色天然冲突 |
| **适合** | 人物近景戏、情绪戏、夜戏、对话戏 |
| **不适合** | 定场大景、名场面复刻、法术特效镜 |

**示例 prompt 片段（`渲染样式:` 行）**
```
实拍电影画面，Super-35 传感器，定焦镜头，f4，1/48 秒快门的自然运动模糊；
高光柔滚不死白，暗部厚实、檐下与林隙允许掉到接近黑、不补光不抬亮；
画面边缘轻微变松、很淡的暗角，高光边缘极轻微色散，细腻不均匀的胶片颗粒；
不是全景深——焦点在主体，越远越淡越软越偏蓝灰。
```

### 3.2 路线 B · 暴雪 CG 过场动画质感

**是什么**：写实的材质与光照 + **保留的夸张比例与强轮廓** + 戏剧化布光。即暴雪自己在过场动画里做的那件事——**它本身就是「把游戏美术翻译成影像」这道题的官方解**。

| | 内容 |
|---|---|
| **利** | ① **辨识度最高**——这是绝大多数观众心里「魔兽的高清样子」；② 它天然解决了 §4 的比例难题（暴雪自己已经解过一遍）；③ 戏剧光与高饱和不打架；④ 名场面复刻最有力 |
| **弊** | ① **离「CG 动画」只有一步**，一旦滑过去就撞上 sk1 被整体否掉的那个坑（「太像动画，不像真实场景」）；② Seedance 对这一档的稳定性低于真人写实档，**同一角色跨镜漂移概率更高**；③ 与仓库既有两部片的基调差最远 |
| **适合** | 定场、名场面、法术特效、群像 |
| **不适合** | 长时间的日常对话戏（容易露出动画感） |

**示例 prompt 片段**
```
影视级 CG 过场动画质感，真实材质与全局光照，人物比例略作英雄化夸张；
强轮廓、清晰可读的外形；戏剧性布光——单侧主光 + 明确的轮廓逆光勾边；
真实皮肤次表面散射与毛孔，金属有真实的磨损与反射，布料有真实的重量与褶皱；
大气介质明显，光柱可见。
```

### 3.3 路线 C · 游戏实机感 / 手绘风

**是什么**：直接做成游戏画面的样子——手绘贴图、平光、纯色块。
**裁决：不推荐，且建议明确排除。** 三条理由都是硬的：

1. **合规**：越像游戏截图，越靠近「游戏素材搬运」的判定边缘（§7）。
2. **仓库纪律**：sk2 的 `myth.014` 已经把 `游戏截图, 游戏引擎渲染, UI 界面, 血条, 名字牌, 低多边形, 卡通渲染, 赛璐璐描边, 塑料高光, 过饱和, 3D 建模预览, 白模, 灰模` 整块挂进负向（`过饱和` 原文有、本路两处引用均漏抄 # 核验修正（W14-V））；选 C 等于要把这块负向反过来当正向，与既有基础设施正面冲突。
3. **观众**：观众可以直接去看实机录像，没有理由看一个不如实机的仿制品。**短剧的增量只能来自「游戏给不了的画面」。**

（保留一个例外用法：**主角的「系统界面 / 技能书 / 角色面板」**如果决定入画，那**必须**是游戏 UI 的样子——这是 UI，不是场景渲染，不在本条排除范围内。见 D2。）

### 3.4 路线 D · 半写实（sk2 `divergence #107` 已选的那条）

**是什么**：**形制、配色、比例忠于游戏；材质、光线、皮肤、大气走写实电影级。**
sk2 选它的理由逐字是：「纯写实会让老玩家认不出这是暴风城（辨识度正来自游戏的夸张形制）；纯游戏风又与系列实拍基调正面冲突」。

| | 内容 |
|---|---|
| **利** | ① **本仓库唯一一条已经有配套基础设施的路线**——负向块、色温三角写法、零文字纪律、参考图政策全部现成；② 辨识度与稳定性都在中上；③ 跨剧一致（如果将来想把本剧与《时空旅行》放在同一个频道下，风格不打架） |
| **弊** | ① 「半」是个**区间不是点**，不把参数写死就会每镜漂；② sk2 的参数是为**一座真实感的城**调的，本剧有**法术、怪物、非人种族**——sk2 的参数覆盖不到这些 |
| **与 B 的真实距离** | **比想象中近。** B 就是「半写实把夸张系数调高」。建议把 D 与 B 合并理解为**一根滑杆**，然后**按镜型分档**（见下） |

### 3.5 裁决矩阵与本路推荐

| 轴 | A 真人写实 | B 暴雪 CG | C 游戏实机 | D 半写实 |
|---|---|---|---|---|
| ① 辨识度 | ★★☆☆☆ | ★★★★★ | ★★★★★ | ★★★★☆ |
| ② 生成稳定性 | ★★★★★ | ★★★☆☆ | ★★★☆☆ | ★★★★☆ |
| ③ 平台合规 | ★★★★★ | ★★★★☆ | ★★☆☆☆ | ★★★★☆ |
| ④ 系列一致性 | ★★★★☆(sk1) | ★★☆☆☆ | ★☆☆☆☆ | ★★★★★(sk2) |
| ⑤ 竖屏适配 | ★★★★★ | ★★★★☆ | ★★★☆☆ | ★★★★☆ |

> **本路推荐：走 D，但把「夸张系数」做成一根按镜型分档的显式滑杆，而不是一个含糊的「半」。**
>
> | 档 | 夸张系数 | 用在哪 | 写法差异 |
> |---|---|---|---|
> | **D-低（≈A）** | 头身比 7.5、肩宽 ≈2.0 头宽 | 对话戏、情绪戏、夜戏、旅店内景 | 摄影事实串全开，不写「英雄化比例」 |

> **理由**：① 短剧的镜型分布本来就极不均匀（大量对话 + 少量名场面），用一个参数去服务两种需求必然两头不讨好；② 这条同时解决了 §4 的比例难题——**比例不是一个全局决定，是一个按镜决定的变量**；③ 它把「半写实」从审美词变成**可执行、可机检的数字**，符合仓库「能量化的反馈必须落成可机检闸门」的既有纪律。

## 4. 人物比例：写实化之后还「像不像魔兽」

### 4.1 先把问题拆对

魔兽人类男性的夸张不是「一个夸张」，是**四件互相独立的事**，可以分别取舍：

| 层 | 游戏里的样子 | 写实化之后 | 取舍建议 |
|---|---|---|---|
| **① 头身比** | 约 6–6.5 头身，头明显偏小 | 7.5 头身（真人） | **可调，按 §3.5 三档滑杆** |
| **② 肩胯比** | 极宽的肩、窄胯，近似倒三角 | 真人 ≈1.6–1.8 头宽 | **必须保**——这是剪影的主承重墙（F1） |
| **③ 手与前臂体积** | 大手、粗前臂（"barrel arms"、"stocky body" 是玩家对旧模型的普遍描述，`look.021/022` 官方承认「比例怪异」） | 正常 | **部分保**：手偏大一档即可，不必做成拳套感 |
| **④ 站姿** | 微驼、重心前压、双臂外张（大猩猩式站立） | 直立 | **建议不保**——这是旧模型被诟病最多的一点，暴雪自己重做时就在修它；强行复刻会让观众觉得「演员姿态怪」而不是「这是魔兽」 |

> ⚠️ **核验修正（W14-V）**：本表「游戏里的样子」一列的**全部数值与形容**（6–6.5 头身、肩宽/头宽倍数、"barrel arms"、"stocky body"、大猩猩式站立）**本路没有取到任何出处**，`look.021/022` 两条 PCGamesN 引文只说到 "odd proportions and face geometry"，不含上述任何一项。这些数字须按 `ai_draft` 对待，**落 prompt 前用客户端/模型查看器实测**。§3.5 三档滑杆里的 7.5/7.0/6.5 与 2.0/2.4/2.8 是本路的设计提案，不是游戏事实，不受此条影响。

**官方口径正好给了我们一句护身符**：美术总监 Chris Robinson 谈重做人类男性模型时说——**「我们的目标是**尊重原版的剪影与风格**，同时提高精度、修掉我们发现的几个大问题」**（`look.021`），并直言旧模型「长期因为**比例怪异与面部几何**被批评」（`look.022`）。
**这就是本项目该做的同一件事**：**保剪影与风格，修比例与面部**。暴雪自己都这么干了，我们跟着干不算不忠于原作。

### 4.2 所以「写实化之后不像魔兽」的真正原因，往往不是身材

实测逻辑很简单：把一个 7.5 头身的真人穿上**蓝金狮纹罩袍 + 熨斗形包金边盾 + T 形观察缝头盔**，没有人会认不出那是暴风城卫兵。
**辨识度的承重墙是装备形制与配色，不是人体比例。**
反过来，把一个 6 头身的夸张身材穿上通用中世纪链甲，也没有人认得出那是魔兽。

> **结论：比例排在第三位。第一位是装备形制，第二位是区域色板，第三位才是身材。**
> 这条直接影响资源分配——**该把调研与建卡的力气压在装备卡与色板上，而不是在头身比上反复试**。

### 4.3 真正会翻车的比例陷阱：**装备等级，不是身材**

这是本路最想让用户看见的一条。

| 陷阱 | 为什么一定会犯 | 后果 | 修法 |
|---|---|---|---|
| **给低级主角穿高级套装** | 生成模型对「World of Warcraft paladin」的默认输出**就是**零售版的发光史诗套装（训练数据里这类图占绝对多数） | ① 版本错置（`look.017`：40 级前根本穿不上板甲）；② **把全剧的视觉爽点一次性泄光** | 每一张主角 shot 的 `角色:` 串里**写死当前等级段的甲类与品质**，并把 `发光的史诗套装, 巨型尖刺肩甲, 附魔光效, 全身板甲` 挂进 1–39 级镜的负向 |
| **肩甲一步到位** | 同上 | 剪影从第一集起就到顶，没有成长感 | 把「肩部槽位」当成一条**显式的剧作曲线**：1–20 级空着 → 20–40 级一对素面小盖片 → 40 级第一对真正的板甲肩 |
| **武器一步到位** | 「圣骑士＝圣光战锤」是最强的刻板印象 | 同上 | 起手是**「用旧的木槌」（Battleworn Hammer）：双手锤、普通品质、3–5 点伤害、攻速 2.90**（`look.019`）——一把旧的、朴素的、不发光的**木槌**（⚠️ 原作写「久战之锤……木柄铁锤」，译名与材质双错，见 look.019 caveat # 核验修正（W14-V）） |

**给主角写一条「装备可视化时间线」，当成和人设卡同级的资产卡来管**（建议落 `2_世界观人设/props/` 或角色卡内的专节）：

| 等级段 | 甲类（硬依据） | 肩 | 武器 | 剪影关键词 | 画面上的「升级瞬间」 |
|---|---|---|---|---|---|
| 1–9 | **布甲 · 灰色品质**（`look.018`） | 无 | 用旧的木槌（双手锤） | 瘦、软、没有轮廓 | — |
| 10–19 | 皮甲 / 杂色布 | 无 | 单手锤 + 小圆盾 | 出现**盾的轮廓** | 第一次有盾 |
| 20–39 | **锁甲**（板甲要到 40，`look.017`） | 一对素面小盖片 | 单手锤 + 骑士盾 | 肩线开始变宽 | 第一次反光的金属 |
| 40 | **第一身板甲** ＋ 圣骑士坐骑 | 真正的板甲肩 | — | 剪影完成 | **全剧第一个真正的视觉高潮** |

> ⚠️ **核验修正（W14-V）——这张表是剧作曲线，不是游戏规则，两者不能混着引。**
> 表里**唯一有硬依据的闸门只有「40 级板甲」**（`look.017` T1）。「1–9 布 → 10–19 皮 → 20–39 锁」这一段**不是经典旧世的熟练度规则**：warcraft.wiki.gg 的 Plate armor 条目在叙述军团再临的改动时逐字写着 "Paladins and warriors now begin with plate armor at level 1 **instead of mail armor**"——反推可知**经典旧世的圣骑士从 1 级起就有锁甲（mail）熟练度**，20 级之前穿不上锁甲的限制并不存在。同理「肩部槽位 1–20 级空着」也**无任何出处**，经典旧世的肩部槽位没有等级门槛。
> 因此：这条曲线作为**剧作资源管理**完全成立（D3 的推荐不受影响），但**不得以「原典规定」为由写进 style_guide 或资产卡**——它只是「主角买不起/打不到更好的」这一处境的合理外化。

### 4.4 电影侧的比例经验（可借鉴的一条）

电影把兽人做到 **6 英尺 6 到 7 英尺 2** 的身高区间，且「大多数动捕替身接近真实身高，**体量感是靠厚度堆出来的**」（`look.031` ⚠️ T3，仅搜索摘要、未抓到原文页）。
**可迁移的方法论**：**别靠拉长骨架做体量，靠加厚与加宽做体量。** 这正好和 §4.1 的裁决一致——保肩胯比（宽），不必大改头身比（长）。

## 5. 竖屏 9:16 与魔兽景观

> **先写指针，别重造轮子**：仓库已有成熟的竖屏速查表 —— `.claude/agent_refs/project/ai_video_yunjing.md` §4「9:16 竖屏适配速查」（航拍走垂直维度 / FPV 选纵深路径 / 甩镜改竖甩 / POV 最适配 / 低机位写「全身完整入画」/ 横画幅例句一律改纵深）。
> 还有 `.claude/agent_refs/project/ai_video_jingbie.md` §2.0 的景别跳档量尺（`人占画高` 比值 ≥2.0 / ≤0.5），以及 CLAUDE.md 那条【TOP PRIORITY】切口纪律。**本节只补魔兽特有的三个冲突。**

| 冲突 | 为什么在魔兽上尤其严重 | 对策 |
|---|---|---|
| **① 宽阔草坡** —— 艾尔文/西部荒野的辨识度来自**横向的广阔**，而 9:16 把横向砍掉三分之二 | 「一片草坡」在竖屏里就是「一条绿带」，认不出是哪个区 | **不靠横宽，靠纵深与垂直分层**：前景（一丛蕨/一段栅栏/主角的肩背）→ 中景（那个区的标志物：艾尔文的农舍与溪桥 / 西部荒野的风车 / 赤脊山的红岩脊 / 暮色森林的枯枝）→ 远景（山脊线）。**每一个野外定场镜必须写满这三层**，否则竖屏定场必然失败 |
| **② 城市天际线** —— 暴风城的辨识度是**蓝色尖顶母题在三个尺度上重复**（sk2 §一9），而三个尺度天然是横向铺开的 | 竖屏塞不下一条天际线 | **把母题竖起来**：仰角构图，让**最小尺度（街灯灯笼顶）压在画面下方前景、中尺度（民居圆锥顶）在中段、最大尺度（大教堂尖塔）顶在画面上缘**——三个尺度沿竖轴排列，一镜之内仍然同时出现两到三个。**这是 sk2 那条母题在竖屏里的正确用法，sk2 自己没写过** |
| **③ 巨型肩甲与竖幅** | 肩甲是横向的，竖屏里人物一近就只剩两个肩片 | ① 低级阶段本来就没有大肩甲（§4.3），问题被自然推迟；② 到了有肩甲的阶段，**近景取「肩—头」斜切构图**（一侧肩甲入画压住下缘、头在上三分），既显体量又不占满横幅；③ 全身展示肩甲一律走**低机位仰拍全身 + 「全身完整入画」**（yunjing §4 已有写法） |

**两条附加纪律**
- **战斗镜优先竖向调度**：扑击 / 下劈 / 后仰 / 起跳 / 被击退后坐 —— 这些是竖轴动作，天然适配；**横向的左右对冲**在竖屏里两个人会同时出框，要么改成前后纵深对冲，要么改机位走过肩。
- **「广阔」的替代表达是「重复」**：拍不下一片麦田，就拍**前景三根麦秆 + 中景一排同样的麦秆 + 远景一条黄色的带**——重复单元比画幅宽度更能传达广阔，且竖屏友好。

## 7. 平台合规：IP 专名能不能进生成块

> 本节是本路在调研中撞出来的、**不在提纲里但必须上报**的一项。

仓库已有硬规则（`ai_video.md` §563，per follow-up nvdi 020，多次实测）：

> 「prompt 内**禁止出现任何 影视剧名 / 画作名 / 景点名 / 游戏名 / 真人(导演/演员/作者)名**（如……**剑网3 / 逆水寒 / 阴阳师**……）——参考锚改为**不点名的通用描述**。」

**这条规则点名的例子里，三个全是游戏名。** 本剧是一部**从头到尾建立在一款游戏之上**的片子，所以必须提前把边界画清楚，否则会在出第一批图时整批被拒。

**建议的三级口径（待用户拍板，见 D4）**：

| 级别 | 词 | 进生成块？ | 理由 |
|---|---|---|---|
| **红 · 绝对不进** | 魔兽世界 / World of Warcraft / WoW / 暴雪 / Blizzard / 艾泽拉斯 / 电影《魔兽》 / 任何真人名 | ❌ | 游戏名 + 公司名，规则明文禁止 |
| **黄 · 待测，默认不进** | 暴风城 / 艾尔文森林 / 西部荒野 / 暮色森林 / 圣骑士 / 兽人 / 豺狼人 / 迪菲亚 | ⚠️ | **世界内专名**。sk2 的角色卡生成块里**已经在用「暴风城」**（如 c22「暴风城摄政」、c31「暴风城卫兵」），但据查 sk2 尚未跑完出图，**这条写法没有被实测验证过**。诊断法按 §563④ 的三分法：先 text-only 试跑，看触发在名字还是内容 |
| **绿 · 放心用** | 一切**不点名的形制描述**：「蓝色陡坡瓦顶的白石城」「群青蓝底金狮纹罩袍的城市卫兵」「持双手锤的年轻圣殿骑士」「灰绿皮肤的獠牙类人战士」「直立行走的鬣狗类人形怪物」 | ✅ | 这正是 sk2 #108 流程的自然产物——**形制串本来就是「不点名的通用描述」** |

**同时要注意的两条**：
- **武器特写触发率高**（`ai_video.md` 2026-06-18 实测）：刀剑刃口 / 显式兵器在**视频**审核里比静图严。本剧是打怪剧，**这会是高频问题**，建议起手就把「刃口特写」类镜改成「击中反馈 + 对手受击」类镜。
- **负向词同样过审**（2026-06-30 实测）：负向里写「不要血腥」会因为「血腥」二字命中关键词。本剧的战斗负向必须用中性正向描述替代，不能靠含违禁词的否定句。

### D2 · ★ 游戏 UI 能不能入画？（本路发现的最大创作分叉）

**背景**：sk2 定了「画面零文字 / 零 UI」硬约束，负向里挂着 `UI 界面, 血条, 名字牌`。那条规则的前提是**「一个真人穿越进了一座真实的城」**——UI 出现就是穿帮。
**但本剧的前提完全相反：主角本身就是一个玩家，他眼里本来就有 UI。** 这时 UI 不是穿帮，可能是**本剧最独特的叙事装置**——等级条涨满、技能图标亮起、任务感叹号、组队框、装备提示——这些是**只有这部剧能用、别的奇幻剧用不了**的东西。

| 选项 | 内容 | 后果 |
|---|---|---|
| **① 全零 UI** | 完全当成一部真人奇幻剧，观众自己靠画面理解"他升级了" | 最干净、最像电影；但丢掉本剧最大的差异化资产，且"练级"这个核心主题在画面上**没有表达手段** |
| **② 全 UI**（像实机录像） | 血条、名字牌、任务框全在 | 立刻变成游戏录像，撞 §3.3 的三条排除理由 |
| **③ 分层：世界零 UI，主角视角有 UI** | 绝大多数镜零 UI；只在**主角的主观镜（POV）/ 关键节点（升级、学新技能、拿到装备）**让极简 UI 元素浮现 | 需要额外定一套 UI 设计规范（字体、透明度、动效），且 UI 上有文字 → 与"画面零文字"纪律要单独开例外 |
| **④ 分层 + 零文字 UI** | 同③，但 UI 只用**图形与光效**，不出现任何文字数字（等级用光环圈数、技能用图标、升级用一道金色冲击波） | 兼顾差异化与零文字纪律；但表达精度下降 |

**我的推荐：③，且把 UI 当成一个正式的"资产卡"来建。**
**理由**：① 本剧的核心动作是**练级**，而练级在画面上是不可见的——没有 UI 就只能靠台词硬说，那是最差的表达；② ③ 把 UI 关在"主观镜"这个笼子里，世界本身仍然是可信的实拍质感，两边都不丢；③ 至于文字——仓库的"零文字"纪律真正的理由是**生成模型渲染不好文字**，而 UI 上的文字完全可以**后期贴**（就像字幕一样），这在技术上不冲突；④ 选④会让"升到 10 级"这种信息变得晦涩，得不偿失。
**但这条我推荐得最不坚定**——它牵动全剧气质，你可能有完全不同的直觉，请务必自己定。
