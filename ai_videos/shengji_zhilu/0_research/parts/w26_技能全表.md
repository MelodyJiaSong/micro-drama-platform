**四路共同的结论**
1. 1.12 玩家施法**没有台词**（客户端法术链只挂音效）；口令只能借训练师 / NPC / 魔兽 3 / 炉石原句，或本剧自定——自定的要写成本剧偏离。
2. 同一法术各阶外观不变，只有读条变长；同名法术谁放都是同一套外观（NPC 的火球除外：3 s 读条、大号弹体）。
3. 有读条的法术都是「双手蓄光 → 单手上举或前送」；瞬发的没有蓄光；物理技能不出光，靠动作、声音、镜头一震。
4. 一个法系一套颜色：圣光暖金 / 白金，火＝白热芯 + 橙黄火舌，冰＝深蓝旋涡 + 青白亮边，奥＝淡青白，暗影＝紫 + 黑烟，自然 / 治疗（怪）＝黄绿，毒＝绿。
5. 光从哪来、落在哪是区分同色法术的关键：圣光术从头顶罩下，牧师治疗从脚下往上冒，惩击 / 审判 / 心灵震爆**没有飞行物**。

### C. 一致性要点（最容易跨镜漂的）

1. **光的方向**：圣光术＝光柱自头顶罩下；牧师治疗＝细光束从脚下往上冒；惩击＝金光痕从目标上方斜劈进胸口；审判、惩击、心灵震爆都**没有飞行物**。三种方向一旦写混，两个奶就分不出来。
2. **同模型撞脸**：两职业神圣读条是同一双手暖金光；圣印＝心灵之火（脚下王冠符文环）；救赎＝复活术；绝望祷言＝圣疗术。同一镜里两人同时施放时，要靠落点与动作区分，别靠换颜色。
3. **三种「罩子」**：真言术：盾＝竖椭圆光圈（只有边）暖金；圣佑术/圣盾术＝带星点的蛋形光壳；保护祝福＝银白偏淡蓝光壳。形状、颜色、时长（30 s / 6–10 s / 6 s）各锁一个串。
4. **颜色锁**：神圣＝暖金/白金；暗影（痛、震爆、尖啸、渐隐）＝紫＋黑烟；祝福按种类分色（若本剧保留出光）；惩罚光环、正义之怒＝红。
5. **手势**：治疗/增益＝双手捧光→单手上举；指向类（惩击、震爆、审判、圣疗术、驱邪）＝一手伸向目标；心灵尖啸＝仰头吼；制裁之锤＝空手前击。圣疗术、保护祝福原典都**不接触**目标（30–40 码）。

#### §S 潜行怎么拍

原典「七成透明」是画给玩家自己看的（V4 能透过身体看见地面）；在敌人眼里他根本不在画面里。`world.md:70` 已把「半透明的自己」给了灵魂态（数据里灵魂也是 0.5 透明），两者会撞。

| 方案 | 做法 | 用在 |
|---|---|---|
| **A 影子（推荐）** | 人是实体。进潜行固定三拍：拉起兜帽 → 肩一沉 → 换成脚尖先落的慢步；颜色随之暗下半档，衣角融进背景的暗处；声音固定为「布料一收加一口气吐尽」。敌方视角里，他只是焦外暗处的一团影子。第一次潜行要配一镜：敌人的目光扫过他，没有停下 | 全部潜行镜 |
| B 原典淡影 | 七成透明、去色，能透过身体看见后面的纹理 | 只用于我方视角的短插；全剧只用这一种淡影 |
| C 纯表演 | 不做任何视觉处理，只靠走位和遮挡 | 写实段落 |

出潜行的规矩：出手的第一刀就现形（原典攻击即破潜行）；疾跑和扰乱不破潜行（T 原文）。

### C. 一致性要点

1. **战士的吼只有一个姿势**。战斗怒吼、挫志怒吼、嘲讽、换姿态都是同一个 BattleRoar：仰头、挺胸、张口。三种吼靠颜色和落点区分：战斗怒吼是红橙月牙、贴地向外；挫志怒吼是蓝色月牙；嘲讽只在被嘲讽者头顶有标记。血性狂暴和反击风暴用的是另一个更长的 EmoteRoar。建议锁一个 `【吼】` 动作串，所有吼共用。
2. **冲锋的方向与落点**：胸口高度一条直线拉到目标，起步扬尘；落点只让对方定住一瞬、不倒地；只在开打前用。「撞翻」「半路改道」都会漂。
3. **颜色语法**（跨集锁死）：战斗姿态红、防御姿态蓝、狂暴姿态红橙；雷霆一击白蓝；战士刀光以红、紫红为主。盗贼方面：邪恶攻击紫、剔骨橙、背刺 / 伏击橙红、切割青蓝、佯攻蓝、凿击和闷棍紫星、毒药绿。本剧若按「战士不发光」处理，也要写明哪几招保留哪种非光的物理痕迹（尘圈、裂纹、踉跄），不能一镜一个样。
4. **「半透明」只能归一样东西**：原典里潜行（0.3）、灵魂（0.5）、闪避（0.5，推断）都是半透明。潜行建议走 §S 方案 A，把半透明留给灵魂态。
5. **没有光的本事靠声音锁**：偷窃无声；开锁是金属拨动加咔哒；闷棍是钝器闷响；脚踢是真的一脚。另外 ep01 的 goals.toml `[[casting]]` 只定义了圣光（G7c），战士、盗贼的招式没有「起手·手·效果」的一处定义。建议补一个 `[[technique]]`（吼 / 冲 / 跺 / 潜 / 闷），由生成器同样机检。

### 1. 结论

1. **口令：1.12 玩家施法无台词**；可借的只有训练师、任务、NPC 原句（mage.009–010、warlock.001–002）。
2. **三套手光录像定死**：火＝白热芯＋橙黄火舌、溅火星；冰＝深蓝旋涡、青白亮边、约一头大；奥＝淡青白（夜景一例）。起手光只在双手，地面只在冰霜新星 / 魔爆术 / 烈焰风暴 / 暴风雪的生效段。
3. **同一法术各阶外观不变，只有读条变长**（火球 1.5→3.0 s）；唯一例外：奥术飞弹 16、24 级换弹体。
4. **变形术**：人瞬间变白绵羊，脚下灰褐烟尘夹紫火星约 0.8 s；羊乱走 ≤20 s，挨打即复原。
5. **造水 / 造食**：3 s 弓身在胸前揉捏，手里不出东西；产量随等级涨（7 级一次 8 瓶，13 级 20 瓶），推翻 w08「个位数瓶」。
6. **敌我火球不是同一模型**：苏伦娜等 NPC 火球 3 s 读条、大号弹体。
7. **常驻外观只有**：法力护盾、冰霜新星冻结、减速染蓝、献祭燃烧、恐惧、猎人印记；霜甲 / 奥智 / 恶魔皮肤 / 守护只一闪。
8. 译名、人名冲突多处，w03 混入探索赛季任务（§D）。

### C. 一致性要点

**法师**
1. **手光按系锁**：火＝白热芯＋橙黄火舌；冰＝深蓝旋涡＋青白亮边；奥＝淡青白；缓落术、侦测魔法是暖金圣手。光只在双手，起手期间地面干净。
2. **出手方向**：定向法术都从举着的那只手朝前上方甩出，都打目标胸口；不写双手前推、不写从杖顶射出。
3. **读条随集变长**：欧文 1→20 级，火球 1.5→3.0 s、寒冰箭 1.5→2.6 s，外观不变；奥术飞弹 16 级换弹体是唯一例外。
4. **增益只一闪**：霜甲、奥智不给常驻光壳；每镜挂着光的只有法力护盾（20 级）。
5. **敌我火球分两条串**：欧文的 low 火球 vs NPC 的 high 火球（3 s）；小鬼火焰箭＝欧文的火球，靠施放者区分。

**术士**：影手（暗影箭、腐蚀、诅咒、恐惧、召唤）与火手（献祭、灼热之痛、火焰之雨）两套不混；三种召唤同一召唤阵，只靠落成音与宠物区分。
**猎人**：几乎零手光，识别靠弓 / 枪与 10 级后的宠物；唯一常驻标记是猎人印记。

### 结论先行

1. **1.12 怪物台词几乎都是文字泡、不配音**；第一季怪物里有配音文件的只有死亡矿井三位首领：拉克佐 1 句、重拳先生 4 句、范克里夫 5 句（`sound/creature/{rhahkzor,mrsmite,edwinvancleef}/`）。杂兵开口是本剧取舍。

### C. 一致性要点

1. **一个法系一套颜色，全季不变**：火＝黄芯橙红加黑烟；冰＝蓝白加雪花；闪电＝白蓝电弧；自然 / 治疗＝黄绿；圣光击＝金白；毒＝绿雾；恐吓 / 凿击＝紫。同名法术谁放都用同一条锁定串（苏伦娜的火＝月溪镇掠取者的火）。
2. **起手只在双手、只在有施法时间的技能上**：火球 / 寒冰箭 / 闪电箭都是两手托光约 3 s，再单手前推；霜甲、新星、投网、各种吼都是瞬发、不蓄力。最常见的漂法：3 秒的火球拍成随手一甩，或把起手光画到脚下。
3. **物理技能不加光**：撞头、猛击、猛踢、背刺、痛击、冲锋只靠动作、声音和镜头一震。眩晕演「人发懵」，不画头顶的圈。
4. **霜甲只在施放那一下看得见**，效果落在打他的人身上（手臂结霜、动作变慢），别给施法者常驻冰壳。
5. **台词按物种固定一套**：狗头人 candle 两句、河爪 fresh meat / bones 两句、迪菲亚 Brotherhood 三句、北郡暴徒和加瑞克 Abbey 两句、首领按血线顺序喊；不互相借。
