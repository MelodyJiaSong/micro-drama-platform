# 职业与技能资产（本剧）

> 用户定（2026-10-19，follow-up 108）：资产里建好魔兽世界全部职业，职业下列出全部技能，先收齐原生资料（文字、图片、技能图标、施法截图、动作），再给每个技能做 demo 视频，镜头引用它。
> 范围：原版 1.12 九个职业的全部主动技能（训练师、任务、天赋；各阶合成一张卡；被动天赋不立卡）。跨剧约定见共用 `assets.md`「技能」。
> 旧流程技能库 `2_世界观人设/skills/`（11 张卡、圣光术等旧样片）已过时，只作参考；它的 11 个键在这里原样沿用。

## 目录

```
classes/
  registry.toml                       技能键唯一出处（k{职业位}{两位序号}，只追加、不重排、不复用）
  cl{位}_{职业}/cl{位}_{职业}.md        职业卡：资源、护甲、天赋系、技能总表
  cl{位}_{职业}/skills/k{键}_{名}/
    k{键}_{名}.md                      技能卡
    icon/{键}_icon.png + refs.md       游戏图标（56×56，剪辑叠加或给人看）
    ref/refs.md                        原生资料登记：来源 URL / 时间点、sha、看到了什么
    ref/wowhead_{号}.jpg               Wowhead 法术页玩家截图（多为 2006–2008 年）
    ref/clip_{来源}_{秒}.mp4、snap_….jpg 实机施法片段与截图
    drafts/、renders/、{目录}_peak.png  技能视频草稿 / 正式条、峰值图（做 demo 时才有）
```

职业位：1 战士、2 圣骑士、3 牧师、4 法师、5 潜行者、6 术士、7 猎人、8 萨满祭司、9 德鲁伊。

人物共用的动作参考（施法动画）在 `0_research/refs/职业技能/动作/`，按客户端动画名一份，技能卡「客户端视觉链」写着用哪个动画。

## 技能卡里有什么

| 节 | 内容 | 谁写 |
|---|---|---|
| 原典 | 学会等级、来源、各阶、施法 / 冷却 / 射程 / 持续 / 消耗、法系、中英说明（数值已代入）、Wowhead 出处 | 生成器，别手改 |
| 客户端视觉链 | 读条 / 释放 / 命中 / 持续各播什么动画、什么特效模型挂在身体哪个点、什么音效 | 生成器，别手改 |
| 施法截图与动作片段 | 指向 `ref/refs.md` | 资料员 |
| 本剧写法 | 施法动作分拍、特效、作用结果、声音；偏离原典的地方和理由 | 做 demo 时写，用户定 |
| Shot prompt 技能 | 一段可原样写进镜头 prompt 的文字，不写游戏专名 | demo 定稿后写 |

生成器与抓取脚本：`.audit/adhoc_agents/2026-10-19/wow-class-skills/`（`build_index.py` 客户端表 → `0_research/refs/职业技能/skills_index.json`；`fetch_tooltips.py` 中英说明与图标名；`build_cards.py` 卡与图标；`fetch_screens.py` Wowhead 截图）。原生资料只给人看、写 prompt 用，不上传生成服务。
