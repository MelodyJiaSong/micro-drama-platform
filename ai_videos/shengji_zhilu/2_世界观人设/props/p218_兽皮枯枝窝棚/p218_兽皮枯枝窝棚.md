# 兽皮枯枝窝棚

全区所有「弯枝骨架 + 兽皮 / 芦苇覆盖」的空置矮窝棚共用这一件：山谷里的兽皮矮棚残迹 `bg225 · b03 / b04 / b05`，湖岸浅滩的浮木芦苇窝棚 `bg226 · b04 / b05 / b06`，洞内斜靠洞壁的兽皮窝棚 `bg232 · b06 / b07 / b08`（h 1.6 m，按块缩放），塔下三座弯木杆兽皮窝棚 `bg236 · b04 / b05 / b06`。形制取 bg225 锁定描述符 #3「兽皮枯枝矮棚残迹」、bg226 #4「浮木芦苇矮窝棚（空置）」、bg236 #4「三座弯木杆兽皮窝棚」与 #6「兽皮窝棚斑驳土褐」，配色对齐 bg222 #6 的暗旧自然色；骨架写成树皮剥落、灰白发旧的枯枝，湖岸浮木与山谷枯枝一件兼用。**不做**：窝棚前的兽骨堆（bg225 另写）、门框鱼骨与晾鱼架（归 a17）、火（火塘归 a12）。资产坐标系正面朝南（开口一面）：宽 5（东西）× 深 4 × 高 2 m；侧面视图（机位左转 90°）看到的是较高的那半边。

**一句话锁定**：`弯枯枝拱架蒙斑驳兽皮与枯芦苇·偏左开低口的空窝棚`

【形制与比例】整体是一个趴着的扁圆拱包，正面宽约五米，纵深约四米，最高处只有约两米，宽是高的两倍半，像压扁的半个蛋壳；轮廓不规整，左半边饱满略高，右半边塌下去一些。
【骨架】十几根手腕粗的弯树枝交叉弯成拱，枝脚落在下缘的压脚石之间，交叉处用生皮绳和干草绳胡乱绑紧；拱枝之间横编一层细枯枝。枝条树皮大半剥落，灰褐发白，像被水泡过又晒干的浮木。几根骨架枝头从棚顶和两侧支出来一截，长短不齐。
【覆盖】骨架外胡乱搭着五六张大小不一的兽皮，斑驳的土褐、灰褐与暗赭，毛面朝外、毛已磨秃成一块块，边缘翘卷不齐；皮与皮互相压着，接缝用粗皮绳大针脚缝过，几处破洞用颜色更深的另一块皮补上。兽皮没盖到的地方塞着一捆捆枯黄干芦苇，用草绳扎成把，横压在拱背和两侧下缘。
【开口】正面偏左开一个低矮的拱形口子，高约一米二、宽约一米半，只能弯腰钻进去；口子上缘挂着半卷起来的一片兽皮当门帘，用皮绳系在一根横枝上。口里是暗的，只看得见地上铺的一层压扁的干草，空着，没有任何东西。
【压脚】整圈下缘用大小不一的灰红碎石压住兽皮边，石头之间露出骨架枝脚。
【配色】兽皮的土褐与灰褐、枯芦苇的枯黄、枯枝的灰白为主，压脚石的灰红点缀，自然不过饱和，整体发暗发旧。
【年代感】搭了好几年、如今空着的旧窝棚：兽皮被日晒雨淋得发硬发白，毛皮大片脱落，有两处裂口没补；芦苇把褪成灰黄，有的散开垂下来；顶上积着一层干枯落叶与松针；右侧塌下去那块的骨架断了一根枝，兽皮跟着凹下去一片。
