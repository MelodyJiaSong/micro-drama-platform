# 半木构白石街屋

全城通用的两层半临街街屋：底层白石铺面、上层半木构逐层外挑。区级卡与各城区卡里的「两三层白石商铺 / 半木构两层公共建筑」、铺子、酒馆、旅店、民居、仓库都落到这一件（白模只锁剪影，换屋顶色不换形）。被这些块引用：`bg268 · b904`（×24）/ `b905`（×26）/ `b909`（×20）——全城俯瞰的街区屋顶肌理；`bg269 · b06 / b07 / b08 / b11`；`bg271 · b04 / b06 / b07 / b08 / b09 / b10 / b11`、`b12`（×3）；`bg272 · b06`、`b09`（×5）、`b10`（×6）；`bg273 · b06 / b10 / b11 / b13`；`bg276 · b04 / b08 / b09 / b12 / b13 / b14 / b15`。形制来自 bg269 #3「半木构两层公共建筑（白灰泥格、深棕木架、中蓝陡坡顶）」、bg276 #3「底层开敞为铺面、上层住人、深褐木窗框与小木阳台、陡坡中蓝石板瓦」与 bg271 #3「底层石、二层深褐木构与暖白灰泥」；色取全城主色中蓝顶，旧城区暗红褐顶（bg272 #6）、法师区紫顶（bg271 #6）只是换色。招牌只画一只陶罐轮廓、无字——各铺真正的器物招牌属 shot 层。**不做**：门口货箱布匹陶罐、晾衣绳、苹果树（各 bg 另有块或属 shot 层）。资产坐标系正面朝南：宽 14（临街山墙）× 深 12 × 高 10 m。
