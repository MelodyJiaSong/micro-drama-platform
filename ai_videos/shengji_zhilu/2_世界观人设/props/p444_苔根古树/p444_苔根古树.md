# 苔根古树

月光林地全区共用的那一棵老古树：村后林带、湖岸古树与兽穴坡上的古树丛都是它。被 `bg612 · b14 / b15 / b16`（村北林带、村东北、西口，各 1 棵）、`bg613 · b04 / b05 / b06 / b07`（北岸、西湖汊北岸、西南岸、东岸，各 1 棵，b07 face = west）与 `bg614 · b06 / b07 / b08 / b09`（北坡 4、东坡 5、南坡 4、主穴丘西北 3 棵，由引擎按 count 散布）引用。形制来自 bg611 锁定描述符 #3「几人合抱的粗壮古树（灰褐树皮、墨绿浓冠）」、bg613 #3「根须伸进水里的几人合抱古树」与 bg614 #3「散立坡上的几人合抱古树」；树根上的厚苔与 bg614 #4「根上绒毯般的厚苔」一致，但**本件不带白菌伞**（那是穴丘根网的标志，留给 `p445` / `a06`）。**不做**：林间淡紫萤光（场景层光效）、树下蕨丛与草地、伸进水里的根须（bg613 场景层补）。资产坐标系正面朝南：冠幅 16 × 16 × 高 28 m；树近似旋转对称，三视图靠根盘与主枝的朝向区分。

**一句话锁定**：`几人合抱的灰褐古树·苔根拱出地面·墨绿伞状浓冠`

p444-1_正面
单个物体的正面正视三维渲染图，设定图式的植物标本照：一棵孤立的老阔叶古树，从根盘到树冠顶完整入画、居中，约占画面八成，四周留出均匀空白，底部只带树自己拱出地面的根盘，不带地形、草地、落叶或土坡。纯浅灰无缝背景；阴天均匀散射光从四面柔和照亮，树下没有投影，没有阳光、没有月光、没有戏剧光、没有光斑。标准镜头，机位约在树干三分之一高度、轻微俯角，无广角变形。参考照片只借树皮、根盘与苔藓的质感，形制、比例与配色以下文为准。
【形制与比例】总高约二十八米，树冠最宽处约十六米，高将近冠宽的两倍。主干极粗，离地一人高处的直径约三米，要五六个人才合抱得过来；主干笔直向上约十米后才分出四五根粗大主枝，向上、向外斜伸撑开树冠。
【根盘】树脚一圈板状的粗根像拱起的脊背从地里鼓出来，最粗的几根拱出地面半人多高，向四周伸出四五米远再钻回地里，根与根之间围出一个个深凹的空档。正面正中这一根板根最大，像一道矮墙朝镜头伸出来。根盘从地面到齐腰高处裹着一层绒毯般的厚厚青苔，苔色暗绿偏黄。
【树皮与树冠】树皮灰褐、厚而粗糙，布满纵向深沟与龟裂的方块，沟里嵌着淡绿地衣。树冠浓密饱满，是一顶墨绿色的伞状圆冠，下缘平整、上缘圆鼓，叶片小而密，透不过光，冠下露出几根主枝的灰褐弯弧。
【配色】灰褐树皮、暗绿青苔、墨绿树冠三色为主，整体冷调、自然不过饱和，没有秋色、没有新芽的嫩黄。
【年代感】活了几百年、仍然健壮：树皮沟深如刀刻，根盘的苔层很厚，几处老树皮剥落后露出颜色略浅的愈合疤；但没有枯枝、没有断杈、没有空心树洞、没有雷劈焦痕。
画面里没有任何人物、动物、鸟、虫或文字。不要投影，不要阳光、月光与戏剧光，不要夜景，不要草地、地形与天空，不要花、果实、蘑菇与菌伞，不要藤蔓缠绕的树干，不要枯枝断杈与树洞，不要挂饰、绳索、灯笼与刻字，没有任何火焰与光源，不要发光的萤火或光点，不要卡通感或游戏引擎渲染感，不要广角变形，不要把物体裁出画面。
