# 圆锥兽皮帐

弯木杆骨架撑起、外蒙拼缝兽皮的圆锥帐，杆头在顶上交叉伸出，下摆一圈乱石压住，正面门帘卷起。被 `bg91 · b01 / b02`（兽皮帐·西一 / 西二，face = southeast）、`bg91 · b03`（兽皮帐·正中，最大、门帘卷起，face = south，放大到约 5.5 m 高）、`bg91 · b04 / b05`（兽皮帐·东二 / 东一，face = southwest）引用——五顶帐共用本件、只改朝向与缩放。形制来自 bg91 锁定描述符 #3「圆锥形兽皮帐（弯木杆骨架、拼缝兽皮、石块压下摆）」与 bg91 锚点 prompt 的「杆头从帐顶伸出」「门帘卷起、挂在两根交叉的木叉上」；配色按 bg91 #6（土黄与深褐兽皮、原木灰褐）。**不做**：杆头缠的红布条（颜色由 bg91 卡写，不进网格）、帐内陈设、帐门前的垫石步道。资产坐标系正面朝南：底径约 7 m、高 4.5 m，门帘在正面；侧面视图（机位左转 90°）门洞落在画面右缘。

**一句话锁定**：`弯木杆圆锥骨架·土黄深褐拼缝兽皮·乱石压摆`
