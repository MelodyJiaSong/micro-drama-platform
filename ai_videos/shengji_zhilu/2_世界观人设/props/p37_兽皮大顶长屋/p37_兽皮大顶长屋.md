# 兽皮大顶长屋

落锤镇寨子正中的兽皮大顶长屋（旅店），兼作高地上各种粗木兽皮棚的体块。被 `bg44 · b01`（兽皮大顶长屋，face = south）、`bg44 · b03`（铁匠棚，face = west）、`bg44 · b04 / b05 / b06`（西北 / 东北 / 西南圆顶帐，face = southeast / southwest / east）、`bg48 · b21`（粗木兽皮大棚，face = south）、`bg50 · b02 / b03 / b04`（倚岩木棚·北壁西 / 北壁东 / 东壁，face = south / south / west）引用。形制来自 bg44 锁定描述符 #3「粗原木立柱与弧形木肋撑起的深棕兽皮大顶长屋（屋脊两端翘起削尖木角）」与 b01 note（皮绳拼缝、门朝南、门口两根挂兽骨与大獠牙的木杆）；配色对齐 bg44 #6「深棕与土黄兽皮、灰褐原木与寨桩」，兽皮暗褐土黄也与 bg50 #6 一致。缩放用途（圆顶帐、敞口铁匠棚、倚岩棚、大棚）只借它的体块与材质。**不做**：寨墙、暗红布幡、火塘、铁砧与水桶。资产坐标系正面朝南：宽 26（长边）× 深 14 × 高 8 m（含脊端木角）。

**一句话锁定**：`粗原木弧肋撑拱形拼缝兽皮大顶·脊端翘尖木角长屋`
