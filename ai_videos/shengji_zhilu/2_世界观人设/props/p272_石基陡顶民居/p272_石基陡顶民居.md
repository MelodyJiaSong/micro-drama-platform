# 石基陡顶民居

两个村子的民居单体：一栋下半截灰毛石、上半截深色竖木板、顶上陡峭深灰木瓦尖顶的单层小屋。被 `bg248 · b03 / b04 / b05 / b06 / b07 / b08 / b09 / b10`、`bg253 · b04 / b05 / b06 / b07`、`bg263 · b18`（×4，崖下远景）、`bg264 · b05`（×6，林缝远景屋脊）引用；二层出挑的两座按块拉高。形制来自 bg253 场景卡锁定描述符 #3「石砌墙基 + 深色木板墙 + 陡峭深灰木瓦尖顶的村屋」与 #4「包铁条的厚木门、从外面合上插了木闩的窗板」、#6「窗板上褪色的暗红漆」，以及 bg248 #3「灰色毛石墙 + 深灰木瓦陡坡屋顶的民居」与 #4「剥落的暗红窗框」。**不做**：窗里的暖黄灯光（bg248 默认态由 shot 层写）、厚茅草顶的变体、门前柴垛（另有块）、砖砌高窄连排屋与铸铁路灯（4.0.3a 后的形制，bg253 明令不画）。资产坐标系正面朝南：长 12（正面长边）× 深 9 × 高 8 m；烟囱贴左（西）端山墙，侧面视图（机位左转 90°）看到的正是这面带烟囱的山墙。

**一句话锁定**：`灰毛石墙基深色竖板墙·陡峭深灰木瓦尖顶小屋`
