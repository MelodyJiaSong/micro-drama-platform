# 朽木板堆

一堆低矮的朽木板，只有木头：长短不一的断板、带锈钉的碎板、两截短方梁与压在最底下的一扇旧门板。被这些块引用：`bg127 · b04`（门前烂干草堆，face = south，×3）、`bg127 · b06`（旧犁，face = south，×1）、`bg135 · b03`（骨骸散落处，face = south，×1）、`bg139 · b02`（门前石阶与碎瓦断梁，face = north，×2）、`bg141 · b05`（农舍木料堆，face = south，×8）、`bg141 · b06`（北侧熊骨，face = south，×1）、`bg141 · b07`（南侧熊骨，face = south，×1）。真正当木料用的只有 bg141 b05 与 bg139 b02 里的断梁；烂干草、旧犁、骨骸、熊骨与碎瓦都是白模里只借它占形，这些东西由各 bg 出图 prompt 另写，本件不画。形制来自 bg141 锁定描述符 #3「深褐朽木料堆」、#4「带钉的旧房梁、门板、窗框、半截篱笆」与锚点「门板上还带着铁合页，房梁上钉着锈钉」，bg139 锚点「几截断梁，断口早已发灰，长满灰绿的苔」；配色取 bg127 #6「灰褐旧木板」、bg139 #6「深褐朽木」与点缀「黑褐锈铁、灰绿苔」。**不做**：断梯（`p132`）、翻扣柳筐（`p133`）、裂口木桶（`p134`）、窗框与半截篱笆（bg141 出图 prompt 另写）、干草、犁、骨头、瓦片、火与烧痕。资产坐标系正面朝南：宽 2.2 × 深 1.4 × 高 0.6 m；正面看的是长边，旧门板的一角从堆底左端（西）伸出；侧面视图（机位左转 90°）正对堆的西端，看得到一层层板头。
