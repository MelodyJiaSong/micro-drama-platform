# 靛瓦弯柱开敞工棚

全城那种四面敞开、没墙没门的靛蓝瓦顶木棚，一件通用：工匠区的作坊工棚、贸易区的小货亭与开敞拍卖大厅、战士区细廊尽头的两座方亭都是它，逐轴撑满各块占地。被 `bg497 · b01 / b07 / b08`（face = south）、`b02`（southwest）、`b04`（west，U 形冷炉棚）、`b05 / b06 / b13`（north）、`b09`（east），`bg500 · b04 / b09`（south）、`b07`（east，拍卖大厅）、`b08 / b13`（east），`bg501 · b06 / b08`（west，方亭）引用。形制来自 bg497 锁定描述符 #3「月白石台基 + 淡紫灰弯木柱 + 靛蓝琉璃瓦翘角弧顶的开敞工棚」、锚点 prompt「台基四角各蹲一只矮石墩，墩顶雕着一弯新月」与 bg500 锚点拍卖大厅「木梁从柱头向中间层层挑出，梁身刻着顺纹的卷叶……一排排淡色的椽子」。**棚下空着**：织机、长石台与玻璃瓶、晾皮架、U 形石棚里的冷炉膛与铁砧、摊台货物、公告木牌、方亭的纱帘都属 shot 层；U 形炉棚与拍卖大厅按区级规划不另立资产。资产坐标系正面朝南：宽 16 × 深 12 × 高 7 m；正面长边正中有三级石阶、背面没有，以此分正反。

**一句话锁定**：`月白石台基·淡紫灰弯木柱·靛蓝瓦四坡翘角顶·四面敞开`

p434-1_正面
单个物体的正面三维渲染图，设定图式的产品照：一座四面敞开、没有墙也没有门的木构工棚，机位正对它的一条长边。整座完整入画、居中，约占画面八成，四周留出均匀空白，底部只带自己的石台基，不带地面、草地或路面。纯浅灰无缝背景；阴天均匀散射光从四面柔和照亮，物体下方没有投影，没有阳光、没有戏剧光、没有高光斑。标准镜头，机位约与檐口同高、轻微俯角，无广角变形。参考照片只借木构、瓦面与石作质感，形制、比例与配色以下文为准。
【形制与比例】长边宽约十六米、进深约十二米，连屋顶总高约七米，檐口离地约四米，屋顶占去总高的将近一半。
【台基】一座齐膝高的月白石砌矮台基，石块方整、灰缝细密，边沿一道圆润的线脚；台基四角各蹲一只矮石墩，墩顶浅浅雕出一弯新月。正面长边正中是三级月白石阶。台基面是空的，平整的月白石板上什么都没放。
【柱与梁】沿台基外圈立着十根淡紫灰的弯木柱，前后各四根、两侧正中各一根；每根都像一截天然长弯的树干，中段向外鼓出一道柔和的弧，上端再向里收回，柱面光滑、没有棱角。柱头上架一圈同色木梁，梁头削成圆润的弧形，梁身刻着顺着木纹的卷叶；从下往上看得见屋面底下一排排淡色的椽子。
【屋顶】四坡顶，屋脊顺着长边横贯，屋面微微内凹成一道柔和的弧，铺满整齐的靛蓝琉璃瓦；檐口挑出一米多，四个翼角高高向上翘起，像新叶的叶尖；屋脊两端也各向上翻起一小段弧。
【配色】靛蓝瓦顶、月白石台基、淡紫灰木构三色为主，雕纹与木色同色系、只靠起伏显形，没有彩绘、没有金饰，自然不过饱和。
【年代感】用了很多年、被照料得整洁：柱根颜色略深、嵌着一圈细苔，瓦檐下垂着几缕细藤，石阶正中被踩出浅浅的凹痕；没有缺瓦、断木或歪斜。
