# 尖顶深棕木屋

全区通用的一层半民居：齐膝毛石墙脚、深棕近黑竖板墙、陡而窄的黑木瓦双坡尖顶、一侧山墙外贴石砌烟囱。民居、酒馆、铺面屋共用这一件，靠块尺寸拉伸成一层小屋、宽矮铺面或带阁楼的高屋。被 `bg127 · b03`（south）、`bg128 · b08`（south）· `b02 / b06 / b09 / b10`（east）· `b03 / b07`（west）、`bg129 · b02 / b04 / b08`（south）· `b03 / b05`（east）· `b06 / b07`（west）、`bg130 · b02`（north）、`bg134 · b01`（south）引用。形制来自 bg128 锁定描述符 #3「深棕近黑木墙 + 毛石墙脚 + 陡而窄的黑木瓦尖顶」、bg127 · b03「毛石墙脚、深褐板墙、屋侧石砌烟囱（冷、无烟），窗板脱钩歪挂」与 bg130 · b02「阁楼小窗、门前两级石阶」。**不做**：bg129 的黄灰泥墙面与二楼挑阳台、酒馆的红鸟招牌、门廊铁臂招牌（各块自己的差异留给 shot 层）；窗里一律不透光（bg128 的窗烛属镜头光，不进资产）。资产坐标系正面朝南：宽 10（檐墙）× 深 8 × 高 8 m，屋脊东西向；侧面视图（机位左转 90°）看到的是西山墙与烟囱。

**一句话锁定**：`毛石墙脚深棕竖板墙·陡窄黑木瓦尖顶的一层半木屋`
