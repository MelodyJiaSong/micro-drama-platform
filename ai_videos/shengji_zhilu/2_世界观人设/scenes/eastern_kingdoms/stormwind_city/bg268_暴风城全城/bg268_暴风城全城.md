## 场景定位

暴风城是人族王国的首都，也是本剧全部交通与任务的原点（贸易区东侧坡道上的狮鹫栖场是全剧的交通原点）：一座**被白石城墙整圈围住、被碧蓝深水运河切成若干近似矩形街区的海崖之城**。本档是**整个区的建场底图**（区级主体）——一张高空斜俯瞰的全城全景，把「白石 + 中蓝瓦顶 + 碧蓝运河 + 街角苹果树」这套城市语言一次写死；所有城区 bg（教堂广场 / 光明大教堂 / 矮人区 / 法师区 / 旧城区 / 运河区 / 暴风要塞 / 花园区 / 贸易区 / 英雄谷）都在它的地貌与色彩框架之内。剧中用法：主角第一次进城的**大远景建场空镜**（style_guide §3「第一次见世面」：低角仰拍城门 → 高空俯瞰全城）、每次回城的过场、以及任何要把「王城」这个尺度感一眼交代出来的镜。

**地貌骨架（区图量取，`planning/blocks.toml` 是几何唯一出处）**：① **全城只有一个陆路口**——东南角的巨型白石正门开向邻区的橡林，门内是一块绿意盎然的天然谷地（英雄谷），谷底一道护城水面、一座宽石桥、桥两侧五尊巨像，主路在像前分岔进城；② **贸易区是几何中心**，四面临水，一座圆喷泉居中；③ **运河不是一个环，而是若干段拼成的网**——贸易区四周的水道把它与教堂广场（西北）、旧城区（东）、法师区（西南）隔开，水网里泡着两座方形石堡（西岛监狱、东岛宝库），只有三座桥可以确证（英雄谷石桥、教堂广场↔矮人区人行桥、要塞吊桥），其余桥数属自行设定；④ **教堂广场在西北**，大教堂的尖塔群是全城最高的天际线；⑤ **矮人区在北角**，敦实低矮的石构街区上方悬着一层不散的灰蓝薄烟，东缘石壁里嵌着一条隧道口（矿道地铁，全城第二个入口）；⑥ **暴风要塞坐在东北角的岩石台地上**，明显高出周围街区一大截；⑦ **旧城区在东**，发黄发灰的旧石与深褐木构，全城最老的一块；⑧ **法师区在西南**，一座爬满藤蔓的独立高塔统领全区，是全城海拔最高的街区；⑨ **花园区在最西端**，城内唯一的绿地，圆形广场居中；⑩ **城西是崖壁与海**——旧世没有港口，西城墙外就是下到海面的崖坡。

**四邻与出入口**：陆路只邻艾尔文森林（东南正门）；矿道地铁通铁炉堡（矮人区东北隧道）；西面临海但**没有港口**（3.0.2 才有）。**给分镜的硬约束**：天际线由三样东西决定——西北的教堂尖塔群、东北高台上的要塞、西南的藤蔓高塔；朝西的远景会撞上城墙外的海平线，朝东南的远景会看到城门外的橡林；城内**没有山、没有森林、没有田野**，只有花园区一块草地（`blocks.toml [meta] absent`）。区图上各城区的街道不显示，本档的道路走向是按城区相邻关系与可见桥位推的（图上虚线），排镜前以实机为准。

> **⚠ 版本口径（本档最容易翻车的一条）**：`ref/` 里那张 c60 区图是 **3.0.2 之后**的版本——西侧画着港口、西北角画着小湖。旧世 1.12 **两处都没有**：城西是城墙外的崖壁与海，教堂广场后面也没有湖与公墓。本档 `terrain.toml` 只量城墙以内的东西，港湾与湖一律不画；prompt 反向声明「没有港口、没有码头、没有泊船」。另外三个旧世独有的细节在这个尺度上**不入画**（属各自的 bg）：教堂广场喷泉上是一座教士纪念碑而非持锤骑士像、城门上可能倒挂着巨龙头颅、旧城区与贸易区之间有一道常年关闭的铁闸门。
> **⚠ 色板强度**：`style_guide.md` §2 暴风城一行标 ✅（引用 sk2「中蓝瓦顶 + 暖白石」）；旧城区暗红褐顶与法师区紫顶同样引自 sk2。运河碧蓝、街角苹果树来自世界树画面。**运河是深而清的碧蓝水**——4.0.3a 才被淤成浅水，正片里不得出现淤泥 / 芦苇。
> **⚠ 16.9 铁律**：区级底图是**纯日光**场景——矮人区的锻炉、要塞与旅店的壁炉、法师区地窖的法阵都属各自的 bg，在这个尺度上一律不入画；矮人区上方只写「灰蓝薄烟」，不写火光；花园区的乳白圆池只写颜色，不写发光。本档反向声明零火、零人工光源。
> **平面图口径**：`planning/terrain.toml`（作者写：区图画得出的城区色块 / 运河蓝带 / 两座岛堡 / 城门 / 城墙塔线全部 `src = "地图量取"`；街道、要塞台地、城西海崖 `src = "推定"`；c60 区图西侧那道带塔的长墙与西北角的墙属 3.0.2 港区通道，不采用——旧世城墙在花园区北角塔处折向东北、绕到大教堂背后，这两段按「推定」画）→ `gen_world_scenes_szzl.py --zone stormwind_city` 合并进 `blocks.toml` → `build_floorplan.py` 出图。世界树里本区所有城区节点都**没有坐标**，十个城区块是按区图量取后以 `b9NN` 写进 terrain.toml、带 `bg` 键交给生成器合并的；`px_per_m` 由生成器定（1.79），不手改。

【出入口与远景】整座城被一圈高厚的白石城墙整圈围住，墙顶是加宽的走道，垛口连续，墙面无窗，蓝金旗幡沿垛口一字挂开，转角与门侧立着圆形与方形的塔楼。陆路只有东南角一个口：一座高过城外树冠的巨型白石正门，门洞深邃、常年洞开，两侧各一座白石塔楼；门外是一片饱和翠绿的阔叶橡林。西面城墙之外没有任何街区——墙脚是灰白的崖壁，一路陡落到下面冷蓝的海面，海面开阔、没有码头、没有栈桥、没有船。天空高远淡蓝。
【纵深层次】前景是东南正门、双塔与门内的绿谷、宽桥与巨像；中景是碧蓝水网与泡在水里的中心街区、两座石堡、四周成片的白石街区与中蓝瓦顶；远景是西北的教堂尖塔群、东北台地上的城堡剪影与西南的藤蔓高塔，三样东西撑起整条天际线，最远处是城墙外冷蓝的海平线，大气透视把它推成淡青灰。
【边界高差】城内有三级落差：最西的绿地与东南谷地最低、街区在中间、东北的城堡台地与西南的塔区最高；运河水面又比街面低一人多高，所以每一段堤岸都是一道清晰的白石边。
【年代感与遗留物】石板路心被几代人踩得发白发亮；运河堤岸的水线以下有一圈深绿的水苔与湿痕；东面老城的墙面爬着水渍与霉斑，木构架颜色深浅不一、显然修补过多次；城墙的白石有新旧两种色——补过的段落颜色更亮、灰浆更白。一切都是在用、在住的，不荒废，也不崭新。
