## 角色定位

前 20 级出镜率最高的四种怪之一（`dossier.md` §怪物）。**全游戏辨识度最高、也最容易被生成模型画错的怪**——它的默认输出几乎一定是「人鱼」或「蜥蜴人」。

国服官方简中译名确为**「鱼人」**（`wow.term.105`，NFU 1.12 中文数据库 npc 46 核过，不是模型记忆）。

**第一季出场**：
- **bg8 黄金鱼塘**（第 09 集）——闪金镇正东的湖，湖里爬满鱼人，对新手相当危险；`Murloc / Murloc Streamrunner` **6–7 级**，`Murloc Forager / Lurker` 9–10 级（`wow.mob.011`）。本剧主角撞见它们的第一现场。
  > ⚠️ 名称层：任务书里的「黄金鱼塘」不是官方译名，**国服官方译名是水晶湖**（`w13` / `g13` 核验记录）。world.md 的 bg8 用「黄金鱼塘」，**本卡沿用 world.md 的 bg 口径**；若日后统一，两处同步改，不要只改一处。
- **西部荒野·鱼人海岸**（第 12–16 集范围）——长滩一线沙滩上全是鱼人，`Murloc Raider 11–12` → `Coastrunner 12–13` → `Netter 14–15` → `Warrior 15–16` → `Hunter 16–17` → `Tidehunter 18–19`（`wow.mob.011`）。等级阶梯本身就是主角「走得更远＝打得更硬」的可视刻度。
- **老鱼眼（Old Murk-Eye）**——西部荒野旧灯塔附近海岸 `[34.4, 84]` 巡弋的名怪鱼人，**体型明显大于同群**，只比周围小弟强一点（`wow.westfall.040`）。⚠️ 它在 1.12 的确切等级/精英态未核到（`wow.westfall.041`），**当战力标尺用之前必须补核**，本卡只锁它的长相不锁它的数值。

**与主角的关系**：练手对象 + 「群」的第一课——他会在这里第一次发现「一只打得过、三只打不过」。

## 标志能力或动作

### 1. 叫声（**本卡的核心资产** · 供后期音效层）

**官方拼法：`Aaaaaughibbrgubugbugrguburgle!`，又写作 `RwlRwlRwlRwl`**（`wow.mob.006` / `wow.audio.020`）。这是全球玩家的共同记忆，是本剧最便宜也最有效的一记共鸣。

- **成年**（音效层锁定串）：`含着一口水从喉咙里爆出的连续咕噜声，音高忽上忽下，尾部带气泡破裂声`（`wow.audio.020` prompt_string）
- **幼年**（另一条完全不同的曲线，不是成年的缩小版）：`高音的婴儿式咿呀与咕噜，带上下起伏的歌唱调`（`wow.audio.023`）
- **语言**：鱼人说 **Nerglish**，与 makrura 共用，**对其他种族不可理解**（`wow.audio.022`）——所以它永远不该出现可辨认的词。
- **音效层纪律**：本剧四层音轨 100% 自制（concept E1 / style_guide §9），**这条叫声要自己录 / 合成**，不取游戏原声。冷知识可留作花絮：这个叫声在开发期间多次差点被砍，因为有人抱怨（`wow.audio.021`）。

### 2. 群战围杀（**排镜硬规律**）

「pack fighters, preferring to swarm opposing forces with overwhelming numbers」（`wow.mob.007`）。
**单独一只鱼人的镜头是反设定的**——`最小单位 3 只，营地 6–12 只`（`w11` §2.1 硬规律①）。
> 与 `ai_video.md` rule 4g ⑥「一镜内主体数 ≤ 8」咬合：营地全景镜里主角 + 队友 + 鱼人加起来仍要 ≤ 8，**超了就拆镜**，不要靠堆数量拍「多」——靠纵深层次与画外叫声拍「多」。

### 3. 渔网

**「没有渔网的鱼人什么都不是」**（`wow.mob.009`）。撒网缠住主角的腿 = 本剧「打不动」的圣骑士被一只 7 级怪拖住的最佳喜剧动作，也是它区别于一切别的杂兵的独有动作。

### 4. 恶臭信息素（**可做剧情机关**）

体表小气味腺分泌恶臭信息素（`wow.mob.008`）。两层用法：
- **镜头语言**：「离鱼人营地近了先闻到味」——用人物捂鼻 / 停步 / 回头的表演表达，不用特效。
- **情节机关**：原典里一瓶浓缩信息素泼到目标身上，**附近鱼人当场陷入暴怒狂潮并把它杀了**（`wow.mob.008`）。这是一条不用杜撰的「以敌制敌」爽点。

### 5. 水里的主场

能水下呼吸（`wow.mob.003`）；**水下视力极佳，近乎全黑也能看见**（`wow.mob.010`）。
→ 夜戏、浑水、湖底镜里**它占优、主角吃亏**，这是拍「主角很菜」最有道理的一种菜法。

### 6. 幼体

亮绿色，年龄越大越暗；有一颗大板牙和一条小尾巴，成年后消失（`w11` §2.1 表「幼体」行，wiki Biology）。
→ 对应 D20「敌人也是受害者」那条支线的备用素材：营地里有崽。

## 招牌台词（音效层 · 不是台词）

**`RwlRwlRwlRwl`**（等价写法 `Aaaaaughibbrgubugbugrguburgle!`）。

- **不配 voice_id**（没有语言），**不进 `## 台词配音 prompt`**，走**音效层**，不走对白层；`casting.md` 把它列在「无台词」。
- **不过台词闸门**——它不是台词，是生物叫声。
- **不出字幕翻译**：Nerglish 对其他种族不可理解（`wow.audio.022`），翻出来就把梗讲死了。
- 全剧改英文（concept G8）之后，D21 / divergence #4 的「英文彩蛋额度」已作废，本条不再涉及任何配额。

### D. 一处必须写明的口径分歧

**`单独一只` 是 shot 负向，不是立绘负向。**
`wow.mob.007` 管的是**镜头**——「单独一只鱼人的镜头是反设定的」。而 `style_guide.md` §7 要求角色立绘是「中性姿态、干净背景」的单主体参考图（否则抠不出干净的参考脸/参考体）。
**裁定**：下方 Seedream 立绘 prompt **单主体、干净背景，不挂 `单独一只` 负向**；**每一个 shot 必须挂**，且鱼人最小出现单位 **3 只**、营地 **6–12 只**。
*(judgment call — 两条规则在字面上冲突，但管的不是同一件事：一个管成片画面的设定真实性，一个管资产参考图的可用性。把它写在卡里，比让下游每次重新发现一遍便宜。)*
