## 角色定位

全剧主角，每集在场。13 岁那年，货栈一只货箱压了父亲的腿，他跑了半座城去光明大教堂（Cathedral of Light）喊牧师，回来晚了。腿保住了，活干不了了。大教堂一位老修士教过他两样：让锤子带一点光，和一段慢得要命的祷告；又说想学圣骑士，就去北郡。他背着小包袱、肩上横挎父亲攒两年钱买的旧双手锤，走进了北郡山谷。

他的光要一口气才聚到手上，脚下一乱就散了——所以他得有人替他拖住。这就是剧名，也是他和同伴 **Duke（杜克，卡目录 `c2_Duke`）** 的全部关系：一个说话前先改口，一个说完话才看路；ep01 从杜克一肩膀撞开他（S02），走到他叫着杜克的名字请他拖住（S21）。

他的高光永远是救人，不是杀敌。

|---|---|
| 萨缪尔修士（Brother Sammuel `c14`） | 第一位师父。"For the time being."（S13）/ "For now."（S23）说了两次，一次没解释 |
| 治安官玛克布莱德（Marshal McBride `c7`） | 对谁都说同一句 "Hey, citizen!"，**从没记住他的名字** |
| 维里副队长（Deputy Willem `c13`） | 只派活；S25 拍了他一下肩——全剧唯一一次碰人 |

| 加瑞克（Garrick Padfoot `c18`） | 第一个有名字、先开口的对手。惨胜，不是爽胜 |

## 性格 / 动机

- **核心动机**：来得及。当那个「本来就在场的人」（S14 杜克替他说出口）。
- **表层人设**：礼貌、较真、话短的新兵，说话前先改口。
- **反差点**：全谷看着最不像能打的那个，却是唯一会回头数人的人；他救人的法子慢得要命。
- **关键弱点**：光要一口气才升上来、一挨打就退回地里。ep01 前半他想一个人撑（S12 败）。
- **不会做的事**：不先跑、不丢下同伴、不对弱者动粗（S16 拿蜡烛头换回锤子）、不拿别人的伤开玩笑。

## 人物灵魂（ongoing · 随集深化 · rule 12.11）

> 以 ep01 剧本的小传为准（concept G9 ①）。后续剧情 / 台词 / 创新创作前必读（rule 12.11-C）。

- **年龄 / 当下处境**：18 岁。刚从 Stormwind 走到北郡，除了老修士教的两样（锤子带一点光、一段慢得要命的祷告）什么都不会；兜里没钱，手里只有父亲的锤。ep01 结束时：学会了用圣光治伤、指哪落哪的审判、给身边人添一把力，第一次在实战里把治疗念完；锤柄多了一道斧口，左小臂缠着布，正往 Goldshire 去。
- **前史（之前在干什么）**：Stormwind 贸易区长大，父亲在货栈扛货（不写码头，码头 3.0 才有）。13 岁那年货箱压了父亲的腿，他跑半座城去大教堂喊牧师，回来晚了；腿保住了，父亲从此干不了活。大教堂一位老修士教过他两样本事，让他去北郡。父亲攒了两年钱，给他买了那把旧双手锤。
- **为什么在做现在做的事（根因）**：那次「回来晚了」。他学圣光，是为了下次不用再跑半座城去喊人——自己就是那个已经在场的人。
- **目标（短期 / 长期）**：短期——在北郡学成，被当成圣骑士学徒（"Trying to be."）；把父亲的锤带在身边，别丢。ep01 末：去 Goldshire 找治安官杜汉报到、找 Brother Wilhelm 接着学。长期——谁倒下的时候，他已经在旁边。
- **需求（needs · 他真正缺的）**：**相信慢一点不丢人，会有人替他撑那三下。**
- **内心欲望（desire · 他以为自己要的）**：**快——快到来得及。** 他想一个人就够用（"Faster than running for a priest."（旧稿台词，ep01 现稿未用））。
- **核心矛盾**：他最怕别人因为他慢而吃亏，可他的光偏偏要别人先替他挨打才出得来。他要当那个不让别人吃亏的人，就得先开口让别人为他吃亏——这句话他说不出口，直到 S24。
- **恐惧**：来不及；别人因为他慢而吃亏。S11 恐惧当场成真：杜克挨了一镐、左肩伤，他跪着起光那几秒没人替他拖住，为了架住杜克丢了父亲的锤。
- **最大创伤 + 致伤事件**：13 岁，父亲的腿（现稿 S07 第一次说出口："My dad. ...His leg. I was too late."——父亲还在，腿压坏了；光正是在这一句之后来的）。他跑了半座城，回来晚了（S14 第一次说出口："A crate came down on my dad's leg. I ran half the city. Got back too late."（旧稿台词，ep01 现稿未用））。
- **此刻怎么 make decision**：① 先数人，谁还在；② 先把事问清楚再动（"Ten each, or ten total?"）；③ 会有人因为我慢吃亏吗？——ep01 前半他的答案是「那我自己顶」，S12 因此被打散；④ **S24 起多了一条**：自己撑不满三下时，叫着名字请身边的人撑。另外他记路、读地形，用地形替自己换时间（S16）。
- **性格特点**：**礼貌 · 较真 · 话短 · 先改口 · 紧张就数数**。从不开玩笑，较真本身好笑。对弱者和对手都存一份尊重——S16 用蜡烛头换回锤子，S20 用拇指抹过面罩里的汗印（"Somebody wore this to work. Every day."（旧稿台词，ep01 现稿未用））。
- **成长 / 变化轨迹**（ongoing，每集回看校正）：
  - S02 → S07：从 "I want to be a paladin" 改口成 "learn to be"，再到 "Trying to be."——先学会不夸口。
  - S05 → S06：挥锤从抡满到只从肩上走——手上的熟练就是世界内的成长。
  - S07 → S08：拜师；萨缪尔先用圣光治好他被锤柄磨破的虎口，他照着做两次落空，说出父亲的腿之后，光第一次聚到他手上，治好了杜克撞破的鼻子（follow-up 047）。
  - S11：一个人把光撑起来，治住了杜克，却没人替他拖住时间，只能逃；付三笔账——杜克挨了一镐、父亲的锤丢在矿里、人情账（S12 杜克认账 "...I owe you one."）。
  - S14：第一次把伤口说出口；杜克说破 "So somebody buys you time."（现稿 S12）
  - S15 → S16：两样新本事，一样是给别人的；靠记路和地形打回去，锤子不是抢回来的，是拿一截光换回来的。
  - S20：第十二块面罩，第一次看见对手也是天天干活的人。

## 说话风格模板（声口锚）

**类型**：**礼貌 · 较真 · 句子短 · 先改口 · 紧张就数数。** 陈述句为主，很少感叹；问句只为把事弄清楚；称呼人用头衔或名字（Brother / Marshal / Duke）。念白按 ≤3 词/秒（G8）。

**典型口吻**（均出自 ep01 剧本）：

- "Aaron, sir. From Stormwind." / "I want to be a paladin." / "...I want to learn to be one."（先改口，S01）
- "Nine. ...Ten each, or ten total?"（较真，S06）
- "Trying to be."（不夸口，S04）
- "One, two, three, four, five, six, seven... eight... nine... ten... ...eleven."（紧张就数数：数洞里的烛光，S09；follow-up 047）
- "You look like a guard." / "It just wanted a light."（只说事实，S14 / S16）
- "Duke. Buy me time."（签名句，叫着名字，S21）
- "One. Two."（数人，S11 / S22 / S25；S25 由杜克接 "...Us."）
- "Thank you, Eagan." / "I'll keep mine. Thank you."（礼貌，S05 / S24）

**禁忌**：

- **伪古英语 / 骑士腔**：thou / thee / hath / verily / ye，以及 "By the Light!" 这类宣誓口号。
- **游戏黑话**（G1）：tank / heal / aggro / buff / pull / quest / level / XP / mob / respawn / loot。

- **讲笑话、吐槽、讲大道理**。他的价值观靠动作演；喜剧来自他的较真和杜克的反差。
- **机制说明**。怎么用光由师父描述（"'Light, give me strength.' ...It's already in you." S07 / "Light goes where you point." S13），他只照做。
