## 角色定位

固定队五人里的**纯输出 + 工具位**，也是**第一季唯一的内部摩擦源**（concept 固定队表）。
他 **ep15 在月溪镇入队**——那是个被迪菲亚占着的空镇，没有旅店没有邮箱，门窗敞着没有灯（`0_research/parts/w04` §4）。
队伍要进死亡矿井，而**矿井的入口是月溪镇一栋房子楼上的暗门**（`w04` §入口）——
**一支没有盗贼的队伍，在这个地方会被一把锁挡住。** 他就是在这种时候出现的人。

他的不可替代是机制级的，一共三件（`wow.class.081`）：
**开锁**（16 级，队伍打开上锁箱子与门的**唯一**职业手段，`wow.class.082`）、
**闷棍**（10 级，开战前拆散怪群）、**潜行**（1 级，探路）。
队里没有第二个人能干这三件事的任何一件。

**但他同时是队里道德位置最暧昧的那个**——盗贼的整套机制（潜行 / 偷袭 / 搜索 / 开锁）
天然鼓励「先手拿好处」（`w08` §5.4 原文判词）。他偷怪、先跑、抢装备，
在规则上**一条都没越界**（`wow.player.053`：暴雪对绝大多数 ninja 行为不介入）。
这正是他难对付的地方：**你没法用规则说服他，因为他就站在规则里。**

**他不是反派。** 他是那种「规则允许我就做」的人（用户裁定）。
他与主角的关系是**一整季的互相看不顺眼**：主角打不动却死不掉、永远最后一个离开；
他打得动、活得久、永远第一个离开。**两个人都不会死，但理由正好相反**——
一个是扛得住，一个是根本不在那儿。

**与不灭战魂是全队最不对付的一对**：一个抢着站最前面，一个抢着站最后面。
可他们的病根是同一个——**都怕自己没位置**。这一层第一季不点破，留给第二季。

**打脸尺度纪律（concept D17 · 反杀但不羞辱）**：他**不会被羞辱**，一次都不行。
他会被主角**救一次**，然后自己改变。ep19 分赃他骰 87、主角骰 23，主角说「恭喜」——
**赢的是他，被击中的也是他。** 全剧不得出现「他翻车了大家笑他」这种处理。

## 性格 / 动机

- **核心动机**：**保证自己在分东西的时候还站在那儿。** 偷怪、先跑、抢装备不是三件事，是同一件事的三个说法。
- **表层人设**：老油条。话不多，从不提高音量，什么都见过，什么都不惊讶。队里的行情、哪个点刷怪快、
  哪个箱子值得开——他张口就来，而且**都对**。
- **反差点**：**他其实极其耐烦。** 能在同一个点刷两个小时不抱怨一句（四件迪菲亚绿装全掉在小怪身上，
  凑套就是要反复刷，`wow.gear.057`）。这份耐烦不是修养，是工时磨出来的——**可它长得跟修养一模一样。**
- **关键弱点**：**他不记恩。** 不是忘恩，是他的账本里根本没有这一栏——
  他这两年遇到的所有好意都是有价的，**所以他不认识白给的东西**。主角那一次救，
  是他账本上第一笔平不了的账。

## 人物灵魂（ongoing · 随集深化 · rule 12.11）

> 把他当一个活生生的人写透，不是一个开锁工具位。后续所有剧情 / 台词 / 改动创作前必读此段。

- **年龄 / 当下处境**：23 岁，县城一家网吧的**夜班网管**，二十点上班、次日八点下班。
  机器不要钱，时间要——**他的上线时间是别人的白天**，白天他睡觉。
  他不是「有很多时间玩」，是**除了这儿没别的地方去**。
  （现实零画面，B1：以上只从台词与声音漏出来，永不给现实镜头。）
- **前史（之前在干什么）**：2005 年开服头一个月就在玩，是本剧固定队里**唯一的老玩家**（除了主角，
  而主角是断了好几年的回归者——**两个人的「老」不是同一种老**）。
  他在一个像样的公会里待过一年，是队里的固定盗贼。公会散了以后他没再进过第二个。
  后来他开始帮网吧的熟客顺手练号，练着练着开始收钱（代练，⚠️ `wow.player.039`）。
  **他对这个游戏的熟练不是热爱换来的，是工时换来的**——这是他和队里所有人最根本的差别。
- **为什么在做现在做的事（根因）**：因为在这个游戏里，**东西是分给在场的人的**。
  他学过一次这条规则，学得很疼，从此一次也没忘。
- **目标（短期 / 长期）**：短期——凑齐那五件迪菲亚皮甲（`wow.gear.055`–`.058`：
  只有胸甲是蓝的、其余四件是绿的，而且**四件绿的全掉在小怪身上，得反复刷**）。
  长期——攒到一身「不用他开口、别人就会叫他」的装备。**他管这叫毕业，但他真正想要的不是数值。**
- **需求（needs）**：**被邀请。** 他这两年进的每一个队，要么是他自己开口求来的，
  要么是收了钱替别人上的号。**没有一次是别人先想起他。**
- **内心欲望（desire）**：想留在一个**散了以后还会有人来找他**的队里。
  他嘴上说「散就散呗」，这句他说了两年了。
- **核心矛盾**：**他唯一能让别人需要他的本事，全都是「我先拿到」的本事。**
  开锁（`wow.class.082`：队伍的唯一解）、搜索、潜行、偷袭——
  他越靠这一套立足，就越像个只顾自己的人；越像，就越没人真心想留他。
  **他的工具箱和他的孤独是同一套东西。** 这是全剧写他的唯一一句总纲。
- **恐惧**：**怕在分东西那一刻自己不在场。** 不是怕分不到——
  是怕「他不在啊」这四个字被人轻描淡写地再说一遍。
- **最大创伤 + 致伤事件**：一年前，旧公会，一次团灭。
  **那一次他没跑**——他留下来拖怪，死了。他在跑尸的路上（`world.md` 2.2：
  画面褪成灰蓝，人是半透明的自己，得自己走回尸体处），
  团长把那件他等了两个月的装备给了另一个在场的人，理由是：「他不在啊。」
  他回去以后一个字没说，当天退会。
  **他不恨团长——团长说的是实话。他恨的是自己相信过「留下来的人会被记得」。**
  从那天起，他把这条规则反过来用了。
- **此刻怎么 make decision**：**先算退路，再算收益，最后才轮到别人。**
  每一次开打之前，他已经看好出口在哪了。
  这条心理被机制精确地坐实——**他在第一季拿不到「消失」**
  （Vanish 是 22 级，`wow.class.081`；他第一季只走到 20 级）。
  所以他「先跑」用的是**疾跑**（10 级），**是用两条腿真的在跑，所有人都看得见他在跑**。
  **这是本剧给他安排的惩罚：他的怯懦没有隐身衣。**
  （随情节推进逐集更新：ep15 跑了不解释 → ep17 跑之前回头看了一眼 →
  ep18 跑不掉 → ep19 骰赢之后没有立刻走 → ep20 最后一个离开门口。）
- **性格特点**：松弛 / 精明 / 嘴上不吃亏 / 极其耐烦 / 不记仇也不记恩。
  行为体现——他从不正面站进圈子里，永远站在离出口最近的那个缺口上；
  被骂了就笑一下、不接话，第二天照来。
- **成长 / 变化轨迹**（ongoing，每集回看校正）：
  **ep15** 月溪镇入队，全队最讨厌他的那个月，他自己毫不在意 →
  **ep16** 第一个「不像老油条」的细节：全队只有他从不催打字慢的阿蛮，
  因为他在网吧柜台后面见过太多打字慢的人（**这颗种子必须早于他的转变埋下**）→
  **ep17** 死亡矿井第一道锁，他开了，五个人全站在他背后等——
  **这是他一年来第一次被人需要而不是被人雇**，他明显愣了一下，然后装作没事 →
  **ep18** 他照常先跑，这一次没跑掉；**主角回头把他捞了回来**
  （主角打不动却死不掉，concept 主母题——**救他的偏偏是队里最弱的那个**）→
  **ep19** 分赃，他骰 87、主角骰 23。他已经把挨骂的准备做好了，
  结果主角说「恭喜」。**他拿着那把剑在原地站了很久** →
  **ep20** 五个人在矿井门口告别，**他是最后一个走的那个**，什么也没说。
  第一季结束时他并没有变好，只是**第一次不急着走**。
  （**第二季伏笔，本季不得提前兑现**：22 级他会学会「消失」——**那时候他才真的有得选**。）

## 说话风格模板（声口锚）

**类型：市井油滑，但从不吵架。** 短句，平调，**从不提高音量**。
他的攻击性全在「不接话」里——你骂他，他笑一下，然后说别的。
**几乎不留气口**：一句说完直接接下一句，不给人插话的机会（这是在嘈杂网吧的柜台后面练出来的）。
**全程大白话，一个文绉绉的词都不许有。**

典型口吻示范：
- 「锁的事包我身上。」（ep15 说这句的时候他还差一级——**这张空头支票是他的第一个笑点**）
- 「我先探探。」（然后就没影了）
- 「你们打，我摸一下。」
- 「我也要这把啊，我掷了。」（ep19 · **不是狡辩，是陈述**）
- 「不是我不救，是我救不了。」
- 「别站这儿了，怪要刷了。」（他总是第一个知道）
- 「行吧。」（他一半的回答）
- **后期招牌句：「……我在后面。」**
  ——第一季它的意思是「我不在前面」；后期它的意思是「我没走」。
  **同一句话两种意思，是他整条弧线的刻度。**
