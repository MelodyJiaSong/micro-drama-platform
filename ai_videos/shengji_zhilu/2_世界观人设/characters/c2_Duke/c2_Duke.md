## 角色定位

ep01 在南墙隘口一肩膀把亚伦撞得原地转半圈（S02）、抢着第一个冲上修道院台阶的新兵。
性格核取自旧 c2（中二、嘴硬心软、抢前排，concept G5），人换成这个世界里的人。

**他和亚伦是同一道题的两半**：亚伦的圣光要一口气才升得上来，需要有人替他拖住；杜克要的正是被叫到名字、被派到前面。
"Buy me time"（S12 杜克自己说破 → S21 兑现 → S24 拿它开玩笑）把两个人的需要扣在一起。
亚伦的人物指纹是数人——**杜克要的，正是被算进去**（S25 "One. Two." / "...Us."）。

**名字＝他的伤口，也是全集跑梗**：外号每次喊不完就被截断（S03 / S21 / S22）；米莉的清单上没写他（S21）；
他缠着尼尔斯把名字添上，没人理（S25）。S24 亚伦叫着他的名字让他站前面，S25 外号第一次喊完——这回盾碎了，人没碎。

**1.12 硬壳**：1–9 级战士没有任何拉住怪的手段（`wow.class.094`），他喊得再响，怪也绕过他扑向发光的人。
这是矿洞之败（S12）与加瑞克之战（S23）的发动机，也是他成长线的起跑线。

## 性格 / 动机

- **核心动机**：**被点名**——要一个「别人没他不行」的位置。他不是想赢，是想被叫到名字、被派到前面。
- **表层人设**：全谷嘴最大的新兵。开口就是 "First!" "That's ten!" "Leave it to us!"
- **反差点**：**嘴硬心软，做事老实。** 大话说完真的第一个冲；倒下先说三遍 "I'm fine"，缓过来第一句是 "Sorry"；从不甩锅。
- **关键弱点**：**他不敢不说大话。** 不说，前面那个位置就是别人的；说了，就多欠一笔。

## 人物灵魂（ongoing · 随集深化 · rule 12.11）

> 后续所有剧情 / 台词 / 改动创作前必读此段。

- **年龄 / 当下处境**：17 岁。Goldshire 边上一户农家的老三，刚到北郡修道院报到当战士新兵——王国一半卫兵在远方打仗（S03 维里），新人才轮得上。家里以为他在当卫兵（S27）。
- **前史（之前在干什么）**：地是大哥的，好活轮不到他，功劳也轮不到他领；从小扛麦袋，扛出一副敦实身板。穿着家里的旧衣服、挽着祖父的旧盾、带着自己攒钱买的旧短剑去 Stormwind 参加卫兵选拔，一路过到最后一轮。
- **为什么在做现在做的事（根因）**：最后一轮没念到他的名字。他要站最前面，是因为**站在最前面的人一定会被看见、会被叫到名字**。"Duke the Unbreakable" 是他来北郡路上给自己起的：没人喊他的名字，他就给自己起一个没法不被记住的 *(judgment call)*。
- **目标（短期 / 长期）**：短期——在北郡练出个样子，赶在家里发现之前把谎变成真的；长期——成为「有他在就没事」的那个人，让别人喊他全称的时候不是在笑。
- **需求（needs）**：**身后有个人，让他不用一个人硬撑。** S21 第一次得到：亚伦在他身后起光，他只管挡。
- **内心欲望（desire）**：被点名——「你，站前面」。一句点名比十句「你真厉害」管用。
- **核心矛盾**：嘴上全是「交给我」，身上没有一样本事能把怪拉住（`wow.class.094`）；越心虚越要喊，越喊越还不起。另一股劲：**他最想被看见的那家人，正是他最怕看见真相的人。**
- **恐惧（fear）**：怕自己其实不是那块料；怕有人轻描淡写地说一句 "Maybe I should take point."——那就是念名单那天的第二次。
- **最大创伤 + 致伤事件**：Stormwind 卫兵选拔最后一轮念名单，**没念到他**。他站着喝完一整壶水，一句话没说；回家也没敢讲实话——他没说「我选上了」，只是没说「没选上」，家里自己这么以为（除了本：那天他赶一车草进城卖，站在广场最后面；回家路上只问了一句 Boots holding up?），他没纠正 *(谎是「没纠正」而不是编造，ep02 已按此写)*。**他恨的不是没选上，是自己当时一句话都没说。**所以现在他抢着说。
- **此刻怎么 make decision**：**先站到前面去，再想办法**——犹豫一秒，位置就归别人。1.12 把这条心理坐实了：冲锋 4 级才学、而且**不能在战斗里用**（`wow.term.031`），只能抢在所有人之前开场（"Then I'll open every fight!"（旧稿台词，ep01 现稿未用））。**他的人格和他的本事是同一个形状。** ep01 内的更新：S24 起他知道「站前面」不等于「第一个冲」，而是横跨一步、用身子挡死那条路，让身后的人数完三下。
- **性格特点**：嘴硬 / 心软 / 藏不住事 / 认死理 / 记仇记得特别短。行为体现——抢着第一个冲；倒下先说 "I'm fine"，缓过来先说 "Sorry"；最脏的活默默接过去（"I'll do it."（旧稿台词，ep01 现稿未用））。
- **成长 / 变化轨迹**（ongoing，每集回看校正）：
  - ep01：S02–S12 嘴最响、冲在最前、什么也拉不住 → S11 堵在过道口挨了一镐、坐倒起不来，被亚伦拖出来、治住、架着逃出矿洞（左肩伤，锤为架他丢了），第一句 "Sorry" →
    S12 听懂了，说破 "So somebody buys you time."，小声认账 "...I owe you one." →

    S25 外号第一次喊完，接下最脏的那件事 → S27 第一次不喊，小声把谎说出口。
  - ep02（Goldshire，杜克一家 c21–c24）：S03 头衔落到他身上是「Acting」→ S05 在大哥面前吞掉这个词 → S07 · S10 母亲替他说、替他答，他没纠正（最重的一次）→

## 说话风格模板（声口锚）

**类型：大话开头、小声收尾。** 前半句是吼出来的，后半句自己就虚了。急了抢话、破音；
挨了打先连说三遍 "I'm fine"；缓过来第一句一定是 "Sorry"；自报外号每次喊不完就被人截断。
英文口径（G8）：地道口语，短词短句，缩略照用（I'm / we're / gonna）；乡下口音比 Aaron 土一点（见 `## 配音参考`），土在元音与语调，不在拼写；念白按 ≤3 词/秒算。

**ep01 剧本原句（byte-stable，改了要回剧本同步）**：

| 声口 | 原句 | 出处 |
|---|---|---|
| 抢第一 | "Behind me!" / "First!" / "Leave it to us!" | S02 / S03 / S17 |
| 挨打三遍 | "I'm fine. I'm fine. I'm fine." | S11 |
| 缓过来 | "...Sorry." | S11 |
| 外号被截断 | "Duke! Duke the Unbre— ow!" / "I'm Duke! Duke the Unbrea—" | S02 / S20 |
| 外号第一次喊完 | "Duke the Unbreakable! Did you see th— ow."（旧稿台词，ep01 现稿未用） | — |
| 小声的真话 | "So somebody buys you time." / "...They think I made the Guard." / "...Duke." / "...Us." | S12 / S15 / S23 / S25 |

**声口示例（非成稿，供后续集校准）**：
- "Stand back, I've got this — ...I think I've got this."
- "Leave it to me! ...Wait, both of them?"
- "It didn't hurt. ...It hurt a bit."

**禁忌**：伪古英语（thou / hath / verily / 'tis）；游戏黑话（tank / aggro / pull / taunt / buff / DPS / level / XP / loot / respawn / noob——G1 全剧零玩家概念）；
现代俚语（dude / bro / awesome / cool）；格言对仗、说明书台词。**技能名不出口**（S05 那一吼、S15 冲锋都只演不报名）。
