## 角色定位

- **是什么人**：同服的一名**人类男性盗贼玩家**，散人，无公会。第一季从头到尾都在，但**总在主角前面一段路**。
- **在剧里的位置**：第一季两条恒定主线之一（concept D2）。练级本身撑不起主线——地图会走完，人不会；他就是那个「不会走完的人」。**外部反派范克里夫在第一季末就死了，他不会。**
- **与主角的关系**：**不是敌人，是参照系。** 他从不抢主角的东西、从不挑衅、也几乎不搭话；他只是**每次都已经做完了**。主角的每一次"慢"——回头救人、听完任务文本、等一个打字慢的队友——都要用他来量。
- **他为什么是对手而不是坏人（可机检的定义）**：ninja 的定义是「拿走本不属于自己的战利品」（`wow.player.050`），而服务器上没有裁判、只有名声（`wow.player.053`）。**他一次都没有越过这条线。** 他不 ninja、不 KS、不骗、不喷。他领先的全部来源是：路线更短、决策更快、不和人商量。
- **出场范围（第一季 · 建议 · 待阶段 3 大纲定死）**——敏捷原则：ep07+ 留松，推进到该集再细化。

  | 集 | 他在干什么 | 台词 |
  |---|---|---|
  | ep06 闪金镇 | 背景里一个快到看不清的影子：进旅店、不坐下、拿完东西就走 | 无 |
  | ep07 艾尔文西部 | 主角一队人打赢霍格正在庆祝，他从画面另一侧独自走过，看都没看 | 无 |
  | ep11 哨兵岭 | 主角第一次坐狮鹫的那一刻——他已经在栖木上，**先起飞** | ≤1 句 |
  | ep13 西部荒野 | 主角在读任务文本，他在同一个 NPC 前交完任务转身就走 | ≤1 句 |
  | **ep16 西部荒野**（**爆点**） | 五人已齐、正在攒装备与踩点；他**已经穿着迪菲亚皮甲从月溪镇方向出来**——他进过本了 | ≤2 句 |
  | ep19–20 矿井门口 | 五个人告别时，他在远处独自走开 | 0–1 句 |

- **"装备比主角好一档"怎么在画面上成立**（第一季唯一需要观众一眼读懂的信息）：

  | | 主角（圣骑士 · 16–17 级） | 踏雪无痕（盗贼 · 20 级） |
  |---|---|---|
  | 武器 | **单手锤 + 木盾**（圣骑士不能双持、不能用匕首，`wow.class.022`） | **双持两把匕首**（10 级学双持，`wow.class.081`） |
  | 护甲 | 锁甲档，1–39 级穿不上板甲（`wow.class.017` / `wow.gear.021`），且多为混档捡来的（`wow.class.020`） | **皮甲档**（`wow.class.021`），且**成套**——迪菲亚皮甲套 |
  | 成色 | 杂、不成套、颜色对不上 | 一件**蓝装胸件** + 四件绿，深浅分明但形制统一 |

- **他为什么不挂战袍**：经典旧世开服时玩家能拿到的战袍只有公会战袍（`wow.gear.042`）。**他胸前空着**——这是画面上"他没有组织、他一个人"的唯一证据，也是和后面主角那五个人的直接对照。

## 性格 / 动机

- **核心动机**：**把每一分钟花在能算出回报的地方。** 不是贪，是怕浪费。
- **表层人设**：全服最没有废话的人。问他路他会答，但答完就走；从不寒暄、从不解释、从不占便宜。
- **反差点**：他看起来像个冷血的效率机器，**其实他是全剧最按规矩做人的人**——不 ninja、不 KS、不骗（`wow.player.050`）。而他守规矩的理由是算出来的：名声坏了以后就组不到团，那是**效率损失**（`wow.player.053`：暴雪不管，服务器靠名声自治）。
- **关键弱点**：**他没法处理"不在计划里的人"。** 一个突然求救的陌生人、一个打字慢的队友、一句"等我一下"——这三样东西能让他整个决策链卡住。他的应对永远是同一个：**走开**。
- **他和主角的根本分歧（一句话）**：主角认为路上的人比路重要，他认为路走完了才有资格谈人。**两个人都不是错的，这是本剧不给他判死刑的原因。**

## 人物灵魂（ongoing · 随集深化 · rule 12.11）

> 把他当一个活生生的人写透，不是功能位。后续所有剧情 / 台词 / 创新创作前必读此段（rule 12.11-C）。
> **现实层的内容严格服从 concept B1（自知玩家 · 现实零画面）与 B7（现实画面最多 1–2 次、极简化）**——以下现实细节是**人物底稿**，只从台词与声音漏出来，**不上画面、不进任何 prompt**。年代锚点 A7：2005–2007 九城时期。

- **年龄 / 当下处境**：24 岁，现实里刚工作一年，做的是那种"谁来都能做"的活。游戏里 20 级人类盗贼，散人，无公会，好友列表只有三个人、两个是同一个人的小号。**他每天上线的时间是买来的**——点卡按分钟算（⚠️ `wow.player.029`，底稿限定不进 prompt），网吧按小时算，而 2007 年超过三分之一的中国网民经常去网吧上网、网吧第一次超过工作场所成为主要上网场所（`wow.player.024`）。**"不浪费一秒"对他不是性格，是算术。**
- **前史（之前在干什么）**：从别的网游过来的，那边的规矩是"路线就是一切"。进魔兽的第一件事不是开号，是先找路线；他把一条 1–20 级的练级顺序抄在一个本子上，本子现在还压在键盘底下。**他练过的第一个号在 12 级被他自己删了——只因为路线走歪了、回头补任务不划算。** 这件事解释了他的一切。
- **为什么在做现在做的事（根因）**：他这辈子遇到的所有好东西都是排队排不到、名额轮不上、"下次再说"的。**魔兽是第一件"只要你算得准就一定拿得到"的东西。** 他要的从来不是那件蓝装，是**「可控」**这两个字本身。
- **目标（短期 / 长期）**：
  - 短期＝**20 级前把迪菲亚皮甲套凑齐**。四件绿装掉自小怪（`wow.gear.057`），意味着要反复刷——这是**真实的重复劳动**，而他肯刷、主角不肯，这就是两个人的全部差别；
  - 长期＝进第一个开荒团，站在那张全服首杀的截图里。（留钩：concept D13「团本留钩不拍」——酒馆里有人在说今晚的事，主角一句也听不懂，**而他听得懂**。）
- **需求（needs）**：**被承认他算得对。** 他不需要朋友，他需要一个证明。这也是为什么他不解释——解释就等于承认需要别人点头。
- **内心欲望（desire）**：**有一次不用算。** 他想知道"随便玩"是什么感觉。他从没试过。剧里唯一泄露这个的时刻是：他在狮鹫背上没有立刻打开地图，而是多看了一眼下面的森林——**半秒，然后就低头了**。
- **核心矛盾**：**他用最快的方式走一条本来是用来慢慢走的路。** 他比全服任何人都熟这张地图，却从来没有在任何一个地方停下来看过一眼。他要的"可控"只在他一个人的时候成立，而他最想要的"被承认"必须由别人给——**他要的两样东西互相取消。**
- **恐惧**：**被落下。** 具体到画面：他一看见别人比自己高一级，当晚就不下线。更深的那层和现实同构——**他怕自己一旦停下来，就再也追不上了**，而他说不清要追上什么。
- **最大创伤 + 致伤事件**：删号不是创伤，是结论。真正的那一夜在更早——**开服那个月他在网吧排了大半夜的队才进得去**（⚠️ `wow.player.008` 排队盛况，底稿限定、剧中不报具体数字），等进去以后发现好名字全被占了、他想去的点全是人，那一天他一级没升。他在网吧坐到天亮，手边是一张只剩几百分钟的点卡（⚠️ `wow.player.029` / `wow.player.030`）。**从那天起他再没有"随便玩"过。** —— 这段永不正面叙述，只在第二季某一集他说漏一句半句时让观众自己拼出来。
- **此刻怎么 make decision**：三步，顺序固定。① 这一步花多少分钟？② 有没有更短的？③ **有没有人会拖慢我？** 三问都过才动。凡是要跟陌生人商量的，默认不做——**所以他不是拒绝主角，他是根本没把"组队"放进选项里**。（随剧推进逐集更新：第二季 40 人团会第一次把第③问撞碎——团本要的不是最优路线，是**愿意等人的人**。）
- **性格特点**：`冷静` / `精确` / `不解释` / `不占便宜` / `内里极紧`。行为体现：打完怪蹲下翻尸体的同时人已经朝下一个目标转身；别人喊他他会停，但脚不停；最能说明他的一幕是——**他把翻出来的灰色垃圾装备随手扔在地上，只把铜币收走**，因为回城卖灰装的那几分钟不值那几个铜板。

## 说话风格模板（声口锚）

**类型**：**短句 / 报数 / 不寒暄。** 他不是话少的人，他是**把说话当成本的人**——每句都在给对方省时间，所以听起来像在赶人。

- 「这条快。」
- 「不用等我。」
- 「你那锤子打不动，换个怪。」
- 「我进过了。」
- （被道谢时）「嗯。」

**硬规则**：
- **每句 ≤ 8 个字**，第一季不破例。第二季某一集他第一次说长句时，那个长句本身就是戏。
- **全部大白话、真人口语**（CLAUDE.md 台词白话 self-check / `ai_videos__白话大师` B1–B7）。朗读必须过。
- **黑话浓度按 A6 中浓度**：可以说「毕业」「刷」「拉怪」；**怀旧服梗整组在主角 30 级前禁用**——他不说「金团」「老板」「辛苦费」（`wow.player.060` / `wow.player.066`–`067` 是怀旧服年代口径，进黑名单）。
- **译名**：说「盗贼」不说「潜行者」（`wow.class.013`）。

**禁忌**：
- 不嘲讽、不说教、不讲道理、不比较、不反问。**他一句嘲讽都没有——这是他不是反派的声学证明。**
- 不喊、不提高音量、不带语气词（没有「啊」「呗」「嘛」）。
- 不说文言、不说对仗、不说格言、不念稿（`ai_videos__白话大师` B2/B3）。
- 不说完整因果句（「因为…所以…」），他只给结论。
