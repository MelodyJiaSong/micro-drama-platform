# 配音 casting 表（voice_id 全剧锁定 · 同角色复用 · 英文配音）

> **铁律**（rule 12.4-H）：同一角色全剧 / 跨集**只用一个 voice_id**；不同镜只改**情绪 / 语速**，**不换音色**。
> 每个有台词的 shot 的 `## 台词配音 prompt` 从本表取 id，与各角色卡「配音参考」段**双向一致**（机检：`python tools/check_stage2.py`）。
> **命名规范**：`en-{m|f|x}-szzl-{角色短名}-{NN}`，`en` ＝ 英文配音，`x` ＝ 非人类。短名一经登记不随角色改名而改。
> **英文化**（concept G8 / G9，2026-09-25）：全剧台词英文、面向英语观众；旧 `zh-…-szzl-X-NN` 一律作废，同短名换 `en-` 前缀。
> 例外两条：c1 → `en-m-szzl-aaron-01`、c2 → `en-m-szzl-duke-01`（G9 定了世界内名字，按新名开槽）。
> 声样（`2_世界观人设/voices/{voice_id}/ref.wav`）一律取英文母语录音；该目录尚未建立，没有旧声样要迁。
> *(judgment call — 早期 18 张卡曾并存五套 voice_id 命名法，已统一为一套；本次整表只换语言前缀，短名不动。)*

**口音口径**（G8 改写 E4）：

| 人群 | 口音 |
|---|---|
| Stormwind / 艾尔文的人类 | **中性、略带英伦的英语**；身份靠音区、语速、句子长短区分 |
| 军人 | 同上，**短促**：辅音干脆、句尾不拖 |
| 农人、乡下人 | **土一点**：元音放松、语调起伏大 |
| 工匠（石匠） | 粗、字短、懒得收尾 |
| 修士 | 慢、轻、室内音量，**不做布道腔** |
| 非人类 | **靠破碎语法与音色区分，不靠口音** |

> **不拿任何真实国家或地区的口音刻板印象做笑点。** 念白闸门（G8）：≤3 词/秒；禁伪古英语（thou / hath / verily…）。
