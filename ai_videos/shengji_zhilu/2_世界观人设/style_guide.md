# style_guide · 《圣光刚好够用》 · *Just Enough Light*

> 全剧统一的**渲染样式串 / 色板 / 情绪光映射 / 负向锁定**。所有角色卡、场景档、shot prompt 从本文 **byte-identical re-paste**，
> **shot 级不新造词**（`ai_video.md` 跨模板不变量）。
> 零 hex（rule 1b）：所有颜色用自然中文色名。
> 版本锚点：经典旧世 Vanilla 1.12 · Year 25 ADP。
>
> **⚠ G 组转向（concept G1–G9）优先于本文旧稿**：零游戏 / 玩家概念、零 UI（**含后期叠层**）、面向英语观众。
> **画幅**：成片与 shot prompt `比例:` 一律 **16:9**（G9⑤，主平台 YouTube 长视频；9:16 短切另议）；**角色立绘仍 9:16**（§7）。
> 片头字卡、画内文字、英文配音见 §8 / §9。

## 1. 渲染路线 —— 半写实基线 + 三档滑杆

**基线**继承 `shikong_lvxing/sk2` #107：**建筑形制 / 比例 / 配色忠于游戏**（让老玩家一眼认出这是艾泽拉斯），
**材质 / 光线 / 皮肤 / 大气走写实电影级**。

三档不是三种画风，是**同一画风的夸张系数**。三档**共用同一套摄影串与做旧层**，只有 `比例句` 与 `布光句` 不同——
所以同一个角色跨档不会漂成两个人。每镜在 `## Shot context` 写一行 `档: D低 / D中 / D高`，生成器 build 时校验。

| 档 | 用在哪 | 比例句 | 布光句 |
|---|---|---|---|
| **D低** | 对话、赶路、日常任务、室内（全剧约 60% 的镜） | 真人正常比例，肩宽略宽于常人，武器与护甲尺寸写实 | 自然光为主，柔和，低对比，不打戏剧光 |
| **D中** | 打怪、组队推进、场景展示（约 30%） | 肩宽明显宽于常人，护肩与武器比真人大一号，轮廓优先 | 有明确主光方向，中对比，轮廓光勾出剪影 |
| **D高** | 名场面、hero beat、集末高潮（约 10%） | 英雄化比例：肩宽为头宽三倍以上，武器夸张放大，剪影极强 | 强戏剧光，高对比，逆光与轮廓光并用，大气透视拉满 |

*(judgment call — 三档是把「半写实」从审美词变成可机检的数字。本剧镜型分布极不均匀：大量任务对话与赶路 + 少量名场面，
一个参数服务两种需求必然两头不讨好。分档同时满足仓库「能量化的反馈必须落成可机检闸门」的纪律。)*

### 全片共用摄影串（`渲染样式:` 的固定前半，每镜 byte-identical）

```text
影视级实拍质感，35mm 胶片颗粒，浅景深，真实皮肤纹理与布料纤维，物理正确的材质反射，
大气透视，画面不烧字幕、不出现任何文字
```

> **⚠ 16.9 铁律**：以上共用串里**只放对每一镜都成立的内容**（影像质感 / 颗粒 / 景深 / 字幕禁令）。
> **光源、天气、时段、天光色温一律拆成条件分句**，按镜写；没有该光源的镜还要**反向声明**。
> 踩过的坑：`冷白灰环境与暖橙火光强色温对比` 被写死进全 12 镜，于是白天挖土的镜也在被要求画暖橙火光。
> 本剧最容易犯的同类错误是**把圣光金色写进共用串**——见 §4。

## 2. 色板（分区开工 · C4）

> **W14 核验（2026-09-20）改写了本节。** 核验员逐条回抓后指出：**六区色板里凡是具体颜色的部分，只有西部荒野一条有原文依据**，
> 其余全是推定；原稿另有**三个自造国服译名**挂在 ✅/T1 上（「北郡谷地」实为**北郡山谷**、「达克希尔」实为**夜色镇**）。
> 下表按核验后的强度重排：**地貌与植被 ✅ 可进 prompt；颜色除西部荒野外一律 ⚠️**。

| 区 | 主色 | 辅色 / 点缀 | 阴影偏向 | 光向 / 时段 | 雾 / 介质 | 强度 |
|---|---|---|---|---|---|---|
| **北郡山谷** | 嫩叶绿（比艾尔文更亮更浅——「新手区」的明亮感） | 修道院**暖白石** + 蓝灰瓦顶；葡萄架**深紫** | 蓝绿 | **上午斜射**，光从南侧谷口来 | 极薄晨霭贴河面 | 地形 ✅ / 色 ⚠️ |
| **艾尔文森林** | **饱和翠绿**（阔叶硬木的浓绿，**不是针叶的墨绿**） | 农舍**赭红瓦** + 麦田**熟黄**；溪水**青碧** | 蓝绿偏冷 | **正午偏午后**，透过树冠打成斑驳光斑 | 树冠间的丁达尔光柱 + 草上露 | 植被气候 ✅ / 色 ⚠️ |
| **西部荒野** | **枯黄草色** | 风车**深棕木** + 匪徒**暗红头巾**；西侧海的**冷蓝** | 暖褐偏灰 | **下午 / 逆光**，长影 | **浮尘必写**（风吹过田的尘） | **色相 ✅**（唯一有原文：「草是黄的」） |
| **赤脊山** | 谷地**深绿**（榆与松） | 长眠湖的**墨蓝绿** | 红褐 | **清晨 / 黄昏** | 山谷晨雾分层、湖面水汽 | 植被 ✅ / 色 ⚠️ |
| **暮色森林** | **近黑的蓝绿灰**（极低明度，**但仍有色相**） | **夜色镇**窗口那一点**孤零零的暖橙**（全区唯一暖色）；坟场**灰白** | 冷紫 | **永夜**——月光为主光，低角度 | **黑雾是主角**，悬在林冠上 | 永夜与黑雾 ✅ / 色相 ⚠️ |
| **暴风城** | **中蓝瓦顶 + 暖白石** | 蓝金狮纹；旧城区**暗红褐**顶；法师区**紫**顶 | 冷蓝 | 见 sk2「色温三角」 | — | ✅ 引用 sk2 |

**三条核验后的纠正，务必记住：**

1. **「赤脊山」的「赤」查无出处。** wiki 该条目只列了别名，**全文未解释地名由来、未提红岩**。
   原稿的「山脊锈红岩」是推断，不得当硬依据——**赤脊山的主色是谷地深绿，不是红**。
2. **暮色森林的黑雾只有一层**（`black fog hanging over the woods`，悬在林冠上）。
   「还有贴地流动的第二层」是推定，不写进定稿。
3. **艾尔文的「暖」来自光，不来自叶子。** 叶子是饱和翠绿，**天光是正午偏午后的暖斜射**——
   两者叠起来才读作「暖金绿」。**把这两件事分开写**是 16.9 的纪律：色是场景属性，光是分镜属性。

> **C10 裁定仍然成立**：艾尔文**不是秋色**。原文反复出现 lush / brightly sunny / fertile，
> **没有任何一处**描写落叶或枯黄。艾尔文的情绪职能是「家」——它必须让后面的西部荒野（干旱荒原）
> 和暮色森林（阴郁浓雾）**在对比中成立**。一上来就秋色萧瑟，会把整部剧的色彩递进曲线提前用掉。

**升实路径**：`pending_user.md` #3（导出 `wago.tools` 的 `LightData` / `Light` CSV，锁 Classic Era 构建）——
一次导出可把**全部六区**一次性升到数据级。在那之前，**⚠️ 的颜色只可用于草稿，不得进定稿 prompt**。

## 4. 圣光特效分级（C5 · 本剧对仓库「藏锋·无外放」默认的偏离）

仓库默认是**藏锋·无外放**（无金光 / 瞳光 / 外放威能）。**不推翻这一条，主角在画面上就和一个拿锤子的普通士兵没有区别**——
圣骑士这个职业的全部识别度就在外放的金光上。裁定：**分级**。

| 档 | 用在哪 | 允许的圣光表现 |
|---|---|---|
| **低（进共用串）** | 日常 / 练级 / 对话镜 | 只有两个最低记号：① **脚下常驻的低亮度贴地光环圈**（不发散、不照亮周围、边缘柔和）② 施放圣印时**武器上一闪而过的金**（≤0.3 秒） |
| **中 · 审判（按镜条件化）** | 把印「推出去」的那一下 | 锤面上聚起**一团**金光、脱锤飞出、命中处一闪即灭；**不起光柱、不成束、不拖尾**；光离开后锤头即旧铁色——**锤子从不持续发光** |
| **高（按镜条件化）** | 救人 / 圣疗 / 圣盾 / 终幕赎回 | 头顶落下的治疗光柱、金色护盾泡泡、制裁之锤落下时的震荡圈 |

**ep01 用到的六种圣光表现各落哪一档**（2026-09-25，剧本第二轮审查后定）：

| 表现 | 档 | 镜 |
|---|---|---|
| 脚下常驻低亮光环 | 低 | S08 首亮 → S11 熄 → S12 起常驻 |
| 请光（上印）时锤头一闪 ≤0.3s | 低 | S05 / S14 / S15 / S22 / S24 |
| 审判：一团金光脱锤飞出 | 中 | S14 / S15 / S22 / S24 |
| 小治疗：掌心一小团暖光，不起光柱 | 低 | S11（第一发）/ S13 |
| 祝福：**不出光**，只拍被祝福者的身体反应（攥拳、青筋、肩一松） | — | S14 / S21 |
| 全量治疗：暖金光柱落下、散成光点 | 高 | **只在 S23** |

**铁律**：高档特效**只写在该镜的条件分句里，绝不进共用串**（16.9）。
**没有圣光表现的镜必须反向声明**：`本镜没有任何圣光特效，人物不自发光，脚下无光环`。

**瞳孔永远不发光**（K13 沿用）——`ai_videos__格式契约` 会扫。

## 5. 负向锁定（基线 · 每镜必贴）

```text
人脸变形，五官漂移，畸形肢体，多余手指，画面文字，字幕，水印，logo，
夸张金光，人物自发光，瞳孔发光，现代服饰，现代建筑，现代器物，
塑料感材质，游戏引擎渲染感，游戏截图质感，UI 界面，血条，头顶名牌，伤害数字，
低模棱角，贴图拉伸，卡通渲染，三维动画感
```

> **基线 22 项**，含仓库强制的 7 项（人脸变形 / 五官漂移 / 多余发光特效 / 画面文字 / 畸形肢体 / 夸张金光 / 现代服饰），
> **不得删基线**，可按镜追加条件组（无例外：§8 定案后书写道具镜也保留 `画面文字`）。
> **本剧特有的四项**——`游戏引擎渲染感 / 游戏截图质感 / 低模棱角 / 贴图拉伸`——是半写实路线的守门员：
> 它们防的正是「看起来像游戏录像」这一件事。
> `UI 界面 / 血条 / 头顶名牌 / 伤害数字` 也在基线里。~~本剧的 UI 全部走后期叠层（B3），一个像素都不进生成块。~~
