# 选题

## 选题标准

| 标准 | 为什么 |
|---|---|
| 场地原始、自然、美，自带尺度 | 系列第一卖点（用户 2026-09-13） |
| 有一个「已经在那里的」锚点 | 和地方达成协议，不是无中生有（`bible.md` §4.1） |
| 能造出过得了档位量尺的房子 | 不简陋、结实（用户 2026-09-12；`bible.md` §4.2） |
| 有一个看得懂的原理 | 观众看懂才收藏转发 |
| 有本地环境钩子和一顿饭 | 按环境引入吸引人的地方、野外做饭（用户 2026-09-12） |
| 模型见过很多、材质有机 | 土、雪、苔、黏土、石、芦苇、雨、火出画稳；水体工程、圆木屋榫口对齐难 |
| 和已拍的集差异够大 | 防止第二集看起来像第一集：做的事、对抗者、原理、奇观四样都要换 |

验证阶段（前几集）优先「容易拍」；跑通后再上难度高的（水面多、冰、潮间带）。

## 第一集选题卡

**ep01 = 雨林第一夜，重做**（代理建议，用户 2026-11-08 认可）。

| 项 | 内容 |
|---|---|
| 为什么 | 用户 2026-09-06 立项时点的就是雨林；Vision 里的「雨里的安逸」在雨林最直接；雨、雾、树冠光柱、湿木纹都是模型强项 |
| 地带 | 东南亚热带雨林（具体地点原型待考据） |
| 锚点候选 | 林间台地（旧 hy1）；或换一个更有地貌特征的锚点（巨大板根之间、溪边岩台），考据时定 |
| 原理候选 | 约五十度陡坡的叠瓦式棕榈叶覆顶 + 屋檐排水沟（看懂为什么不漏） |
| 对抗者 | 午后暴雨与天黑 |
| 奇观 | 树冠缺口漏下的实体光柱；板根与人的尺度 |
| 钩子与一顿饭 | 待考据（候选：溪里抓鱼、竹筒煮） |
| 访客候选 | 犀鸟（远远一次） |
| 风险 | 旧 hy1 已做过同一题材：新一集要按新骨架重新构思，不照抄旧分镜；雨中长镜的水体细节要审 |

备选：深雪（模型稳、反差强，旧 hy4 的雪洞尺度问题已知）、草崖（黄土崖横掘，旧 hy3 的「墙裂」教训已知）。
