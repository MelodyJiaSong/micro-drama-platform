# 《荒野生活》· 系列圣经

> 本文件是**跨集不变量**的唯一出处。每一部片子（`hy1` / `hy2` / …）的 `1_立项/concept.md`
> 只写**这一部特有的东西**，凡是「系列都这样」的，一律指回这里、不复述（rule 4i ①：一份东西只有一个出处）。

---

## 1. 一句话

**一个人走进一片没有人的地方，用一天时间，让自己今晚能睡得着。**

不是求生挑战，不是征服自然，不是教程。是**一个人和一个地方之间，一天之内达成的一份临时协议**。

## 2. 系列公式（每一部都照这个走）

| # | 不变量 | 说明 |
|---|---|---|
| 1 | **一天之内** | 从晨雾到夜火。不跨日、不闪回、不预告。 |
| 2 | **一个地方** | 一部片只有一个世界（一片林子 / 一道谷 / 一座岛）。所有 shot 都在它里面。 |
| 3 | **一个人，从头到尾没有一句话** | 无台词、无旁白、无配音、无字幕。**声音就是旁白。** |
| 4 | **第一夜** | 片名一律是「{地方} · 第一夜」。他今晚要睡在这里——这是全片唯一的赌注。 |
| 5 | **他造/改的东西必须被用到** | 屋顶要挡住雨，沟要走水，火要不烧到树。**没被用到的工程不许拍。** |
| 6 | **三次同机位对比帧** | 同一个固定机位（各片自己的 `N1`）拍三次：动工前 / 中途 / 建成。进度不靠解说。 |

| 8 | **一个活物，只出现一次** | 每部片有一只本地生物，**全片只给它一次**，不给反应镜、不给特写、不解释。 |
| 9 | **长线伏笔：有人来过** | 每部片在某个远景的边缘留下一处「上一个人的痕迹」，不到两秒、不推镜、不对焦。**只埋不收。** |

| 10 | **每部片一张四站发布页** | `{片}/5_6_分镜与prompt/publish.md`，固定七节：母版与通用设置 / 封面帧 / **YouTube** / **TikTok** / **抖音** / **小红书** / 平台对照 + 发布前检查。**YouTube 与 TikTok 英文，抖音与小红书中文**，四份文案各自创作、不是互译。每块可复制内容单独进 ```text 围栏。通用契约＝`ai_video.md` rule 16 |

| 12 | **无人声 ⇒ 一条母版通吃四站** | 不配音、不翻译、不出竖版；横屏直投短视频站、接受上下黑边。这是系列声音策略换来的最大红利 |

## 2b. 场地：系列的第一卖点（2026-09-13 用户定调）

> **「hy 系列其中最吸引人的地方就是场地，环境要原始、自然而且要美。」**

这一条排在「那个人」之前，因为**人每部会换，场地不会降级**。三条硬要求：

| # | 要求 | 判据 |
|---|---|---|
| 1 | **原始** | 画面第一眼要说「没有人来过这里」。不是郊外、不是牧区、不是林场边缘。凡看着像**农田 / 牧场 / 人工林 / 公园**的地貌一律换掉 |
| 2 | **自然** | 地貌必须是**某种自然过程的产物**，而且那个过程看得出来（冰川刨的、河水切的、风磨的、树倒掀起来的、火烧空的）。**看不出来历的地形就是没有故事的地形** |
| 3 | **美** | 每部的 `bg1` 必须是**一眼就震的地貌奇观**，并且**自带尺度参照**——人站进去要明显被压过 |

**判据一句话**：**`bg1` 拿掉人之后，它自己是不是一张值得单独看的照片？** 不是就重挑。

### 已确立的反面教训（`hy3` 初版，2026-09-13）

hy3 初版的 `bg1` 是「一道三米高、坡度四十度的土坡，覆草皮，灰白无方向散射光」。
它**逻辑自洽但毫无吸引力**，三处失误值得每一部开工前回看：

1. **「一个地形」不等于「一个地方」。** 三米高的坡，人站前面头顶就到一半——**没有尺度压迫**。
   hy1 靠九十米的红杉、hy2 靠四米高的根盘；一道普通的坡给不了这个。
2. **为了技术纪律牺牲了美。** 为了「地面几乎没有锐利投影」而定了灰白无方向散射光——
   那条纪律来自 hy1 / hy2（雨林与红杉本来就在树冠与海雾下），
   **草原没有树冠，草原本来就该有斜光**。照搬纪律 ＝ 把这个地方的光照错了。
   **→ 立规：光的性质由地点决定，不跨片照搬。**
3. **为了逻辑自洽牺牲了题材。** 「没有一棵树所以必须横掘」这条推理没错，
   但它把画面里所有可看的东西都拿掉了。**自洽是底线，不是卖点。**

### 已确立的反面教训 ②：**对抗者不能是「房子会坏」**（`hy3` shot05，2026-09-13）

hy3 初版把对抗者定成**「土会塌」**——黄土沿一道贯穿裂纹在他头顶整块剥落，他没有躲，
因为他早上看过那道裂纹。设计上很漂亮：危险、伏笔回收、老手证明一次到位。

**出图就废了。** `bg2-1` 里那道黑缝从草线一路劈到洞口正上方，
**看着整面墙要下来** —— 而本系列的核心承诺恰恰是
**「房子要有特点、要有安全感、不简陋」**（`../proposal.md` A）。

> **立规：对抗者永远不能是「已建成的结构在失效」。**
> 一个会塌的墙、一个漏的顶、一根断的梁，**把这部片最该卖的东西当场卖掉**。
> 观众要的是「我想住进去」，不是「幸好他躲开了」。

**合法的对抗者长什么样**（三类，按优先级）：

1. **材料/场地不告诉你答案** —— 哪一段土是实的、哪块石头压得住、这土黏不黏。
   他靠**读**（敲声、捏土、看层）解决。hy3 现在走这条。
2. **天气与时间** —— 天黑前必须完工、暴风夜会不会漏。
   注意：天气可以**考验**已建成的结构，但结构**必须通得过**（hy3 shot13 暴风夜里
   挑檐一动不动、屋里是干的 —— 这是「安全感」的正面证明，不是危机）。
3. **一个技术原理成不成立** —— 烟会不会自己走、火能不能引燃、水能不能排掉。

**证明「他是老手」的正确形式是预防，不是化险。**
老手的分界线不在「险中不慌」，而在**「险根本没来得及发生」**：
土还完好的时候他就把梁架上了；挖之前他先敲了三下。
这比「塌下来他没躲」更硬，而且方向和「安全感」一致。

## 3. 那个人（**每部可换** · 用户 2026-09-12 定调，见 `../proposal.md` §0 决定 7）

**服装与体型跨片 byte-identical，不换季、不换装。**这是系列最强的识别符——观众认的是那个剪影。
冷、热、湿、干，靠**呼出的白气 / 手上的泥 / 汗湿的领口 / 姿态**表现，**不靠加外套**。

- **锁定描述符（每一部的 `角色:` 行原样复制）**：
  `橄榄绿长袖衬衫炭灰工装裤旧布帽，腰侧棕皮刀鞘，中等偏瘦`
- **人脸一致性**由用户建立的 **Seedance 人物 entity** 承载（立绘 + turntable + entity description）。
  **shot prompt 一律不写文字五官**——写了会和 entity 打架。
- **三条硬规矩**：① 永远不看镜头（视线越过镜头看向环境或手上的活）；② 不磨皮不美颜；
  ③ **脏污只增不减**，一天之内单调递增。
- **决策逻辑**：先看，再动。每一部的第一件事都是站定环视一圈——他不是冲进来就干活的人。
- **唯一一次情绪外露**：建成的那一刻，**肩膀落一下**。别的什么都不做。

## 4. 声音（无人声，声音就是旁白）

| 段 | 声音主轴 |
|---|---|
| 起 | 本地环境音最密（虫 / 风 / 水）→ 脚步与地面材质 → 第一个人造声音 |
| 承 | **动作音全面接管**：刀、木、石、绳、土。**中段不铺 BGM**，把耳朵让给工具与材料 |
| 转 | **环境音突然变静**（这是天气将变最真实的预告）→ 风 → 火的轻爆 → 水/雨的三层 |
| 合 | 声音退到只剩火与滴水 → 另一套夜声起 → 签名定帧处**可铺极简 BGM**，全片仅此一处与开场 |

**一条镜一条音床。** 生成器按镜生成，一条镜的环境音是整段统一的——所以切分单位是
**一个地点 ＋ 一个状态 ＝ 一条镜**，镜内换段靠切镜、不接音（见 §5）。

## 5. 制作规格（跨片默认）

| 项 | 值 |
|---|---|
| 画幅 | **16:9**（不出竖版） |
| 片长 | **260–285s**（约四分半） |
| 镜数 | **12 镜上下**，单镜 **15–30s**，实际落 20–27s |
| 镜内切镜 | **允许**。每镜 `分镜:` 行写死各段起止秒与「连续运镜 / 切」；切镜不做转场特效、不改变时间线 |
| hero 段位置 | **排在各自镜的片尾**（情绪最高点 / 签名定帧）——坏了只重跑那一条 |
| 承接 | 镜与镜之间**全部硬切**，无首末帧交接链 |
| 台词 | 每镜 `台词: 无`，负向块必带人声抑制词组（格式契约 K22） |
| 字幕 | **全片零字幕**，由用户后期自加 |

**三条实拍纪律**（生成器字段强制，不靠人记；全局规则见 `agent_refs/project/ai_video.md` rule 16）：

1. **干活的镜一律不背包** —— 背包只在赶路段背着，**必须有一镜把「卸下」演出来**，此后一律不在身上。
2. **掉落物走真实重力** —— 越落越快、落地即停并溅起；负向带 `慢动作 / 落体滞空 / 羽毛般缓降`。
3. **人造结构件成型即锁定** —— 绳结 / 捆绑 / 榫卯 / 封口写成一条 byte-identical 描述串，
   凡该节点入画的镜原样复现；成型之前的镜**反向声明「此时尚未…」**。

## 6. 每一部必须换掉的四样

系列最大的风险是**第二部看起来像第一部**。所以每开一部，先在这张表上把四格填出不同的答案：

| # | 维度 | `hy1` 雨林 | `hy2` 红杉 | `hy3` 草崖 |
|---|---|---|---|---|
| 1 | **他做的是什么事** | **从零搭一个家**（砍、削、架、绑、盖） | **住进一棵活着的树**（清、垫、挡、封——改造一个已有的空间） | **往垂直的黄土崖里横着掘**（掘、支、砌、抹、挑檐——第三个方向） |
| 2 | **对抗者是谁** | 雨林本身（永远在把人造物拆回去） | **风暴与潮湿**；而**树是盟友**，它替他挡住了风 | **黄土沿竖向干缩裂纹整块剥落**——第一次对抗者是材料本身，不是天气 |
| 3 | **黑科技是什么**（观众看懂一个原理） | 棕榈叶**叠瓦**——上层压住下层上半段，水顺搭接线走，不渗缝 | **火怎么在活树里烧才不烧到树**——石板隔热 + 离壁一臂 + 洞口上方留排烟缝；外加**垫高地面防返潮** | **烟为什么会自己走**——炉膛收口 + 烟道收细 + **烟道穿过五米厚黄土直通崖顶**，屋在崖面下、烟囱在崖顶草里 |
| 4 | **奇观是什么** | 树冠缺口漏下的**实体光柱** | **从树洞里往外仰拍，树干一路收进九十米高的雾里** | **一道横贯出画、看不到尽头的七米黄土崖 + 崖顶逆光透亮的银白针茅草海**；远景里整面崖只剩一个黑点和一缕烟 |

> **20 部的排产、这四格的全部答案、元素怎么系统化引入、结构强度标准、逐部概念卡与调研证据，
> 全部在 `../proposal.md`**（系列根目录下的总提案文档）。本表只留已拍两部，后续各部不在这里复述。

**天气预兆也不许重复**：hy1 是鸟先飞走，hy2 就**不能**再用「动物离开」——改用**雾的方向反转、突然沉下来**；hy3 两样都不用——改用**远处的云边发白**（外加崖顶草海整体换向）。
