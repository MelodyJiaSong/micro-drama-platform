# 《荒野生活》· 系列圣经

> 本文件是**跨集不变量**的唯一出处。每一部片子（`hy1` / `hy2` / …）的 `1_立项/concept.md`
> 只写**这一部特有的东西**，凡是「系列都这样」的，一律指回这里、不复述（rule 4i ①：一份东西只有一个出处）。

---

## 1. 一句话

**一个人走进一片没有人的地方，用一天时间，让自己今晚能睡得着。**

不是求生挑战，不是征服自然，不是教程。是**一个人和一个地方之间，一天之内达成的一份临时协议**。

---

## 2. 系列公式（每一部都照这个走）

| # | 不变量 | 说明 |
|---|---|---|
| 1 | **一天之内** | 从晨雾到夜火。不跨日、不闪回、不预告。 |
| 2 | **一个地方** | 一部片只有一个世界（一片林子 / 一道谷 / 一座岛）。所有 shot 都在它里面。 |
| 3 | **一个人，从头到尾没有一句话** | 无台词、无旁白、无配音、无字幕。**声音就是旁白。** |
| 4 | **第一夜** | 片名一律是「{地方} · 第一夜」。他今晚要睡在这里——这是全片唯一的赌注。 |
| 5 | **他造/改的东西必须被用到** | 屋顶要挡住雨，沟要走水，火要不烧到树。**没被用到的工程不许拍。** |
| 6 | **三次同机位对比帧** | 同一个固定机位（各片自己的 `N1`）拍三次：动工前 / 中途 / 建成。进度不靠解说。 |
| 7 | **签名定帧收尾** | 最后一镜一律是：**退到很远，黑暗里只剩他那一点火光，镜头极缓后拉**。每一部都用这个收法——观众刷到就认得。 |
| 8 | **一个活物，只出现一次** | 每部片有一只本地生物，**全片只给它一次**，不给反应镜、不给特写、不解释。 |
| 9 | **长线伏笔：有人来过** | 每部片在某个远景的边缘留下一处「上一个人的痕迹」，不到两秒、不推镜、不对焦。**只埋不收。** |

| 10 | **每部片一张四站发布页** | `{片}/5_6_分镜与prompt/publish.md`，固定七节：母版与通用设置 / 封面帧 / **YouTube** / **TikTok** / **抖音** / **小红书** / 平台对照 + 发布前检查。**YouTube 与 TikTok 英文，抖音与小红书中文**，四份文案各自创作、不是互译。每块可复制内容单独进 ```text 围栏。通用契约＝`ai_video.md` rule 16 |
| 11 | **封面按站分两种** | **YouTube 永远用签名定帧**（建系列识别，观众刷到就认得）；**短视频站用本片最抓人的那一帧**（吃点击率）。小红书另出一张 **3:4 竖裁**封面 |
| 12 | **无人声 ⇒ 一条母版通吃四站** | 不配音、不翻译、不出竖版；横屏直投短视频站、接受上下黑边。这是系列声音策略换来的最大红利 |

**第 9 条的进度**（这是唯一跨片累积的东西）：

| 片 | 痕迹 | 给法 |
|---|---|---|
| `hy1` 雨林 | 被藤蔓吃掉的旧木构架 | 他扛杆走过时，画右中景一闪，约两秒，失焦 |
| `hy2` 红杉 | 树洞内壁高处几道旧刻痕 + 一枚锈死的方头铁钉 | 他举火照亮内壁时扫过，约两秒，他没停手 |
| `hy3` 草坡 | 掘开的土层剖面里露出一段烧过的木炭层 | 锹刃刮过时露出，约一秒半，他停半秒后继续掘 |
| 后续 | 留松，不预排 | —— |

## 3. 那个人（跨片同一个人）

**服装与体型跨片 byte-identical，不换季、不换装。**这是系列最强的识别符——观众认的是那个剪影。
冷、热、湿、干，靠**呼出的白气 / 手上的泥 / 汗湿的领口 / 姿态**表现，**不靠加外套**。

- **锁定描述符（每一部的 `角色:` 行原样复制）**：
  `橄榄绿长袖衬衫炭灰工装裤旧布帽，腰侧棕皮刀鞘，中等偏瘦`
- **人脸一致性**由用户建立的 **Seedance 人物 entity** 承载（立绘 + turntable + entity description）。
  **shot prompt 一律不写文字五官**——写了会和 entity 打架。
- **三条硬规矩**：① 永远不看镜头（视线越过镜头看向环境或手上的活）；② 不磨皮不美颜；
  ③ **脏污只增不减**，一天之内单调递增。
- **决策逻辑**：先看，再动。每一部的第一件事都是站定环视一圈——他不是冲进来就干活的人。
- **唯一一次情绪外露**：建成的那一刻，**肩膀落一下**。别的什么都不做。

## 4. 声音（无人声，声音就是旁白）

| 段 | 声音主轴 |
|---|---|
| 起 | 本地环境音最密（虫 / 风 / 水）→ 脚步与地面材质 → 第一个人造声音 |
| 承 | **动作音全面接管**：刀、木、石、绳、土。**中段不铺 BGM**，把耳朵让给工具与材料 |
| 转 | **环境音突然变静**（这是天气将变最真实的预告）→ 风 → 火的轻爆 → 水/雨的三层 |
| 合 | 声音退到只剩火与滴水 → 另一套夜声起 → 签名定帧处**可铺极简 BGM**，全片仅此一处与开场 |

**一条镜一条音床。** 生成器按镜生成，一条镜的环境音是整段统一的——所以切分单位是
**一个地点 ＋ 一个状态 ＝ 一条镜**，镜内换段靠切镜、不接音（见 §5）。

## 5. 制作规格（跨片默认）

| 项 | 值 |
|---|---|
| 画幅 | **16:9**（不出竖版） |
| 片长 | **260–285s**（约四分半） |
| 镜数 | **12 镜上下**，单镜 **15–30s**，实际落 20–27s |
| 镜内切镜 | **允许**。每镜 `分镜:` 行写死各段起止秒与「连续运镜 / 切」；切镜不做转场特效、不改变时间线 |
| hero 段位置 | **排在各自镜的片尾**（情绪最高点 / 签名定帧）——坏了只重跑那一条 |
| 承接 | 镜与镜之间**全部硬切**，无首末帧交接链 |
| 台词 | 每镜 `台词: 无`，负向块必带人声抑制词组（格式契约 K22） |
| 字幕 | **全片零字幕**，由用户后期自加 |

**三条实拍纪律**（生成器字段强制，不靠人记；全局规则见 `agent_refs/project/ai_video.md` rule 16）：

1. **干活的镜一律不背包** —— 背包只在赶路段背着，**必须有一镜把「卸下」演出来**，此后一律不在身上。
2. **掉落物走真实重力** —— 越落越快、落地即停并溅起；负向带 `慢动作 / 落体滞空 / 羽毛般缓降`。
3. **人造结构件成型即锁定** —— 绳结 / 捆绑 / 榫卯 / 封口写成一条 byte-identical 描述串，
   凡该节点入画的镜原样复现；成型之前的镜**反向声明「此时尚未…」**。

## 6. 每一部必须换掉的四样

系列最大的风险是**第二部看起来像第一部**。所以每开一部，先在这张表上把四格填出不同的答案：

| # | 维度 | `hy1` 雨林 | `hy2` 红杉 | `hy3` 草坡 |
|---|---|---|---|---|
| 1 | **他做的是什么事** | **从零搭一个家**（砍、削、架、绑、盖） | **住进一棵活着的树**（清、垫、挡、封——改造一个已有的空间） | **往山坡里横着掘**（掘、垒、砌、抹、盖——第三个方向） |
| 2 | **对抗者是谁** | 雨林本身（永远在把人造物拆回去） | **风暴与潮湿**；而**树是盟友**，它替他挡住了风 | **土会塌**——第一次对抗者是材料本身，不是天气 |
| 3 | **黑科技是什么**（观众看懂一个原理） | 棕榈叶**叠瓦**——上层压住下层上半段，水顺搭接线走，不渗缝 | **火怎么在活树里烧才不烧到树**——石板隔热 + 离壁一臂 + 洞口上方留排烟缝；外加**垫高地面防返潮** | **烟为什么会自己走**——炉膛收口 + 烟道截面小于炉膛 + 灶口低于烟道口 + 烟囱高出屋脊两掌 |
| 4 | **奇观是什么** | 树冠缺口漏下的**实体光柱** | **从树洞里往外仰拍，树干一路收进九十米高的雾里** | **草原远景里没有房子，只有一根石烟囱在草里冒烟** |

> **20 部的排产、这四格的全部答案、元素怎么系统化引入、结构强度标准、逐部概念卡与调研证据，
> 全部在 `../proposal.md`**（系列根目录下的总提案文档）。本表只留已拍两部，后续各部不在这里复述。

**天气预兆也不许重复**：hy1 是鸟先飞走，hy2 就**不能**再用「动物离开」——改用**雾的方向反转、突然沉下来**；hy3 两样都不用——改用**远处的云边发白**。

- 每片的 spec 落 `specs/ai_video/hy{N}/`。
- 生成器一律 `tools/gen_shots_hy{N}.py` + `tools/gen_scene_prompts_hy{N}.py`。
- webapp 侧：`series.json` 让侧边栏把整个系列收成一个可折叠组；剧根由后端 `is_drama` 标记，
  **不许按路径深度推断**（`libs/common/drama_ref.py`）。
