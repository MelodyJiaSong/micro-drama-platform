## A · 元素系统与场景骨架

### 1. 这 20 部为什么能成立

调研的核心发现（D §一读数 3）：**同类频道里跑得最稳的那一个，
二十条视频拍的是同一件事，每次只换「房子挂在哪」**——根盘下 / 空心树里 / 两棵橡树之间 /
树桩下 / 山丘里 / 水面芦苇上——播放中位数不因重复而衰减。

所以这 20 部的骨架不是 20 个题材，是 **20 个锚点**。观众每次来看的是同一个承诺
（一个人，一天，外面极端，里面暖），变的只是**这一次他把家挂在什么东西上**。

| 类别 | 数量 | 规则 |

| **新变量**（每部必须全换） | 6 | 锚点 · **构造特征** · 一个原理 · 对抗者 · 奇观 · **环境专属钩子** |
| **轮换量**（每部一个，全系列不重复） | 5 | 野生访客 · 声音签名 · **本地容器** · **人物类型** · **反差类型（≥3 处，类型不重复）** |

| **跨片线**（人每部换之后，连续性只剩这两条） | 2 | **痕迹人链**（每部的人留下的东西，是另一部的人看见的痕迹）· **那只贯穿的动物**（可选，见 §0 决定 12） |

#### 十一条元素轴（A–K）

**轴 A · 位置锚点 + 构造特征（新变量，两格都必填）**

- **锚点** —— 片单的骨架，20 个不重复。它回答「房子挂在什么东西上」：
  倒木根盘 / 空心树 / 树桩 / 巨岩下 / 洞口 / 深雪 / 山坡横掘 / 芦苇水上 / 竹丛穹顶 /
  礁石缝 / 倒木躯干之上 / 三棵树之间 / 砾石阶地 / 碎石坡石圈 / 冻土石圈 / 旧地基。
  **锚点必须是一个「已经在那里的东西」**——系列的立意是「和一个地方达成协议」，不是无中生有。
- **构造特征（2026-09-12 新增必填）** —— 锚点回答「在哪」，构造特征回答「**这栋房子长什么样，
  观众三个月后还记得哪一处**」。它必须是**一个能一句话说完、并且只属于这一部的建筑做法**：
  草皮顶外一根独立石烟囱 / 漂来的船板当门 / 白色的桦皮瓦屋顶 / 一排把水送到远处的竹槽 /
  要低头才能进的矮门 / 离地三米的平台加一段斜木梯 / 别人的石墙配他的新顶。
  **判据**：把它从片里拿掉，这部片就和上一部长得一样了——拿不掉，才算及格。

**轴 B · 一个原理（新变量）** —— 每部**只给一个**能看懂的原理，贪三个是这个品类最常见的死法
（hy2 调研 §3 已判）。热工程是最稳的来源，未用完的格：
反射火墙 / 石头蓄热床 / 黏土壁炉+排烟道 / 冷空气沉降（挡低不挡高）/ 小火烧石过夜 /
雪的隔热+呼吸孔 / 落叶堆厚度（空气才是保温的那个东西）/ 火在活树里不烧树 /
芦苇捆的隔潮与浮力 / 竹节导水 / 太阳能凝水坑 / 架高防返潮。

**轴 C · 对抗者（新变量）** —— 雨 / 雪 / 风 / 霜 / 热 / 潮水 / 涨水 / 渗水 / 蚊群 /
没有燃料 / 没有水 / 土会塌 / 苔藓湿滑 / **他自己上一次的错误**。
**至少有一部要把「钟」换掉**：系列默认的倒计时是天黑，hy5 换成**潮水**，hy14 换成**上游的雨**。
**换人之后新开了一格**：城里来的那一部，对抗者是**他自己的不熟练**（§2e 人物候选池）。

**轴 D · 生物（轮换量 + 跨片线）** —— 调研里回报最高的一条，但要拆成三层，
**不要混成「每次换一只小动物」**（D §一读数 5）：

| 层 | 出现规律 | 作用 | 受圣经第 8 条约束 |
|---|---|---|---|
| ① **一次性野生访客** | 每部一只，**全片只给一次**，不给反应镜、不给特写、不解释 | 新鲜感 + 「这个地方是活的」 | **是**（这一条就是为它写的） |
| ② **那只贯穿的动物**（2026-09-12 改写） | **它不属于任何人**——它一直在那片荒野里，人来了住一夜就走，它还在。从某一部起每部露一次，**只有老观众认得它** | **依恋** + 把立意推一层：**它是房东，人是过客** | **否**（见 §0 决定 1、12） |
| ③ **远处的危险** | 全系列不超过三次，只给痕迹或远景，**从不交互** | 让「里面暖」有代价 | 否（不入画） |

**轴 E · 奇观（新变量）** —— 每部一个构图级奇观，写进 `style_guide.md`。
已用：树冠光柱（hy1）、坑底仰拍根盘（hy2）。

**轴 F · 声音签名（轮换量）** —— 每部一条贯穿全片的主音，**它替代了旁白**：
雨打叶 / 雪落（几乎无声）/ 单点滴水 / 潮 / 风穿石缝 / 干叶沙响 / 竹林同向的响 / 水下闷响。

**轴 G · 痕迹线（累积量）** —— 圣经第 9 条。每部埋一处，不到两秒、不推镜、不对焦。
**hy22 收束**（调研读数 7：遗迹/修复本身就是一个跑量格式）。

**轴 H · 他身上的东西（累积量）** —— **2026-09-12 重写，见 §2b「工具：三类分开管」**：
原生工具（刀 + 随身五件）永不变；自制件每部 +0 或 +1、**上限 6 件**；
**地方工具用完留在原地**（它同时是痕迹线的机制）。
服装另立三层制度（锁定层 / 气候层 / 脏污层），见 §2b。

**轴 I · 完成度六件套（不变量，每部都要）** —— 用户 2026-09-12：「要有点安全感，不要太简陋」。
调研佐证（D §六）：**床 + 灶一起进标题的那条最大（43.0M）**；
Cyprien 的卖点词是 `complete` 与 `comfort`——**「完成」本身就是卖点**。
每部房子必须做出这六样，缺一件就是简陋：

| # | 件 | 为什么它让人有安全感 |
|---|---|---|
| 1 | **一扇能关上的门** | 有轴 / 有绑扣 / **能从里面顶住**——不是挡一下的树皮。关门那一下是全片最被需要的动作 |
| 2 | **一张离地的床 + 一层干铺垫** | 离地 ＝ 不返潮不爬虫；干铺垫（干蕨 / 干草 / 桦皮）是「今晚睡得着」的物证 |
| 3 | **一个固定的灶** | 石圈 / 挡火墙 / 烟道——不是地上一堆火。灶固定了，这里才是「家」而不是「营地」 |
| 4 | **一个采光或排烟口** | 叙事上是「不闷」，技术上是**白天内景不黑**的前提（AI 出图尤其需要） |
| 5 | **一处储物** | 壁龛 / 挂杆 / 吊篮——东西有地方放 ＝ 有人住，不是躲一夜 |
| 6 | **一件「多余的东西」** | 一张凳子 / 一个木钩 / 一道门帘 / 一块垫脚石。**生存不需要它，住下来需要它——「不简陋」的真正来源就是这一件** |

**安全感是拍法，不是道具**（五条，写进每部 `style_guide.md`）：

1. **关门后必须有声音落差** —— 外面的声音降一档。无人声片里这是最强的安全感表达。
2. **至少一镜从里面向外看** —— 门框 / 窗口把外面的风雨框住，**人在暗处、外面在亮处**。
3. **屋里不能留一个朝黑暗的未处理开口** —— 留了观众会不安（他们自己说不出为什么）。
4. **夜镜里火光必须照到围合** —— 能看见墙、顶、门**都在**。只照到人脸＝还是在野外。
5. **他在屋里至少回头看一次门** —— 确认它关好了。一个动作顶十句台词。

#### 轴 I 附则 · 房子的档位与结构强度（2026-09-12 用户定调）

用户原话是「房子也结实点，要有安全感，比如标准可以是抵御得了大风还有野兽」，
随后澄清：**「野兽」是用来形容档位的，片里不需要真的出现野兽。**

所以这一条是**质量口径，不是剧情要求**：
**每个构造细节都要撑得住「它扛得住一场大风、也扛得住一头大牲口撞上来」这个想象。**
观众不需要看见那头牲口——他们看见的是**梁有多粗、结绑得多死、门闩多实**，
然后自己得出「这房子结实」的结论。

调研佐证：风夜头部 19–40M（附录 §十）——**「结实」本身就是流量**。
「野兽题材」经调研已否决，依据见附录 §九。

**档位量尺（八行，开片时逐行对一遍；这是「什么 level」的可执行答案）**

| 部位 | 简陋（不要） | **我们要的档位** |
|---|---|---|
| 梁与柱 | 手指粗的枝条互相搭着 | **手臂粗的原木**；柱脚埋进地里一掌以上，或用石抱脚 |
| 连接 | 靠自重压着、互相搭着 | **每个交叉点都绑死或榫住**，绳圈数看得出来 |
| 墙 | 一层枝叶，站外面能看见里面 | **实墙**：土 / 石 / 垒木 / 双层捆 —— **看不透** |
| 屋顶 | 一层树叶或树皮盖着 | **有坡 + 叠瓦式压接 + 上面还压着石头或压木** |
| 门 | 一块挡着的树皮、一片帘子 | **有框、有轴、有闩 —— 能从里面固定** |
| 地面 | 裸土 | **有垫层或木地板**，床离地 |
| 灶 | 地上一堆火 | **固定灶**：石圈 / 挡火墙 / 烟道 |
| 体量 | 蹲着才能进、只能躺下 | **能坐直、能转身、有地方放东西** |

**最后一行是最好用的一条判据**：**「他能不能在里面坐直」** —— 一眼就分出「窝」和「房子」。
凡是锚点先天窄的那几部（树腔、雪洞、矮门洞），都必须**靠往下挖或掏宽**把这一行挣回来，
挣不回来就换锚点（hy2 调研里「树洞摆不下床」就是这条判据的第一次应用）。

**抗风六条（纯工程，全部做成生成器字段，不靠作者每镜手写）**

1. **屋顶靠压，不靠自重** —— 压石 / 压木 / 绳绕桩。风掀屋顶只有一个原因：没有压重。
2. **迎风面低，出口永不开在迎风面** —— 房子的低边朝主风向；每部的主风向写在 B §5 的表上。
3. **所有构件交叉处必须绑** —— 不是叠放。绳结锁成 byte-identical 串（`ai_video.md` rule 16 ③），
   凡该节点入画的镜原样复现；成型前的镜反向声明「此时尚未捆绑」。
4. **柱脚深埋或石抱脚** —— 埋入地面一掌以上；不埋的柱子风一推就走。
5. **屋顶有坡、无大平面** —— 大平面就是风帆。
6. **风的缺口被处理过** —— 每部至少一镜是他去堵一道缝（这同时是「他在检查」的性格戏）。

**三级（每部都要全过，不分档）**

| 级 | 要求 | 适用 |
|---|---|---|
| **L1 档位** | 档位量尺八行全过 | 20 部全部 |
| **L2 抗风** | 抗风六条全做到 | 20 部全部 |
| **L3 被看见** | 三种可见证据至少用两种（见下） | 20 部全部 |

**非刚性门的补偿规则**（hy12 芦苇帘 / hy15 帆布 / hy17 帆布 / hy21 竹帘 四部适用）：
这四部的门先天过不了量尺「门」那一行，必须补三样才算过 ——
① **门框做成实框**（帘只是面层）；② **内侧顶杆或压石**，让「关得死」有画面；
③ 门口加一道**挡风屏**。三样齐了才算 L1 通过。

**怎么把档位拍出来（三种可见证据，每部至少用两种）**

1. **他自己测它** —— 推一把、拉一下、把全身重量挂在梁上、用脚踹一下柱脚。
   **每部第 11 或 13 镜必有一次**，这是最直接的一种，也是「结实」唯一不靠解说的证明。
2. **风来验证它** —— 第 13 镜：屋顶在风里**只有边缘在抖，主体不动**；门在外面的风里不响。
3. **和被否决的方案对比** —— 第 02 镜否决的那个选项，从此固定成
   **「一个不结实的方案」**（低洼处 / 没遮挡的平地 / 会被风灌的开口方向 / 坐不直的窄腔）。
   观众自己会想「幸好他没选那个」，不需要任何解释。

**明确不做**：野兽本体、兽夜、爪痕、响声预警物、陷阱、猎杀、人兽对抗。
依据两条：① 用户澄清「野兽」只是形容档位；② 附录 §九 调研 ——
「猎杀 / 设陷阱 / 正面打」一派量级掉一到两档，与系列立意（人不是来征服荒野的）也冲突。

**轴 J · 灶与一顿饭（新变量，每部一道）** —— 用户 2026-09-12：「引入野外做饭、煮汤、烤肉」。
调研佐证（D §五）：**做饭是这一派的第二主线**，不是配菜——
Outdoor Boys 把「建 + 抓 + 煮」拍成 15–73M 的常态，`Best Campfire Meal Ever` 直接进标题；
最能说明问题的是**有人靠「点评他的每一顿饭」拿到 24.1M**。用户点名的「炖汤 + 烤面包」
有 4.6M 的无解说直接样本（Men With The Pot），黏土炉烤饼 17.5M。

四条纪律（防止它变成美食视频）：

1. **食材必须是这一部取到的那一样** —— 第 9 镜取食 → 第 12 镜下锅，**因果闭环**。
   这同时是「不能太单一」的解法：**钩子不同 → 食材不同 → 做法不同 → 容器不同。**
2. **一顿饭只占一镜（≤30s）** —— 不给吃相特写、不摆盘、不切多道菜、不拍「好吃」的表情。
3. **必须有蒸汽 + 一条声音** —— 蒸汽是「热」唯一的可见形式；声音选一条：
   汤滚 / 油滴进火 / 壳裂开 / 面饼贴在石板上的那一声。
4. **他吃第一口时唯一的反应是呼吸慢下来** —— 见 §0 决定 4（这会给系列添第二处情绪外露）。

**本地容器（轮换量，每部一个，全系列不重复）**：随身那口熏黑铝锅是底线（跨片锁定描述符已有），
每部**额外做或捡到一个本地容器**——桦皮罐 / 竹筒 / 泥包 / 石凹 / 大贝壳 / 吊锅 / 黏土炉 /
热石板 / 地坑 / 空心木。它是「这一顿只能在这里做」的物证。

**轴 K · 环境专属钩子（新变量，每部一个）** —— 用户 2026-09-12：「要根据不同环境引入吸引人的地方」。
每个地带都有一件**别的地带给不了**的事。实测钩子库（D §七）：

| 地带 | 专属钩子 | 实测量级 |
|---|---|---|
| 雪 / 极寒 | **冰钓**（凿冰 → 等 → 把鱼拖出来） | **38.1M** |
| 雪 / 极寒 | 温度数字进平台标题 · 极光 | 32–35M · 27.4M |
| **古树 / 丛林** | **掏野蜂蜜**（爬高 + 烟熏 + 蜂群） | **39.1M** |

**野蜂蜜（39.1M）是两轮调研里性价比最高的一个发现**：它和 `hy8 空心巨树` 天生咬合——
蜂巢就在树腔高处，他得用**烟**把蜂赶走，而烟正好是那一部的「一个原理」。
**一个钩子同时给了奇观（爬高）+ 危险（蜂群）+ 一顿饭（蜜）+ 原理复用（烟）。**

#### 轮换规则（防止第二部看起来像第一部）

1. **相邻两部不得共享**：气候带 / 锚点类别 / 对抗者 / 主要材料 / 天气预兆手法。
2. **主要动作要换动词**：往上搭（hy1）→ 往下挖（hy2）→ 掏（雪、空心树）→ 垒（石）→
   捆（芦苇、竹）→ 堆（落叶）→ 捡（漂流物）→ 修（遗迹）。
3. **奇观的主色不得连续重复**：暖色（hy1 光柱）→ 灰绿（hy2 雾）→ 蓝（雪顶、蓝冰）→ 金黄（秋）。
4. **天气预兆手法全系列不重复**：鸟先飞走（hy1）→ 雾反方向（hy2）→ 环境音被雪吃掉 →
   潮线上移 → 水色变浑 → 竹林同向倒 → 远处的云边发白。

### 2b. 人物 / 服装 / 工具：每部都换（用户 2026-09-12 定调）

**用户定调：人物、工具都是每集可以换的。** 我原先建议「二十部同一个人」，用户否了这条，按用户的来。
下面是按新口径重算的方案，以及必须跟着动的几处结构。

| 项 | **定论** |
|---|---|
| 人物 | **每部换。** 二十部是二十个不同的人 |
| 服装 | **随人换**（不再有跨片锁定层；一部之内仍 byte-identical + 脏污递增） |
| 工具 | **每部换，而且工具就是人设**（见下） |

#### 我先更正自己一个判断

我之前说「换人 ＝ 二十个 entity ＝ 成本 20 倍」，**这个判断是错的**。
每部本来就要新建 14 格 bg 资产，多建一个人物 entity 的**边际成本很小**；
而**跨片锁定同一张脸恰恰是这套流程里最难维持的一件事** ——
每次出图漂一点，识别符就毁一点，二十部下来必漂。
**每部换人反而把跨片一致性风险从「二十部」压到「一部之内」**，这是技术上的净收益。

#### 换人换出来的三个好处（这是用户这条改动真正的价值）

1. **反差轴（§2d 轴 L 类①）彻底解放。**
   「女汉子劈柴」不再需要另开支线，**直接进 hy 序列**。
   而且可以一部一换：**女汉子 / 年过六十的老手 / 十六七岁的少年 / 瘦小的人挪巨木 /
   一个明显是城里来的人**。每一部的「人与活」都可以是新的反差。
2. **每部可以挑最配那个地方的人。**
   雪原给一个粗壮的北方人、竹林给一个瘦而利索的当地人、礁岛给一个渔民、
   苔原给一个不说话的老猎人、岩漠给一个走了很远路的人。
   **人选本身变成了一条新的变量轴**，而且是二十部里最不容易重复的一条。
3. **长线伏笔从「设计」变成「必然」。**
   圣经第 9 条「有人来过」原先是一个刻意埋的彩蛋；
   现在**每部的人留下的东西，就是另一部的人看见的痕迹** ——
   二十部串成一条人链：**先后有二十个人经过同一片荒野的不同角落，
   每个人都留下一点东西，后来的人看见了，不知道那是谁。**
   hy22「旧地基」从一个设计变成一个必然的结局。这条线比原来强得多。

#### 代价，以及怎么补

丢掉的是「观众认剪影」这个最便宜的品牌效应。必须把恒定符号**转移**到别的东西上，
否则二十部会像二十个不相干的短片。**五样恒定符号（每部一样不许改）**：

| # | 恒定符号 | 说明 |
|---|---|---|
| 1 | **签名定帧收尾** | 退到很远，黑暗里只剩那一点火光，极缓后拉。**这是最强的一条，观众刷到就认得** |
| 2 | **片名格式** | 一律「{地方} · 第一夜」 |
| 3 | **全程无人声** | 无台词 / 无旁白 / 无配音。声音就是旁白 |
| 4 | **14 镜骨架 + 同机位三帧 + 档位量尺** | 形式恒定 —— 观众说不出来，但会感觉到「这是同一个系列」 |
| 5 | **火** | 每部的情绪高点都是火第一次烧起来的那一刻；每部的最后一帧都是那一点火光 |

**外加一条建议的第六样：那只动物**（见下）。

#### 工具：从「累积物」改成「人设」

原来的轴 H 是「每部 +1 件自制品、跨片累积」，**这条随人换而作废**。换成更有表现力的：

**工具即人设 —— 一个人带什么来，就说明他是谁。** 不需要一句台词：

| 这个人 | 他带来的 | 观众立刻知道 |
|---|---|---|
| 伐木工 | 一把长柄斧、一把楔子 | 他干这个为生 |
| 木匠 | 一把锯、一支卷尺、一根墨线 | 他会量，他讲究 |
| 少年 | 只有一把小折刀 | 他什么都没准备好 |
| 渔民 | 一支渔叉、一卷线、一把小刀 | 他靠海吃饭 |
| 老猎人 | 一把用了很久的刀、一块磨石 | 他来过很多次 |
| 城里来的人 | 崭新的多功能工具、一个太干净的背包 | 这是他第一次 |

三条纪律：

1. **一部之内工具锁定**：型制、磨损、缠绳位置写成 byte-identical 串，跨镜原样复现。
2. **工具的磨损程度＝这个人的资历**。崭新 ＝ 新手；柄被手磨出油光 ＝ 老手。
   **这是「不用台词交代人物」最省的一手。**
3. **地方工具用完留在原地**（这条保留，而且现在更有力）——
   它就是下一部那个人会看见的痕迹。

#### 那只动物：建议让它成为唯一贯穿的角色

人每部换之后，**「常驻同伴」原来的设计（同一个人收留它）就不成立了**。
建议翻转一下：

> **让那只动物成为整个系列唯一贯穿的角色。它不属于任何人。**
> 它一直在那片荒野里。人来了，住一夜，走了；它还在。
> 从某一部起，它开始在每部的某一镜出现——**不是被谁收养，是它来看看这个新来的人**。

这个翻转把系列的立意又推了一层：**它是房东，人是过客。**
而且它把「每部一只小动物」和「一只贯穿的动物」两条合并了，不再冲突——
**每部仍有本地生物（一次性访客），另有一只跨片的，只有老观众认得它。**

（这条要不要做、以及它是什么，见 §0 决定 12。）

#### 服装：一部之内锁定，跨部随人

- **不再有跨片锁定层。** 每部一套，属于那个人。
- **一部之内 byte-identical**，脏污只增不减（这条保留，它是单日叙事的证据）。
- **按地带配衣**（原「气候层」升为常识而不是例外）：雪原穿得住雪，岩漠穿得住晒。
  这条现在反而更自由——不用再想办法让同一件衬衫在冰川和沙漠都合理。
- **全系列统一色域**：灰 / 棕 / 墨绿 / 土黄之内，不出现鲜色与 logo。
  **色域是丢掉剪影之后仅剩的视觉统一手段，必须守死。**

#### 换人连带影响的三部（必须改写，这是这条改动唯一的实际代价）

| 片 | 原来怎么写的 | 换人之后怎么改 |
|---|---|---|
| **hy11 它来了** | 「他」收留一只幼犬，从此每部都在 | 改成**自足的一部**：「**带着狗来的那个人**」的第一夜 —— 他本来就有狗，不是这天捡的。**给它也造一个小屋**这条最好的设计原样保留，「它撞门、门不开」也保留（那是全系列唯一一次「结实」被另一个活物测出来） |
| **hy16 雪原 · 第二个冬天** | 「他和它的第二个冬天」，跨片续写 | 两条路：**若决定 12 ①成立** → 改成「**另一个人，同一只动物**」：那只动物又出现了，这次陪的是别人（**这比原设计更动人**）；**若不成立** → 改成普通的第二个雪片，换锚点（风吹雪脊下的雪檐），片名去掉「第二个冬天」 |
| **hy18 洪水之后** | 「他」回到自己在 hy1 造的棚屋，对抗者是他自己上次的决定 | **建议走决定 12 ②**：让 **hy1 那个人回来**，全系列唯一一次人物复现。理由——「**回到自己造的房子，面对自己上次的错误**」这个 beat 换人就没了，而它是二十部里最有重量的一个。若不留这个例外，就把对抗者改成「**上一个人的决定**」，但那样 hy18 和 hy22 会撞题（两部都在修别人的东西） |

**其余十七部完全不受影响** —— 锚点、构造特征、原理、对抗者、奇观、钩子、一顿饭、档位量尺
全部与「是谁在干」无关。

**一条建议的措辞**：默认每部换人，但圣经写成「**人物每部可换**」而不是「**必须换**」——
留出 hy18 这类刻意复现的口子，也允许同一种人物类型在相隔很远的两部里复现
（类型可复现，**人必须是不同的人**：不同的脸、不同的工具、不同的磨损程度）。

### 2c. 除了每部一只小动物，还能加什么（提案，2026-09-12）

按「在无台词片里有多有效 × 成本」排。**前六条建议立刻立成常量，后三条可选，最后两条不建议。**

#### 建议立刻采用（六条）

1. **他修正一次自己的错误**（每部常量）
   每部必须有一次「做错 → 自己看出来 → 改」。hy10 已经有（先把挡风墙砌高了，
   冷还是灌进来，他拆低重砌）。**升为系列常量。**
   **这是可信度最强的来源** —— 一次修正比十次成功更像真人干活，
   而 AI 生成内容最缺的恰好是「不完美的过程」。成本零。
2. **远处的文明痕迹**（全系列 2–3 次）
   他在某个远景里看见一样**属于文明的东西**：一条翻过山脊的电线、天上一道飞机白痕、
   夜里海面上一盏船灯。**不给特写、不推镜、他也不反应，只是看见了。**
   它一下把「他为什么在这里」立成悬念——而这个系列到现在还没有任何悬念。
   **我认为这是最有潜力的一个新元素**，成本几乎为零。建议放在 hy5（海上的灯）、
   hy15（山脊的电线）、hy22（最后一次，飞机白痕）。
3. **每部那个人身上有一件说不清来历的私人物品**（永不解释）
   帽子内侧别着的一枚旧铜扣、口袋里一小块叠好的布、一枚磨平的硬币。
   **一部之内露两次，每次不到两秒，永不解释、永不提起。**
   无台词片里想给人物加深度，这几乎是唯一的低成本手段——
   它和痕迹线是一对：**荒野里有别人的过去，这个人身上有自己的过去。**
   （人物每部换之后这条反而更强：**每部一件不同的私人物品，
   等于每部白送观众一个想象的人生。**）
4. **一处三秒的真空白**（每部一处，位置固定）
   不是环境音变小，是**真的静音三秒**。放在第 10 镜「天气预兆」之前。
   在一部全靠声音叙事的片子里，**空白是最重的标点**——
   而且它天然是「不祥」的（人耳会自动警觉）。hy4 深雪那部本来就是「雪吃掉声音」，
   到那一部这条会达到顶点。
5. **水的仪式**（每部一镜）
   洗手 / 洗脸 / 洗锅。它是「一天结束了」的通用信号，
   同时是**脏污递增的对照点**——洗完手，指甲缝里还是黑的。
   这一镜也给「他是个讲究的人」一个证据，直接服务「不简陋」。
6. **手的特写作为签名**（每部至少三镜）
   只拍手：结绳、削木、抹泥、把石头摆平。这个品类的 ASMR 属性大半靠手。
   **它同时是 AI 生成的避险手段**——手部近景不涉及人脸一致性，
   是全片最稳的镜次，可以放心给时长。

#### 可选（三条，看你要不要）

7. **夜里风停的那一刻**（情绪奖赏）
   现在每部的结构都是「天气变坏 → 抢工 → 撑住」，缺一个**奖赏**。

   并保证二十部里四季各有 4–6 部。好处是系列有时间感，坏处是多一个排产约束。
9. **「他做了一件完全没用的东西」升格**
   完成度六件套的第 6 件现在是「一件多余的家具」（凳子 / 木钩 / 门帘）。
   建议把它扩到**纯审美**：在门框上刻一个记号、把一块好看的石头摆在窗台、

### 2d. 反差（轴 L，2026-09-12 新增）

用户给的例子是「**女汉子劈柴**」，它点出了一个我前面漏掉的机制：**反差**。

而且这个系列其实**一直在用它，只是没写成规则**：
「外面暴雪 / 里面暖」是反差、「九十米红杉 / 一个人」是反差、「蓝冰 / 一点橙火」是反差、
「满画面金黄 / 最后一镜白霜」是反差。**它一直是这个系列最有效的东西，却从来没被管理过。**

**立成轴 L：每部至少三处反差，类型不重复。** 七类如下，★ 是这次新提的。

| 类 | 机制 | 候选 |
|---|---|---|
| **① 人与活** | 干这活的人「看起来不该干这活」 | ★**女性主角劈柴 / 扛原木**（→ §2e，已可直接进主线）｜★瘦小的人挪动比自己大三倍的倒木｜★**干净秀气的手 → 满是伤和泥的手**（首尾同机位对照） |
| **② 外与内** | 外面极端 / 里面暖 | **系列核心引擎，已在用**（第 13 镜） |
| **③ 尺度** | 巨物 / 一个人 | 已用（红杉 · 巨岩 · 竹林）｜★**一只很小的动物 / 他造的整栋房子**（衬尺度，也衬「有人住」） |

| **⑤ 声音** | 巨响 / 极静 | ★**外面狂风，屋里蜡烛的火苗不动**｜已提的三秒真空白 |
| **⑥ 时间** | 新 / 旧 | 同机位三帧（已用）｜★**手上的新伤 × 旧疤**｜★他一天造的东西 × 旁边几十年的旧木架 |
| **⑦ 选择** | 他有更容易的办法，却不用 | ★**他有镁棒，却蹲下来搓火钻** —— 不是没有，是不用 |

#### 这批里我最想推的四条

1. **外面狂风，屋里蜡烛的火苗不动**（类⑤）
   **这是「结实」最优雅的证明** —— 比他推墙、比屋顶不抖都强，因为它是**零解释的**：
   一根火苗立在那里不动，观众立刻知道这屋子没有一丝风进来。
   一镜之内先给外面的风（树在倒、雪在横着走），切进屋内，**火苗是直的**。
   建议**升为每部常量**，替代原来「他推一把墙」那种略显刻意的验证方式。
2. **手的编年史**（类①/⑥）
   **第 01 镜与第 14 镜用同一个手部机位**：干净的手 → 满是划痕、木屑、泥、一个新血口。
   它和「同机位三帧」是一对，区别是——**那三帧拍房子的进度，这两帧拍人的代价。**
   成本为零，而且手部近景不涉及人脸一致性，是 AI 生成最稳的镜次。
3. **重量必须被看见**（类①的执行纪律）
   **AI 生成最容易把重物拍成泡沫** —— 原木飘着走、石头轻飘飘落地。
   所以立一条纪律：**每部至少一镜专门表现重量** ——
   扛起来时的一顿、走两步换一次手、放下时的闷响加一次地面震动、喘、
   把东西搁在膝盖上缓一下。这是 `rule 16 ①`（掉落物真实重力）的**表演版**。
   反差在这里是自动产生的：**东西越重，人越显得小。**
4. **他带着更省事的家伙，却不用**（类⑦）
   腰上挂着镁棒，却蹲下来搓火钻；背上有锯，却用刀顺着木纹劈。
   **不解释、不犹豫、也不失败。**
   这一条给人物加的深度比任何台词都多：**他不是被困在这里的，他是选了这里。**
   人物每部换之后这条更好用——**它成了区分「老手」和「新手」的那一笔**：
   老手选难的做法，城里来的那个人会掏出最省事的工具。全系列给 3–4 次，**永不点明**。

### 2f. 第二批新元素候选（非反差类）

1. **他在门框上刻一道** —— 和 hy2 根盘、hy8 树腔里那种刻痕**同一种刻法**。
   观众要到 hy22 才会明白：**痕迹线里有一部分是他自己留下的。**
   这一条和「地方工具留在原地」是同一个机制的第二层。
2. **他先在地上用炭画一下要造的样子** ★★
   一镜 6 秒：地上一张简图，然后他照着做。
   **给「他有计划」一个证据**，同时让观众**预知结构** ——
   后面每一镜的可读性都会提高（观众能看懂他在装哪一部分）。
   **这一条是这批里最实用的**，尤其对 AI 生成的片子：观众有了图，就不容易被漂移搞糊。
3. **雨或雪落在镜头上** —— 一滴水糊在画面一角，几秒后消失。
   「有人在现场拍」的临场感，低成本、极有效。
   **慎用**：一部最多一次，全系列不超过 5 次，否则变成滤镜。
4. **他数东西** —— 数捆数、数石头层数、数椽子。把「工程」可视化。
   **注意**：hy1「数椽子」踩过 AI 跨镜一致性的坑，所以
   **只给手势和声音（嘴唇不动的点数），不给可数的全景**。
5. **他给房子留了一个不必要的窗，专为看某个方向** ★★
   那个方向就是这一部的奇观点（轴 E）。
   **它一次解决两件事**：奇观镜有了存在的理由（不是导演要给，是他想看），
   而且「为了看风景开一个窗」是「住下来」最强的证据之一 ——
   **比任何一件家具都强。** 建议**升为每部常量**，并写进完成度六件套第 4 件（采光口）。
6. **气味的可视化** —— 无台词片里「味道」只能靠可见的雾气表达：
   烟、蒸汽、呼出的白气、湿木受热的白汽、汤面的热气。
   立成一条拍法纪律：**每部至少四镜带可见雾气**，这是「有温度」唯一的视觉通道。

### 7. 决定 1 / 2 / 4 / 5 / 6 的完整理由

> 编号与 §0 的表格一致。**决定 3（结构强度标准）的理由写在 A §2「轴 I 附则」**，不在这里重复。

#### 决定 1 · 圣经第 8 条要不要修（**必须先定，它卡住 hy11 之后的全部**）

现行第 8 条：**「一个活物，只出现一次」**。常驻同伴与它直接冲突。
建议的最小修订：**第 8 条改为只管「本地野生生物」**——每部一只本地生物、只给一次不变；
**常驻同伴不属于「本地生物」，不受本条约束**。这样一字不改原意，只加一句作用域。
证据：D §一读数 5（Man and Dog 三连 12.8M / 12.7M / 4.3M、RYUCAMP 16.2M、
救狗+造屋 992.5M）；机理：**无台词片里，动物是唯一能不说话就产生「对话」的对象**。

#### 决定 6 · 要不要试一部 10 分钟的加长版

调研读数 10：全场前三里最短的一条只有 10 分钟（337.2M），7 分钟的也有 90.1M。
我们的 4 分半短于所有赢家。建议在 **hy5 或 hy6** 做一次对照：同一部片出 4 分半与 10 分钟两版
（加长版多的是取材段与原理段的实拍细节，不加新情节），比完播与赞率。
**不改系列规格，只做一次实验。**

#### 决定 4 · 情绪外露从「一次」改成「两次」

圣经 §3：**「唯一一次情绪外露：建成的那一刻，肩膀落一下」**。
加入「一顿饭」之后，吃第一口热汤是一个**必然会有反应**的时刻——不给反应反而失真。
建议改成**两处，位置固定、形式不同、都极小**：

| 时刻 | 反应 | 归谁 |
|---|---|---|
| 建成那一刻（第 10 镜镜尾） | **肩膀落一下** | 工程的结算 |
| 吃第一口（第 12 镜镜尾） | **呼吸慢下来**（不闭眼、不摇头、不看镜头、不笑） | 身体的结算 |

这是本次四条反馈里唯一动到「那个人」的一条，所以单独列出来等你拍板。

#### 决定 2 · 片长从 4:35 升到约 5:20、镜数 12 → 14

14 镜骨架 × 平均 23s ≈ **320s**，圣经 §5 的「260–285s」要改成 **300–340s**。
换来的是：一个环境专属钩子（第 9 镜）+ 一顿饭（第 12 镜）+ 完成度落地（第 7、11 镜）。
调研支持：最短的赢家 10 分钟（337M）、7 分钟（90.1M），**5:20 仍在安全区内**。
如果你想保持 4:35，替代方案是把「取材」并进「主体成型」、把「完成度②」并进「一顿饭」——
能压回 12 镜，但那两段都会薄，**不推荐**。

#### 决定 5 · 「回到旧地点」破不破例

圣经第 4 条是「第一夜」，hy18（洪水之后）与 hy22（旧地基）都不是严格意义的第一夜。
建议：**保留片名格式与全部其他不变量，把这两部定义为「在一个有过去的地方的第一夜」**——
hy18 是他自己的过去，hy22 是别人的过去。系列走到第 18 / 22 部时，观众要的正是这个。

## D · 调研证据（附录）

> 三轮调研，57 组搜索视角 + 4 条频道全量拉取 → 404 条去重样本。
> 播放量全部 yt-dlp 实测；赞率只有 2026-09-09 那批 22 条（原因见 §四）。

### 〇、本轮的数据边界（先说清）

1. **本轮新样本只有播放量，没有赞率。** `yt_research.py meta`（取 like_count 的唯一途径）
   今天全量失败：YouTube 对 watch 页启用了 bot 校验（`Sign in to confirm you're not a bot`），
   升级 yt-dlp 到 2026.08.19、换 4 个 player_client 均无效。**赞率结论一律沿用 09-09 那批 22 条实测**，
   本轮只用播放量做「这个题材有没有观众」的存在性判断。补齐办法见 §六。
2. **播放量来自搜索/频道列表页，是 YouTube 自己的近似值**（频道拉取会取整到 0.01M 量级）。
   当量级用，不做精确横比。
3. **样本是搜索排序前列，不是随机抽样。** 搜索排序本身带偏；「某题材搜不到高播放」只能读成
   **「这个题材在 YouTube 的头部供给里不存在」**，不能读成「拍了一定没人看」。
4. **所有赢家都是真人实拍。** 这个品类还没有 AIGC 可比样本——既是风险也是空位（沿用 09-09 结论）。

### 一、十条读数（按对片单的决定性排序）

#### 1. 情绪引擎只有一个：**外面极端 / 里面暖**

09-09 赞率榜前六里五条是「雪 + 地窝 + 里面是暖的」（1.0–2.0%，26–94M）。本轮把这条推到了更前面：
**全场播放最高的三条非奇观向作品，形态完全一致**——

| 播放 | 时长 | 频道 | 形态 |
|---|---|---|---|
| **337.2M** | 10min | Mr.Heang Update | 半地下土屋 + **草皮屋顶** + **黏土壁炉** |
| **280.1M** | 20min | Cyprien Outdoor Adventures | 土屋 + **草皮屋顶** + 壁炉（09-09 已测赞率 1.03%） |
| **43.0M** | 34min | Vadim in the WILD | 地窝 + **暖石床** + **黏土壁炉**（标题直接写这三样） |

**土 + 火 + 一个像样的房间 = 这个品类的中位数天花板。** 不需要泳池，不需要奇观。

#### 2. 标题级卖点是两个词：**secret / hidden** 和 **warm / cozy**

Polissya Bushcraft 近期 30 条上传里，**绝大多数标题同时带这两组词**
（`Building a Warm and Cozy Dugout` / `Secret Dugout Inside a Hollow Tree` /
`Building a Cozy Shelter under a Tree with a warm clay bed, Hidden dugout`）。
播放稳定落在 2.3–43M。**隐蔽＝观众的占有幻想；暖＝生理奖赏。** 两个都不是视觉奇观，是承诺。

#### 3. **位置锚点是变量，室内回报是常量**——这是 20 部片单的结构答案

Polissya 一个频道把**同一件事**拍了二十遍，每次只换「房子挂在哪」：

| 空心树内部（`Inside a Hollow Tree`） | 23.0M |
| 山丘里的秘密洞（`Secret cave` + 圆木） | 17.0M |
| **两棵橡树之间** | 15.0M |
| 橡树树根下 | 13.0M |
| 地下圆木小屋 | 9.7M |
| 大树内部深处 | 9.6M |
| 树下 + **暖黏土床** | 8.6M |

**没有一条是靠新题材，全部靠新锚点。** 中位数不因重复而衰减——这是 20 部可行性的最硬证据，

### 二、对片单的直接推论

1. **20 部的骨架 ＝ 20 个锚点，不是 20 个题材**（读数 3）。

### 八、对片单的追加推论

1. **加两段戏：「取食」与「一顿饭」各占一镜。** 12 镜装不下，骨架升到 **14 镜 / 约 320s**
   （仍远短于同类全部赢家）。
2. **饭的食材必须是这一部取到的那一样**——第 9 镜取食 → 第 12 镜下锅，因果闭环。
   这同时解决「不能太单一」：**每部的钩子不同 → 食材不同 → 做法不同 → 容器不同。**
3. **「不简陋」拆成六件套 + 一套安全感拍法**（A §2 轴 I）。灶与床是一对。
4. **每部房子必须有一个记得住的构造特征**（本文 A 轴 A 的新必填格）。
5. **保存食物 / 采集** 不进片单（无量）。
6. **温度数字进平台标题**（雪片专用，实测最便宜的一个 CTR 手段）。

### 十一、对片单的追加推论

1. **「结实」必须是可见的，不能是声称的。** 无人声片里只有三种可见证据：
   **他自己去测它**（推、拉、挂上全身重量）、**风来验证它**、
   **和一个被否决的不结实方案作对比**。三种都要用（写进 A §2 轴 I 附则）。
2. **「什么 level」要落成可勾选的量尺** —— 见 A §2「档位量尺（八行）」。
   其中最好用的一条判据是**「他能不能在里面坐直」**：一眼分出「窝」和「房子」。
3. **风夜每部都有**（第 13 镜本来就是极端夜），但**每部的风向与受力点不同**，
   在 B §5 的逐部表上写死。
4. **不做**：野兽本体、兽夜、爪痕、响声预警物、陷阱、猎杀、人兽对抗 ——
   用户已澄清 + 本节 §九 的量级证据。
5. **可留的一条**：`Storm Destroyed the Forest`（10.6M）提示**「一个被风改写过的场地」
   比一片完好的林子更有故事**，可以当某一部的开场条件（不需要野兽也能有危险感）。
