# 荒野生活 · 深雪第一夜（hy4）

> 系列第四部。跨片不变量见 `../_series/series_bible.md`，排产提案见 `../proposal.md` §C。

## 一句话

**一个女人走进两米深的雪里，在一棵大云杉的树冠下挖出一个洞，
在里面烤了一张饼、煮了一锅鱼汤，然后把雪砖拖回来，把门堵上。**

## 规格

| 项 | 值 |
|---|---|
| 画幅 · 片长 · 镜数 | **16:9 · 448s（7:28）· 18 镜** |
| 地带 | 北方针叶林雪原，隆冬，雪深 2–3m，−25℃ |
| 锚点 | 大云杉树冠下的**雪井**，向下掏到地面再横掏 |
| 一个原理 | **雪能保温，但必须留呼吸孔**（两半缺一不可） |
| 对抗者 | −25℃ 与持续落雪 —— **雪会自己把洞口封掉** |
| 奇观 | **洞内仰看，雪顶透成一整片冰川蓝** |
| 声音签名 | **几乎没有声音**（起段近乎无声，全系列唯一） |
| 人物 | **三十出头的女性**（本片新建，人物每部可换） |

## 这一部和前三部最大的不同

**她不只是活下来，她还给自己做了一顿饭。**

用户 2026-09-13 定调「这次一定要增加制作美食环节」，所以**美食线占 4 镜（shot12–15）**，
升为与建造线并列的第二主线：**雪 → 化水 → 和面 → 火边醒面 → 石板烤饼**，配冰钓上来的鳟鱼汤。
**食材（面粉 / 盐 / 油）是带来的**——这是对系列「就地取材」默认的一次显式放宽，**仅限食材**。
