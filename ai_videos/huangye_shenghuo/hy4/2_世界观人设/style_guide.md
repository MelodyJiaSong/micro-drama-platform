> 本文是本片**画面的唯一标准**。所有 shot prompt 与场景主体 prompt 的取词以此为准。
> 跨片不变量在 `../../../_series/series_bible.md`。

---

## 1. 本片最大的技术风险：**全白糊掉**

雪景在 AI 生成里最容易变成一张**没有层次的白纸**：过曝、死白高光、雪面没有质感、
人和雪分不开。这是本片唯一会导致「整部片不能看」的风险。

**对策 ＝ 锁死双色分工。**

| 色 | 归谁 | 出现在哪 |
|---|---|---|
| **蓝** | **雪** —— 从冷灰白到深青蓝的一整条灰阶 | 外景全部；洞内雪顶透光处最饱和 |
| **橙** | **火** —— 只有火、烛、烤饼的焦斑、汤的热气被照亮处 | 灶周围一小圈；夜镜的唯一暖源 |

**中间没有第三种色。** 她的深红毛线帽是唯一例外（构图锚点，见 §4）。

### 雪必须有层次 —— 四条硬要求

1. **雪面永远不是纯白** —— 受光面是冷灰白（约 85–92% 亮度），背光面是**青蓝**（55–70%）
2. **雪面必须有肌理** —— 风垄、脚印、铲痕、落雪堆积的颗粒感、被压实处的反光差异
3. **高光不许爆** —— 最亮处保留质感，**不出现纯 255 的死白块**
4. **新雪与压实雪要分得出来**：新雪松、糙、吃光；压实雪紧、滑、反光

**负向常驻**：`过曝纯白, 死白高光, 无层次雪面, 雪面像纸, 高光溢出, 灰蒙蒙一片, 雾化模糊`

## 2. 光

**光的性质由地点决定，不跨片照搬**（圣经 §2b 反面教训 2）。

| 场合 | 光 |
|---|---|
| **外景（全片）** | 厚云层，**光从整个天空来**，地面几乎没有锐利投影；**但雪面自身的起伏必须靠明暗分出来**，不许平成一块 |
| **正午前后（shot05–09）** | 云层略薄，**有一点方向感** —— 雪垄有极柔和的一侧暗，物体有极淡的影 |
| **洞内 · 白天（shot06–08）** | 唯一光源是**透过雪顶的散射光**，整体暗青蓝；呼吸孔捅穿后**多一束近乎垂直的光柱** |
| **洞内 · 夜（shot12–16）** | 唯一光源是**火**，自下而上；雪壁把橙光反成一圈很淡的暖色，**再往外迅速衰减到近黑** |
| **外景 · 夜（shot17–18）** | 几乎全黑，只有**洞口/呼吸孔透出的一点橙**；雪面靠极弱的天光留一点冷青 |

### 呼吸孔那束光（本片的奇观时刻）

**捅穿之前**：洞内是闷的暗青蓝，光只从洞口进来一点。
**捅穿之后**：一束**近乎垂直、边界柔和的光柱**落进洞内，光柱里看得见悬浮的雪尘与呼出的白气。

> **纪律**：这束光**必须是她捅出来的结果**。捅穿前的镜里绝不许出现它。

### 透蓝的雪顶（封面候选 1）

洞内向上看，**整片雪顶被外面的光透成一整片蓝** —— 不是天蓝，是**冰川蓝**：
青中带灰、厚处更深、薄处发白，能看见雪层的层理像年轮一样横过去。

## 3. 材质词典

| 物 | 怎么写 |
|---|---|
| **新雪** | 干、松、颗粒分明，踩上去塌陷并发出吱嘎声；不结块、不湿、不反光 |
| **压实雪（洞壁）** | 拍打后表面致密、微微反光，能看出手套的压痕与铲面的刮痕 |
| **雪砖（门）** | 锯出来的规整块体，**六个面都是锯齿留下的平行细纹**；下缘削成斜口 |
| **冰（湖面）** | 雪下面是**灰青色的厚冰**，凿开后断口呈**贝壳状**，碎冰是半透明的白 |
| **云杉枝** | 深墨绿近黑，针叶硬而密；断口处露出浅黄白的新木 |
| **扁石板（灶底）** | 灰褐带铁锈色斑，表面粗糙，边缘不规则 |
| **面团** | 从粗糙带面粉的疙瘩 → 揉到**表面光滑发亮**；醒发后鼓起、按下去回弹慢 |
| **烤饼** | 贴石板那面先起焦斑，鼓起时表面绷紧发亮，翻面后是**不均匀的金褐与深褐斑** |
| **鳟鱼** | 背部墨绿带黑斑、腹部银白、鳍边橙红；冻硬后表面结一层白霜 |
| **热汤蒸汽** | **零下环境里蒸汽是唯一能拍出「热」的东西** —— 浓、白、上升快，被火光照亮 |

## 4. 她在画面里怎么被找到

雪地最大的构图问题是**人会消失**。三条：

1. **深红毛线帽是唯一的高饱和点** —— 全片唯一不属于蓝/橙体系的颜色，
   它的功能就是**让观众在大远景里一眼找到她**
2. **深靛蓝外套** 比雪暗两到三档，在冷灰白背景上永远是一个清晰的暗块
3. 远景里**她的动作要有幅度** —— 静止的小黑点会被雪面吃掉

## 5. 镜头语言

| 项 | 值 |
|---|---|
| 画幅 | **16:9** |
| 镜头 | 外景广角为主（16–28mm）；洞内 24–35mm（空间小，广角才进得去）；细节 85–100mm 微距 |
| 景深 | 外景 f8 全景深；洞内 f4 浅景深（把注意力压在手上）；微距 f2.8 |
| 运动 | **慢**。本片是全系列最静的一部——雪本身在动，镜头不必再动 |
| 手持 | **只有 shot11 冰钓的「等」那一段是纹丝不动的固定机位**，其余可有极轻微呼吸感 |

## 6. 本片视觉底线（每个相关镜的负向都带）

| # | 底线 | 画错了会怎样 |
|---|---|---|
| 1 | **火不许直接烧在雪上**，必须看得见石板垫底 | 「灶为什么不陷下去」这个原理废了 |
| 2 | **呼吸孔捅穿之前，洞内不许有那束光** | 奇观时刻失效，观众不知道她捅了个什么 |
| 3 | **雪面不许过曝成纯白** | 整部片不能看 |
| 4 | **不许出现针叶林之外的树种**（阔叶、棕榈、竹） | 气候带穿帮 |
| 5 | **不许出现人造物**：路、电线、围栏、伐木桩、其他建筑、机械 | 圣经 §2b 第 1 条「原始」 |
| 6 | **洞内不许画成冰屋（igloo）** —— 它是**掏出来的雪洞**，壁面是刮出来的，不是砌的砖 | 形态穿帮，与门的雪砖混淆 |
