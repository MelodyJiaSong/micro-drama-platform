## 人物灵魂（`ai_video.md` rule 12.11，十二维）

| 维 | 内容 |
|---|---|
| **年龄** | 三十二岁 |
| **前史** | 在北方长大，父亲是冬季护林员。她从小跟着进林子，**十岁那年第一次看父亲挖雪洞过夜**。后来去了城市，做了八年和雪毫无关系的工作 |
| **动机根因** | 不是逃离，也不是证明。是**她想再确认一次那件事是真的** —— 雪能救你，只要你知道怎么用它 |
| **目标** | 今晚睡在这棵云杉下面，**并且吃上一顿热的** |
| **needs（她需要的）** | 确认自己的手还记得 |
| **desire（她想要的）** | 一顿像样的饭。不是活下去的口粮，是**一顿饭** |
| **矛盾** | 她带了燃气炉，却一次没用。她知道那样更快，但**快不是她来这儿的目的** |
| **恐惧** | 不是冻死。是**发现自己已经不会了** |
| **创伤 + 致伤事件** | 父亲最后一个冬天，她没回去。**他是在林子里没的**。她没说过这件事，本片也不说 |
| **此刻决策逻辑** | 先看，再动。到一个地方先站定环视一圈，判断风从哪来、哪棵树的冠够大。**每个动作一次到位，不试探** |
| **性格** | 利落，不说话，不浪费动作。做事有顺序感——工具用完一律插回原处 |
| **成长轨迹** | 从「检查自己还会不会」到「**她还会，而且她做了一顿饭**」。最后那一口热汤是全片的落点 |

> **这些一个字都不会说出来。** 无台词、无旁白。它们只决定**她怎么动**。

## 表演纪律

| # | 规矩 |
|---|---|
| 1 | **永远不看镜头** —— 视线越过镜头看向环境或手上的活 |
| 2 | **不磨皮不美颜不网红脸** —— 三十出头的真实皮肤，冻红的颧骨与鼻尖 |
| 3 | **脏污只增不减** —— 雪水 → 烟灰 → 面粉 → 鱼腥，一天之内单调递增，**绝不变干净** |
| 4 | **动作一次到位** —— 不试探、不返工、不犹豫。这是「她以前干过」的全部证据 |
| 5 | **唯一一次情绪外露**：`shot16` 第一口热汤时，**呼吸慢下来**。别的什么都不做 |
| 6 | **手是第二主角** —— `shot01` 与 `shot18` 同一个手部机位（反差轴⑥，手的编年史） |

### 手的编年史（反差轴⑥）

| 镜 | 手的状态 |
|---|---|
| `shot01` | **干净**。指甲整齐，皮肤完好，戴着半指手套 |
| `shot18` | **冻红、指节开裂、虎口一道新口子**，指缝里有干面粉，指尖沾着鱼鳞与烟灰 |

**同一个机位、同一个焦段、同一个光位。** 它和「同机位三帧」是一对——
**那三帧拍房子的进度，这两帧拍人的代价。**
