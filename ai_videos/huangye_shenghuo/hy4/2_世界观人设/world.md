# 世界观 · 《荒野生活 · 深雪第一夜》

> 跨片不变量在 `../../../_series/series_bible.md`。本文只写**这一个地方**。
> 立项依据见 `../1_立项/concept.md`。

## 1. 这是什么地方

**一片被大雪压了整个冬天的原始北方针叶林，和一个冻住的湖。**

没有路、没有电线、没有围栏、没有伐倒的树桩。人到这里只有一个办法：走进来。

| 项 | 值 |
|---|---|
| 地带 | 北方针叶林（taiga）雪原，隆冬 |
| 雪深 | **2–3m**（平地到大腿根，背风处更深） |
| 气温 | **−25℃ 上下**，全天不回升 |
| 天气 | **落雪一刻没停** —— 细密的干雪，不是鹅毛片 |
| 光 | 云层厚、光从整个天空来，**几乎没有锐利投影**；正午前后短暂地有一点方向感 |
| 时间跨度 | 一天：上午抵达 → 傍晚建成 → 入夜吃饭 → 夜里封门 |

### 地貌的来历（圣经 §2b 第 2 条：看不出来历的地形就是没有故事的地形）

这片林子和这个湖是**同一场冰川退缩留下的**：湖是冰川挖出来的洼，
林子长在它留下的碛石坡上。所以——
**湖岸是平的、林地是起伏的、树是歪的**（根系被石头挤过），
这三件事必须在画面里同时成立。

## 2. 两个核心地点

### A · 冰湖（`bg1` / `bg9`）—— 开场与吃饭的来源

**开场奇观**，也是全片唯一的开阔视野。

- 整片湖冻实，冰面上覆着 20–30cm 的干雪，**被风扫出一道道平行的雪垄**
- **贴着冰面走的雪雾** —— 薄薄一层，齐膝高，被风推着横移
- 对岸是**一堵齐平的针叶林墙**，深墨绿近黑，顶线平直得像剪出来的
- 天与冰面几乎同色，**地平线靠对岸那堵林墙分出来**
- 人站进去只是冰面上的**一个小黑点**（尺度参照全靠这个）

> **为什么开场放这里**：它是 **shot11 冰钓的伏笔**。开场埋、中段收。
> 她从湖面走进林子，观众**先看见她要吃饭的地方，再看见她要睡觉的地方**。

### B · 大云杉与它的雪井（`bg3`–`bg8` / `bg11`）—— 家

**锚点**。一棵孤立的大云杉，树冠宽而密，**替它自己挡住了雪**——
树干周围形成一个漏斗形的凹坑（tree well），这是她能开工的全部理由。

| 元素 | 内容 |
|---|---|
| 树 | 一棵**大云杉**，树干直径约 1.2m；**下层枝已经被雪埋掉**，最低的露枝在人头顶上方 |
| 树冠 | 压满雪，枝条被压得向下垂，**整棵树像一顶盖到地的帐篷** |
| 雪井 | 树干周围直径约 40m 的漏斗形雪窝（宽是深的九倍；树冠挡住中心、风绕孤树打旋掏走四周的雪），**坑底比周围雪面低 4.5m 左右（整间小屋藏得进去，坑底平坦开阔）**，下半段坑壁才变陡；这棵树长在背风洼地，**四周风积雪六米多深**——必须大到能在坑底再下挖、横掏出居住洞 |
| 她挖的方向 | 从雪井底部**先向下掏到地面**（还有 1m 多），再**横掏**出居住空间 |
| 洞口朝向 | **背风侧**，开在树干的下风向；洞口做**斜坡向下**（雪不容易灌进来） |

## 3. 材料清单（这个地方能给她什么）

| 材料 | 来源 | 用在哪 |
|---|---|---|
| **雪** | 到处都是 | 墙、顶、门（压实雪砖）、水 |
| **云杉枝** | 大云杉下层的枯枝 + 周围小树 | 床（铺两层）、引火 |
| **扁石板** | 雪井底部、树根之间被翻上来的碛石 | 灶底（**防融陷**，本片灶的要害） |
| **枯立木 / 死枝** | 林间 | 柴 |
| 地面针叶层 | 掏到底才露出来 | 床的最下层、洞内地面 |
| **鱼** | 冰湖（冰钓） | 汤 |

**她带来的**（§0 偏离 3，仅限食材）：**面粉、盐、油**。
工具与建材一律随身或就地——这条不放宽。

## 4. 声音（本片的签名：几乎没有声音）

**全系列唯一一部起段近乎无声。** 雪吃掉一切环境音。

| 段 | 声音主轴 |
|---|---|
| **起** | **近乎无声** —— 只有雪被踩实的吱嘎、呼吸、衣料摩擦。**没有鸟、没有虫、没有水流**。观众会先觉得「耳朵坏了」 |
| **承** | 工具接管：铲面切雪的沙沙、雪锯的锯齿声、雪块落地的闷响、冰镩凿冰的金属脆响与冰下的回声 |
| **转** | **环境音被雪吃掉得更彻底**（预兆：声音先变，画面后变）→ 洞内只剩火的轻爆、锅里水开、面团被按压的钝响 |
| **合** | 门拖上的那一刻**声音落差最夸张**（外面风雪 → 里面只有火）→ 签名定帧处可铺极简 BGM |

**shot17 的声音落差是全片最重要的一个声音节点**：
门拖上之前是风雪，拖上之后**只剩火**。中间不做渐变，就是那一下。

## 5. 物理纪律（本片专属，进生成器字段）

| # | 纪律 | 为什么 |
|---|---|---|
| 1 | **雪一刻没停** —— 每个外景镜都有落雪；她挖出来的雪堆，隔几镜再看**已被新雪盖圆** | 这是「钟」，也是对抗者 |
| 2 | **呼出的白气必须在**；洞内的白气**明显比洞外淡**（因为洞里接近 0℃） | 这是「雪能保温」唯一的可见证据 |
| 3 | **火不许直接烧在雪上** —— 灶必须有石板垫底，否则融陷 | 本片灶的要害；画错了原理就废了 |
| 4 | **呼吸孔没捅穿之前，洞内不许有那束光** | 光是她捅出来的结果，不是布光 |
| 5 | **金属碰到会粘手** —— 她碰冰镩、锅、铲柄时都戴手套或隔着布 | −25℃ 的可信度 |
| 6 | **零下的面团变硬很快** —— 和面要快、醒面必须靠火 | 美食线的物理前提 |
