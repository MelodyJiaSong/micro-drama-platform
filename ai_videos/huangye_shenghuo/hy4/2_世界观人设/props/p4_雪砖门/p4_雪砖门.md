# p4 · 雪砖门

## 锁定描述符（`shot09` 成型后每一镜原样复制）

```
一块锯出来的压实雪砖，约六十厘米宽、八十厘米高、二十五厘米厚，六面都留着锯齿的平行细纹，下缘削成斜口，中部横穿一根米白麻绳、内侧打双套结、余头三指长
```

## 为什么门必须是这个样子

| 要求 | 做法 | 不这么做会怎样 |
|---|---|---|
| **能从里面拖回来** | 穿麻绳，**结打在内侧** | 从外面关门 ＝ 人在外面，没意义 |
| **卡得住、不倒进来** | 下缘**削成斜口**，卡进洞口的向下斜坡 | 夜里被风推倒，白挖了 |
| **不被雪封死** | 洞口做斜坡向下，门内侧留一道能用手抠的槽 | 早上打不开 |
| **和洞壁分得清** | 门是**锯出来的规整块体**，洞壁是**刮出来的曲面** | 画成 igloo（`style_guide.md` §6 第 6 条） |

## 绳结锁定串（rule 16.3，成型即锁定）

```
麻绳横穿雪砖中部，内侧打一个双套结，两道绳圈并排贴紧，结头压在绳圈下方，余头三指长、绳梢散开起毛
```

**成型之前的镜（shot01–08）必须反向声明**：`此时门与麻绳尚不存在`。
