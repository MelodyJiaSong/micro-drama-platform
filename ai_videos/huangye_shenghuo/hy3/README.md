# 荒野生活 · 草崖第一夜（Wild Living — First Night on the Loess Cliff）

一个砌了一辈子炉子的老人，带一把锹、一把斧、一把抹泥板走上一道草崖，
**用一天时间横着掘出一个屋，让烟自己走出去。**

> **本片＝一部约五分半的独立短片**，由 14 个 shot 拼接成一条成片。**不是分集剧，没有 EP 结构。**
> 《荒野生活》是系列名，跨片不变量见 `../_series/series_bible.md`，
> 二十二部的排产与元素系统见 `../proposal.md`；本目录只装本片。

## 和前两部差在哪（系列圣经 §6 强制的四格）

| # | 维度 | hy1 雨林 | hy2 红杉 | **hy3 草崖** |
|---|---|---|---|---|
| 1 | 他做的是什么 | 从零往上搭 | 往地下挖 | **往垂直崖面里横着掘**（第三个方向） |
| 2 | 对抗者 | 雨林本身 | 风暴与潮湿（树是盟友） | **土的脾气**——哪一段实、哪一段虚（材料本身，第一次不是天气） |
| 3 | 原理 | 棕榈叶叠瓦 | 床下烟道 | **烟为什么自己走**（炉膛收口 + 烟道收细 + **穿五米黄土到崖顶的高差**） |
| 4 | 奇观 | 树冠光柱 | 坑底仰拍根盘 | **看不到尽头的崖线 + 逆光透亮的银白草海**；远景里整面崖只剩一个黑点和一缕烟 |

天气预兆也不重复：hy1 鸟先飞走 · hy2 雾反方向 · **hy3 远处的云边发白**。

## 使用说明

1. **先出 `bg1-1`**（本片唯一一张零参考自由生成图），过完验收；
   其余 13 张场景图**全部挂它或挂它的下游**（继承拓扑见 `world.md` §2）。
2. **人物**：按 `characters/c1_砌炉的老人/` 的 `c1-1` 立绘 + `c1-2` turntable
   建一个**新的 Seedance 人物 entity**。entity 建好后，**每镜 prompt 不写文字五官**。
3. **道具与结构件**：`p1-1` 铁锹 / `p2-1` 随身装备 / `p3-1` 抹泥板 / `p3-2` 黏土壁炉 /
   `p4-1` 草皮门 / `p4-2` 挑檐层次 —— 六张，锁形制与使用痕迹。
   **落盘一律只用路由键命名**（`p3-1.png` / `p3-2.png` …），中文视图名住在卡里、不进文件名；
   导入按**键**匹配，不依赖中文部分（`ai_video.md` rule 4b-A）。
4. **出片**：每个 `shotNN.md` 内的 `## 视频 prompt` 代码块整段复制进 Seedance。
   比例 **16:9**，单条 18–27s。镜内允许切镜（`分镜:` 行写死了每段起止秒与切进来的方式）。
5. **无配音层**：本项目不生成 `台词配音 prompt`；成片音轨 = 环境音 +（可选）极简 BGM。
6. **字幕**：全片零字幕；平台标题与描述见 `5_6_分镜与prompt/publish.md`。

## 改东西的规矩

**prompt 与场景图文案都由生成器产出，改内容＝改生成器重跑，不手改 md**（`ai_video.md` rule 4i ①）：

```bash
python tools/gen_shots_hy3.py          # → shotlist.md + 14 × shotNN.md
python tools/gen_scene_prompts_hy3.py  # → 14 × bg*/bg*.md
python tools/build_all_shot_prompts.py "ai_videos/huangye_shenghuo/hy3/5_6_分镜与prompt"
python tools/prompt_light.py "ai_videos/huangye_shenghuo/hy3"   # 光源措辞扫描
```

`gen_shots_hy3.py` 自带三道硬闸，**不合格直接终止生成**：
**① 正向 prompt ≤5000 字**（逐镜计数）· **② 13 个接缝全部强档且两端机位不同** ·
**③ 共用风格串里不许点名具体光源**（光源只写在每镜的 `光线:` 里）。
