## 1. 他是谁

**年过六十，一辈子在砌炉子、盘灶、搭烟道。** 他不是来挑战荒野的，
他是**带着一门手艺走到了一个没有房子的地方**，于是用这门手艺给自己弄出一个今晚。

**为什么选他**：本片唯一的原理是「烟为什么会自己走」。
**让一个真的会这件事的人来做，整部片的可信度不需要任何解释**——
他不试错、不犹豫、不看说明书，他只是按顺序做。
**老手的重活是靠姿势和节奏省下来的，不是靠力气**（这是本片反差类①的拍法，见 `../style_guide.md` §7）。

## 2. 锁定描述符（本片 byte-identical，原样复制进每镜 `角色:` 行）

```
旧靛蓝粗布对襟上衣深棕灯芯绒长裤褐色毡帽，腰后别一把木柄旧抹泥板，六十余岁精瘦
```

**腰后那把抹泥板是他的识别符** —— 它在每一镜都在身上（哪怕不干砌活的镜），
**是「工具即人设」在本片的具体形式**：观众不用一句台词就知道他会砌东西。

## 3. 人物灵魂（`ai_video.md` rule 12.11 · 12 维）

| 维 | 内容 |
|---|---|
| **年龄** | 六十三 |
| **前史** | 十五岁跟师父学盘灶，此后四十多年在各处给人砌炉、修烟道。手艺是从手上学的，不是从书上 |
| **动机根因** | **他信「烟会自己走」这件事是有道理的**——一辈子靠这个道理吃饭，他要在一个什么都没有的地方再验证一次 |
| **目标（本片）** | 天黑之前，在这道坡里弄出一个**今晚能睡、而且不返烟**的屋 |
| **needs（他真正需要的）** | 证明那门手艺在没有任何现成材料的地方**依然成立** |
| **desire（他以为自己要的）** | 一个挡风的地方 |
| **矛盾** | 他知道最省事的做法（包里那把锯、坡脚那块平地），**但他两样都不用** |
| **恐惧** | 不是塌方，不是天黑 —— 是**烟往屋里返**。那会让他四十年的判断落空 |
| **创伤 + 致伤事件** | 早年砌过一个返烟的炉子，主人家一整个冬天把它当废物。**从那以后他下第一锹前一定先看土层剖面** |
| **此刻决策逻辑** | 先看，再算，再动。看土层 → 定掘多深 → 定支撑位置 → 才下第一锹。**顺序从不颠倒** |
| **性格** | 话本来就少（本片一句也没有）；动作慢但不停；**东西放回原处** |
| **成长轨迹（本片内）** | 无成长弧。**他一开始就会。** 全片唯一的变化是脏污与手上的裂口在增加 |

> **不做「他学会了」的励志弧**（`concept.md` §15）。他的技术在第一锹之前就已经完备，
> 这部片是**让观众看懂他会的那件事**，不是看他学会。

## 4. 他在本片里的三条硬规矩（系列圣经 §3）

1. **永远不看镜头** —— 视线越过镜头看向环境或手上的活。
2. **不磨皮、不美颜** —— 六十三岁的皮肤、手上的老裂口、指甲缝里的黑都要在。
3. **脏污只增不减** —— 一天之内单调递增：
   shot01 干净（只有旧衣物的磨损）→ shot05 手与裤腿一层干土 →
   shot06 **两只手连同小臂全是深赭黄湿黏土** → shot10 草屑与土混在一起 →
   shot12 洗过一次手但**指甲缝里还是黑的** → shot14 手背上一道新裂口。

## 6. 本片的一次「他是谁」的证明

**shot03，下第一锹之前：他先蹲下，用手把坡侧断面的浮土抹掉，看那三层土。**
看完才站起来，走到掘口位置，下第一锹。

**这一下就是全片对「他是个老手」的全部交代**——
新手是掘到塌了才补，老手是掘之前就知道哪一层会塌。
