## 1. 这是什么地方

**温带丘陵草原，秋末。** 一道朝南的土坡，坡面覆着厚草皮；坡顶是一片起伏的开阔草原。

**这里最要紧的一件事：没有一棵成材的树。**

草原上只有远处一条低矮的灌丛线。他能弄到的最粗的木料是**手臂粗的细杆**——
所以这个屋的跨度只能做到两米出头，**支撑必须立柱不能架长梁**。
**这不是限制，这是本片全部结构决策的来源**：为什么往坡里横掘（坡自己就是三面墙）、
为什么屋顶要靠草皮而不是木板（没有板材）、为什么烟囱要用石头（没有粗木做烟囱）。

### 地形四件

|---|---|---|
| **坡面**（朝南） | 一道约三米高、坡度四十度的土坡，覆厚草皮 | **屋掘在这里**（N1 机位正对掘口） |
| **坡脚浅沟** | 一道宽一米的浅沟，沟底草色更深、有水流过的痕迹 | **第 02 镜被否决的那个选项**——更平坦，但水从这里走 |

| **灌丛线** | 远处一条低矮灌丛，最粗的杆子只有手臂粗 | 木料唯一来源 |

## 3. 那道坡（本片的物理前提，写死）

| 项 | 数值 | 为什么 |
|---|---|---|
| 坡高 | 约 3m | 低于 3m 掘不出净高 1.5m 的屋顶覆土 |
| 坡度 | 约 40° | 再缓就要掘很深才进得去，再陡就会整体滑塌 |
| 掘口 | 宽 2.2m · 进深 2.6m · 净高 1.5m | 宽度受**手臂粗细杆**的跨度限制；净高保证**他能坐直** |
| 土层 | 腐殖层 25cm / 黄土层 1.6m / 砾石层 | 黄土层＝**黏土来源**；砾石层＝**扁石来源**；腐殖层＝**会塌的那一层** |
| 草皮 | 厚 8–10cm，根系密实 | 秋末含水低、切块不散，所以**能整块起下来当瓦用** |

**这道坡画错了这部片就没有理由存在**：坡画矮了，屋顶就没有覆土厚度；
土层画成均质一色，「为什么有黏土可用」「为什么会塌」两件事同时失去依据。
→ 负向块必带 `均质土墙 / 砖石砌墙 / 混凝土 / 整齐的方坑 / 挖掘机痕迹`。

## 4. 真实性铁律（违反即重做）

1. **没有成材的树。** 全片不许出现原木、板材、锯材、木桩。木料一律是**手臂粗的细杆**。
2. **草皮是切块的，不是铺的草。** 每块约 40×30cm，**断面能看见 8–10cm 的根土层**；
   草面朝上、块与块交错叠压。负向压 `整齐草坪 / 修剪过的草 / 草籽播种 / 土堆`。
3. **屋顶必须有防水层。** 草皮之下是**树皮/桦皮层**，不是直接压在椽子上——
   否则第一场雨就渗。这一层要在 shot10 的画面里看得见。
4. **黏土是湿的、深赭黄色，会粘在手上和抹泥板上。** 干透的黏土是浅灰黄——
   **两种颜色不许混用**：抹的时候湿、烧过之后才开始转浅。
5. **烟囱是石砌 + 黏土抹缝，高出屋脊两掌。** 不许出现砖、不许出现圆形陶管。
6. **火大半在炉膛里。** 本片视觉底线：**炉膛外只有炉口一小块橙光**，
   不许画成敞开的大火堆——画成大火堆，「烟为什么自己走」这个唯一的原理就废了。
7. **掉落物走真实重力**（`ai_video.md` rule 16 ①）：土块、草皮块、石板、黏土团一律
   越落越快、落地即停并溅起；负向带 `慢动作 / 落体滞空 / 羽毛般缓降`。
8. **干活的镜一律不背包**（rule 16 ②）：shot01 背着 → shot03 镜内卸下 → 此后不在身上。
9. **结构件成型即锁定**（rule 16 ③）：**绑扎串 / 支撑串 / 壁炉串 / 屋顶串 / 门串**
   各一条 byte-identical 描述，凡该节点入画的镜原样复现；成型之前的镜**反向声明「此时尚未…」**。
10. **他不看镜头**、不磨皮不美颜、**脏污只增不减**（系列圣经 §3）。

## 7. 无声叙事约定

全片无台词、无旁白、无配音、无字幕。**声音就是旁白。**

| 段 | 声音主轴 |
|---|---|
| 起 | 草原的风底噪最密（草叶互相刮擦）→ 脚步踩在草皮上的闷响 → **第一锹下土的钝响** |
| 承 | **动作音全面接管**：锹、斧、石、黏土、麻绳。**中段不铺 BGM** |
| 转 | **草声突然变了向**（天气将变的预告）→ 风 → 炉火的轻爆 → 雨打草皮顶的三层 |
| 合 | 声音退到只剩炉火与屋外远处的风 → 签名定帧处**可铺极简 BGM**，全片仅此一处与开场 |

**声音签名（本片唯一，全系列不重复）**：**土的钝响 + 草根被撕断的脆声**。
草根被撕断那一声只在**切草皮块**时出现（shot04 / shot10），它是这部片的听觉标记。

**一处三秒真空白**（`proposal.md` A §2c 第 4 条）：放在 **shot10 的 6–9s**，
天气预兆之前——草声、风声、他的动作声**全部停掉三秒**，然后风起。

**一条镜一条音床**：切分单位＝一个地点 ＋ 一个改造状态 ＝ 一条镜，镜内换段靠切镜、不接音。
