## 1. 这是什么地方

**一片无人的高草草原，被一条早已干涸的古河道切出一道垂直的黄土断崖。秋末。**

崖高约七米、崖面近乎垂直，**横贯画面并向左右双双出画**；崖线一路朝深处退去、
一道接一道被晨雾洗淡，**最远处完全消失在雾里——看不到这道崖的尽头**。
崖顶是齐人高的银白针茅草海；崖沿的草皮整片倒垂下来，形成一道半米长的干草根帘。

**这个地方的三个「为什么」：**

| 为什么 | 答案 |
|---|---|
| 为什么它好看 | **看不到尽头的崖线 + 逆光透亮的针茅草海 + 低斜光把每道竖向裂纹打出细长的影**。暖金（受光崖面与草海）与冷蓝（背光凹处）双色系 |
| 为什么它原始 | **垂直断面只有水和时间能造出来**；崖面上成群的崖燕废弃旧洞是画面里唯一的居住痕迹，**而它不是人的** |
| 为什么非它不可 | 垂直黄土断面 ＝ **横掘的唯一合理地形**；黄土 ＝ **最好的黏土**；五米厚黄土 ＝ **烟道高差**；崖顶草海 ＝ **草皮块来源**；崖脚古河床 ＝ **扁石来源**。**这道崖把本片要用的东西一次给全了** |

### 地形四件

| 位置 | 是什么 | 在片里干什么 |
|---|---|---|
| **崖面**（近乎垂直，高约七米） | 三层土一目了然；满是竖向干缩裂纹；中段有成群崖燕旧洞 | **屋横掘在崖面底部**（N1 机位正对掘口）；**那道贯穿的主裂纹是本片的对抗者** |
| **崖顶草海** | 齐人高的银白针茅，一直铺到天际线 | 草皮块来源 · 石烟囱立在这里 · 取食凹地 · 他走进来的那条小径 |
| **崖脚砾石滩** | 古河床留下的灰白与青灰扁石，半埋在枯草与地衣里 | 扁石来源 · 崖根黄土层取黏土 · **獾的洞口就在崖燕旧洞群的正下方** |
| **崖脚洼地** | 比周围低三十厘米、积水；崖面上有一道从崖顶下来的水痕 | **第 02 镜被否决的那个选项**——更平坦更背风，但水从这里走 |

**没有一棵成材的树。** 最远只有一条低矮灌丛线。他能弄到的最粗木料是**手臂粗的细杆**——
所以屋的跨度只能两米出头、支撑必须立柱、挑檐只能挑出八十厘米、烟囱必须用石头。

## 3. 那道崖（本片的物理前提，写死）

| 项 | 数值 | 为什么 |
|---|---|---|
| 崖高 | 约 **7m** | **人站崖下只到它的五分之一**——这是本片的尺度交代（对标 hy1 九十米红杉 / hy2 四米根盘） |
| 崖面 | **近乎垂直**，局部内凹成浅龛 | 垂直才能横掘；斜了就只是个坡 |
| 崖线 | 横贯出画、向深处一道接一道退去**消失在雾里** | **看不到尽头**——和 hy1「看不到树顶」是同一招 |
| 掘口 | 宽 2.2m · 进深 2.6m · 净高 1.5m，**开在黄土层里** | 宽度受手臂粗细杆限制；净高保证**他能坐直** |
| 土层 | 腐殖层 30cm / **黄土层 5m** / 古河床砾石层 1.5m | 黄土层＝掘口所在 + 黏土来源 + **烟道的五米高差**；砾石层＝扁石来源 |
| 裂纹 | 黄土层里**近乎垂直的干缩节理**，掘口上方有一道贯穿的主裂纹 | **本片的对抗者**：黄土真实的失效模式是**沿垂直节理整块剥落**，不是掉土屑 |
| 草皮 | 崖顶针茅，草皮厚 8–10cm、根系密实 | 秋末含水低、切块不散，所以**能整块起下来当瓦用** |

**这道崖画错了这部片就没有理由存在**：崖矮了尺度就没了；崖面画成斜坡横掘就不成立；
土层画成均质一色，「哪来的黏土」「为什么会塌」「五米高差」三件事同时失去依据。

## 4. 真实性铁律（违反即重做）

1. **这是黄土崖，不是岩石山崖。** 不许出现花岗岩、层积岩石壁、峡谷地貌。
2. **没有成材的树。** 全片不许出现原木、板材、锯材、木桩。木料一律**手臂粗的细杆**。
3. **崖面必须有竖向干缩裂纹，并且被低斜光打出细长的影。** 平滑无裂纹的崖面 ＝ 重做。
4. **草皮是切块的，不是铺的草。** 每块约 40×30cm，**断面能看见 8–10cm 的根土层**。
5. **挑檐必须有防水层。** 草皮之下是**树皮层**，不是直接压在悬臂杆上——否则雨顺崖面渗进屋。
6. **挑檐的草与崖顶倒垂的草根帘连成一片。** 这是本片的伪装，也是「房子不见了」的机制。
7. **黏土湿是深赭黄、干透是浅灰黄**，两种颜色不许混用。
8. **石烟囱立在崖顶草海里，屋在崖面下，两者之间是五米实土。** 这个高差是原理的全部理由。
9. **火大半在炉膛里。** 炉膛外只有炉口一小块橙光——画成大火堆，唯一的原理就废了。
10. **掉落物走真实重力**（rule 16 ①）；**干活的镜一律不背包**（rule 16 ②）；
    **七条结构件成型即锁定**（rule 16 ③：支撑 / 壁炉 / 烟囱 / 挑檐 / 门 / 小方口 / 床台）。
11. **他不看镜头**、不磨皮不美颜、**脏污只增不减**（系列圣经 §3）。

## 7. 无声叙事约定

全片无台词、无旁白、无配音、无字幕。**声音就是旁白。**

| 段 | 声音主轴 |
|---|---|
| 起 | **齐人高针茅在风里整片的「沙——」**（本片的底色，而且**没有混响**）→ 脚步压倒草茎 → **第一锹下土的钝响** |
| 承 | **动作音全面接管**：锹切黄土的闷响、**斧切断草根的脆声**、扁石相扣、黏土被抹开的黏腻、麻绳绕紧、火柴 |
| 转 | **三秒真空白** → 风起、草海换向 → 草皮压上挑檐的沉闷 → **顶杆抵墙一声闷响，外面风声降一档** → 雨打草皮（**闷**） |
| 合 | 只剩炉火与远处的风 → 签名定帧处**可铺极简 BGM**，全片仅此一处与开场 |

**声音签名（本片唯一，全系列不重复）**：**土的钝响 + 草根被撕断的脆声**。
草根被撕断那一声只在**切草皮块**时出现（shot04 / shot10），它是这部片的听觉标记。
**针茅草海整片的「沙——」是底色**，不是签名——它从第一秒响到最后一秒。

**一处三秒真空白**：**shot10 的 6–9s**，天气预兆之前——草声、风声、动作声全停三秒，然后风起。

**一条镜一条音床**：切分单位＝一个地点 ＋ 一个改造状态 ＝ 一条镜，镜内换段靠切镜、不接音。
