# 草皮门与屋顶 · p4（完成度第 1 件 ＋ 本片的构造特征）

## 定位

**门是「安全感」的全部载体；屋顶是「从外面看不见房子」这个构造特征的全部载体。**

两件都用同一种材料——**切块的草皮**，因为这道坡上没有别的东西可用
（`../world.md` §1：没有一棵成材的树）。

**草皮块的做法（本片的真实性铁律之一）**：每块约 40×30cm、厚 8–10cm，
**用短柄斧顺着草根切下来，断面能看见上层枯黄草叶与下层深褐根土两层**；
草面朝上、块与块**交错叠压**。秋末的草含水低、根系结实，所以**能整块起下来当瓦用**。

> **切草根那一声是本片的声音签名**（`../style_guide.md` §10）：
> 土的钝响 + **草根被撕断的脆声** —— 只在 `shot04` 与 `shot10` 出现。

---

## 1. 屋顶 · 锁定描述符（成型后跨镜 byte-identical）

```
屋顶＝掘口外沿横架三根手臂粗的细杆作椽、椽上顺坡满铺一层整片的深褐树皮作防水层、树皮之上压两层交错叠压的草皮块、草面朝上并与周围坡面的草连成一片，屋脊沿线压着一排拳头大的灰白扁石，屋顶单坡自坡面向外倾斜、整体低矮贴地
```

**防水层必须看得见**（铁律 3）：草皮之下是**树皮层**，不是直接压在椽子上——
否则第一场雨就渗。这一层在 `shot10` 的画面里要露出边缘。

## 2. 草皮门 · 锁定描述符（成型后跨镜 byte-identical）

```
草皮门＝三根细杆扎成的方框上绑满草皮块、外侧草面朝外与坡面同色、内侧露出深褐根土与麻绳的十字绑扎，门高约一米三宽约七十厘米，靠一根穿过上下横杆的木轴立在掘口右缘，门内侧横着一根可抵在土墙上的顶杆
```

**内侧那根顶杆是「抵御得了大风」的全部形式**（`proposal.md` A §2 轴 I 附则）：
门不是挡上，是**能从里面顶死**。`shot13` 要拍到他把顶杆压上去的那一下。

## 3. 采光/排烟小方口 · 锁定描述符

```
门上方土墙上一个约二十厘米见方的小方口，四边用细杆压边、边缘抹了一圈黏土，从屋内看出去正对草原起伏的那道天际线
```

**他特意把它开在能看见草原起伏的那个方向**（`proposal.md` A §2f 第 5 条：
**为看风景开的窗**）——奇观镜因此有了存在的理由：不是导演要给，是他想看。
`shot13` 里这个口**塞了一把干草只留一条缝**（安全感拍法第 3 条）。

---

## 4. 成型时序（生成器 `roof` / `door` 字段强制 · rule 16 ③）

| 阶段 | 镜 | 声明 |
|---|---|---|
| **都不存在** | `shot01`–`shot06` | **掘口外沿完全敞着、头顶是天** —— 画面里不存在椽子、树皮层、草皮顶、门板、方口；负向带 `掘口有顶 / 草皮屋顶 / 椽子 / 树皮层 / 屋脊压石 / 掘口有门` |
| **门与方口做好、顶还没盖** | `shot07` 起 | 门已挂上木轴并能开合、方口已压边抹好；**屋顶仍不存在**（负向仍带屋顶词） |
| **屋顶盖好（锁定）** | `shot10` 起 | 按屋顶锁定描述符原样复现，此后不再变 |
| **门顶死** | `shot13` 起 | 顶杆抵在土墙上，方口塞了干草只留一条缝 |

> **注意这个顺序和 hy2 是反的**：hy2 先封顶再装门；hy3 **先装门再封顶**。
> 理由是真实施工顺序——**门框要先立好，屋顶的椽子才有地方搭在门框上沿**。
> 这也让 `shot07`（完成度①：门 + 采光口）能独立成镜，不和封顶抢戏。
