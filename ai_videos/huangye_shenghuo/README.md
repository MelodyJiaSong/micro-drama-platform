## Vision（观众体验）

> **跟着一个人走进一片没人来过的原始荒野，看他用一天亲手造出一个家：夜里风雨在外面，屋里火光干燥安稳，像自己也住了进去。**

核心：一个人和一片原始荒野，在一天之内达成一份协议——读懂这片地方、就地取材，造出一个结实、像样、能安心睡着的家；每一步都看得懂、站得住。

## 这是什么

Julian，一个四十岁左右、儒雅沉稳的中美混血男子，走进一片原始荒野（雨林、红杉林、草崖、深雪、礁岛……），只带少量工具，用一天时间抢在天黑和坏天气之前给自己造出一个家，夜里风雨来了，他在里面睡着。全程无人声：没有台词、没有旁白，声音就是旁白。每集换一个地方、换一栋房子，人还是 Julian；集与集之间没有连续剧情。

标题公式：`Wild Living · First Night in the {地方}`（中文 `荒野生活 · {地方}第一夜`）。平台标题和简介可以加 hidden、secret、cozy 这类词；中文平台标题可以按 B 站公式写出画面里不说的东西（谁、造出什么、结果），但写的必须兑现（`0_research/parts/h01_同类视频怎么拍.md` §5 #6、#18）。系列要拍到二十集以上（用户 2026-09-12）。
