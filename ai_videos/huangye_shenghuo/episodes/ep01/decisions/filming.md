# EP01 影视改编决策记录

Vision：分镜让观众「跟着一个人走进原始荒野、看他一天造出一个家、夜里风雨在外而屋里安稳」——开场一闪先给回报（场一），T1 大景与板根尺度给「原始荒野」，按工序的状态镜与三次 N1 对比帧给「看着它长出来」，场八的关门、仰望干屋顶、开门看洪水、睡着给「安稳、像住进去」。
依据：故事稿 v3（`story.md`）与故事决策记录（地形与房子、逐时工作表、站位与视线）；`bible.md` §3 单集骨架、§5 镜头模板 T1–T14、§6 质量底线；共用指南 1.2 影视改编（`filming.md`「给剪辑留出进出与余量」「镜组只用在连贯比剪辑选择更重要的地方」）、连续剧片种（`filming-series.md`：EP1 定风格）。

## 为什么这样分

- **场的边界 = 地点 + 时段**：溪谷清晨、阶地清晨、林隙上午、阶地搭建、潭尾午后、阶地傍晚、屋里夜；每场开头一镜交代到了哪（`filming.md`「给剪辑留出进出与余量」）。
- **一律单拍，不分镜组**：本集几乎每镜都有手部动作、道具或工序（易出物理错误），按共用规则一律单拍；每镜一张首帧图钉住开场，再拼成场故事板。
- **N1 对比帧**：s3 st6、s5 st4、s7 st7 同一机位同一取景（N1：角落正西约六米、镜头离地约一米、35mm），分别挂 bg3、bg3-1、bg3-2；s8 st8 屋外透光也用 N1（bg3-3），观众第四次看到同一个角落时，它在雨夜里只剩一线光。
- **场一 = s8 st5**：两镜同一个画面（机位、取景、光），成品一闪必须兑现（bible T12）。
- **无对白**：全集 dialogue 为空；声音设计写在 action / beats（翅膀声、拍水声、雨声降档、溪声变沉、远处闷雷），编译器给每镜加「本镜没有人说话」。

## 开场钩子与集尾

- 开场钩子：s1 成品一闪（4 秒）→ s2 st1 延时云（钟，第 5–9 秒）。
- 集尾：s8 st7 他睡着 → st8 屋外透光 → st9 签名定帧，从对岸往后退。

## 跨集连续性（EP1 定风格）

- 风格：真实野外纪录片质感，自然光；林下偏绿、无强对比；夜里只有火光与树脂灯。
- 常用：全景交代人与环境的尺度，近景 / 特写只给手和工序（bible §5 T3、T4）；人物不看镜头。
- EP1 定稿后把光、色、常用景别写进剧级风格说明（`filming-series.md`）。

## 空间一致性审稿 r1 处理（2026-11-14，follow-up 023）

用户 2026-11-14：「空间大小的正确性非常重要……门口的小溪离房子多近？下雨后能变成多大？这些都要一致性检查……做饭的场景可以加一点……把房子内部做的惬意一点」。

1. **Blender 白模**：按锁定表搭地形、溪（平水 / 洪水）、板根、平台、屋顶、门、灶、床与 1.78 米人偶，渲染外景、屋内、剖面、门口主观视角，存 `2_世界观人设/background/borneo_ep01/_blockout/`（`hut_blockout.blend`）。之后出图都拿它当尺度参考。
