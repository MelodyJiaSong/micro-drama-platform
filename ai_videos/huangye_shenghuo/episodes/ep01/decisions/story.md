# EP01 故事决策记录

本集体验：跟着 Julian 走进一片没人来过的婆罗洲雨林，看着一座搭在锚点树树干西边的高脚小屋从落叶里一点点长出来；黄昏的暴雨把早上对岸那片诱人的砾石滩整个淹掉，他在干燥的火光里吃上一口热饭、安心睡着，像自己也住了进去。
Vision：全剧 Vision 是「跟着一个人走进一片没人来过的原始荒野，看他用一天亲手造出一个家：夜里风雨在外面，屋里火光干燥安稳，像自己也住了进去」。板根、巨树与光柱给「原始荒野」；取材到封顶给「一天亲手造出一个家」；水帘、一滴不漏、淹掉的砾石滩给「风雨在外面、屋里干燥安稳」；竹筒饭、树脂灯与他睡着给「像自己也住了进去」。核心「读懂这片地方、就地取材，造出结实、像样、能安心睡着的家」落在看得见的事上：漂积线与泥痕、躲开最高的树（读懂）；现割的藤、只取成熟叶、倒树的柴与树皮（就地取材）；浇水测试与暴雨中一滴不漏（结实）；他睡着（安心）。
被放弃的方案里与 Vision 冲突的：①考据候选 B「不靠大树的岩台」——没有只属于这一集的构造特征，削弱「原始荒野」的奇观（v2 改选「更高的树中间一棵中等高的板根树」，同时解决雷击问题）；②开场先给工序教学——那是教程，`bible.md` §1 说本系列「不是教程」；③让暴雨掀起一角屋顶、他冒雨抢修——对抗者变成「已建成的结构失效」（`bible.md` §4.4），把安全感当场卖掉。

## 六个问题

| 问题 | 答 |
|---|---|
| 关于谁 | Julian，一个四十岁左右、儒雅寡言的野外老手 |
| 想要什么 | 天黑和暴雨来之前，造出一个能挡雨、能生火做饭、能安心睡着的家（全剧主目标的本集版本） |
| 为什么得不到 | 时间：上午上游的云已经在翻滚，下午四点雨就到；这片地方不告诉你答案——哪里会被淹、哪棵树会招雷掉枝、哪种叶子不漏；他手里只有背包里的七样和一把砍刀 |
| 怎么办 | 先读：看漂积线和泥痕、躲开最高的树、推板根看树冠；就地取：倒树的杆与柴、现割的藤、成熟的扇叶、树脂、枯棕纤维；按原理造：陡坡叠瓦、浇水自测；先封顶，再取食、做灶 |
| 为什么没成（阻碍与代价） | 本系列的「没成」不是结构失败（`bible.md` §4.4）。代价是时间与体力：中午云塔已经发灰，他满身汗、裤脚是泥；雨比饭先到，他淋湿了才跨上平台生火 |
| 怎样结束 | 暴雨里门一关，屋里一滴不漏；他拉开门看见早上那片诱人的砾石滩已经淹在褐色洪水下，他早上的选择被证明是对的；他吃了一口热饭，睡着了。结局来自他一开始就做的预防，不是运气 |
