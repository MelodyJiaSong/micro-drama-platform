# 全片段落结构 ·《荒野生活 · 雨林第一夜》

> **单片，无分集。12 个 shot 拼接成一条成片，合计 275s（4:35）**，平均 22.9s。
> **全片零承接、全部硬切** —— 没有首末帧交接链，每一镜独立生成、独立重跑。
> **单镜 15–30s，镜内允许切镜**（follow-up 002）。切分单位＝**一个地点 ＋ 一个建造状态 ＝ 一条镜**。
> 生成器 `MIN_D=15 / MAX_D=30` 做生成时校验；每镜的 `分镜:` 行写死内部各段的起止秒与切进来的方式。
> 上游：`1_立项/concept.md` · `2_世界观人设/`。下游：`5_6_分镜与prompt/shotlist.md`。
> **逐镜表在 `shotlist.md`，本文件不复述**（rule 4i ①：一份东西只有一个出处，副本必漂）。
> 本文件只管**段落层**：结构、合并决策、露脸分布、覆盖核对、贯穿检查、声音。

## 为什么是 12 镜（第三轮合并 · follow-up 002）

三轮：初稿 40 镜 → **33 镜 / 238s** → **25 镜 / 245s**（消灭 4–6s 碎镜）→ **12 镜 / 275s**。

**这一轮的关键裁定（用户 2026-09-08）：一个视频里切换镜头是 OK 的。** 第二轮时我把合并
限制在「一镜到底的连续运镜」，因此有 7 镜并不了、只能补 beat 撑到 7s。这一轮取消了那条限制，
合并单位随之改成——

> **一个地点 ＋ 一个建造状态 ＝ 一条镜。**

理由与代价各一条，两边都要认：
- **收益**：生成器按镜生成，**一条镜的环境音 / BGM 是整段统一的**。一个地点一条镜，音床天然一致，
  剪辑台上不必再接；同时镜数从 25 降到 12，出片轮次减半。
- **代价**：**一条 27s 的镜里任何一拍崩了，整条 27s 都要重跑**，好的几拍一起赔进去。
  所以不无限往上并——落在 **15–27s**，并把 hero 段（`shot11` 的情绪最高点、`shot12` 的签名定帧）
  排在各自镜的**片尾**，坏了只重跑那一条、前面的证明段还能单独取用。

### 新增的一镜：骨架怎么搭出来的（`shot04`）

原来的镜表里，画面从「架第一根椽子」直接跳到「十一根成型」——**骨架是凭空出现的**。
`shot04` 用四段把中间那一步补上，每一段各答一个问题：

| 段 | 答什么 |
|---|---|
| 0–6s 架第一根 · 搭上倒木 · 踩实入土 | 一根椽子是怎么立住的 |
| 6–11s 用小臂比着量间距 · 立起第二根 | **间距靠什么定**（不是估的，是量的） |
| 11–15s 贴地 · 杆脚削尖插进湿泥 · 一脚踩实，泥翻起来包住它 | **它为什么不倒**（受力有出处） |
| 15–25s 一根接一根往上架 → 十一根成型 → 对比帧 #2 | **它是一根一根长出来的**（动作同一套、落点一格一格向画右推进） |

## 三条实拍纪律（follow-up 001 · 生成器强制注入，不靠人记）

| # | 纪律 | 落法 |
|---|---|---|
| 1 | **干活的镜一律不背包** | 背包只出现在 `shot01`（他还在赶路）；`shot02` 的 9–11.5s **镜内把包卸在倒木根部**；此后每一镜的 `走位:` 都带"背包不在身上"，负向块带 `登山包背在身上 / 干活时背着背包`。生成器 `bag` 字段控制，无法漏写 |
| 2 | **掉落物走真实重力** | 断枝、整片棕榈叶、木片、木屑、泥块、水珠一律"越落越快、落地即停并溅起"，负向块带 `慢动作 / 落体滞空 / 羽毛般缓降 / 掉落物匀速下落`。生成器 `fall` 字段控制，命中 8 镜 |
| 3 | **绳结前后一致，扎完不许消失** | 捆绑在 `shot05` 成型后即锁定为一条 byte-identical 描述串（三圈十字 / 顺时针 / 结头在交点右下 / 两端各留八厘米余头 / 木头上一道浅压痕），此后每一镜的 `场景:` 行原样再贴一次；`shot04` 反向声明"**此时尚未捆绑**"。负向块带 `绳结消失 / 捆绑处空着 / 结头位置改变`。生成器 `lash` 字段控制 |

## 露脸分布（12 镜里 9 镜给到脸）

**脸的一致性由用户建立的 Seedance 人物 entity 承载**，不再靠遮脸回避漂移；
shot prompt 也**一律不写文字五官**（写了会和 entity 打架）。详见 `2_世界观人设/style_guide.md` §6。

| 类型 | 镜 |
|---|---|
| **认人镜**（脸给得最完整） | `shot02` 转身环视 + 仰头（0–14s 段） |
| **正面** | `shot05` 喝水（仰头脸全开）· `shot08` 对比帧#3（**转过身来**，唯一一次「我做完了」） |
| **侧脸 / 四分之三** | `shot02` 抓土 · `shot03` 砍杆 · `shot04` 骨架成型末段 · `shot05` · **`shot11` 内视（火光打亮侧脸，全片最好的一张脸）** · `shot12` 火边 |
| **仰视** | `shot07` 压实屋顶 · `shot09` 抬头看被掀起的叶角 |
| **末段显现** | `shot01` 走近后脸变清晰 |

其余 3 镜（`shot06` / `shot10` 的大部分 / 无人的段落）是手部微距、材质特写、纯空镜或极远景——
**那些段里本来就不该有脸**。

## 声音结构（无人声，声音就是旁白）

| 段 | 声音主轴 |
|---|---|
| **起** | 蝉鸣与虫声最密 → 脚步与落叶 → 卸包时肩带与织物的摩擦（`shot02`）→ **抽刀的金属摩擦**，全片第一个真正的人造声音 |
| **承** | **动作音全面接管**：劈砍、木屑、树倒、木碰木、藤条收紧、叶片砸地、挖土。**中段不铺 BGM**，把耳朵让给工具与材料。**一条镜一条音床**——12 条镜就是 12 段完整的环境音，剪辑台上不必再接 |
| **转** | **虫声突然变静**（`shot09` 起，雨前最有效的紧张手段）→ 犀鸟振翅 → 风 → 火的轻爆 → **雨的三层**：树冠高频细密 / 叶顶低频闷响 / 檐下点状滴落 |
| **合** | 雨渐弱 → 只剩檐下滴水与火的低频 → 另一套夜虫声起 → 签名定帧处**可铺极简 BGM**（全片仅此一处与开场） |

> **雨必须分三层铺。**「屋内 vs 屋外」这个核心卖点有一半是靠声音成立的，画面只做了另一半。
