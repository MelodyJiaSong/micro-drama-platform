# 风格指南 · 《荒野生活 · 雨林第一夜》

> 所有 shot 的 `光线/色调:` `渲染样式:` `负面词:` 三行都从本文件取值并 **byte-identical 复制**。
> 颜色一律用**自然中文色名，零 hex**（rule 1b）。画幅 **16:9**（per-project divergence）。
> 本片＝一部约四分钟的独立短片，多个 shot 拼接成一条成片。本文件的锁定串同样可供系列后续短片复用。

## 1. 影像基调（一句话锁定 · 复制到每个 shot 的 `渲染样式:`）

```
自然纪实影像，真实自然光，浅景深长焦与广角混用，高湿度空气感，冷绿环境与暖橙火光强色温对比，颗粒细腻，无风格化滤镜
```

## 2. 调色

| 层 | 色名 | 说明 |
|---|---|---|
| 环境主色 | **苔绿 / 墨绿 / 青灰** | 树冠、蕨类、湿岩。整体偏冷。 |
| 环境辅色 | **赭红 / 湿褐** | 红泥地面、湿木、板根。给冷绿垫一层暖底，避免全片发青。 |
| 高光 | **乳白雾光** | 透过树冠的天光与晨雾，永远是柔的、有体积的。 |
| 火与室内 | **暖橙 / 琥珀** | 唯一的暖源。**必须比环境亮 2 档、暖 2 档**，对比不够就等于没有这个卖点。 |
| 夜 | **近纯黑 + 一点暖橙** | 火光之外压到接近纯黑，不提黑位、不补光。 |

**冷暖对比是本片的签名**：任何同时出现"棚内"与"棚外"的镜头，**画面里必须同时看得见冷绿与暖橙**，交界线要清楚（屋檐线 / 门口 / 火光边缘）。

## 6. 露脸约定（2026-09-06 定调 · **推翻原「遮脸约定」**）

**脸要看得见。** 人脸一致性由用户建立的 **Seedance 人物 entity** 承载（机制与场景主体同构：
entity 存 description + 参考图，shot 只引用不重描），所以**不再靠遮脸来回避漂移**。

**shot prompt 一律不写文字五官**（眉/眼/鼻/唇/轮廓）——写了会和 entity 打架。

### 露脸分布（12 镜里 9 镜给到脸）

| 类型 | 镜 | 怎么给 |
|---|---|---|
| **认人镜** | `shot02` 0–14s | 转身环视 + 仰头，**脸给得最完整的一次**。全片的「介绍这个人」 |
| **正面** | `shot05` 末段喝水（仰头，脸完全打开）· `shot08` 19–26s 对比帧#3（**转过身来**，唯一一次「我做完了」） | 脸完整可见 |
| **侧脸 / 四分之三** | `shot02` 抓土 · `shot03` 砍杆 · `shot04` 骨架成型末段 · `shot05` 喝水前 · `shot11` 末段内视（**火光打亮侧脸**，全片最好的一张脸）· `shot12` 火边 | 侧脸与下颌线清晰 |
| **仰视** | `shot07` 12–20s 压实屋顶 · `shot09` 14–22s 抬头看被掀起的叶角 | 仰角下脸完整可见 |
| **末段显现** | `shot01` 14–19s 从深处走近，走到近前脸清晰 | 由虚到实 |

**其余 3 镜（以及各镜里的手部/空镜段落）不给脸不是在躲**——它们本来就是手部微距、材质特写、纯空镜或极远景，
那些镜里本来就不该有脸。

### 三条硬规矩

1. **永远不看镜头。** 视线越过镜头看向环境或手上的活。这是纪实感的底线。
2. **不磨皮、不美颜。** 三十五岁、常年日晒、有毛孔细纹与胡茬。负向块专门防这个。
3. **脏污只增不减。** 出场干净 → `shot05` 末段起额角一道泥印 → 雨后衣服半湿贴身。
   脏污写进 shot 的 `角色:` 行作为状态补充，**不改 entity description**。

## 7. 音轨约定（无人声）

- **无台词、无旁白、无 TTS、无字幕**。shot 不写 `台词:`，不生成 `## 台词配音 prompt`。
- 成片音轨 = **环境音为主**（刀声 / 雨声 / 火声 / 鸟声 / 风声 / 脚步与树叶摩擦）+ 可选极简 BGM，后期铺。
- 生成阶段：视频 prompt 里**不要求模型出声**，声音全部后期处理。

## 8. 画幅与时长

- 画幅：**16:9**（全片，含所有参考图与 turntable）。
- 单镜时长：**15–30s，镜内允许切镜**。切分单位＝**一个地点 ＋ 一个建造状态 ＝ 一条镜**（实际落在 20–27s）——生成器按镜生成，一条镜的环境音/BGM 是整段统一的，一条镜一条音床，剪辑台上不必再接；上限压在 27s 以内，是因为一条镜里任何一拍崩了整条都要重跑。
- **全片总时长：275s**，由 **12 个 shot** 拼接而成（平均 22.9s）。**镜与镜之间零承接、全部硬切**——合并镜次时顺手消掉了首末帧交接这一整类失败点；**镜内的切镜不是承接**，同一时刻、同一条音床。
