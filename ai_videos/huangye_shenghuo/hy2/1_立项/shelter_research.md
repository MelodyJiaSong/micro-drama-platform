3. **Cyprien 那条 280M 是全场唯一「非奇观也非真人解说」的超级爆款**，

   它证明：**土 + 火 + 一个像样的房间**，不靠泳池也能到三亿。

## 三、时长这一项要如实说

**证据里的赢家几乎全是 15–40 分钟的长片**，我们要做的是 **4 分半**。这是一个真实的差距，
不能假装数据支持我们的格式。两条对冲证据：

- `Wild Bush Drive Turbo` 把自己那条 39 分钟的树桩屋剪成 **6 分钟快版，拿到 13.8M**——
  说明**短版本在这个品类里立得住**，它是同一内容的另一个产品。
- 我们本来就不是要复刻长片的信息量，而是要**四分半里给足奇观 + 一个原理 + 一次情绪反差**。

**结论：短片不是问题，但它必须更狠地取舍**——只保留一个能看懂的原理，别贪三个。

## 四、给 hy2 的结论

**保留红杉林，换掉住所形态：从「树洞」改成「倒下的巨型红杉根盘下的地窝」。**

理由四条：

1. **它解决尺寸问题。** 红杉倒伏时连根掀起的**根盘（root plate）高达四到六米**，
   立起来就是一堵现成的墙；根盘拔出的坑（pit-and-mound）本身就是个房间大小的洞。
   挖深、垒边、封顶之后，**2.5×3.5 米，床、火塘、储物都摆得下**。
2. **它是实测最稳的形态。** Polissya Bushcraft 整条频道就是「树根下的隐蔽地窝」，
   34.3M / 22.9M / 13.4M / 9.6M / 8.7M / 7.0M / 4.9M——不是一条爆款，是一个可复制的格式。
3. **它对 AI 生成最友好。** 土、根、石、黏土、草皮——全是有机材质，
   **没有一样需要跨镜数数或对齐榫口**（原木屋和泳池隧道都要）。
4. **它保住了原来的立意。** 「树是盟友」不但没丢，还更实在了：
   **不是一棵活树给了他一个洞，而是一棵倒下的巨树，用自己的根替他挡住了风。**

### 顺带保住的东西

| 原设计 | 在新方案里 |
|---|---|
| 红杉尺度奇观（看不到顶） | **保留**，而且更强：根盘立面比人高三倍，倒木本体横贯画面 |
| 洞内仰拍收进雾 | 改成**从坑里仰拍**：根盘边缘 → 倒木躯干 → 更高处的活红杉 → 雾 |
| 屋内暖 vs 屋外横雨 | **保留并强化**——半地下 + 草皮顶 + 黏土壁炉，反差比树洞更大 |
| 火在活树里怎么烧（黑科技） | 换成**黏土壁炉 + 排烟道**（Vadim 那条 43.3M 的核心看点），仍是一个能看懂的原理 |
| 香蕉蛞蝓 / 内壁旧刻痕 | **保留**，刻痕改刻在根盘的老木上 |
| 三次同机位对比帧 | **保留**（坑口正前方 N1） |

### 需要放弃的

- 「空心红杉 goosepen」这个**冷知识本身**很迷人，但它是**一个奇观镜的料，不是一部片的房子**。
  建议**降级成 hy2 里的一个路过镜**（他先看见一棵活着的空心红杉、进去看了一眼、
  **发现太窄摆不下床，退出来**），既保住这个知识点，又顺手给了「他为什么选了根盘」的动机。

## 六、局限

- 样本是**搜索排序前列**，不是随机抽样；YouTube 的排序本身带偏。
- 赞率受频道体量与受众地区影响，跨频道横比只能当量级判断。
- **所有赢家都是真人实拍**；AIGC 版本在这个品类里还没有可比样本——
  这既是风险（观众可能不认），也是空位（这个品类还没被 AI 占）。
