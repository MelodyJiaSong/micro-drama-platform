# 全片段落结构 ·《荒野生活 · 红杉第一夜》

> **单片，无分集。12 个 shot 拼接成一条成片，合计 283s（4:43）**，平均 23.6s。
> **镜与镜之间零承接、全部硬切**；**单镜 15–30s，镜内允许切镜**（切分单位＝一个地点 ＋ 一个改造状态 ＝ 一条镜）。

> **逐镜表在 `shotlist.md`，本文件不复述**（rule 4i ①）。
> 跨片不变量（那个人 / 声音 / 签名收尾 / 三条实拍纪律）见 `_series/series_bible.md`。

## 只讲一个原理（调研结论落地）

`shelter_research.md` §三的结论：**实测赢家几乎全是 15–40 分钟长片，而我们做四分半——
短版必须更狠地取舍，只留一个能看懂的原理。**

> **烟道从床下走：火塘的烟不往上，它先从睡觉的那片地底下钻过去，绕一圈，再从根盘背面出去。**

| 环节 | 镜 | 画面上怎么成立 |
|---|---|---|
| **教** | `shot05` | 沟被挖出来时是**敞开**的，从上方一眼看清全走向；剖视给宽深与**上升坡度**；根盘背面开出**出烟口** |
| **藏** | `shot06` | 石板一片压一片盖住，黏土封缝抹平，铺上干蕨叶——**沟从此再也看不见** |
| **验 ①** | `shot10` 末段 | 生火后**烟不往上走**，被吸进床底；切到坑外，**根盘背面稳定冒出一股白烟** |
| **验 ②** | `shot11` 中段 | **湿透的外衣摊在床面上，白汽升起来了** —— 床是热的 |

**两个验证都是可拍的物理现象，不需要一个字解释。**
其余诱人的原理（防返潮的三层地面、黏土壁炉的抽力）一律不讲——四分半装不下。

## 四条实拍纪律（生成器强制注入，不靠人记）

| # | 纪律 | 落法 |
|---|---|---|
| 1 | **干活的镜一律不背包** | `shot01`/`shot02` 背着 → `shot03` 的 2–5s **镜内卸在根盘底部** → 此后每镜 `走位:` 带「背包不在身上」。生成器 `bag` 字段 |
| 2 | **掉落物走真实重力** | 土块、断根、石板、整片树皮、草皮、水珠、炭屑一律「越落越快、落地即停并溅起」。生成器 `fall` 字段，命中 10 镜 |
| 3 | **顶与门四阶段锁定** | 不存在（`shot01`–`shot06`，**反向声明**）→ 封顶（`shot07`）→ 门斜靠（`shot08`）→ 门扣上并锁定（`shot09` 起）。生成器 `door` 字段 |
| 4 | **床台成型即锁定** | `shot06` 之后每镜 `场景:` 行原样复现同一条 byte-identical 串；此前反向声明「坑底还没有床台」。生成器 `bed` 字段 |

**外加一条视觉底线**：**火大半被压在床下**，坑内只有火塘口一小块直接的橙光，
其余是从石缝渗出的微弱暖光。**画成敞开的大火堆，「能烧的暖床」这个唯一的原理就废了**——
每个有火的镜负向都带 `敞开的大火堆 / 明火直接烧在床面上 / 火焰照亮整个坑`。

## 贯穿检查表（改任何一镜，前后都对一遍）

| # | 项 | 落点 |
|---|---|---|
| 1 | **同机位对比帧三次** | `shot02` 16–24s（`bg5-1` 原始的坑）/ `shot06` 18–22s（`bg8-1` 床台成型）/ `shot08` 18–24s（`bg9-1` 完全建成）——全部 **N1 机位**，逐帧同位 |
| 2 | **N1 机位一共出现七次** | 上面三次 + `shot05` 末段（开出烟口）+ `shot07` 末段（封顶）+ `shot09`（风暴前）+ `shot10` 末段（风暴夜验烟）。**同一个位置看着这个坑变了七次** |
| 3 | **根盘必须高约四米** | 每镜 `场景:` 行都带；负向带 `矮土坡 / 根盘低于人身高 / 树桩`。**画矮了这部片就没有理由存在** |
| 4 | **不砍活树** | 木料只来自那棵倒木与地上的枯枝；`shot07` 剥皮那根**必须是横躺着的** |
| 5 | **材料就在现场** | 石板从根盘的土里拔出（`shot03`）· 树皮从同一棵倒木上剥（`shot07`）· 黏土从坑壁挖（`shot06`）。**他只离开这个坑一次，而那也是同一棵树** |
| 6 | **成果被"用"到** | 根盘挡风（`shot09`）· 烟道抽烟（`shot10` 末段）· 床是热的（`shot11` 白汽）· 门挡横雨（`shot11`）· 顶让坑内是干的（`shot11`/`shot12`） |
| 7 | **只给一次的两样** | 香蕉蛞蝓（`shot03` 11–15s）/ 坑底的旧炭（`shot04` 7–10s，约两秒，**不推镜、不对焦、不给反应镜**） |
| 8 | **全片只有一个人** | 12 镜全部；负向锁定块前 5 项每镜原样带 |
| 9 | **脸：9 镜给到，且永远不看镜头** | 见上方露脸分布表 |
| 10 | **时长** | **283s**（起 47 + 承 140 + 转 69 + 合 27）；单镜 **15–30s**，最短 21s、最长 27s |
| 11 | **过程镜的参考图是终态** | `bg6` / `bg7` / `bg8` 的参考图是**该状态的终点**；`shot04` / `shot05` / `shot06` 是**通向它的过程**，靠 `参考用法` 里一句话说清 |
| 12 | **与 hy1 的四格差异** | 动词（往下挖 vs 往上搭）· 对抗者（风暴与潮湿，倒下的树是盟友）· 黑科技（烟道从床下走）· 奇观（坑底仰拍：根盘 → 倒木 → 活树 → 雾）。**天气预兆不重复**：hy1 鸟飞走 → hy2 雾反转 |

## 声音结构（无人声，声音就是旁白）

| 段 | 声音主轴 |
|---|---|
| **起** | **极低底噪 + 长混响**（雨林是满的，红杉林是空的）→ 雾里滴下的水珠 → 踩厚落叶层的闷响 → **进树洞后声音突然变干、混响消失**（空间一下子从九十米变成一米） |
| **承** | **铁刃切进湿土的闷响**（主音）→ 土块甩出去落地 → **石板与石板相扣的清脆** → **黏土被手掌抹开的黏腻声** → 树皮纤维被撕开的长裂声 → 草皮落下时土簌簌掉。**中段不铺 BGM** |
| **转** | 环境音**突然变静** → 风穿过树干列柱的低频呜咽 → **门板扣上的一声闷响**（全片最重要的声音节点：外面被关在外面了）→ 镁棒两下刮擦 → **火在床下的闷烧声**（听得见火、看不见火）→ 横雨打在门板外侧 |
| **合** | 雨渐弱 → 只剩床下的闷烧与缝外滴水 → 湿衣服上水汽蒸腾的细响 → 签名定帧处**可铺极简 BGM**，全片仅此一处与开场 |

> **本片最特别的一条听感设计：火被埋在床下，所以火声是「闷」的。**
> hy1 的火是敞开的、噼啪清脆；hy2 的火隔着石板与黏土，只剩低频的呼呼声与偶尔一下被闷住的爆响。
> **听觉上就能听出「火在下面」。**

> **一条镜一条音床**：12 条镜就是 12 段完整的环境音，镜内换段不必接音。
