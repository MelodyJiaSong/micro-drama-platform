# 荒野生活 · 红杉第一夜（Wild Living — First Night in the Redwoods）

一棵巨杉倒了，连根掀起四米高的根盘。根拔出来的那个坑，正好能睡一个人。
**他在坑底挖了一条烟道，让床自己烧起来。**

> **本片＝一部约四分半的独立短片**，由 12 个 shot 拼接成一条成片。**不是分集剧，没有 EP 结构。**
> 《荒野生活》是系列名，跨片不变量见 `../_series/series_bible.md`；本目录只装本片。

## 和 hy1 差在哪（系列圣经 §6 强制的四格）

| # | 维度 | hy1 雨林 | **hy2 红杉** |
|---|---|---|---|
| 1 | 他做的是什么 | **从零搭一个家**（往上搭） | **往地下挖一个家**（掏 / 挖 / 垒 / 盖 / 封） |
| 2 | 对抗者 | 雨林（永远在把人造物拆回去） | **风暴与潮湿**；而**倒下的那棵树是盟友** |
| 3 | 黑科技 | 叠瓦不漏水 | **烟道从床下走——人睡在一根热管子上** |
| 4 | 奇观 | 树冠缺口的实体光柱 | **从坑底仰拍：四米高的根盘 → 倒木躯干 → 九十米的雾** |

天气预兆也不重复：hy1 是鸟先飞走，hy2 是**雾自己反了方向**。
形状也是反的：hy1 往上搭（屋顶、椽子、叠瓦），hy2 往下挖（坑、沟、床台）。

> 住所形态从最初的「空心红杉树洞」改成「倒木根盘下的地窝」——
> 依据是 `1_立项/shelter_research.md` 的 22 条 YouTube 实测：**树洞是同类形态里房间最小的一档，
> 摆不下床**；而「树根下的隐蔽地窝」是可复制的高赞率格式。
> 空心红杉降级成 `shot02` 的一个路过镜（**太窄，他退出来**），顺手给了主角选择的动机。

## 使用说明

1. **参考图**：先出场景主体 18 张，再出 `c2` 蛞蝓锚点。
   **`c1` 造家的人与 `p1` 砍刀、`p2` 随身装备跨片复用 hy1 的，不重出图。**
2. **出片**：每个 `shotNN.md` 内的 `## 视频 prompt` 代码块整段复制进 Seedance。比例 **16:9**，单条 20–27s。
   **每条镜内部允许切镜**——`分镜:` 行写死了各段的起止秒与切进来的方式；一条镜 ＝ 一个地点 ＋ 一个改造状态 ＝ 一段完整的环境音。
3. **无配音层**：不生成 `台词配音 prompt`；成片音轨 = 环境音 +（可选）极简 BGM，后期铺。
4. **字幕**：全片零字幕；平台标题与描述见 `publish.md`。

## 出图顺序（**18 张，按依赖顺序**）

```
第一轮 · 唯一一张零参考自由生成
  ① bg1-1 林中列柱全景  ← 全片视觉源头，反复重跑到过完验收

第二轮 · 挂 bg1-1 的四个独立地点（可并行）
  bg2-1 树冠仰视 · bg3-1 步道全景 · bg4-1 空心红杉 · bg5-1 根盘与坑（N1 机位）

第三轮 · 改造状态链（**严格串行**，几何在累积）
  bg5-1 ─► bg6-1 挖深垒边 ─► bg7-1 烟道成型 ─► bg8-1 床台盖好 ─► bg9-1 建成日
                                              └─► bg10-1 风暴前 ─► bg11-1 风暴夜 ─► bg12-1 远景

第四轮 · 派生视图（各挂本主体锚点，可并行）
  bg3-2 倒木剥皮处 · bg5-2 坑底仰拍 · bg7-2 烟道剖视 ·
  bg9-2 坑内朝外 · bg11-2 坑内朝外（夜）· bg11-3 床面与火口微距

另：c2-1 香蕉蛞蝓锚点 —— 零参考，随时可并行
```

**三条铁律**：
1. `bg1-1` 是本片**唯一一张零参考自由生成**的图，其余全部挂它或挂它的下游。
2. **改造状态链必须串行**——坑的几何在被加减法改造，星形会让坑的尺寸、烟道走向、床台高度对不上。
3. **N1 机位是同一个位置**：`bg5-1` / `bg6-1` / `bg7-1` / `bg8-1` / `bg9-1` / `bg10-1` / `bg11-1` 七张
   必须严格同机位同焦段，否则三次进度对比帧不成立。
