# 风格指南 · 《荒野生活 · 红杉第一夜》

> 跨片不变的部分（那个人的锁定描述符、三条硬规矩、声音结构、签名收尾）见
> `_series/series_bible.md`。本文件只写**红杉篇的调色、光、负向与本片特有的约定**。

---

## 1. 一句话调色

**冷白的雾 + 深红棕的树皮 + 湿黑的土 —— 三样东西撑满前三分钟；
最后一分钟只剩一样：从床缝里透出来的暖橙。**

`hy1` 的冷色是**绿**（雨林的散射绿光），`hy2` 的冷色是**白灰**（海雾）。
`hy1` 的暖色在**棚内的火塘**（看得见火），`hy2` 的暖色**藏在床底下**（看不见火，只看得见热）——
这是两部片在观感上分得开的根本原因。

## 2. 色彩锁定（**零 hex**，一律用色名）

| 元素 | 锁定色名 |
|---|---|
| 雾 | 冷白偏灰蓝，越远越白，最远处与天完全融为一体 |
| 红杉树皮（外） | 深红棕，纵向深沟，沟底更深近乎黑褐，脊部被雾打湿泛冷光 |
| **根盘的根须** | 深褐近黑，扭结缠绕，末端断口露出浅褐色的新鲜木质 |
| **根盘夹带的土** | 湿润的深褐与赭红混杂，成块附着在根须之间，边缘不断有细土簌簌落下 |
| 坑底腐土 | 湿黑褐，掏开后下层是红褐色矿质土 |
| **旧炭层**（伏笔） | 哑光炭黑，混着几块被烧得发红发脆的石头 |
| 扁石板 | 灰白与青灰，湿处深一档并有反光 |
| 黏土（封缝） | 湿时深赭红、抹平后表面发亮，干后转浅灰褐 |
| 剑蕨 | 墨绿，叶面哑光、背面浅一档 |
| 红木酢浆草 | 嫩黄绿，三片心形小叶，比剑蕨亮两档 |
| 干蕨叶（床面） | 黄绿偏枯，比洞外的活蕨亮两档、饱和度低一档 |
| 草皮（屋顶） | 墨绿苔藓与枯黄草根混杂，切块边缘露出深褐土层 |
| 火与炭 | 暖橙，炭心通红，火星金黄 |
| 夜的暗部 | 近乎纯黑，**黑位绝不提亮**，不许出现噪点堆 |

**hex 一律不写**（rule 1b）。

## 3. 光（每一段一条规矩）

| 段 | 主光 | 特征 |
|---|---|---|
| **起** 晨 | 高处漏下的**冷白光锥**穿过雾 | 光锥边界柔和、内部可见悬浮水汽；地面无锐利投影 |
| **承** 昼 | 灰白**无方向散射光** | **地面几乎没有投影**——红杉林最真实的一条；坑内靠上方开口进来的方向光 |
| **转** 傍晚 | 整体降一档、转灰蓝 | 光锥消失，空间失去方向感，雾贴地涌动 |
| **合** 夜 | **火是唯一实光源**，且**大半被压在床下** | 坑内只有火塘口那一小块直接的橙光，其余是**从床台石缝里渗出来的微弱暖光** |

**本片光的骨架是「火被藏起来」**：
hy1 的火是敞开的、照亮整个棚屋；**hy2 的火大部分被石板盖住，只从缝里漏出来**。
所以夜戏的光比 hy1 更暗、更低、更贴地——**观众看不到火，只看到被烤热的东西**。

## 4. 本片特有的两个奇观构图

1. **坑底仰拍**（全片第二卖点）：机位贴坑底、极端仰角，
   **画面下沿是坑壁与盘结的根须，中段是四米高的根盘立面，
   越过根盘边缘是横躺的倒木躯干，再往上是更高处那些还活着的红杉，最后收进九十米高的白雾。**
   一个镜头同时说清楚：这树多大、这坑多深、他为什么选这里。
2. **门缝同框**（情绪最高点）：机位在坑内床沿高度朝外，
   **画面下三分之一是干蕨叶床面与从石缝渗出的暖橙，中间是树皮门留出的一道竖缝，
   缝外是横着走的雨与冷灰蓝的林子。**
   干与湿、暖与冷、安全与危险，全在一个画面里，中间只隔着一块树皮。

## 6. 露脸（12 镜里 9 镜给到脸）

脸的一致性由用户建立的 **Seedance 人物 entity** 承载（与 hy1 同一个），
**shot prompt 一律不写文字五官**。

| 类型 | 镜 |
|---|---|
| **认人镜**（脸给得最完整） | `shot02` 钻进空心红杉后站直、张开手臂碰到两壁的那一下，仰角天光打脸 |
| **正面** | `shot07` 剥树皮的用力面 · `shot08` 对比帧#3 转过身来 |
| **侧脸 / 四分之三** | `shot03` 拔石板 · `shot04` 挖深 · `shot06` 抹黏土 · `shot11` 火边侧脸（**全片最好的一张脸**） |
| **仰视** | `shot03` 末段抬头看根盘 · `shot09` 抬头看天 |
| **末段显现** | `shot01` 从雾里走近 |

**冷是靠身体演的，不靠加衣服**（系列圣经 §3）：呼出的白气、缩起的肩、搓手、
**把手掌贴在床面上**、领口被雾打湿发深。**服装跨片 byte-identical，不换季。**

## 7. 音轨约定（无人声）

- 无台词、无旁白、无 TTS、无字幕。shot 一律 `台词: 无`。
- **红杉林的声音底噪极低**——雨林是满的，红杉林是**空的**。
  空旷感靠**长混响**：一铲土落地、一块石板放下，都带着从九十米高处返回来的余响。
- 本片的声音记号：**铁刃切进湿土的闷响**（承段主音）· **石板与石板相扣的清脆**·
  **黏土被手掌抹开的黏腻声** · **风穿过树干列柱的低频呜咽**（转段）·
  **火在床下的闷烧声**（合段——**听得见火，看不见火**）。
- 极简 BGM 只在**开场**与**签名定帧**两处。

## 8. 画幅与时长

- 画幅：**16:9**（全片，含所有参考图）。
- 单镜 **15–30s，镜内允许切镜**；切分单位＝**一个地点 ＋ 一个改造状态 ＝ 一条镜**，实际落 21–27s。
- **全片 283s**，12 个 shot。**镜与镜之间零承接、全部硬切**；**镜内的切镜不是承接**，同一时刻同一条音床。
