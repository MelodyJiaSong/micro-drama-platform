# 树皮门与顶 · p3（本片新增·核心道具）

## 定位

**本片的「材料就在现场」爽点，也是屋内舒心 vs 屋外狂风暴雨的物理分界。**

红杉树皮厚达三十厘米、纤维状、富含单宁——**防水、极难燃、天生带弧度**。
他从**同一棵倒木**上剥下两批：大片的做顶，一整片的做门。不需要加工，不需要钉子。

> **不砍活树**（`world.md` 铁律）。树皮只从那棵倒木上剥，这一点必须在 `shot07` 的画面里成立——
> 他剥的那根树是**横躺着的**。

## 锁定描述符（成型后跨镜 byte-identical，凡入画原样复现）

**屋顶**：

```
坑口横架着五六根手臂粗的枯木作梁，梁上顺坡铺满整片红杉树皮、外侧深红棕带纵向深沟、
片与片之间叠压约两掌宽，最上面压着一层切块的草皮，草皮边缘露出深褐土层，
屋顶靠根盘一侧直接搭在根盘的根须上、另一侧落在垒起的石土边墙上
```

**门**：

```
一整片弧形红杉树皮门板，高约一米四、宽约七十厘米、厚约二十厘米，外侧深红棕带纵向深沟、
内侧是浅褐色纤维断面，下缘垫在一块扁石上，两根手臂粗的枯枝自内侧斜撑抵住坑壁，
门板与坑口右缘留出约一掌宽的竖缝
```

**那道一掌宽的竖缝是设计，不是缝隙**：进新鲜空气、看得见外面的雨，
也是情绪最高点那一镜的构图分界线。
