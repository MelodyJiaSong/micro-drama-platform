# 人物网 · 《荒野生活 · 红杉第一夜》

本片只有一个人。所谓「关系」，是**他与四样非人事物之间的关系**——
这四条线决定了每一镜里他的身体怎么动、看哪里、停多久。

```
                     ┌──────────────────┐
                     │  倒下的那棵巨杉  │  盟友（系列首次：自然站在他这边）
                     └────────┬─────────┘
                              │ 根盘替他挡住风、土里给他石板、树皮给他门与顶；
                              │ 他不砍活树、木料只取自它与地上的枯枝
     风暴与潮湿 ────────── 造家的人 ────────── 香蕉蛞蝓
     （对抗者）                │              （这地方的原住民）
                              │
                     ┌────────┴─────────┐
                     │  坑底的那层旧炭  │  上一个人（长线伏笔第二格）
                     └──────────────────┘
```

## 1. 他 ↔ 倒下的那棵巨杉：**盟友**（系列里第一次，自然站在他这边）

- hy1 的雨林是**对抗者**——它永远在把人造物拆回去。这棵树不是。
  它倒下来的时候，**顺手给了他四样东西**：一堵四米高的墙（根盘）、
  一个房间大小的坑、一堆被根带上来的石板、以及封顶与做门的树皮。
- 这条关系靠**「他几乎没有从别处拿过任何东西」**来表现：
  全片他只离开这个坑一次（去倒木上剥树皮），**而那也是同一棵树**。
- 情绪落点：`shot03` 末段他直起腰抬头——**镜头从坑底仰上去，
  四米的根盘立面、横躺的倒木躯干、更高处还活着的红杉、最后是雾**。
  他站在一棵树倒下来留出的空当里。

## 2. 他 ↔ 风暴与潮湿：**对抗者**

- 潮湿是**慢的敌人**（一整个白天都在跟它斗：掏腐土、挖深、垒边、封缝）；
- 风暴是**快的敌人**（傍晚才到，二十分钟内决出胜负：扣门、生火）。
- 两个敌人各有一个专属的爽点：潮湿输在**床面从湿黑变成干黄**，
  风暴输在**横雨打在树皮门上、而他躺在一张热的床上**。
- **根盘是这场对抗里的第三方**：风来的时候，坑外的剑蕨全体倒向一边，
  **而坑内的蕨叶一动不动**——那堵四米高的墙在替他挡着。

## 3. 他 ↔ 香蕉蛞蝓：**客人 ↔ 原住民**

- 全片交集三秒（`shot03`）。他连着一块腐土把它捧到坑外的剑蕨叶上。
- **它不回来、不再出现、不给回望**。这条关系的全部重量就在那一个动作里。

## 4. 他 ↔ 坑底的旧炭：**没有交集**（长线伏笔）

- `shot04` 往下挖时带出一层**黑色的旧木炭与几块被烧得发红的石头**——
  **这个坑，以前有人在里面生过火。**
- 约两秒。**他把它拨到一边，继续挖。镜头不推、不对焦、不给反应镜。**
- 观众自己发现，或者不发现。系列长线第二格——第一格是 hy1 那副被藤蔓吃掉的旧木构架。
