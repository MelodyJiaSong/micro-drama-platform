# 中西对照、术语与 IP 边界

## 1. 仙侠 → 西幻 对照表

按[仙侠公共库](../xianxia/systems.md)的 26 个设定维度逐项给出西幻的**对等物**。对等不等于翻译：右列是欧洲传统里本来就有、功能相近的东西，常常机制不同。

| 仙侠维度 | 仙侠常见写法 | 西幻对等物（本库） | 关键差异 |
|---|---|---|---|
| 族源与生命形态 | 人、妖、魔、仙、鬼 | 存在之链：天界存在、妖精与长生种、凡人诸族、变形者与诅咒者、亡灵、深渊存在；链外元素与龙 PL00 | 按位格高低排序，不按善恶阵营 |
| 能源与循环 | 灵气、仙元、妖力、魔气 | 九种力量源 PS01–09 | 力量来源不同，获取方式不同（学、赐、借、生、造、挣、取） |
| 境界、突破与劫数 | 炼气、筑基、金丹……渡劫 | **无统一境界：头衔 + 种族等级 + 威胁度**——路线头衔 TL01–05、各族等级链 RC、威胁度 BS00（野兽 / 怪物 / 恐怖 / 灾厄，之上神话）；觉醒 EV01；封神之试 EV04（可选） | 西幻主流（《指环王》《权力的游戏》）没有人人共用的力量阶梯：强弱靠组织授予的头衔、族内地位与「对付它要多大代价」来讲；寿命不随强弱增长；成半神靠功业与一次死亡重生，不是天雷 |
| 灵根、妖脉与魔脉 | 灵根属性与品质 | 天赋之火 GF01 + 四种气质 GF02 | 属性同时是性格；天赋多是自己显露，不靠入门检测 |
| 灵体、妖体与魔躯 | 至尊骨、重瞳、先天道体 | 天生异相 GF03–09（第七子之七子、胎膜之子、光痕、女巫印记、换生儿、冷铁之魂、预言之子） | 来自民间信仰，常带「被猎杀」的风险 |
| 灵性生命与神魂 | 元神、元婴出窍、夺舍 | 灵魂出窍与入梦（灵魂术 DK04、梦境 PL09）、附身 FL03、护命匣 IT20 | 附身者是有名字可谈判的存在 |
| 功法与心法 | 功法秘籍 | 学派 SC × 领域 EL；魔法书 IT16 | 知识在书与学院里，可被夺、被禁 |
| 武技、剑法与兵器术 | 剑修、剑气 | 武艺熟练度（不需觉醒）、勇武 PS09、燃剑 AU01、骑士 CL02 | 技艺与超凡分开计；英雄之光随勇气与荣誉，不靠内力积蓄 |
| 元素术法 | 五行 + 风雷冰 | 四古典元素 + 冰、雷、星辰、时空 EL01–08 | 四元素 + 以太，不是五行，无相生 |
| 秘术、禁术与代价 | 燃血、以寿换力 | 禁忌魔法 DK01–04（契约、血、诅咒、灵魂） | 核心是「代价付给了谁」，契约有条款 |
| 秘籍与传承载体 | 玉简、传承 | 魔法书 IT16、圣物传承 GR08、认主之剑 IT19 | — |
| 丹药、药剂与养化 | 丹药、丹毒 | 药剂 IT01–07、药毒规则、炼金 CF01 | 中西炼金术是真实历史平行；西方成品多为液体 |
| 符箓、咒式与印记 | 符箓 | 卷轴 IT11、符文石 IT10、护身符 IT12、契约书 IT08、咒偶 IT09 | — |
| 法宝、本命器与权器 | 法宝、本命法宝、仙器 | 施法器 IT14–17、器物等第 IR01（按来历）、圣物与神器 IT18–30 | 价值在来历与名字，不在品质色；认主 = 灵魂缔结，需觉醒 |
| 阵法、结界与领域 | 阵法、护山大阵 | 法阵与结界 CF03、护界石 IT13、圣域 HL03 | — |
| 灵材、灵植与资源 | 灵石、灵草、妖丹 | 以太晶 MT01（战略资源，不当货币）、银/冷铁/山铜/精金、曼德拉草、狼毒草、兽石 MT12（稀有奇石，不是力量核） | 财富是金币、土地与圣物；克制材料来自民俗且全剧通用 |
| 灵兽、伴生兽与役兽 | 灵宠、坐骑 | 使魔 BS15、狮鹫、飞马、恐狼、魔像 | 经灵魂缔结 GR06 |
| 神兽、祖兽与镇域种 | 龙凤麒麟 | 龙、凤凰、独角兽 | 西方龙贪婪守宝，凤凰核心是重生 |
| 门派与传承共同体 | 宗门 | 法师学院、骑士团、德鲁伊环、赫尔墨斯学会（隐世）、猎魔人会馆 OR | 是学术/誓约机构，不是家族式宗门 |
| 世家、族群与家系 | 世家 | 贵族家族 OR10（公侯伯子男、纹章） | — |
| 组织、政体与公共制度 | 朝廷、仙盟 | 王庭 OR11、圣光教会 OR02、商人与手工行会 OR17；冒险者公会 OR07（可选） | 王庭—教会—学院—行会四方博弈 |
| 派系与政治立场 | 正魔两道 | 教会慈悲派/审判派、学院守旧/革新、光辉/幽暗宫廷 | — |
| 山门、聚落与地理 | 洞天福地 | 地脉与圣地 PL10、妖精国度 PL05 | 彼岸时间流速不同 |
| 生产、贸易与交通 | 坊市 | 行会制度、七里靴、传送阵 | — |
| 礼制、契约与日常 | 拜师礼、道侣 | 学徒契约 GR01、授剑礼、誓言与禁誓、灵魂缔结 | 契约精神贯穿社会 |
| 失衡、灾害与对抗 | 走火入魔、心魔、天劫 | 炉渣、腐化、附身、失恩 FL01–04 | 腐化逐集可见 |

**本库默认关闭、欧洲其实也有的**：轮回转世。希腊冥界有判官与分途，柏拉图厄尔神话中灵魂喝遗忘河水后转世，凯撒记载德鲁伊信灵魂转生；本库默认「死者安息」，采用剧可打开「转生」模块。

**仙侠常见、欧洲传统少见的**：人人共用的境界线、闭关千年、修为越高寿命越长、入门测资质、灵石当货币、打怪掉妖丹。**西幻有、仙侠少见的**：契约法律化、真名、冷铁/银等民俗克制、教会作为政治实体、名声作为力量、技艺与超凡分开计。

## 3. IP 边界

每部剧引入条目前对照此表。分三档：

| 档 | 规则 | 例 |
|---|---|---|
| 可直接用 | 通用类型词与公有领域神话民俗 | elf、dwarf、orc、paladin、necromancer、lich、werewolf、Alpha/Luna、phoenix、basilisk、philosopher's stone、geas、selkie |
| 只借机制 | 作品机制可借，名称、外观、组合须原创 | 药剂毒性条、高死亡率异变试炼、以兽为名的猎人流派、心魔试炼式入门 |
| 禁用 | 作品自创专名、地名、组织名与标志组合 | 见下 |

**禁用专名（摘自九份研究报告第 11 节）**

- 托尔金：mithril、Istari、Valar/Maiar、Nazgûl、Balrog、palantír、lembas、hobbit、Middle-earth。
- 冰与火：Valyrian steel、dragonglass（用 obsidian）、wildfire、Faceless Men、Maester、White Walkers、Night's Watch、Kingsguard。
- 时光之轮：Aes Sedai、Ajah、saidin/saidar、angreal、Warder、the Dark One。
- 魔兽：Azeroth、Kirin Tor、Fel（作力量名）、Scourge、Burning Legion、Naaru、Argent Crusade、Silver Hand；以及「蒙眼+绿纹+骨翼」「符文剑+蓝眼+冰霜板甲」「蓝皮+蹄+尾+触须」等整套组合。
- D&D：beholder、mind flayer、githyanki、yuan-ti、Forgotten Realms 地名与神名；tiefling、aasimar 建议改用 cambion、angel-born（The Graced）。
- 上古卷轴：Tamriel、Daedra/Aedra、Thu'um、Dwemer、Altmer 等族名、Dark Brotherhood、College of Winterhold。
- 猎魔人：Witcher（作职业名）、Aard/Igni 等法印名、Trial of the Grasses、Elder Blood、Aen Seidhe、dimeritium；「背银钢双剑+竖瞳+狼头吊坠+白发」组合。
- 龙腾世纪：the Fade、Lyrium、Circle of Magi、Chantry、Harrowing、Joining、Grey Wardens、Darkspawn、Tranquil。
- 战锤：八风名（Aqshy 等）、Sigmar、Khorne/Tzeentch/Nurgle/Slaanesh、Skaven、warpstone。
- 暗黑 / Dota / 英雄联盟：Sanctuary、Nephalem、Horadrim、Roshan、Aegis、Runeterra、Demacia、Darkin、Hextech。
- 名称层面轻度识别：Star Elves（被遗忘国度）、Assassins' Brotherhood（刺客信条，本库用 the Quiet Hand）、Masquerade（吸血鬼：避世血族）、Shadowhunters 式 nephilim 设定；冰原狼 direwolf 与雄鹿纹章同用会联想到权力的游戏。
- 其他：Cradle 的境界组合（Copper→Iron→Jade→Gold）、Overlord 与哥布林杀手的冒险者金属等级、斗罗「魂环颜色+年限」组合、哈利波特的 Horcrux/O.W.L./学院名。

**组合禁用**（单条可用，整套组合会被认出）：

| 不得同时按原样采用 | 会被认成 |
|---|---|
| 药剂变异猎人 + 竖瞳 + 山中要塞 + 以兽为名的流派 + 银钢双剑 | 猎魔人 |
| 木料 + 杖芯（龙、凤、独角兽）定性格 + 最强的接骨木杖 + 隐身斗篷 + 红色贤者之石 | 哈利波特魔杖与死亡圣器 |
| 隐身 + 支配他人 + 长生 + 噬主的朴素金戒 | 托尔金至尊魔戒 |
| 部落 + 萨满 + 图腾柱 + 羽饰 + 战酋长 Warchief | 魔兽兽人（且有原住民刻板印象） |
| 地下 + 白发 + 灰紫或深色皮肤 + 畏光 + 刺客 | D&D 卓尔精灵 |
| 天使之血的混血猎魔人 + 与恶魔之子相恋 | 暗影猎人 |
| 一科一金属链环 / 七色宗派加黑色卧底宗 | 冰与火学城 / 时光之轮 |

**真实宗教距离表**（圣光教会只借中世纪拉丁教会的结构）：

| 可以用 | 不用 |
|---|---|
| 主教制、什一税、修道院、圣徒追认、圣物崇拜、驱魔仪式、宗教审判的结构 | 十字架、圣彼得交叉钥匙、上帝之眼、真实圣人名、弥撒 / 圣体等圣事名、圣痕原形（手掌与额头的受难伤） |
| 原创七芒太阳盘 | 十六芒韦尔吉纳太阳、直芒波芒交替的五月太阳、sun-wheel / 黑太阳 |
| 光誓骑士 Lightsworn | crusader、Templar 作为组织名 |

**其他敏感**：北欧 Othala、Algiz 等符文被仇恨团体挪用，符文一律自创字形；图腾柱、羽冠、灵兽三连等北美原住民文化元素不用作奇幻种族装饰；哥布林不写「尖鼻 + 贪财 + 地下金融」；「深肤色 = 暗面」不作种族设定；Loa 等仍在信仰中的神灵名不用。
