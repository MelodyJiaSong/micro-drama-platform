# 西幻体系总纲 · v1.2

欧美原生的对等体系：结构上和仙侠一样完整（强弱、天赋、功法、丹药、法器、宗门、种族、三界），但每一块的内在逻辑都取自欧洲自己的传统，不是把仙侠词翻成英文。「仙侠参照」只帮中文团队理解，很多地方写着差异或「无直接对应」。

本库只放基本元素，不含剧情与人物。每部剧从这里挑选需要的部分引入（第 12 节）。条目细节看 [图鉴](codex/)，每条有卡片与图。v1.2 去掉了灵魂金属成色，强弱只用头衔、各族等级链与威胁度，记录见第 13 节。

## 1. 一个角色怎么描述

| 轴 | 回答 | 本库条目 |
|---|---|---|
| 种族 | 他是什么存在 | 种族 RC/RS（每族有自己的社会等级链） |
| 力量源 | 能量从哪来、付什么代价 | 九种力量源 PS01–09 |
| 职业 | 怎么用这份力量、属于哪个圈子 | 职业 CL01–24 |
| 头衔 | 社会承认的身份，也是同一路线里讲强弱的主要方式 | 路线头衔 TL01–05、组织 OR |
| 武艺 / 手艺 | 不靠超凡的本事有多熟 | 熟练度五级（第 4 节） |
| 天赋 | 先天上限与气质 | 天赋之火 GF01、四种气质 GF02、天生异相 GF03–09 |
| 威胁度 | 跨种族、跨路线比，他有多危险 | 威胁度 BS00（第 3 节、第 6 节换算表） |

例：*人类 · 圣光 · 圣武士 · 旗骑士 · 武艺大师 · 明火 · 胆汁质 · 怪物级*。

仙侠是一条境界线统管一切；西幻没有人人共用的等级，把**头衔、技艺、天赋、威胁度**拆开。头衔只写典型强弱，不设硬门槛，所以会有连圣愈都施不出的主教（政治任命）、驱逐过灾厄级恶魔的乡村神父、未觉醒却武艺通神的老骑士——这种错位是西幻社会的常态。

|---|---|---|---|---|---|

| PS03 | 自然 Primal | **被接纳的**：土地与兽灵借给你 | 野化、与土地绑定 | 苔绿 + 琥珀 | 焚烧、冷铁与城市 |

| PS06 | 深渊 Infernal | **借贷来的**：契约 | 条款兑现、腐化 | 焦黑 + 熔岩橙 | 圣物、真名、契约漏洞 |
| PS07 | 血脉 Bloodline | **生来的** | 理智被血压制、被猎杀 | 随血脉 | 天敌材料、封印 |
| PS08 | 符文与工艺 Runecraft | **造出来的**：刻进物质 | 耗时、只能预制 | 熔金 / 冰蓝刻痕（与圣光同画面时用冰蓝） | 磨损、熔毁 |

**圣光的形而上学**（神与信仰 GD）：本库默认「信念点燃圣光，众多信念汇聚成神，神再回应信者」；采用剧可换成「神主动赐予」或「无神，纯信念」。

法术另有两条正交分类：**学派**（做什么）——防护、咒法、预言、惑控、塑能、幻术、死灵、变化 SC01–08；**领域**（用什么）——火、水、土、风四古典元素加冰、雷、星辰，时空为可选模块 EL01–08；另有圣光分支 HL、禁忌魔法 DK、赛兹与变形 PR、燃剑 AU。一个火球术 = 塑能 × 火。

## 3. 强弱怎么讲

主流西幻没有通用的力量阶梯：《指环王》里甘道夫与戒灵没有「境界」，《权力的游戏》比的是头衔、军队与龙，《魔兽世界》的强弱也落在大法师、死亡骑士、龙王这类头衔与族内等级上。本库照此只用三样东西讲强弱，**不设统一境界，也不用金属或颜色分级**。

**同一路线：职业头衔**（组织授予，靠考核、誓言与受封，见 TL 与晋升仪式 EV05）

| 路线 | 头衔链（低 → 高） | 条目 |
|---|---|---|
| 骑士 | 侍童 → 侍从 → 骑士 → 旗骑士 → 王国重臣 → 王之斗士 | TL02 |
| 法师 | 学徒 → 熟手 → 法师 → 大师 → 大法师 | TL01 |
| 神职 | 侍祭 → 执事 → 神父 → 主教 → 大主教；圣徒另行追认 | TL03 |
| 德鲁伊 | 吟游者 → 卜者 → 德鲁伊 → 大德鲁伊 | TL04 |
| 女巫 | 学徒 → 女巫 → 高阶女巫 → 长老 | TL05 |

没有组织头衔的路线（术士、契约师、死灵法师、游侠）直接用威胁度说：「一个怪物级的契约师」。

**同一种族：本族等级链**（第 6 节）——狼群 Omega → Beta → Alpha、吸血鬼新生者 → 长老 → 始祖、妖精宫廷爵位、恶魔爵位、天使三阶九级、龙的年岁。

**跨种族、跨路线：威胁度**（BS00，默认）——回答「要多大代价才对付得了」：

| 威胁度 | 要什么才对付得了 | 例 |
|---|---|---|
| 野兽 Beast | 一名老练战士或几个民兵 | 巨狼、狮鹫幼崽；更弱的害兽（巨鼠、鬼火）不入等级 |
| 怪物 Monster | 骑士、法师一级的职业者小队 | 蛇怪、蝎尾狮 |
| 恐怖 Terror | 王国重臣、大法师一级的强者，或一支军队 | 九头蛇、成年龙 |
| 灾厄 Calamity | 传说中的英雄或举国之力，威胁一个王国 | 古龙、海妖王 |
| 神话 Mythic | 凡人不能靠力量取胜，只能靠圣物、真名、契约漏洞或牺牲 | 神、魔王、半神 |

人不「升」威胁度，只是被「评」为某一级；各族怎么对上见第 6 节换算表。

### 各路线怎么变强

| 路线 | 怎么变强 | 对应条目 |
|---|---|---|
| 骑士、战士、游侠 | 功业被传颂、守住誓言、受封；觉醒常发生在一场以命相搏的战斗里 | GR07、GR03、EV01、EV05 |
| 神职、圣武士 | 神恩与守誓；圣迹被认可 | GR11、GR03 |
| 法师、先知 | 学习、出师杰作、答辩与入门秘仪 | GR01、GR02、EV05 |
| 女巫 | 入会礼、月相仪式、与使魔缔结 | TL05、GR06 |
| 契约师 | 每次续约多得一分力量，同时多付一笔代价 | GR05、DK01 |
| 术士、天恩之子、魔裔 | 血脉随年龄与危机分次觉醒 | GR04 |
| 德鲁伊、元素术士 | 被土地或元素一次次接纳，随季节节庆 | PS03、PS04 |
| 死灵法师 | 亲历死亡、灵魂术，终点是巫妖 | DK04、RC14 |
| 炼金术士 | 在自己身上做嬗变实验 | CF01、GR09 |

**觉醒**（EV01）：约一成人类一生中会觉醒，此后才有法术、英雄之光等超凡之力；不觉醒照样能当骑士、成武艺大师。**封神**（EV04，可选模块「封神」）：凡人经传说功业与一次死亡重生成为半神，威胁度进入神话级。

**寿命不随强弱增长**：长寿只来自生命之酒、贤者之石、契约、种族与神恩。

**失败**：炉渣（透支或强行越过极限后的灵魂裂痕 FL01）；腐化（力量源带毒，身体逐集可见地改变 FL02）；附身（FL03）；失恩（背誓 FL04）。

## 4. 武艺与手艺熟练度

不靠超凡的本事另计：**生手 Novice → 学徒 Apprentice → 熟手 Journeyman → 大师 Master → 宗匠 Grandmaster**。剑术、骑术、锻造、药理、学识都按此分级。

- 骑士身份靠武艺、誓言与受封，**不要求觉醒**；九成的人一生不会觉醒，其中照样有武艺大师。
- 英雄之光是勇武的**超凡**表现，只在觉醒后出现；一场以命相搏的功业常常就是觉醒的契机。
- 冷铁之魂（GF08）不会觉醒，只能凭武艺成长。

## 5. 天赋：先天的那一半

| 轴 | 分级 | 决定什么 |
|---|---|---|
| 天赋之火 GF01 | 无火 / 微火 / 明火 / 烈火 / 天火 | 觉醒难易、成长速度与能走多远（微火多止于熟手、神父一级，明火可成法师、旗骑士，烈火是大法师、王之斗士之才） |
| 四种气质 GF02 | 多血质—风 / 胆汁质—火 / 抑郁质—土 / 黏液质—水 | 元素亲和与性格，二者天然一致 |
| 天生异相 GF03–09 | 第七子之七子、胎膜之子、女巫印记、光痕、换生儿、冷铁之魂、预言之子 | 特殊能力与特殊风险，来自欧洲民间信仰 |

欧洲叙事里天赋多是**自己显露**的（危机中的觉醒、被器物选中），不靠仪器测；本库不设测资质的道具。

## 8. 道具规则

- **器物等第**（IR01）按来历分：凡品 → 名匠之作 → 附魔器 → 有名之器 → 圣物 → 神造之器。有名之器以上需认主（灵魂缔结，需觉醒）。品质色只供道具组内部参考，不上屏。
- **财富**是金币、土地与圣物；以太晶（MT01）是被垄断的战略资源，不当货币；兽石（MT12）稀有、各物各效，不是可吞服的力量核。
- **药毒**（IT07，默认）：同时饮用的药剂累计毒性，凡人约两瓶，久经锤炼的骑士或大师级法师约五瓶，超出即中毒。
- **施法器不是力量来源**：失去魔杖仍能施法，只是更弱；失去魔法书（IT16）则失去传承。
- **制作四工艺**：炼金 CF01、附魔与符文锻造 CF02、法阵与结界 CF03、抄写 CF04。

## 9. 组织

公开：法师学院、圣光教会（光誓骑士团、异端裁判所）、骑士团、德鲁伊环、猎魔人会馆、商人与手工行会。王权：贵族家族、王庭。隐秘：女巫会、赫尔墨斯学会、盗贼行会、静手会（刺客）、恶魔教团。种族社会：狼群、血族议会。可选：冒险者公会（会员用星级，委托难度沿用威胁度）。

一个人可同时属于多个组织；王庭—教会—学院—行会四方的权力博弈是西幻社会的基本张力。

## 10. 宇宙

存在之链居中排序；凡世在中，上有七重天，下有九层环狱与冥界（冥河、判官、遗忘之河），旁有妖精国度（时间流速不同）与梦境，四周元素界，外有以太之海与外域虚空。地脉交汇的圣地是各界之门最薄处。

**默认：死者安息、不轮回**。这是设定选择而非「欧洲没有轮回」——柏拉图的厄尔神话与德鲁伊都有转生说，采用剧可打开「转生」模块。

## 11. 屏幕语言（锁定）

每个视觉通道只负责一件事，同一画面最多两种力量光：

| 通道 | 表达 | 怎么上屏 |
|---|---|---|
| 特效颜色 | 力量源 | 见第 2 节与 visual_guide |
| 服饰与道具 | 头衔 | 徽章、马刺、袍色、权杖（见 TL 各条），不做成光效 |
| 不上屏 | 气质、天赋、威胁度、器物等第 | 台词与设定交代 |

强弱不靠光色或光泽区分：同一种力量，强者只是范围更大、更稳、代价更小。

## 12. 采用规则

每个条目标有采用层级：

| 层级 | 含义 | 例 |
|---|---|---|
| 锁定 locked | 跨剧一致，不改 | 九种力量源的定义与颜色、克制关系、存在之链 |
| 默认 default | 采用剧可改名、改数值、改细节 | 大部分条目；威胁度与跨体系换算表、药毒瓶数、头衔细节 |
| 可选模块 optional | 采用剧可整块关闭 | 封神、时空魔法、冒险者公会、炼金蜕变、多神、转生 |

做法：

1. 复制 [adoption_template.json](adoption_template.json) 到剧目录，填库版本、采用条目 ID、模块开关与改动；或从模板里的题材预设包开始（狼人吸血鬼恋爱、骑士与教会、学院法师、妖精宫廷、深渊契约、史诗战争）。
2. 剧内改名改数值写在剧目录，不改本库。
3. 本库图片是概念参考（特效语言、服装与物件方向），不是剧中人物或最终镜头资产；人物仍走剧内的人物资产流程。
4. `inspired` 条目只借机制，外观与名称须原创；组合禁用见 appendix 第 3 节。
5. 多部剧都需要的新元素，再加回本库并升版本。
