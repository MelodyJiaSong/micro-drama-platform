# 西幻体系总纲 · v1.1

欧美原生的对等体系：结构上和仙侠一样完整（境界、天赋、功法、丹药、法器、宗门、种族、三界），但每一块的内在逻辑都取自欧洲自己的传统，不是把仙侠词翻成英文。「仙侠参照」只帮中文团队理解，很多地方写着差异或「无直接对应」。

本库只放基本元素，不含剧情与人物。每部剧从这里挑选需要的部分引入（第 12 节）。条目细节看 [图鉴](codex/)，每条有卡片与图。v1.1 按独立审稿修订，记录见第 13 节。

## 1. 一个角色怎么描述

| 轴 | 回答 | 本库条目 |

| 种族 | 他是什么存在 | 种族 RC/RS（每族有自己的社会等级链） |

| 天赋 | 先天上限与气质 | 天赋之火 GF01、四种气质 GF02、天生异相 GF03–09 |
| 头衔 | 社会承认的身份 | 路线头衔 TL01–05、组织 OR |

例：*人类 · 圣光 · 圣武士 · 铁阶 · 武艺大师 · 明火 · 胆汁质 · 旗骑士*。

仙侠是一条境界线统管一切；西幻把**超凡强度、技艺、天赋、头衔**拆开。头衔只写典型成色，不设硬门槛，所以会有锡阶主教（政治任命）、银阶乡村神父、未觉醒却武艺通神的老骑士——这种错位是西幻社会的常态。

**圣光的形而上学**（神与信仰 GD）：本库默认「信念点燃圣光，众多信念汇聚成神，神再回应信者」；采用剧可换成「神主动赐予」或「无神，纯信念」。

法术另有两条正交分类：**学派**（做什么）——防护、咒法、预言、惑控、塑能、幻术、死灵、变化 SC01–08；**领域**（用什么）——火、水、土、风四古典元素加冰、雷、星辰，时空为可选模块 EL01–08；另有圣光分支 HL、禁忌魔法 DK、赛兹与变形 PR、燃剑 AU。一个火球术 = 塑能 × 火。

## 3. 灵魂成色：大功业

依据：欧洲灵性炼金术相信，把铅炼成金就是把灵魂炼到完美（Magnum Opus）；密特拉秘仪的「七门梯」由七种金属铸成；《赫尔墨斯文集·Poimandres》写灵魂穿过七重天、每层交还一种恶。**顺序、行星配对与每阶之恶都是本库重组**：Celsus 记载的原梯（Origen《驳 Celsus》VI.22，已核实）是铅—土星、锡—金星、铜—木星、铁—水星、合金—火星、银—月、金—日，顶上另有第八门，行星配对与后世炼金不同；Poimandres 原文只写第一至第七区、未写行星名（学界多读作月至土星），第一区交还的「增长与消减」本身也不算恶。研究见 `research/works/w07` 第 13 章。

**三条性质**：

1. **成色不是储量**：不是打坐积累的修为，而是灵魂被炼到的纯度，可以被验出来（试金石 IT22）。
2. **各路线怎么被炼，完全不同**（见下表）。
3. **寿命不随成色增长**：长寿只来自生命之酒、贤者之石、契约、种族、神恩。唯一例外：金不锈，金阶者不再衰老。

|---|---|---|---:|---|---|

### 各路线怎么升阶

| 路线 | 灵魂怎么被炼 | 对应条目 |
|---|---|---|
| 骑士、战士、游侠 | 功业被传颂、守住誓言；觉醒常发生在一场以命相搏的战斗里 | GR07、GR03、EV01 |
| 神职、圣武士 | 神恩与守誓；圣迹被认可 | GR11、GR03 |
| 法师、先知 | 学习、出师杰作、答辩与入门秘仪 | GR01、GR02、EV05 |
| 女巫 | 入会礼、月相仪式、与使魔缔结 | TL05、GR06 |
| 契约师 | 每次续约升一阶，同时多付一笔代价 | GR05、DK01 |
| 术士、天恩之子、魔裔 | 血脉随年龄与危机分次觉醒 | GR04 |
| 德鲁伊、元素术士 | 被土地或元素一次次接纳，随季节节庆 | PS03、PS04 |
| 死灵法师 | 亲历死亡、灵魂术，终点是巫妖 | DK04、RC14 |
| 炼金术士 | 在自己身上做嬗变实验 | CF01、GR09 |

每次升阶都要经过「灵魂的黑夜」（EV02）。**四相**（黑化→白化→黄化→红化，PH01）与**每阶之恶**是可选模块：打开时，刚升阶最不稳、突破要战胜本阶之恶；关闭时，黑夜的内容由采用剧决定。

**失败**：炉渣（灵魂裂痕 FL01）；腐化（力量源带毒，身体逐集可见地改变 FL02）；附身（FL03）；失恩（背誓 FL04）。

## 4. 武艺与手艺熟练度

不靠超凡的本事另计，不折算金属：**生手 Novice → 学徒 Apprentice → 熟手 Journeyman → 大师 Master → 宗匠 Grandmaster**。剑术、骑术、锻造、药理、学识都按此分级。

- 骑士身份靠武艺、誓言与受封，**不要求觉醒**；九成的人是原质，其中照样有武艺大师。
- 英雄之光是勇武的**超凡**表现，只在觉醒（铅阶起）后出现；一场以命相搏的功业常常就是觉醒的契机。
- 冷铁之魂（GF08）永远不在金属成色内，只能凭武艺成长。

## 8. 道具规则

- **器物等第**（IR01）按来历分：凡品 → 名匠之作 → 附魔器 → 有名之器 → 圣物 → 神造之器。有名之器以上需认主（灵魂缔结，铜阶起）。品质色只供道具组内部参考，不上屏。
- **财富**是金币、土地与圣物；以太晶（MT01）是被垄断的战略资源，不当货币；兽石（MT12）稀有、各物各效，不是可吞服的力量核。
- **药毒**（IT07，默认）：同时饮用的药剂累计毒性，凡人约两瓶、铁阶约五瓶，超出即中毒。
- **施法器不是力量来源**：失去魔杖仍能施法，只是更弱；失去魔法书（IT16）则失去传承。
- **制作四工艺**：炼金 CF01、附魔与符文锻造 CF02、法阵与结界 CF03、抄写 CF04。

## 9. 组织

公开：法师学院、圣光教会（光誓骑士团、异端裁判所）、骑士团、德鲁伊环、猎魔人会馆、商人与手工行会。王权：贵族家族、王庭。隐秘：女巫会、赫尔墨斯学会、盗贼行会、静手会（刺客）、恶魔教团。种族社会：狼群、血族议会。可选：冒险者公会。

一个人可同时属于多个组织；王庭—教会—学院—行会四方的权力博弈是西幻社会的基本张力。

## 10. 宇宙

存在之链居中排序；凡世在中，上有七重天，下有九层环狱与冥界（冥河、判官、遗忘之河），旁有妖精国度（时间流速不同）与梦境，四周元素界，外有以太之海与外域虚空。地脉交汇的圣地是各界之门最薄处。

**默认：死者安息、不轮回**。这是设定选择而非「欧洲没有轮回」——柏拉图的厄尔神话与德鲁伊都有转生说，采用剧可打开「转生」模块。

## 11. 屏幕语言（锁定）

每个视觉通道只负责一件事，同一画面最多两种力量光：

| 通道 | 表达 | 怎么上屏 |
|---|---|---|
| 特效颜色 | 力量源 | 见第 2 节与 visual_guide |
| 虹膜与质感 | 灵魂成色 | 只在验石、突破或全力爆发时，靠质感与动态区分（铅下沉、锡单薄、铜传导、铁火星、汞流动、银潮汐、金长影），不靠色相 |
| 不上屏 | 气质、四相、天赋、器物等第 | 台词与设定交代 |

## 12. 采用规则

每个条目标有采用层级：

| 层级 | 含义 | 例 |
|---|---|---|
| 锁定 locked | 跨剧一致，不改 | 九种力量源的定义与颜色、克制关系、存在之链 |
| 默认 default | 采用剧可改名、改数值、改细节 | 大部分条目；人口基准、药毒瓶数、头衔细节 |
| 可选模块 optional | 采用剧可整块关闭 | 四相、每阶之恶、神话阶、时空魔法、冒险者与讨伐等级、炼金蜕变、多神、转生 |

做法：

1. 复制 [adoption_template.json](adoption_template.json) 到剧目录，填库版本、采用条目 ID、模块开关与改动；或从模板里的题材预设包开始（狼人吸血鬼恋爱、骑士与教会、学院法师、妖精宫廷、深渊契约、史诗战争）。
2. 剧内改名改数值写在剧目录，不改本库。
3. 本库图片是概念参考（特效语言、服装与物件方向），不是剧中人物或最终镜头资产；人物仍走剧内的人物资产流程。
4. `inspired` 条目只借机制，外观与名称须原创；组合禁用见 appendix 第 3 节。
5. 多部剧都需要的新元素，再加回本库并升版本。
