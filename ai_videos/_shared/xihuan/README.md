# 西幻公共资料库

欧美奇幻（西幻）世界的基本元素库：结构上与[仙侠公共库](../xianxia/README.md)一样完整，但每一块的内在逻辑取自欧洲自己的传统——炼金术、骑士与行会制度、教会、凯尔特与北欧民间、希腊神话，以及研究过的现代西幻作品的通用机制。不含剧情与人物；每部剧从这里挑选需要的元素引入。

## 核心设计

- **分轴描述一个角色**：灵魂成色（超凡强度）、武艺手艺（技艺）、天赋（先天）、头衔（社会身份）分开，不像仙侠一条境界线统管一切。
- **灵魂成色 = 炼金金属**：铅 → 锡 → 铜 → 铁 → 汞 → 银 → 金，之上贤者之石、以太（可选）。成色是灵魂的纯度而不是修为储量；骑士靠功业、神职靠神恩、法师靠学位与秘仪，各路线升阶方式不同；寿命不随成色增长。四相与「每阶之恶」是可选模块。顺序是本库设定，依据见研究综述。
- **跨体系换算表**：金属成色、讨伐等级与狼人、吸血鬼、妖精、恶魔、天使、龙各族等级的大致对应。
- **九种力量源按「怎么得来」分**：学来的奥术、被赐予的圣光、被接纳的自然、谈判来的元素、取来的死亡、借贷来的深渊、生来的血脉、造出来的符文、挣来的勇武。
- **每个种族一条社会等级链**：狼人 Alpha/Luna、吸血鬼始祖与长老、妖精宫廷爵位、恶魔爵位、天使九级。

## 采用

复制 [adoption_template.json](adoption_template.json) 到剧目录，填库版本（当前 1.1.0）、采用条目、可选模块开关与剧内改动；模板里有六个题材预设包（狼人吸血鬼恋爱、骑士与教会、学院法师、妖精宫廷、深渊契约、史诗战争与龙）可作起点。剧内改动写在剧目录，不改本库。详见 [systems.md](systems.md) 第 12 节。

## 维护

- 唯一数据源是 `data/*.json`。改完运行 `python ai_videos/_shared/xihuan/build.py`，重建 `library.json`（管理 UI 读取）、`entries/*/card.md`、`entries/*/prompt_vN.txt`、`codex/`、`STATUS.md`、`index.html`。`--check` 只校验不写。
- 出图：`python ai_videos/_shared/xihuan/gen_images.py --jobs 3`。经 `tools/codex_image.py`，每次先写请求日志（归入 `ai_videos/_shared/request_log.md`），已有图跳过；没拿到图的条目记在 `qc/gen_attempts.json`，默认不自动重提，核实后用 `--retry ID`。
- 改图：条目 `image.version` 加一，写新 brief，出 `anchor_v2.png`，旧图保留。
- 验收：独立审图结论用 `qc/review_tools.py merge` 写入 `qc/reviews.json`，绑定图片 SHA256；换图即回到待验收。
- 已出图条目的 prompt 文件是请求记录，build 不覆盖；改出图描述必须升 `image.version` 重出（build 会报出描述已改但图未重出的条目）。
- 管理 UI：左侧「西幻」系列 → 公用资产。
