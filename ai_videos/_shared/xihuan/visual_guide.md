# 视觉规范

全库统一的屏幕语言（锁定）：观众靠光色认出力量，跨剧一致才有积累。

**通道规则**：特效颜色只表达力量源；强弱不靠颜色或光泽区分（第 2 节）；气质、天赋、威胁度、器物等第不上屏。同一画面最多两种力量光。

## 1.1 七芒太阳盘（圣光教会标志，锁定）

圆盘外七道等长的短楔形芒，内有一道细环。七芒对应七重天。不用十字、不用十六芒、不用直波交替芒、不用 sun-wheel。

## 2. 强弱怎么上屏

本库不设统一境界（见 systems.md 第 3 节），也没有表示强弱的光色或金属光泽。强弱靠三件事让观众看懂：

- **头衔看服饰与道具**：马刺、徽章、袍色、权杖、金链（见 TL 各条的图），不做成光效。
- **威胁度看规模与代价**：同一种力量，强者范围更大、更稳、代价更小；周围人的反应（逃散、跪伏、集结军队）比特效更能说明一级之差。
- **族内地位看行为**：Alpha 之令让人低头、长老入场时新生者退后，用调度和表演交代。

## 3. 物件

器物等第按来历分（IR01），不上屏颜色。道具组内部可用白 / 绿 / 蓝 / 紫 / 橙 / 红金区分等第，但不做成光效、不进字幕。有名之器以上可以有自己的微光，颜色随它所承载的力量源。

材质原则：药剂用真实的手吹玻璃、蜡封、亚麻绳；金属器物有使用磨损；符文用自创字形，不用任何真实字母。

## 4. 本库图片怎么用

| 用途标签 | 内容 | 能用于 | 不能当作 |
|---|---|---|---|
| magic | 背对镜头的兜帽施法者 + 一种效果 | 特效组的颜色、形状、材质参考 | 剧中人物、镜头构图 |
| character | 职业原型演示形体 | 服装方向、职业辨识元素 | 剧中角色定妆（人物仍走剧内人物资产流程） |
| race | 一男一女种族设定（全身） | 化妆与特征方向 | 具体角色 |
| race_closeup | 一男一女半身特写 | 眼、耳、皮肤等面部特征 | 具体角色 |
| portrait | 单人头肩特写 | 天生异相的面部记号 | 具体角色 |
| scene | 成长途径的典型瞬间（一至三人） | 这类事件的气氛与要素参考 | 剧中具体场次、角色 |
| allegory | 概念寓意画 | 帮助理解抽象规则（存在之链、四种气质等） | 剧中画面 |
| creature | 生物 + 人形比例剪影 | 体型比例与质感 | 动作设计 |
| item / item_set | 单件或同类陈列 | 道具组参考 | 精确尺寸与三视图 |
| environment | 位面与地点概念 | 世界观气质 | 剧中具体场景的空间布局 |
| emblem | 组织旗帜徽记 | 纹章风格参考 | 剧内组织标志（各剧需原创自己的纹章） |
| insignia_set | 头衔或威胁度徽记陈列（低→高） | 头衔道具参考 | — |

图片状态以 `STATUS.md` 为准：有图不等于已验收，验收绑定当前图片 SHA256。改图另写 `prompt_v2` 并出 `anchor_v2`，旧图保留。
