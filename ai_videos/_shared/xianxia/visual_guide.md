# 公共资产视觉规范

这是本库的创作选择，不是对历史建筑或器物的复原规范。基调为电影实物感的东方幻想：先看清材料、形状、用途，再看灵性效果。

## 共同识别语言

| 维度 | 默认选择 | 跨剧变化方式 |
|---|---|---|
| 石 | 灰石、真实层理、明确接地 | 地区可改石色，主结构不变 |
| 木竹 | 可见纤维、榫接或包箍 | 新旧、湿度、磨损为状态 |
| 铜铁银 | 铜绿、锻痕、磨边与有限反光 | 镶嵌材料改变需登记 |
| 玉 | 温润、半透、内部纹理 | 不能同时画成玻璃、塑料和发光晶体 |
| 纸绢 | 纤维、折痕、笔画方向 | 纸本和绢本按不同耐久变体 |
| 光 | 来源明确、覆盖面积有限 | 休眠/激活/过载分状态 |
| 色 | 五行相性或构件用途 | 不用同一色同时编码三个等级 |
| 字 | 基图无可读字、只有原创装饰纹 | 准确文字用后期排版固定 |

## 各类出图目标

| 类 | 画面重点 | 本轮图像边界 |
|---|---|---|
| 符 | 完整纸边、符胆、笔路、耗用载体 | 一张基型，不含燃尽动画 |
| 丹药 | 成品、表面纹理、封装容器；大小可读 | 不声称真实药物或可用配方 |
| 法器 | 完整轮廓、主功能结构、材料接点 | 单角度概念锚点 |
| 仙器 | 可辨用途和规则接口 | 不靠更大光晕替代结构 |
| 灵体/骨相/瞳术 | 无人像的抽象结构或展示标本 | 不创建角色肖像、人体解剖证据 |
| 灵材 | 原始形状、断面、纤维/矿皮 | 不冒充真实物种标本 |
| 阵法 | 节点数、连接路径、中心/边界 | 静态整体设计，非实时模拟 |
| 建筑 | 出入口、承重、通行、留白 | 概念空间，不是可施工蓝图 |
| 地貌 | 岩性、地形、远近层次、光源 | 不作为真实地理照片 |
| 特效 | 起点、路径、作用区、衰减 | 非透明PNG特效层，不是动画 |
| 日用品 | 可操作结构、尺度线索 | 无人物手部演示 |

## 四套可选择的环境外观

| 套系 | 材料与空间 | 适用资产 | 固定边界 |
|---|---|---|---|
| 山地青灰 | 灰石基、木柱、深灰瓦、雾中清晰路径 | 山门、洞府、栈道、宗门殿 | 高差必须有路径或已定义交通 |
| 园林温润 | 小院、水渠、木廊、低饱和陶瓦 | 药圃、客舍、亭、静室 | 水源与排水不可互相冲突 |
| 地火铜赭 | 黑石、旧铜、耐热陶、局部暖光 | 丹房、器坊、材料仓 | 火源、烟道、冷却区分离 |
| 仙域淡金 | 淡石、细金属边、低密度云、稳定界面 | 仙宫、浮岛、跨界港 | 悬浮由明确规则承载，不能默认所有物件都失重 |

这些是换装方向，当前 PNG 仅对应已生成的具体外观。没有生成的套系变体不能算已有图片。

## 空间组合模块

通用构件为：基座、台阶、柱网、门洞、梁架、屋面、回廊、水渠、储物壁、工作台、节点基座与安全边界。它们在本版本属于设计词汇，未拆成独立三维组件。

入口必须接到可站立的地面；台阶的首末级不能悬空。炉具区给上部排烟/散热与侧向检修空间。书架、储材架和药田之间留连续通道。若存在二层，明确实际楼梯或启用的交通机制；不能仅画一扇高处门让使用者自行猜测。

建筑图可用于确定材质和气氛，不能从单幅透视反推出精确尺寸。剧级布局需要按米记录；同一场地的东西南北、主入口、炉火/水源、地标及不可穿越边界应固定。

## 变体与继续出图

优先级依次是：实际要用的状态→实际镜头方向→局部关键结构→其他装饰版本。新请求引用原 PNG 和明确的保持项，输出 `anchor_v2.png` 或状态变体文件，保留旧版。不得通过裁切或把同一图换名宣称新增视角。

每张候选图与其原始 prompt、请求日志、生成结果和验收证据绑定。独立审图使用原图；典型必须修订项包括：关键身份或主材质错误、功能形制误读、核心结构数量错误、把资产变成人物、主要物件被截断、空间严重断裂。轻微构图偏差或偏好差异记录备注，避免无限重抽。

## 镜头资料包前的验收

概念验收只判断这张图能否固定设计。正式用于视频还要核对：所需侧面是否存在、是否与具体场地的 blocks 一致、画面时段是否匹配、动作是否会暴露未定义的背面、准确牌匾是否需要后期文字，以及资料包引用的图像 SHA 是否对应当前文件。

## Foundation 图像用途

| 类型 | 图像应回答的问题 | 采用边界 |
|---|---|---|
| 物件 | 完整外形、材料、操作接口在哪里 | 不自动包含制造配方 |
| 生灵种型 | 器官如何支持能力，完整身体能否辨认 | 不是具名人物或具体个体 |
| 依附灵体 | 意识/灵性依附什么载体，如何表现 | 不将匣灵、泉灵等统一兽化 |
| 功法过程 | 条件、输入、作用路径和结果能否串起 | 演示者仅为无身份形体，不建立演员资产；静图不证明时间或流量 |
| 组织徽记 | 组织识别结构是什么 | 徽记不代表全组织建筑、人物、服制已完成 |
| 场所 | 承重、入口、用途和连续通行是否成立 | 同主体正侧背用于概念对齐，剧级尺寸另定 |
| 结构状态 | 构件数、连接和状态差异是什么 | 非现实解剖或工程蓝图 |
| 阵法空间 | 节点、边界、来源和隔离点在哪里 | 不由额外光圈增加作用范围 |

功法图依次表现准备、作用、结果；资产卡仍为机制依据。图中的同色光线不自动具有同一功能。任何图像新增了主数据未定义的能力、物种或结构，需改图或明确修订主数据，不能用“艺术表达”略过矛盾。
