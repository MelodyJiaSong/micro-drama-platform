# 术语、组合与跨剧采用手册

本页给出本库的制作语义。传统词语可能在不同作品或宗教语境中有其他解释；以下不宣称统一历史定义。

## 术语检索

| 词 | 本库语义 | 区分点 |
|---|---|---|
| 灵气 | 环境中可引导的能量 | 环境密度不是人物境界 |
| 灵力 | 经载体转换后可使用的能量 | 储量和输出速率分开 |
| 真元 | 剧可选择的高凝聚能量称谓 | 不默认另增一套境界 |
| 仙元 | 仙域扩展的能量 | 凡界需转换和限流 |
| 丹田 | 储能与循环的空间称谓 | 不把器官图当医学图 |
| 经脉 / 灵脉（体内） | 引导能量的结构通路 | 与地下灵脉区分 |
| 灵脉（地理） | 环境能量的持续输送带 | 不等于开采后无限再生 |
| 周天 | 一次闭合循环 | 不默认对应真实时长 |
| 神识 | 有带宽、有范围的灵性感知 | 不默认读心、全知 |
| 识海 | 神识组织空间的视觉隐喻 | 不自动是可住人的实体世界 |
| 丹核 | 结丹阶段的核心结构 | 与可携丹药不同 |
| 元婴 | 本库独立神识载体 | 库图使用抽象光核，不创建人物 |
| 法域 | 一定边界内持续生效的规则 | 领域外没有自动同等作用 |

| 渡劫 | 突破承载边界时的考验事件 | 不强制每次都雷击 |

## 咒式与执行语法

三体系扩展的族源、灵智、修行道路与组织籍属口径，见 [世界规则](systems.md) 的「三体系 Foundation」。灵兽／神兽是种型标签，化形是技能，魔修是道路，入魔是失衡状态，都不能直接替代妖族／魔族身份。秘术是特殊代价的方法；秘籍是记载方法的载体，两个维度分开登记。

暂不绑定真实宗教经咒、演员声线或人物招式。下面十二种执行结构是可复用机制模板，具体词句由剧选择；无需为声音概念强做一张假道具图。

| 模板 | 执行顺序 | 可连接资产 | 中断 / 解除 |
|---|---|---|---|
| 触发式 | 识别载体→确认目标→释放 | TAL001、TAL002 | 未确认目标可撤销；释放后扣储能 |
| 维持式 | 建立闭环→稳定供能→周期校验 | ARR003、ARR019 | 断供渐弱，防护不永久残留 |
| 封闭式 | 识别接口→围合→锁定 | TAL004、ARR002 | 结构断裂或授权解封 |
| 牵引式 | 标记来源→建立路径→限制流量 | ART004、ART015 | 超程先断连接，物质不消失 |
| 感知式 | 校准样本→扫描→比较差异 | TAL012、ART003 | 遮蔽、噪声、样本失效 |
| 配对式 | 两端互认→握手→允许短讯 | TAL010、UTL021 | 对端离线只显示失败，不假装送达 |
| 记录式 | 载体清空→开启窗口→封存 | TAL011、ART026 | 满额停止，记录不能倒改过去 |
| 绑定式 | 校验访问权→建立控制→留解绑口 | ART001、UTL001 | 撤销或相性失配后降效 |
| 转换式 | 测原能量→限流→转换→散余能 | IMM012、ARR007 | 不兼容即关闭，守恒有损耗 |
| 校正式 | 读取偏差→小量反馈→复测 | ART032、UTL007 | 超出量程不输出伪精确结果 |
| 跨界式 | 两端锚定→验证承载→连接→关闭 | ARR014、IMM001 | 传送与航行分开，故障处理各自定义 |
| 解封式 | 识别锁型→验证权限或消耗破拆→解除 | TAL015、TAL019 | 未知锁型不能万能解开 |

状态词汇是可选超集：`idle → armed → active → depleted / interrupted`。一次性纸符和丹药耗尽后终止，须新载体或新批次；可充能器具在完整度检查及补能后才进入 `recover → idle`。中断不等于耗尽，中断后的恢复条件按机制另定。持续式的 `active` 持续耗能；一次式只扣本次储能。动作和声音是触发通道，沉默、遮挡或肢体受限是否影响执行由剧明确选项。

| 炼器设施 | BG005 + UTL009/011 + MAT002/008/009 | 材料量、控制距离、急停与破损 |

## 跨剧采用步骤

1. 选定整套修炼配置，决定是否开启仙域、空间、特殊灵体等扩展。暂不采用的规则保持关闭。
2. 按 ID 选资产，将采用模板复制进该剧资料，记录库版本、系统版本、资产版本和局部 ID。
3. 看图核对当前 SHA 和独立验收。使用备注图时读具体备注；需修订或未审图不作为正式锚点。
4. 配置适用的范围、持续、冷却、能源、载重、容积、人数、价格与币种。`null` 是未定，`n/a` 是不适用；两者不同。
5. 写显式覆盖。换门派标记、天气、磨损或时段需登记变体；主轮廓、节点数或能力机制改变则升版本。
6. 到具体拍摄场地时，建立实际空间方向与 `planning/blocks.toml`，补确实要用的方向图；随后按既有镜头资料包流程同步和检查。

## 版本规则

`asset_id` 稳定。补充不改变外观和能力的资料可补丁升级；能力边界或主结构变化需另立版本，并保留原图。`variant_id` 区分时段、状态和材质；同一名字不构成同一资产。审核绑定 PNG 哈希，换文件后旧审核自动失效。

任何采用关系都不能反向把具体剧的规则写成全库事实。若某剧把凝基丹设为必定突破，只在该剧 `overrides` 中记录；共享卡仍保持“辅助、不保证”。
