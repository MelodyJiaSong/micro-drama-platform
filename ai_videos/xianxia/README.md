# 仙侠

仙侠剧系列。现阶段先建设共用世界规则与资产，后续具体剧目放在本目录的各自子目录中。

管理 UI 左侧点“仙侠”进入公用资产总览；展开“仙侠 → 公用资产”可浏览设定与图片。

公共资产唯一源为 [仙侠公共资产库](../_shared/xianxia/README.md)，由 `series.json` 的 `shared_library` 引用。这里不复制图片或规则；具体剧采用时固定资产 ID、版本和图像指纹。

公共库v1.1已补入仙家、妖族、魔族三套Foundation，覆盖26个设定维度；资产定义443项（原256项加新增187项）。新增条目图片尚未生成，具体完成状态见公共库STATUS；本系列仍未创建具体剧目、故事或人物。
