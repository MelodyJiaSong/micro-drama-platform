有两个保留：

1. **小节数有争议，但证据支持「对」**。两个 librosa 跟拍器只在源 40–50 s（成片 0:40–0:50 和 1:24–1:34 两次）这一段不一致：我的 hop 256 跟拍器在源 45.5–48.5 s 把拍间隔压到 348–372 ms，数出 113 拍；构建脚本的 hop 512 在源 40–42 s 拉到 418 ms，数出 112 拍。其余位置两者相差 ≤ 12 ms。用和声节奏做裁判：按 112 拍计，全曲和弦变化拍位始终一致；按 113 拍计，源 40–50 s 前后会凭空错一拍。所以判断 112 拍是对的，接点的小节相位没有问题。我原先想用鼓型（kick / snare 按八分位置统计）做第二个裁判，但对照组里只有 21% 能在零偏移处匹配，这个方法在这首曲子上没有分辨力，已放弃。
2. **乐句层面没法测**。28 小节不是 8 小节的倍数（28 mod 8 = 4），如果这首曲子按 8 小节分乐句，跳回点可能落在乐句的一半。测量上接点没有新颖度峰，频谱和电平也都连续，大概率听不出，但「乐句是不是被截短了」只有人耳能判断。

结论：从测量看，这是一处干净的拍点 / 小节对齐跳剪，没有错拍、换速、电平坑或爆音。和 v1 那个 4 s 交叉淡化（-4 LU 凹陷、154 / 159 BPM 打架）相比是实质性改善。

### F2【minor】同一段 43.8 s 连放两遍：0:35.97–1:19.76 = 1:19.76–2:03.55

- 证据：见第二节，逐样本相同。源 40.9–50.2 s 是一个独立小段（前后各有一个新颖度峰，长约 9.3 s；两个跟拍器正是在这里分歧，说明节奏上有些特别，比如过门或切分），所以观众会在 **0:40.1 和 1:23.9 各听到一次同样的段落转换**，相隔 43.8 s。

### F4【minor】结尾实际是「渲染器 3 s 淡出」，源曲是急停，不是自然收尾：3:34.47–3:37.47

- 证据：
  - 源 A3 一直保持满电平（20 ms RMS -17 至 -21 dB），没有渐慢，也没有延长和弦；
  - **173.94 s（成片 3:36.93）**在约 100 ms 内掉了约 20 dB；之后只剩高频残响（<200 Hz 占比 0，质心 3.2 → 2.4 kHz），到文件结束（174.48 s）还在 -43 dB，没有完全衰减完。
  - 渲染器在最后 3 s 线性淡出（实测增益 3:35.5 为 -2.3 dB，3:36.5 为 -7.8 dB，最后 0.5 s 约 -11.5 dB），所以急停发生在淡出增益约 -15 dB 的时候。
  - 成片 3:36.96 起 < -40 dB，3:37.17 起 < -60 dB，3:37.40 起 < -80 dB，最后 50 ms 峰值 2.6e-4，最后一个样本约为 0。
- 判断：片尾干净，不会听成「中途被剪掉」。但观众听到的是一个普通的淡出，不是 `09_music_bed_v3.py` 文档和 `qc.md` 说的「原曲高潮 + 自然收尾」。`qc.md` 写的「最后 0.5 s 自然衰减（-17 → -43 dB）」数值上对，但这其实是急停加一截残响，而且残响在 -43 dB 处就被文件结尾截断了。
- 修法（可选）：先人耳判断源的急停算不算一个完整的「stop 结尾」。如果算，可以把渲染淡出缩到最后约 0.5 s，只处理残响，让急停原样出现；如果听起来像被截断，就保持现在的 3 s 淡出。
