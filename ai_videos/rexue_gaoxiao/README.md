# 热血高校（预告片）

原创现代校园·不良番·拳脚称王短剧，**冷酷暴力美学**调性。本期产物 = 一条 **60s 预告片**，用于验证画风与燃感，验证通过后再决定是否铺成多集。

- **task_name**：`rexue_gaoxiao`（pinyin；中文名见本文件）
- **形态**：short 单片预告（9:16 母版，60s，约 12–18 镜）
- **题材**：纯肉搏不良高校，零异能/零特效/零系统
- **主角**：姜川野——沉默狠人转校生，笑里藏痛
- **反派**：陈劲——黑石高中现任霸主
- **反派副手**：柴宇宁——陈劲的冤种副手，块头唬人却憨怂、经常被误伤（喜剧担当）
- **配角**：廖彦廷——第一个跟随姜川野的兄弟
- **暗线**：泳池旧事——姜川野来黑石的真正理由
