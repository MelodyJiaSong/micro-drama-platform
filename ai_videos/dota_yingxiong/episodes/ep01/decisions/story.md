# EP1 · 斧王 · 故事决策记录（集级）

2026-10-18：第一至三稿是带因果链的战斗小故事（两轮独立冷读）→ **第四稿（follow-up 003）改为无剧情的技能展示**：一段亮相加四个技能模块，每个模块自带站位、可单独复用；技能外观改由技能卡锁定。

本集体验：在宏大的天灾兵道上，第一次绕着一个真实立体的斧王看个够，再看他把四个熟悉的技能一个一个放出来，每一个都比记忆里更绚丽。

Vision：「宏大绚丽的战场」→ 斜俯开场与收尾给出整条兵道、尖塔与河的尺度，地面霜、雾、冷光；「更真实、更立体的英雄」→ 亮相环绕背面、侧面、正面、另一侧，并贴地仰拍；「更绚丽的技能」→ 四个模块各自按技能卡的物理光源与可见结果；核心「同一个技能在哪一段都是同一个样子」→ 本稿不再描述技能外观，只写「按 `k65N`」，外观、动作、声音都引用技能卡。

## 片种、时长与结构

片种短视频、无剧情（用户 2026-10-18）。`episode_seconds` 60–120 秒；粗估亮相约 25 秒，每个技能模块约 15–20 秒，合计约 90–105 秒，分镜时核算。

结构判断（无共用指南，判断依据：用户要求技能可复用、前后一致）：每个技能模块开头自带目标与站位，不依赖上一模块的结果，所以可以单独剪出来放进别的视频；模块之间的连续性（地上已有的焦痕、倒下的树人）只在本集剪辑时顺带保留，不作为模块的前提。放弃第三稿的因果链（德鲁伊逃跑、食尸鬼追击），因为它把四个技能绑成一条不能拆开的线。

## 六个问题

无剧情的展示片只答到最小：1 关于斧王；2 他要把冲上来的近卫兵一个个放倒；3 敌人多、有远程；4 用四个技能分别对付围攻、远程、贴身围砍、残血；5–6 每个模块各自兑现，不设失败与反转。

## 目标影响

本集内目标：把冲上来的近卫兵放倒（无剧情，没有跨集主目标）。

| 事件 | 影响 | 为什么 |
|---|---|---|
| 近卫兵线冲上来 | − | 敌人多 |
| 狂战士的怒吼拽住树人 | + | 敌人集中到他身上，食尸鬼解围 |
| 德鲁伊远程打他 | − | 他够不着 |
| 战斗饥渴点燃德鲁伊 | + | 它跑不快 |

| 残血树人挡路再砸 | − | 拦住他 |
| 淘汰之刃劈开它 | + | 终结；食尸鬼被激得冲出去 |
