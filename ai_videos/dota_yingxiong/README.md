# DotA 英雄

## Vision（观众体验）

> **宏大绚丽的战场上，比记忆里更真实、更立体的英雄，放出比记忆里更绚丽的技能。**

核心：把每个英雄和他的技能做成真的——同一个技能，无论在哪一段里出现，都是同一个样子。

全剧 Vision：用户 2026-10-18 定方向（follow-up 003：现阶段只要场景宏大绚丽、人物更真实立体、技能更绚丽；剧情以后再加），措辞由代理起草，**用户 2026-10-18 确认（follow-up 006）**。每个模块创作与审查都对照它。

| 体验 | 怎么做到 | 主要落在 |
|---|---|---|
| 场景宏大绚丽 | 两方战场按 `battlefield.md`：近卫绿林金光、天灾霜冻黑岩，远景有尺度、有真实光源 | 资产（背景）、影视改编（建立镜头） |
| 人物更真实立体 | 真人与实拍级特效生物；镜头绕人物、贴地仰拍、越肩，给出正面与侧面（`world_rules.md` §1） | 资产（人物）、影视改编（运镜与角度） |
| 技能更绚丽 | 特效有物理来源、照亮人物与地面、打在小兵身上有可见结果（`world_rules.md` §3） | 技能资产（各英雄目录下 `skills/`）、Prompt 编译 |
| 技能前后一致 | 每个技能一张技能卡，锁定动作、特效、受击与声音；任何一段用到同一个技能都引用同一张卡 | 技能资产 |
| 剧情 | 现阶段没有剧情；每段 demo 只是一个英雄的技能展示战斗；剧情以后再加 | 故事 |

围绕《魔兽争霸 3》DotA 地图（DotA 1 / DotA Allstars）的英雄介绍短片。第一步每个英雄一段 1–2 分钟 demo：正面、侧面亮相，然后在搭好的场景里对着几个小兵逐个放出 4 个技能。

**用户定（2026-10-18，follow-up 001）**：画面为**真人电影质感**（魔兽 3 模型翻译成真人奇幻电影里的人物、生物与场景，准则见 [world_rules.md](2_世界观人设/world_rules.md)）；片种为**短视频，每段独立、没有连续剧情**（`workflow.json` `format: short`；共用片种页目前只有电影、连续剧，短视频页待故事创作开始时补）；**先备齐全部资产**（人物、背景、道具等），再选先做哪个英雄。
