# DotA 英雄

## Vision（观众体验）

> **宏大绚丽的战场上，比记忆里更真实、更立体的英雄，放出比记忆里更绚丽的技能。**

核心：把每个英雄和他的技能做成真的——同一个技能，无论在哪一段里出现，都是同一个样子。

> **Claude / Codex 共享原声与技能参考**：[交接索引](0_research/media_refs/shared_handoff.json) · [当前统计](0_research/media_refs/coverage.json) · [本地试听／实机](0_research/media_refs/index.html) · [版本与限制](0_research/media_refs/README.md)。
> 做任一英雄的声音或技能研究前，先读该英雄 `ref/shared_media_refs.json`；本英雄的原声路径、视频与时间点在索引指向的 `reference.json`。索引路径相对于该索引文件，共享清单内的媒体 `path` 相对于仓库根。
> 已补至112位有带声音实机参考；旧记录中的“未下载／仅19位”是首轮状态。当前素材含6.85k高清改模、6.83d AI等版本，逐技能原版声画与干净音轨仍待验收；原版资料只供研究，不自动上传生成服务。


全剧 Vision：用户 2026-10-18 定方向（follow-up 003：现阶段只要场景宏大绚丽、人物更真实立体、技能更绚丽；剧情以后再加），措辞由代理起草，**用户 2026-10-18 确认（follow-up 006）**。每个模块创作与审查都对照它。

| 体验 | 怎么做到 | 主要落在 |
|---|---|---|
| 场景宏大绚丽 | 两方战场按 `battlefield.md`：近卫绿林金光、天灾霜冻黑岩，远景有尺度、有真实光源 | 资产（背景）、影视改编（建立镜头） |
| 人物更真实立体 | 真人与实拍级特效生物；镜头绕人物、贴地仰拍、越肩，给出正面与侧面（`world_rules.md` §1） | 资产（人物）、影视改编（运镜与角度） |
| 技能更绚丽 | 特效有物理来源、照亮人物与地面、打在小兵身上有可见结果（`world_rules.md` §3） | 技能资产（各英雄目录下 `skills/`）、Prompt 编译 |
| 技能前后一致 | 每个技能一张技能卡，锁定动作、特效、受击与声音；任何一段用到同一个技能都引用同一张卡 | 技能资产 |
| 剧情 | 现阶段没有剧情；每段 demo 只是一个英雄的技能展示战斗；剧情以后再加 | 故事 |

围绕《魔兽争霸 3》DotA 地图（DotA 1 / DotA Allstars）的英雄介绍短片。第一步每个英雄一段 1–2 分钟 demo：正面、侧面亮相，然后在搭好的场景里对着几个小兵逐个放出 4 个技能。

**用户定（2026-10-18，follow-up 001）**：画面为**真人电影质感**（魔兽 3 模型翻译成真人奇幻电影里的人物、生物与场景，准则见 [world_rules.md](2_世界观人设/world_rules.md)）；片种为**短视频，每段独立、没有连续剧情**（`workflow.json` `format: short`；共用片种页目前只有电影、连续剧，短视频页待故事创作开始时补）；**先备齐全部资产**（人物、背景、道具等），再选先做哪个英雄。

**人物视频（建立视频）本剧特殊安排（用户 2026-10-18 follow-up 013）**：人物视频放在每段 demo 开头播放，所以用 **16:9、约 10 秒（最后 2 秒定住收尾，follow-up 023）、全景看到全身**（不是通用的 9:16 / 4 秒；follow-up 016），正面开口说一句原台词、**嘴型与台词同步**，再转身交代侧面与背面、回到正面；挂本剧自有声音参考（卡里「叫声设计」+ `ref/audio/*.mp3`，暴雪原声在 `ref/audio/original/`，不挂）。样板 `characters/天灾_scourge/c65_Axe`。

**剧集交片：每次改动给整场剪辑（用户 2026-11-03，follow-up 350）**：剧集（`episodes/`）里任何一次改动——改分镜后重出、换条、重画镜组板——做完就把受影响的**整场**按镜组顺序剪成一条完整视频，放 `scenes/sN/edit/final/sN_assembly_v{N}.mp4`（另出左下角标镜组与条号的 `_review` 版，决定写同名 `.json`），交片时给预览链接：整场视频 `http://127.0.0.1:5174/file/<视频路径，URL 编码>`、场故事板 `http://127.0.0.1:5174/scene-preview?path=<场目录，URL 编码>`，另附改动镜组的 `group-preview` 链接；每个链接单独一个代码块。

**demo 出片与剪辑标准（用户 2026-10-25，follow-up 217，新英雄必读）**：[demo_standard.md](demo_standard.md)。新出的亮相改 **12 秒**；**四个技能条合计必须 ≥ 53 秒**，各条时长由代理按技能分配（预算表写进英雄卡，随第一张时间轴交审），原片不够时每条首尾可各加 0.5 秒停顿补足，再不够就加长重出；每条开头留 1–2 秒起势（只有预备动作，不出特效）、结尾留 1–2 秒收势（结果可见、余波消散、人物回站姿），**写进出片 prompt**（剪辑里只允许上述 0.5 秒停顿）；剪辑转场改为**不重叠压暗**（前段渐黑 0.4 秒、后段渐亮 0.4 秒，不吃时长），沿用英文标题卡 + 角标 + 淡出，成片 ≥ 65 秒；技能主体动作不留空、不慢放，要填时间就让小兵多挨几下再死（攻击频率不变），每条下载后代理先跑 `tools/motion_check.py` 并看 4 fps 拼图做流畅自检，有慢动作嫌疑自己改 prompt 重出（follow-up 245）。本条取代上面亮相「约 10 秒、最后 2 秒定住」的旧规格；已定版的六个英雄 demo 按用户要求逐个重做，从冰女开始。
