# D11 英雄原台词 · 近卫智力（c40–c59）

**用途**：给 DotA 英雄介绍 demo 找原台词。收的是每个英雄在 DotA 1 里借用的 WC3 单位语音组的**全部台词**（选中、移动/确认、攻击、战吼、连点烦躁等），每句英文原文、中文意译、WC3 文件路径与 wiki 音频页。用户已同意含专名的原句也可用（follow-up 002）。

**版本**：DotA Allstars **6.83d**（最后正式版，见 d01/d04）。DotA 1 英雄没有自己的配音，借 WC3 单位的语音组；Dota 2 台词不是 DotA 1 的，未收。

**覆盖**：近卫智力 20 名英雄（c40–c59）全部写到。
- 18 人有人声，用 16 套 WC3 语音组：萨尔组（圣骑士、干扰者）和猛禽德鲁伊组（风暴之灵、大魔导师）各被两人共用。
- 2 人无人声：仙女龙（仙女龙叫声）、双头龙（奇美拉吼叫）。
- 16 套语音组共 **325 条**文件（其中人声台词 324 条，另 1 条是修补匠死亡音）。按英雄分节重复列出后，表格合计 362 行。
- d04 记「未取证」的神谕者（WC3 牧师组）本文已补全。

**取证与置信度**
- **英雄用哪套语音 ✅ 地图直读**：6.83d 英文版地图 `Units\UnitUI.slk` 的 `unitSound` 字段，20 人逐一核对，与 d04 写的语音组全部一致。
- **台词原文 ✅**：warcraft.wiki.gg 的「Quotes of Warcraft III」各阵营分页（Human Alliance / Night Elf Sentinels / Orc Horde / Neutral / Neutral Heroes），用 MediaWiki API 取的 wikitext（2026-10-18）。每句后面的文件名是 wiki 标注的原始语音文件名。PlayDotA 存档里给每个英雄列的两句（见 d04）都能在对应组里找到，只有修补匠一句转写有出入（见 c52）。
- **wiki 音频页 ✅**：表中 325 个文件名都用 API 查过 `File:` 页，全部存在。链接格式是 `https://warcraft.wiki.gg/wiki/File:<文件名>`，页面上可直接试听和下载。**本次没有下载任何音频**。
- **WC3 文件路径**：文件名 ✅。目录里地精工兵、食人魔、破法者三组 ✅，这三个目录在 6.83d 地图脚本里出现过。其余目录按 WC3「Units\阵营\单位名\」惯例推断，标「⚠️目录」，下载前用 MPQ 工具核对。
- **中文**：WC3 官方中文配音文本**没找到**（中文网页搜索无可用台词表）。表中中文全部是**意译**，专名按国服通行译名，咒语/种族语句写「无官方释义」。
- **出处缩写**：WQ-Human / WQ-NightElf / WQ-Orc / WQ-Neutral / WQ-NeutralHeroes 分别指 `https://warcraft.wiki.gg/wiki/Quotes_of_Warcraft_III/` 下的 `Human_Alliance`、`Night_Elf_Sentinels`、`Orc_Horde`、`Neutral`、`Neutral_Heroes`。「wiki 注」是 wiki 原注（英文，多为流行文化出处或双关说明），照录未译。
- 不调用任何收费服务。

**类别说明**
- 出场 Ready：单位训练/雇佣完成时说。战役英雄组（穆拉丁、吉安娜、萨尔、玛法里奥）没有这一句。DotA 从酒馆选英雄时会不会播这句没有核对 ⚠️。
- 选中 What／移动·确认 Yes／攻击 Attack／战吼 Warcry／连点烦躁 Pissed：WC3 标准五类。Pissed 是连点同一单位时的彩蛋句，多是流行文化梗。
- 测试版 ⚠️：wiki 标 (Beta) 的句子，只在 WC3 测试版里有，正式版不触发。
- 嘲讽 Taunt ⚠️：只有穆拉丁组有，wiki 给的是 .mp3 文件，不像 1.x 经典版的 .wav 语音，疑似重制版新增，DotA 1 不会播放。
- 死亡（非台词）：只有修补匠组单列，是呻吟和机械声。

**选句原则（英雄卡建立视频台词）**：在该组里选最有代表性、又符合英雄性格的一句，3 秒内能说完。连点烦躁句里的 meta 梗和流行文化梗（如「Click me baby, one more time.」）虽然出名，但会打断观众的角色代入，只在推荐里提，不放进英雄卡。两人共用一组时，各选不同的句子。原卡时间轴按两句分说的（沉默术士、修补匠、工程师、食人魔魔法师、大魔导师），保留两句结构，两句都换成本组原句。

## 地图脚本对本组语音的额外用法（DotA 地图自己的触发）

6.83d 地图**没有为这 20 人导入自制语音**。地图导入的人声只有连杀播报（`Sounds\firstblood.mp3`、`Double_Kill.mp3`、`GodLike.mp3` 等），与本卷英雄无关。不过地图脚本 `war3map.j` 直接调用了下面几条 WC3 原语音（脚本追踪 ⚠️）：
- **地精工程师**：学会「自杀攻击，冲啊！」（A06B）后会注册一个触发：下达命令 ID 852040（推断就是该技能的 selfdestruct 命令 ⚠️）且目标点在 700 码内时，在目标点播放 `Units\Creeps\GoblinSapper\GoblinSapperYesAttack4.wav`「We come in peace!」。遥控炸弹的「引爆」（A0AM/A0A3/A0A4/A02T/A1FZ/A1WF）炸死英雄时，在死者位置播放 `GoblinSapperYesAttack1.wav`「Good night!」。
- **`-quote [编号]` 聊天命令**：从 65 句 WC3 连点烦躁语音里播一句，不带编号就随机，并提示「You have randomed quote number N」。本卷相关的是破法者 Pissed1–5（沉默术士）、食人魔 Pissed1–5（食人魔魔法师）、地精工兵 Pissed1–7（地精工程师）。其余是巫医、恐惧魔王、炼金术士、火枪手、暗影猎手、剑圣、熊猫酒仙。命令名与处理函数的对应由字符串 `"-quote"` 与 `SubString(…,7,…)` 推断 ⚠️。
