# 两方基地地形调查

从本次已校验的6.83d地图读取129×129个顶点（128游戏单位间隔）；主基地建筑中心采样为1024，泉水、两座建筑商店及商人/出生圈中心采样为1152。两区差128游戏单位；12单位/米的电影工作比例下约10.67米，此米制并非游戏官方尺度。

二进制结构与高程计算参照 [HiveWE 地形格式文档](https://github.com/stijnherfst/HiveWE/wiki/war3map.w3e-Terrain)，没有复制或运行外部代码。原文件sha见 terrain_samples.json。边坡使用高度场线性插值，未重建游戏专用悬崖、坡道模型或贴图；建筑底面只按中心高程放置，完整地基接地还需精模核对。
