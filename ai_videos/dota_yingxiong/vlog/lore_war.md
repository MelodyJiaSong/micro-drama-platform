# 战争的第一层：两方为什么打（草案 v5，待用户 review）

> follow-up 314。用户 2026-11-01：战争逻辑分三层；第一层要一个两方都认为自己正义的理由。
> 用户再定：**灵脉有限即可，不用非要变弱**。
> 用户定（v4 review）：**灵脉变弱可以，双方抢夺资源，逻辑通顺**；不用纠结谁先越过了河，反正战争开始了；**不要「亡者也是我们的人」「没有人被抛下」这类说法——双方都是为了争夺有限的资源**。
> 本剧原创设定，参照《魔兽争霸 3》取意，不冒充官方剧情。前几版的「永恒之泉被劈开」「冰川水库」「古老约定」「生死观之争」全部撤下。

## 1 争的是什么：一条有限的「灵脉」

- 这片土地底下有一条**灵脉**——不是水，是生命力本身。泉水能治好伤、古树能走路、死者能站起来，用的都是灵脉的力量。
- 灵脉沿星球的自转轴贯穿两端，在两端冒出地面：**一端是近卫的泉水，另一端是天灾的泉水**（原版地图里两口泉本来就是同一个模型）；灵脉的支流在赤道涌出，汇成环形大河（星球设定见 [world_globe.md](world_globe.md)）。
- 两边各有一颗「**心脏**」，像泵一样从灵脉里取力：**世界之树**养着近卫的森林、古树和士兵；**冰封王座**养着天灾的军队。
- 灵脉的总量**有限**。一边多取，另一边就少。

## 2 战争的逻辑

1. 两边的人越来越多，灵脉的力量越来越不够分。
2. 为了让自己的人活下去，两颗心脏都越取越多；越取越多，灵脉就越不够分。
3. 两边都明白一件事：**只要对方的心脏还在，自己就永远不够；推倒对方的心脏，整条灵脉就归自己**。
4. 所以战争开始了，而且只有一种结束方式——**摧毁对方的主基地**（正好就是游戏的胜负规则）。
5. 每三十秒，两颗心脏都把灵脉的力量变成一队士兵送上前线：兵线永远不停，因为谁停下，谁的人就先饿死。

## 3 两边各自的正义：都是为了让自己的人活下去

| | 近卫 | 天灾 |
|---|---|---|
| 心脏 | 世界之树 | 冰封王座 |
| 养着谁 | 整片森林、古树、德鲁伊和近卫的英雄 | 北方的军队、亡者与天灾的英雄 |
| 为什么而战 | 推倒冰封王座，让灵脉的力量流回近卫，森林才能活下去 | 推倒世界之树，让灵脉的力量流回天灾，北方才能活下去 |
| 眼里对方的错 | 冰封王座取得太狠 | 世界之树根扎得最深，抽得最多的是它 |

- 两边都不是为了作恶；**都在做同一件事：保护自己的人，从有限的资源里多抢一份**。
- 两边都觉得是对方取得太多——这是双方互相指责、都认为自己有理的地方。

## 4 地图上的「证据」：都在说同一件事

| 地图上的东西 | 说明 |
|---|---|
| 两口泉一模一样 | 同一条灵脉的两个出口 |
| 中间的河 | 灵脉最浅的地方，两边必争 |
| 天灾那边发黑龟裂的土地 | 灵脉不够分时最先枯掉的地方（近卫说是天灾抽干的，天灾说是世界之树抽走的） |
| 每 30 秒走出来的树人 / 食尸鬼 | 两颗心脏把灵脉的力量变成士兵 |
| 泉水能治伤 | 灵脉的力量在泉眼最浓 |
