# DotA 英雄 · 世界规则与真人化改编准则

> 用户定（2026-10-18，follow-up 001）：**真人电影质感**；片种为无连续剧情的短视频，每个英雄一段 demo。
> 事实出处：`0_research/dossier.md` 与 `parts/d01–d08`（版本锚点 DotA Allstars 6.83d）。本文是**创作选择**：怎样把魔兽 3 的模型与特效翻译成真人电影画面。各资产卡以本文为准；与某张卡冲突时改卡，不改本文（改本文由用户定）。

## 1. 总原则：认得出，像真的

1. **认得出**：每个英雄保留 6.83d 模型的识别层——种族、体型轮廓、主色、武器、坐骑、最显眼的附加物（翅膀、尾巴、发光部位）。老玩家一眼认出「这是 DotA 里的那个」。参考的是 **DotA 1 / 魔兽 3 模型**（d02–d07「模型来源」），**不是 Dota 2 的造型**；两者不同处以 DotA 1 为准。
2. **像真的**：识别层之外按真人奇幻电影重做：真演员、真服装道具、真材质；非人类是实拍级的电影特效生物（像《魔兽》2016、《指环王》）。不出现游戏的低模、夸张比例、卡通配色、UI。
3. **不照搬游戏比例**：魔兽 3 的大头、大手、巨型肩甲收成可信的比例；体型差异（巨人、龙、小地精）保留。英雄比小兵高一截的「主角感」靠站位、光与镜头，不靠把人放大。
4. **游戏染色翻译成材质色**：地图里的染色（如狼人品红、骷髅王暗绿）翻译成可信的材质颜色（暗红皮毛、苔绿腐蚀的骨甲），不画成纯色塑料。
5. **原名不进生成 prompt**：卡里的 prompt 只写看得见的样子，不写 DotA、Dota 2、魔兽、英雄名、技能名、物品名（避免模型拉向游戏图与他人设计）。原名只写在卡头给人看。

## 3. 技能特效的翻译

- **有物理来源**：火来自掌心或武器，冰从地面结起，雷从云层落下，毒是有体积的雾或液体。特效有光源时照亮人物与地面（真实布光），不是贴在画面上的平面光效。
- **保留颜色语言**：沿用魔兽 3 特效的主色（如水晶室女的冰蓝、莉娜的橙红火、宙斯的白蓝电弧），这是认得出的关键。
- **结果要看得见**：每个技能在小兵身上有可见结果（被击飞、冻住、点燃、变形、倒地）。只对英雄生效的技能，demo 用一个敌方英雄替身（见各卡「技能画面」）。
- **被动与光环**：用一次可见的触发来表现（暴击时武器闪光、光环在脚下地面一圈微光扫过），不常驻发光。
- **无 UI**：没有血条、伤害数字、技能图标、选中光圈、头顶名牌。

## 4. 生成与资产规则（沿用共用约定）

- 人物卡 `characters/c{N}_{英文名}/`，怪物与小兵、召唤物 `m{N}_{英文名}/`；形态变化（变身、终极形态）是卡内子目录 `c{N}-{M}_{形态}/`。编号见 `assets_index.md`，只追加、不复用。
- 人物立绘：中性浅灰摄影棚、全身、正面；人形 9:16，四足兽、龙、宽体生物 16:9。立绘之后按共用流程出 4 秒建立视频（**视频生成由用户点**）再抽正侧背三视图。
- 人类与类人英雄写明族裔或奇幻种族（如「西欧白人」「暗夜精灵」），避免默认东亚脸；奇幻种族不写人类族裔词。
- 出图 prompt 不写血腥词（尸体、内脏、血浆、渗液、断肢、伤口特写）：ElevenLabs 会按服务条款拦截（2026-10-18 c68 实测 moderated，改成中性材质词后通过）。不死、骷髅、缝线、腐朽用材质词表达。
- 背景图只画固定结构，无人物；主光有真实光源。
- 图片引擎按 `tools/image_engine.py`（ElevenLabs → Codex，额度不够才换），先写请求日志；视频只走即梦，且由用户决定生成。
