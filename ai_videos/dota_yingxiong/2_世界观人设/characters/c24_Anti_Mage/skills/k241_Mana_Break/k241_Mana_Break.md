# 法力损毁 · Mana Break

## 原典（6.83d）

- 效果：每次攻击烧掉目标魔法，并按烧掉的量追加伤害 ✅（d03 §敌法师，地图技能说明）。被动（法球）。
- 攻击：近战，射程 128 ✅（近战贴身，按 README 贴身接触不放大；画面仍是贴脸劈砍 ⚠️ follow-up 006）。
- 作用对象：有魔法的敌方单位才看得出（法师类小兵、英雄）；对没有魔法的单位只是普通攻击。
- WC3 特效：命中特效 `Feedback\SpellBreakerAttack`（地图 ✅），即魔法破坏者「反馈」的蓝紫色击中火花 ⚠️。

## 施法动作（锁定）

> 被动；随普攻触发，用连续几刀表现。

| 拍 | 秒数 | 动作 |
|---|---|---|
| 贴身 | 0–0.4 | 他低身贴到法师面前，两把比手臂还长的巨大新月战刃一前一后 |
| 第一刀 | 0.4–0.7 | 右刃斜劈，刃口迸出一簇蓝紫火花 |
| 第二刀 | 0.7–1.0 | 左刃反撩，又一簇火花；法师杖头的暗光暗下去一截 |
| 连斩 | 1.0–2.0 | 双刃交替再砍两三刀，每刀一簇火花、杖光再暗一截 |
| 收势 | 2.0–2.6 | 杖头暗光彻底熄灭；法师踉跄后退，他双刃斜垂、站定 |

## 特效（锁定）

- 来源：刀刃命中的那一点——像电焊一样从刃口与目标接触处迸出，不是刀身常驻发光。
- 形状与颜色：每刀一簇拳头大小、向外喷溅的蓝紫色火花，带几缕细碎的电弧丝，0.2 秒内熄灭。
- 魔法被抽走的表现：目标身上原有的法力光（法师杖头、兽头骨眼洞里的暗光）每刀暗一截，最后熄灭；不加任何蓝条。
- 光：每簇火花一闪蓝紫光，照亮他蒙眼布下的脸和刀刃、目标的胸口。
- 不画：刀身常驻火焰或电光、蓝色能量从目标飞进他身体。

## 作用结果（锁定）

- 小兵：亡灵法师被砍得一刀一退，杖头暗光一截截熄灭，最后连施法的光都聚不起来，踉跄后退。食尸鬼（无魔法）被砍只有普通刀光，没有火花。
- 英雄：有魔法的英雄同样每刀迸火花、身上的法力光变暗（需要时用敌方英雄替身）。
- 不能作用：没有魔法的单位（不出火花）。

## 声音（锁定）

- 挥刃：双刃破风的短促「嗖」。
- 命中：每刀一声金属砍中声叠一声电焊般的「滋啪」，火花噼啪。
- 台词（游戏原句）："Revenge..."（`d10` §敌法师 Attack，1.2 s），低声。
