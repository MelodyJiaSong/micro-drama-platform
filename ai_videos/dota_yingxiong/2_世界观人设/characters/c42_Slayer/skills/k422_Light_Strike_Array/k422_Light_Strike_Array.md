# 光击阵 · Light Strike Array

## 原典（6.83d）

- 效果：0.5 秒延迟后在落点升起火柱，造成伤害并晕眩 ✅（d04 §3）。
- 范围：地面点，225 范围（约半径 4.5 m，按 1 单位 ≈ 2 cm 放大换算 ⚠️（用户 2026-10-18 follow-up 006））。
- 作用对象：范围内敌方单位（小兵、英雄都可）✅。
- WC3 特效：落点升起 WC3「烈焰风暴」火柱 FlameStrike1；被晕单位头上是雷霆一击的晕眩星 ThunderclapTarget ✅文件。

## 施法动作（锁定）

| 拍 | 秒数 | 动作 |
|---|---|---|
| 起手 | 0–0.3 | 右手掌心的火苗一蹿，抬手 |
| 指地 | 0.3–0.5 | 右手食指与中指并拢指向远处地面 |
| 延迟 | 0.5–1.0 | 落点地面烧出一个发亮的圆形火纹，停半拍 |
| 火柱 | 1.0–1.8 | 一根粗大的火柱从圆里冲天而起 |
| 收势 | 1.8–2.5 | 收手吹一下指尖，看着敌人站不稳 |

## 特效（锁定）

- 来源：落点的地面——火从地下冲出（指尖只是指引，不射出飞行物）。
- 预兆：落点地面先烧出一个直径约 9 m、发亮的橙色圆形火纹（是土里透出的灼热裂纹，像烧红的炭，不是刻画的符文阵），草叶边缘卷黑，停 0.5 秒。
- 火柱：一根直径约 8 m、高约 16–20 m 的橙红火柱从圆里冲天而起，中心发白发黄、外层橙红、顶端翻卷成黑烟；热浪把周围草叶和尘土向外推开。
- 持续：火柱 0.8 秒后塌落成火星；落点留下一个焦黑、冒白烟的圆斑（留存）。
- 光：火柱自下而上照亮周围一切，敌人投出长长的影子；她远远被照亮半边脸。

## 作用结果（锁定）

- 小兵：圈里的食尸鬼被火柱掀翻、身上冒烟，爬起来后摇摇晃晃、站不稳、眼神发直（晕眩用身体表演，**不画头顶星星**）。
- 英雄：同样被掀翻、晕眩踉跄（需要时用敌方英雄替身）。
- 不能作用：圈外的单位、友军。

## 声音（锁定）

- 预兆：地下一声沉闷的「轰」，火纹里炭火的嘶嘶声。
- 火柱：一声爆燃的巨响「呼——轰」，热浪呼啸。
- 命中：食尸鬼被掀翻落地的闷响、晕乎乎的含混嘶声。
- 台词：不说。

## 镜头可变

机位、景别、从哪个角度看；目标数量（3 个 `m4` 食尸鬼挤在一小块）；场地（夯土烧黑、冻泥化开冒白汽、水面爆起蒸汽柱）。
