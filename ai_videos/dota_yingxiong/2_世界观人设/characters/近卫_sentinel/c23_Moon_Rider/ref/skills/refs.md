## 结论（据图，用于 follow-up 094 改卡）

1. **时间是夜晚**。DotA 1 演示全程夜景；6.83d 月之祝福给夜视（d03 ✅）、月蚀施放 `A1T6`（月亮石 `AIct`）让全图入夜 10 秒（下文「月蚀补充参考」§1 ✅ 6.83d 脚本）。月之骑士的技能放在月夜里才成立——旧片全部是白天林道，月光被阳光冲淡。
2. **月光不是宽光幕**：原版是一根**细而极亮**的青白光柱（芯很窄、外有辉光），命中处有**绕目标旋转的淡蓝月牙光圈**。旧卡「约两人宽、边缘柔和」被模型画成了瀑布状水幕，是主要偏差。
3. **月刃飞行有紫蓝色拖光**：原版投射物不是纯钢反光，而是带一道紫蓝彗尾；旧卡「无自带光源」让飞刃在画面里不起眼。
4. **月之祝福**：表现为她周身与脚下的冷蓝月辉向外扩散；旧片低机位把光环拍成了一条贴地横线，看不出是「一圈」。
5. **月蚀**：起手黑豹人立、她高举月刃；天上月轮被黑影吞没只剩银白光环、周围转入深夜；随后同一种细亮光柱一根接一根随机劈落。

- 数据取自 epicwar 免费下载的 **DotA v7.03b2 Allstars** 地图（sha `bc2053f82696`；**不是 6.83d**，6.83d 原图没找到下载）。解密 `war3map.j` 后，月光（技能码 `A042`）的触发函数：伤害 `75×等级`，**眩晕 0.8 s**，在目标的 `origin` 挂点上执行 `DestroyEffect(AddSpecialEffectTarget("effects/Eclipse.mdx", 目标, "origin"))`；施法者身上不挂任何特效，也不另外播放声音。月蚀用的也是同一个 `effects/Eclipse.mdx`。（暗月皮肤另用 `H/Luna/Dark/MoonFireSlash.mdx`，与本片无关。）
- `effects/Eclipse.mdx` 是地图自带的自定义模型（内部名 `Eclipse_FX.mdx`，作者署名 Unexpect3D，sha `fe74b7246e1d`），解析结果：
  - 贴图：`grad2b`（竖向渐变光柱）、`Moon_Cresent`（星辰坠落的月牙）、`Clouds8x8`（云雾粒子）、`GenericGlow2_64`（辉光）；光柱材质是加色叠加。
  - 几何：一个圆筒，从地面 −50 到 **1500 游戏单位高**（约英雄身高的 8–10 倍，画面里必然出顶）；另有一块小月牙面片在 **216–293 单位高**（大约在头顶上方）。
  - 动画：**Birth 0.667 s**：两层半径同时从 684 收缩，外层光幕缩到 0.3（直径约 400 单位，≈5–6 个身位），内层光芯缩到 0.07（直径约 96 单位，≈1 个身位）；透明度 0→1。**Death 2.0 s**：外层再缩到 0.18，光芯缩到 0.03（直径约 40）；光柱 0.67 s 后开始变淡，约 0.67 s 内淡完；月牙 1.0 s 内淡完。合计约 **2.7 s**，和 2010 年录像量到的 ≈2.5 s 吻合。
  - 颜色：几何着色 (0.50, 0.75, 1.0) ≈ `#80BFFF` **冰蓝**（MDX 通道顺序有 RGB、BGR 两种说法，这里按实机画面取冰蓝）；白天在草地上会显得偏薰衣草紫。

### 结论（第三轮，供改卡和声音设计）

**A. 光柱外观（以 D1 为准）**
1. 光柱分**两层**：外层是一块宽的半透明冰蓝光幕（约 5–6 个身位宽，带竖向光纹），内层是一根白亮偏青的光芯（约等于目标身体宽，后段收到约半个身宽）。既不是一根均匀的粗光柱，也不是细到看不见的激光。【D1 经典 + D1 脚本】
2. 节奏：0 → 0.67 s，宽光幕**从更宽处向中心收拢**，同时亮起（先见一根细亮线，再见光幕罩下）；0.67 → 1.3 s 最亮并保持；1.3 → 2.0 s 光幕淡掉，光芯继续变细；约 2.5–2.7 s 全部消失。【D1】
3. 颜色：光芯近白（带冰青），外辉是 `#80BFFF` 冰蓝；夜景里最好看，白天会被冲淡、偏淡紫。【D1】
4. 高度与角度：光柱**竖直**，从目标脚下一直通到画面顶端以外（模型 1500 单位高）。录像里的「斜」全是 WC3 俯视透视造成的。拍法建议：主镜头里光柱保持竖直；想要「斜」的力量感，就用低机位仰拍或广角透视来做，不要把光柱本身做斜。【D1 脚本】
5. 地面与附件：柱脚**没有硬边的地面法阵或光环**，只有一团向上翻的**白色云雾**和一小圈被照亮的地面；头顶上方漂着一轮**银白冰蓝的小月牙**（早期版本更明显）；有细光粒顺着光柱往下坠。【D1 脚本；6.49c 画面可见】

**D. 音效设计（毫秒时间轴；0 ms = 光柱出现）**
- D1 原味（主层；依据 6.83d 实机混音和已确认的音效文件 StarfallCaster1.wav。有底噪干扰，时间是估计值）：
  - 0–500 ms：一口软的中低频魔法「呼——」涌起（约 300–1100 Hz，没有爆点、没有敲击），像气流被吸进光柱。
  - 400–1100 ms：一串**上行的晶莹音点**（钟琴、钢片琴、玻璃风铃的质感），约从 2.3 kHz 升到 3.2 kHz，每个音约 100–150 ms，一共上行约 6 个半音。
  - 1100–1800 ms：音点小幅回落（≈2.9 → 2.5 kHz），底下拖着一层细的持续高音（≈1.1 kHz 和 ≈1.9 kHz 两条）。
  - 1400–2000 ms：3–9 kHz 的细碎星尘「沙沙」闪光，然后约 0.5 s 淡出。全长约 2.0–2.5 s。**没有低频轰击，没有雷声，没有电流声**；整体轻、亮、神圣。
