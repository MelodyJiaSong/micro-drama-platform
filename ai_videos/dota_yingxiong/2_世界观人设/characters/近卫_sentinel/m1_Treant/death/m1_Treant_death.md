# m1 树人：死亡动作

2026-10-23 · follow-up 092。照食尸鬼 `m4` 死亡样板（[m4_Ghoul_death.md](../../../天灾_scourge/m4_Ghoul/death/m4_Ghoul_death.md)，follow-up 067–069）做近卫近战兵树人的死亡动作资产；不改立绘 `m1_Treant.png` 与建立视频。

## 方向

- **死法**：被打中后像一棵被伐倒的树，**整个身子直挺挺往后仰面倒下**，根须脚从泥里被扯出来、带起土块，碎叶断枝四散，断口是新鲜的浅色木头；不流血。出处：人物卡「受击反应 · 倒地 / 死亡」。
- **倒地以后**：仰躺的树尸 → 叶子枯褐掉落、湿苔枯黄、树皮发灰干裂剥落 → 只剩一截银灰、开裂、半空心的枯木半埋在土里，仍看得出躯干、枯枝长臂和三根木指、翘起的枯根脚，眼窝成了两个黑洞。对应 m4 的 Death → Decay（倒下 → 尸体 → 烂成白骨），树人没有骨头，「白骨」换成「枯木」。
- **证据边界**：WC3 树人模型（`units\nightelf\Ent\Ent`）单体 Death / Decay 的实际样子本轮在网上没查到直接资料（warcraft.wiki.gg 与 Hive Workshop 搜索无结果，wiki 图片要过人机验证）；以上后段属于本剧的电影化创作选择，不宣称是原版终帧。
- **时长**：用户定「直接出 4 秒」（不先出长条再剪）。0–0.6 s 站立、受击；0.6–1.4 s 直挺挺倒下砸地；1.4–1.8 s 仰躺不动；1.8–3.2 s 快进式枯萎成枯木；3.2–4 s 定格。
- 机位、地面与光线照 m4：低机位膝盖高、三分之四侧面、平坦干硬的土黄夯土地、阴天散射光，方便同场混剪。
