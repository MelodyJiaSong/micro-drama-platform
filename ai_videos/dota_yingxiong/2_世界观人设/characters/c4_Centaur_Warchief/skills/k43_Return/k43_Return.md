# 反击 · Return

## 原典（6.83d）

- 效果：所有攻击他的单位受反伤 ✅（d02 §4）。被动。
- 作用对象：攻击他的敌方单位。
- WC3 特效：身上挂 WC3「荆棘光环」（`ThornsAura`），被打时攻击者身上闪荆棘伤害特效 ✅文件 / ⚠️外观。

## 施法动作（锁定）

> 被动，没有施法动作；这里锁的是「挨一刀」的一拍，每挨一刀重复一次。

| 拍 | 秒数 | 动作 |
|---|---|---|
| 挨打 | 0–0.3 | 一只敌兵一刀砍在他的马躯上 |
| 反刺 | 0.3–0.5 | 被砍处皮毛下弹出一圈褐色荆棘刺影，扎回攻击者的手臂 |
| 缩手 | 0.5–1.2 | 攻击者惨叫缩手、踉跄后退；他不躲，只甩一下尾、喷一声鼻息 |

## 特效（锁定）

- 来源：被砍处的皮毛下——一圈褐色、像折断的荆棘倒刺的半透明刺影，从挨刀的那一点射出；不常驻，身上平时没有光环。
- 形状与颜色：十几根褐色、带节疤的荆棘刺影，长约 30–50 cm，扇形射向攻击者，扎进它的手臂和胸口后像干木屑一样碎散消失。
- 持续：每次约 0.3 秒；每挨一刀闪一次。
- 光：无自发光。
- 「越打越残」的表现：每只攻击者手臂上的裂口越来越多、动作越来越抖。

## 作用结果（锁定）

- 小兵：围攻他的食尸鬼（`m4`）每砍一刀，手臂干皮就多出几道裂口（不流血），惨叫缩手；越围攻越残。
- 英雄：同样受反伤（需要时用敌方英雄替身）。
- 不能作用：没有攻击他的单位、友军。远程攻击者的反刺本剧 demo 不拍（d02 未载其外观）。

## 声音（锁定）

- 挨打：刀砍皮毛的闷响。
- 反刺：一串木刺崩裂般的噼啪。
- 攻击者：吃痛的惨嘶。
- 施法者：不吭声，只喷一声粗重鼻息。
- 台词：不说（无语言台词，`d09` §4）。

## 镜头可变

机位、景别、从哪个角度看（特写每次挨打时攻击者身上的反刺）；围攻者数量（按分镜，4–5 个 `m4`）；场地。
