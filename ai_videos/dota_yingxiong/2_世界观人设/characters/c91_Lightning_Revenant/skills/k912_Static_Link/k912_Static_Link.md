# 静电连接 · Static Link

## 原典（6.83d）

- 效果：和一个敌方英雄之间拉起电链，持续偷对方攻击力 ✅（d06 §16）。
- 单体，**只能对英雄放** ✅。
- 作用对象：敌方英雄。
- WC3 特效：连接单位是先知闪电球 `FarseerMissile`（缩放 0.8），施法动作 spell ✅。

## 施法动作（锁定）

| 拍 | 秒数 | 动作 |
|---|---|---|
| 起手 | 0–0.4 | 他抬起空着的左手，五指张开指向替身 |
| 连接 | 0.4–0.7 | 一条蓝白电弧从他掌心「啪」地打到替身胸口，连上 |
| 抽取 | 0.7–5.0 | 电弧持续跳动、粗细一阵一阵地变；替身的手臂越来越软，他身上的电光越来越亮 |
| 断开 | 5.0–5.5 | 电弧一闪断开；替身踉跄，他甲缝里的电弧密密亮着 |

## 特效（锁定）

- 来源：他的掌心——电弧从他掌心发出，一端牢牢连在替身胸口；不是从天上落下。
- 形状与颜色：一条持续跳动的蓝白色电弧，手腕到小臂粗，粗细一阵一阵地变，像一条被拉紧又放松的绳；电弧中段偶尔鼓起一颗小小的蓝白电球顺着电弧滑向他（被偷走的力量）。
- 尺度与持续：两人相距约 12–16 m（施法距离研究未记，按 ×2 放大 ⚠️（用户 2026-10-18 follow-up 006））；连接持续数秒（按分镜），断开时一闪即灭。
- 光：电弧是真实光源，持续照亮两人之间的地面与替身的胸口、脸；他身上甲缝的电弧随时间越来越密、越来越亮。
- 偷攻击的表现：替身握武器的手臂发软，巨剑剑尖慢慢垂到地上；他手中的长刃裂纹里透出越来越亮的白蓝光。

## 作用结果（锁定）

- 英雄（替身 `c8`）：胸口被电弧连着，全身轻微抽搐，双手握着的巨剑越来越沉、剑尖慢慢垂落拖地，想挥剑却抬不起来。
- 小兵：不能对小兵放（镜头里不出现连向小兵的电弧）。
- 不能作用：小兵、建筑、友军。

## 声音（锁定）

- 连接：一声清脆的电爆「啪」。
- 持续：低沉而不稳的电流嗡鸣，随电弧粗细起伏，偶尔噼啪。
- 断开：一声短促的「嗞」，随后安静。
- 台词（游戏原句，亡灵法师语音 Warcry）："They'll all be mine, in the end!"（`d13` §闪电幽魂，NecromancerWarcry1）。

## 镜头可变

机位、景别、从哪个角度看；英雄替身换哪一位（须敌方、立绘已出）；连接持续多久；场地。
