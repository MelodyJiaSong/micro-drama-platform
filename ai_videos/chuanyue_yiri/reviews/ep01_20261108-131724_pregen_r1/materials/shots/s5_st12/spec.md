## 分镜规格
**动作**：接上一镜，回到双人主机位。Riley 右手比着 OK 手势伸向柜台里，挑眉等着；Asellina 看着她的手愣了一下，然后右手也比出同样的 OK 手势，冲她点点头。Riley 眼睛一亮，惊喜地转向镜头说话；说完放下手，笑着转回去看 Asellina。道具：面包布包挂在 Riley 左胯；钱在她裤子左侧的大口袋里。
**走位**：同 st2 的双人主机位：Asellina 在画左（柜台里），Riley 在画右（柜台外），Riley 四分之三侧脸对镜头；说台词时 Riley 转脸朝镜头（画左外侧），说完转回画左看 Asellina。配角一行：Asellina——看着 Riley 的手，心想「这手势我也懂」，乐了。
**节拍**：0–1秒 第 0 秒：画右，Riley 右手比着 OK 手势伸向柜台里，挑眉等着；画左，Asellina 在柜台后看着她的手，愣着；没人说话；1–2.5秒 Asellina 愣了一下，然后右手也比出同样的 OK 手势，冲 Riley 点点头（Asellina 的反应拍，单独一拍），没人说话；2.5–3.5秒 Riley 眼睛一亮，惊喜地转向镜头（Riley 的反应拍，单独一拍），不说话；3.5–6秒 她对镜头说那句话（3.6–5.8 秒）；6–8秒 Riley 放下手，笑着转回去看 Asellina，嘴闭着；没人说话
**镜头**：他拍：固定机位旁观拍摄，眼平；中景双人，斜对柜台：Asellina 在画左、Riley 在画右，两人腰以上，两人比的 OK 手势都清楚可见。
