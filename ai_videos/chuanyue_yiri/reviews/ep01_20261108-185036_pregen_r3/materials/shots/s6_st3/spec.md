## 分镜规格
**动作**：天快黑了。城南靠近斯塔比亚门的一条街，镜头站在街面上朝东看街的深处，城门和大车店都在镜头身后。路面是深灰色的多边形玄武岩大石板，两边是高出路面约四十厘米的人行道；临街的灰泥墙刷着赭黄和庞贝红，墙脚一圈深色墙裙，屋檐是红陶筒瓦。左边人行道上、离镜头约五米，一个铺子主人（普通路人，晒黑的中年男人，脸刮得干净，穿褐色短 tunica）正把一块素木门板竖着插进自家门框的槽里。路的右半边，一头灰驴套在两根车辕中间、走在车的正前方，拉着满载陶罐的两轮货车往街的深处走，车尾朝着镜头；赶车的车夫（普通路人，灰褐短 tunica）走在驴头左侧，背对镜头。第 0 秒 Riley 在左边人行道上、离镜头约七米，在铺子主人身后约两米，全身入画，有点累地朝镜头走来，两手空着。她从铺子主人身边走过时，他抱着门板停了一下，扭头瞥一眼她的裤子和靴子，再转回去插门板。她走到离镜头约两米处停下，左手从裤子左侧的大口袋里掏出剩下的钱，倒进右手掌心攥住，对镜头说话；说到 This 时把右手往前递到胸前，掌心朝上、手指微微并拢成一个浅窝、朝镜头这边斜约三十度，四枚钱平躺在掌心窝里：正好 3 枚红铜小钱和 1 枚明显大一圈的金黄大黄铜币，互不重叠；她先低头看着钱，说到后半句才抬眼看镜头。说完收回手攥起来、叹口气。接着她像听见画面左边、镜头身后有人吆喝，转头朝画面左边看，听出那个词有点像 hospitality，眼睛一亮，攥着钱朝画面左边走出画。本镜只生成 Riley 自己的两句话；那声吆喝是 Fortunata 在 s6_st1 喊的，剪辑时贴进来作画外声。道具：钱（p2）进场在 Riley 裤子左侧口袋里（看不见）→ 4.5–6.3 秒左手掏出、倒进右手掌心攥住 → 7.9–12.5 秒右手摊在胸前（正好 3 枚小钱＋1 枚大黄铜币）→ 12.5 秒起攥在右手里，出场仍攥在右手。画面里共 3 个人：Riley、插门板的铺子主人、背对镜头的赶车车夫。
**走位**：镜头站在大车店东边几步的街面上、贴着左边（北侧）人行道的路缘石，朝东看街的深处；大车店车门和城门都在镜头身后（西边）。Riley 从街的深处沿左边人行道朝镜头走来（每秒一米出头），约 2 秒从铺子主人身边走过，4.5 秒停在人行道边沿、离镜头约两米、画面左边约四分之一处，面朝镜头；14.6 秒起转向画面左边，从镜头左侧走出画（去身后的大车店，下一镜从画面右边进来）。货车在路的右半边，0 秒车尾在画面右边、离镜头约七米，一直往街的深处越走越远。插门板的铺子主人在左边人行道、离镜头约五米的自家门口；第 0 秒 Riley 在他身后、离镜头更远。配角：铺子主人在 Riley 走过时扭头瞥一眼她的裤子和靴子，在想「这女人怎么穿着裤子」，再转回去插门板。大车店的女店主此刻在镜头身后画外。
**节拍**：0–1.2秒 暮色里的街：Riley 在左边人行道上、离镜头约七米，在铺子主人身后，全身入画，朝镜头走来，两手空着自然摆动，神情有点累，嘴闭着；货车车尾朝镜头，往街的深处慢慢走远；铺子主人在往门框里插门板；没人说话；1.2–2.6秒 Riley 从铺子主人身边走过，他抱着门板停一下，扭头瞥一眼她的裤子和靴子，又转回去插门板（Riley 照常往前走），没人说话；2.6–4.5秒 Riley 走到离镜头约两米处，在人行道边沿停下，腰以上入画，面朝镜头，没人说话；4.5–6.3秒 她左手伸进裤子左侧的大口袋，掏出剩下的钱，倒进右手掌心，右手攥成拳停在胸前，没人说话；6.3–7.5秒 她对镜头说 Sun's going down.；7.9–12.5秒 她说 This is what's left of the budget… and still no bed.——说到 This 时右手往前递到胸前，掌心朝上并朝镜头斜约三十度，张开成一个浅窝：正好 3 枚红铜小钱和 1 枚大黄铜币平躺在掌心窝里、互不重叠，停住让人数清；前半句她低头看着钱，说到 and still no bed 时抬眼看镜头；12.5–13.6秒 她把右手收回胸前攥起来，叹一口气，不说话；13.6–14.6秒 她像听见画面左边、镜头身后有人吆喝，转头朝画面左边看，眼睛一亮，嘴闭着（吆喝剪辑时从 s6_st1 贴进来）；14.6–17秒 她攥着钱朝画面左边走，约 15.8 秒从画面左边走出画；街上只剩越走越远的货车和插门板的铺子主人，不说话
**镜头**：他拍：固定机位，比眼平略高（约一米七）、略往下看，40mm 镜头感，站在街面上贴着左边路缘石朝东看街的深处；全景起（她全身约占画高一半），她走近到腰以上的中近景（她走近，镜头不动），停在画面左边约四分之一处；7.9–12.5 秒她递到胸前的右手和钱在画面左半、中间偏下，离镜头约一米四，掌心朝镜头斜着，四枚钱清楚可数；Riley 两只手都在画面里、都能用。
**光线**：日落后的傍晚：太阳刚落到城西边、在镜头身后；镜头朝东，画面里的天空是干净的蓝紫色，越往街的尽头越暗；Riley 的脸和身前是从镜头身后照来的柔和余晖，暖而淡；街面和墙脚已经发暗；街的远处一家铺子门里透出一点暖光。
**台词**：Riley（有点累、自嘲，美式英语，对镜头）：Sun's going down. This is what's left of the budget… and still no bed.
