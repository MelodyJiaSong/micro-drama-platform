## 分镜规格
**动作**：车门口，接上一镜：Fortunata 的右手伸在两人中间、掌心朝上。Riley 把攥着钱的右手伸过去摊开，掌心朝上：手心里正好 3 枚红铜小钱和 1 枚明显大一圈的金黄大黄铜币。她用左手拇指和食指、中指把 3 枚小钱错开捏成一小排（三枚边挨着边，像一把小扇子），整排一次放进 Fortunata 摊开的手心，手指碰到她的手掌再松开；放下后 3 枚小钱在她掌心里错开摊着、互不重叠，看得清是 3 枚（钱一直在手指里或掌心上）。Fortunata 看看手心，又抬眼看 Riley，手停着。Riley 叹口气，用左手把右手心里那枚大黄铜币捏起来，放在那 3 枚小钱旁边，松手。Fortunata 合上手，攥成拳；点头说 Convenit；左手拉开腰间小皮钱袋袋颈上的绳结、用手指把袋口撑开，右手的拳头伸到袋口，把钱放进去，再抽出空手。Riley 摊开两只空手看看，苦笑。Fortunata 腰带上只挂一个拳头大的小皮钱袋。车门左边墙龛里那盏点着的小陶油灯（p1：赭红素陶，手掌大、长约十二厘米的圆形扁灯身，顶面是一整块封死的浅凹圆面、中间一个小注油孔，前端一个短单嘴，尾部一个能勾进一根手指的环形把手；整盏是一体的陶）一直在 Fortunata 身后左上方，不动。道具：钱（p2）付前 Riley 右手心正好 3 枚红铜小钱＋1 枚大黄铜币 → 付出 1.5–3.5 秒 3 枚小钱、6–7.5 秒大黄铜币 → 付后 Riley 手里 0 枚；Fortunata 手心里先是正好 3 枚，再是正好 3 枚加 1 枚大币，7.5 秒攥在她右拳里，10–12.5 秒收进她腰间的小皮钱袋（袋颈本来用绳子扎着，她先拉开）。油灯（p1）进场、出场都在墙龛里点着。画面里只有 Fortunata 和 Riley 两个人。
**走位**：两人在车门口面对面，相距约一米：Fortunata 在画左、Riley 在画右（接上一镜）；两人伸出的手在画面中间。墙龛和那盏灯在 Fortunata 身后左上方。镜头在两人侧面偏 Riley 一侧，略高往下俯，离两人的手一米半多。配角：Fortunata 一直看着 Riley 的手和脸：3.5–5 秒在想「就这些？不够」，收到大币后想「这还差不多」，8.5 秒点头成交。
**节拍**：0–1.5秒 Fortunata 右手掌心朝上伸在两人中间，看着 Riley 的手；Riley 的右手摊开伸在两人中间偏她那边，掌心朝上：正好 3 枚红铜小钱和 1 枚大黄铜币，她低头看着，左手垂在身侧，没人说话；1.5–3.5秒 Riley 用左手拇指和食指、中指把 3 枚小钱错开捏成一小排，整排放进 Fortunata 的手心，手指碰到她的手掌再松开；3 枚小钱在她掌心里错开摊着、互不重叠，看得清是 3 枚，没人说话；3.5–5秒 Fortunata 低头看手心里的 3 枚钱，再抬眼看 Riley，手停在那儿，不说话；5–6秒 Riley 叹一口气，肩膀一沉，低头看右手心里剩下的那枚大黄铜币，不说话；6–7.5秒 Riley 用左手把那枚大黄铜币捏起来，放在 Fortunata 手心里那 3 枚小钱旁边，松手；Fortunata 手心里正好 3 枚小钱加 1 枚大币，不说话；7.5–8.5秒 Fortunata 把手合上，攥成拳，不说话；8.5–10秒 Fortunata 点一下头，干脆地说 Convenit.（8.7–9.5秒）；10–12.5秒 Fortunata 左手拉开腰间小皮钱袋袋颈上的绳结，用左手手指把袋口撑开，右手的拳头伸到袋口松开，钱落进袋里，再抽出空手，不说话；12.5–14秒 Riley 摊开两只空手看了看，冲 Fortunata 苦笑一下，不说话
**镜头**：他拍：中景双人，两人腰以上，40mm 镜头感，从两人侧面偏 Riley 一侧拍，机位略高往下俯，离两人的手一米半多，固定机位；两人伸出的手在画面中间，Fortunata 摊开的手掌朝上，手心里的钱清楚可数；墙龛和灯在画面左上；Riley 两只手都在画面里：右手托着钱，左手捏钱、放钱。
**光线**：日落后的傍晚：太阳已落到城西边，西边天空余下一点橙色、头顶蓝紫，天空干净；街面发暗，两人身上是柔和的余晖天光；墙龛里那盏小陶油灯的火苗是近处唯一的暖光，给两人的手和脸添一点暖色。
**台词**：Fortunata（拉丁语，古典发音 KON-weh-nit；干脆，点一下头）：Convenit.
