> **系列名改为 Portal Travel**（用户 2026-11-07）：Riley 穿过时空门，可以回到过去的某时某地，也可以去某个虚拟世界（例：奇幻城堡）；每集仍是在那里过完一天。之后做一段**时空门穿梭的固定开场**，各集反复使用（待设计）。原名《穿越一日 · One Day in ___》，目录名 `chuanyue_yiri` 不变。

## Vision（观众体验）

> **在另一个时代、另一座城里过完一整天：像自己真的去过那里，亲眼看见、亲口尝到、亲耳听到那一天的人怎么生活。**

核心：那时那地普通人的一天——他们靠什么活、信什么、吃什么、穷人和富人各自怎么过；每个细节都真实可查，又让今天的人惊讶。

（方向用户 2026-11-06 定：「给观众身临其境，体验一天生活的感觉」；措辞由代理起草，用户认可。）

| 过完一整天 | 每集从清晨到入夜；固定开头和结尾，中间按时段排栏目 | `bible.md` §3 |

| 让人惊讶 | 每个栏目至少落一个「今天的人会意外」的日常细节；每集有本集特色 | `bible.md` §4 |

## 这是什么

一位性格开朗的女 vlogger 穿越到某个时代的某座城，用一天体验当地生活：早市、信仰场所、谋生、政府、医疗、旅馆过夜、贫富对照、饮食等。这些是常驻栏目；每集另有临时加入的本集特色。标题公式 `One Day in {地点} {年份}`。

长期方向是**给一个地点和年份，AI 自动出片**：约 80% 从模板库里抽取，20% 每集自由发挥。不追求 100% 自动和一次成功，也**不为自动化牺牲画面质量**（用户 2026-11-06）。

## 已定

|---|---|
| 片种 | `series`：同一主持人、同一套栏目跨集；每集换地点和年份，集与集之间没有连续剧情 |
| 画幅 / 语言 | 16:9；**先只做英文**，中文以后再定做法 |

| 当地人 | 说当地语言（庞贝是拉丁语）；她听不懂就猜，用肢体语言回应，不靠固定手语（用户 2026-11-06） |

| 重出次数 | **每个镜头最多重出两次**（11-09 先定一次，同日改两次，follow-up 050）；第二次重出后审核仍不满意就停，不再出，剪辑用几条里最好的一条，并列给用户处理（用户 2026-11-09，follow-up 049；已写进全仓流程 `prompts-generate.md`「重试与搁置」） |

| 虚拟世界 | 以后可以做，谨慎处理 IP 与商用风险（见 `bible.md` §9） |
