# 选题

## 选题标准

| 标准 | 为什么 |
|---|---|
| 小城、可步行 | 一天走得完；场景数可控 |
| 考古和图像资料多 | 画面能核对，不靠猜 |
| 模型见过很多（影视作品多） | 出画稳，减少返工 |
| 常驻栏目都能找到对应 | 能套模板 |
| 至少一个今天的人会意外的细节 | 有看点 |
| 不碰灾难当天 | 用户 2026-11-06 |

验证阶段（前几集）优先「容易拍」；跑通后再上难度高的（大城、人群多、水面多、资料少）。

## 第一集选题卡：One Day in Pompeii 75 AD（用户 2026-11-06 定）

| 项 | 内容 |
|---|---|
| 地点 | 庞贝，罗马帝国坎帕尼亚地区的港口小城，约 1 万人（数字待考据核实） |
| 年份 | 公元 75 年，维斯帕先在位；平常一天，距火山爆发还有几年，片中不提 |
| 为什么容易拍 | 城小，考古资料世界第一；罗马题材影视作品多；常驻栏目几乎都有现成对应 |
| 栏目候选 | S02 街边熟食铺与面包房；S04 神庙；S05 洗衣作坊或面包作坊；S06 广场；S07 公共厕所与外科工具；S08 富人宅邸对平民小屋；S10 浴场；S11 旅店 |
| 特色候选 | 鱼露 garum；洗衣作坊用尿；街上的垫脚石 |
| 风险 | 墙上的竞选标语和涂鸦是看点，但画面不写字，只能远看或由她口述；浴场注意着装尺度 |
| 时长 | 90–180 秒，挑 3–4 个栏目 |

以上只是候选，栏目与特色在第一集考据和故事创作时定。
