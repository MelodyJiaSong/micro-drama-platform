# ep1_s3_st8 · 一间敞开门脸的面包房：门脸上的石台、后面的石磨与砖炉，门外的街 · 清晨，晴
时长 9 秒；场目的：清晨，一间门脸朝南、对着东西向街道敞开的面包房：门脸上横着卖面包的石台，店里有两座石磨和一座砖炉；这一场是 Riley 在古城第一次买东西、吃东西。

## 画面
清晨的街，面包房门脸在后景：镜头在门脸斜对面（西南边）的街边，朝东北斜对门脸。Riley 站在石台外侧，侧背对镜头、面朝石台里的 Felix，挥一下右手告别，挥完右手放下，不去碰托板；然后转身朝街上走两步，走到街上停住，低头看一眼自己的左手、把左手往身侧一抬，确认哪边是左，自信地点头，然后朝她自己的左边（街的东头，画右）转身，大步走出画右；布包在她左胯边随步子晃。一对母子沿街从画右走来，从她身后（她和门脸之间）错身而过：小男孩一只手拽着母亲的袖子，另一只手好奇地指着 Riley 脚上的系带短靴，母亲拉着他赶路，眼睛看着前面的路（普通路人，各忙各的），两人往画左走出画。Felix 从头到尾站在后景的石台里侧（店里），石台挡住他腰以下；他端着托板原地站着，只转头看着她，不走出门脸、不绕到石台前面、不迈到街上。石台上是小陶碗和那一摞待卖的面包。画面里除了 Riley 和 Felix，只有这一对母子两个路人。道具：布包一直挂在她左胯；Felix 的托板上正好五个面包，一直端在他两手里。配角：Felix 看着她往画右走，一时愣住；路过的小男孩好奇的是她的靴子。第 0 秒：Riley 在画面中间偏左、石台外侧的街面上，全身，侧背对镜头、面朝石台里的 Felix，右手举起来挥；Felix 在她左边一点（画面左侧三分之一处）、石台里侧，石台挡住他腰以下，端着放了正好五个面包的托板，看着她；母子还在画右画外。

## 走位
镜头在门脸斜对面（西南边）的街边，朝东北斜对门脸，在 Felix 和 Riley 连线的西侧：Felix 在石台里侧、画面左侧三分之一处，从头到尾原地站在石台后面（石台挡住他腰以下），不走出门脸，Riley 在他右边一点，两人在画面里错开；Riley 从石台外侧走到街上（离镜头更近、画面偏右），再朝她自己的左边（街的东头，画右）走出画；母子沿街从画右往画左走，从 Riley 身后（她和门脸之间）经过。

## 动作节拍
0–1.5秒 第 0 秒：Riley 站在石台外侧、侧背对镜头、面朝 Felix，布包挂在左胯，挥一下右手；Felix 在后景石台里侧（石台挡住他腰以下）端着放了五个面包的托板看着她；两人都安静；1.5–3.5秒 她转身朝街上走两步，走到街上；3.5–4.5秒 她停住，低头看一眼自己的左手，把左手往身侧一抬，确认哪边是左，自信地点头；4.5–6秒 一对母子从画右沿街走来，从她身后错身而过，小男孩一只手拽着母亲的袖子、另一只手指着她的短靴，母亲拉着孩子往画左走（单独一拍，Riley 只顾看自己的左手）；6–9秒 Riley 朝她自己的左边（画右）转身，大步走出画右，布包随步子晃；Felix 仍站在后景石台里侧原地，只转头看着她走的方向；只有街上的环境声

## 镜头
他拍：全景，眼平，35mm；Riley 全身约占画高七成（头顶靠近画面上沿，脚在画面下部）；镜头在门脸斜对面西南边的街边、朝东北斜对门脸，面包房门脸和石台在后景；Riley 从石台前走到街上再出画右；固定机位。

## 光线
清晨的太阳在街的东头、还很低，在画右画外，阳光从画右斜照过来，石板路面一半亮一半在阴影里；面包房门脸里偏暗，最里面砖炉口透出橙红火光。
