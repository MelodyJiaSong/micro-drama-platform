目的：验证「Codex 静帧 + 深度 2.5D + Blender 程序化动效」能否替代 Seedance 出无人物的建立 / 空镜。

做法：首帧做成按深度位移的网格（初始机位精确还原原图），天空换成远处的星空平面；油灯按遮罩做 4D 噪声闪烁，星点闪烁；
一盏无人提灯沿街慢走（光晕 + 地面光斑）；相机 2–9 秒平滑上摇 20°，同时轻微前推产生视差；ffmpeg 加颗粒与暗角。
花费：Seedance 0 积分；Codex 2 张图；本机渲染约 5 分钟（RTX 5000 Ada）。

## v2：3D 提灯人（同日）

- 人体：本机 Blender 的 MPFB 扩展生成男性人体 + game_engine 骨骼（`scripts/make_walker.py` → `work/walker.blend`）；长袍、斗篷、头发是程序建的简单网格，自动权重挂骨骼。
- 走路：程序化步态（大腿 ±22°、膝盖在摆动相弯曲、空手摆臂、持灯臂前伸），转动按世界轴定义再换算到每根骨骼，不依赖骨骼轴向约定。
- 进场景：按原首帧里提灯人的高度（约 78 像素）定世界比例，沿街从 30 m 处以 1.05 m/s 向镜头走（步幅与速度匹配，不滑步）；灯笼点光照亮人物，月光冷色补光，地面暖光斑 + 光晕是加法贴片。
- 限制：底图是不受光的照片，人物照不到墙、影子不落地；人物约 45–55 像素高，再近就会露出模型粗糙、动作程序化。

## v3：真人动捕步态（同日，用户反馈 v2 程序化走路「没有真人走路的韵律」）

- 数据：CMU Graphics Lab 动捕库 07_04「slow walk」（Bruce Hahne 的 BVH 版，`mocap/07_04.bvh`；READMEFIRST 写明可用于研究与商用）。
- 迁移（`scripts/retarget_mocap.py`）：按骨骼名映射到 MPFB game_engine 骨骼；每根骨骼取「动捕相对其静止姿势的世界转动」，先补 T 字与 A 字静止姿势的方向差，再作用到目标骨骼；持灯右臂只保留 35% 摆动。
- 循环：在 3.75 秒片段里找姿态最接近、相隔 0.9–1.7 秒的两帧（结果 34 帧 = 1.42 秒一个完整步态），无缝循环到 9 秒；胯部水平位移去掉，保留起伏与左右晃。
- 速度：动捕实测 0.96 m/s（按腿长换算到 1.67 m 人物），沿街按这个速度移动，不滑步；脚的最低点对齐地面。
