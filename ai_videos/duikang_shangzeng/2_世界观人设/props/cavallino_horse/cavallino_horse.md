# cavallino_horse · 那匹马 — 全片唯一暗线（S 级资产）

> 全片**只有一匹马**。它换场景、换毛况，但**始终是同一个存在**。
> 竞品在 63 秒用一个镜头"说出"了车马关系，却从未兑现它。
> 本片把马做成从第 1 秒埋到最后一帧的暗线：**观众跟了 105 秒的这匹马，就是车标。**

---

## 一、锁定描述符（byte-identical · 逐字复制进每一个出现马的 prompt）

```
cavallino_horse — 一匹纯黑色的高大骏马，肌肉线条紧实，鬃毛与尾毛浓密微卷；额头正中一道细窄的白色竖纹，从两眼之间延伸到鼻梁上方；四蹄为深灰近黑，左前蹄内侧有一小块白斑；眼睛为深褐色、瞳孔清晰、眼白极少；不戴任何鞍具与缰绳
```

> 冰原段唯一允许的变化：**追加**「披覆厚重冬季长毛，鬃毛结霜」——
> 骨架、毛色、额头白纹、左前蹄白斑**一律不变**。

## 二、五幕形态表

| 幕 | 形态 | 关键点 |
|---|---|---|
| **Ⅰ** | 广场中央的**青铜跃马雕像**，前蹄腾空、后蹄立于石台座 | 铜绿斑驳、灰、静止；**边缘与鬃毛尖端正在粒子化剥落** |
| **Ⅱ** | 车驶过 → 铜色从蹄向上**褪成真实黑色皮毛** → **迈下台座**，落地扬起一圈灰 | **机制的第一次证明**。全片最重要的一个转折镜 |
| **Ⅲa** | 中世纪骑士的战马（**背上有骑士，但马是同一匹**） | 石板路上与车并驾；蹄铁敲石、扬起金色尘土 |
| **Ⅲb** | 冰原上的马（**追加厚冬毛**，鬃毛结霜） | 冰面上与车并驾；蹄下碎冰与雪沫飞溅 |
| **Ⅳ** | 与车并线加速 → **腾空跃起** → 在空中散成粒子、汇入车身左侧翼子板 | 全片唯一一次马的瓦解，且是**主动的、向上的** |
| **Ⅴ** | 粒子收拢成形 = **F80 翼子板上的跃马盾徽** | 揭示。最后一帧 |

### 雕像 → 真马的过渡工艺（第Ⅱ幕关键镜）
必须**从下往上**：蹄 → 小腿 → 躯干 → 颈 → 头。铜绿褪去、露出黑色皮毛的湿润反光。
**不是闪光变身、不是溶解、不是特效爆闪** —— 是"颜色和材质从下往上被灌回来"，
与 `world.md` §四 的复原法则同构。

## 三、硬约束（违反 = blocker）

1. **马永远在画面左侧**，车在中/右。全片统一，防越轴。唯一例外是第Ⅳ幕腾空。
2. **马永不超越车、永不与车相撞、永不挡住车头**。它是并驾者，不是竞争者。
3. **马不发光、不透明、不是幽灵、不带任何特效**。
   它是一匹有重量的真马 —— 蹄子踩地会陷、会扬尘、肌肉会颤、呼吸会喷白气。
4. **马不瓦解**（除第Ⅳ幕）。被唤醒之后它就在熵增的作用之外。
5. **奔跑必须有重量三拍**：蹄落着地（尘/雪爆开）→ 身体下沉吃住 → 蹬地推出。
   禁止漂浮式跑动。
