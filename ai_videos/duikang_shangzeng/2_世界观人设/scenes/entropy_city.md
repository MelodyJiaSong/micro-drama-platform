# entropy_city · 熵增都市（S 级场景 · 全片主场）

## 场景定位
一座正在滑向热寂的现代都市。**不是废墟、不是战后、不是赛博朋克** ——
它看上去几乎正常，只是**所有颜色都在褪、所有运动都在慢、所有边缘都在散**。
恐怖感来自"日常正在失效"，不来自破坏。

## 锁定描述符（byte-identical）

```
entropy_city — 现代都市街区，玻璃幕墙高楼与低层商铺混杂；整体褪成无饱和的灰烬色，像烧尽的纸；天空灰白、阴云均质、无方向主光、看不见太阳；空气中悬浮着极细的灰色微粒，缓慢向下飘落并在地面积起薄薄一层；霓虹招牌与广告屏的色彩已褪成灰白，只剩极淡的形状；地面湿润、有薄水膜、映出灰白的天光
```

## 四个机位板（Blender 一份 `.blend` 定死相对位置）

| plate | 地点 | 用途 | 幕 |
|---|---|---|---|
| `bg1_广场_铜马台座` | 中央广场，青铜跃马雕像立于石台座 | 马的埋点与活化；第Ⅴ幕回归此地**收尾** | Ⅰ / Ⅱ / Ⅴ |
| `bg2_主街_商铺长街` | 两侧商铺与广告屏的长直街道 | 路跑主力；瓦解与复原的展示面（路人 / 机械犬 / 酒杯） | Ⅰ / Ⅱ / Ⅳ / Ⅴ |
| `bg3_高架_跨江桥` | 城市高架桥段，两侧无遮挡 | 对冲 / 反拉 / 速度镜；第Ⅳ幕整城复原的**全景视点** | Ⅱ / Ⅳ |
| `bg4_隧道` | 城市隧道，顶部条形灯规律排列 | 抖动 / 逼近 / 灯光穿梭；**第Ⅲ幕世界切换的入口与出口** | Ⅱ / Ⅲ |

> **空间连续性铁律**：第Ⅱ幕从 `bg1` 广场冲出的方向，
> 与第Ⅴ幕回到 `bg1` 广场的方向必须一致（Blender 布局保证）。

## 关键变化态

| 态 | 出现 | 描述 |
|---|---|---|
| **熵增态** | 幕Ⅰ–Ⅱ | 见锁定描述符。行人步子越迈越小、旗帜停在半飘、雨滴悬在半空 |
| **复原态** | 幕Ⅳ–Ⅴ | 颜色沿车尾流灌回、微粒从地面升起归位、悬停的雨滴继续落下、行人迈完那一步 |
| **常态** | 幕Ⅴ 尾 | 干净的自然日光，普通的城市。**普通就是胜利** |

## 三个瓦解展示物（`bg2` 主街 · 主题最好的载体，竞品几乎没给时间）
1. **路人的背影** —— 衣角与发丝先散，轮廓变模糊。
2. **机械犬** —— 四肢先化为微粒，躯干失去支撑坠地，随即彻底瓦解。（继承原分镜第 16 镜）
3. **露天餐吧的高脚杯** —— 杯壁逐渐透明、粒子化，酒液失去容器束缚，
   在空中保持杯形一瞬后化作一团微粒雾散去。（继承原分镜第 17 镜 —— 全片最好的单点创意）
