# entropy_city 场景主体建立 · 固定视图集

> **规范来源**：`.claude/agent_refs/project/ai_video.md` rule 4e（场景主体）+ rule 4d §B（字段契约）。
> **视图集是场景无关的固定一套**——同一份规格将来照搬到草地、古镇、室内。
> 凡「读本片分镜表才能定」的东西一律不属于主体，属于 shot。

## 边界：一个 World，五个 Place，八个主体（rule 4f）

`entropy_city` 是一个 **World（L1）**，不是一个场景 —— 一份 `.blend`、一套几何。
广场/主街/高架/隧道/全城是五个 **Place（L2）**：判定标准是「靠同一套材质与光能不能读成一个地方」。
**主体（L3）＝ Place × State**，故共 **8 个**（5 基线 + 3 复原变体），每镜 `@` 用到的那一个。

| 主体（Place × State） | 视图数 | 选配依据 |
|---|---|---|
| `广场` 基线 | 5（正向/反向/侧向/斜瞰/材质） | 开阔地、非单轴 → 加侧向；有空中视点 → 加斜瞰 |
| `主街` 基线 | 4（正向/反向/侧向/材质） | 单轴但两侧商铺立面是主要展示面 → 加侧向 |
| `高架` 基线 | 3（正向/反向/材质） | 单轴，正反两向已够 |
| `隧道` 基线 | 3（正向/反向/材质） | 单轴封闭空间 |
| `全城` 基线 | 1（斜瞰） | 世界级布局与天际线，服务空中视点 |
| `广场复原` | 5（同基线） | 变体只重出 look 类视图 |
| `主街复原` | 4（同基线） | 同上 |
| `全城复原` | 1（斜瞰） | 同上 |

**共 26 张。** 视图集规格里的 `{地点}平面` 不在其中——平面图是**从 blend 渲**的
（`tools/render_scene_plan.py`），不是生成图，不进主体图集。

**基线态 ＝ 熵增态**（`日·阴·完好·剧情态=熵增`），视图键不带状态标；
变体带 ≤2 字状态短标（`广场正向` vs `广场复原正向`）。
高架与隧道全片只在熵增态出现，无变体（rule 4f「用到才建」）。

> 一次生成引用 1–8 个主体效果最好（官方稳定性建议），本片一镜最多用到
> 场景 1 + 车 1 + 车内 1 + 马 1 + 驾驶者 1 ＝ 5 个，在安全区内。

## 出图顺序（图先行，3D 在后）

```
① 广场正向  ← 纯文字、**不挂任何参考图**       ★ 全片视觉源头，细节做满
      │        它同时是「广场」的 look 锚点 + 整个世界的基调源
      │
      ├─► ② 主街正向 / 高架正向 / 隧道正向 / 全城斜瞰   ref = 广场正向(世界基调)
      │        │
      │        └─► ③ 各地点派生视图（反向/侧向/斜瞰/材质）  ref = 本地点正向
      │
      └─► ④ 复原态变体   ref = 对应基线图（只改色，几何一寸不改）
                │
                ▼
      ⑤ Claude 照这些图建 / 校正 3D 模型      ← **3D 是图的下游**
      ⑥ 从图里挑 + description ──► 建 8 个 Seedance 主体
```

**三层星形**：① 是世界基调源，② 各地点锚点全挂它；③ 各地点派生全挂本地点锚点。
同层之间互不参考（不链式），误差不累积；某张歪了只重跑那一张。

> ⚠ **`.blend` 永远不进出图的参考位。** 手工 blockout 就是一堆方盒子，
> 拿它当参考等于把生成图的质量上限锁死在方盒子水平——与当初废止「白模渲图当结构参考」
> 是同一个坑（rule 4e）。blend 的两个正当用途：**人看布局** 与 **previz 运镜走位**。
> 相关产物一律住 `_blender/`，不参与出图。那批旧的平面图 4 张 + 灰模透视 12 张是「灰模当出图参考」这条废止路线的遗留、已删；校验产物由 `_blender/blender_build.md` §8 的两条渲染命令按需重出。

## ②③④⑤⑥ 每张视图的 prompt 住在主体 md 里

`bg{N}_{主体名}/bg{N}_{主体名}.md`，由 `python tools/gen_scene_prompts.py` 从单一模板生成——

> 「参考 ＝ 广场正向（世界基调）」。**2026-09-01 删掉摘要表**——
> 一份 prompt 只应有一个出处（这正是 rule 4e「一个目录 ＝ 一个主体」的同一条理由）。

要看某张图的 prompt、参考、验收，直接开对应的主体 md：

## 复原态（已定：另建变体主体）

第Ⅳ–Ⅴ幕是**复原态**（颜色沿车尾流灌回、微粒升起归位），与熵增态同几何、不同色彩状态，
跨度是「饱和度近零 → 满色域」。按 rule 4f 的调色师判定——「饱和度近零 → 满色域」调色调不回来——**另建变体主体**，
而不是在原主体里混两种长相。已建 `全城复原` / `广场复原` / `主街复原` 三个，
各自继承基线的平面图，只重出 look 类视图。
