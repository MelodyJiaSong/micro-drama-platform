## 0. 这一步在干什么

一句话：**把 26 张已定稿的参考图里读得出来的几何，落进唯一那一份 `entropy_city.blend`。**

分工（rule 4g §D，四层一致性各有保证人）：

| 层 | 内容 | 谁保证 |
|---|---|---|
| **几何** | 楼在哪、多高、街多宽、桥在哪、转角看到什么 | **只有这份 .blend** ← 本步做的就是它 |
| 长相 | 色调、材质、年代、风化 | 参考图 + 场景主体（**不进 blend**） |
| 光照 | 时辰、光向、天气 | previz 灯光 + shot 的 `光线:` 字段 |
| 衔接 | 相邻镜首末帧承接 | 跨镜首帧承接机制 |

所以：**只做几何。不建材质、不建灯光、不做装饰细节、不做贴图。**
参考图上那些灰烬色、积灰、水膜、胶片颗粒——一个都不要往 blend 里搬。

## 7. 几何规矩（builder 已按这些写；改脚本时守住）


1. **只做几何。** 不建材质、不建灯光、不做贴图、不做装饰细节。
   窗框、招牌、空调外机、花池、路灯、单车、售货机、屋顶设备——**一律不建**。
   它们由出图模型画；建了既拖慢 previz，又诱使人按「好不好看」评判 previz。
2. **真实米制**，以车长 4.84m 校准（§1 尺度基准）。
3. **守 §3 空间契约**，守 §1 的三条不可动。
4. **照 §2 的图、按 §4 的表校正每个 Place**。§4 已经是裁决后的结论，直接照建；
   §5 只在你想知道某个数字为什么是这样时才看。
5. **精度按镜头接近度分级**（rule 4g §E），不按「是不是主角」：

   | 级 | 谁 | 做到什么程度 |
   |---|---|---|
   | **A · 贴身而过** | 广场四壁的底部三层；主街两侧商铺立面全长；隧道内壁全长；高架桥面＋护栏 | 真立面：墙 + 洞口位置 + 檐口 + 退进关系，按开间模数实例化 |
   | **B · 中景** | 广场四壁三层以上；主街四层以上；高架下方的街区屋顶 | 体块 + 屋顶形制 + 开窗位置，不做构件细节 |
   | **C · 远景剪影** | `FABRIC` 与天际线 | 纯体块 |
   | **D** | 建筑内部、店内、窗后 | **不建** |

6. **重复用实例化，不用复制**（rule 4g §C）：先定开间模数（主街商铺读 bg2-3 定，
   建议 4–6m 一开间），构件按模数出，拼装时自然对齐；重复感在拼装层解决
   （逐实例旋转/缩放微抖），不在建模层解决。
7. **`FABRIC` 保持确定性种子**——重跑要得到同一座城；补建/调整后 keep-out 仍让开全部走廊。
8. **命名与分区**沿用 `BG1_PLAZA` / `BG2_STREET` / `BG3_BRIDGE` / `BG4_TUNNEL` / `FABRIC`
   与 `{BG}_{ROLE}_{NN}`。

本目录只该有三类东西：**这一份指令 md** + **`.blend`** + **校验产物（PNG）**。

⚠ **场景层不出 mp4**（ai_video.md rule 4g §J）。场景 blend 里没有机位动画、没有走位、
没有时间轴，渲出来的视频不回答任何问题。场景要回答的是「几何对不对」——那是平面图 +
定机位灰模**静帧**的活儿。**唯一出 video 的是 shot previz**（`shots/shot{NN}/shot{NN}_previz.mp4`），
因为 previz 的全部价值在于「第几秒到哪」，静帧表达不了；那段 mp4 才进 shot 的视频参考位。

⚠ **校验产物不是出图参考。** 它们只回答「几何对不对」，**不进任何 prompt 的 `参考:` 行**——
拿 blockout 渲图当出图参考，会把生成图的质量上限锁死在方盒子水平（rule 4e，此坑已踩过两次）。
