# 《失光者》开发调研（2026-11-08）

第一部西幻新剧。上一版构思《贱金属》依赖炼金金属等级，用户认为不是西方主流，已移入 `ai_videos/_deleted/jian_jinshu/`，资料库同步去掉金属成色（xihuan_assets follow-up 006）。本版按用户选定的方向「被逐的圣骑士」开发，只用主流西幻元素。

## 1. 观众与市场（沿用上一版调研）

| 结论 | 对本剧的意思 |
|---|---|
| 核心观众是美国 25–55 岁女性，男性观众在增长 | 女性主角、恋爱线；圣骑士与恶魔的打斗也照顾男性观众 |
| 最稳的钩子是「隐藏身份 + 逆袭打脸」，复仇与恋爱主导付费 | 开端当众失恩；之后蒙面归来复仇（基督山伯爵式） |
| 狼人 / 命定伴侣已经很挤 | 换成圣光对深渊，竞品少、观众又熟 |
| 浪漫奇幻读者想要更暗、道德更复杂的故事，敌对到相爱最受欢迎 | 男主是恶魔亲王：不说谎，只是不说全；他和女主想要同一样东西 |

## 2. 主流参照：观众已经懂的东西

| 参照 | 观众已经懂什么 | 本剧借什么 |
|---|---|---|
| 《魔兽世界》圣骑士与圣光、恶魔 | 圣骑士 = 剑 + 圣光；圣光克恶魔 | 力量对立的基本盘（PS02 对 PS06） |
| 圣女贞德（公有领域） | 女战士被教会法庭定罪 | 开端的审判与失恩 |
| 《基督山伯爵》（公有领域） | 被至亲背叛，换身份归来复仇 | 蒙面归来、让仇人认不出她 |
| 《浮士德》（公有领域） | 与魔鬼立约，代价写在条款里 | 契约与「字面」：库里锁定的克制关系 |
| 《指环王》 | 小人物的信念比力量更重要 | 从没受膏的侍从，也能点燃光 |

## 3. IP 核对

对照[资料库附录第 3 节](../../../_shared/xihuan/appendix.md)：

| 风险 | 处理 |
|---|---|
| 魔兽「堕落圣骑士」阿尔萨斯 | 女主不堕落、不变死亡骑士；不用符文剑、冰霜板甲、蓝眼；不用 Silver Hand、Fel、Burning Legion 等专名 |
| 暗影猎人「天使血混血 + 与恶魔之子相恋」 | 女主是普通人类，光来自信念不是血统；男主是恶魔亲王本人，不是「恶魔之子」 |
| 真实宗教 | 只借教会结构（大主教、异端审判、圣徒追认）；圣徽用库里的七芒太阳盘，不用十字架与真实圣人名 |
| 骑士团名 | 用库里的「光誓骑士 Lightsworn」，不用 crusader / Templar |

没有命中禁用专名与组合。
