# 07 观众与爽点 · 《失光者》

## 核心体验

（草稿，由用户定）看一个被教会夺走光的女骑士，戴着恶魔给的面具回来，让每个出卖她的人当众跪下，最后发现光一直在她自己心里。

## 爽点

| 类型 | 在本剧里长什么样 |
|---|---|
| 当众打脸 | 比武大会上揭下面具，只用剑击败作伪证的未婚夫 |
| 隐藏身份 | 仇人都在「亲王的骑士」面前说漏了嘴 |
| 敌对到相爱 | 她和恶魔要同一顶冠冕，却爱上了他 |
| 以弱胜强 | 从没受膏的侍从，手里亮起了光 |
| 智斗 | 开端那一句「归还原主」，在高潮绑住了恶魔 |
| 观众先知道 | 只有观众看见冠冕在仪式后亮了一分 |

## 目标观众

女性向为主（美国 25–55 岁），喜欢浪漫奇幻与复仇逆袭；也照顾喜欢圣骑士、恶魔题材的游戏观众。
