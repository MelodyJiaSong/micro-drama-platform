# 02 世界 · 《失光者》

## 舞台

一座王都与它的边境。教会说圣光只由它赐予：「受膏」是教会把光赐给骑士的仪式，「失恩」是当众把光收回，失恩者一无所有。边境的深渊裂口一年比一年多。

## 种族与势力

| 名称 | 库 | 一句话 |
|---|---|---|
| 圣光教会 | OR02 | 宣称圣光只由它赐予，也只由它收回 |
| 光誓骑士团 | OR03 | 教会的圣骑士，守边抵御深渊 |
| 异端裁判所 | OR04 | 审判失恩者与异端，权力越过王庭 |
| 深渊 | RC16 | 恶魔以契约为法，渴望进入凡世 |
| 信众 | RC01 | 信教会，也被教会收赎罪税 |

## 正在发生的变化

骑士接连「失恩」，边境守不住，裂口越来越多。教会说这是罪人太多，加征赎罪税；没人想到骑士的光去了哪里。
