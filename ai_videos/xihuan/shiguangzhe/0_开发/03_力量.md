# 03 力量 · 《失光者》

两种力量对打：被说成「赐予」的圣光，和借贷来的深渊。没有统一等级，强弱看头衔与恶魔爵位。

## 力量源

| 力量 | 库 | 谁拥有 | 代价 |
|---|---|---|---|
| 圣光 | PS02+GD01 | 圣骑士、牧师；其实人人可点燃 | 信念动摇即熄灭 |
| 圣裁 | HL02 | 圣骑士 | 用尽会脱力 |
| 失恩仪式 | FL04 | 大主教主持 | 光被锁走，人以为是自己背誓 |
| 圣物冠冕 | ≈IT17 | 大主教 | 装着偷来的光，离身就漏 |
| 深渊之力 | PS06 | 维斯珀，借给签约者 | 每一分都有利息 |
| 契约 | DK01+IT08 | 维斯珀与阿维琳 | 按字面兑现，双方都受约束 |
| 驱魔 | HL04 | 审判官 | 须当面念出恶魔的名 |

## 强弱阶梯

| 层级 | 谁在这一层 |
|---|---|
| 深渊亲王 | P02 |
| 自己点燃的光 | 结局的 P01 |
| 大主教（偷来的光） | P03 |
| 骑士团长 | P04；开端的 P01（团里最强） |
| 审判官 | P05 |
| 被逐者，只剩剑 | 失恩后的 P01 |
| 侍从与信众 | P06 |

## 克制

| 克制者 | 被克制 |
|---|---|
| 圣光 | 深渊之力 |
| 契约字面 | 深渊之力 |
| 失恩仪式 | 圣光 |
| 自己点燃的光 | 失恩仪式 |
| 圣物冠冕 | 光誓骑士团 |
| 驱魔 | 深渊之力 |

失恩仪式只锁得住「以为光是教会给的」人；光由自己点燃，就锁不住。
