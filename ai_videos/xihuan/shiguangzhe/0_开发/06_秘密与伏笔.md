# 06 秘密与伏笔 · 《失光者》

## 秘密

| 秘密 | 谁知道 | 何时揭开 | 揭开后改变什么 |
|---|---|---|---|
| 卢坎作了伪证 | P04、P03（观众开端就看出） | 大转折一（对她）、大转折二（对全城） | 卢坎当众认罪，阿维琳洗清罪名 |
| 她的光流进了冠冕 | P01（仪式上亲眼看见） | 开端 | 她在契约里写下「归还原主」 |
| 冠冕里锁着每个失恩骑士的光 | P03、P02 | 大转折一 | 复仇变成夺回 |
| 光由信念点燃，不靠教会 | 无人 | 中点 | 她不再需要赦免 |
| 维斯珀要的也是冠冕里的光 | P02 | 大转折二 | 盟友成了对手，偏在她爱上他之后 |
| 玛杰丽的哥哥也被失恩 | P05 | 高潮 | 审判官当场倒戈，逮捕大主教 |
| 契约里的「归还原主」 | P01 写下，P02 没在意 | 高潮 | 恶魔被自己的契约绑住 |

## 伏笔

| 钉子 | 先看起来是什么 | 后来意味着什么 |
|---|---|---|
| 她坚持在契约上加「归还原主」，他以为只指她自己 | 骑士的固执 | 高潮时绑住恶魔 |
| 维斯珀从不说谎，只是不说全 | 恶魔的狡猾 | 他也受契约字面约束 |
| 大主教布道时冠冕总在发光 | 神恩 | 偷来的光 |
| 失恩后她的剑偶尔发热 | 余温 | 光没熄，只是被锁 |
| 托宾从没受膏，却从不怕黑 | 少年胆大 | 光来自信念 |
| 卢坎不敢看她的眼睛 | 心虚的未婚夫 | 作了伪证 |
| 维斯珀说「撕约的恶魔会失去一切，所以我从没撕过」 | 恶魔的骄傲 | 结局他撕约，失去爵位，留在凡世 |
| 玛杰丽宣判失恩前总闭眼片刻 | 程序上的祷告 | 她哥哥当年也是这样被判的 |
