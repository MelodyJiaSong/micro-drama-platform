# 西幻

欧美奇幻（西幻）剧系列。共用的世界基本元素库之外，第一部剧[《失光者》Lightless](shiguangzhe/README.md) 处于开发稿阶段。

公共资料库唯一源为 [西幻公共资料库](../_shared/xihuan/README.md)，由 `series.json` 的 `shared_library` 引用。这里不复制图片或规则；具体剧采用时在剧 README 写明库版本与条目 ID，剧内改动写在剧目录。

## 开新剧

按 [西幻新剧开发框架](framework/README.md) 建一部剧的核心 mental model：五页核心（主题 → 世界 → 力量 → 人物 → 矛盾）加「其他」（秘密与伏笔、观众与爽点，可之后补），不谈季与集；开发稿放在剧目录 `0_开发/`，用 `framework/check.py` 检查后交给故事创作模块。框架是本系列的试点，跑通后再考虑推广到其他系列。
