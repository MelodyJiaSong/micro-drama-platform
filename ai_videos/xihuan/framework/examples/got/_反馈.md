# 试套反馈：用框架 v0.1 反向拆解 HBO《权力的游戏》

范围：七页 + A1（只做第一季十集），按 HBO 剧集，不用原著补设定。凭通识写，第一季分集结尾经 Wikipedia 季页与单集页核对（E8 结尾的屏幕顺序没找到明确来源，按记忆写为珊莎求情）。

检查：`python ai_videos/xihuan/framework/check.py ai_videos/xihuan/framework/examples/got` 通过（含 A1），无错误、无提示。

过程中检查工具被另一会话更新过。旧版第一次运行就通过；新版加了「矛盾页与秘密页直接写人名」的提示，拦出 06 与 07 里的「乔佛里」「夜王」，我已改成编号，同时顺手改掉了它查不到的简称（布兰、布蕾妮等）。误报、漏报的试验都在 scratchpad 副本上做，旧版、新版各跑一遍，没有改样例，结果见第 4 节。

## 0. 总评

- **骨架是对的**：主题三级放大、「先写代价再写能力」、次要矛盾「怎样牵动主要矛盾」、秘密表「揭开后改变什么」这四个问题问得很准，拆《权游》时都能直接给出有用的答案。
- **框架有诊断力**：照着填，能自己暴露出本剧后两季被诟病的几处问题——
  - 04 代价表里夜王一栏「没有可见代价」，所以 S8E3 一刺终结显得廉价；
  - 06 演变表里 C11（丹妮莉丝与琼恩争继承权）只在最后两集爆发，她的转变没有挣来；
  - 02 的「不要什么」写了「不给主角光环」，而后两季主要人物大批生还，和核心体验相冲。
  
  一套框架能把一部名剧的已知毛病标出来，说明它的问题问在了点子上。
- **最大的短板是「单主角、高魔」的默认假设**：P01 唯一主角、对手只有一个、主要矛盾一句话、力量页围着超自然力量与灵魂成色转，碰上群像加低魔政治剧就处处要变通。第 3 节专门讲。
- **检查工具**：旧版有一个严重漏报，编号紧挨中文时（「P01与P02」「OR10的」）完全识别不到，新版已修。仍然存在的问题有三个：定义页自己的引用不查；季号 S2 与秘密 S2 撞车；人名提示只认全名。

## 1. 逐页记录

### 01 主题

- **好填**：「去掉奇幻元素还成立吗」对本剧一秒就能答（玫瑰战争），这条检验有效。一句话 32 字，一段 174 字，一页约 610 字，三级放大的节奏舒服。
- **卡住：英文 logline**。模板要求「主角 + 处境 + 目标 + 阻碍」，只能装一个主角。我只好选琼恩那条线，丹妮莉丝和兰尼斯特两条线就丢了。群像剧的推销句通常是「世界前提 + 两三个争夺者」，模板没有给这种写法。
- **问题不清**：
  - 「一页」要写「主要人物各自怎样回答主题」，这和 05 人物表的「对主题的回答」一栏、06 的「价值冲突」是同一件事，要写三遍。没说哪一处是权威、另两处可以多简略。
  - README 交接表写「主题的一句话、观众页的核心体验 → Vision 草稿」，可按 story-audience.md，一句话对应的是「核心：」，核心体验才对应 Vision。两者写成同一个去向，容易被合并成一句。
- **没地方放**：「结局有没有回答问题」只能答有或没有。答案是被挣来的还是被宣布的，没有地方记；本剧结局的争议正好出在这里，我最后写进了 06。
- **篇幅**：合适。

### 02 观众与爽点

- **好填**：核心体验、体验地图、爽点表都很顺。「多久兑现一次」一栏很好，逼人写出「每季第 9 集」这类节奏。
- **卡住：目标观众**。这一节按短剧研究来引导（女性向 / 男性向分化、`episode_seconds`），本剧是 50–80 分钟一集的付费台长剧，「权谋 + 战争 + 禁忌恋」不落在任何一类里。
- **卡住：钩子节奏**。模板只想到单集，本剧最重要的节奏在季这一层（第 9 集放大事件，第 10 集收拾后果）；我写进了钩子节奏，但模板没有这个格子。
- **问题不清：「不要什么」的例子「不拖沓的政治会议」**。对权谋剧这是误导：御前会议和密室对话是本剧的主菜。该禁的不是会议，而是「没有输赢的会议」。
- **没地方放**：
  - 爽点常见类型里没有「意外之死 / 没有主角光环」「权谋智斗」「战争大场面」「道德困境」，这几样正是本剧的招牌，要自己补。
  - 体验地图只有「全剧 / 第一季 / 每集」三层，群像剧每条线的体验不一样（艾德线是眼看他走进陷阱的无力，艾莉亚线是复仇的快感），缺「每条主线」这一层。
- **篇幅**：合适（正文约 740 字）。

### 03 世界

- **好填**：社会规则（宾客权、弑亲、私生子、逃兵）一写就是戏；「至少一条禁忌和违反的后果」这一条非常好用，红色婚礼就是从这里长出来的。「正在发生的变化」也好填。
- **卡住：库 ID 一栏**。只允许填「ID 或原创」，我实际用到六种写法，没有统一记法，检查工具也读不出差异：
  - 直接对应：`OR10`
  - 有差异：`OR03（差异）`
  - 差异大：`RC14（差异大）`
  - 组合：`OR09 + SC06`
  - 只是近似：`库外（近 GD01 + DK02）`
  - 二选一：`RC10 / BS01`
- **卡住：龙该写 RC10 还是 BS01**。本剧的龙不说话、不施法，库里 RC10 却写着「会说话、会魔法」，更接近 BS01 的猛兽形态。库里同一种东西有「种族」「生物」两个 ID，框架没说该用哪个。
- **卡住：和锁定规则相反的设定**。本剧的亡灵是冰，不怕圣光与盐，只怕火、龙晶和瓦雷利亚钢，正好违反库里锁定的克制关系。做分析时写「差异大」就行；可新剧若想要这样的亡灵，框架没说该原创一个新种族，还是借 RC14 的 ID 再改（锁定规则不许改）。
- **问题不清**：
  - 「种族与势力」把种族、组织、家族放在一张表里。本剧只有人类一个主线种族，势力却有二十来个，光贵族家族就占了 6 行 OR10。「主线种族不超过三四个」的提醒管不到势力。
  - 「舞台范围越小越好拍、三五个地点」对短剧是对的，对史诗剧没给出路。本剧的做法是每条线一个主据点，每集只去几处。
- **没地方放**：
  - **前史**。本剧的秘密几乎全埋在前史里：劳勃的叛乱、疯王、喜悦之塔。模板禁止写百科年表，这没错，可也就没有地方写「仍在发酵的前史事件」。
  - **经济与资源**：王室欠债、铁金库、兰尼斯特的金子、过冬的粮食，这些推动了大量剧情，无处可放。
  - **关系随时间变化**：关系矩阵是静态的，本剧几乎每对关系都在变（结盟→世仇），我只能写成「联姻→世仇」塞进一格。
- **篇幅**：正文只有约 560 字，信息都在三张表里（表格约 1300 字，不计入）。

### 04 力量

- **好填**：「代价与边界」一表最有价值，「绝对做不到」逼出了龙的真正限制（不能让被征服的人爱你），也照出夜王没有代价这个缺陷。「力量的社会分配」直接生出矛盾页的 C 条目。
- **卡住，也是最大的结构问题：这一页假定主力量是超自然的**。本剧是低魔世界，决定胜负的是兵力、金钱、联姻、人质、情报与合法性：
  - 库里没有这类力量源，我只好在表末加了一行「库外」；
  - 完成标准「主角和对手的力量写清强弱（可用跨体系换算表）」在这里没法用。琼恩对瑟曦比的是军队，不是灵魂成色。
- **卡住：等级**。灵魂成色主梯整个关不掉，只能写「几乎人人 TR00」。实际在用的三条梯子（头衔、武艺熟练度、兵力与财富）都没有现成的格子。
- **问题不清**：「克制」要求「引用库的锁定克制关系」，默认这些关系在本剧成立。本剧大多不成立，该怎么写没有指引。
- **没地方放**：**力量曲线**。魔法随龙长大逐季回潮，第一季几乎为零，第七季已有亡龙毁长城，这是本剧重要的设计，模板没有「每季观众看到的力量上限」一格。
- **篇幅**：正文约 820 字，偏紧但够。

### 05 人物

- **好填**：人物表七栏的问题都好，「对主题的回答」一栏最能看出群像各自站在哪。关系网的「张力」一栏也好用。
- **卡住：核心人物 5–8 个**。我的取舍：
  - 核心 P01–P14：有自己的线，跨三季以上，其选择改变了王座或长夜的走向；
  - 外围 P15–P24：线不长，但是矛盾或秘密的知情人、执行者，矛盾页与秘密页要用编号引用，所以必须编号；
  - 布蕾妮、猎狗、戴佛斯、耶哥蕊特等受欢迎的角色不编号。
  
  即便如此，矛盾页和秘密页还是有人物没有编号：知情人莱莎、佛雷与波顿家主、伊蒙学士、布蕾妮，以及前史人物雷加、莱安娜、疯王。我只能写成「其妻」「两家家主」「老学士」「一位女骑士（未编号）」「前王太子与 P05 之妹（未编号）」，绕开了「只用编号」的规则。秘密页尤其如此，最大的秘密 S4 的两位当事人都是前史中的死者，按规则根本无从引用。
- **卡住：P01 唯一主角**。本剧每条线有自己的主角，每季也不一样，第一季的主角其实是艾德（P05）。我选了琼恩当 P01，把丹妮莉丝写成「并列主角→最终对手」。
- **卡住：对手只有一个**。本剧的对手分三层：王座线是瑟曦（前四季背后是泰温），存亡线是夜王，终季是丹妮莉丝。「对手」一节我只能先声明做不到，再挑一个。
- **问题不清：角色类别**。故事指南写着「类别不中途更换」，本剧的核心手法恰恰是换类别：詹姆从对手代理变成盟友，丹妮莉丝从主角变成对手，席恩从盟友变成叛徒再赎罪，珊莎从受威胁的无辜者变成女王。这一栏需要能写「起→终」。
- **没地方放**：
  - 多条弧线。「主角的弧线」只给一个人，丹妮莉丝的堕落弧是全剧结局的支点，却只能塞进表格一格。
  - 效忠、人质与婚姻结构：谁是谁的封臣，谁在谁手里当人质，比两两关系更能说明政治局面。
- **篇幅**：正文约 770 字没问题，但人物表 24 行 × 7 栏约 2100 字不计入，接近新版的表格提示线 2500。

### 06 矛盾

- **好填**：次要矛盾的「怎样牵动主要矛盾」是全框架最好的一个问题，逼我把每条线撞到王座上。价值冲突按力量源的「怎么得来」来分（生来的血统、挣来的推举、学来的理性、取来的野心、被赐予的信仰），用在王位合法性之争上出奇地贴切，这是框架的意外收获。
- **卡住：主要矛盾只能有一条**。本剧有两条量级相当的主线，王座之争和生者对死者。我按「谁决定结局」选了王座线，把声势更大的长夜线放进次要矛盾 C1。这样写反而照出了本剧的结构问题：长夜线在终季第三集就解决了，它牵动王座线的方式只剩「消耗兵力和龙」。框架如果支持「双主线 + 汇合点」，这个问题会更早暴露。
- **问题不清**：演变表四个阶段对应八季，没有「季」一栏，阶段和季的对应得自己写进格子。
- **没地方放**：
  - **阴谋**。小指头横跨七季的长局、红色婚礼、紫色婚礼，都是「谁策划、谁执行、谁知情、何时被识破」的结构，一半落在矛盾页，一半落在秘密页，两边都放不全。
  - **多人的内在矛盾**。「内在矛盾」只给主角，詹姆（爱与良知）、丹妮莉丝（解放者与征服者）、艾莉亚（复仇与名字）的内在矛盾同样承重。
- **篇幅**：正文约 450 字，宽裕。

### 07 秘密与伏笔

- **好填**：本剧本来就是靠秘密驱动的，秘密表的六栏几乎完美。「揭开后改变什么」一栏逼人说清每个秘密的价值。伏笔表也好填，13 颗钉子都有兑现。
- **卡住：集数记法**。「观众何时知道」要写到集，长剧最自然的写法是 S3E9，这和秘密编号 S1、S2 撞了。我写「S2 公开檄文」（意思是第二季），检查工具会把它当成秘密 S2，不报错，却会悄悄误判；只好改成「第二季」。S3E9 能通过只是因为 E 紧跟在数字后面，新旧版都一样；旧版里`\b` 不成立。
- **问题不清**：
  - 「谁知道」不是静态的：布兰、山姆是后来才知道的。时间线只能挤进一格。
  - 「揭开时刻」没说是对其他人物揭开，还是对全天下公开。本剧两者常常不同：詹姆弑君的真相只告诉了布蕾妮一人。
- **没地方放**：**公开说法与真相之间的差**。全天下以为提利昂毒死了国王、琼恩是奈德的私生子、布兰和瑞肯死了。权谋剧靠这些误信运转，它们不是「藏起来的秘密」，而是「被相信的谎言」。
- **和故事指南冲突**：伏笔规则说「钉子宽、承诺窄」，每颗钉子要能接两种解释；完成标准却要求「每颗钉子都有兑现」。做反拆不受影响，开新剧时会逼人过早写死。
- **篇幅**：正文约 330 字，宽裕。

### A1 季结构与分集

- **好填**：第一季套三幕非常干净：第一幕 E1–E2，第二幕 E3–E7，第三幕 E8–E10，第 9 集是全季最大事件。「关键节点要对应 C 或 S 编号」这条把附录和前七页绑在一起，很好。
- **卡住：「主角在做什么」只有一栏**。第一季有 A 线（艾德）、B 线（丹妮莉丝）、C 线（琼恩），我只能把 B、C 线写进括号。
- **没地方放**：
  - 每集各线的出场分配：故事指南的 6:3:1 篇幅比在这里用不上；
  - 集级体验：story-audience.md 要求每集一句话体验；
  - **全剧季规划**。八季的走向（前四季王座战，五到七季汇合，第八季收束）没有页可放，只能借 06 的演变表。A1 只管一季，七页之间缺一张「全剧 × 季」的图。
- **篇幅**：合适（正文约 440 字）。

## 2. 用库的情况

本剧约四成的势力与力量是「库外」或「差异大」。库是为高魔、力量体系驱动的剧设计的，低魔政治剧会用到的这些东西库里都没有：

- 银行与信贷、雇佣兵团、奴隶制城邦、游牧骑兵民族；
- 间谍网（小小鸟）、人质制度、宾客权一类的习俗、私生子与继承法；
- 冰系亡灵、森林之子这类原住古族。

按要求我没有往库里加任何东西。但框架应该给「库外条目」一个标准出口，比如 03 和 04 末尾各一张「库外候选」表，好在 systems.md 第 12 节第 5 条「多部剧都需要的新元素再加回本库」真正发生时有据可查。

## 3. 群像与政治阴谋：框架缺的结构

| 本剧的结构 | 框架现在的位置 | 问题 |
|---|---|---|
| 三到七条并行的线，每线有自己的主角、对手、目标 | P01 唯一主角、对手唯一 | 只能在「对手」一节先声明「做不到」 |
| 每季主角不同（第一季是艾德） | A1「主角在做什么」一栏 | 只能用括号塞 B、C 线 |
| 两条同量级主线（王座 / 长夜）和汇合点 | 06 主要矛盾只能一条 | 只好把长夜线降成 C1 |
| 角色换阵营（詹姆、丹妮莉丝、席恩） | 角色类别一栏、「类别不中途更换」 | 需要能写「起→终」 |
| 长期阴谋：策划者、执行者、知情人、被谁识破 | 拆在 06 与 07 之间 | 两边都放不全 |
| 公开说法与真相（谁被冤枉、谁被认为已死） | 无 | 秘密表只管「谁知道」，不管「大家以为」 |
| 效忠、人质、婚姻构成的权力网 | 05 关系网两两成对 | 看不出层级 |
| 俗世力量：兵力、金钱、合法性、情报 | 04 只有超自然力量源 | 只能加一行「库外」 |
| 外围知情人（莱莎、佛雷、伊蒙） | 编号只有一层 P | 要么把外围人物升进核心表，要么违反「只用编号」 |

## 5. 篇幅限制

- 40 / 200 / 1000 字和 35 词合适：一句话用了 32 字，logline 用了 31 词。群像剧的 logline 最紧，但正好逼人挑一条线。
- 其余页 1000 字的正文上限从没碰到（最多的 04 约 820 字），因为信息都进了表格。真正膨胀的是表格的**行数**：
  - 03 有 21 个势力加 13 组关系，表格约 1300 字；
  - 05 人物表 24 行 × 7 栏，约 2100 字；
  - 07 有 10 个秘密加 13 颗钉子，约 1400 字。
  
  新版按字数提示（2500）。可行数才是团队记不住的根源：21 个势力每行都很短，字数提示管不到。建议再加行数软上限，比如核心人物 ≤12、势力 ≤12、秘密 ≤10。
- 05 若要写多条弧线，1000 字会紧，建议弧线也做成表。

### v0.2 新出现的问题

在 scratchpad 副本里逐条试过：

1. **故事线主角不能交接，也不查。** D 线（史塔克家）的主角是 P05→X01→P07，三易其人，中间一位是外围人物；模板「主角（P）」默认一条线一个核心主角。把这一格改成「无」，检查照样通过（V5）。完成标准写了「每条线有主角、对手、汇合点」，工具不查。建议：允许写「P05→X01→P07（季）」，并检查每行至少引用一个 P 或 X。
2. **人名提示有子串误报。**
   - 写「X21 琼恩·艾林被毒死」会提示「琼恩没带编号，请写成 P01」（V1），因为 P01 的别名「琼恩」是另一个人全名的一部分；
   - 别名「太后」这类头衔，任何一处「太后」都会提示（V8），可剧里不止一位太后。
   
   群像剧同名、同头衔很多，P01 的名字就和前首相同名。建议：同一行里先匹配更长的人名，被更长人名覆盖的别名不再提示；头衔类别名在别名列里加标记，只提示不拦，或者不收进别名。
3. **剧种要求无从落实。** 模板说阴谋表「政治、宫廷、复仇剧必填」，但它放在可选小节里，删掉也通过（V6）。建议 02 加一个机读的类型字段（如「类型：权谋」），检查工具据此把阴谋表升为必填。
4. **天降式解决只靠人填。** 代价表的「首次铺垫」「高潮是否靠它」两列都写成「季-集」后，机器其实可以比较；把夜王的铺垫改成与高潮同一集（8-03），也不报（V7）。建议铺垫晚于「高潮集减一」时给提示。本剧这一行填出来的结论正说明了问题：「夜王一死造物全灭」到 7-06 才说出，离 8-03 只隔一集。
5. **势力上限 12 逼出合并行。**

   - 学城只能挪到正文。

6. **IP 核对在试套里形同虚设。** 原作分析必然全部命中，只能写「本页是原作分析，照写」。建议 `examples/` 下的试套免填，或改填「新剧借用时的改法」。另外 IP 核对全靠手写，检查工具可以把 appendix 的英文禁用专名（Valyrian steel、Faceless Men…）扫一遍，命中就提示。
