# 07 观众与爽点 ·《权力的游戏》

## 核心体验

在一个没有人安全的世界里，看你押注的人一次次为选择付出血的代价，越怕越停不下来。

## 爽点

| 类型 | 在本剧里长什么样 |
|---|---|
| 意外之死 | 主角级人物被杀：奈德、红色婚礼 |
| 背叛与复仇 | 小指头倒戈，多年后被珊莎审判 |
| 权谋智斗 | 提利昂用嘴和脑子碾压对手 |
| 力量觉醒 | 丹妮莉丝浴火携龙而出 |
| 揭露身份 | 王子是私生子；琼恩是坦格利安 |
| 禁忌之恋 | 詹姆与瑟曦；琼恩与姑母 |

## 目标观众

付费有线台的成人观众，偏男性而兼顾两性；熟悉《指环王》、玫瑰战争史。
