# 06 秘密与伏笔 ·《权力的游戏》

故事阶段对应全剧：开端为王都陷阱，大转折一为奈德被斩，中点为两场婚礼，大转折二为长城倒塌，高潮为长夜之战与焚城，结局为选王。

## 秘密

| 秘密 | 谁知道 | 何时揭开 | 揭开后改变什么 |
|---|---|---|---|
| 王子是乱伦所生 | P04、P08 | 大转折一：P05 查出后被杀 | 王位失去合法性，诸王开战 |
| 推布兰下塔的是詹姆 | P08、P09 | 高潮前，P09 私下宽恕 | 衡量 P08 的赎罪 |
| 前首相是小指头毒死的 | P10 | 大转折二：P07 审判 P10 | 战争的第一把火是他点的 |
| 红色婚礼是密谋 | 兰尼斯特家 | 中点，当场 | 北境之王身死，北境沦陷 |
| 紫色婚礼的下毒者 | P10 | 大转折二，下毒者临死承认 | P03 被冤，逃前弑父 |
| 詹姆弑君是为救城 | P08 | 中点，只对一人说 | 重读 P08，为焚城埋线 |
| 琼恩是坦格利安合法继承人 | P05、P09 | 大转折二对观众；高潮前对 P01 | P02 的合法性崩塌 |

## 伏笔

| 钉子 | 先看起来是什么 | 后来意味着什么 |
|---|---|---|
| 凛冬将至 | 家训口号 | 长夜真的来了 |
| 三颗龙蛋 | 石化的贺礼 | 火中孵出龙 |
| 下次再谈你母亲 | 父子告别 | 身世的秘密 |
| 瓦雷利亚钢匕首 | 刺客的凶器 | 揭穿 P10，斩首夜王 |
| 「不是今天」 | 剑术课的玩笑 | P06 刺杀夜王 |
| 「烧光他们」 | 疯王的遗言 | P02 焚城 |

| 杀一个异鬼，尸鬼全倒 | 一场小战斗 | 高潮一刀终结亡灵 |
