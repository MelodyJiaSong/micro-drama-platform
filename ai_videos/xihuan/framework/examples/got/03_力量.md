# 03 力量 ·《权力的游戏》

低魔世界：决定胜负的主要是俗世权力（兵力、金钱、合法性）。这类力量库里没有对应条目，标「原创」。

## 力量源

| 力量 | 库 | 谁拥有 | 代价 |
|---|---|---|---|
| 龙 | PS07+GR06 | P02 | 长大难控，会被巨弩与冰矛杀死 |
| 光之王复活 | ≈PS02+DK02 | 红袍僧 | 每次复活丢一段记忆；大力量要人祭 |
| 血魔法 | DK02 | 厄索斯巫女 | 以命换命，换回的只剩躯壳 |
| 绿视 | SC03+PL09 | P09 | 失去自我；碰过夜王就被找到 |
| 换脸 | ≈SC06 | 无面者、P06 | 放弃名字与身份 |
| 唤尸 | 原创 | 异鬼 | 看不到代价 |
| 野火 | CF01 | P04 | 不分敌我 |
| 兵力与金钱 | 原创 | 诸侯、铁金库 | 要养要还，会倒戈 |
| 合法性 | 原创 | 铁王座 | 一个丑闻就被抽空 |

## 强弱阶梯

| 层级 | 谁在这一层 |
|---|---|
| 顶 | 夜王的亡灵大军、成年的龙 |
| 王座 | 坐上铁王座的人（P04） |
| 大诸侯 | 兰尼斯特家；有龙的 P02；北境之王时的 P01 |
| 谋士 | P03、P10：没有兵，靠头脑与情报 |
| 守夜人 | 誓言兄弟 |
| 底 | 私生子、女孩、残疾者：P01、P06、P09 的起点 |

P01 从底层爬到大诸侯，结局却拒绝王座，回到墙外。

## 克制

| 克制者 | 被克制 |
|---|---|
| 龙晶与瓦雷利亚钢 | 异鬼 |
| 火 | 尸鬼 |
| 夜王的冰矛 | 龙 |
| 巨弩 | 龙 |
| 龙 | 军队 |
| 斩首夜王 | 整支亡灵军 |
| 情报 | 武力 |
| 被轻视的小人物 | 骑士与王 |

诊断：唤尸没有代价，「斩首夜王即全灭」直到高潮前夕才说出，于是 P06 一刀终结亡灵，成了天降式解决。
