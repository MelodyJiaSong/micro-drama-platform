# 《指环王》试套反馈 · 框架 v0.1

对象：彼得·杰克逊三部曲影院版（加长版独有处已注明）。八页写完，`check.py` 第一次运行即通过。这次通过说明不了多少：后面的反例测试显示，检查工具漏掉了好几类明显的错误（见「检查工具」）。

## 总评

- **好用的部分**：主题三级放大、次要矛盾的「怎样牵动主要矛盾」、代价表的「绝对做不到」、信息差策略、「不要什么」。这几处逼我把《指环王》为什么成立说清楚，比如阿尔玟线之所以不游离，是因为它推动埃尔隆德重铸圣剑。
- **卡住的部分**：框架默认这是一部单主角、单线、有成长体系、靠力量解决冲突的短剧。《指环王》四条全不符合：从第一季末开始三线并行；核心力量是负担而不是工具；没有等级；高潮里主角输了。卡住的地方都集中在这四点上。

## 逐页记录

### 01 主题

- **好填**：三级放大很顺。一句话 32 字，一段 183 字，一页 664 字，logline 32 词，都在上限内，上限合适。「不含人名、罩得住每条线」这条检验有效：初稿写的是「拒绝力量」，罩不住阿拉贡（他的线是承担王位，不是拒绝），所以改成「守住自己」。
- **问得不清楚**：「一页」要求按「起点 → 被打破 → 追求 → 最大危机 → 结局方向」写，同时又说「不写成流水账」。这个结构本身就是按时间顺序排的，反向拆解时很自然就写成了梗概。真正属于「放大主题」的内容是「各人怎样回答」那一段。
- **没地方放**：「写之前问自己」的三个问题（例如「去掉奇幻元素还成立吗」，《指环王》的答案是成立：成瘾与战争）和「完成标准」勾选都没地方记录。
- **交接不清**：README 写的是「一句话 + 核心体验 → Vision 草稿」，但 story-audience 把 Vision（感受）和「核心：」（关于什么）分成两行。实际对应关系应该是：一句话 → 核心，核心体验 → Vision。现在写法容易把两者混在一起。

### 02 观众与爽点

- **好填**：「不要什么」最有价值。写出「不让主角用戒指解决问题」「不让主角升级」，本剧的底线就清楚了。
- **卡住**：
  - 爽点类型列表偏短剧言情和逆袭（打脸、逆袭、禁忌之恋）。《指环王》最核心的兑现是援军到达、拒绝诱惑、悲壮牺牲、归来、并肩，列表里一个都没有，只能自己加，并标「模板未列」。
  - 打脸和逆袭在本剧几乎不用，因为主题反对以力压人。
- **问得不清楚**：「钩子节奏与集长匹配」在没有 `episode_seconds` 时不知道怎么填。「多久兑现一次」的单位不明（集？季？）。
- **没地方放**：多线交叉剪辑。这是《指环王》主要的钩子手法：一条线停在危险最高处，切到另一条线。模板只有「每集开头 / 结尾」，没有「线」的概念。

### 03 世界

- **好填**：「正在发生的变化」「社会规则（禁忌 + 后果）」两小节写起来快，也有用。
- **卡住**：
  - 种族和势力放在同一张表里不顺。「人类」要拆成刚铎、洛汗、游侠、南方人四个政体，每个都写 `RC01 + OR11`。
  - 表里没有「与库的差异」列，我只好自己加一列。README 说差异写进 `xihuan_adoption.json`，但开发稿阶段还没有这个文件。
  - 模板只给「库 ID / 原创」两种状态，实际需要四种：
    - 精确对应，例如 RC19。
    - 近似对应，例如炎魔近 RC16、翼兽近 BS02。
    - 库外：传统或类型里通用、但库里没有的东西，例如树人、巨鹰、巨蛛、战象。这类是入库候选。
    - 原创：本剧专属，例如魔多、强兽人。
- **规则与作品冲突**：
  - 模板说「三五个主要地点」「主线种族不超过三四个」，《指环王》有 8 个地点、十多个种族，照样记得住。原因是每到一站只引入一个种族，而且每族有一张脸（洛汗 = 希优顿，罗斯洛立安 = 加拉德瑞尔）。更好的规则是「每段新引入的种族不超过一个，每族绑定一个 P 编号」。
  - 关系矩阵需要「代表人物」，但这一页写在人物页之前，此时还没有 P 编号。
- **没地方放**：
  - 关键前史：伊西铎没有毁戒。这件三千年前的事是阿拉贡心结和埃尔隆德不信任人类的根源。最后只能塞进人物表（加了 P23）和秘密页。
  - 旅程路线：远征故事里，地图本身就是情节。
- **与库的对照（只记录，未改库）**：
  - 吻合好的：RC02/RS01/RS02、RC03、RC07、RC19、RC14 + FL04（背誓的亡者）、GR03、IT24（晶石「只说真话但不说全」）、IT19/IT29（重铸王剑）、DK03（魔窟刀）、FL02/FL03（腐蚀与附身）。
  - 方向相反的：RC06 兽人在库里刻意写成有习惯法的战士民族，影片里是无面目的作恶仆从；BS12 恐狼在库里是游侠伙伴，影片里是敌方坐骑；CL10 法师是学院学者，影片里的巫师没有学院、来历不明。
  - 库里没有的：巨蛛、巨鹰、树人、战象、「被培育出来的种族」、成套分赐的戒指体系、「王位空悬、宰相摄政」、精灵渡海离去。

### 04 力量

- **卡住最严重的一页。**
  - 模板默认力量是主角的工具箱和升级路线，例如「主角最终到汞阶」「弱者靠克制以小胜大」。《指环王》的核心力量是负担和麦格芬，同时又是贴身对手。主角从头到尾不施法、不变强。
  - 「力量源（PS 编号）」要求先知道力量是怎么得来的。影片是软魔法，巫师和精灵的力量来源都不交代，只能写「库外，表现近 SC01/SC04/EL04」。
  - 「等级」是必填项，但影片没有等级。硬套灵魂成色（戒灵约 TR05、甘道夫约 TR06–07）对理解影片毫无帮助。真正起作用的是一条隐性等级：谁扛得住戒指（霍比特人 > 法拉米尔 > 波罗米尔 > 萨鲁曼 > 咕噜）。模板没有问「本剧真正的强弱轴是什么」。
- **好填**：代价表的「绝对做不到」一列；Sanderson 第一定律的提醒。我借这两处检查出影片的两次「天降」：巨鹰在第一季只露过一次面，亡者大军在同一季内铺垫完就立即解决战局。但模板没有专门的列来记录这件事。
- **问得不清楚**：「主角和对手的力量写清了强弱关系」。主角没有力量，对手的力量没有量化，这一条无法回答。
- **没地方放**：
  - 非力量的克制：怜悯决定结局；「没有男人能杀死他」是预言漏洞。模板只让引用库的锁定克制关系。
  - 至尊魔戒同时叠了 IT26、IT28、IT20、FL02 四个条目。库 IP 表的「组合禁用」第三行（隐身 + 支配 + 长生 + 噬主金戒）写的就是这枚戒指，但力量页和世界页都没有「IP 核对」这一步。如果是新剧，这种问题要到很后面才会被发现。

### 05 人物

- **卡住**：
  - 「核心人物 5–8 个」。因为矛盾页和秘密页只能用编号引用，凡是要被提到的人都得进人物表，最后编到 P23（连序幕里的伊西铎都要编号）。表有 7 列 × 23 行，在窄屏上没法读。
  - 「对手只有一个，有自己的道理」。索伦在片中只是一只眼睛，没说过自己凭什么是对的。影片把对手的道理分给了萨鲁曼、波罗米尔、德内梭尔三人，真正贴身的对手是戒指这件物。模板只能装一个「人」作对手。
  - 「主角的弧线」只有一个主角。阿拉贡（B 线主角）、山姆、伊奥温、希优顿都有完整弧线，没地方写。
  - 「类别不中途更换」：波罗米尔是对比盟友，在阿蒙汉变成阻碍；咕噜既是向导又是阻碍。模板没有「表面类别 / 真实类别（隐藏意图）」一列，而 story-characters 明确允许角色隐藏真实意图。
- **问得不清楚**：「种族 / 职业 / 成色」里的成色，对多数人只能写「未量化」，这一栏成了噪音。「主目标贯穿全剧」也不完全成立：阿拉贡的目标从「护送」变成「称王」。
- **没地方放**：开场同情来源。模板链接了同情来源一页，但没有字段记录用了哪几种。

### 06 矛盾

- **好填**：「次要矛盾 → 怎样牵动主要矛盾」是整个框架里最有用的一列。八条次要矛盾都能接回主线，阿尔玟线接在重铸圣剑上，伊奥温线接在斩杀巫王上。内在矛盾的「逼选时刻」也好填：阿蒙汉、奇立斯昂哥台阶、火山口三处。
- **卡住**：
  - 「价值冲突」要求按力量源的「怎么得来」和五个固定价值（秩序、求知、野心、自由、自然）对照。很多角色没有力量，这一项只能硬凑。《指环王》真正的价值轴是「占有 vs 放下」「希望 vs 绝望」，这两条是从主题一句话里导出来的，不在五个固定价值里。
  - 演变表的四个阶段没说明范围是全剧还是每季。我按全剧填，又和 A1 的分季节点对了一遍。
- **只用编号的代价**：转成纯编号之后，「P03 劝 P01 别说 P05 该死」这样的句子，不翻人物表就读不懂。检查工具也查不出页面里写了名字没写编号：我初稿用了几十处人名，照样通过。
- **没地方放**：倒计时，例如阿尔玟日渐衰弱、白城被围、佛罗多越来越走不动。

### 07 秘密与伏笔

- **好填**：信息差策略。《指环王》以悬念为主、在转折点用同步惊奇，这一节写起来很顺。
- **问得不清楚**：「揭开时刻」没说是对谁揭开：人物还是观众？「观众何时知道」和「揭开时刻」经常是同一刻，我只能在格子里写「与 P01 同步」。真正关键的「谁被蒙在鼓里」（佛罗多不知道咕噜的计划）也没有列。
- **顺序问题**：秘密页要写「第几集揭开」，但分集要到 A1 才排。新剧写到 07 时还没有集号，这里应该先用「季 / 幕 / 节点」的粒度，等 A1 排好再落到集。
- **伏笔表**：「关联秘密」一列多数填「—」。《指环王》的钉子大多是物件的铺垫与回收（刺叮剑、星光瓶、精灵绳），关联的是矛盾而不是秘密。另外缺「可能的接法」列，story-foreshadowing 的要求是「钉子宽，至少两种接法」。

### A1 季结构与分集

- **卡住**：
  - 模板只排「第一季」。三季只能自己约定「季-集」编号，每季重复一次三幕，全剧弧和各季弧要自己分层写。
  - 「主角在做什么」一列只装得下一条线。第二季另外两条线只能挤在括号里。
  - 分集表没有「推进哪条线」「本集体验」两列。前者对多线剧必不可少，后者是 story-audience 的集级体验要求。
- **好用**：每部电影的「两次大转折 + 中点」都落得很准，说明三幕结构放在季这一层是对的。

## 篇幅限制

| 限制 | 实际 | 判断 |
|---|---|---|
| 一句话 ≤40 字 | 32 | 合适 |
| 一段 ≤200 字 | 183 | 偏紧但合适，逼人删 |
| 一页 ≤1000 字 | 664 | 合适 |
| logline ≤35 词 | 32 | 合适 |
| 其余页正文 ≤1000 字 | 257–596 | **管不住**：内容都在表格里，表格不计字数 |

各页表格内容约 450–1700 字（03 有 21 行，05 有 23 行，A1 有 34 行）。03 的「与库的差异」格子里我写的其实是小段落，违反了「表格不写成段落」，检查工具看不出来。这条规则需要可测的约束，例如单元格上限 60 字，或表格总量另设上限。

## 检查工具

- **实际运行**：第一次就通过，没有误报。
- **漏报（已在副本上验证）**：下面这份副本把内容故意改坏，仍然显示「形式检查通过」。
  - 爽点表只留表头、删掉所有行（模板要求至少三类）。
  - 正文写「引用了不存在的人物P99与矛盾C99……库条目RC99型」。原因是 `\b` 在 Python Unicode 模式下把汉字当作单词字符，编号紧贴汉字时匹配不到。实测「精灵RC02」「由P01发起」「见C9和」「IT26型」都匹配不到。
  - 03 种族表某一行的库 ID 删空（模板要求每行都有 ID 或「原创」）。
- **其他问题**：
  - 首列编号加粗（`| **P01** |`）不会被识别为定义，会报「表第一列没有 P 编号」。
  - P 编号必须两位数，`P1`、`P123` 会被静默忽略；C、S 却允许任意位数，规则不一致。
  - 有潜在误报：`S2 季`、`C4 炸药` 这类非编号用法会被当成秘密或矛盾引用。
  - 检查工具不核对 06/07 是否用了人名而没写编号，不核对「至少一个秘密在第一季内揭开」，不核对 A1 引用的 C/S 编号与 06/07 的集号是否一致。
- **好的一面**：工具忽略目录里的额外文件（如本文件），必填小节从模板读取，规则只维护一处。

## 框架修改建议（按重要性排序）

1. **加入「故事线」概念**。在 02 或 05 新增「线」表：A/B/C 线各自的主角（P 编号）、目标、对手、篇幅占比、在哪里汇合。02 的钩子节奏写交叉剪辑，A1 分集表加「推进哪条线」列，06 的次要矛盾标所属线。依据：《指环王》从第一季末起三线并行，框架里没有任何地方能放下这件事；story-series 的 A/B/C 6:3:1 也没有落到框架里。
2. **04 力量页支持「力量是负担 / 麦格芬」和软魔法**：
   - 新增「核心力量物」小节：谁想要它、为什么不能直接用、用了会怎样、怎样才能摆脱。
   - 「等级」允许填「不设」，改问「本剧真正的强弱轴是什么」（可以是抵抗诱惑，而不是战斗力）。
   - 「力量源」允许填「来源不交代」。
   - 代价表加「首次铺垫在哪」「高潮是否靠它解决」两列，用来自动发现天降式解决。
   - 克制允许非力量项，例如怜悯、预言漏洞。
3. **05 人物页重构**：
   - 分成「核心人物」（≤8，全字段）和「次要人物」（编号、名字、类别、一句话目标）两张表，检查工具两张都认。
   - 「对手」允许是力量、物或处境，同时写「代言人（P 编号）」和「对手的道理由谁说出口」。
   - 「主角的弧线」改成「各线主角的弧线」表。
   - 加「表面类别 / 真实类别」和「开场同情来源」两列。
4. **修 check.py 的漏报**：
   - 编号与库 ID 的边界改用 `(?<![A-Za-z0-9])…(?![A-Za-z0-9])`，汉字相邻时也能匹配。
   - 只有表头的表格算空小节；首列允许加粗。
   - P、C、S 位数规则统一。
   - 03 种族表每行必须有库 ID、近似 ID、「库外」或「原创」之一；02 爽点表 ≥3 行。
   - 06/07 出现人物表里的名字但没带编号时报警。
   - A1 的 C/S 引用、07 的集号与 A1 的分集表要对得上。
   - 表格单元格设字数上限。
5. **库映射语法与 IP 核对**：
   - 统一四种写法：`RC19`（精确）、`≈RC16`（近似）、「库外」（入库候选）、「原创」（本剧专属）。03/04 的表加「与库差异」列。
   - 03/04 末尾加「IP 核对」一行，对照 appendix 第 3 节的禁用专名与组合禁用。《指环王》的魔戒正好命中组合禁用第三行，新剧要在开发稿阶段就拦住这种问题。
   - check.py 汇总各剧的「库外」条目，作为入库候选清单。
6. **07 秘密表改列**：
   - 拆成「人物何时知道（谁、何时）」「观众何时知道」两列，再加「信息差类型（悬念 / 惊奇 / 谜题）」和「谁被蒙在鼓里」。
   - 揭开时间在 A1 之前用季、幕、节点表示，A1 排好后再落到集号。
   - 伏笔表的「关联」允许填 C 编号，并加「可能的接法（≥2）」列。
7. **A1 支持多季**：三幕表加「季」列，另起「全剧弧」小节，加「季末钩子」；分集表加「线」和「本集体验」两列；编号格式定为「季-集」，不用 S1E1，以免和秘密编号冲突。
8. **02 爽点类型扩充**：加入援军到达、拒绝诱惑、悲壮牺牲、归来、并肩、绝境守城，并区分「情感兑现」和「力量兑现」；「多久兑现一次」写明单位；没有 `episode_seconds` 时允许填「不适用」。
9. **03 世界规则改写**：
   - 「三五个地点 / 三四个种族」改成「每段新引入的种族不超过一个，每族绑定一张脸（P 编号，可以写完人物页再回填）」。
   - 种族表和势力表分开。
   - 新增「关键前史（≤3 件，只写影响人物选择的旧事）」，以及可选的「旅程路线」。
10. **06 价值冲突的轴由主题导出**：不再固定五个价值，改成「从一句话的问题里拆出两条对立轴」。演变表注明范围（全剧 / 本季）；加可选的「倒计时」。

### v0.2 新出现的问题

1. **检查工具仍不核对结构一致性**（已在副本上验证）。下面每一项改动之后检查仍然通过：
   - 秘密表写了不存在的集号 `9-99`；
   - 写了旧记法 `S3`（不再报错，也不提示）；
   - 关键前史删掉了 M 连接；
   - 次要矛盾的「所属线」写成故事线表里没有的 `Z`；
   - A 线主角写成 P02（README 规定 P01 为 A 线主角）。

   另外，人名提示按整行判断：一行里只要出现过 P01，同一行里没带编号的「佛罗多」就不会被提示。
2. **12 人上限把矛盾当事人挤进外围**。德内梭尔是 C4、C6 的一方，法拉米尔是 C6 的一方并拒绝戒指，二人都只能进 X 表，只剩「一句话作用」，没有主目标与缺陷。树须只为满足种族「每族一张脸」才编了号。建议外围表加可选的「主目标」列，或允许「矛盾当事人」进核心而不计入上限。
3. **天降检查只按集数**。亡者大军 3-04 首次提到、3-08 解决战局，形式上满足「早于高潮一到三集」，观众仍普遍觉得是天降：铺垫只在同一季，而且没先让观众看过它的限制。「高潮」指本季高潮还是全剧高潮，规则也没说。建议改成「铺垫要交代限制或代价」，全剧级的解决手段要在前一季就铺垫。
4. **类别提示误伤对照用的 ID**。「与库差异」列里写「最近的是 GD03」会触发「类别不对」，为了清掉提示只能删 ID，反而丢了可追溯性。建议类别检查只看「库」列。
5. **种族表混着生物**。巨鹰、尸罗、巨魔、座狼、翼兽、猛犸没有可绑定的脸，「代表人物」只能填「—」。「每段新引入不超过一个种族」在 1-08 就被打破（矮人亡者、巨魔、炎魔同集出现），影片照样成立。建议新增可选的「生物」表，不要求代表人物，也不计入种族规则。
6. **秘密表 8 列太宽**。「谁、何时知道」与「对人物揭开」经常重复；「公开」一列对永不公开或只对观众揭开的秘密（M6、M7、M10）只能填「不公开」。建议把「公开」改成可选列。
7. **logline 与 Ensemble premise 共用 35 词**。A 线 logline 已用 32 词，群像前提实际写不进去。建议群像前提单列，上限约 25 词。
8. **主要弧线限 3–5 人**。山姆（跟班 → 希望救星）与波罗米尔（堕落 → 赎罪）的完整弧线放不进去，只能散在核心人物表的「角色类别（起→终）」里。可以接受，但对群像剧偏紧。
