# 02 世界 · 《指环王》

## 舞台

一整片大陆（中土西北部），铁器时代末到中世纪早期的样子。旅程一路从绿丘走到雪山、地底、金色森林、草原、白城，最后是火山荒原。

## 种族与势力

| 名称 | 库 | 一句话 |
|---|---|---|
| 夏尔 | RC19 | 霍比特人的乡间，只想不被打扰 |
| 精灵 | RC02 | 长生，正渡海离开中土 |
| 刚铎 | RC01+OR11 | 衰落的人类大王国，王位空悬、宰相摄政 |
| 洛汗 | RC01+OR11 | 骑马民族的小王国，王被附身 |
| 艾森加德 | 原创 | 叛变巫师的塔、熔炉与强兽人私军 |
| 魔多 | 原创 | 索伦的国度：奥克（≈RC06）、戒灵（≈RC14） |

## 正在发生的变化

索伦重聚力量，沉睡六十年的魔戒醒了，要回到主人身边；精灵撤离，人类王位空着。
