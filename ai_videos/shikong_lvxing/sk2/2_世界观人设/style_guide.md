## 0. 第一条规则：蓝色尖顶母题

**这是「一眼认出暴风城」的真正机制**，文字来源里无人写过，由读图得出（`look_from_images.md` §1.9）。

```
全城贯穿母题：同一个「陡坡收尖 + 蓝色瓦面」的形状，在三个尺度上重复——
街灯灯笼顶（最小）→ 民居与塔楼的圆锥屋顶（中）→ 大教堂的细高尖塔群（最大）。
```

**执行**：凡拍城市全景、街景或含建筑的中远景，**画面里至少同时出现其中两个尺度**。这一条比任何单独的材质描述都更决定「像不像暴风城」。

## 1. 画风定义（半写实的操作口径）

| 层 | 走哪边 | 具体 |
|---|---|---|
| **形制** | **忠于游戏** | 屋顶形状、塔的比例、城垛齿形、狮子与狮鹫纹章、街灯造型、招牌做法、雕像姿态 |
| **配色** | **忠于游戏** | 蓝顶白石、区域色系（见 §2）、蓝底金狮 |
| **比例** | **忠于游戏** | 雕像高过城墙、城门高过树冠、矮人区层高压低 |
| **材质** | **写实电影级** | 石材的孔隙与风化、木料的纹理与开裂、金属的磨损与氧化、布料的织纹与垂坠 |
| **光线** | **写实电影级** | 真实的光源方向与衰减、体积光、大气透视、软阴影 |
| **皮肤与毛发** | **写实电影级** | 真实的皮肤次表面、毛孔、汗光、发丝 |

**一句话**：**照着游戏的形，用实拍的料和光重做一遍。**

**两头都要防**：
- 往游戏那边滑 → 塑料高光、赛璐璐描边、过饱和、低多边形、UI 残留
- 往写实那边滑 → 变成通用欧洲中世纪石城、米那斯提力斯、灰褐色、红瓦茅草——**丢掉蓝顶白石就不是暴风城了**

## 3. 建筑语汇锁定串（逐条 byte-identical 复用）

### 3.1 墙体
```
暖白偏浅灰的石灰岩砌体，石块方正而大、一块约与人躯干等宽，灰缝浅而宽、可见凹槽；表面经年略泛米白与浅灰，有轻微污渍与色差；墙体厚重，转角与基座石块更大
```
*负向*：`红砖, 混凝土, 玻璃幕墙, 抹灰, 木板房, 夯土, 瓷砖, 细密灰缝, 灰褐色石墙`

### 3.2 屋顶
```
陡坡瓦顶，瓦片呈鱼鳞状层叠、边缘厚薄不匀；坡面或为四坡、或收成圆锥尖顶，屋面上开三角形山墙老虎窗；屋脊与檐口有浅色石或木收边
```
*负向*：`红瓦, 琉璃瓦, 茅草, 金属波纹板, 沥青瓦, 平顶`（旧城区镜除外——那里正是暗红褐顶）

### 3.3 窗
```
矩形木框多格窗，木棂把窗面分成四到六格，格内玻璃偏暖黄、夜里从室内透出暖光；窗框与墙面平齐略凹，外沿一圈浅色石套
```
*负向*：`尖拱窗, 哥特花窗, 圆窗, 落地窗, 平板玻璃, 无框玻璃, 铝合金窗`

### 3.4 门洞
```
半圆拱门洞，拱券由楔形石块砌成、拱线清晰；门套为浅色石砌、比墙面略外凸；门扇为深棕厚木板拼合、带黑铁合页与门钉；民用门洞偏矮偏窄
```
*负向*：`尖拱门, 高大双开门, 通高玻璃门, 自动门`

### 3.5 半木结构立面
```
一层为白色石砌基座，二层挑出，深棕色木构架外露——竖柱、横枋与斜撑构成方格与人字，格内填白灰泥墙面；转角与门窗周围木料加厚；木色偏深褐、经年发灰，白灰面略有污渍与色差
```

### 3.6 街灯
```
黑铁立杆，方形石质基座，杆身约两人高、中段有一圈装饰箍；杆顶是四面菱形玻璃的灯笼，灯笼顶收成一个小尖顶、四角挑出小尖角，罩内是暖黄色火光
```
*负向*：`电灯, 灯泡, 路灯杆, 霓虹, LED, 玻璃灯罩`

### 3.7 招牌（**画面零文字的正向依据**）
```
门前以一根横木悬臂外挑，横木两端各垂一条黑铁链，链下吊一块厚木牌；木牌四角包铁，牌面是一整块浮雕图形——一件衣服、一只酒杯、一柄剑、一条面包——以形表意，牌面上没有任何文字
```
**读图证实：游戏里的招牌本来就是图形浮雕、零文字。画空白/纹样木牌不是妥协，是还原。**

### 3.8 铺地（三种，按区分用）
```
① 主干道与广场——大块米白偏浅灰的矩形石板，块面大、缝浅，表面被踩得微微反光
② 人行带与街沿——深色小砖以人字纹斜向交错铺砌，与主道之间有一道窄石缘分隔
③ 巷道与旧城区——灰色不规则卵石铺地，石块圆钝、缝隙积细尘，间或穿插红褐色砖带
```
*负向*：`柏油, 水泥, 沥青, 现代方砖, 整版同向铺砖, 土路为主`

### 3.9 城墙与塔楼
```
城墙为大块方石砌体，墙顶方齿城垛、齿宽与齿间空档大致相等；墙段之间以半圆拱过街桥相连。塔楼圆柱形，塔身开竖长条窗，顶部出挑檐口后收方齿城垛，或戴蓝色圆锥顶
```

### 3.10 运河与护岸
```
运河护岸为白石砌直壁，岸顶一道矮石栏、栏板顶面起伏成连续的浅齿；栏侧固定黑铁系缆环。水面明净偏蓝绿、微微反光，堤顶到水面有明显落差
```
*负向*：`淤泥, 芦苇, 半干涸的运河, 露出水面的杂物, 能趟过去的浅水, 混凝土渠, 浑浊黑水`
**注**：Vanilla 是**深水**；半淤浅是 4.0.3a 才改的。

### 3.11 桥
```
厚重白石拱桥，桥拱高起，两侧实心石栏板，栏板顶面磨得发亮
```

### 3.12 纹章与旗幡（两个不同的东西，各锁各的）
**旗幡（垂幡 / 罩袍 / 盾面）**
```
群青蓝底，正中一枚金色狮首纹章，四周一道金色饰带，下摆分成两到三个尖角；布面厚重，随风缓摆
```
**盾徽（盾形纹章）**
```
银白底，正中一枚正面朝前的金色狮首，狮首外缘镶一道钴蓝细边；外圈金色边框同样镶钴蓝细边
```
*负向*：`红底纹章, 绿底, 黑底, 双头鹰, 十字纹, 百合花纹, 侧面狮身, 站立狮, 双狮`

### 3.13 街具
```
深棕木花槽（正面有卷草纹浅雕，内种低矮灌木）· 横档式木栅栏 · 堆放的木桶与板条箱 · 石砌圆井（井口石砌、上架两根交叉木柱与一根横轴辘轳）· 弧形石凳 · 结红果的苹果树
```

### 3.14 室内木作（酒馆 / 旅店堂屋）
```
通高木构大厅，屋顶露明木梁与斜撑；地面为宽木板、板缝清晰、被踩得发亮；墙面下段木护板、上段白灰；长条木吧台，台后多层木货架上横放木酒桶、绿色玻璃细颈瓶、陶罐、木碗、锡杯；厚木长桌配竖板条高背椅；照明只有屋顶垂下的木环烛台、墙上与桌上的烛台、石砌壁炉的火光
```
*负向*：`酒店前台, 柜台登记簿, 房卡, 电灯, 玻璃扎啤杯, 不锈钢, 现代吧台, 高脚凳, 霓虹`

## 6. 光线与时段

| 时段 | 光 | 用在 |
|---|---|---|
| 清晨 | 低角度暖金侧逆光，长影，薄晨雾贴地 | 航拍开场 · 英雄谷 |
| 上午 | 高位偏白日光，影子短而硬，天空明亮蓝 | 贸易区 · 旧城区 |
| 正午 | 顶光，反差最大，石面反光强 | 要塞 · 王座厅（**厅内靠高窗斜落的光柱**） |
| 午后 | 暖白偏黄，影子拉长 | 矮人区（**此处叠暖橙炉火**）· 地铁（**全封闭，光只来自隧道灯具**） |
| 傍晚 | 橙金低光，天空由蓝转琥珀 | 大教堂（**内厅高窗光柱**） |
| 日落 | 强逆光，天空品红与橙的渐层 | **花园区月亮井（本片最好的一张画）** |
| 入夜 | 深蓝天空 + 暖黄街灯点 | 法师区（**叠紫色奥术灯**）· 运河 |
| 夜 | 极低照度，光源只有街灯、窗内暖光、卫兵油灯 | 回旅店 · 吹灯 |

## 7. 镜头语言

- **画幅 16:9**（系列 divergence #1）。
- **单镜 20–30 s**；相邻镜按「硬切 + 景别跳档」设计，`人占画高` 比值 ≥ 2.0 或 ≤ 0.5 且机位标签不同（CLAUDE.md 景别档铁律，生成器 `jb= / jbcam=` 逐对机检）。
- **一镜内可辨主体 ≤ 8**（rule 4g ⑥）；人群做成低模剪影群算 1 个主体。
- **唯一的承接首帧对**：航拍开场两镜（I-14）。
- **每站 ≥ 1 个一镜到底穿街长镜**：本站是英雄谷石桥 → 贸易区喷泉（181 m ≈ 79 s，**切 3 段，三段机位标签互不相同**）。
