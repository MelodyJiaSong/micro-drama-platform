# 暴风城入城段形制规格书 —— 城门 + 英雄谷（Vanilla 锚定）

> **面向 S01–S07**：从城外沿大道低飞 → 穿城门 → 掠过英雄谷 → 望见贸易区。
> **版本锁死**：经典旧世 Vanilla（1.x / Classic），**大灾变 4.0.3a 之前**。
> **图证**：`ref/refs.md`（14 张，全部亲眼放大 2–6 倍判读；**一张都不入画、不上传生成模型**）。
> **置信度记法**：`✅` ＝ 两张及以上独立图互证；`⚠️` ＝ 仅单图或仅由比例反推。

## 0. 开工前自查对账（`ai_video.md` rule 4i ③）

本文写的是**真实形制**，不是**现状**。开工前先对三件事：

1. **现状是什么**：`tools/build_stormwind.py` 的城门段 ＝ 方墩 + 实心过梁 + 两根光秃圆柱 + 灰棱锥帽，
   门外 180 m 石板引道摆 4 对空基座，门内主路两侧摆 **5 对（10 尊）** 箱体巨像。
   **几乎每一条都与实物不符**，差距逐条见 §6。
2. **本文的边界**：只覆盖**城门 + 英雄谷**（原点向内 0–150 m）。贸易区内部、运河环线、其余各区不在本文内。
3. **本文没有推翻的东西**：`0_research/parts/w1_city_layout.md` 的 GM 世界坐标表仍然是全城骨架的
   唯一坐标源；本文的入城段尺寸是**在该骨架内部**做细化，不改任何锚点。

## 1. 坐标系与总平面

**本文坐标系（局部，建模直接用）**

- **原点 O** ＝ 城门洞正中的地面点（两扇木门之间、门槛线中点）。
- **+Y** ＝ 入城方向（朝城内）。**+X** ＝ 面朝城内时的右手（＝东侧）。**+Z** ＝ 上。单位：米。

**与 `build_stormwind.py` 现有 (east, north) 骨架的换算**（城门锚点已经在原点，直接套）：

```
局部 +Y 方向 = (east, north) = (-0.6245, +0.7813)     # 入城方向：北偏西 38.6°
局部 +X 方向 = (east, north) = (+0.7813, +0.6245)
# 由 ANCHORS["城门_英雄谷"]=(0,0) → ANCHORS["贸易区南入口"]=(-112.8, 141.1) 归一化得到，
# 即入城主轴并非正北，这一点与 r12 旧世界地图上英雄谷斜向西北的走向一致 ✅
```

**总平面（沿 +Y 的里程桩）**

| Y（m） | 内容 |
|---|---|
| −60 … 0 | **城外**：艾尔文森林一侧。只有**土路/碎石小径 + 草地 + 零星针叶小树**，两侧是**土黄色陡峭岩壁**夹峙。**没有石板引道、没有基座、没有夹道林带、没有护城河、没有吊桥**（r03/r05 门外地面 ✅） |
| 0 | **城门线**：两扇巨型木门（常开外张，贴在两侧塔基上）。**门上方无过梁、无拱券、无吊闸**——是两座圆塔之间的一道豁口 ✅ |
| 0 … 8 | 门内短平段，木门槛横梁 |
| 8 … 45 | **护城水面段**：引道左右各一片水面，引道从中间以石堤形式穿过；水面北缘一道**蜜色木横梁护栏** ⚠️ |
| 45 … 110 | **英雄谷长直段**：三层铺装（中央石板主路 + 两侧人字砖步道），灯柱密排，**无雕像** |
| 110 … 145 | **雕像区**：南对（库德兰 W / 丹娜斯 E）在 Y≈118，北对（卡德加 W / 奥蕾莉亚 E）在 Y≈136 |
| ≈148 | **北端屏墙**：带方齿雉堞的横墙，东西各开一座大圆拱；中轴是**图拉扬方台**，台后大阶梯 |
| 屏墙之后 | 蓝瓦半木建筑（贸易区口）→ 再后方是**光明大教堂尖塔群**的剪影 |
| ≈181 | 贸易区南入口（GM 坐标算出的直线距离，T3） |

> **本段最容易建错的一条**：五尊雕像**集中在北端**、不是沿全程等距排开。
> 从城门望进去，前 100 m 是一条只有灯柱的空旷石堤，雕像在尽头忽然压过来——
> 这个「先空后压」的节奏就是入城段的戏。r01 / r02 / r03 三图一致 ✅

**铭牌**：每尊基座侧面一块题献铭牌（文字见 wikitext《Valley of Heroes》§Statues；署名分别为

**统一造型语汇**：石材是**冷调月白灰**，但**盔甲边饰、纹章、腰扣、袍纹一律以暗金/土金色勾出**——
这是雕像最重要的一条：**它们不是素灰石像，是带金饰的彩石像**（r01/r02/r06/r09/r10 五图一致 ✅）。

## 6. 与现有 `tools/build_stormwind.py` 的差距清单

对账对象：`ANCHORS` / `build_walls()` / `build_gatehouse()` / `build_approach()` /
`build_heroes_vale()` / `build_landmarks()`（读的是当前仓库版本）。

| # | 现在建的是什么 | 真实是什么 | 差在哪（严重度） |
|---|---|---|---|
| 1 | `build_gatehouse()`：两块方墩 `GATE_PIER_W=10` + **一整块实心过梁** `W_gate_lintel` + 顶上方齿 | **门上方没有任何东西**——两座圆塔之间的豁口，直接见天 | **致命**。实心过梁把入城口变成隧道口，S01「低飞穿门」拍出来是钻洞，不是穿门 |
| 2 | 门塔 ＝ `primitive_cylinder` r=7 + `prism(verts=12)` 灰棱锥帽 | 高瘦圆塔 + **蓝色多道肋纹锥顶** + 锥尖旗杆紫蓝燕尾旗 | **致命**。蓝锥顶是暴风城第一识别特征；灰棱锥帽等于把暴风城建成了通用中世纪堡 |
| 3 | 城门段只有 2 座塔 | **4 座**：内侧 2 高瘦圆塔 + 外侧 2 矮粗堡塔（木甲板顶 + 大旗） | **致命**。外堡塔＋大旗是「从城外看城门」的主体量，缺了整个门脸就散了 |
| 4 | 无门扇 | **一对 12 m 高木门扇**，常开外张贴塔基 | 重要。门扇是穿门瞬间画面两侧的近景前景 |
| 5 | 无狮首、无旗帜 | 塔基**巨型狮首石雕**；外堡大旗 + 内塔窄旗 + 顶部燕尾旗 | 重要 |

**重建优先级**（按对 S01–S07 画面的贡献排序）：
① 去过梁 + 换蓝锥顶 + 补外堡双塔与大旗 → ② 门内水面 + 三层铺装 + 灯列 →
③ 五尊雕像重做（数量、位置、八角基座、姿态剪影）→ ④ 北端屏墙与轴线收头 →
⑤ 门外清空（去引道、去基座、去林带，换土路草地 + 两侧岩壁）→ ⑥ 上色。
