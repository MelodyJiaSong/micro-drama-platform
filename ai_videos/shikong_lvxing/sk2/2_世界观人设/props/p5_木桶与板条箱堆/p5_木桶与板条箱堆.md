> **朝向**：正面朝 `+Y`（归一化目标；`object.toml` 的 `目标朝向`）

本卡是**工装卡**，不是入画的画面卡：这三张图是喂 image-to-3D 的原料，

## 开工顺序

1. 先出 **`p5-1` 正面**（纯文字生成）——**它就是那张参考**，形制、比例、部件位置由它定死。
2. 再出 **`p5-2` 侧面 / `p5-3` 背面**，两张都把 `p5-1` 放进参考槽、**只换机位**。
3. 三张齐了（自动出图：`python tools/image_fetch.py --object p5`），跑：

```bash
python tools/hyper3d_fetch.py --tier Regular --bbox 1.6 1.2 1.3 \
  --image ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p5_木桶与板条箱堆/p5-1.png \
  --image ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p5_木桶与板条箱堆/p5-2.png \
  --image ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p5_木桶与板条箱堆/p5-3.png \
  --out ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p5_木桶与板条箱堆/whitemodel/raw.glb

blender -b --factory-startup --python tools/whitemodel_normalize.py -- \
  --src ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p5_木桶与板条箱堆/whitemodel/raw.glb \
  --spec ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p5_木桶与板条箱堆/object.toml \
  --out ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p5_木桶与板条箱堆/whitemodel/p5_木桶与板条箱堆.blend
```

4. 白模落盘后重跑 `tools/build_bianjing.py`——`resolve_asset` 会自动把 `p5` 的同尺寸替身
   换成真网格，shot previz 跟着变，**布局代码一个字都不用改**。

- [ ] **横放木桶** 在，且不是糊成一坨
- [ ] **板条箱** 在，且不是糊成一坨
- [ ] **麻绳捆** 在，且不是糊成一坨

- [ ] 没有多生出来的部件、没有把背景当成几何吸进来
- [ ] 薄件（辕、杆、栏、绳）没有被甩成碎渣——这是 image-to-3D 最不稳的地方，挂了就重掷
