# 钱袋与金银铜币 · p15（物件白模源）

> **它是什么**：旅行者的钱：一只束口皮钱袋，袋口敞开，旁边散着几枚硬币——金、银、铜三色，币面是一枚侧向的狮首，币面没有任何数字与年号
>
> **出现在**：bg2 贸易区、bg12 旅店堂屋、全片记账镜
> **真实尺寸**：宽 0.22 × 长 0.18 × 高 0.09 米（`object.toml` 的 `尺寸`，白模闸门按它等比缩放）
> **朝向**：正面朝 `+Y`（归一化目标；`object.toml` 的 `目标朝向`）

本卡是**工装卡**，不是入画的画面卡：这三张图是喂 image-to-3D 的原料，
按 sk1 divergence #18 一律**正交 + 阴天均匀光**，与 follow-up 014 的 GoT 实拍画风无关。

## 开工顺序

1. 先出 **`p15-1` 正面**（纯文字生成）——**它就是那张参考**，形制、比例、部件位置由它定死。
2. 再出 **`p15-2` 侧面 / `p15-3` 背面**，两张都把 `p15-1` 放进参考槽、**只换机位**。
3. 三张齐了（自动出图：`python tools/image_fetch.py --object p15`），跑：

```bash
python tools/hyper3d_fetch.py --tier Regular --bbox 0.22 0.18 0.09 \
  --image ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p15_钱袋与金银铜币/p15-1.png \
  --image ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p15_钱袋与金银铜币/p15-2.png \
  --image ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p15_钱袋与金银铜币/p15-3.png \
  --out ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p15_钱袋与金银铜币/whitemodel/raw.glb

blender -b --factory-startup --python tools/whitemodel_normalize.py -- \
  --src ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p15_钱袋与金银铜币/whitemodel/raw.glb \
  --spec ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p15_钱袋与金银铜币/object.toml \
  --out ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p15_钱袋与金银铜币/whitemodel/p15_钱袋与金银铜币.blend
```

4. 白模落盘后重跑 `tools/build_bianjing.py`——`resolve_asset` 会自动把 `p15` 的同尺寸替身
   换成真网格，shot previz 跟着变，**布局代码一个字都不用改**。
