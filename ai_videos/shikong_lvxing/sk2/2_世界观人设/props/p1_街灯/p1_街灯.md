# 街灯 · p1（物件白模源）

> **它是什么**：暴风城街灯：黑铁立杆立在方形石座上，杆顶一只四面菱形玻璃的灯笼，灯笼顶收成一个小尖顶、四角挑出小尖角
>
> **出现在**：bg1 英雄谷、bg2 贸易区、bg3 旧城区、bg9 法师区、bg11 运河、全片街景
> **真实尺寸**：宽 0.45 × 长 0.45 × 高 3.6 米（`object.toml` 的 `尺寸`，白模闸门按它等比缩放）
> **朝向**：正面朝 `+Y`（归一化目标；`object.toml` 的 `目标朝向`）

本卡是**工装卡**，不是入画的画面卡：这三张图是喂 image-to-3D 的原料，
按 sk1 divergence #18 一律**正交 + 阴天均匀光**，与 follow-up 014 的 GoT 实拍画风无关。

## 开工顺序

1. 先出 **`p1-1` 正面**（纯文字生成）——**它就是那张参考**，形制、比例、部件位置由它定死。
2. 再出 **`p1-2` 侧面 / `p1-3` 背面**，两张都把 `p1-1` 放进参考槽、**只换机位**。
3. 三张齐了（自动出图：`python tools/image_fetch.py --object p1`），跑：

```bash
python tools/hyper3d_fetch.py --tier Regular --bbox 0.45 0.45 3.6 \
  --image ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p1_街灯/p1-1.png \
  --image ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p1_街灯/p1-2.png \
  --image ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p1_街灯/p1-3.png \
  --out ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p1_街灯/whitemodel/raw.glb

blender -b --factory-startup --python tools/whitemodel_normalize.py -- \
  --src ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p1_街灯/whitemodel/raw.glb \
  --spec ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p1_街灯/object.toml \
  --out ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p1_街灯/whitemodel/p1_街灯.blend
```

4. 白模落盘后重跑 `tools/build_bianjing.py`——`resolve_asset` 会自动把 `p1` 的同尺寸替身
   换成真网格，shot previz 跟着变，**布局代码一个字都不用改**。

## 验收（`object.toml` 的探针只测体量，这几条要人眼看）

- [ ] **方形石座** 在，且不是糊成一坨
- [ ] **铁立杆** 在，且不是糊成一坨
- [ ] **装饰箍** 在，且不是糊成一坨
- [ ] **四面玻璃灯笼** 在，且不是糊成一坨
- [ ] **顶部小尖顶** 在，且不是糊成一坨
- [ ] 整体比例与 `形体规格` 对得上（不是被拉长或压扁的）
- [ ] 没有多生出来的部件、没有把背景当成几何吸进来
- [ ] 薄件（辕、杆、栏、绳）没有被甩成碎渣——这是 image-to-3D 最不稳的地方，挂了就重掷
