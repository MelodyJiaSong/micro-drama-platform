# 拍卖行长台 · p21（物件白模源）

> **它是什么**：拍卖行的长木台：台面上并排摊着三本厚账簿，每本旁边一枚铜铃、一支羽毛笔插在墨水瓶里；台后墙上钉满一张张羊皮纸告示，纸面只有墨迹笔画、没有可读的字
>
> **出现在**：bg2 贸易区
> **真实尺寸**：宽 3 × 长 0.8 × 高 1.2 米（`object.toml` 的 `尺寸`，白模闸门按它等比缩放）
> **朝向**：正面朝 `+Y`（归一化目标；`object.toml` 的 `目标朝向`）

本卡是**工装卡**，不是入画的画面卡：这三张图是喂 image-to-3D 的原料，
按 sk1 divergence #18 一律**正交 + 阴天均匀光**，与 follow-up 014 的 GoT 实拍画风无关。

## 开工顺序

1. 先出 **`p21-1` 正面**（纯文字生成）——**它就是那张参考**，形制、比例、部件位置由它定死。
2. 再出 **`p21-2` 侧面 / `p21-3` 背面**，两张都把 `p21-1` 放进参考槽、**只换机位**。
3. 三张齐了（自动出图：`python tools/image_fetch.py --object p21`），跑：

```bash
python tools/hyper3d_fetch.py --tier Regular --bbox 3 0.8 1.2 \
  --image ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p21_拍卖行长台/p21-1.png \
  --image ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p21_拍卖行长台/p21-2.png \
  --image ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p21_拍卖行长台/p21-3.png \
  --out ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p21_拍卖行长台/whitemodel/raw.glb

blender -b --factory-startup --python tools/whitemodel_normalize.py -- \
  --src ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p21_拍卖行长台/whitemodel/raw.glb \
  --spec ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p21_拍卖行长台/object.toml \
  --out ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p21_拍卖行长台/whitemodel/p21_拍卖行长台.blend
```

4. 白模落盘后重跑 `tools/build_bianjing.py`——`resolve_asset` 会自动把 `p21` 的同尺寸替身
   换成真网格，shot previz 跟着变，**布局代码一个字都不用改**。

- [ ] **羊皮纸告示** 在，且不是糊成一坨
