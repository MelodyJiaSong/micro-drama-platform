# 酒器组 · p14（物件白模源）

> **它是什么**：吧台上的一组酒器：一只横放的小木桶、两只绿色玻璃细颈瓶、一只陶罐、一只木碗、一只带盖锡壶
>
> **出现在**：bg12 镀金玫瑰旅店堂屋、bg3 猪和哨声
> **真实尺寸**：宽 0.9 × 长 0.5 × 高 0.55 米（`object.toml` 的 `尺寸`，白模闸门按它等比缩放）
> **朝向**：正面朝 `+Y`（归一化目标；`object.toml` 的 `目标朝向`）

本卡是**工装卡**，不是入画的画面卡：这三张图是喂 image-to-3D 的原料，
按 sk1 divergence #18 一律**正交 + 阴天均匀光**，与 follow-up 014 的 GoT 实拍画风无关。

## 开工顺序

1. 先出 **`p14-1` 正面**（纯文字生成）——**它就是那张参考**，形制、比例、部件位置由它定死。
2. 再出 **`p14-2` 侧面 / `p14-3` 背面**，两张都把 `p14-1` 放进参考槽、**只换机位**。
3. 三张齐了（自动出图：`python tools/image_fetch.py --object p14`），跑：

```bash
python tools/hyper3d_fetch.py --tier Regular --bbox 0.9 0.5 0.55 \
  --image ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p14_酒器组/p14-1.png \
  --image ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p14_酒器组/p14-2.png \
  --image ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p14_酒器组/p14-3.png \
  --out ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p14_酒器组/whitemodel/raw.glb

blender -b --factory-startup --python tools/whitemodel_normalize.py -- \
  --src ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p14_酒器组/whitemodel/raw.glb \
  --spec ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p14_酒器组/object.toml \
  --out ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p14_酒器组/whitemodel/p14_酒器组.blend
```

4. 白模落盘后重跑 `tools/build_bianjing.py`——`resolve_asset` 会自动把 `p14` 的同尺寸替身
   换成真网格，shot previz 跟着变，**布局代码一个字都不用改**。
