## 6. 配乐（BGM）—— 英语系（用户 2026-09-19 定）

**总纲：全片配乐走英语系（西欧 / 不列颠）语汇，不用东亚音阶、不用中式乐器。** 这条的理由是**世界观**——暴风城是西方奇幻的人类王都，原作配乐本身就是管弦 + 凯尔特民谣的底子。

> **注（2026-09-19）**：艾拉改说美式口音后，这一节**不跟着改**。配乐的依据是世界观而不是主持人的国别——她换个口音，暴风城不会因此变成一座美国城市。旧版本这里曾把「主持人是英国人」也列为理由之一，那是一条会随选角漂移的假依据，已删。

### 6.1 乐器与语汇

| 用 | 不用 |
|---|---|
| 西欧管弦：弦乐组、法国号、双簧管、竖琴 | 古筝、琵琶、二胡、笛箫、扬琴 |
| 不列颠民谣底子：锡笛（tin whistle）、提琴（fiddle）、鲁特/西特恩琴、手鼓（bodhrán） | 五声音阶写成的「东方风」旋律 |
| 教堂段：管风琴、无词人声合唱（拉丁语式母音，**不唱可辨歌词**） | 任何语种的可辨歌词（会与口播抢） |
| 矮人区：低音打击 + 铁砧敲击入节拍 | 电子鼓机、合成器 Lead |

**调式**：以自然小调与多利亚调式为主（不列颠民谣的底子），教堂段可转到利底亚/混合利底亚。

### 6.2 分段音乐设计（对齐 `3_大纲/outline.md` 的 44 镜）

| 镜段 | 情绪 | 编制 |
|---|---|---|
| S01–S02 航拍开场 | 开阔、带一点初见的屏息 | 弦乐长音铺底 + 法国号主题陈述 + 竖琴分解 |
| S03–S07 英雄谷 | 庄重但不沉重 | 主题在低音弦乐上再陈述一次，加定音鼓弱奏 |
| S08–S13 贸易区与旅店 | 轻快、市井 | 锡笛 + 提琴 + 手鼓的民谣快板，**这是全片最「活」的一段** |
| S14–S19 运河与旧城区 | 松弛转微沉 | 编制减到提琴独奏 + 拨弦；进旧城区后去掉手鼓 |
| S20–S22 王座厅 | **克制、留白** | **近乎无乐**——只留一层极弱的弦乐持续音。**戏剧反讽靠观众自己发现，不许用音乐提示** |
| S23–S24 矮人区 | 沉重、有劳作感 | 低音打击 + 铁砧敲击入拍 + 低音弦乐 |
| S25–S31 矿道地铁 | 机械感 → 奇观 | 规律的低频脉冲（车轮节拍）；**入水一刻（S30）全部撤掉打击，只留一层扩散的钟琴与低频** |
| S32–S34 大教堂 | 敬畏 | 管风琴 + 无词合唱（母音，不可辨词） |
| S35–S36 花园区月亮井 | **全片最美的一段** | 无节奏氛围 + 女声无词吟唱 + 竖琴泛音；日落逆光那一镜音乐最满 |
| S37–S39 法师区与地窖 | 悬而未决 | 弦乐高把位持续音 + 稀疏的钢片琴；地窖段只留低频 |
| S40–S43 运河夜与旅店 | 收束、慢下来 | 低音提琴拨弦 + 提琴独奏；**S43 吹灯镜尾音乐先于画面收干净** |
| S44 次晨与收尾 | 开场主题回归 | 法国号把 S01 的主题完整奏一次，末尾只剩竖琴 |

### 6.3 纪律

- **绝不使用暴雪原声音乐**（版权；与 `divergence #110` 的 IP 定性同一条线）。全片配乐**原创**。
- **音乐不许抢口播**：讲解段音乐压到 −18 dB 以下，`I-9` 密度合同要求每分钟 ≥3 个可核对事实，听不清就白讲。
- **无词**：不出现任何语种的可辨歌词。
- **S20–S22 王座厅**是全片唯一「几乎无乐」的段落——**这是设计，不是遗漏**。
- **三个声音锚**（`concept.md`）由音效承担、不由音乐承担：矮人区锤声与炉火爆响 · 矿车钢轮声与**入水一刻的声场变化**（空气→水体，混响骤然拉长、高频被吃掉）· 大教堂的钟。

### 6.4 生成

走 `tools/stableaudio_gen.py`；每段一条 prompt，按上表的「情绪 + 编制 + 调式」写，**英文 prompt**。成片时用 `tools/mux_av.py` 把视频 + 台词 + BGM 三轨合起来。
