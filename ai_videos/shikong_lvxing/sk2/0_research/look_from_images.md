## 一、通用建筑语汇（填 `w2_architecture.md` 语汇表的空格 + 订正两条）

### 1. 窗（W2 语汇表**故意留空**的第一格，Q1 第一缺口）

```
民居与商铺的窗：矩形木框多格窗，木棂把窗面分成四到六格，格内玻璃偏暖黄、夜里从室内透出暖光；
窗框与墙面平齐略凹，外沿一圈浅色石套；不是拱窗、不是尖拱窗、不是圆窗、不是落地窗。
```
- **来源**：视频 f_960（旧城区街景）· f_240（运河边）· f_2580
- **版本**：✅ 形制未变
- **填的空**：W2 Q1「窗户是尖拱还是圆拱、有没有铅条玻璃」——**答案是两者都不是：民居窗是方形多格窗**。拱只用在门洞。
- **负向**：`尖拱窗, 哥特花窗, 圆窗, 落地窗, 平板玻璃, 无框玻璃, 铝合金窗`

### 2. 门洞

```
门洞：半圆拱，拱券由楔形石块砌成、拱线清晰；门套为浅色石砌，比墙面略外凸；
门扇为深棕厚木板拼合、带黑铁合页与门钉。民用门洞偏矮偏窄，成年人进门需略低头。
```
- **来源**：f_960 · f_240 · 官方 Classic 导览图（城墙下的过街拱同为半圆）
- **版本**：✅
- **填的空**：W2 Q1 的门形制部分；与 `arch.023`（门洞偏矮）一致

### 3. 街灯（W2 语汇表**故意留空**的第二格「街具」）

```
街灯：黑铁立杆，方形石质基座，杆身约两人高、中段有一圈装饰箍；
杆顶是四面菱形玻璃的灯笼，灯笼顶收成一个小尖顶、四角挑出小尖角，罩内是暖黄色火光。
```
- **来源**：官方 Classic 导览图 · f_30（英雄谷）· f_240 · f_960 · f_2580
- **版本**：✅ 五张图形制一致
- **关键**：**灯笼顶的小尖顶与全城屋顶、大教堂尖塔是同一个形状**——见下「蓝色尖顶母题」
- **负向**：`电灯, 灯泡, 路灯杆, 玻璃灯罩, 霓虹, LED, 壁挂式火把作为主街照明`

### 4. 铺地（三种，按区分用）

```
铺地三种：
① 主干道与广场——大块米白偏浅灰的矩形石板，块面大、缝浅，表面被踩得微微反光；
② 人行带与街沿——深色小砖以人字纹（斜向交错）铺砌，与主道之间有一道窄石缘分隔；
③ 巷道与旧城区——灰色不规则卵石铺地，石块圆钝、缝隙积细尘，间或穿插红褐色砖带。
```
- **来源**：f_30（①②，英雄谷人字纹极清晰）· f_240（③ 卵石 + 红砖带）· f_960（② + ③）
- **版本**：✅
- **填的空**：W2 语汇表原只有一句「宽阔石板大道」，**人字纹小砖这一层文字来源里没有**
- **负向**：`柏油, 水泥, 沥青, 现代方砖, 整版同向铺砖, 土路为主`

### 5. 招牌（**最重要的一条**——它给「画面零文字」纪律提供了正向依据）

```
店招：门前以一根横木悬臂外挑，横木两端各垂一条黑铁链，链下吊一块厚木牌；
木牌四角包铁，牌面是一整块浮雕图形——一件衣服、一只酒杯、一柄剑、一条面包——
以形表意，牌面上没有任何文字。牌随风微微摆动。
```
- **来源**：f_960（旧城区，浮雕图案是一件罩衫，清晰可辨）
- **版本**：✅
- **意义**：W2 的 `arch.026` 原标 ⚠️（「空白木牌 / 实物幌子」属推测）。**现在证实：游戏里的招牌本来就是图形浮雕、零文字**。所以本片画空白 / 纹样木牌**不是妥协，是还原**——这条应写进 `style_guide.md` 与每镜口播依据。
- **负向**：`招牌文字, 印刷体, 手写体, 字母, 汉字, 数字, 灯箱, 霓虹, logo, 价目表`

### 6. 半木结构（民居与商铺的主要立面做法）

```
半木结构立面：一层为白色石砌基座，二层挑出，深棕色木构架外露——竖柱、横枋与斜撑构成方格与人字，
格内填白灰泥墙面；转角与门窗周围木料加厚。木色偏深褐、经年发灰，白灰面略有污渍与色差。
```
- **来源**：官方 Classic 导览图 · f_240 · f_2580 · f_30
- **版本**：✅
- **填的空**：W2 Q7「民居与商铺的层数与立面组织」——**答案：一层石砌、二层挑出木构，即欧洲 half-timbering**

### 7. 墙体（**订正 W2 一条**）

```
墙体：暖白偏浅灰的石灰岩砌体，石块方正而大（一块约与人躯干等宽），灰缝浅而宽、可见凹槽；
表面经年略泛米白与浅灰，有轻微污渍与色差；墙体厚重，转角与基座石块更大。
```
- **来源**：官方 Classic 导览图 · f_30 · f_960
- **订正**：W2 语汇表原写「石块方正、**灰缝细密**」——**实测是大块石材、缝宽而浅**，不是细密灰缝。这条影响每一张锚点图，必须改。

### 8. 屋顶（**订正 W2 一条** + 按区分色）

```
屋顶：陡坡瓦顶，瓦片呈鱼鳞状层叠、边缘厚薄不匀；坡面或为四坡、或收成圆锥尖顶，
屋面上开三角形山墙老虎窗。屋脊与檐口有浅色石或木收边。
```
**按区分色（这是全城最强的识别系统）**：
- **贸易区 / 要塞 / 大部分城区** ＝ **饱和的中蓝**（不是深蓝灰）
- **旧城区** ＝ **暗红褐色**
- **法师区** ＝ **紫色**
- **来源**：官方 Classic 导览图（蓝）· f_960（旧城区红褐）· f_240（法师区紫）
- **订正**：W2 语汇表原写「**深蓝灰色**石板瓦」——**实测是相当饱和的中蓝**。半写实画风下蓝调错了整座城就不像暴风城了，这条必须改。
- **升实**：W6 的 `house.009` ⚠️「旧城区屋顶是暗红褐色不是蓝色」→ **证实**；W2 说「紫色尖塔查无实据」→ **证实：紫色是法师区的屋顶色**

### 9. 🔑 蓝色尖顶母题（**文字来源里无人写过，是「一眼认出暴风城」的真正机制**）

```
全城贯穿母题：同一个「陡坡收尖 + 蓝色瓦面」的形状，在三个尺度上重复——
街灯灯笼顶（最小）→ 民居与塔楼的圆锥屋顶（中）→ 大教堂的细高尖塔群（最大）。
凡拍城市全景或街景，画面里应至少同时出现其中两个尺度。
```
- **来源**：官方 Classic 导览图（一帧内三个尺度同时出现）
- **建议**：写进 `style_guide.md` **第一条**

### 10. 城墙与塔楼

```
城墙：大块方石砌体，墙顶为方齿城垛（齿宽与齿间空档大致相等）；墙段之间以半圆拱过街桥相连。
塔楼：圆柱形，塔身开竖长条窗，顶部出挑檐口后收方齿城垛，或戴蓝色圆锥顶。
```
- **来源**：官方 Classic 导览图 · f_30
- **版本**：✅

### 11. 运河与护岸

```
运河护岸：白石砌直壁，岸顶一道矮石栏，栏板顶面起伏成连续的浅齿；
栏侧固定黑铁系缆环。水面明净偏蓝绿、微微反光。岸边间或探出小块木质平台与堆放的木桶。
```
- **来源**：f_240
- **版本**：✅ 几何未变；**但 4.0.3a 起运河被改成半淤浅（淤泥 / 芦苇 / 杂物），Vanilla 是深水**——`myth` 版本错置第 7 条，**堤顶到水面必须有明显落差**
- **负向**：`淤泥, 芦苇, 半干涸的运河, 露出水面的杂物, 能趟过去的浅水`

### 12. 街具杂项

```
街具：深棕木花槽（正面有卷草纹浅雕，内种低矮灌木）· 横档式木栅栏 · 堆放的木桶与板条箱 ·
石砌圆井（井口石砌、上架两根交叉木柱与一根横轴辘轳）· 弧形石凳 · 结红果的苹果树。
```
- **来源**：f_240（花槽）· f_1500（水井、石凳）· f_2580（木栅栏）· f_960（苹果树）
- **版本**：✅
