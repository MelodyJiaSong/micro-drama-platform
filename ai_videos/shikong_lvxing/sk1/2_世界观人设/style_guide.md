## 1. 一句话调色

**黄土 · 灰瓦 · 柳色 · 本白皂黑 · 一抹朱漆——朱漆只给虹桥、御街杈子、城楼木作与宣德楼门扉。**

这座城的底色是**土与木**：黄土街面、素木不上漆、灰瓦、泥抹墙刷白灰；人是**本白与皂黑的麻布**（端拱二年诏，`kaifeng.dress.002` ✅）；清明给它一层**嫩黄绿的柳色**；朱漆是这座城里最贵的颜色，只出现在「饰以丹雘」的虹桥（`route.004` ✅）、御街两行朱漆杈子（`route.009` ✅）与城楼的朱橙木作（`gate.006` ✅）。彩楼欢门上的红是**绸帛**，不是漆。**全片没有红灯笼、没有金。**

**天要蓝、水要绿**（2026-09-14 sk1 follow-up 004）：每一张图、每一镜，凡画面里露出天，白天一律是晴天干净通透的蓝天；凡露出水（汴河、护龙河、御沟、园池），一律碧绿。打个比方：天气好的时候无人机航拍出来的效果——空气通透、没有灰霾；雾只允许贴着水面一层很淡的晨雾。夜里的天是深蓝、不是灰黑。例外：p8–p10 是 image-to-3D 三视图，必须阴天均匀光，不画蓝天，水照样画绿（divergence #18）。

**画风基准 ＝《权力的游戏》的实拍电影感**（2026-09-16 follow-up 014；依据 `look_research.md`）。它和上一条不冲突，但**改掉了「晴天」的画法**：

- 取的是 GoT **南境（君临 / 多恩）的晴天档**，不是北境的阴天档——太阳**硬**、影子**实**、天是蓝的，但灰度比明信片高一档，空气里有**浮尘**。
- **远景不再「清楚」，改成「退远」**：越远越淡、越远越软、越远越偏蓝灰（大气透视）。**没有灰霾 ≠ 远近一样清楚**；奶白色的地平线雾带进负向。
- **暗部该黑就黑**：屋檐下、门洞里、桥腹、看棚下允许掉到接近黑，只留极少细节。**不许反向补蓝**——冷蓝只给**真的被天空照到**的面。GoT 的立场是「宁可看不清，不要假亮」。
- **日外优先逆光与遮蔽下的散射光**，其次才是侧光；正面均匀照明是打光棚的味道，进负向。
- **一切表面都是被用了很多年的**：做旧不是「材质种类」（木纹、麻布纤维）而是「污损状态」（晒白、发霉、包浆、补丁、水渍、缺口、泥点）。君临的每一块「石头」都是人工逐块画旧的——这套纪律照搬，落点是 §11.2 的做旧层。
- **构图不是产品图**：允许前景遮挡、允许主体被画框切掉一块、重量不对称。
- **参考图政策同时改了**（§10）：**宋画一律退出上传窗口**，只作作者对账；上传位给世界锚点与照片类参考。这是「太像动画」最大的一个成因。

## 3. 光（**按时段条件化**，每镜自己写；共用串里没有光）

**规矩**：`渲染样式:` / `STYLE_BASE`（§7）只放**对每一镜都成立**的东西——影像质感、颗粒、无字幕。**光源、天气、时段一律拆成条件分句写进该镜的 `光线:`**；**没有该光源的镜要反向声明**（「本镜画面里没有任何火、没有任何暖色光源、没有灯笼」）并挂对应负向组（§6 条件块）。rule 16.9 / 格式契约 K32；`python tools/prompt_light.py` 巡检。

**天与水**（follow-up 004）：生成器在每镜 `光线:` 末尾按时段追加天与水的条件分句——白天「晴天蓝天、碧绿的水」（航拍镜再加「像天气晴好时无人机航拍的实景」），五更「清冷透亮的蓝」，夜「深蓝夜空、深碧绿水面」；**不进 `STYLE_BASE`**，因为夜镜没有蓝天（rule 16.9）。

**光的四条纪律**（follow-up 014，GoT 打光法；每镜 `光线:` 逐条落地，`STYLE_BASE` 只收「暗部该黑就黑」这一条纪律、不收光源）：

1. **先找逆光**。日外的主光优先写**逆光 / 侧逆光**，其次写**遮蔽下的散射光**（檐下、棚下、树冠下、门洞里）。正面平均照明不写——GoT 的日外基本不打光，全天可拍靠的就是把镜位排成逆光或在遮蔽下。
2. **写光比，不写「明亮」**。每镜 `光线:` 明写「受光面与阴影差三到四档，阴影里只有天光、没有一盏补光」。白天镜三到四档、正店门首与夜市油灯镜五档以上、三更客店六档以上。
3. **暗部不救**。屋檐下 / 门洞里 / 桥腹 / 看棚下 / 舱棚里掉到接近黑，只留极少细节；负向必挂「抬亮的暗部, 补出来的蓝色暗部」。
4. **空气里必须有东西**。每镜写一样介质：贴水晨雾、街上被光柱切出来的浮尘、灶上的白汽、灯下的油烟、郊路上牲口踏起的土。没有介质的空气＝渲染图的空气。

> **【全程绝对无字幕…】前缀**（2026-09-14 FIX2_sk1 · R8 W1 / 格式契约 K19 口型对白镜高风险档）：逐字取自 hy1–hy4 生成器的同一句；K19 已裁定它优先于 K26 ⑤、保留在 `渲染样式:` 里。它只属于 shot 视频 prompt 的 `渲染样式:`；主体卡的 `样式:` 用**去掉这一前缀之后的同一串**（静帧没有台词可烧），由 `tools/gen_scene_prompts_sk1.py` 逐卡盖章，两边其余部分逐字相同。

**这一串里没有光源、没有天气、没有时段、没有建造状态、没有做旧清单、没有景深说明、也没有介质**——它们各有自己的一行：光与天各镜条件化写（§3）、做旧走 §11.2、景深归 `摄影:`、介质归 `光线:`。共用串只留**对每一镜都成立又没有别处可放**的东西：机身 / 镜头 / 快门、影调纪律（高光柔滚、暗部该黑就黑）、光学缺陷（暗角 / 色散 / 柔光晕 / 颗粒）、一句反 CG。

> **2026-09-16 二次收紧**：图 prompt 的硬线从 2800 压到 **< 2000**（用户定调）后，共用串是唯一能整段省下来的地方——它在每张图里各占一份。办法是**把重复的那几件各归其位**（去重，不是删信息），共用串因此从 299 字压到 210 字；反 CG 的长清单交给负向块里的 `NEG_CG` 逐条挡，正向只留「是实拍，不是 CG、不是插画、不是效果图」一句。同时取消了 `光色:` 整行——它说的「与世界锚点同一套影调」`参考用法:` 已经说过一遍。

改这一串 ＝ 改这里 → `tools/gen_scene_prompts_sk1.py` 与 `tools/gen_shots_sk1.py` 各改一处 → 两个生成器重跑；两边的 `gate()` 会逐字比对，不同步就跑不出来（rule 4i ①）。

**长度自检（两条硬线，都由生成器 raise，不靠人记）**：每镜 `## 视频 prompt` ```text 块 **≤ 5000 字**（K10，`tools/gen_shots_sk1.py` 的 `MAX_PROMPT`）；**每张主体图 prompt < 2000 字**（用户 2026-09-16 定调；`tools/gen_scene_prompts_sk1.py` 的 `LO, HI`）。图侧 2000 是紧的——新增的 `摄影:` 与 `【质感与做旧】` 两层要挤进去，办法是**共用串去重**：`STYLE_BASE` 里不再写景深性质、做旧总纲与介质，那三件各由 `摄影:` / `【质感与做旧】` / `【光】` 逐镜写一次，不是丢了，是只写一处（rule 4i ①）。

> **2026-09-16 follow-up 014 改了什么、为什么**：旧串是「自然纪实影像、实拍质感……35mm 胶片颗粒」——**「实拍」是个形容词，模型当标签收下就完事了**；出来的图边到边一样锐、暗部被抬成浅灰、表面崭新、天是插画的天，整体像游戏引擎的过场。新串把同一个意图翻译成**可执行的摄影事实**（机身+镜头+快门+景深+光学缺陷+反 CG），并把「全景深」这条直接**反掉**——它是效果图与游戏截图的签名特征，不是电影摄影的。逐条诊断见 `look_research.md` §1。

## 11. 每张图 / 每镜的两条新行（follow-up 014）

### 11.1 `摄影:`（器材事实，**替代原来「f8，全景深」的写法**）

模板（`{}` 按镜填，由生成器拼）：

```
ARRI ALEXA，Super-35，Cooke S4/i {焦距}，{f}，1/48 秒；焦点在{对焦主体}，{景深说明}；轻微暗角。
```

- **光圈按景别给**：大景 / 航拍 `f4`（远景靠大气退远，不靠虚化）；中景 `f2.8`；近景与人物 `f2`。
- **`{景深说明}` 必写**，且必须落在「不是全景深」那一侧：航拍写「越远越淡越软、偏蓝灰」；地面大景写「远处房脊已经软下去」；中近景写「背景虚成一片可辨色块」。
- **原来所有卡里的 `f8，全景深` 一律作废**，由生成器从 `机位:` 行里摘掉。
- **焦距写死在生成器的 `LOOK` 表里**（`foc=`），不从卡里回读——光学尾巴一旦被摘掉，回读第二遍就读不到了，会悄悄退回默认值。

### 11.2 `【质感与做旧】`（图）/ `做旧:`（镜）
