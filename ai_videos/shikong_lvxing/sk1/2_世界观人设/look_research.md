# 画风调研 · 《权力的游戏》实拍电影感（sk1 · follow-up 014）

> 用户 2026-09-16 定调：现有出图**太像动画 / 游戏 CG，不像真实场景**，全站重来，画风改 GoT 一路的实拍电影感。
> 本文是 `style_guide.md` §1 / §3 / §6 / §7 / §10 的依据；结论落进 `tools/gen_scene_prompts_sk1.py`（出图 prompt 的 look 层唯一出处）与 `tools/gen_shots_sk1.py`（shot prompt 的 `渲染样式:` / `光线:` / 负向）。
> 可泛化的那一条已上交 `.claude/agent_refs/project/ai_video.md` rule 4j（画类参考图 → 插画感；实拍感靠摄影语汇 + 脏旧 + 真实暗部）。

## 1. 先定诊：现有图为什么像动画

拿已出的 `bg1-1_虹桥锚点全景` 逐条对照（这张是全站质量最高的一张，问题也最典型）：

| 症状 | 画面证据 | 真正的成因 |
|---|---|---|
| **① 一切都同样清楚** | 前景土坡、中景桥、远景桅杆、天上的云，锐度完全一样 | prompt 写死了 `f8，全景深`。真实电影镜头在 24–28mm / f2.8–f5.6 下，远景一定会软下去、空气会吃掉对比度。「全景深」是**游戏引擎和建筑效果图**的特征，不是电影摄影的特征 |
| **② 暗部是浅灰的，不是黑的** | 桥腹、船篷背光面、屋檐下全是抬亮的青灰，没有一处真正暗下去 | prompt 写「背光处是天光反射的冷蓝」，模型理解成**整体补光**。GoT 的做法相反：McLachlan「不怕黑、不怕剪影」，暗部就让它掉下去 |
| **③ 干净得不真实** | 黄土没有泥、木头没有霉、墙没有水渍、河面没有漂浮物、人身上没有汗和土 | 材质词写的是「木纹 / 麻布纤维 / 夯土粗糙」——那是**材质种类**，不是**污损状态**。缺的是 grime / 磨损 / 水渍 / 缺口 / 修补痕 |
| **④ 天是插画的天** | 均匀渐变的蓝、地平线一圈奶白雾、云是装饰性的几缕 | 「干净通透的蓝天」+「远景清楚」两条一起，把大气层的**密度**抹掉了。真实晴天航拍远处一定有**蓝灰色的大气消光**，不是奶白雾 |
| **⑤ 人像塑料小人** | 群众衣服同色同新、姿态僵、没有运动模糊、脸磨平 | 群众只写了「宋代平民装」，没写**磨损、脏、汗、不同新旧、走动的动态模糊** |
| **⑥ 构图是展示图不是剧照** | 主体完整居中、前景无遮挡、地平线正、一切可见 | 「横向用满、地平线水平、主体落三分线」是**产品图**的构图法。剧照会有前景遮挡、被切掉的边缘、非对称重量 |
| **⑦ 没有摄影机的痕迹** | 无暗角、无高光溢出、无色差、颗粒是均匀叠加的 | `35mm 胶片颗粒` 一个词救不了。要连**镜头型号级别的光学缺陷**一起写 |
| **⑧ 参考图是绢本画** | 上传的是《清明上河图》北宋原本局部 | **这是最大的一条。** 卡里写了「绢本的色调、线描笔触和平面透视一律不照搬」，但图像模型对参考图的**风格吸收**远强于对文字否定的服从。喂一张画，出的就是画的亲戚 |

**一句话结论**：现有 prompt 把「实拍」当成了一个**形容词**（「自然纪实影像、实拍质感」），而模型需要的是一串**可执行的摄影事实**——机身、镜头、光圈、快门、滤镜、光比、脏旧状态、光学缺陷。前者是标签，后者才是约束。

## 2. GoT 的实拍感是由什么构成的

### 2.1 器材与影像底子（有出处）

- 主力机身是**各代 ARRI ALEXA（Super-35 传感器）**，配 **Cooke S4/i** 定焦与 **Angénieux Optimo** 变焦；个别用 RED EPIC DRAGON 上 Freefly MoVI（冰岛外景 Steadicam 进不去的地方）。
- 选 ALEXA 的理由本身就是本项目要的：**对比过胶片与各家数字机后，认定 ALEXA 最接近胶片**。
- Cooke 的画质性格（业内俗称 "Cooke Look"）正是**高光滚得软、暗部过渡厚、肤色偏暖、边缘略松**——和「数码锐、全景深、边到边一样清楚」完全相反。

→ **进 prompt 的写法**：不写「电影感」，写 `ARRI ALEXA + Cooke S4/i 定焦 + Super-35` 这一串器材事实，再写它带来的具体后果（高光柔滚、暗部厚、边缘略松、轻微暗角）。

### 2.2 光：只用动机光，且不怕黑

- McLachlan 说早期第一季「有大量没有动机的逆光，连日外都看得出是打过的」，后来全季的方向是让景**「看上去完全不是我们打的光，只有大自然或者几支蜡烛」**。
- Fabian Wagner：**日外基本不打光**，靠**负补光（negative fill）与反光板**；让光的叙事随人物的叙事走。
- 日外的排期是**围着太阳走的**：一天八十多个镜位，靠把几乎每个镜头安排成**逆光**或**在遮蔽物下（canopy）**来保证全天可拍。
- 夜内用**入画的实用光源**（5000W 大灯直接摆进画面）+ **烟雾/空气介质**藏器材；参考的是古典绘画里「只有一小扇窗光的阴暗室内」。
- 争议极大的《长夜》是**故意压暗**的——这是本剧光的立场：宁可看不清，不要假亮。

→ **进 prompt 的写法**：① 每镜光源可指认（太阳 / 油灯 / 烛），② **大量逆光与遮蔽下的散射光**，而不是正侧光均匀照亮，③ **暗部允许掉进黑**、不反向补蓝，④ 空气里永远有介质（尘、烟、水汽），⑤ 明确写**光比**（受光与暗部差 3–4 档）。

### 2.3 美术：真材料 + 逐块做旧

- 王之国都是**真景**（Dubrovnik 老城）与**实景搭建**：钢骨架 + 胶合板 + 灰泥/泡沫饰面，**每一块「石头」都是人工逐块画出来的旧**（patina），材料就地取。
- 结果是一种**被用过的**表面：不均匀、有修补、有污渍、有年头。

→ **进 prompt 的写法**：材质层要写**状态**不是种类——「哪里磨白了、哪里长霉、哪里补过、哪里被水洇出深色边」。

### 2.4 反过来说：AI 出图「像 CG」的通用成因

来自出图侧的通用结论，与上面互相印证：
- 塑料皮肤 / 蜡感、光线完美均匀、一切等锐、饱和度偏高，是**「AI 味 / CG 味」的四大标志**；
- 修法是**写实触发词 + 摄影参数 + 具体瑕疵**（皮肤毛孔、织物经纬、浅景深与虚化）；
- 负向要把 `3D render / CGI / game engine / illustration / painting / concept art` 明确挡掉——**光写正向不够**。

## 3. 与本站既有定调的冲突与裁决

| 冲突 | 既有定调 | GoT 做法 | 裁决 |
|---|---|---|---|
| 天气 | follow-up 004：**天要蓝、水要绿**，「天气好的时候无人机航拍的效果」 | 北境大量阴天、低饱和 | **保留蓝天绿水**，改用 GoT 的**南境（君临 / 多恩）晴天档**：太阳硬、影子实、天蓝但**灰度更高**、空气里有尘与热浪。不是取消晴天，是取消「明信片式的晴天」 |
| 景深 | 全卡写死 `f8，全景深` | Super-35 + Cooke 定焦，中远景一定有大气消光与柔化 | **删掉「全景深」**。改写 `f4` 一类的实际光圈 + **远景随距离变淡变软（大气透视）** |
| 远景 | 「远景清楚、没有灰霾」 | 真实晴天远景是**蓝灰色的退远**，不是奶白雾 | 改写：**没有灰霾、但有蓝灰色的大气退远**；奶白色地平线雾进负向 |
| 参考图 | 每主体上传 1–2 张《清明上河图》原本局部定形制 | — | **宋画全部退出上传**，只留在卡里作者对账用（`refs.md` / 形制词对账表照旧）。上传位改为：世界锚点 `bg0-1` + **照片类参考**（现存宋辽木构实拍、贯木拱桥实拍） |
| 暗部 | 「背光处是天光反射的冷蓝」 | 不怕黑、不怕剪影 | 冷蓝只留在**有天空直接照到的面**；**屋檐下 / 门洞里 / 桥腹**允许掉到接近黑，负向挂「抬亮的暗部」 |
| 颗粒 | `35mm 胶片颗粒` | ALEXA + 后期胶片感 | 升级成一整套**光学与影像缺陷串**（见 §4） |

## 4. 结论：进 prompt 的词表

### 4.1 摄影事实串（新 `摄影:` 行，每张图 / 每镜带）

```
ARRI ALEXA 拍摄的实拍电影画面，Super-35 传感器，Cooke S4/i 定焦镜头，{焦距}，{光圈}，1/48 秒快门的自然运动模糊；
高光柔滚不死白，暗部厚实有层次但允许掉进黑，画面边缘轻微变松、有很淡的暗角，高光边缘极轻微的色散与柔光晕，
细腻不均匀的胶片颗粒；不是全景深——{景深说明}。
```

### 4.2 脏旧与瑕疵层（新 `【质感与做旧】` 段，每张图带）

固定要素：**尘、汗、泥、霉、磨白、水渍、修补、缺口、褪色、不匀**。
- 木：向阳面晒成灰白、背阴面发暗长霉斑，握持处磨出油亮的包浆，裂缝里塞着泥；
- 瓦：哑光、颜色一垄深一垄浅，瓦楞里积着落叶与瓦松枯草，个别瓦是新补的、颜色不一样；
- 墙：白灰剥落成不规则斑块露出黄泥草筋，墙根被雨水溅出一道深色泥线；
- 土：干处扬灰、湿处发深、车辙里有积水，混着碎草与牲口粪；
- 布：麻布起毛、领口袖口发深发亮，补丁的颜色与本布不一样，下摆有泥点；
- 人：皮肤有毛孔与晒痕，指甲缝里有黑泥，头发油、不服帖。

### 4.3 光的写法（每镜条件化）

- 主光方向**优先逆光 / 侧逆光**，其次是**遮蔽下的散射光**；正面均匀照明进负向。
- 明写**光比**：「受光面与阴影差三到四档，阴影里只有天光、没有补光」。
- 空气介质必写：晨雾贴水、街上的浮尘被光柱切出来、灶上的白汽、夜里的油烟。
- 暗部指令：「屋檐下、门洞里、桥腹掉到接近黑，只留极少细节，不补光、不抬亮」。

### 4.4 负向新增块（`NEG_CG`）

```
3D 渲染, CG 动画, 游戏引擎画面, Unreal Engine, Octane 渲染, 建筑效果图, 概念设定图, 数字绘景, 插画, 手绘, 国画, 绢本设色, 水墨, 动画电影, 皮克斯风格, 三维动画, 塑料质感, 蜡像感, 全景深, 边到边一样锐, 均匀布光, 无影棚光, 抬亮的暗部, 补出来的蓝色暗部, 高饱和明信片色, 奶白色地平线雾, 装饰性云朵, 完美无瑕的表面, 崭新的木头, 崭新的布, 一尘不染, 主题公园, 影视城新建景, 沙盘模型, 微缩模型
```

### 4.5 构图（改掉「产品图」构图法）

- 允许并鼓励**前景遮挡**（柳枝、栏杆、人的肩背、挑担的筐）压在画面边缘；
- 主体**可以被画框切掉一部分**；
- 重量不对称；地平线仍保持水平（航拍除外，允许极轻微倾斜）。

## 5. 参考图新政策（落 `style_guide.md` §10）

| 类别 | 例 | 上传？ | 作用 |
|---|---|---|---|
| **世界锚点** | `bg0_汴京全城/bg0-1.png` | ✅ 第一张，恒定 | 定全站影像基调（光、色、脏旧、颗粒、大气） |
| **照片类形制参考** | 现存宋辽木构实拍（初祖庵大殿 1125、隆兴寺摩尼殿、晋祠圣母殿、保国寺大殿、应县木塔）、浙南贯木拱廊桥实拍、真实木帆船实拍、夯土城墙实拍 | ✅ ≤ 2 张 | 定形制与**真实材质光影** |
| **宋画原本** | 《清明上河图》北宋原本各局部、《瑞鹤图》、《金明池争标图》 | ❌ **一律不上传** | 只作者对账：`refs.md`、卡里「形制词对账」表、验收清单照旧引用 |
| **摹本 / 复制品** | 清院本、Met 摹本 | ❌ | 本就不作形制依据 |

**理由**：图像模型对参考图的风格吸收强于对文字否定的服从；喂画出画。宋画作为**史料**的地位不变——它证明形制，由作者读完写成文字，文字进 prompt。
