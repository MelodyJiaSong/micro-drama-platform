## 这个主体是干什么的

**虹桥形制的唯一标准，也是一镜到底的起点。** 世界锚点是 `bg0_汴京全城/bg0-1.png`（2026-09-14 sk1 follow-up 003 由本图改过去，divergence #17）；本图挂它继承基调（晴天蓝天、碧绿河水、做旧程度、颗粒），再挂 2 张北宋原本局部定形制。它定死虹桥本身的形制（无柱、木拱、朱漆、表木、栏柱距），`bg0-2`、p8、p9 的虹桥与漕船都照本图。

**它同时是一镜到底的起点**：概念卡「段 0 开场」的虹桥一镜到底（25–30 s）从南岸桥头低角度侧跟起，上桥 → 桥面人流 → 北岸桥尾「十千脚店」门口收；本图的机位就是那条路径的第 0 秒机位（见 § 一镜到底路径）。

**谁在等它**：bg2–bg8、p8_虹桥单体、`_blender/`（S2_E）、style_guide.md 的调色与 `STYLE_BASE`——**它不定稿，一张都不能开。**

## 视图 1 · 虹桥锚点全景　★ 必做

**用在**：段 0 开场（卯时）——古今叠印穿越的落点 + 林问桥头出镜 + 一镜到底第 0 秒；站五末（申–酉）回到虹桥的险情段（同机位、傍晚变化态另出）；封面帧候选（林问宋装举包子、身后虹桥与纲船）。

**验收清单**（有一条不过就重跑）：

- [ ] **桥下没有一根桥柱、没有桥墩**——单孔、拱下是空的河面
- [ ] **是木拱，不是石拱、不是砖券**：看得见整根圆木两层交错编织、横木穿插
- [ ] **朱漆是褪旧的暗朱红**，棱角露木色；不是鲜红新漆、不是金漆彩绘
- [ ] 桥面两侧是**方木栏柱、约一米一根、两道细横栏**；不是石栏板、不是雕龙望柱
- [ ] **桥两端各有一对高木杆，杆顶横木立木鸟**（表木在）；不是石华表、不是旗杆
- [ ] 桥上有**席棚 + 大伞小摊**，中间留窄道；桥面不是空的
- [ ] **桥下漕船桅杆已放倒斜卧舱顶**，船头水手撑篙；不是张帆过桥、不是龙舟
- [ ] 漕船**平底高舷、有席篷舱棚与舵楼**；不是乌篷小船、不是海船
- [ ] 河滩上有**纤夫弯腰拉纤**（可为剪影）
- [ ] 北岸桥尾有**彩楼欢门的脚店**，木匾空白无字（店名后期加）；**所有招牌无字**
- [ ] 沿岸建筑是**灰瓦木构、素木柱、席棚披檐**；无马头墙、无琉璃瓦、无红柱金匾
- [ ] **远处看不见城墙、城楼**——桥在城外
- [ ] 两岸有**老柳、新绿嫩芽**；不是樱花、不是油菜花海
- [ ] **可辨人物 ≤ 8**，其余是远景剪影；所有人宋代平民装，**无立领 / 盘扣 / 长辫 / 瓜皮帽**
