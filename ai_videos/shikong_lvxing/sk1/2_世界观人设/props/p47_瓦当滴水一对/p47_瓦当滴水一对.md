# 瓦当滴水一对 · p47（物件白模源）

> **它是什么**：檐口一对青灰陶瓦件：一只圆瓦当压住筒瓦头，紧邻一只尖底滴水挑出檐外，两者共坐在一小段板瓦垄上
>
> **出现在**：所有 A 级建筑檐口
> **真实尺寸**：宽 0.35 × 长 0.42 × 高 0.18 米（`object.toml` 的 `尺寸`，白模闸门按它等比缩放）
> **朝向**：正面朝 `+Y`（归一化目标；`object.toml` 的 `目标朝向`）

本卡是**工装卡**，不是入画的画面卡：这三张图是喂 image-to-3D 的原料，
按 sk1 divergence #18 一律**正交 + 阴天均匀光**，与 follow-up 014 的 GoT 实拍画风无关。

## 开工顺序

1. 先出 **`p47-1` 正面**（纯文字生成）——**它就是那张参考**，形制、比例、部件位置由它定死。
2. 再出 **`p47-2` 侧面 / `p47-3` 背面**，两张都把 `p47-1` 放进参考槽、**只换机位**。
3. 三张齐了（自动出图：`python tools/image_fetch.py --object p47`），跑：

```bash
python tools/hyper3d_fetch.py --tier Regular --bbox 0.35 0.42 0.18 \
  --image ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p47_瓦当滴水一对/p47-1.png \
  --image ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p47_瓦当滴水一对/p47-2.png \
  --image ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p47_瓦当滴水一对/p47-3.png \
  --out ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p47_瓦当滴水一对/whitemodel/raw.glb

blender -b --factory-startup --python tools/whitemodel_normalize.py -- \
  --src ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p47_瓦当滴水一对/whitemodel/raw.glb \
  --spec ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p47_瓦当滴水一对/object.toml \
  --out ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p47_瓦当滴水一对/whitemodel/p47_瓦当滴水一对.blend
```

4. 白模落盘后重跑 `tools/build_bianjing.py`——`resolve_asset` 会自动把 `p47` 的同尺寸替身
   换成真网格，shot previz 跟着变，**布局代码一个字都不用改**。

- [ ] **圆瓦当** 在，且不是糊成一坨
- [ ] **尖底滴水** 在，且不是糊成一坨
- [ ] **后接板瓦垄** 在，且不是糊成一坨
- [ ] 整体比例与 `形体规格` 对得上（不是被拉长或压扁的）
- [ ] 没有多生出来的部件、没有把背景当成几何吸进来
- [ ] 薄件（辕、杆、栏、绳）没有被甩成碎渣——这是 image-to-3D 最不稳的地方，挂了就重掷
