# 草屋 · p54（物件白模源）

> **它是什么**：城墙边与郊外的草屋：泥抹编竹墙，一扇歪斜的板门，屋顶厚厚一层芦苇草，脊上压着几根木杆与石块
>
> **出现在**：城墙脚下、郊外、关厢、huts 地块类型的母本
> **真实尺寸**：宽 4.2 × 长 4 × 高 3.6 米（`object.toml` 的 `尺寸`，白模闸门按它等比缩放）
> **朝向**：正面朝 `+Y`（归一化目标；`object.toml` 的 `目标朝向`）

本卡是**工装卡**，不是入画的画面卡：这三张图是喂 image-to-3D 的原料，
按 sk1 divergence #18 一律**正交 + 阴天均匀光**，与 follow-up 014 的 GoT 实拍画风无关。

## 开工顺序

1. 先出 **`p54-1` 正面**（纯文字生成）——**它就是那张参考**，形制、比例、部件位置由它定死。
2. 再出 **`p54-2` 侧面 / `p54-3` 背面**，两张都把 `p54-1` 放进参考槽、**只换机位**。
3. 三张齐了（自动出图：`python tools/image_fetch.py --object p54`），跑：

```bash
python tools/hyper3d_fetch.py --tier Regular --bbox 4.2 4 3.6 \
  --image ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p54_草屋/p54-1.png \
  --image ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p54_草屋/p54-2.png \
  --image ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p54_草屋/p54-3.png \
  --out ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p54_草屋/whitemodel/raw.glb

blender -b --factory-startup --python tools/whitemodel_normalize.py -- \
  --src ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p54_草屋/whitemodel/raw.glb \
  --spec ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p54_草屋/object.toml \
  --out ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p54_草屋/whitemodel/p54_草屋.blend
```

4. 白模落盘后重跑 `tools/build_bianjing.py`——`resolve_asset` 会自动把 `p54` 的同尺寸替身
   换成真网格，shot previz 跟着变，**布局代码一个字都不用改**。

- [ ] **泥抹编竹墙** 在，且不是糊成一坨

- [ ] 没有多生出来的部件、没有把背景当成几何吸进来
- [ ] 薄件（辕、杆、栏、绳）没有被甩成碎渣——这是 image-to-3D 最不稳的地方，挂了就重掷
