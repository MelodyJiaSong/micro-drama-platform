## 开工顺序

1. 先出 **`p49-1` 正面**（纯文字生成）——**它就是那张参考**，形制、比例、部件位置由它定死。
2. 再出 **`p49-2` 侧面 / `p49-3` 背面**，两张都把 `p49-1` 放进参考槽、**只换机位**。
3. 三张齐了（自动出图：`python tools/image_fetch.py --object p49`），跑：

```bash
python tools/hyper3d_fetch.py --tier Regular --bbox 2.4 0.14 1.05 \
  --image ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p49_木栏杆一段/p49-1.png \
  --image ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p49_木栏杆一段/p49-2.png \
  --image ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p49_木栏杆一段/p49-3.png \
  --out ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p49_木栏杆一段/whitemodel/raw.glb

blender -b --factory-startup --python tools/whitemodel_normalize.py -- \
  --src ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p49_木栏杆一段/whitemodel/raw.glb \
  --spec ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p49_木栏杆一段/object.toml \
  --out ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p49_木栏杆一段/whitemodel/p49_木栏杆一段.blend
```

4. 白模落盘后重跑 `tools/build_bianjing.py`——`resolve_asset` 会自动把 `p49` 的同尺寸替身
   换成真网格，shot previz 跟着变，**布局代码一个字都不用改**。

- [ ] **望柱与柱头** 在，且不是糊成一坨
- [ ] **扁平寻杖** 在，且不是糊成一坨
- [ ] **方棂** 在，且不是糊成一坨
- [ ] **地栿** 在，且不是糊成一坨
- [ ] 整体比例与 `形体规格` 对得上（不是被拉长或压扁的）
- [ ] 没有多生出来的部件、没有把背景当成几何吸进来
- [ ] 薄件（辕、杆、栏、绳）没有被甩成碎渣——这是 image-to-3D 最不稳的地方，挂了就重掷
