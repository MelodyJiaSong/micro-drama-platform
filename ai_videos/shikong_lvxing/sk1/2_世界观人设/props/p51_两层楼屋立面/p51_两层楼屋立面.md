# 两层楼屋立面 · p51（物件白模源）

> **它是什么**：北宋临街两层楼屋·三间：下层柱间板门与直棂窗，二层出挑一道木栏杆平座，栏内三扇支摘窗，檐下斗拱托深远出檐，青灰板瓦悬山顶
>
> **出现在**：bg4 州桥御街、bg5 正店酒楼、bg17 州桥夜市、繁华沿街两层房的母本
> **真实尺寸**：宽 11.1 × 长 9 × 高 8.5 米（`object.toml` 的 `尺寸`，白模闸门按它等比缩放）
> **朝向**：正面朝 `+Y`（归一化目标；`object.toml` 的 `目标朝向`）

本卡是**工装卡**，不是入画的画面卡：这三张图是喂 image-to-3D 的原料，
按 sk1 divergence #18 一律**正交 + 阴天均匀光**，与 follow-up 014 的 GoT 实拍画风无关。

## 开工顺序

1. 先出 **`p51-1` 正面**（纯文字生成）——**它就是那张参考**，形制、比例、部件位置由它定死。
2. 再出 **`p51-2` 侧面 / `p51-3` 背面**，两张都把 `p51-1` 放进参考槽、**只换机位**。
3. 三张齐了（自动出图：`python tools/image_fetch.py --object p51`），跑：

```bash
python tools/hyper3d_fetch.py --tier Regular --bbox 11.1 9 8.5 \
  --image ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p51_两层楼屋立面/p51-1.png \
  --image ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p51_两层楼屋立面/p51-2.png \
  --image ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p51_两层楼屋立面/p51-3.png \
  --out ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p51_两层楼屋立面/whitemodel/raw.glb

blender -b --factory-startup --python tools/whitemodel_normalize.py -- \
  --src ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p51_两层楼屋立面/whitemodel/raw.glb \
  --spec ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p51_两层楼屋立面/object.toml \
  --out ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p51_两层楼屋立面/whitemodel/p51_两层楼屋立面.blend
```

4. 白模落盘后重跑 `tools/build_bianjing.py`——`resolve_asset` 会自动把 `p51` 的同尺寸替身
   换成真网格，shot previz 跟着变，**布局代码一个字都不用改**。
