## 开工顺序

1. 先出 **`p57-1` 正面**（纯文字生成）——**它就是那张参考**，形制、比例、部件位置由它定死。
2. 再出 **`p57-2` 侧面 / `p57-3` 背面**，两张都把 `p57-1` 放进参考槽、**只换机位**。
3. 三张齐了（自动出图：`python tools/image_fetch.py --object p57`），跑：

```bash
python tools/hyper3d_fetch.py --tier Regular --bbox 15.5 7.5 9.5 \
  --image ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p57_寺院大三门/p57-1.png \
  --image ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p57_寺院大三门/p57-2.png \
  --image ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p57_寺院大三门/p57-3.png \
  --out ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p57_寺院大三门/whitemodel/raw.glb

blender -b --factory-startup --python tools/whitemodel_normalize.py -- \
  --src ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p57_寺院大三门/whitemodel/raw.glb \
  --spec ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p57_寺院大三门/object.toml \
  --out ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p57_寺院大三门/whitemodel/p57_寺院大三门.blend
```

4. 白模落盘后重跑 `tools/build_bianjing.py`——`resolve_asset` 会自动把 `p57` 的同尺寸替身
   换成真网格，shot previz 跟着变，**布局代码一个字都不用改**。
