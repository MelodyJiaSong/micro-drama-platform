# 漕船 · p12（物件白模源）

> **它是什么**：北宋汴河漕船：平底高舷木壳货船，船中一列带木窗的席篷舱棚，船尾高起为舵楼、一根长木舵斜插入水，桅杆放倒斜卧舱棚顶上，舱面堆鼓胀粗布粮袋
>
> **出现在**：bg0-2 汴河低空、bg1 虹桥、bg3 汴河码头、shot01 码头段、shot26 险情
> **真实尺寸**：宽 4.5 × 长 18 × 高 3 米（`object.toml` 的 `尺寸`，白模闸门按它等比缩放）
> **朝向**：正面朝 `+Y`（归一化目标；`object.toml` 的 `目标朝向`）

本卡是**工装卡**，不是入画的画面卡：这三张图是喂 image-to-3D 的原料，
按 sk1 divergence #18 一律**正交 + 阴天均匀光**，与 follow-up 014 的 GoT 实拍画风无关。

## 开工顺序

1. 先出 **`p12-1` 正面**（纯文字生成）——**它就是那张参考**，形制、比例、部件位置由它定死。
2. 再出 **`p12-2` 侧面 / `p12-3` 背面**，两张都把 `p12-1` 放进参考槽、**只换机位**。
3. 三张齐了（自动出图：`python tools/image_fetch.py --object p12`），跑：

```bash
python tools/hyper3d_fetch.py --tier Regular --bbox 4.5 18 3 \
  --image ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p12_漕船/p12-1.png \
  --image ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p12_漕船/p12-2.png \
  --image ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p12_漕船/p12-3.png \
  --out ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p12_漕船/whitemodel/raw.glb

blender -b --factory-startup --python tools/whitemodel_normalize.py -- \
  --src ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p12_漕船/whitemodel/raw.glb \
  --spec ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p12_漕船/object.toml \
  --out ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p12_漕船/whitemodel/p12_漕船.blend
```

4. 白模落盘后重跑 `tools/build_bianjing.py`——`resolve_asset` 会自动把 `p12` 的同尺寸替身
   换成真网格，shot previz 跟着变，**布局代码一个字都不用改**。

- [ ] **舵楼与长木舵** 在，且不是糊成一坨
- [ ] **放倒的桅杆** 在，且不是糊成一坨
- [ ] **舱面粮袋** 在，且不是糊成一坨
- [ ] 整体比例与 `形体规格` 对得上（不是被拉长或压扁的）
- [ ] 没有多生出来的部件、没有把背景当成几何吸进来
- [ ] 薄件（辕、杆、栏、绳）没有被甩成碎渣——这是 image-to-3D 最不稳的地方，挂了就重掷
