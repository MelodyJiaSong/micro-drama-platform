# 一间小瓦房立面 · p61（物件白模源）

> **它是什么**：北宋坊巷最常见的一间小瓦房立面：一开间木构，两根柱夹一扇板门、门旁一扇小直棂窗，檐下只有简素替木不用斗拱，青灰板瓦悬山顶出檐深远，台基只有两三寸
>
> **出现在**：bg7 坊巷民居、城内街区四米面宽档（占全城约四成）、shot01 河街、shot02 汴河两岸
> **真实尺寸**：宽 4.6 × 长 5 × 高 4.2 米（`object.toml` 的 `尺寸`，白模闸门按它等比缩放）
> **朝向**：正面朝 `+Y`（归一化目标；`object.toml` 的 `目标朝向`）

本卡是**工装卡**，不是入画的画面卡：这三张图是喂 image-to-3D 的原料，
按 sk1 divergence #18 一律**正交 + 阴天均匀光**，与 follow-up 014 的 GoT 实拍画风无关。

## 开工顺序

1. 先出 **`p61-1` 正面**（纯文字生成）——**它就是那张参考**，形制、比例、部件位置由它定死。
2. 再出 **`p61-2` 侧面 / `p61-3` 背面**，两张都把 `p61-1` 放进参考槽、**只换机位**。
3. 三张齐了（自动出图：`python tools/image_fetch.py --object p61`），跑：

```bash
python tools/hyper3d_fetch.py --tier Regular --bbox 4.6 5 4.2 \
  --image ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p61_一间小瓦房立面/p61-1.png \
  --image ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p61_一间小瓦房立面/p61-2.png \
  --image ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p61_一间小瓦房立面/p61-3.png \
  --out ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p61_一间小瓦房立面/whitemodel/raw.glb

blender -b --factory-startup --python tools/whitemodel_normalize.py -- \
  --src ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p61_一间小瓦房立面/whitemodel/raw.glb \
  --spec ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p61_一间小瓦房立面/object.toml \
  --out ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p61_一间小瓦房立面/whitemodel/p61_一间小瓦房立面.blend
```

4. 白模落盘后重跑 `tools/build_bianjing.py`——`resolve_asset` 会自动把 `p61` 的同尺寸替身
   换成真网格，shot previz 跟着变，**布局代码一个字都不用改**。
