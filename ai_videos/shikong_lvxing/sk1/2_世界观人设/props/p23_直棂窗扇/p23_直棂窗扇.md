# 直棂窗扇 · p23（物件白模源）

> **它是什么**：宋式直棂窗：一扇木框内竖着一排等距的方棂条，没有花纹、没有格心，是这座城最常见的一扇窗
>
> **出现在**：bg7 坊巷民居、bg10 赵太丞家、bg14 客店、bg1 民居
> **真实尺寸**：宽 1.2 × 长 0.08 × 高 1.4 米（`object.toml` 的 `尺寸`，白模闸门按它等比缩放）
> **朝向**：正面朝 `+Y`（归一化目标；`object.toml` 的 `目标朝向`）

本卡是**工装卡**，不是入画的画面卡：这三张图是喂 image-to-3D 的原料，
按 sk1 divergence #18 一律**正交 + 阴天均匀光**，与 follow-up 014 的 GoT 实拍画风无关。

## 开工顺序

1. 先出 **`p23-1` 正面**（纯文字生成）——**它就是那张参考**，形制、比例、部件位置由它定死。
2. 再出 **`p23-2` 侧面 / `p23-3` 背面**，两张都把 `p23-1` 放进参考槽、**只换机位**。
3. 三张齐了（自动出图：`python tools/image_fetch.py --object p23`），跑：

```bash
python tools/hyper3d_fetch.py --tier Regular --bbox 1.2 0.08 1.4 \
  --image ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p23_直棂窗扇/p23-1.png \
  --image ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p23_直棂窗扇/p23-2.png \
  --image ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p23_直棂窗扇/p23-3.png \
  --out ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p23_直棂窗扇/whitemodel/raw.glb

blender -b --factory-startup --python tools/whitemodel_normalize.py -- \
  --src ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p23_直棂窗扇/whitemodel/raw.glb \
  --spec ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p23_直棂窗扇/object.toml \
  --out ai_videos/shikong_lvxing/sk1/2_世界观人设/props/p23_直棂窗扇/whitemodel/p23_直棂窗扇.blend
```

4. 白模落盘后重跑 `tools/build_bianjing.py`——`resolve_asset` 会自动把 `p23` 的同尺寸替身
   换成真网格，shot previz 跟着变，**布局代码一个字都不用改**。

## 验收（`object.toml` 的探针只测体量，这几条要人眼看）

- [ ] **窗框** 在，且不是糊成一坨
- [ ] **竖棂条** 在，且不是糊成一坨
- [ ] 整体比例与 `形体规格` 对得上（不是被拉长或压扁的）
- [ ] 没有多生出来的部件、没有把背景当成几何吸进来
- [ ] 薄件（辕、杆、栏、绳）没有被甩成碎渣——这是 image-to-3D 最不稳的地方，挂了就重掷
