# 太平车与独轮车 · p6（东京般载车三式）

## 定位

**站一「东水门入城」与码头段的街车层。** 卷三「般载杂卖」：「东京般载车，大者曰太平，上有箱无盖，箱如构栏而平，板壁前出两木，长二三尺许，驾车人在中间，两手扶捉鞭裹驾之，前列骡或驴二十余，前后作两行；或牛五七头拽之。车两轮与箱齐，后有两斜木脚拖夜；中间悬一铁铃，行即有声……可载数十石」（`kaifeng.cart.001` / `kaifeng.travel.008` ✅）；「平头车亦如太平车而小，两轮前出长木作辕木，梢横一木，以独牛在辕内，项负横木，人在一边，以手牵牛鼻绳驾之，酒正店多以此载酒梢桶」（`kaifeng.cart.002` ✅）；「独轮车，前后二人把驾，两旁两人扶拐，前有驴拽，谓之串车……般载竹木瓦石」（`kaifeng.cart.003` ✅）。

- **本站误传 ❌**：街上跑四轮载人马车（`kaifeng.myth.013` ⚠️ / 黑名单 K13）——史料只见太平车 / 平头车 / 串车运货，人骑驴马或乘轿；画中驴多马少（`kaifeng.cart.004` T3）。
- **两个锚点**：`p6-1` 太平车 + 串车（一大一小两式，同一街面）；`p6-2` 平头车运酒梢桶（正店门口那一辆，`price.006` 梢桶酒一贯五百文）。**器物锚点一律无人无畜**——牲口与车夫在 shot 里按原文加（太平车牛五七头 / 骡驴二十余两行；串车前后二人把驾、两旁二人扶拐、前有驴拽），并受**一镜 ≤ 8 主体**约束：太平车镜只用「牛五头」版，不用骡驴二十余。
- 判断：`refs.md` 把太平车 / 串车 / 平头车三式合在一个目录（`p6`），与 rule 4e「一个目录＝一个主体」有张力；三式都是「东京般载车」、共用木作材质与轮制，本卡按简报保留同目录、以两张锚点分别锁定，不再拆目录。

## 用法纪律（写进有它的镜的 `动作:` / `场景:` 行）

1. **人畜按原文、受 ≤ 8 约束**：太平车镜写「牛五头分两行拽、驾车人立在前出两木之间执鞭」，不写骡驴二十余；串车镜写「后一人把驾、前一人拉绳、旁一人扶拐、前一头驴拽」（四主体）；平头车镜写「独牛在辕内项负横木、车夫在一边牵牛鼻绳走」——**车夫不坐车上、不挥鞭**（`cart.002` negative）。
2. **铁铃走声音**：太平车动起来铁铃「行即有声」——声音锚写进 `台词:` 之外的声效行；静止镜铁铃垂直不摆。
3. **车尾两斜木脚拖地**：行进时拖出两道浅沟、停下时撑住车尾——地面痕迹走 rule 16.8「痕迹是名词化的冷材质」（「车辙与两道拖痕」），不写「正在拖」除非车在动。
4. **东水门入城镜**：「卖麦面一宛」的太平车从城外守门入城（`kaifeng.job.021`）——车厢里码的是麻袋，不是木桶；平头车才载酒梢桶（`cart.002`），两式不混。
5. **载重要看得见**：数十石的麻袋把栏板压满、轮下地面有压痕；空车镜要反向声明「车厢空、栏板内无物」。
6. **驴多马少**（`cart.004`）：街面配畜默认驴与牛，马只给身份角色。
7. **负向必带**：四轮马车, 带篷马车, 欧式 carriage, 橡胶轮胎, 铁辐条轮, 车夫礼帽, 自行车, 三轮车, 手推购物车。
