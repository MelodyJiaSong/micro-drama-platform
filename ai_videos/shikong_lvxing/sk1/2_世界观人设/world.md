## 1. 这是什么地方

**北宋东京汴梁，外城周四十余里的漕运之都；宣和二年清明这一天，全城的人都在城外，夜市却照样开到三更。**

| 为什么 | 答案 |
|---|---|
| 为什么它好看 | **一座桥、一条街、一片彩楼、一片田野**：东水门外七里那座无柱朱漆木拱虹桥「宛如飞虹」（`kaifeng.route.004` ✅）；御街阔二百余步、两行朱漆杈子夹出御道、杈子里御沟遍植莲荷（`route.009` `route.010` ✅）；街市酒店「彩楼相对，绣旆相招，掩翳天日」（`shop.003` ✅）；清明日「四野如市」，轿顶插满杨柳杂花（`festival.007` `festival.008` ✅）。四个奇观构图都有原文 |
| 为什么它可信 | 285 条事实、266 条带逐字原文；写这座城的人（孟元老）1120 年本人就住在城里（`person.001`）；画这座城的人（张择端）宣和间在翰林图画院（`person.002`）。**每个形制词后面有一个 `fact_id`，每个 `fact_id` 指向一张参考图**——真实感来自查到的东西，不来自模型的想象 |
| 为什么非它不可 | 汴河一年运六百万石粮进城（`travel.001` ✅《宋史》），仓前「袋家每人肩两石」（`job.001` ✅）——**一天工钱、一斗米、一贯铜钱，在这里全部能落到一个具体的人身上**；汴京不禁夜（`travel.011` `travel.012` ✅），一天可以从五更报晓讲到三更收市；清明日迎祥池一年只开这一天（`route.014` ✅）——**一天讲清一座城，只有这一天** |

## 2. 地形与城市结构（`city_plan` 要素，S2_E / 建城脚本照此摆）

汴京是平原上的一座三重城（外城 / 内城 / 宫城，城墙并不正南北，外城南北墙偏约 14°，`city.024`），汴河从西北向东南斜穿城中。旅行者路线（2026-09-14 游览形态，见 `../3_大纲/outline.md`）：**航拍扫全城 → 虹桥（城外）→ 东水门（入城）→ 沿城客店入住换装 → 天晓早市 → 汴河码头 → 街市租驴 → 赵太丞家医铺 → 州桥 · 御街 → 宣德楼 · 宣德门内 → 开封府 → 相国寺 → 园池雅集 → 出郊 · 迎祥池 → 回虹桥（险情）→ 瓦子勾栏 → 州桥夜市 → 正店 → 客店过夜 → 五更航拍收束**。虹桥在东水门外七里（`route.004`）。

## 8. 真实性铁律（违反即重做）

1. **画面里不生成任何文字**（2026-09-14 审查裁定）：真实店名「孙羊正店」「十千脚店」「香饮子」「赵太丞家」（`shop.004` T2，出片前对原本逐字核）一律由后期加字，锚点与分镜 prompt 里的招牌、木匾全部空白；负向必带「乱码汉字 / 印刷体招牌」。
2. **零 hex**：颜色全用中文色名（`style_guide.md` §2）。
3. **平民只有皂、白、灰青麻布；交领 / 直领对襟；软巾、包髻、无脚圆顶幞头；天足低帮鞋**——锁定串必带一句「不是 X」。
4. **铜钱是唯一货币**：麻绳串、七十五陌；负向：银锭 / 元宝 / 碎银 / 银票 / 纸币。
5. **建筑素木不上漆、灰瓦、无彩画**；朱漆只给虹桥（`route.004`）、御街杈子（`route.009`）、城楼木作（`gate.006`）、宣德楼朱漆金钉门（`palace.002`；宣德楼单檐绿琉璃瓦是全片唯一的琉璃瓦，`palace.004`）；彩楼欢门上的红是绸帛不是漆。
6. **虹桥在城外七里、州桥是青石低桥**——不许把木拱桥画到御街上。
7. **蜡烛只在正店**；平民夜里油灯；街上无灯笼串。
8. **群像 ≤ 8 主体可辨**，其余远景剪影；桥上人流、清明出郊、夜市都拆镜或剪影。
9. **`ai_draft` 不进 prompt**；⚠️ 镜口播「史书没写 / 按……推算」。
10. **光按时段条件化写进每镜**；共用串里不放任何光源（rule 16.9）；无该光源的镜反向声明。
