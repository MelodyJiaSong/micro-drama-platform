# 人物网 · sk1

> `ai_video.md` rule 12.11 要求每部建人物网。sk1 是**游览 vlog**（用户 2026-09-14）：林问是唯一开口的人，默认哪儿都能去、没人拦她；她不采访、不和任何当地人交谈——古人的口音谁也不知道，她只看、只付钱、只对镜讲。
> 所以这张网参照 hy4 的写法，记的不是对话关系，而是**她与这座城、与她亲手试的东西、与她一再注意到的沉默的人**。站与站独立，本表没有跨站关系。
> 与各角色卡 `## 人物灵魂` 双向一致：林问以本站变体卡 `characters/c1_林问/` 的 sk1 校正为准（未改维度指回系列卡）；c2–c4 以各自卡的沉默版为准。变化态按一日时间线写，具体镜次待新大纲回填（ongoing）。

## 本站当前主题

**一个只能看、只能付钱、不能开口问的外乡人，怎么把这座城平平常常的一天讲清楚。**

立意落点（concept）：历史不是课本上的年号，是那天早上有人扛着两石米走到仓门口——她问不了他，只能看见他，再把看见的讲清楚。

## 1. 她与这座城

| 关系 | 内容 |
|---|---|
| **不是征服，也不是采访** | 城不认她，也不理她；她不打扰任何人。**她在这座城里当一天不开口的客人**：跟着人流进城，跟着人流出郊 |
| **是通行** | 没人拦她——街市、客店、瓦子、码头、御街、当天大事的现场，连医馆、官署、宫城外、文人聚处都能去看一眼。**她的限制不是「进不去」，是「问不了」** |
| **是翻译** | 城不解释自己。她把看见的东西对镜讲出来，并说清哪句史书写了、哪句是推测（⚠️ 的内容必须口播「史书没写」） |
| **是规矩的旁观者** | 御街朱杈子里不许走（`route.009`），「大人」只叫爹（`lang.004`）——这些规矩没人拿来拦她，是她自己看明白、对镜讲给观众 |

## 2. 她与她亲手试的东西

| 物 | 关系 |
|---|---|
| **铜钱**（`p2`） | 这座城只认铜钱，碎银在摊子上被摇头推回（`myth.001`）。**付钱是她和这座城唯一的「交谈」**：递过去、对方数、点头。街市一「百」文只数七十五枚（`money.002`）——她是看着别人数才学会的 |
| **吃食**（`p1` / `p4` / 早市与夜市） | 先看别人怎么买，再照着买；吃一口，对镜打分。她不问价，价钱靠史书和看见的铜钱数 |
| **客店**（`bg7-2`） | 住一晚的地方：椅凳、油灯、白瓷碗（`house.001` `house.005` `house.012`）；夜里在油灯下把一整天翻一遍 |
| **宋装**（c1 锁定串） | 进城后第一件「我试试」：逐件换上，逐件对镜讲「不是明代立领、不是清代长辫」；换完先把三件不变物安顿好，再出门 |
| **三件不变物 + 胸牌**（`p3`） | 她身上唯一的现代物。**话筒不递给任何人**，只对着镜头；采访本每到一处翻一页 |

## 3. 她一再注意到的沉默的人（可选入画）

> 三个人都是**可选的沉默复现面孔**，是否出场、出几镜由新大纲定。他们不知道有人在看，也从不看镜头。

| 人 | 她看见什么 | 为什么值得看 |
|---|---|---|
| **李十六**（c2，仓前袋家） | 扛两石布袋上跳板；歇脚时撩开衣领摸肩上的纤绳印子；领钱当面数到头；黄昏直起腰看一条船过闸 | 他就是「一天工钱」本人。她对镜算「一贯钱够脚夫扛几天」时，画面上是他的背影 |
| **周四娘**（c3，汤茶药摊主） | 竖两根手指报价，铜钱当面数完才递碗，递来碎银就摇头推回；客人稀了，朝河面望很久 | 林问在她这儿付出第一笔真钱；这个撑家的女人不用一句话，就让她懂了「这座城只认铜钱」 |
| **沈十九**（c4，虹桥头铺兵） | 白天靠着骨朵晒太阳；险情时第一个冲上桥头、挥骨朵把人往桥栏两边拨；急完靠着桥栏喘，把歪了的幞头扶正 | 当天大事里，他是「在场且必须动手的人」，她是「在场却不能动手的人」 |

## 人物 × 主题

| 角色 | 在主题命题上站哪边 | 印证 / 反诘主题 |
|---|---|---|
| c1 林问 | 主题的执行者：只看、只付钱、不开口问 | **印证**——她把「问」全换成「看 + 讲」；**反诘**——当天大事上她「话到嘴边」（只走画外），说明不开口是选择，不是冷漠 |
| c2 李十六（可选） | 被看的那一天本身 | **印证**——没留下名字的人的一天，就是立意里那「两石米」；他不知道有人在看，这正是「在场而不打扰」 |
| c3 周四娘（可选） | 这座城的规矩由她的手说出来 | **印证**——铜钱、数陌、不收银子，全靠动作教会外乡人；**反诘**——她忙得没空理任何人，外乡人的好奇在她的一天里无足轻重 |
| c4 沈十九（可选） | 在场、必须动手的人 | **反诘**——他和林问是一对镜像：同在桥头，他能冲上去，她只能看；主题因此不是「旁观很轻松」，而是「旁观有代价」 |
| 城里的无名人群 | 不开口的背景 | **印证**——群声没有可辨字句，这座城对她是可看而不可问的 |
