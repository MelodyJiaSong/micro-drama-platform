# 锡镴与木器餐具 · Seedance 主体（物件）

## 这个主体是干什么的

两顿可拍的饭（w3 §4.6：正午街头一顿 + 下午一顿）的全部器皿，也是「**零叉子**」这个反差点的画面证据——1666 年平民吃饭只有**手指、一把随身小刀、一只勺**，叉子被视为「意大利式的外国做作」（`london1666.food.027`，L08）。器皿按阶层分三档（`london1666.food.028`），本卡只做最下两档：穷人的木托盘 trencher + 素陶杯 / 中等人家的锡镴盘与锡镴大杯；**乡绅的银器与瓷器不在本站画面里**。**三视图与网格只做锡镴大杯那一件**——它是唯一会被端在手里、进近景的器物；其余器皿在第四张平摊图里给形制，不各自建网格。

## 锁定描述符（跨镜 byte-identical，自然色名无 hex）

| # | 字段 | 值 |
|---|---|---|
| 1 | 类型 / 时代 / 室内外 | 1666 年伦敦平民与中等人家的一副餐具，桌面；室内外两顿饭共用 |
| 2 | 锡镴大杯（网格主体） | 直筒微收口的单柄大杯，高约一掌半、口径约三指；柄是扁条弯成的 C 形、下端收成卷尾；杯身**灰白哑光、几乎不反光**，有凹痕与磨白的边（`london1666.food.028`） |
| 3 | 锡镴盘 | 浅圆盘，宽平沿、盘心刀痕累累，同样灰白哑光；中等人家有，极穷人家没有 |
| 4 | 木托盘 trencher | 橡木或山毛榉削出的方形或圆形厚木板，边缘刀痕累累、木纹被油浸成深褐发黑；极穷人家就吃这个（`london1666.food.028`） |
| 5 | 素陶杯 | 无釉或半釉的粗陶杯，砖褐到灰褐，壁厚、口沿不匀、底有旋坯痕 |
| 6 | 送进嘴的只有三样 | **手指、一把随身小刀（窄刃、木柄，单独别在腰上）、一只木勺或角勺**；肉用刀尖挑进嘴，汤羹用勺，面包用手撕——**画面里一根叉子都没有**（`london1666.food.027`） |
| 7 | 配色（自然色名） | 锡镴的灰白哑光、木器的深褐油浸、陶的砖褐到灰褐、刀刃的暗锈灰、木柄的风化木褐 |
| 8 | 一句话锁定 | 灰白不反光的锡镴、油浸发黑的木盘、粗陶杯，一把刀一只勺，没有叉子 |

**锁定串必带「不是 X」**：**不是**西餐摆台（刀叉并排、餐巾折花、成套同款）——**一根叉子都不许出现**，三齿四齿叉更要到 17 世纪第三个四分之一才有（`london1666.food.027`，L08）；**不是**白瓷盘、玻璃杯、不锈钢餐具；**不是**闪亮反光的金属器皿——锡镴是**灰白哑光、几乎不反光**的，有凹痕与磨白的边；**不是**成套同款——每件的来路与磨损都不同。专属负向：`叉子, 三齿叉, 四齿叉, 刀叉并排, 餐巾折花, 成套同款餐具, 白瓷盘, 骨瓷, 玻璃杯, 不锈钢, 镜面反光金属`

## 三视图链（image-to-3D 输入，rule 4d）

`-1 正面` 纯文字生成 ＝ 那张参考 → `-2 侧面` / `-3 背面` 把 `-1` 挂进 `images` **只换机位**。三张各自独立生成一定不互相同意（形制、比例、部件位置各漂各的）。
**三视图一律阴天均匀光、灰底**——它们是喂重建的工装图，不是给人看的画面。

## 走 Hyper3D（rule 4g §B 四问：有界的有机小件）

`python tools/hyper3d_fetch.py` 出原始网格 → `tools/whitemodel_normalize.py` 过闸门 → `p4.blend`。**出了模型先渲一眼再往下做**，别拿没看过的网格去绑定。

## 已知空白（不编，显式留着）

⚠️ **锡镴大杯的盖与柄的确切形制未查到**——`london1666.food.028` 只给到「灰白哑光、有凹痕与磨白的边」这一级。本卡按同期英格兰锡镴器通例写成**无盖、单 C 形柄**，**标 ⚠️、不作形制断言**。⚠️ 随身小刀的刃长、柄材与佩带方式同样是通例推算，无一手出处。⚠️ `london1666.food.028` 给的 6–12 件 / 40–50 件是**自耕农家庭**的清单数，不是伦敦城内的；画面只用它的**分档关系**，**不报件数**。
