# 余杭客栈 · 几何契约（`build_yuhang_kezhan.py` 的唯一输入）

> 本文件是**这座建筑所有数值的唯一出处**。改几何 ＝ 改本文件 + 改生成器重跑，
> **绝不手改 `.blend`**（`ai_video.md` rule 4h ④）。
> 生成器只出**几何**，不做材质、不打灯（rule 4g ⑤：建筑保持灰模，长相由场景主体卡与生成模型给）。
> 形制依据：明代江南（杭州—余杭）市镇临街二层客栈，**穿斗式木构架 + 粉墙小青瓦 + 悬山顶**。
> 画面依据：`0_原作资料/refs_game98/p01/` t00150（逍遥房内）、t00220（大堂青砖地与方桌长凳）。

## 0. 坐标系与朝向

| 项 | 约定 |
|---|---|
| 轴 | `+X = 东`，`+Y = 北`，`+Z = 上`；单位 **米** |
| 原点 | 一层室内地坪面（±0.000）与**西南角柱中心**的交点，即 `(0, 0, 0)` |
| 临街面 | **南**（`y = 0` 一侧），大门在明间 |
| 晨光来向 | **东**（`+X`）。李逍遥房在东端、窗开在东山墙，故清晨直射光进他的房；大堂东侧二层槛窗把光打进挑空 |

> 朝向是被剧本反推定的：script.md 要求「清晨的光从木格窗斜进来」与「晨光从大堂高处斜下来」，
> 且要求逍遥出房后**沿走廊跑一段**才到楼梯。故**房在东、楼梯在西**，走廊自东向西 10.5 m。

## 2. 柱网

**面阔（x，西→东）**：`0 / 3.30 / 7.20 / 10.50`　→　西次间 3.30｜**明间 3.90**｜东次间 3.30｜**总面阔 10.50**

**进深（y，南→北）**：`0 / 1.50 / 7.50 / 10.50 / 12.00`
| 柱列 | y | 作用 |
|---|---|---|
| 前檐柱 | 0.00 | 临街廊柱 |
| 前金柱 | 1.50 | 前廊进深 1.50；大堂南界 |
| 中柱 | 7.50 | 大堂进深 **6.00**；大堂北界 |
| 后金柱 | 10.50 | 走廊北界／客房南墙 |
| 后檐柱 | 12.00 | 客房北墙；**总进深 12.00** |

柱脚均落 `石础`：方础 0.45×0.45×0.12 ＋ 鼓镜 R 0.17 × h 0.06。

## 3. 竖向

| 标高 | 值 | 说明 |
|---|---|---|
| 一层地坪 | ±0.000 | 大堂 **青砖墁地**（见 §7） |
| 一层梁底 | +3.600 | 二层楼板大梁底 |
| 二层楼面 | +3.800 | 楼板面；北半部才有，南半部是挑空 |
| 二层梁底 | +6.350 | 檐檩底 |
| 檐檩顶 | +6.600 | 出檐处 |

**大堂挑空**：`y ∈ [1.50, 7.50]` 全面阔通高，地坪到屋架下约 **6.6 m**。
穿斗式**柱通到顶**（不是层叠柱），一层柱与二层柱是同一根，中间由穿枋拉结——这是本建筑能挑空的构造前提。

## 4. 屋架（悬山顶，脊沿东西向）

**七檩**，y 位置与檩顶标高（举折曲线，檐缓脊陡，江南做法）：

| 檩 | y | 顶标高 | 该段坡度 |
|---|---|---|---|
| 前檐檩 | −0.90 | 6.600 | — |
| 前下金檩 | 1.50 | 7.180 | 0.242 |
| 前上金檩 | 3.75 | 8.000 | 0.364 |
| **脊檩** | 6.00 | 9.300 | 0.578 |
| 后上金檩 | 8.25 | 8.000 | 0.578 |
| 后下金檩 | 10.50 | 7.180 | 0.364 |
| 后檐檩 | 12.90 | 6.600 | 0.242 |

- 檩径 0.20，出山（悬山挑出）东西各 **0.60**，故檩长 `10.50 + 0.24 + 2×0.60 = 11.94`。
- 椽 0.09（宽）× 0.07（高），**中距 0.35**，沿 x 排布，跨在相邻两檩之间，按两檩顶连线铺设。
- 望板 0.025 厚，铺在椽上。
- **小青瓦仰合瓦**：仰瓦（凹面朝上）中距 0.16，合瓦（凸面朝下）压在仰瓦垄缝上；瓦长 0.20、搭接 0.07。
  沿坡方向逐段按该段坡度铺，段与段之间不强行连续（举折本来就是折线）。
- 正脊：清水脊，高 0.28、厚 0.10，沿 x 通长。

## 5. 二层平面（+3.800）

`y ∈ [7.50, 12.00]` 有楼板，`y ∈ [1.50, 7.50]` 是挑空。

| 分区 | y 范围 | 说明 |
|---|---|---|
| **走廊** | 7.50 – 9.00（宽 1.50） | 南侧临挑空，设栏杆；北侧是四扇客房门。东西通长 10.50 |
| **客房带** | 9.00 – 12.00（深 3.00） | 四间，西→东：客房丙 2.40｜客房乙 2.40｜客房甲 2.40｜**李逍遥房 3.30** |

**李逍遥房**：`x ∈ [7.20, 10.50]`，`y ∈ [9.00, 12.00]`，净 3.30 × 3.00 ≈ 9.9 ㎡。
东山墙开 **木格窗** 1.00 × 1.00，洞口中心 y = 11.25，窗台 +4.70（离室内地面 0.90）——晨光由此进；详见 §6。

**楼梯**：西端，`x ∈ [0, 1.20]`，直跑，自二层走廊西端（y ≈ 8.25）向南下至一层 `y ≈ 3.85`。
**18 级**：踏步高 0.2111（3.800/18），踏面宽 0.26，总水平投影 `17 × 0.26 = 4.42`，坡度 39°。
梯段宽 1.10，两侧无栏板，仅靠墙一侧有扶手。

**栏杆**（走廊南侧临空，栏杆中线 y = 7.62）：
**x 自 1.20 起至 10.50**——`x ∈ [0, 1.20]` 是楼梯口，栏杆必须在此让开，
否则人从走廊根本下不去楼梯（首轮建完即由 qc_03 发现）。
望柱 0.10×0.10，高出楼面 0.95，**9 档 × 1.0333**；寻杖扶手 0.09×0.07；
下部绦环板高 0.22（贴楼面）；中间竖棂 0.035×0.035，每档 5 根。

## 6. 门窗

- **一层南面明间**：六扇 **隔扇门**，每扇净宽 0.60、高 2.80。
  上部格心占 0.55 高度比，**步步锦**棂格（横竖棂 0.03 见方）；中部绦环板 0.18；下部裙板。
- **一层南面两次间**：**槛窗**，窗台墙高 0.90，窗高 1.60，每次间 4 扇，格心同上。
- **二层南面**（挑空之上的外墙）：通长槛窗，窗台 +4.70，窗高 1.40 —— 晨光斜下的来源。
- **二层客房门**：单扇板门 0.80 × 1.95，朝走廊（南开），四扇一模一样。
- **李逍遥房东窗**：木格窗 **1.00（沿 y）× 1.00（高）**，步步锦，**洞口中心 y = 11.25**，窗台 +4.70。
  y 必须落在 `y = 10.50` 与 `y = 12.00` 两根柱之间——首版取 y = 10.60，柱子正立在窗当中。
  **这是一个真开洞**（Boolean 穿透山墙），不是贴在墙上的窗框：剧本要的「晨光一道一道切在地板上」
  没有真洞就打不出来。

### 6b. 穿枋标高（避窗）

一层三道：`1.35 / 2.55 / 3.60`；二层两道：**`4.35 / 6.15`**。
二层两道**必须避开窗洞带 `(4.70, 6.10)`**——首版取 `Z_FLOOR2 + 1.35 = 5.15`，
结果一根穿枋从东窗正中横穿而过。生成器 `assertions()` 已把这条钉死。

### 6c. 后堂隔断

中柱线 `y = 7.50` 两次间砌板壁（厚 0.04，通高至 +3.60），**明间留通道**——
李大娘「从后堂出来」「我去厨房备酒菜」走的就是这个口子。

  铺设范围 `x ∈ [−0.12, 10.62]`，`y ∈ [1.50, 7.50]`。依据 t00220。
- **二层楼面**：木楼板，板宽 0.22、厚 0.04，沿 **x 向** 通铺（走廊方向即板缝方向）。
- **山墙（东、西）**：粉墙，厚 0.24，自 ±0.000 砌至各处屋面下皮（随举折折线收顶）。
