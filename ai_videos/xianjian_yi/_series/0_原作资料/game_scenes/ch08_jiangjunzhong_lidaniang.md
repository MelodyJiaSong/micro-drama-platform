# ch08 · 白河村与将军冢 · 灵儿的身孕、鬼将军、赤鬼王

> 流程位置：林家堡后院走散 → 隐龙窟（逍遥月如寻人）→ **白河村·韩医仙医馆（灵儿获救·诊出身孕·不愿相见）** → 采药配丹 → 白河桥岔路 → 玉佛寺（玉佛珠）→ 黑水镇 → **将军冢（鬼将军·空棺）** → **血池（赤鬼王·土灵珠·引路蜂）** → 回白河村（村长被绑·韩梦慈被黑苗人掳为人质）→ 钩出鬼阴山
> 版本口径：1995 DOS 原版为主线；98 柔情版差异以「98版差异：」行内标注；2001《新仙剑》属另一版本，仅在明确标注处引用（该版把这一段命名为「第三章 白河寒秋」）。

> **范围校正提示（详见文末「六」）**：派工单原写的「李大娘之死与客栈被毁」「拜月教爪牙追杀到盛渔村」经考证**不成立**（李大娘在原作中并未死亡）；「逍遥记忆逐步苏醒」发生在**远在其后的锁妖塔**，不属本章。但派工单点到的「**灵儿有孕**」**确实属于本章**——它正是白河村段落的剧情核心，本文据此把章界重划为「白河村 + 将军冢」。

## 二、场景志

### 场景 1 ｜ 隐龙窟出洞：救错了人的救援

**场景描写**
隐龙窟是一处蛇妖巢穴：大厅居中，右手边是金库区，深处一道石门锁着被掳来的女子。窟内是典型的妖穴质地——潮、暗、闭塞，人质被关在石门之后。出洞之后，画面第一次转亮，眼前就是白河村。

**人物出场描写**
- **李逍遥／林月如**：这一段两人是纯粹的「寻人者」。他们冲进这个洞的唯一理由，是以为灵儿在里面。
- **蛇妖男／蛇妖女**：窟内两只主事的妖。蛇妖女的座位底下压着开石门的钥匙——原作把「钥匙在压迫者屁股底下」这件事做成了实体机关。
- **被掳女子群像**：石门后关着一屋子女人（贴吧记述为「进去后发现里面全是女人」）。她们能一个个被对话、被救走。

**对白实录（详实转述）**
救人段的对白都是短促的：先与蛇妖女交谈、再动手；石门开后逐一与被囚女子说话，把人放走。整段最重要的信息其实是**「没说出来的那句」**——救出这么多人，里面**偏偏没有灵儿**。逍遥与月如打空了一趟。
（存疑：本段来源为攻略叙述，未见逐句台词记录。）

**事件逐拍**
1. 逍遥、月如为寻灵儿误入隐龙窟。
2. 击败蛇妖男 → 深入。
3. 与蛇妖女对话后击杀 → 从其座下取得钥匙。
4. 开石门 → 逐个救出被掳女子。
5. 出洞 → 抵达白河村。

**转折/伏笔**
这场戏的功能是**制造错位**：观众（玩家）以为救人的高潮在洞里，其实灵儿早在洞外的林子里被另一个人救走了。下一场的情绪冲击，全靠这一场的落空来蓄。

**视觉扩写（创作用，非原作实录）**
石门推开、一屋子女子的脸依次转向火把——逍遥举着火把一张张看过去，最后一张也不是。这一记「找脸」的横移镜头是本章第一个泪点位。

### 场景 2 ｜ 白河村外·林子：采药的姑娘拾到一个人

**场景描写**
白河村外的林子。这是一个从头到尾**没有反派**的场景，也是本章唯一一处纯粹的善意。地物很简单：树、草药、林间小路，路的一头通村。（存疑：来源仅记「外出采药时，发现昏倒在村外林子里的赵灵儿，将她带回医馆」，林相、时辰未考证到。）

**人物出场描写**
- **韩梦慈**：白河村村长韩医仙的亲生女儿，**略通医术，温柔善良**，与江家大公子**江少云自幼订有婚约**。她的出场方式就是她的性格：一个人挎着药篓进林子，弯腰、抬头、看见地上躺着个人——不问来历，先救。
- **赵灵儿**：本章开场时的她是「一个昏倒在地的陌生女子」。观众知道她是谁，救她的人不知道。这个信息差是这场戏的全部张力。

**对白实录（详实转述）**
可考的记录里这一场没有对白——因为地上的人昏着，救人的人只有动作。韩梦慈这一趟的「台词」是把药篓放下、把人背回村。
（存疑：未考证到本场任何台词记录，切勿脑补为实录。）

**事件逐拍**
1. 韩梦慈出村采药。
2. 在林中发现昏倒的赵灵儿。
3. 将其带回村中医馆救治。

**转折/伏笔**
① 韩梦慈救下灵儿这一举动，是她后来**被黑苗人抓去当人质**的远因——她救了那个黑苗人正在找的人。全章的因果在这一拍就闭环了：救人者最终因所救之人而受难。
② 也正因为她救的是灵儿，后段「以梦慈换灵儿」的要挟才格外锋利。

**视觉扩写（创作用，非原作实录）**
药篓落地、草药撒了一地；镜头不给脸，只给两只手——一只失去意识地摊在腐叶上，一只伸过去探鼻息。

### 场景 3 ｜ 白河村·韩医仙医馆：一个被瞒下来的诊断

**场景描写**
医馆兼村长家，是白河村最重要的一间屋子，本章前后三次回到这里（诊治 → 求助 → 案发）。屋内该有的都有：药柜、药炉、诊案、内间一张病榻。这里也是白河村的公共中枢——村里被僵尸咬伤的人都往这里送，韩医仙救得过来一时，救不了根。

**人物出场描写**
- **韩医仙**：白河村村长兼大夫，资料称其为**「仁心仁术的大夫」**。他这个人物在本章的塑造是靠两件事完成的：一是明知村里的僵尸之患自己**「竭尽心力，只能治标，不能治本」**，仍旧一个个救；二是诊出灵儿身孕之后，**为尊重灵儿的意愿，对李逍遥与林月如把这件事瞒了下来**。
- **赵灵儿**：昏卧在内间榻上。她在本章的大半时间里是「不能说话」和「不愿说话」的叠加态。
- **韩梦慈**：在医馆里帮着照料。

**对白实录（详实转述）**
这一场的对白是全章分量最重的一组，而它的重量恰恰在于**说出来的比想说的少**。韩医仙搭过脉之后，把诊断结果告诉了灵儿本人：她**怀了身孕**。灵儿的回应不是喜、不是慌，而是**请他不要说出去**——这一请求本身就说明她清楚地知道，孩子的父亲此刻并不记得她。韩医仙没有追问原委，也没有拿医者的立场去劝，他只是应下来，然后照着一个孕妇该受的照料去安排药与静养。
（存疑：来源为角色词条叙述「韩医仙診斷出靈兒懷有身孕，為尊重她的意願，向李逍遙和林月如隱瞞此事」，未见逐句台词原文；上文为按此事实链所作的转述，其中「孩子的父亲不记得她」一句系与「忘忧散失忆」设定的合并推论，非原作明写。）

**事件逐拍**
1. 灵儿被抬进医馆，安置于内间病榻。
2. 韩医仙诊脉 → 确认有孕。
3. 灵儿表达不愿声张之意。
4. 韩医仙答应隐瞒，转为安胎调养的思路开方。

**转折/伏笔**
这是全章的**情感总开关**。此后每一场戏——逍遥来找妻子、月如替情敌跑腿采药、三人一起下将军冢——都在这个「有一件事只有三个人知道，而最该知道的那个人不知道」的信息差上运转。它也解释了灵儿为什么在下一场里不肯见人。

**视觉扩写（创作用，非原作实录）**
搭脉的手指停住的那一瞬间，药炉的水正好开了——用一声水响代替诊断结果的台词。老大夫抬眼看向病人，病人先摇了头。

### 场景 4 ｜ 医馆内间：不愿相见

**场景描写**
同一间医馆，一道门帘之隔。门外是刚从隐龙窟一身血污赶来的逍遥与月如，门内是醒着却背过身去的灵儿。原作在这里用的是最省的调度——**一道帘子、一张榻、两拨人**，把整段感情戏的空间关系说尽了。

**人物出场描写**
- **李逍遥**：这一路他是把整座隐龙窟翻遍了才找到这儿的人。他此刻的问题不在于找不到，而在于**找到了也认不全**——「忘忧散」抹掉的是仙灵岛的那一段（见「六」），他心里的这个人和她心里的那个人，不是同一份记忆。
- **林月如**：她跟着来。她的位置在这一场里最微妙：她是来陪着一个男人找他的妻子的。
- **赵灵儿**：昏迷在床、**不愿见他们**。这不是耍性子——她刚被告知自己怀了身孕，而这件事她连告诉孩子父亲的立场都还没有。

**对白实录（详实转述）**
这一场的往来非常简单，因此格外扎人：逍遥直奔内间要见人，被拦下；灵儿那边传出的意思是不见。逍遥不明白为什么——在他有限的记忆里，他没做过任何该被这样对待的事。月如什么都没多问，她只是站在他半步之后。这一场里没有争吵、没有解释，只有一道帘子两边各自的沉默。
（存疑：来源记为「李逍遙為尋妻子，同林月如來到醫館，發現昏迷在床、不願見他們的靈兒」，无逐句台词；灵儿拒见的具体理由，各资料表述不一——一说与身孕有关，一说与她知晓自己女娲后裔的身世、决意担起使命有关。两说并存，均未见原作明文，勿写死。）

**事件逐拍**
1. 逍遥、月如自隐龙窟赶到白河村医馆。
2. 得知灵儿在此。
3. 求见 → 灵儿不愿相见。
4. 三人同处一屋而不相见的僵局，直到药成灵儿醒转才化开。

**转折/伏笔**
本章、乃至《仙剑》全篇最锋利的一处「近在咫尺却隔着一整个真相」。它同时把三条线拧到一起：逍遥的失忆、灵儿的身孕与身世、月如的自处。

**视觉扩写（创作用，非原作实录）**
帘子是唯一的运动元素：风一动，帘缝里露出榻上背对着的一角衣袖，随即又合上。逍遥的手抬到一半没有掀。

### 场景 5 ｜ 采药三事：树上、林间、桥头

**场景描写**
三个采药点把白河村的地理跑通了一遍：**医馆／村长家后院**的银杏树；**村外山路**——路边先能拾到一具废弃的「逋兽夹」，山道上有鹿的固定出没路线；**村口木桥**——溪水从桥下过，是全村最开阔的水面。

**人物出场描写**
- **李逍遥**：本章唯一一段少年气外放的戏。上树、下夹、赶鹿、蹲桥头钓鱼，四个动作一件比一件不像救命的大事，全靠手脚的利落把「急」演出来。他此刻还不知道自己在为一个孕妇采药。
- **林月如**：她领走的是人参、雪莲子、何首乌三味贵重药——凭林家堡的门路。这是她第一次为灵儿奔走，也是她与逍遥关系从「争」转「共」的分水岭。
- **鹿**：调度最完整的非人角色。它走固定路线，须先把夹子摆在必经处，再从后方驱赶它上夹。

**对白实录（详实转述）**
本段只有三次功能性交谈：向村民**借鱼杆**；向村人**打听鹿的去处**；以及回医馆**交付药材**。信息全在动作里。熬药小童报出的六味是：**人参、雪莲子、何首乌、银杏子、鹿茸、鲤鱼**，一味不可缺；分工是逍遥取后三味（要跑腿、要动手、要下水的），月如取前三味。谁都没把「一个救妻子、一个救情敌」这层说破。
（存疑：攻略仅记录药名与分工事实，未见逐句台词。）

**事件逐拍**
1. 熬药小童报出六味药材 → 二人分工。
2. 后院上树 → 摘银杏子。
3. 村外拾逋兽夹 → 判断鹿的路线 → 布夹 → 绕后驱赶 → 鹿踩夹 → 取鹿茸。
4. 向村民借鱼杆 → 村口木桥垂钓 → 得鲤鱼。
5. 月如同时段取回人参、雪莲子、何首乌（并行线，原作未演出）。

**转折/伏笔**
这是本章唯一的「无怪物段落」，功能是给将要开始的地宫下坠段做情绪落差：先把乡野光线、生活质感、少年气给足，后面的血池才砸得下来。

**视觉扩写（创作用，非原作实录）**
三段可剪成同节奏三拍：抓树枝的手／压铁夹的手／握钓竿的手——同一双手，三种质地（叶、铁、水）。第四拍切回医馆药炉，同一双手把药包放上诊案。

### 场景 6 ｜ 医馆：药成，灵儿醒转

**场景描写**
与场景 3、4 严格同机位的第三次使用，只换两个变量：药炉上多了一炉炼好的丹，榻上的人睁开了眼。

**人物出场描写**
- **赵灵儿**：从「静物」变回「人物」。她醒来后的第一反应不是问自己怎么了。
- **熬药小童**：交出成药，完成功能。
- **逍遥／月如**：分头归来、同时在场。这一拍是三人组的正式编成。

**对白实录（详实转述）**
药成、服下、醒转。攻略把这味药记作**「六神丹」**；而 DOS 版实况把这一整段任务直接叫作**「为灵儿寻找安胎药」**——两个名字指向同一件事，也等于从旁佐证了韩医仙那个被瞒下来的诊断：这六味药本就是往「安胎」上开的，只是取药的两个人不知道。
（存疑：「六神丹」出自图文攻略，「安胎药」出自 DOS 版实况标题，二者是否为同一物，未见权威口径统一，故并列不合并。）

**事件逐拍**
1. 六味药材凑齐 → 交熬药小童。
2. 炼成丹药 → 灵儿服下。
3. 灵儿苏醒 → 队伍完整、可以再上路。

**转折/伏笔**
逍遥、灵儿、月如三人同行的格局在此定下，一直延续到鬼阴山、苗疆、南诏。

### 场景 7 ｜ 医馆：治标与治本

**场景描写**
医馆外堂。白河村此刻不是安全区——村里已经有人被僵尸咬伤，恐惧是这一场的底色。原作把灾情放在灵儿刚醒的下一拍，不给主角一秒喘息。

**人物出场描写**
- **韩医仙**：第二次以「求助者」的姿态出场（第三次是被绑）。他讲的核心是一个医生的挫败：**治标不治本**。
- **韩梦慈**：她在这一段里不只是照料伤员的女儿——资料明确记她**认定「解决尸妖之乱才是根本」**，并**与李逍遥、林月如等人协力对抗这场危机**。她不是被动的受害者，她是这条支线的推动者之一。
- **三人组**：刚把自家的命救回来，转头接下别人的命。

**对白实录（详实转述）**
韩医仙说的是三层：一、**黑水镇的尸妖已经闹到白河村**，村民被僵尸咬伤；二、他这个大夫**只能压症状，压不住源头**，再拖下去村子保不住；三、**玉佛寺的方丈有法力**，请三位替村子跑一趟，求方丈出手收服僵尸。韩梦慈补的是最关键的一句判断：救伤员救不完，**根子不除，白河村就一直是这样**。逍遥应得干脆，理由也朴素——刚受了村里的救命之恩，不能不还。灵儿听到「尸妖」二字时的反应比两人都重：以人命炼功的邪法，是她这个女娲后人本能排斥的东西；这份排斥在玉佛寺战后由智泽揭出真相时被彻底点着。
（存疑：来源为攻略叙述与角色词条，未见逐句台词；灵儿的反应属人物逻辑推演，非原作明写。）

**事件逐拍**
1. 韩医仙陈情：尸妖为祸、村民中尸毒、医术只能治标。
2. 韩梦慈定调：除尸妖才是治本。
3. 指路：玉佛寺方丈可解。
4. 三人受托出村。

**转折/伏笔**
本章从「私事」转「公事」的换轨点。同时埋下最重要的一条误导线——**村长把三人指向玉佛寺**，而真正的祸根在将军冢底；玉佛寺只是拿「钥匙」的地方。

### 场景 8 ｜ 白河桥·守桥壮丁：左玉佛寺，右鬼阴山

**场景描写**
出医馆往左走，先过一名守桥壮丁，再过桥。桥这头是白河村，桥那头是一个明确的 **Y 字岔路**：左通玉佛寺，右通鬼阴山。这是全章最重要的地理节点——它把本章（玉佛寺—将军冢）与下一章（鬼阴山—鬼阴坛）摆进了同一个画面。

**人物出场描写**
- **守桥壮丁**：路标型 NPC，一句话的功能。他的存在本身也是情报：白河村已经戒备到桥要人守。

**对白实录（详实转述）**
壮丁把两条路一次说清：左边玉佛寺，右边鬼阴山；此刻该走左边。三人（与玩家）在这里得到的信息是「右边有个叫鬼阴山的地方」，却没有理由去。这个「知道但不去」的悬置，正是本章末尾韩梦慈被掳时能瞬间起效的原因。
（存疑：来源记「过守卫和桥梁后，左边是玉佛寺，右边是鬼阴山，优先选择左边」，无逐句台词。）

**事件逐拍**
1. 出医馆 → 向左 → 遇守桥壮丁。
2. 得知左右两路。
3. 三人取左路。

**转折/伏笔**
标准的「枪挂在墙上」：鬼阴山在这一场被指名道姓挂出来，直到场景 16 才被取下。

**视觉扩写（创作用，非原作实录）**
过桥时给一记回望——白河村的炊烟还在，而前方两条路都通向不是人待的地方。

### 场景 9–10 ｜ 玉佛寺：一场毫无道理的剃度，与满寺乱斗

**场景描写**
玉佛寺是本章的「假目的地」：山门、庭院、佛殿三段式。院里僧众走动，殿内大佛坐镇——**这尊大佛不是布景，方丈稍后会拿它砸人**，是原作埋在场景里最漂亮的一个道具伏笔。攻略特别提示：**寺内可搜的物品必须在与智修大师交谈之前拿完**，一旦触发对话就进连场战斗，回不去了。这条机制反过来说明了空间结构：自由探索区与触发即锁死的战斗区是分开的。

**人物出场描写**
- **小和尚智泽**：三人在寺内先遇上的是他。小、稚气、话多。
- **老方丈智修大师**：随后追来的老僧，一身住持威仪，出手却毫无出家人的样子。
- **真身**：多方资料一致——这一老一小是**同一个存在**。它的本体是**玉佛珠**（相传为达摩祖师所持之物），日夜受佛法薰陶、修行已九百九十九年，化人形落入人间，可作「老住持智修」与「小和尚智泽」两副面孔；后来赵灵儿给它取名「**小石头**」，它便以真身玉佛珠的形态跟在灵儿身边，最终经灵儿点破迷津而顿悟。（经搜索摘要间接引用：百度百科／搜狗百科「小石头」词条。palweb 图文攻略另记作「源自摩呢世家的佛珠」，与百科系说法有出入，见「四」。）

**对白实录（详实转述）**
这一场的张力全在「无理」二字：三人是来求方丈出手除僵尸的，智修大师**答应了**——但开的价码是**要李逍遥留在这里当和尚**，当场剃度。不解释、不商量。逍遥当然不干（他此行是替全村求人，村里还有个刚醒的孕妇），一口回绝；方丈却不由分说，直接动手落刀。于是求助变成打架：先是智泽这一路和尚上来，接着满寺僧众群起，最后三人退到门口，被方丈亲自拦下决战。
战后真相才由智泽说破，这几句是本章的**剧情枢纽**——他告诉灵儿：黑水镇那些尸妖不是天灾，是**赤鬼王**为修炼「**血魔神功**」而驱使的；而这一老一小两副皮相，本就是同一件法器所化。剃度之闹在这里被追认为一场试炼：他要看的是这三个人配不配拿走那颗珠子。
（存疑：来源记录了「智修大師答應其請求，卻要求李逍遙在這裡做和尚為代價」「方丈无故欲为逍遥剃度、逍遥拒绝、方丈强行剃度引发战斗」「智泽告诉灵儿黑水镇尸妖是赤鬼王为练血魔神功所操纵」等事实链与关键名词，未见逐句台词原文。不同攻略把首战对手写作「智泽等人」或「智杖和尚」，命名有出入。）

**事件逐拍**
1. 入寺 → 搜完寺内物品（机制：须在触发剧情前完成）。
2. 遇小和尚智泽 → 老方丈智修追至。
3. 三人陈情求助 → 方丈应允，索价「留下当和尚」 → 逍遥拒绝 → 方丈强行剃度。
4. **第一战**：智泽一路（攻略建议以天师符法、炎咒、一阳指集火秒掉一个）。
5. **第二战**：满寺和尚群起。
6. **第三战**：门口被方丈拦下决战——方丈以大佛砸人，伤害高，须及时补血；建议灵儿会旋风咒（群攻）、月如会铜钱镖（单体高伤）。
7. 战罢真相揭晓：一老一小同为一体，真身即玉佛珠；黑水镇尸妖出自赤鬼王之手。
8. 得**玉佛珠**——灵儿佩戴后灵力大增，**且是进入将军冢的必备条件**；逍遥另可得罗汉袍。

**转折/伏笔**
① 本章的反派在这一场才第一次被命名：**赤鬼王**。此前三人只知有僵尸，不知有主使。
② 玉佛珠既是战力升级，也是**门票**——原作用一件装备同时完成「变强」与「解锁」，是全章最紧的一处结构设计。
③ 佛门法器对付以人血练功的邪法——这组「佛 vs 血」的对立，是血池段落全部视觉设计的依据。

**视觉扩写（创作用，非原作实录）**
剃刀落下前的静止一拍：刀锋、香火、佛脸、光头四样同框；下一拍佛像的影子先动——大佛比人先出手。

### 场景 11 ｜ 黑水镇：尸妖之镇

**场景描写**
黑水镇是白河村与将军冢之间的过渡区。它的功能不是解谜，是**举证**——前面韩医仙口中的「尸妖猖獗」，到这里变成三人亲眼所见。（存疑：多方攻略仅将黑水镇记为「连接白河村与将军冢的过渡区域／继续前进到达将军冢入口」，未见 95 版对镇内街巷、居民状态的具体文字描述。另有资料把黑水镇内标为「乱葬岗」、将军冢标为三层，但那出自后出的《仙剑奇侠传：新的开始》，**不属 95 原版**，本文不采。）

**事件逐拍**
1. 三人自白河村推进至黑水镇。
2. 穿镇而过，抵达将军冢入口。

**转折/伏笔**
地名本身就是设计：白河 → 黑水。从「白」走到「黑」，从人间走进冢里，颜色先于剧情完成了叙事。

**视觉扩写（创作用，非原作实录）**
镇口一块半塌的界碑；街上没有活人走动的声音，只有风。三人过街时一句台词不给——上一场还在寺里打闹，情绪落差全靠留白。

### 场景 12–14 ｜ 将军冢：踏板、岔路、两具石棺

**场景描写**
将军冢是本章的核心迷宫，也是全作公认难走、氛围最压人的关卡之一——考据文章把它列为《仙剑 1》最让玩家发怵的地图，说它单靠氛围与迷宫复杂度就足以劝退玩家重玩。结构上它是**上下双层**：下冢之后先遇到**前后两个向下的坑**，攻略通称前坑「**甲坑**」、后坑「**乙坑**」；甲坑里有一只 25000 经验的宝箱，而**入乙坑之后才是迷宫的正式开始**——乙坑下去先是一个岔路口，走下方那条可拿到 9000 经验的箱子，并在那里**撞上第一个鬼将军**（措辞暗示鬼将军不止一个）。内部大量岔路配合**踏板机关**，最折磨人的体验被攻略原话记成一句——「好几次我们都看到将军的棺材了，就是走不过去」：目标一直在视野里，路却一直不通。另一篇考据说得更狠：这张图**无论从左往右还是从右往左都绕不出去，全图正确路线只有一条**。这两句就是将军冢最准确的场景描写：**看得见、走不到；路只有一条，而你不知道是哪条。**
终点是石棺厅。厅中**并排两具石棺**：一具里躺着鬼将军，**另一具是空的**——多数玩家还是先摸到那具空棺，再苦苦去找真正的 BOSS 棺。这具空棺至今没有官方解释，被玩家社群称作《仙剑 1》最大的谜团之一。**流传最广的一种玩家考据**是：赤鬼王的血魔神功当时尚未大成，早先一次尸兵复活并不成功，那具棺中的将军挣脱控制、逃走不知所踪；第二具棺里的将军复活成功，被役为守冢者——所以一具空、一具有鬼将军。（**此为玩家推测，非官方设定**。）
（存疑：有攻略写「将军冢入口在黑水镇右上角，砍开草丛进入」，但该条出自《新仙剑奇侠传》系资料，95 DOS 版的入口画面细节未考证到，勿写死。）

**人物出场描写**
- **鬼将军**：将军冢的守关 BOSS、冢的主人。身份是「将军」，形态是「鬼」——按赤鬼王词条的设定，他是被赤鬼王**驱使去控制僵尸**的那一环，即黑水镇尸潮的直接执行者。（存疑：95 版对鬼将军外形的官方文字描述未考证到，勿臆造形貌。）
- **三人组**：本章体力消耗最大的一段。攻略反复提醒在将军冢一带**务必收齐化尸水、赎魂灯、孟婆汤**——这三样道具名本身就是场景氛围的一部分。

**对白实录（详实转述）**
将军冢段落几乎无对白：全部信息由空间与机关传达。唯一的「发言」是棺盖开启的那一刻——墓主苏醒、直接发难，不问来意、不通姓名。
（存疑：未考证到本段的具体台词记录。）

**事件逐拍**
1. 自黑水镇进入将军冢（需灵儿已佩玉佛珠）。
2. 下冢 → 面对甲坑、乙坑两个下行口 → 甲坑取箱 → 入乙坑，迷宫正式开始。
3. 乙坑岔路取下路 → 遇第一个鬼将军。
4. 踩踏板、绕岔路，数次望见石棺而不得近前。
5. 抵石棺厅：两具石棺，一空一实。
6. 走到「将军」的棺前 → **墓主苏醒，突然攻击** → 鬼将军战。
7. 击败鬼将军 → **地板坍塌** → 三人一同坠入下层洞窟。

**转折/伏笔**
① 打赢却掉下去——原作在这里把「胜利」直接变成「更深的陷落」，是本章情绪曲线的最低点起点。
② 空棺不解释、不回收，成为全作最著名的开放性留白。
③ 结构上鬼将军是「果」、赤鬼王是「因」：打完执行者才见主谋，两段式 BOSS 设计。

**视觉扩写（创作用，非原作实录）**
棺盖推开时先出的是灰，不是人；两具石棺一开一闭并置于同一构图（一具敞着黑口，一具永远合着）是本章最强静帧。坠落一拍不给尖叫，只给无声失重与火把翻转。

---

### 场景 15–16 ｜ 血池：赤鬼王的练功场

**场景描写**
坠落之后，眼前是本章、也是全作最直白的一处恶意景观：**周围血流成河**——这里正是赤鬼王修炼血魔神功的据点「**血池**」，位于黑水镇将军冢的底部。行进规则与上层不同：**从右下角起步，必须踩踏机关才能通过**特定区域；池中有一只**红色的浮空妖物，免疫法术，只能靠普攻打掉**。终点是一处**漩涡**，赤鬼王在那里。

**人物出场描写**
- **赤鬼王**：本章的终点。设定上他**本为人类**——为了修炼魔法，他驱使鬼将军控制僵尸、吸取人血，最终在血池之中变成**半人半魔**的存在。这一层「他曾经是人」的身份，是他与寻常妖魔最大的分别，也是本章主题（以人命换法力）的落点。（经搜索摘要间接引用：百度百科「赤鬼王」「血池」词条。95 版对其外形的官方文字描述未考证到——「赤」「鬼王」二字与血池底色是可靠的视觉依据，更细的形貌请勿臆造。）
- **三人组**：战力被逼到上限。攻略给出的战前准备很能说明这一战的规格——逍遥要学**万剑诀**、灵儿要学**五雷咒**（另荐**旋风咒**群攻）、月如要有**铜钱镖**（单发耗 500 铜钱、伤害高），并备足**还魂灯／赎魂灯**；灵儿的**五气朝元**回复在这一战最吃重。赤鬼王**带秒杀技**。
- **隐性的第四个人**：灵儿此刻是**孕身**下到血池底的。这一层信息全场只有她自己知道——本章所有的战斗压力，都要按这个前提重新掂一遍分量。

**对白实录（详实转述）**
可考的对白记录极少。本段的「说话」主要由场景完成：血池本身就是供词——它说明黑水镇死了多少人、村民为什么会被咬、鬼将军为谁办事。
（存疑：赤鬼王与三人交手前后的具体台词未考证到，请勿脑补为实录。）

**事件逐拍**
1. 三人坠入下层，看清此处是血池。
2. 自右下角起步，踩机关开路。
3. 遭遇免疫法术的红色浮空妖物 → 只能普攻解决。
4. 行至漩涡处 → **赤鬼王战**（对方带秒杀技，须以补给与高伤技能硬碰）。
5. 击败赤鬼王 → 得**土灵珠**与**引路蜂**。
6. 以引路蜂传送出迷宫（**用两次**回到黑水镇），再返白河村。

**转折/伏笔**
① **土灵珠**在这里入手——本章的实质战利品。它把「替一个村子除害」的地方性任务，接进了全剧的灵珠主线；到下一章它立刻转为「钥匙」：逍遥装上土灵珠，三人才能合体施「山神」破开鬼阴山口拦路的两名苗人。
② 赤鬼王「本是人类」的设定，与后文拜月教主那条「人以自身意志改写天地」的野心线遥相呼应：本章是那条线的**小型预演**。
③ 引路蜂既是脱身道具，也是原作对玩家的体恤——它承认将军冢确实难走。

**视觉扩写（创作用，非原作实录）**
血池的红压到近黑，只在漩涡口留一圈亮；三人踩过的踏板每落一块，红光就从缝里涌一次。赤鬼王现身用「先见血涌、后见人形」的顺序——他是从池子里长出来的，不是走进来的。

### 场景 17 ｜ 回白河村：以人换人

**场景描写**
回到医馆——本章第四次、也是最后一次用这间屋子。前三次它是救人的地方、是求人的地方、是隔着帘子不相见的地方；这一次它是案发现场：**韩医仙被绑着**。

**人物出场描写**
- **韩医仙**：第三次出场，也是与第一次最残酷的对照。上一次他是替全村求人的村长，这一次他是被捆在自己医馆里的人质家属。资料记他此时的角色是「**带话的人**」——黑苗人留他一条命，就是为了让他把条件说出去。
- **韩梦慈（不在场）**：全章最重的一次「缺席出场」。她救了灵儿，于是她被抓来换灵儿。
- **三人组**：刚从血池爬出来、刚拿到土灵珠，本以为事情已了。

**对白实录（详实转述）**
松绑之后，韩医仙说出的是本章最后一记重击，也是三条信息：一、**梦慈被鬼阴山的黑苗人抓走了**；二、抓她不是为了她——黑苗人要的是**赵灵儿**；三、对方让他**带话**：**拿灵儿去换梦慈**。到这里，场景 8 那句「右边是鬼阴山」终于被取下——玩家几小时前就知道有这么个地方，此刻才有了非去不可的理由。攻略把三人的反应记成一句判断：**事因灵儿而起，当然不能坐视不管**。灵儿本人的沉默在这一拍最响：她是被要的那个人，也是唯一知道自己身上还带着一条命的人。
（存疑：来源为攻略叙述「回来发现村长被绑，村长的女儿被鬼阴山的苗人抓去」与角色词条「將韓夢慈抓走，讓韓醫仙帶話讓趙靈兒換韓夢慈」，未见逐句台词原文。）

**事件逐拍**
1. 引路蜂传出将军冢 → 经黑水镇 → 回白河村医馆。
2. 见韩医仙被绑 → 解救。
3. 得知韩梦慈被黑苗人掳走，条件是以灵儿相换。
4. 三人转向鬼阴山。

**转折/伏笔**
本章以「解决了一祸、立刻撞上更大的一祸」收束：赤鬼王之死没有换来太平，只换来一道选择题。下一章三人杀入苗寨、在鬼阴坛对峙，**灵儿最终为保同伴选择随石长老离去**；李逍遥在鬼阴坛被打晕，**是赶来的韩医仙把他救醒的**——那个被他们救过一次的老大夫，反过来救了他，并陪他立下把灵儿寻回来的誓。这条「救与被救」的回环，是白河村这一整章真正的主题。

**视觉扩写（创作用，非原作实录）**
最后一帧回到那道帘子：这一次帘子后面的榻是空的。屋里三样东西还在原处——药炉、诊案、散在地上的绳头。

## 四、95 vs 98 差异

- **总体**：98 柔情版是 95 DOS 版的增强版本。本章的地点顺序（白河村→玉佛寺→黑水镇→将军冢→血池→赤鬼王→回白河村）与关键产出（玉佛珠、土灵珠、引路蜂）两版一致——现存攻略普遍把「玉佛寺与将军墓」放在同一份文档里同时覆盖 DOS 与 98 两版，未标注流程分歧。（经搜索摘要间接引用：百度文库 98 柔情版攻略条目。）
- **98版差异：** 柔情版在音乐、画面与部分战斗数值上有增补；赤鬼王一战的难度体感与建议配置在两版攻略中的写法略有出入。（存疑：具体数值差异未考证到，勿写死。）
- **命名与来源出入（属资料源差异，不是版本差异）**：玉佛寺一段，不同攻略把方丈写作「智修大师」，首战对手写作「智泽等人」或「智杖和尚」；palweb 图文攻略把玉佛珠的来历记作「**摩呢世家的佛珠**」，百科系则记作「**达摩佛祖所持的玉佛珠**」。引用时建议采用两方都成立的最小公约数：**一老一小同为一珠所化，此珠是佛门法器，修行已久**。
- **药名出入**：图文攻略记为「六神丹」，DOS 版实况把这段任务称作「为灵儿寻找安胎药」；两者是否同物未见统一口径，本文并列不合并。
- **2001《新仙剑》**：另有重制版本，画面与部分演出重做，把这一段命名为「**第三章 白河寒秋**」。不在本文口径内，仅作章名参考。

## 五、可用于 MV 的画面记忆点

1. **找脸**：隐龙窟石门推开，一屋子被囚女子的脸依次转向火把，逍遥一张张看过去——最后一张也不是她。
2. **药篓落地**：林中两只手的特写——一只失去意识摊在腐叶上，一只伸过去探鼻息。救人者不知道自己救的是谁。
3. **一声水响代替一句诊断**：老大夫搭脉的手指停住，药炉水开；他抬眼看病人，病人先摇了头。全章最大的秘密在这一帧里被封住。
4. **一道帘子**：风一动，帘缝里露出榻上背对着的一角衣袖，随即合上；逍遥的手抬到一半没有掀。
5. **一双手，三种质地**：抓树枝／压铁夹／握钓竿，三拍同节奏切；第四拍切回医馆，同一双手把药包放上诊案。
6. **大佛先动**：剃刀落下前的静止帧——刀锋、香火、佛脸同框；下一拍佛影先动，佛像比人先出手。
7. **看得见走不到**：将军冢里隔着断层与踏板遥望石棺的主观镜头，目标始终在画面正中却始终不能靠近。
8. **两具石棺**：一具敞着黑口、一具永远合着，并置同一构图——全作最著名的留白。
9. **无声坠落**：地板塌陷、火把翻转，三人在黑里失重，一声不出。
10. **血从池底长出人形**：近黑的红池、漩涡口一圈亮，先见血涌、后见赤鬼王现形。
11. **空掉的榻**：结尾回到那道帘子，帘后的榻是空的；屋里只剩药炉、诊案、散在地上的绳头。

## 六、范围校正说明（考证结论）

派工单给本章列的四项内容，考证后应作如下处置：

1. **「灵儿有孕」——确属本章，且应升格为本章的情感主线。** ✅
   韩梦慈外出采药时在村外林子里发现昏倒的赵灵儿，将她带回医馆；韩医仙诊出灵儿**怀有身孕**，并**为尊重灵儿的意愿，向李逍遥与林月如隐瞒了此事**；逍遥与月如寻妻至医馆，见到的是昏卧在床、**不愿见他们**的灵儿。DOS 版实况也把这段任务直接称作「为灵儿寻找安胎药」。（经搜索摘要间接引用：中文百科全书／百度百科「韩医仙」「韩梦慈」词条 + DOS 版实况标题。）**这条线是本章与将军冢地宫并列的另一半，不能省。**

2. **「逍遥记忆逐步苏醒」——不属本章，发生在远在其后的锁妖塔。** ❌
   - **失忆的起点**在余杭镇—仙灵岛那一段：李逍遥被黑衣人诓骗（谎称仙灵岛有瘴气），实则服下了「**忘忧散**」，因而忘掉了仙灵岛上的一切。（经搜索摘要间接引用：百度知道相关问答。）
   - **记忆恢复的地点是锁妖塔**——他在锁妖塔中突然恢复全部记忆，与灵儿的感情在此达到顶点，也正是这一转折间接导致了林月如之死。（经搜索摘要间接引用：搜狐《〈仙剑1〉李逍遥为什么偏偏在锁妖塔恢复记忆》。）锁妖塔在本章之后还隔着鬼阴山→苗疆→南诏一线，**绝不可写进将军冢章**。
   - 不过：**失忆状态本身在本章是「在场」的**——它正是灵儿不愿相见、韩医仙代为隐瞒之所以成立的前提。本章要演的是「失忆的后果」，不是「记忆的苏醒」。

3. **「李大娘之死与客栈被毁」——查无实据，应删。** ❌
   多个角色词条一致记载：赵灵儿牺牲之后，**李大娘把客栈交给张四与丁香兰夫妇，自己搬到仙灵岛去照顾李忆如**——也就是说她活过了全剧结局。（经搜索摘要间接引用：百度百科「李大娘」词条。）另注：李大娘是逍遥的**婶婶**，不是母亲；她的病是逍遥当初上仙灵岛求药的动机；95 DOS 版开场地为**余杭客栈**，逍遥在店里当店小二（由 palweb 图文攻略第 1 页直接佐证）。「李大娘之死／客栈被毁」疑为与影视改编或其他作品串线，**不可写入 95 原版实录**。

4. **「拜月教爪牙追杀到盛渔村」——地名成立，但与本章无流程关联。** ⚠️
   盛渔村确为《仙剑奇侠传》中的实有地名（资料记为李逍遥、王小虎的故乡）。（经搜索摘要间接引用：百度百科「盛渔村」词条。存疑：它在 95 DOS 版流程中的具体位置与所属章节未考证到；与之矛盾的是 95 版开场明确在余杭客栈。建议单独考证后再定归属，**本章不收**。）

5. **本章的正确名称与范围建议**
   - 章题宜改为 **「ch08 · 白河村与将军冢 · 灵儿的身孕·鬼将军·赤鬼王·土灵珠」**。
   - 范围：**隐龙窟出洞 → 白河村（韩梦慈拾人／韩医仙诊出身孕并隐瞒／灵儿不愿相见／采药配丹／灵儿醒）→ 白河桥岔路 → 玉佛寺（玉佛珠）→ 黑水镇 → 将军冢（鬼将军·空棺）→ 血池（赤鬼王·土灵珠·引路蜂）→ 回白河村（韩医仙被绑·韩梦慈被掳·以人换人）**。
   - 「解白河村之祸」的准确说法是**解黑水镇尸妖之祸**——尸妖源出黑水镇将军冢底的赤鬼王，白河村是被波及的一方（村民被咬伤，韩医仙只能治标）。
   - 下一章（ch09）应为 **鬼阴山 → 鬼阴坛 → 石长老**：逍遥装土灵珠、三人合体施「山神」破苗人拦路；杀入苗寨；鬼阴坛对峙，灵儿为保同伴随石长老离去；逍遥被打晕，韩医仙赶来救醒他并誓言寻回灵儿。
   - 另建议单独派两章：**（余杭镇·仙灵岛·成亲·忘忧散失忆线）** 与 **（锁妖塔·记忆复苏·月如之死）**——派工单里被错放进本章的两项，正确的家在那里。
