# ch13 · 锁妖塔 · 月如之死

> **流程位置**：本章在 1995 DOS 原版《仙剑奇侠传》的真实流程中位于**「黑水镇 / 山间野店之变 → 蜀山」之后、「大理 → 苗疆南诏 → 拜月教总坛」之前**。维基百科给出的地点主序列为：余杭盛渔村 → 仙灵岛 → 苏州 → 隐龙窟 → 白河村 → 玉佛寺 → 黑水镇 → 扬州 → 长安 → **蜀山（含锁妖塔）** → 大理 → 南诏王宫。也就是说：**锁妖塔在苗疆主线之前**，赵灵儿此时已怀有身孕但尚未生产，李忆如出生在锁妖塔之后的南疆段落。
>
> **版本口径**：以 1995 DOS 原版为主线；98 柔情版差异用「98版差异：」行内标注。
>
> **⚠ 分工范围修正**：任务简报写「三人闯塔」（含阿奴）。经考证，**95 原版进塔的只有李逍遥、林月如两人**——维基百科明确写「李林二人决然进塔救人」，阿奴属于锁妖塔之后的大理／苗疆段落人物，不在本章队伍中。本文按「二人闯塔」实录，详见 § 五。

## 二、场景志

### 场景 1 ｜ 灵儿被擒 · 独孤剑圣的误判（本章之因）

**场景描写**（存疑：多方来源仅提及事件本身，具体镜位未考证到）
黑水镇一线的黑苗、白苗争夺赵灵儿，石长老自爆身亡，现场一片狼藉。蜀山仙剑派掌门**独孤剑圣**闻讯赶到，见妖气冲天、死伤狼藉，而现场唯一的「非人」是女娲后裔血脉的赵灵儿——他据此断定祸事为灵儿所为。

**人物出场描写**
- 独孤剑圣：蜀山仙剑派掌门，正道领袖形象（外貌细节未考证到确切文字描述，游戏中为道装长须剑仙一路）。
- 赵灵儿：此时已身怀有孕，体弱；女娲血脉在她自己也不能完全控制的情况下外显，反成「妖」的证据。

**对白实录**（存疑：具体台词未考证到逐句文本）
可确证的是这场对话的**性质**：独孤剑圣以「除妖卫道」的立场宣判，不听申辩；逍遥与月如的辩解在「正道公论」面前无效。灵儿被视作祸世妖类，判入锁妖塔镇压。

**事件逐拍**
1. 黑白苗之乱酿成人命 → 2. 独孤剑圣到场，把因果归到灵儿身上 → 3. 灵儿被擒、押入锁妖塔 → 4. 逍遥、月如被隔在门外，正道不许他们插手 → 5. 二人决意自己去救。

**转折/伏笔**
这一场把全剧最大的反讽种下：**当年把灵儿锁进塔的是蜀山正道，后来成为蜀山掌门的是灵儿的丈夫。**同时，「正道的误判」是月如之死的第一因——月如不是死于妖，是死于人的判断错误。

**视觉扩写（创作用，非原作实录）**
- 逆光下的剑阵封锁，逍遥被剑气逼退；月如横身挡在他与剑之间。
- 灵儿被带走时的一次回头，画面从她的视角糊掉。

### 场景 2 ｜ 蜀山山门 · 求情不成

**场景描写**
蜀山是云海之上的仙山门派：盘山石阶层层而上，巨石山门牌坊立于云雾之中，其后是宫观群落与镇守用的剑冢／剑阵；仙剑派弟子御剑往来。光线为云雾金边逆光、青松白石，仙气缭绕。主色：云白、松青、石灰白、道袍青。锁妖塔即蜀山所辖的镇妖之地。

**人物出场描写**
- 李逍遥：此时已非余杭镇小伙计，一身行旅装束，佩剑；神情从少年的跳脱转为压抑的执拗。
- 林月如：标志性红衣劲装、高马尾，佩剑（林家堡枪／剑／鞭皆通，游戏内多以剑呈现）。她在这一场里是**先开口的那一个**——性子急，受不了「讲道理讲不通」。

**对白实录**（以转述为主）
二人上山求情，把灵儿的来历、苗疆之乱的真凶一并说明；蜀山这一边的答复是立场性的、不可协商的——女娲后裔属妖类，锁妖塔是镇妖之所，放人等于毁誓。逍遥先讲理，讲不通；月如则直接顶撞，把「你们凭什么」摔在了掌门面前。结果是二人被逐出／被拒之门外，蜀山不允许人力干涉塔中之事。

**事件逐拍**
1. 二人登阶上山 → 2. 求见掌门／值守弟子 → 3. 陈情被驳 → 4. 月如激烈顶撞，气氛僵住 → 5. 二人退下山门，转身却不是回头路——他们去了塔。

**转折/伏笔**
月如在这场里第一次把自己完全押上：救的是「情敌」，出的力却比谁都足。这为她在塔底断后埋下性格依据——她不是临时起意的牺牲，她一路上都在做这个选择。

**视觉扩写（创作用，非原作实录）**
- 云海石阶的极大远景，两个小小的人影逆着下山的弟子往上走。
- 山门牌坊阴影里，月如把逍遥往前一推：「走。」（此为创作台词，非原作实录）

### 场景 3 ｜ 塔外 · 锁妖塔全貌

**场景描写**
锁妖塔是蜀山镇妖的宝塔，全作最具压迫感的建筑：塔身高耸，外缠青铜巨链，层层加锁；塔面贴有符咒封条，符纸在山风里翻动却不脱落。塔基坐落在蜀山所辖之地，四围是山岩与云气；塔中封着历代所擒的妖物，妖气自缝隙渗出，呈幽绿色。**光线／色调**：幽绿妖气 + 青铜冷光 + 符咒微芒；主色为幽绿、青铜、玄黑，与蜀山山门那一场的云白青松形成硬切对比。**声音氛围**：铁链低沉的摩擦声、塔内不知深浅的兽吼与呜咽，从石壁后面透出来。

**人物出场描写**
逍遥与月如立于塔前。塔身向上收束的透视把两人压得极小。月如的红衣在整片幽绿冷调里是唯一的暖色——这是本章的视觉主控关系：**红／绿的对立从进塔开始，到塔崩为止。**

**事件逐拍**
1. 二人抵塔 → 2. 确认塔门／封印所在 → 3. 破封或入门（具体开门方式未考证到确切机制，存疑）→ 4. 门在身后合上，外界光被切断，塔内只剩妖气的绿光。

**转折/伏笔**
「进去容易出来难」在此成立。塔的结构本身就是本章的倒计时装置。

**视觉扩写（创作用，非原作实录）**
- 仰角大全景：塔尖没入云中，青铜链在风里晃出一寸幅度。
- 门缝合拢的一线光被压成零。

### 场景 4 ｜ 塔内 · 万妖囚困的迷宫（逐层深入）

**场景描写**
塔内为**树状迷宫结构**——一条主路加若干岔路，岔路尽头多为宝箱（此结构判断来自关卡分析类资料，经搜索摘要间接引用）。玩家的行进方向是**自上而下**：从进入处往塔底走，越深越接近被镇之物。石壁上有封妖用的符咒与锁链，被囚的妖物或困在壁龛、或被链锁住，形貌各异；沿途还有蜀山弟子的亡魂（有资料提到亡魂授予七星剑一线，存疑：不同版本／不同攻略说法不一致，未考证到统一口径）。

（存疑：坊间攻略提到塔内层数、「镇狱明王」「五神龙」等具体敌名与「下右上下左，上左下右」的解谜口诀，出自二手 SEO 攻略文，与 95 原版是否对得上未能交叉验证，不作为实录采信。）

**人物出场描写**
- 两人一路且战且行。月如在前开路的比重更大——她是队伍里唯一的「练家子出身」，林家堡大小姐的武艺在这一段是实打实的输出。
- 逍遥则是急——他的每一次催促、每一次抢先，都是在替灵儿抢时间。

**对白实录**（以转述为主）
塔内的对话密度低，主要是**两种**：一是战斗中的短促招呼与提醒；二是月如式的嘴硬——她一路上并不掩饰「我为什么要来救她」的别扭，却一路走在最前面。这一段的潜台词是：**她说的话和她做的事是相反的，而观众都懂。**

**事件逐拍**
1. 沿主路下行，逐层清妖 → 2. 岔路取宝／补给 → 3. 遇机关阻断，破解后继续 → 4. 越往下妖气越浓、结构越封闭 → 5. 抵达塔底那一层。

**转折/伏笔**
塔是「妖的监狱」，而灵儿被关在最底层——把女娲后裔和万妖关在一起，是全剧对「妖」这个字最残酷的一次定性。

**视觉扩写（创作用，非原作实录）**
- 一条被链住的巨妖在两人经过时缓缓抬眼，链子拉直又松开。
- 幽绿气流沿石阶往下淌，像水一样指向塔底。

### 场景 5 ｜ 塔底 · 镇妖柱与救出灵儿

**场景描写**
塔底是全塔的核心：中央立着**镇妖／盘龙巨柱**（多处资料称「七星盘龙柱」，蟠龙缠柱、柱上有星点光位；「七星」名目与柱纹细节属二手攻略说法，存疑）。这根柱子同时是**镇妖的法器**和**塔体的支撑结构**——这一点是本章全部悲剧的机关所在。柱周有符阵光纹，妖气在此最浓。空间是环形的、向上望不到顶的深井感。

**人物出场描写**
- 赵灵儿：被缚／被镇于柱上，重伤垂危。此处有资料提到她现出蛇身（人首蛇身的女娲原形）——在被镇压、失去控制力的状态下真身外显（经搜索摘要间接引用，属关卡分析类资料）。
- 逍遥见到她的一瞬间是全章的情绪拐点：从「闯塔」变成「必须马上带她走」。
- 月如站在稍后一步的位置——这个站位本身就是她在这段三角关系里的位置。

**对白实录**（以转述为主）
三人在柱下的交流极短，因为时间不允许：确认灵儿还活着、确认柱子是唯一的解法、确认毁柱意味着什么。**关键在于「毁柱＝塔塌」这个信息是当场就知道的**——维基百科的表述是「为逃离塔毁，众人毁坏支撑柱」，即毁柱与塔毁是同一个决定的两面。他们是**明知会塌而砸的**。这一点决定了后面月如的死不是意外事故，而是三个人一起按下按钮后的代价。

**事件逐拍**
1. 抵达柱下，看见被镇的灵儿 → 2. 判断只能毁柱 → 3. 合力击破镇妖柱 → 4. 灵儿脱困、被扶起（重伤，走不快）→ 5. 柱裂的同时，塔体开始从上往下裂 → 6. 三人转身往回跑。

**转折/伏笔**
「救人的动作本身就是毁塔的动作」——这是全剧结构上最漂亮也最狠的一个设计：**善意与灾难同一个来源**。它预演了结局：灵儿救苍生的方式也是毁掉自己。

**视觉扩写（创作用，非原作实录）**
- 柱裂的第一道缝从星点位置炸开，光纹熄灭，符阵一层层灭掉。
- 灵儿被扶起时手垂下来，指尖擦过柱基的碎石。

### 场景 5b ｜ 塔内 · 记忆归位与三人和解（本章的情绪炸点）

**场景描写**
仍在塔内，柱破之后、塔崩之前的一小段空隙。妖气因镇压解除而外泄，光源不稳；空间是刚刚被打碎的柱基残骸与三个人挤在一起的近景。这是全章唯一一段「安静」——安静得只够说几句话。

**人物出场描写**
- 赵灵儿：刚从柱上脱困，重伤、体力透支，靠人扶着；她此刻最不需要解释、最需要的是被认出来。
- 李逍遥：**记忆在这一刻回来了**——仙灵岛的湖、水月宫的许愿、被姥姥逼着拜的那一堂、还有离岛时被抹掉的那一段，全部归位。他从「护送者」瞬间变回「丈夫」。
- 林月如：站在这场认亲的**旁边**。她是唯一一个从头到尾没有失去过记忆的人，也是唯一一个在这场戏里没有得到任何东西的人。

**对白实录**（以转述为主，逐句原文未考证到可靠一手文本）
可确证的事实是三件：① 逍遥在这次营救中恢复了失忆期间的记忆；② **三人达成和解**——即之前横在三人之间的误会、别扭、争执，在这里被清账；③ 这段和解发生在塔崩之前，是月如做出断后选择的**前置条件**。
- 逍遥这边是认错与认人：他终于知道自己对灵儿做过什么承诺、欠了什么。
- 灵儿这边是释然：她等的从来不是道歉，是「你终于记得我了」。
- 月如这边是**成全**：她的和解方式不是说漂亮话，而是把位置让出来——这跟她一贯的嘴硬正好相反，也正因为如此才成立。

**事件逐拍**
1. 柱破、灵儿落下被接住 → 2. 逍遥看清她的脸，记忆冲回来 → 3. 三人把话说开、和解 → 4. 塔身第一声崩响打断这段安静 → 5. 逃。

**转折/伏笔**
这是全章、乃至全剧最锋利的一次结构安排：**先让月如亲眼看见自己彻底出局，再让她用命去保住那个让她出局的结果。**如果没有 5b，月如的死只是勇；有了 5b，她的死才是爱。
后文的两个回声都从这里长出来：灵儿把女儿取名「忆如」（她在场，她看见了月如让位的那一眼）；逍遥日后的仙术「爱无限」被解读为源自对月如的眷恋（据搜狐评论文，属解读非原作明写）。

**视觉扩写（创作用，非原作实录）**
- 逍遥认出灵儿的那一秒，反打给月如：她先笑了一下，然后把脸转开。
- 三个人的影子在残柱的余光里叠在一起，然后被第一块落石打散。

### 场景 6 ｜ 塔崩 · 逃出的路

**场景描写**
支柱既断，镇压之力失效，塔体自上而下连锁崩解：石梁断裂、青铜链绷断抽飞、封妖符阵成片熄灭，被镇的妖物的嘶吼与石块坠落声混成一片。烟尘、火光、坠石充满画面；原本幽绿的塔内被崩塌的粉尘染成灰白，绿光只剩在裂缝里一闪一闪。

**人物出场描写**
- 逍遥架着灵儿在前——灵儿重伤，几乎是被半拖着走的，这是他跑不快的原因，也是月如必须断后的原因。
- 月如在后——红衣在灰白烟尘里是全画面唯一能追踪的色块。

**事件逐拍**
1. 塔从顶部开始塌 → 2. 三人循原路上行／夺路 → 3. 通道被坠石切断，出现「只够一人先过」的瓶颈 → 4. 月如把逍遥和灵儿推／送过去 → 5. 巨石落下。

**转折/伏笔**
逃生路的**瓶颈**是这场戏的戏剧装置：它把「谁先走」变成必须当场回答的问题，而答案在这三个人之间只有一个。

**视觉扩写（创作用，非原作实录）**
- 一根青铜巨链自上而下抽断，像鞭子扫过镜头。
- 尘幕里三人的剪影，前二后一。

### 场景 7 ｜ 月如之死（本章核心）

> **实录边界声明**：95 原版此处为像素画面 + 文字对白的过场演出。**逐句台词文本未能考证到可靠出处**，本节按可确证的事实骨架（月如为救李、赵二人死于塔毁）逐拍还原，凡属推演的动作与情绪均标注，不伪造对白。

**场景描写**
崩塌中的塔内通道：坠石、断梁、飞尘；光源是崩口漏下的天光与残余符火。空间关系是**一条被石块逐渐堵死的路**：逍遥与灵儿在出口一侧，月如在里侧。

**人物出场描写**
- 林月如：红衣劲装、高马尾，此时已经乱了——发带松、衣上有灰与血。她的体态是全章最后一次「英姿」：站着，面朝里侧（面朝危险），背对出口。
- 李逍遥：被推出去后转身，架着灵儿，手还伸着。
- 赵灵儿：重伤未愈，意识半清；她是这场里最无力的人，也是最明白「这条命是拿什么换来的」的人。

**对白实录**（以转述为主，逐句原文未考证）
可确证的关系性内容是：**月如把逍遥与灵儿推向生路，自己留在了里面**；她死前与逍遥有最后的对望与交代，而逍遥没有来得及给出完整的回应。坊间与影视改编中广为流传的「临终托付／把他交给你」一类的台词，**属于 2005 电视剧与各版小说的改写，不能当作 95 原版实录引用**（此处明确留白，避免把改编当原作）。

**事件逐拍**
1. 通道被落石压窄，只剩一个人通过的间隙。
2. 月如反手／伸臂把逍遥与灵儿推出去（推的方向是出口，她自己反向留在塔内侧）。
3. 逍遥回身要拉她——手伸出去，中间隔着正在落下的石与尘。
4. 顶上的巨石／断梁坠落，砸中月如所在的位置。
5. 通道被彻底封死。逍遥被塌方与灵儿的重量同时拖住，喊也没用、回不去。
6. 三人变成两人。塔在身后继续塌。

**遗体与后续（可确证的部分）**
月如死后遗体并未被遗弃在塔中——后续剧情里，**苗疆圣姑以「傀儡虫」之法暂时维系死者，可让死者短暂复生，但需要定期收集傀儡虫来延续法术**（中文维基百科·林月如条目）。这条设定是月如线在锁妖塔之后能继续存在的唯一依据，也是 95 原版结局雪中树下那个撑伞身影的来源。更后的时间线里，长大后的**李忆如以「九转回魂珠」正式复活林月如**（同上，属续作时间线）。

**转折/伏笔**
1. **铁三角碎裂**：从苏州比武招亲结成的三人行，到锁妖塔为止。
2. **灵儿的赴死决心从这里开始加码**：她清楚地知道自己活下来的代价是另一个女人的命；结局她换命救苍生，有一部分是在还这笔账。
3. **「忆如」这个名字**：锁妖塔之后灵儿产女，取名李忆如——「忆如」＝忆月如。这个名字是本场戏在后文的唯一遗物。
4. **傀儡虫伏笔**：本场的死不是终点，而是 95 原版结局那把伞的起点。

**视觉扩写（创作用，非原作实录）**
- 月如推人那一下是**背对镜头**的，观众先看见的是逍遥被推得踉跄的脸。
- 落石之前有半秒的静音，只有灰尘在光柱里悬着。
- 最后一格：石堵死之后，红色从画面里消失，只剩灰与绿。

### 场景 8 ｜ 出塔之后

**场景描写**
塔外。锁妖塔已成废墟或半塌，青铜链垂落，尘烟未散。天光重新回到画面里，但色调是被尘染灰的暖白——与进塔前那种干净的云白不同。

**人物出场描写**
- 逍遥抱／背着灵儿；灵儿伤重、身怀有孕。两人身上都是灰。
- **独孤剑圣**：本章的另一处反讽在此闭环——**把灵儿关进塔的人，正是把逍遥与灵儿从塌塔中救出来的人**。中文维基百科·赵灵儿条目原文：「锁妖塔倒塌，林月如意外去世，而赵灵儿和李逍遥两人被独孤剑圣救下并送达了大理城」。

**对白实录**（存疑：此处交接的具体对白未考证到一手文本）
可确证的是**行为**：独孤剑圣救人、并把二人送到大理城。他既不是纯粹的反派，也没有为误判道歉——他只是把「该镇的镇、该救的救」执行完了。这种「正确的人做出错误的判断、又用正确的方式收拾残局」的处理，是本章最不像爽剧、最像悲剧的地方。

**事件逐拍**
1. 塔崩、通道封死 → 2. 独孤剑圣出手，救下逍遥与灵儿 → 3. 二人（携月如遗体）被送达大理城 → 4. 灵儿在大理临盆，产下女儿**李忆如**；调理一段日子后与逍遥前往大理城神殿祭拜娘亲石像，获得母亲的传承（维基·赵灵儿条目）→ 5. 月如遗体线转入苗疆圣姑的傀儡虫之法。

> 存疑：月如遗体是如何被带出塌塔的，各方来源均未交代具体过程。可确证的只是「后续剧情中遗体确实在队伍手上，方有圣姑傀儡虫续命一节」。MV 若要拍这一拍，须按「视觉扩写」处理，不可当实录。

**转折/伏笔**
1. 本章结束时队伍从「三人」变成「二人 + 一具遗体」。
2. 逍遥自此同时背着两件事：**救灵儿腹中的胎**（南疆寻凤凰蛋壳与麒麟角安胎）与**救月如的命**（圣姑傀儡虫）——这是他从少年正式变成成年人的位置。
3. **「忆如」之名在下一场就落地**：灵儿产女取名李忆如，「忆如」＝忆月如。锁妖塔死的那个人，被写进了活下来那个孩子的名字里。

## 四、95 vs 98 差异

| 维度 | 95 DOS 原版 | 98 柔情版（《仙剑奇侠传 98 柔情篇》） |
|---|---|---|
| 画面与演出 | 像素美术；过场以静态画面 + 文字对白为主 | 人物、场景、迷宫全盘重画，音乐／片头／剧情动画／片尾动画重制（Windows 化）——**锁妖塔一段的演出观感被显著加强** |
| 月如线补完 | 无梦境段落 | **新增罗刹洞（梦境）／罗刹洞（回魂仙梦）等「梦境／回魂」剧情迷宫**，与月如相关的情感补完（后为《新仙剑》罗刹鬼牢一脉的雏形） |
| 难度 | 原始数值 | 下调（仙术习得等级、敌方生命值降低等），塔内战斗压力相应降低 |
| 结局呈现 | 结局以文字／静态收束 | 正版通关可见结局动画：**月如（傀儡虫续命）雪中撑伞、怀抱李忆如等候逍遥归来** |
| 事件顺序 | 见 § 一 | 主线顺序未变；阿奴登场提前至余杭镇码头，但**仍不参与锁妖塔**（阿奴入队仍在锁妖塔之后的苗疆线） |

> 注：坊间常把 2005 电视剧版的锁妖塔演绎（灵儿被囚十年、拜月教介入、月如临终托孤台词等）当作原作，**剧版与 95/98 游戏在本章的差异极大**，MV 若要引用台词须先声明取的是哪一版。

## 五、可用于 MV 的画面记忆点

1. **仰角塔身**——幽绿妖气自石缝渗出，青铜巨链一圈圈缠住塔体，符纸在山风里翻动；塔尖没入云。
2. **红衣入绿塔**——月如的红色劲装是全塔唯一的暖色块，进门那一刻红／绿硬切成立，这个对比撑到她死为止。
3. **囚妖长廊**——被链锁在壁龛里的妖物在两人经过时缓缓抬眼，锁链拉直又松开。
4. **柱下相见**——巨柱符阵的光纹里，被镇的灵儿垂着头；逍遥仰头看她的那一眼是全章拐点。
5. **柱裂**——第一道裂缝炸开，符阵一层层熄灭，光从塔底往上灭上去。
6. **断链**——青铜巨链自上而下抽断，像鞭子扫过画面。
7. **推**——月如背对镜头把两人推向出口；观众先看到的是逍遥被推得踉跄的脸。
8. **红色消失**——石堵死之后，画面里再没有红，只剩灰与绿。
