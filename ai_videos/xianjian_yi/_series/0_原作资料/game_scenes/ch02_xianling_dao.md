# ch02 · 仙灵岛 · 水月宫（初见与拜堂）

> **流程位置**：余杭县（婶婶病倒）→ **仙灵岛（求仙丹·初遇赵灵儿）** → 余杭县（治好婶婶·忘忧散发作失忆）→ 十里坡（初遇酒剑仙学艺）。本章是全作第二个可游玩地图，也是李逍遥与赵灵儿的唯一一次「婚前相处」，全作所有情感债务都由这一章埋下。
> **版本口径**：1995 DOS 原版为主线；98 柔情版差异以「98版差异：」行内标注；凡属 2005 电视剧或后续作品而非游戏原作的内容，一律标注「（非游戏原作）」。
> **可靠性口径**：本章的「实录」层只写检索得到、可溯源的内容。原作对白的逐字文本未能全部考证到，因此对白层以**详实转述**为主（谁对谁说、说了什么、态度如何、对方怎么反应），并对未考证到确切文本的地方明确标注「（存疑）」。为分镜需要的视觉补完一律另开「视觉扩写」小项，与实录严格分栏。

**流程顺序的两处重要考据修正（见 `scope_correction`）**

1. **「许愿池」在 1995/98 游戏本篇中未考证到。** 仙灵岛上有名有姓的水体是**荷花池**（六石像机关所在）与**桃花灵池**（初见所在）。「许愿池」很可能来自电视剧或系列后续／衍生作品（非游戏原作）。本文不把它写成实录。
2. **抹去李逍遥记忆的不是姥姥。** 多份攻略与问答一致指向：**黑苗头领在他上岛之前**就以「防瘴气丹丸」为名骗他吞下**忘忧散**，药效延迟到他回客栈救活婶婶之后才发作。姥姥全程没有对他施忘忧法术。这一点直接改变本章的悲剧结构——**遗忘是外人的阴谋，不是长辈的慈悲**。

## 二、场景志

### 场景 1 · 余杭县码头 · 张四哥的渡船（登岛前奏）

**① 场景描写**
江南水乡的旧码头。木栈桥探进浑黄的江面，桩子上缠着水草，栓着两三条乌篷小船。岸上是矮檐瓦房、晒着的渔网与倒扣的木桶。时段偏白昼，天光是江南特有的那种被水汽泡软的白——不刺眼，却把一切都罩上一层薄薄的灰。声音层：水拍船帮、木橹吱呀、远处集市的人声。空间关系：李逍遥从镇内街道下坡走到栈桥，船夫张四守在船边；船头朝外海，一出栈桥就是茫茫水面，仙灵岛在视线尽头的雾里。

**② 人物出场描写**
- **李逍遥**：客栈店小二打扮，短打布衣、束腰、脚下布鞋（游戏前段可从秀兰、香兰处得到布鞋）。此刻他身上多了两样不该属于店小二的东西——腰里别着黑苗头领给的**破天锤**（一柄沉手的短柄大头锤），肚子里刚咽下一颗被骗吃的丹丸。神情是急的：婶婶病倒是这一整章的引擎，他没心思看风景。
- **张四（张四哥）**：本地船夫，渔家装束、卷裤腿、赤脚或草鞋，皮肤被日头晒成深色。（存疑：具体衣着与外貌，攻略文本未描写，此处为渔家通例。）

**③ 对白实录（转述为主）**
李逍遥找到张四，说明要去仙灵岛。仙灵岛在余杭一带是有名的「去不得」之处——李逍遥先前在**集市上就听人讲过仙灵岛的传说**（集市听闻是游戏内的一段前置对话），民间把它当成有仙女、也有凶险的禁地。张四最终还是把他渡了过去。（存疑：张四此处的逐句对白未考证到确切文本；多份攻略只记「与船夫张四对话后前往仙灵岛」。）

**④ 事件逐拍**
1. 婶婶病倒 → 医不好 → 李逍遥被逼到必须找「仙药」这条路上。
2. 黑苗头领**主动**在客栈门口给锤、给丹丸、给方向——他不是好心，他要的是有人替他去砸开封岛法阵。
3. 李逍遥吞下丹丸（他以为是防瘴气的）——**全章最大的伏笔在此刻已经生效，而观众和主角都不知道**。
4. 到码头，找张四，上船，离岸。

**⑤ 转折 / 伏笔**
这一拍是「被人当刀使」的开端。李逍遥以为自己是去救婶婶，实际上他是黑苗人用来撬开仙灵岛的钥匙——**六座石像的法阵不是他该破的，是苗人破不了才让他破的**。后来余杭大战苗人救灵儿（第 5 章）之所以会发生，根子就在这一船。

**⑥ 视觉扩写（创作用，非原作实录）**
- 开场可用一个空镜：栈桥木缝里漏下的江水反光，锤头压在腰间把布衣坠出一道褶。
- 「吞丹丸」这一拍值得给特写：喉结一动，一颗药丸落下去——MV 里这就是全片的「命运扣下扳机」镜。
- 船离岸时可用低机位贴水面，让余杭的屋檐一点点退出画面。

### 场景 2 · 仙灵岛外岩 · 岩洞通道（登岛）

**① 场景描写**
船靠在岛外的礁岩边。仙灵岛的外圈是**岩体与洞窟**——攻略记为「往右上通过仙灵岛岩洞通道」。这是一段窄而弯的天然石道，两侧岩壁湿滑，顶上滴水，光从洞口斜切进来，越往里越暗，出口那头又亮起来。洞外岛上有树，**树上可采鼠儿果和水果**（游戏明写的可采集物），说明外圈至少是有林木、有活物、能活人的地貌，不是荒石。声音层：滴水、回声、脚步、以及被放大的自己的呼吸。

**② 人物出场描写**
李逍遥独自入洞。他这时的体态还是「愣头青闯禁地」——好奇多过恐惧，走两步还要伸手去摘树上的果子。进画方式：从画面右下角出船、沿岩壁往画面右上方走，游戏的行进方向本身就构成一个「向上、向内」的运动。

**③ 对白实录（转述为主）**
本段无对白。（存疑：DOS 原版此处是否有独白提示，未考证到。）

**④ 事件逐拍**
1. 登岛 → 2. 向右上进入岩洞通道 → 3. 沿途遭遇岛上妖物（回合制战斗，界面含法术／普攻／双人合击／道具）→ 4. 穿出洞道，眼前豁然是**荷花池**。

**⑤ 转折 / 伏笔**
从「窄暗的岩洞」推到「开阔的荷花池」，是全章第一次视觉打开。仙灵岛的空间结构本身就在讲故事：**外圈是石与暗，中圈是水与花，最内是宫**——一层层剥进去，才见得到灵儿。

**⑥ 视觉扩写（创作用，非原作实录）**
- 洞道适合做「窄画幅」处理：两侧岩壁挤压 9:16 竖屏，人只占中间一条。
- 出洞那一拍给全片第一次「过曝」——从暗到亮的瞬间，观众和逍遥同时被光刺一下。

### 场景 3 · 荷花池 · 六座石像的封岛法阵

**① 场景描写**
一整片开阔的池水，水面浮满荷叶与荷花。**部分荷叶是可以踩上去的踏板**（攻略称「黄色荷叶」「蒲苇垫」），踩上去会载着人在水面上挪动——这是本作最有辨识度的机关之一。水面上立着**六座石像**，围成一圈，是封住仙灵岛内层的法阵；池心还有一块**中央踏板**，六像未破时它是暗的。池边可拾**五张灵符**与**雪莲子**。色彩是青碧＋粉白＋灰石三色，光线是敞亮的天光直照水面，反光晃眼。

**② 人物出场描写**
李逍遥单人站在一片荷叶上，锤扛在肩上，随着荷叶漂移不断调整重心。这是本章唯一的「体力活」段落——他不是在谈情，他是在**拆一座上古法阵**，而且拆得笨手笨脚。

**③ 对白实录（转述为主）**
本段无对白（纯机关解谜）。石像的来历游戏内未明说；坊间解读普遍认为**六像是护岛的守护法阵，砸掉才会露出通道**（经搜索摘要间接引用，知乎专栏 p/548159661 主题即为「去仙灵岛为啥要砸石像」）。

**④ 事件逐拍**
1. 踏上荷叶，靠荷叶漂到第一座石像前。
2. 举破天锤砸——石像碎。
3. **按顺（顺时针）序**逐一砸完六座；顺序错会导致后续触发出问题（多份攻略特别强调这一点）。
4. 六像尽碎 → 池心**中央踏板发亮**。
5. 踏上中央踏板 → 通道开启 → 进入**桃花灵池／仙灵洞天**。

**⑤ 转折 / 伏笔**
**这是全作因果链上最被低估的一拍。** 李逍遥亲手砸开了保护灵儿的最后一道屏障。他为救婶婶而来，却顺手替苗人拆掉了仙灵岛的封印——第 5 章苗人能摸到水月宫、姥姥后来会死在苗人夜袭之下，路是他今天砸出来的。**救一个人的路，同时是害另一个人的路**，仙剑的宿命主题在这里第一次落到实处。

**⑥ 视觉扩写（创作用，非原作实录）**
- 六座石像可给一组统一构图的「砸碎」蒙太奇：同机位、同景别，六次落锤、六次崩裂，越砸越快。
- 最后一像碎裂时，水面反光整片一颤，中央踏板亮起——这一亮可以做成全片第一个「命运节点」的视觉符号。
- 荷叶载人的漂移感建议用横移镜头（人不动、世界在动）。

### 场景 4 · 桃花灵池 · 桃花林（初见 · 出浴）

**① 场景描写**
通道后是与外圈完全两个世界的地方：**桃花灵池**。一片桃树林，花开得极盛，落英铺在地上和水面上；林间是一泓静水（游戏中的「灵池」）。这里没有妖物压迫感，光是柔的、暖的，粉白的桃花把整片画面的色温压到暖调——与前一场荷花池的冷青、更前一场岩洞的灰黑形成**三段式色彩递进**。声音层：风过花枝、水声、以及——女子的水声。空间关系：李逍遥从通道口出来，**沿湖边往右下方向走**，岸边草地上放着**一堆女子的衣物**。

**② 人物出场描写**
- **赵灵儿**：年方十六。游戏此刻只给她一个背影／半身的出浴形象——她在池中沐浴，长发披水。她的设定气质是「莲花不染纤尘」「小鸟依人」（维基百科条目所述设计意图：塑造成「男性梦想中完美女性的代表」）。她的真身是女娲族后裔，**原形为人脸蛇身**——这一层此刻完全不露。
- **李逍遥**：从林中钻出来，看见衣服，起了坏心眼去「调查」——这一步是玩家亲手按下去的，游戏把「偷看」的责任交给了玩家。

**③ 对白实录（转述为主）**
调查衣物 → 撞见出浴。灵儿立刻发觉，**先把这个「登徒浪子」教训了一顿**（维基百科赵灵儿条目用词）。李逍遥的反应是他这个人一以贯之的：不认怂、耍贫嘴、拿衣服当筹码——**98 版攻略明确记载他「盗了赵灵儿的衣服」，并以归还衣服为条件，要她给紫金丹**。灵儿又羞又恼，但听他讲完婶婶病重、他是来求药的之后，**同情他的遭遇，答应给药**。（存疑：两人这段拌嘴的逐字对白未考证到确切原文，此处为多方攻略叙述的转述。）

**④ 事件逐拍**
1. 出通道 → 沿湖往右下 → 发现岸边女子衣物。
2. 「调查」衣物 → 触发出浴撞见。
3. 灵儿惊怒，教训他一顿。
4. 李逍遥**拿走／扣住衣服**，开条件：要紫金丹。
5. 他说明来意——婶婶病重、非仙药不可。
6. 灵儿由怒转怜，**答应给药**，领他去水月宫。

**⑤ 转折 / 伏笔**
全作的情感起点。**注意这段关系的底色不是浪漫，是一场胡闹的胁迫**——他偷看、他扣衣服、他讲条件；而她之所以松口，不是因为动心，是因为**心软于一个孩子要救养大自己的婶婶**。仙剑之所以耐读，是因为最大的爱情从一个最不体面的开场长出来。同时，「灵儿轻易就带外男进水月宫」这一点，直接引出下一场姥姥的雷霆之怒。

**⑥ 视觉扩写（创作用，非原作实录）**
- 建议用「不拍人、只拍水」的处理：水面碎光、发梢滴水、桃花瓣打旋——把「出浴」做成意象而非奇观，MV 更立得住。
- 岸边那堆衣物是本场的题眼道具，可给一个静物特写（衣带垂进水里）。
- 反打李逍遥时，用桃枝做前景遮挡——「偷看」的机位语言。
- 灵儿转身发怒的一瞬，可让整片桃花被风掀起——她的情绪＝环境的情绪，为后面她的水系法术埋一个视觉伏笔。

### 场景 5 · 水月宫 · 宫内与紫金丹

**① 场景描写**
**水月宫在仙灵岛最深处**（百度百科「水月宫」词条述：位于仙灵岛深处，以水月宫主为首，**宫中素来不许男子进入**，所习法术偏疗愈而非争斗——经搜索摘要间接引用）。这是一座清冷、素净、以水为魂的宫室：白石、素幔、水痕、月意。游戏内它同时是功能性的**回复点**，宫内散布物品与宝箱——攻略明确提到此区可得**紫金丹、观音符、苗刀**。空间关系：宫有正殿与厢房，**紫金丹在「左边的房间」**里由灵儿交给李逍遥；出宫要走回同一条路——这条「回头路」就是下一场撞见姥姥的地方。

**② 人物出场描写**
- **赵灵儿**（穿好衣物后的正式登场）：这才是全作观众记住的那个灵儿——素色衣裙、长发、赤足或软履，动作轻，眼神干净，说话有分寸。她在自己家里，是主人；但她十六岁，没见过外人，所以**她的「主人姿态」是学来的、绷着的**。
- **李逍遥**：一个男人站在「素来不许男子进入」的宫里，本身就是越界。他大概率还在东张西望、顺手摸宝箱——这是这个人物的喜剧底色，也是他此刻**完全不知道自己踩了多大的雷**的证据。

**③ 对白实录（转述为主）**
灵儿把他领进宫，在**左边的房间**里与他对话，**把紫金丹交给他**。这是她第一次为一个外人破自己家的规矩。李逍遥的态度多半仍是嬉皮笑脸的道谢；灵儿则是既想快点打发他走、又忍不住多问两句外面的世界。（存疑：宫内对白的确切文本未考证到；「宫中不许男子进入」的宫规来自百科词条摘要，游戏内是否由角色口述未考证。）

**④ 事件逐拍**
1. 灵儿领李逍遥进水月宫。
2. 进左边房间，对话，**取得紫金丹**。
3. 李逍遥顺路搜宫（观音符、苗刀、宝箱），在回复点补状态。
4. 转身出宫——**正撞上回来的姥姥**。

**⑤ 转折 / 伏笔**
紫金丹到手，本章的「任务目标」其实已经完成了。**从这一刻起，后面发生的一切都不是他要的，是命运硬塞给他的**——这是本章结构上最关键的分界线：目标达成之后，故事才真正开始。

**⑥ 视觉扩写（创作用，非原作实录）**
- 水月宫的视觉关键词：**白、素、水、月**。建议全场只用冷白＋淡青，与前一场桃花林的暖粉硬切，制造「进了别人家的规矩」的体感。
- 交丹药一拍：两只手在画面中心交接一粒丹丸，背景虚化——这是本章的「信物镜」。
- 宫内可用大量水的反射（地面积水、水镜）来做「水月」二字的字面视觉。

### 场景 6 · 水月宫出口 · 姥姥登场与逼婚

**① 场景描写**
同一处宫门／回廊，但气压完全变了。姥姥是从外面回来的，逆着光站在门口——她堵住的正是李逍遥唯一的出路。空间上这是一个**封闭三角**：姥姥在门（唯一出口），灵儿在中间，李逍遥在最里侧退无可退。

**② 人物出场描写**
- **姥姥**：苗人妇女，年事已高（考据：姓姜，旧版本作姜绮萝，**不具女娲血统**，是当年护着灵儿母女逃亡到仙灵岛的外人；虽是外人，却凭威望成为水月宫实际主事者——经搜索摘要间接引用网易文章 HB1PKF3F055265DW）。外形上是苍老、精瘦、目光极利的老妇；她的「梦蛇」等手段被后世分析认为**多半是唬人的障眼法**，但在这一场，李逍遥不知道，观众也不知道——她此刻就是绝对权威。
- 她的进画方式极关键：**她不是被撞见的，是她撞见了他们**。

**③ 对白实录（转述为主）**
姥姥厉声责问灵儿：为什么把一个陌生男人带进水月宫。（水月宫不许男子入内的规矩，加上灵儿的身份必须避人，两条一起犯。）随即她转向李逍遥，态度是要当场处置他的——多份攻略用的词是「威逼李逍遥留下」。
关键一拍在灵儿身上：**灵儿以「贞节」相救**（攻略原用词：「幸得灵儿以贞节相救」）——即她把两人已有肌肤之亲这件事担了下来，用自己的名节替他挡了这一刀。姥姥于是就坡下驴，**逼李逍遥负责**：既然坏了灵儿清白，就得娶她，**两人今日成婚**（维基百科赵灵儿条目：「姥姥在了解缘由后，强令李逍遥为赵灵儿负责，两人同日成婚并洞房」）。
游戏在此给玩家一个**「是否同意成亲」的选择**，须选同意才推进情感主线（怀旧指南明确：「选择同意即可触发成婚剧情，这对后续情感线发展至关重要」）。（存疑：姥姥与灵儿这一段的逐字对白未考证到确切文本。）

**④ 事件逐拍**
1. 姥姥归宫，堵在门口，撞见外男。
2. 姥姥厉责灵儿：谁准你带他进来。
3. 姥姥转向李逍遥，要处置他。
4. 灵儿以贞节相救——把自己押上去。
5. 姥姥改口：那就负责，今日成婚。
6. 玩家选择「同意」→ 剧情推进。

**⑤ 转折 / 伏笔**
姥姥的动机在游戏里没有摊开讲，这恰恰是它耐嚼的原因。后世解读普遍指向两点：**其一，她时日无多**，必须给灵儿找一个能托付的人；**其二，仙灵岛的封印已被砸开**，灵儿再也藏不住了，她赌的是这个愣头青。所以这场戏表面是「老太太蛮不讲理」，里子是**一个知道自己快死了的守护者，在最后一刻替孩子押注**。这个视角一立，全章的悲剧密度立刻翻倍。

**⑥ 视觉扩写（创作用，非原作实录）**
- 姥姥登场务必逆光剪影：她的脸留到第二个镜头才给。
- 三人站位是本场的全部戏——**门（权力）、中间（灵儿的选择）、深处（无路的逍遥）**，一个固定机位就够。
- 灵儿「担下来」的那一拍，建议她主动往前跨半步挡在逍遥身前：**这是她全片第一次主动做决定**。

### 场景 7 · 拜堂之夜 · 洞房

**① 场景描写**
仙灵岛上的婚礼是**一场没有宾客的婚礼**——没有喜宴、没有亲族、没有仪仗，只有一个逼婚的老人、一对昨天还不认识的新人，和一屋子红。红烛、红帐、红盖头，全片唯一一次大面积暖红，插在冷白（水月宫）与青碧（荷花池）之间，突兀得像一场梦。时段是夜，声音层是极静——烛芯爆响都听得见。

**② 人物出场描写**
- **赵灵儿**：新嫁衣、盖头。她今天上午还在池子里洗澡，晚上就成了亲。**她十六岁，没有拒绝的余地，也没有想拒绝**——这是全片最需要演员（或分镜）用「沉默」演的一段。
- **李逍遥**：新郎，多半还带着那股没回过神的懵。他被推着完成了拜堂的每一个动作。
- **姥姥**：主婚者。她在场，然后她退场——把门关上。

**③ 对白实录（转述为主）**
攻略对这一夜的记述极简：「**当晚李逍遥和赵灵儿成亲**」「一夜缠绵之后」。维基百科条目记为「两人同日成婚并洞房」，并明确李逍遥在这一夜**承诺会回来接她**（李逍遥条目：「当晚浓情蜜意，承诺会回来接她」）。这句承诺是全作最重的一句话——因为第二天他就会忘掉它。（存疑：洞房夜的逐字对白未考证到确切文本；游戏对此的表现极为克制。）
**辨伪**：网络流传的「既不回头，何必不忘；既然无缘，何须誓言……」常被误系在新婚之夜（网易某文即如此归类），但多方来源一致指向该诗出现在**全作结局**、灵儿与水魔兽同归于尽时的诀别，**不属本章**。本文按结局归属处理。

**④ 事件逐拍**
1. 姥姥主婚，拜堂。
2. 入洞房，红烛。
3. 李逍遥**许下「我会回来接你」的承诺**。
4. 一夜。

**⑤ 转折 / 伏笔**
全作的「情债」在此签字画押。**遗忘之所以残忍，是因为在遗忘之前，他真的许过诺。** 后来锁妖塔底，李逍遥见到灵儿的蛇身人形时才猛然想起「原本已和赵灵儿洞房花烛在先」（维基百科李逍遥条目）——那一记回忆之所以能把玩家击穿，全靠今晚这几根红烛。

**⑥ 视觉扩写（创作用，非原作实录）**
- 建议整场不给全景，只给：烛火、盖头的一角、交叠的手、窗纸上晃的影。红要满，但人要藏。
- 「承诺」一拍可以只拍嘴型不给声音——因为这句话马上就要被药抹掉，用「无声」预演它的命运。
- 一个可复用的意象：一支红烛在画面里烧到一半，下一场直接接晨光——省掉过程，留下代价。

### 场景 8 · 次日 · 离岛与姥姥扫墓

**① 场景描写**
清晨的仙灵岛。桃花林、荷花池、岩洞通道，昨天来时的路要反着再走一遍——但光完全不同了：晨雾、低角度斜光、露水。**这是全章唯一一次「回头看」的机会，而角色并不知道自己再也回不来了**。逃走途中会**撞见姥姥正在扫墓**（攻略明记「逃跑时发现姥姥扫墓的剧情」）——岛上有坟，坟前有一个不肯说话的老人。

**② 人物出场描写**
- **赵灵儿**：换回素衣，送他到岸边。她昨天是新娘，今天是送行的人。
- **李逍遥**：怀里揣着紫金丹，脑子里揣着一个承诺。
- **姥姥**：远处，背对，扫墓。她不拦。**她昨天可以为了灵儿把刀架在他脖子上，今天却放他走**——这个反差是她这个角色最好的注脚。

**③ 对白实录（转述为主）**
攻略记述：**次日趁姥姥不在（另一说为在灵儿相助下），赵灵儿协助李逍遥离开仙灵岛**。送别的具体对话未考证到确切文本。（存疑：此处逐句对白缺考；「趁姥姥不在」与「撞见姥姥扫墓」两说并存于不同攻略，可能是同一事件的不同表述——姥姥去了墓地，所以「不在」宫中，逃走路上才会撞见她在扫墓。本文按此调和。）
**墓主未考证到**：岛上这座坟是谁的，检索未得确证，不作脑补。

**④ 事件逐拍**
1. 天亮，灵儿助他离开。
2. 原路回撤：水月宫 → 桃花林 → 荷花池 → 岩洞 → 岸边。
3. 途中撞见姥姥在扫墓（她没有阻拦）。
4. 上船，离岛。

**⑤ 转折 / 伏笔**
「扫墓」这一拍是整章埋得最深的一根刺：**这座岛上是有死人的**，而且姥姥知道自己也快是其中之一。她昨夜的逼婚与今晨的放行，在这座坟前被同一个动机串起来。对 MV 而言，这是把「甜」立刻拽回「悲」的最好素材。

**⑥ 视觉扩写（创作用，非原作实录）**
- 建议做「同景别倒放」：来时的每个关键构图，今晨各回一个镜，但光从冷变暖、人从一个变两个再变回一个。
- 姥姥扫墓一拍用极远景，人小、坟小、岛大——**命运视角**。
- 船离岸，灵儿站在岸上不动，直到成一个点。她此后要等很久很久。

### 场景 9 · 余杭客栈 · 救活婶婶 · 忘忧散发作（本章因果闭环）

**① 场景描写**
回到余杭客栈的病房。狭小、昏暗、有药味，与仙灵岛的开阔明净构成收尾对照。李逍遥先得去找**洪大夫**取灵芝（药引），再回房用紫金丹。

**② 人物出场描写**
- **婶婶（李大娘 / 孙岚）**：卧病。她是李逍遥自幼失怙后把他养大的人——他去仙灵岛的全部理由。
- **李逍遥**：他此刻是个刚成了亲的十九岁少年，兴冲冲地回家救人，还准备回去接新娘。

**③ 对白实录（转述为主）**
无关键对白记载。（存疑：救治场面的具体台词未考证到。）

**④ 事件逐拍**
1. 找洪大夫取灵芝。
2. 服紫金丹，婶婶病愈。
3. **忘忧散在此刻发作**——李逍遥当场晕倒。
4. 醒来：**从婶婶生病开始、到取回紫金丹为止的这一整段记忆全部消失**（百度知道／网易攻略一致口径：苗人头领「以防止岛上瘴气为由，给李逍遥吃下了忘忧散」，作用是「让其忘记他婶婶生病开始到取回紫金丹这期间发生的事情」）。仙灵岛、水月宫、桃花林、灵儿、那一夜、那句承诺——全部清空。
5. 随后他从事先做好的密道离开客栈，走向十里坡（下一章：初遇酒剑仙学艺）。

**⑤ 转折 / 伏笔**
本章的真正结局不在岛上，而在这间小屋。**他救活了养他的人，代价是弄丢了爱他的人**——而且他连「弄丢了」这件事本身都不知道。全作最锋利的一刀在这里落下，且落得毫无戏剧动静：他只是晕了一下，醒来继续做店小二。
> 结构上要点明：**遗忘是他人（黑苗头领）的算计，不是恋人或长辈的选择。** 这让悲剧从「无奈」升级为「被剥夺」。

**⑥ 视觉扩写（创作用，非原作实录）**
- 建议用「记忆抽走」的具象化：桃花林、荷花池、红烛、灵儿的脸，逐帧褪色 / 被水冲淡 / 化成白。
- 最后留一个空白的画面，接他醒来睁眼的特写——眼里干干净净，什么都没有。
- 可与全片结尾（灵儿诀别）做首尾呼应：一次是他忘了她，一次是她离开他。

## 四、95 vs 98 差异

**已考证到的差异**

1. **宝物获取的机制差异（DOS 原版 bug）**：百度文库《仙剑奇侠传1 Dos怀旧版》图文攻略明确指出，**DOS 版因 bug 无法取得某些宝物**，而 **98 版可以通过踩荷叶（睡莲踏板）逐一采集**（经搜索摘要间接引用）。也就是说，荷花池的荷叶踏板在两版中的可达性不同——98 版把这套机关做得更完整。
2. **叙事表现的丰简**：98 柔情版（《仙剑奇侠传98柔情版》）的攻略对仙灵岛一段的**剧情文字记述明显更细**（盗衣、以紫金丹为条件、姥姥威逼、当晚成亲、次日灵儿助其离开、回客栈后忘忧散发作晕倒），95 DOS 原版的攻略叙述则更贴近「操作步骤」。**（存疑：这可能反映 98 版增补了剧情演出，也可能只是攻略作者详略不同，未能从来源中区分开。）**
3. **结局动画**：B 站有「《仙剑奇侠传1》双版本结局动画」比对视频，说明 **DOS 版与 98 版的结局动画不同**（经搜索摘要间接引用）——但这属于全作结局，不属本章。

## 五、可用于 MV 的画面记忆点

1. **落锤碎像**——荷叶漂着，锤起锤落，六座石像依次崩裂，水面反光整片一颤。（救人的动作＝毁灭的动作）
2. **中央踏板亮起**——六像尽碎后，池心那块石板由暗转亮，通道洞开。全片的「命运扣响」镜。
3. **岸边那堆衣物**——桃花瓣落在素色衣带上，衣带一角垂进水里。不拍人，就拍这一堆衣服。
4. **出浴的水面**——只给碎光、发梢的水珠、打旋的落花；转身的一瞬，满林桃花被风掀起。
5. **一粒紫金丹在两只手之间交接**——冷白的水月宫，画面中心只有那一点金。
6. **姥姥堵在门口的逆光剪影**——门是唯一的出路，她站在光里，脸在暗中；灵儿往前跨半步挡在逍遥身前。
7. **没有宾客的红**——红烛、红帐、盖头一角、交叠的手、窗纸上的影。全片唯一一次大面积暖红。
8. **岸上越来越小的白影**——船离岛，灵儿站着不动，缩成一个点；而远处山坡上，姥姥在扫墓。
9. **记忆被冲白**——桃花、荷池、红烛、她的脸，逐帧褪成空白；接一个睁眼的特写，眼里干干净净。
