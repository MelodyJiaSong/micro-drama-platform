> **抽取方式聲明**：每頁一幅俯視全景地圖 + 一個標題框。本檔**完整轉錄全部 59 個官方地名**（逐頁標題帶已全數判讀），並對 **10 個代表性場景**做了美術觀察（色調／地貌／構造）；其餘場景僅有地名，未逐幅描述美術——因為同一地名的多幅（如鎖妖塔一～九）在美術上是同一套素材的不同樓層佈局，對本劇的價值在地名體系與空間類型，不在每層迷宮的通路走法。

## 二、對既有資料的地名增量（`scenes_source.md` / `game_scenes/` 未見或未定名者）

以下是這份官方地圖表帶來的、既有資料裡沒有獨立成卡的場景：

- **十里坡** —— 逍遙離開餘杭後的第一段郊野。（「十里坡劍神」的典故出處）
- **亂葬崗（一）（二）**、**將軍塚（一）（二）**、**血池** —— 赤鬼王線的三段式地理：亂葬崗（外）→ 將軍塚（墓道）→ 血池（核心）。**官方確認赤鬼王「在血池中修成半人半魔」，血池是有獨立地圖的實體場景。**
- **鬼陰山（郊外／洞內一二三五六／鬼陰壇內）** —— 共 7 幅，是本作**規模最大的洞窟系統之一**，且有專屬祭壇「鬼陰壇」。
- **黑蜘蛛森林（一）（二）** —— 毒娘子（黑蜘蛛精）與彩依線的專屬場景。
- **火麒麟洞（一）（二）** —— 對應敵角色表中的「火麒麟」。
- **蛤蟆谷 / 蛤蟆谷－山谷 / 蛤蟆洞（一）（二）** —— 共 4 幅，對應「柳媚娘與毒物蛤蟆精為伍」的官方設定，是柳媚娘線的專屬地理。
- **木道人洞府內** —— 木道人（＝木靈道士，桃源鄉線反派）的巢穴，有獨立地圖。
- **大理城東郊**、**試煉之洞郊外** —— 兩處外景過場地。
- **南詔城－地牢 / 南詔城水底（一）（二）** —— 南詔城的三個附屬空間（水底迷宮 2 幅是既有資料未見的）。
- **白苗神殿南詔城之地下迷宮（一）（二）（三）**、**地下迷宮至南詔城之入口** —— 白苗神殿與南詔城之間的地下通道系統，共 4 幅。

## 三、代表場景美術觀察（10 幅，直接可餵 `scenes/` 場景卡與 shot 的「場景」欄）

| 場景 | 官方美術特徵 |
|---|---|
| **十里坡** | 俯視丘陵地。**草綠為底、赭紅色土路蜿蜒穿過**，散布深綠灌木叢與土黃岩壁。開闊、明亮、無壓迫感——是「少年出門闖江湖」的第一景，色調應該是全劇最鮮亮的。 |
| **亂葬崗（一）** | 深綠林地被**赭褐色木柵欄**切割成迷宮狀通道，地面散落白色小點（骸骨）與土黃色墳丘、灰色陶甕。陰森但仍在戶外日光下。 |
| **血池** | **整幅底色為濃郁的赤紅／磚紅**，其上是黑色不規則塊狀的通道與平台，零星青綠色點。**全書色彩最極端的一幅**——沒有一點自然綠。赤鬼王「吸取人血、在血池中修成半人半魔」的視覺就是這片紅。做成 shot 時應保持「純紅底＋黑色剪影」的強對比。 |
| **鎖妖塔（三）** | **等角俯視的多層方塊建築剖面**，米白／淺綠磚牆，房間如蜂巢般密集堆疊，牆上滿是門洞，少數房間地板為**赭紅色**（重點房）。背景全黑。壓抑、規整、無出口感——「囚牢」的建築語言。 |
| **神木林（一）樹上** | **巨大的赭黃色垂直樹幹柱列**貫穿整個畫面，樹幹之間橫架著細木棧橋（呈交叉的 X 形），背景是深黑與濃綠的樹冠層。**這是「在巨樹之間、離地極高處行走」的空間**，垂直感極強，非常適合做仰角／俯角的眩暈鏡頭。 |
| **神木林底** | 相對於樹上，是林地面層，通往大理城與木道人洞府。 |
| **蛤蟆谷** | 深綠密林 + **土黃色小徑**盤繞，谷地邊緣是**垂直的黃褐色斷崖**（切面清晰可見岩層紋理），畫面右中有一座**灰白色小亭／建物**。背景黑。是「懸崖環抱的封閉谷地」。 |
| **試煉之洞郊外** | **土黃／橄欖褐為主色**的荒原，深綠植被帶呈環狀盤繞，中央有一個黑色洞口。荒涼、乾燥——與蜀山的雲霧、苗疆的濃綠都不同，是女媧試煉的獨立色系。 |
| **南詔城水底（一）** | **黑色水底背景**上，藍綠色的珊瑚／水草質感牆體構成迷宮，牆面散布橘紅與藍色小點（水生物）。左上角有一座金色欄杆的方形平台。冷色調、幽閉、有微光。 |
| **南詔城－地下宮殿** | **深墨綠／灰藍色調**，灰白石磚砌成的宮殿式方形迴廊與階梯，中央有金色欄杆圍起的核心平台。莊嚴、幽暗、有「王城地下」的規格感。 |
| **白苗神殿南詔城之地下迷宮（二）** | **土褐色顆粒質感的高牆**組成的密集直線迷宮，牆體極厚、通道極窄，背景黑。是全書最「純迷宮」的一幅，壓迫感最強。 |
| **地下迷宮至南詔城之入口** | 黑色虛空背景中，**懸浮的石砌平台與階梯**由窄橋連接（平台邊緣有金色圓形機關點）。空間破碎、無地面——適合做「懸空石台」的奇觀鏡。 |

## 四、對本劇的可用結論

1. **色彩地理是分區的、且官方分得很清楚**：中原郊野＝草綠＋赭紅土路；亂葬崗／將軍塚＝深綠＋褐柵欄＋骸骨白；血池＝純赤紅＋黑；鎖妖塔＝米白磚＋黑底；神木林＝赭黃巨柱＋濃綠；苗疆谷地＝濃綠＋土黃＋斷崖；南詔城水底＝黑＋藍綠；地下宮殿＝墨綠＋灰白石。**本劇的 `style_guide.md` 可直接照這套分區配色定調，每個場景卡鎖一組色名。**
2. **空間類型也是分好的**：開闊郊野（十里坡／大理城東郊）／柵欄迷宮（亂葬崗）／洞窟系統（鬼陰山 7 幅、蛤蟆洞、火麒麟洞）／垂直樹冠層（神木林樹上）／多層囚牢（鎖妖塔 8 層）／水底（南詔城水底）／石砌宮殿（地下宮殿）／懸空石台（地下迷宮入口）。**運鏡設計可按空間類型選鏡：垂直空間用仰俯，迷宮用跟拍平移，懸空石台用大遠景。**
3. **鎖妖塔有 8 個獨立樓層、試煉之洞有 10 個獨立洞層** —— 官方把這兩處做得最深，說明它們在敘事上的份量最重。本劇分配鏡數／集數時，這兩段應給到相稱的篇幅，不宜一集帶過。
4. 幾個既有資料未立卡的場景值得補卡：**十里坡、血池、鬼陰壇、黑蜘蛛森林、蛤蟆谷、木道人洞府、南詔城水底**。
