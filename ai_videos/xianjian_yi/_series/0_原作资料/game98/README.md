## 两层结构：原版 → 演进
| 层 | 位置 | 性质 |
|---|---|---|
| **原版底本** | `_raw/`（gitignored·只读） | 原始 docx 字节级副本 + 机械转换的 `*_原文.txt` 平行档。**基准线，永不编辑**；演进层与原文不符时以此为准。 |
| **演进层** | 本目录 `ch01–ch10.md` / `side_quests.md` / `npc_flavor.md` | 在原版之上加工：逐场景详实转述 + 标志性名句少量直引（同场景 ≤3 句）+ **MV 可用度**标注。 |

演进层每一条都可回溯——章名/场景名/地点名直接在 `_raw/*_原文.txt` 里 grep 即可定位原文。后续任何演进（改写、增补、再加工）都在演进层做，`_raw/` 保持原样。

## 五灵珠体系（跨章勘误）
土灵珠（ch03 血池）、雷灵珠（ch05 毒娘子体内）等属五灵珠；**五毒珠是另一体系，勿混**。

## 剧游差异的正确查法
各章档内的「与 05 剧差异」节**不做臆测**——98 版文本内部不含电视剧内容。要做剧游对照，请以 `../plot_tv2005.md`（05 剧剧情与改编差异，独立考证）为准，与本套逐章交叉比对。造型差异另见 `../appearance_ref.md`。
