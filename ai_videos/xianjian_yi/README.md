## 一句话体裁

**ARPG 式一镜到底**——镜头是跟在李逍遥身后的第三人称跟随机位，像玩家操控角色在城里走：
一个地点一条连续长镜走完整座城、整间客栈、整条山道，靠**承接首帧**把镜与镜缝成一条不断的运镜线，
观感上完全看不出接缝。硬切只留给真正该断的地方（换地点/换时间/回忆进出/越轴），
而那些断点通常正好就是集与集的边界。

## 怎么推进

1. 从 `_series/episode_map.md` 取下一集的原作出处与漫游单元。
2. 该集所需的几何若未建，先按「几何清单」建 `_series/scenes/{地点}/_blender/`——
   **先画该地点全部集的长镜路径，再定几何精度**。
3. 按 `ai_videos__全流程编排` 走该集的立项 → 分集细纲 → 剧本 → 分镜 → prompt。
4. 出片前跑 `ai_videos__审查总编排`；改动记 `specs/ai_video/xj{N}/changelog.md`。
