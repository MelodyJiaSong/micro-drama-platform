# 人物网 ·《幽灵撤离》

## 三人小组内部
```
        渡鸦(c1) ──── 带队/负疚 ────► 雏鸟(c3)
           │  ▲                          ▲
    默契/替他说狠话                 保护欲/嫉妒
           ▼  │                          │
        灰隼(c2) ──── 压制与推开 ────────┘
```

- **渡鸦 → 雏鸟**：投射。上一支队伍他弄丢过一个同样年纪的兵，雏鸟是他的第二次机会。所以他对雏鸟**过度保护**，这既是全片的情感线，也是他最后丢掉数据核心的动机来源。
- **雏鸟 → 渡鸦**：仰望 + 想证明自己。他所有的错都出在"想有用"上。
- **灰隼 ↔ 渡鸦**：老搭档。全片零解释的默契——一个眼神换位、一句半截话就懂。灰隼替渡鸦承担"说狠话的人"这个角色（"别管他了"这种话只有她说得出口，也只有她说了渡鸦才会反着做）。
- **灰隼 → 雏鸟**：表面嫌弃、实际最先扑过去替他挡。她不认为自己在保护他，她认为自己在**减少变量**。

## 与虫群的关系
虫群**不是人格化对手**，因此人物网里它不占节点，只占**压力源**。三人对它的态度分层：
- 渡鸦：把它当**地形**——可预测、可绕开、不可战胜。
- 灰隼：把它当**数量问题**——算弹药、算时间、算射界。
- 雏鸟：把它当**怪物**——恐惧的唯一承载者，观众的代入口。

## 与增援的关系
- 舰桥指挥官（画外）↔ 渡鸦：**制度 vs 人**。指挥官关心的是情报和舰船暴露风险，渡鸦要的是三个人。最后指挥官批准闪现——制度让了步，这是"没有人被留在后面"从口号变成事实的一刻。

## 与主题的关系
- 全片主题＝**"带回去"**。三个人各自带回不同的东西：渡鸦带回人，灰隼带回情报副本，雏鸟带回那半秒不该看见的影像。
- **暗线人物**（不出场、只留轮廓）：前哨站三百人 —— 他们没被带回去。这是渡鸦所有行为的背景压力，也是续集的门。
