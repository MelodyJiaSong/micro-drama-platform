# 风格指南 ·《幽灵撤离》

## 总基调
**影视级写实军事科幻** —— 参照《异形2》《明日边缘》《黑鹰坠落》的实拍质感：脏、旧、有重量。不做游戏 CG 观感，不做高饱和英雄光。

## 全片统一渲染样式串（每个 shot prompt 的「渲染样式」字段粘贴此串）
```
真人实拍电影质感 · 军事科幻战争片 · ARRI 大画幅数字摄影机 · 35mm 胶片颗粒 · 低饱和冷调 · 手持微抖与呼吸感 · 真实烟尘与体积光 · 镜头轻微畸变与浅景深 · 装甲金属做旧掉漆与油污 · 生物质湿润次表面散射 · 非完美对称的真实构图 · photorealism 照片级写实 · 不卡通不CG不建模感
```

## 三段色调曲线（按叙事段切换，跨镜一致）
| 段 | 场景 | 光线 | 色调 |
|---|---|---|---|
| 一 · 潜行 | bg1 / bg2 | 行星黄昏、低角度侧逆光、长影 | **脏橙 + 灰褐**，高对比、大片阴影，安静 |
| 二 · 暴露与围攻 | bg3 | 天色转暗、只剩菌毯生物荧光 + 枪口闪光 | **深紫 + 病青**，光源全部来自"敌人"，压迫 |
| 三 · 增援 | bg4 | 引擎白光、探照灯、大和炮柱光 | **冷白蓝 + 火橙**，第一次出现"人族自己的光"，情绪释放 |

> 色调逻辑一句话：**全片的光一直属于虫群，直到增援来了，光才回到人这边。**

## 镜头词典（情绪 → 运镜）
| 情绪 | 运镜 |
|---|---|
| 潜行/悬置 | 缓慢横移轨道镜、低机位贴地、长焦压缩 |
| 发现/惊觉 | 手持急摇 + 变焦推（dolly zoom 只用一次，留给迷彩解体） |
| 围攻/失控 | 肩扛手持、频繁遮挡、画面被虫体扫过 |
| 增援/释放 | 广角仰拍、缓慢升格、稳定器跟随 |
| 收尾/余韵 | 固定机位长镜、景深虚化前景菌毯 |

## 声音基调（供后期 mux）
- 幽灵段：几乎无配乐，只有呼吸、静电通讯、菌毯黏液声。
- 围攻段：低频脉冲 + 虫群嘶鸣的"人声化"处理。
- 增援段：铜管与合成低音进入，**大和炮开火瞬间全频段静音 0.4 秒**再炸开。

## 一致性铁律
- 单位的**锁定描述符**逐字复制，不得改写同义词。
- 同一镜里同一角色**只具名一次**。
- 三名幽灵**全程戴面罩/护目镜**，只有指定的两处摘面罩镜露脸（见人物卡）。
- 机甲与虫体的**体量比**写死：小狗＝齐腰的猎犬体量；刺蛇＝立起后高于机枪兵一个头；监察王虫＝悬空的公交车体量；战列舰＝天上的一座城。
