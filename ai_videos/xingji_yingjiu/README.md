# 《幽灵撤离》— AI 军事科幻概念短片

> 三个隐形的人，在一颗已经不属于人类的星球上，被看见了。

- **task_type**：`ai_video` · **sub_type**：`short`（单片）
- **画幅 / 时长**：16:9 横屏 · 180s（3:00）· 36 shots
- **风格**：影视级写实军事科幻（《异形2》《明日边缘》质感）
- **结局基调**：惨胜 · 带走每一个人
- **定位**：AI 概念短片 · 致敬经典星际题材（同人向，非商业发行）

## 故事一句话
人族三名幽灵特工潜入被虫群同化的殖民星侦察，被反隐形的监察王虫识破，在虫潮合围中撑到增援从轨道砸下来 —— 全员生还，但有些东西被留在了那里。

## 三条读得懂全片的规则
1. **光的归属**：全片的光一直属于虫群与黄昏，直到 shot26 运输机着陆灯压下来 —— 光才回到人这边。
2. **方向语法**：潜行左→右，撤退右→左；bg4 的虫潮永远从画面左侧坡口来。
3. **大和炮只有一发**，在 shot32。它不是武器，是"有没有人来救我们"这个问题的答案。
