# ch12 · 巫后青儿 · 身世揭晓

> 流程位置：全剧第三幕（终幕）前半 — 蜀山锁妖塔崩塌之后，主角一行南下大理苗疆；于**女娲神殿**触发「回魂仙梦」，回到**十年前的南诏国**亲历巫后青儿的最后时日，再返回现世直取南诏王宫（拜月教总坛）。

### 场 1 · 圣姑家 —— 产女之后，母亲身份先于身世到来

**场景描写**
苗疆白苗聚落中的一间吊脚木屋，属白苗圣姑所有。此地位于大理城外围山地，与大理城之间有可来回的山路（一个在贴吧被反复问到的走法问题，说明两地在地图上是分开的两块，需要走出城再走回山寨）。屋内是苗家药婆的陈设：草药、蛊罐、供台。相对于外面大理城正在经历的**大旱**——赤地、龟裂、井枯、黑苗压境——圣姑家是全章唯一带「体温」的安全屋。

**人物出场描写**
- **赵灵儿**：刚在锁妖塔劫后产下女儿李忆如，身体极虚，只能卧床，因此在游戏机制上**暂时离队**。这是全剧她第一次以「母亲」而非「女娲后人」的身份被安置在画面里。
- **李忆如**：初生婴儿。她的存在本身就是「女娲后人代代单传」这条宿命链的下一环——观众此刻还不知道，这条链的代价是什么。
- **圣姑**：白苗族的女性祭司/药师，收留一行人。她后来会托李逍遥去试炼窟取三十六只傀儡蛊（游戏中期最著名的支线任务之一）。

**对白实录**
考证到的确切内容：圣姑收留一行人；灵儿因产后虚弱留在圣姑家养病、暂时退出队伍；圣姑交给李逍遥**两个香蕉**，明说这是下一处迷宫（神木林）必须带的东西。稍后的流程里，圣姑再托付李逍遥去试炼窟**收集三十六只傀儡蛊**。
（存疑：多方攻略只记录了「灵儿暂时离队」「得香蕉」「傀儡蛊委托」这三个事件节点与道具交接，未见对白原文的公开转录，故不作实录还原。）

**事件逐拍**
1. 锁妖塔崩、月如死、水魔兽脱封 → 一行人南下苗疆投奔圣姑。
2. 灵儿在圣姑家分娩，产下李忆如 → 体力透支，卧床。
3. 灵儿离队 → 队伍战力结构改变，逼出下一步「李逍遥必须自己去闯」的叙事动机。
4. 圣姑给香蕉、指路神木林 → 支线钩子落地。
5. （稍后）圣姑委托三十六傀儡蛊 → 引出试炼窟十层与五灵最强仙术。

**转折 / 伏笔**
这一场是全剧的「呼吸口」：把女主角从战斗前线撤下来，让她先当一次普通的母亲。它同时埋下最重的一根钉子——**李忆如的出生，等于宣告女娲血脉的接力棒已经交出去了**；而后文女娲神殿会告诉观众：交出接力棒的那一代，就该死了。灵儿此刻的虚弱不是产后疲劳，是宿命开始收账。

**视觉扩写（创作用，非原作实录）**
吊脚楼半掩的竹帘，外面是干得发白的天光，屋里是一点药炉的暖橘。灵儿侧躺，怀里婴儿睡着；她伸手去碰孩子的脸，手背上蛇鳞状的浅纹一闪即隐。李逍遥背对着门站，手里攥着两根不合时宜的香蕉，肩膀还没从锁妖塔的灰里洗出来。

### 场 2 · 大理城 —— 一座渴死的城，与被煽起来的族仇

**场景描写**
南诏国旧地的大理城，全城笼罩在**旱灾**里。游戏后段的核心矛盾即「大理干旱、黑白苗争斗」，而降雨要靠五灵珠齐聚 + 女娲后人念祈雨咒文才能实现。城中设有**白苗议事厅**——本章的信息中枢，一行人从这里得知取五灵珠的方向，并被指往火麒麟洞。

**人物出场描写**
- **阿奴**：黑苗少女，在神木林一战后正式入队。她是全剧唯一横跨「黑苗 / 白苗 / 中原人」三方的角色，她在场就等于「族仇是可以被跨过去的」这个论点站着。
- **白苗长老们**：议事厅里的一群老者，代表被旱灾逼到墙角的白苗一方。
- **唐钰小宝**：与阿奴一线相牵的中原少年（唐门后人），此段仍在这条线里。

**对白实录**
可溯源的内容：议事厅一段确立了「大理大旱、黑苗压境、须集齐五灵珠祈雨」的目标，随后队伍前往火麒麟洞取土灵珠。
（存疑：白苗议事厅的具体对白未见公开转录；各版攻略均只标注「前往白苗议事厅 → 前往火麒麟洞口」这一动线。）

**事件逐拍**
1. 入大理城 → 目睹旱情。
2. 白苗议事厅 → 得知祈雨须五灵珠。
3. 出城入火麒麟洞 → 战火麒麟 → 得**土灵珠**。
4. 持土灵珠开路 → 前往**女娲神殿**。

**转折 / 伏笔**
「旱」是本章的天气，也是本章的政治：水没了，族群就互相咬。而**能让天下雨的只有女娲后人**——这句设定把灵儿从「一个被追杀的姑娘」抬成了「一个必须被消耗的公共资源」。拜月教主的阴谋之所以能落地，正是因为他先把这口水拿走了（水魔兽 / 水灵珠线）。

**视觉扩写（创作用，非原作实录）**
城门口的水缸底朝天，缸沿一圈白盐霜。石阶上蹲着排队等水的孩子，陶碗磕在石头上叮叮响。议事厅内，白苗长老的银饰在昏光里晃，墙上挂的是干成褐色的稻穗。

### 场 3 · 女娲神殿 —— 跪拜石像，母亲显灵，宿命揭晓（**本章第一高点**）

**场景描写**
女娲神殿是全剧地点链的倒数第二站（女娲神庙 → 南诏王宫），供奉女娲，殿中立有**灵儿娘亲的石像**。这里既是祭祀空间，也是全剧唯一一处「女娲后人的家谱现场」。神殿另设**祭雨坛**，坛边有台座，五颗灵珠（水、土、风、雷、火）各归其位后即可行祈雨大礼——也就是说，这个空间同时承担「认祖」与「救世」两种功能。

**人物出场描写**
- **赵灵儿**：康复后归队，一路击退黑苗人才抵达神殿。她在石像前**跪拜**——这是她全剧第一次以女儿的姿态出现在母亲面前，而母亲只是一尊石头。
- **巫后青儿（显灵态）**：以「母亲的灵魂」/ 女娲之灵显现。可溯源的描述包括「灵儿来到女娲神殿后，见到了她母亲的灵魂」，以及「女娲像显灵，把圣灵珠、圣灵披风和天蛇杖传授给赵灵儿」。她的形象基调——按多方人物评述——是**容貌清丽、端庄大气**的神裔，同时是「一个可怜的女人」：身为女娲后裔，却被自己的丈夫误认为妖怪。
- **李逍遥**：在场见证。对他而言，这一场是「我娶的姑娘到底是谁」的最终答案。

**对白实录**
可溯源的内容按序如下：
1. 灵儿恭敬跪拜娘亲的石像 → 女娲之灵/母亲之灵现世。
2. 显灵者将**圣灵珠**与**圣灵披风**（另有来源并列**天蛇杖**）授予灵儿一行，并明示**接下来的任务十分艰巨**——这是一句「预警」，不是祝福。
3. 女娲后人的宿命在此摊开：这一族**世世代代守护天下苍生，秉承女娲遗志**；**历代女娲后人都背负沉重的命运，代代以身殉道，不得善终**；一旦繁衍后代，就会**褪去神体、灵力慢慢减弱、逐渐衰老，最后灵力衰竭而死**；又因不耐人间浊气，身体会变成蛇身妖形，反被天界与世人污蔑为妖魔。
4. 母亲本人的遭遇作为「宿命的判例」被交代：她被拜月蛊惑下的丈夫当成妖怪；她最终**为了换来和平，牺牲自己封印水魔兽**。
（同场少量直引，仅取来源明确的短句：来源转述女娲之灵授物时「预示着接下来的任务将十分艰巨」。除此之外不作对白直录——各公开来源均为事件转述，未见逐句台词转录，强行还原即为杜撰。）

**事件逐拍**
1. 灵儿康复归队 → 一路杀退黑苗人 → 抵神殿。
2. 灵儿跪拜母亲石像 → 触发显灵。
3. 授物：圣灵珠 / 圣灵披风 / 天蛇杖 → 战力与身份同时升级。
4. 宿命说明：单传 → 生女即衰 → 蛇身被诬为妖 → 代代殉道。
5. 母亲的判例：被丈夫当妖、被拜月构陷、以身封印水魔兽。
6. **因果落点**：灵儿刚生下忆如 → 她已经站在母亲当年站过的位置上。这一步把「悲情」从外部威胁（拜月）转成内部倒计时（血脉）。
7. 施法送人回十年前取水灵珠（见场 4）。

**转折 / 伏笔**
全剧最大的一次「身世揭晓」。此前灵儿的蛇身只是一个被追杀的理由，此后它变成一份继承来的死刑判决书。同时它把结局提前写死了：**灵儿最后决定「和巫后一样，牺牲自己与拜月教主／水魔兽同归于尽」**——母亲怎么死的，女儿就会怎么死。这一场是整部戏的「宿命闭环」扣上的一声。

**视觉扩写（创作用，非原作实录）**
神殿深处，石像被穹顶落下的一束天光罩住，石像的面容与灵儿有七分像。灵儿膝盖触地的一瞬，殿内所有烛火同时向内一倾。石像眼窝里浮出一层水光，像是石头在流泪；随后光从石缝里渗出来，凝成一个半透明的女人，她抬手要摸女儿的脸，指尖穿了过去。

### 场 4 · 回魂仙梦 —— 把人送回十年前

**场景描写**
承接神殿一场。「回魂仙梦」是一种可以送人**回到十年前**的法术；在《仙剑奇侠传一》中，**赵灵儿的母亲巫后（林青儿）对李逍遥施展此术，使他回到十年前并取回水灵珠**。这一段在攻略里被单独命名为「回梦试炼」，是本章从「听说母亲」跃到「亲眼见到活着的母亲」的机关。

**人物出场描写**
施法者是巫后（以遗念 / 显灵之身）；受术者是**李逍遥**——注意，是他，不是灵儿。（存疑：各来源明确记载受术者为李逍遥；十年前段落的同行队友配置、灵儿是否随行，公开攻略未一致交代。）

**对白实录**
可溯源的内容：巫后施「回魂仙梦」送李逍遥回十年前，目的明确——**取回水灵珠**（凑齐五灵珠祈雨所缺的最后一颗）。
（存疑：施术当场的台词未见公开转录。）

**事件逐拍**
1. 神殿授物毕 → 缺一颗水灵珠。
2. 巫后施回魂仙梦 → 李逍遥被送回十年前的南诏国。
3. 目标：取水灵珠；副产品：亲历母亲之死的全过程。

**转折 / 伏笔**
这是全剧最狠的一次结构设计：**观众要跟着男主角，去看一遍女主角十年后将要重演的死法。** 「取一颗珠子」是任务，「看着岳母怎么死」才是这段的真实内容。

**视觉扩写（创作用，非原作实录）**
石像掌心浮起一枚旋转的水纹符印，符印展开成一圈涟漪，把李逍遥整个人吞进去。画面在涟漪里换季——同一座城，屋顶换成完好的琉璃，街上有人在走动，天是十年前还没干透的天。

### 场 5 · 十年前 · 南诏王宫地牢 —— 母女之外的相认（**本章第二高点**）

**场景描写**
十年前的**南诏城**已被拜月教实际把持：拜月教主是南诏王国**黑苗族大祭司**，名义上是巫王的臣子，**实际上却控制着巫王**。巫后被诬为「亵渎神灵的女妖」，关在**王宫右侧的牢房**里。攻略动线记得很死：**到王宫右方的牢房与巫后娘娘谈话**；而王宫**大殿中间的门可通往地下室**，地下室由**石长老**把守，需要对上口令才能过。

**人物出场描写**
- **巫后青儿**：手上带着**镣铐**（一处人物评述明确写到「手带镣铐的巫后被押了上来」这一处刑画面）。她的形象是「容貌清丽、端庄大气」的神裔女子，此刻却以囚徒之姿出现。她在游戏机制上会**入队**，与李逍遥同行；到水底迷宫之后**永久离队**。
- **李逍遥**：十年前的闯入者。他知道结局而她不知道——这是这场戏所有张力的来源。
- **石长老**：地下宫殿的守护者，掌口令。
- **巫王**：南诏国君，巫后的丈夫。听信拜月谗言，**逼皇上下令杀死巫后**的记载即指向他被操纵后签下的这道命令。

**对白实录**
按可溯源的先后顺序转述：
1. 李逍遥摸到王宫右侧牢房，**与巫后娘娘交谈**。
2. 巫后从他口中**得知自己的女儿正被追杀**——这是关键的一击。她原本已经准备好赴死（宿命 + 政治双重判决），但一听说女儿还活着且在被追杀，态度立刻变了：**她不打算白白牺牲**。这句转折是本场的心脏：一个已经认命的人，因为「孩子还在外面」而重新要一个「死得有用」的死法。
3. 她说明条件：**必须有天蛇杖才能施法**。
4. 她告知天蛇杖的下落——**天蛇杖被锁在地下宫殿里**，并**告诉李逍遥通过地下宫殿守护者石长老的方法**（口令）。
5. 李逍遥依言下地下室，对石长老说出口令，得以通行。
（同场不作台词直引：公开来源均为转述，未见逐句原文，直引即为编造。上述五拍的内容、态度与因果均可溯源。）

**事件逐拍**
1. 李逍遥入十年前南诏城 → 发现王宫已是拜月的地盘。
2. 摸进王宫右侧牢房 → 见到活着的、戴镣铐的巫后。
3. 告知「你女儿还活着，正被追杀」 → 巫后由认命转为「要死得值」。
4. 巫后提出唯一条件：天蛇杖。
5. 巫后交出情报：天蛇杖锁在地下宫殿，守护者石长老，附通关口令。
6. 巫后入队 → 母亲第一次成为「可操作的同伴」。

**转折 / 伏笔**
这是全剧唯一一次**女儿的处境反过来改写母亲的选择**。也是「代代殉道」这条链上唯一一次有人主动拧了一下方向：她不是拒绝死，她是拒绝**白死**。这个选择直接生成了后面水底迷宫的封印，也生成了十年后灵儿手里那颗水灵珠。**结构上，母亲在十年前救的是十年后的女儿。**

**视觉扩写（创作用，非原作实录）**
牢房只有一线高窗，光是斜的，落在地上一条长方。镣铐链子拖过石地的声音先到，人后到。她抬头时，先看清的是这个陌生年轻人腰上的剑穗——十年后她女儿会给同一个人系上同样的东西。她问「外面」，他答不出来；等他说出「你女儿还活着」，她扶着栏杆的手指一根一根收紧。

### 场 6 · 十年前 · 地下宫殿 —— 石长老与天蛇杖

**场景描写**
南诏王宫**大殿中间的门**通往地下室；地下宫殿是南诏国的祭祀腹地，**祭坛**即设于此（十年后的终局对决也发生在「南诏城的地下宫殿祭坛」——同一个空间，用了两次）。**天蛇杖被锁在这里**，守护者是**石长老**，需口令方能通过。

**人物出场描写**
- **石长老**：地下宫殿守护者，形象与职能都是「门」——他不是敌人，是一道需要正确口令的锁。
- **巫后**：随队。这是她第一次以「同行者」而非「囚徒」的身份走在自己的王宫里。

**对白实录**
可溯源的内容：巫后事先把「通过石长老的方法」（口令）告诉李逍遥；李逍遥凭口令通过；取回天蛇杖。
（存疑：口令具体文字与石长老的问答台词未见公开转录。）

**事件逐拍**
1. 自大殿中门下地下室。
2. 遇石长老 → 报口令 → 放行。
3. 深入地下宫殿 → 取得**天蛇杖**。
4. 天蛇杖到手 → 巫后具备施封印之法的条件。

**转折 / 伏笔**
天蛇杖是一件把「巫后」与「灵儿」焊在一起的道具：十年前它让母亲封住了水魔兽；十年后女娲神殿的显灵又把**同一根杖传给了女儿**（98版记为「女娲像显灵，把圣灵珠、圣灵披风和天蛇杖传授给赵灵儿」）。道具的传递路径 = 宿命的传递路径。

**视觉扩写（创作用，非原作实录）**
地下宫殿是青黑石，柱身盘着蛇纹；石长老像是从柱子里长出来的一块。天蛇杖被四道石环锁在祭坛正中，杖首是一个蛇头，蛇眼是一颗未点亮的珠。巫后伸手去握的时候，杖身从底到顶亮起一线水色。

### 场 7 · 十年前 · 水底迷宫 —— 封印水魔兽，母亲永久离队（**本章第三高点，全章情绪落点**）

**场景描写**
水底迷宫是十年前段落的终点。攻略对这段的描述是**「边战边向前逃到迷宫尽头」**——不是打赢，是**逃**。这个动词定了整场的调子：这不是一场胜仗，是一次代价高昂的撤退。

**人物出场描写**
- **巫后青儿**：本场的主角。她在此**永久离队**——游戏机制上的「永久离队」，在剧情上就是死。
- **水魔兽**：拜月教主豢养的巨兽，特性是**遇水不死**；后来与拜月教主**合体**。它是本章一切灾祸（旱、族仇、追杀）的物理根源。
- **李逍遥**：唯一的见证者，也是唯一会把这段记忆带回十年后的人。

**对白实录**
可溯源的内容：巫后**为了换来和平，牺牲自己封印水魔兽**；她原本「不打算白白牺牲」，条件（天蛇杖）达成后，便以此完成封印；一行人边战边逃出迷宫，**巫后自此永久离队**；李逍遥携**水灵珠**返回现世。
（存疑：诀别当场的台词未见公开转录。多方来源一致的只有「牺牲自己封印水魔兽」这一事实与其动机「为了换来和平」。）

**事件逐拍**
1. 天蛇杖到手 → 直奔水魔兽所在。
2. 巫后施法封印水魔兽 → 以自身为代价。
3. 封印成立 → 环境崩坏 → 边战边逃向迷宫尽头。
4. 巫后永久离队 → 十年前的线在此断掉。
5. 李逍遥带**水灵珠**回到现世 → 五灵珠齐。

**转折 / 伏笔**
这一场把全剧的因果彻底闭合：
- 巫后封住的水魔兽，正是十年后**锁妖塔崩塌时脱封**的那一只——母亲的封印，被女儿的牢笼倒掉时放了出来。
- 母亲死于「封印水魔兽」，女儿最终也**「决定和巫后一样，牺牲自己与拜月教主同归于尽」**。
- 母亲留下的水灵珠，成了女儿祈雨救大理的最后一块拼图——**母亲的死，是女儿救世的原料**。

**视觉扩写（创作用，非原作实录）**
水底迷宫的顶是一整片倒悬的水面，光从上面漏下来，像在深井里看天。封印成的一刻，水色由墨转白，从杖首一圈圈推出去；巫后的身影在那圈白里越来越淡。李逍遥被水推着往后退，最后看见的是一只松开的手，和手心里那颗慢慢浮起来的水灵珠。

### 场 8 · 拜月教主 —— 阴谋浮出水面

**场景描写**
拜月教的权力中心在**南诏城的地下宫殿祭坛**（终局对决地）。通往那里要经过**无底深渊**。同一座地下宫殿，十年前锁着天蛇杖，十年后坐着这位教主——空间的重复使用本身就是叙事：**他一直坐在这个国家的地基上。**

**人物出场描写**
- **拜月教主**：**拜月教的教主、南诏王国黑苗族大祭司**；**名为巫王之臣子，但实际上却控制着巫王**。他是游戏最终 BOSS，**豢养水魔兽企图称霸天下，最终被赵灵儿封印**。
  思想上，他被公认为全系列最特殊的反派：他不为财色权，他要的是**真理**——多篇评述把他概括为「相信科学」的那一个（与李逍遥「相信爱」、剑圣「相信道」对照），其极端追求折射的是「人类对于未知事物的好奇心与征服欲之间微妙而又复杂的联系」。
  经典台词（经搜索摘要间接引用，来源：知乎专栏 p/397238427）——信仰崩塌一刻他说：「这些，我也曾经拥有过、曾经得到过，只是我，只是我放弃了。」
- **巫王**：南诏国君、巫后之夫。被拜月操控；在拜月的蛊惑下**认为巫后是亵渎神灵的女妖，逼皇上下令杀死巫后**。终局时与拜月一同成为对决对象。
- **水魔兽**：拜月豢养的巨兽，**遇水不死**，最终与拜月**合体**。

**对白实录**
可溯源的阴谋链条（按因果顺序转述）：
1. 拜月身为黑苗大祭司，**实际控制巫王**，把南诏国变成自己的实验场。
2. 他**豢养水魔兽**，图谋称霸天下。
3. 他的**头号敌人是巫后**——因为女娲后人是唯一能封印水魔兽、能为大地祈雨的力量。
4. 他以「亵渎神灵的女妖」为罪名**陷害巫后**，并**怂恿巫王处死巫后**。人物评述记下的画面是：**手带镣铐的巫后被押了上来**，当众被定为妖魔。
5. 巫后被杀 / 自我牺牲后，他**追杀其女赵灵儿**——这正是灵儿自幼流亡中原、由姥姥带往仙灵岛水月宫避难的原因。
6. 十年后他**挑拨黑白苗族**相斗，并以旱灾为杠杆，逼出最终局面。
7. 终局：他与水魔兽**合体**；败后**不愿相信自己的失败，从桥上跳入水中，沉入水魔兽的尸体**（此细节来自 98 版完整流程攻略的转述）。
8. 最终**被赵灵儿封印**——女儿完成了母亲十年前那件没做完的事。

**事件逐拍**
1. 控巫王 → 2. 养水魔兽 → 3. 除巫后（构陷 + 借刀）→ 4. 追杀灵儿 → 5. 挑黑白苗 → 6. 制造旱灾格局 → 7. 与水魔兽合体 → 8. 被灵儿以命封印。

**转折 / 伏笔**
拜月的阴谋一旦摊开，前面所有看似不相干的事都被串成一条线：仙灵岛为什么藏着一个姑娘、锁妖塔里为什么锁着水魔兽、大理为什么不下雨、黑白苗为什么互相咬。**他不是在这一章才出现的反派，他是这十六年的作者。**

**视觉扩写（创作用，非原作实录）**
祭坛四周点着一圈冷白的月纹灯，他背对着来人，面前是一具巨大的、仍在缓慢呼吸的兽形轮廓。他转身时不怒不喜，像在核对一个演算结果。跳水那一下没有嘶吼，只有一个人平静地走完了自己的逻辑。
