# ch03 · 返回余杭 → 苗人劫岛 → 再遇灵儿

> **流程位置**｜本章接 ch02（仙灵岛求药·莲池初见·水月宫拜堂）之后，止于李逍遥与赵灵儿离开余杭镇启程南下。维基百科《仙剑奇侠传（游戏）》条目给出的全流程地点顺序是：**仙灵岛 → 余杭镇 → 苏州 → 隐龙窟 → 白河村 → 扬州 → 京城 → 蜀山仙剑派 → 锁妖塔 → 大理 → 苗疆**。本章即「仙灵岛 → 余杭镇」到「余杭镇 → 苏州」之间的全部戏，是全作从「市井少年梦」翻进「宿命流亡」的转轴章。
>
> **版本口径**｜以 1995 DOS 原版为主线。1998《仙剑奇侠传 98 柔情篇》的差异一律以「98版差异：」行内标注。凡未考证到确切细节的，一律写「（存疑：…）」，不脑补成实录。

## 二、场景志

### S3-1 · 离岛归航：一碗药，一段被拿走的记忆

**1｜场景描写**
仙灵岛外的水面。岛在身后，是一座被雾气托着的孤峰式仙岛——入岛的路是先穿峡谷、再钻洞窟水路，然后才层层展开莲花池、桃树林与水月宫（岛内空间结构见 `scenes_source.md` §2）。所以「离岛」这一程在视觉上是**倒着走一遍那条路**：先从桃粉与素白的宫前退回幽蓝的洞窟水道，再从洞窟口一头钻出，眼前豁然是灰白的开阔水面。天光偏冷，雾没散，岛的轮廓在船尾越缩越小。船是江南水乡常见的乌篷小船／舢板，逍遥自己划来的那一条。船板上放着从姥姥处求得的灵药。声音只有桨声、水声与远处水鸟。

**2｜人物出场描写**
李逍遥：余杭县盛渔村客栈的店小二，**仙剑一开篇时年十九**（腾讯新闻《仙剑1剧情结束后诸人后续与结局》一文明载），穿的是干活的短打／布衣（游戏立绘中一身少年侠客的轻便装束，具体形制见 `appearance_ref.md`）。此刻他身上有刚经历过闯岛、破阵、被逼成亲一夜的疲惫与恍惚。他回头望岛的那个动作——**是全作最要紧的一个「回头」**：这一眼之后，他脑子里的仙灵岛就没了。
> **本章必须先立住的一条身世反讽**（腾讯新闻同源）：李逍遥的父母**李三思与葛巧菱，当年正是被拜月下毒暗算而死**，他才由婶婶养大。也就是说——本章里把仙灵岛屠尽、把他记忆抹掉的那股势力，正是他自己的杀父杀母仇人，而他一无所知。这条线在本章不揭，但只要观众知道，S3-5「苗人坐在他家客栈里、他还笑着给人斟酒」那一拍的分量就完全不同。

**3｜对白实录**
本场基本无对白；若有，也是逍遥独自划船时的自语。（存疑：多方来源均只叙述「离岛后失忆」这一结果，未见离岛船上有可考的具体对白。）

**4｜事件逐拍**
1. 逍遥从姥姥处取到能治婶婶病的灵药，被送离仙灵岛。
2. 归途中／离岛前后，他关于仙灵岛的记忆被抹除。
3. 抵岸时，他只剩「我出海取到了药」这一条干净的因果，中间那一整段——莲池边的少女、水月宫的许愿、烛下被逼着拜的那个堂——全部消失。

**记忆被抹除的成因：两说并存（重要考证分歧）**
- **甲说（忘忧散·姥姥所为）**：姥姥怕尘缘耽误灵儿的女娲族宿命，在逍遥离岛时令其服下「忘忧散」，抹去他在仙灵岛的全部记忆。维基百科《仙剑奇侠传（游戏）》条目在叙述后段剧情时确有「**忘忧散失效**让李逍遥想起对赵灵儿在仙灵岛的承诺记忆」一句——可确证游戏中「忘忧散」这味药确实存在，且它就是失忆的直接载体。
- **乙说（黑苗下药）**：维基百科《李逍遥》条目原文作「返回渔村后，李逍遥**因黑苗族下的药而失忆**」；《赵灵儿》条目亦称「李逍遥求药**被拜月教利用**，破阵后记忆尽消，导致水月宫遭灭门之灾」。按此说，失忆发生在**回到余杭之后**，是黑苗／拜月教在客栈对他下的手，目的是拿走他脑中那条「通往仙灵岛的路」并抹掉痕迹。
- **本库取舍**：两说都可溯源，且并不完全互斥（「忘忧散」这味药可以由任一方施用）。**分镜建议按乙说排序**——因为乙说能解释「苗人为什么找得到仙灵岛」（逍遥破阵在先、被利用在后），也能解释「灭门之灾」的因果链；甲说则更适合作为情绪层的解读（姥姥的私心）。**凡剧本要写这一拍，必须二选一并在文档里标注取的是哪一说**，不要把两说混着写。

**转折/伏笔**
这是全作前半所有误会与虐点的总闸门：**他忘了，她记得**。也是后段「忘忧散失效、记忆回潮」那一拍的埋线——记忆不是被毁掉，只是被压住了。

**视觉扩写（创作用，非原作实录）**
- 一个「记忆被抽走」的可视化：船尾水面上岛的倒影先于实岛消失／碎散。
- 逍遥手按额角、桨停了一拍，随即若无其事继续划——观众知道刚刚发生了什么，他不知道。
- 色彩由岛上的桃粉+素白，一格一格褪成归途的灰青。

### S3-2 · 余杭镇渡口靠岸（98版：阿奴在此提前登场）

**1｜场景描写**
余杭县盛渔村的临湖码头／渡口。江南水乡形制：青石板街、白墙黛瓦、木构两层客栈，镇口有山神庙，码头泊着乌篷小船，木栈桥伸进水里（空间结构据 `scenes_source.md` §1，源自关卡分析与攻略摘要）。时段宜取清晨或近晚——晨雾湿润的江南光，暖黄灯笼配青灰瓦与木褐，水面反光柔和。声音是市集的人声、橹声、鸡犬声——**和仙灵岛的静谧仙气形成硬对比**，这是本章第一个重要的「回到人间」的听觉转场。

**2｜人物出场描写**
逍遥抱着药包跳上栈桥，脚步是急的——他心里只有「婶婶还等着这副药」。他从雾里走进烟火气里，身上还带着岛上的水汽。

**98版差异：阿奴提前登场——⚠ 本条未获直抓来源证实，标为高度存疑。**
- **传闻内容**：98 柔情版把苗族少女阿奴的首次出场**从苗疆一线前移到余杭镇码头**，即逍遥第一次从仙灵岛回来时就与她照面。此说见于 98 版流程攻略与版本对比文章的搜索摘要，**属经搜索摘要间接引用**（另见既有研究档 `plot_game.md` §四.4）。
- **反证（重要）**：维基百科《阿奴》条目明确记载，她「**初登场在于圣姑附近的神木林与李逍遥碰面**」，当时「以为李逍遥为偷蛋贼」（对应逍遥为灵儿安胎寻凤凰蛋壳的一线），之后与逍遥同寻水灵珠、在桃花村打败木道人。**该条目未提及任何余杭镇码头的提前登场**。
- **本库结论**：本次可直抓来源**无一支持**「阿奴 98 版余杭码头登场」；正典登场点是苗疆·神木林（圣姑一线）。**剧本若要用余杭码头那一版，必须先另行考证坐实，否则视为不可用**。已列入本章 gaps。
- **顺带更正一条流传甚广的错误**：阿奴**不是黑苗蛊后之女**。维基条目载其身份为「**白苗少主、南蛮王之女、白苗族长**」，后为海棠夫人、巫月神教掌门，「爱慕李逍遥」且终身未嫁；性格「刁钻活泼」、「外表一派天真烂漫」，但「施用巫术毒蛊的手段，却叫人毛骨悚然」，游戏中把逍遥耍得团团转。既有研究档 `plot_game.md` §七将其写作「黑苗蛊后之女」，**应以维基条目为准更正**（族群色对照见 `scenes_source.md` §8：白苗银饰彩绣 vs 黑苗玄衣——阿奴属**银饰彩绣**一侧，不是玄衣）。

**3｜对白实录**
（存疑：95 版此处未考证到对白；98 版阿奴码头一节的具体对白亦未取到可靠原文，仅确认「登场时机前移」这一事实。）

**4｜事件逐拍**
1. 小船靠岸，逍遥上栈桥。
2. 穿过码头集市回客栈。
3. （98版）与阿奴打了个照面／起了点小摩擦。

**转折/伏笔**
码头是本章的「门」：逍遥两次跨海都要经过它——第一次带着药回来，第二次带着灵儿回来。同一个机位拍两遍，情绪完全不同，是 MV 极好用的对位点。

**视觉扩写（创作用，非原作实录）**
- 同机位两拍：①晨雾中少年抱药包快步上岸（暖）；②后来同一栈桥上，他扶着一身狼狈的白衣少女下船（冷）。
- 阿奴登场可给一个「格格不入的颜色」——江南的青灰木褐里，突然一点苗银的冷亮与彩绣的浓艳。

### S3-3 · 李家客栈·婶婶服药，沉疴痊愈

**1｜场景描写**
李家客栈内。前堂是木柜台、酒坛、条凳方桌；后头是木楼梯、客房、后院（结构据 `scenes_source.md` §1）。婶婶李大娘的病榻在内间／楼上厢房，窗小光暗，屋里有久病人家的那股药味与闷气。一盏油灯或一线窗光落在榻上。色调：木褐、青灰，一点灯的暖橘。

**2｜人物出场描写**
李大娘（婶婶）：李逍遥自幼父母双亡，是她一手带大的；她经营这间客栈，**积劳成疾**才病倒（维基条目原文即「因婶婶积劳成疾，前往仙灵岛求药」）。此刻她在榻上，形容枯槁、气力不济。（存疑：她「早年江湖人称铁掌飞凤」的设定见于既有资料整理 `plot_game.md`，本次未在可直抓来源中复核到，标为待考。）
逍遥进屋的方式：撞门／小跑进来，把药举到她面前，一路上憋着的那口气到这里才泄。

**3｜对白实录**
这场是一来一往的家常对话，不是宣言。**转述**：逍遥急着报喜，说药求到了、是仙灵岛上的仙人给的；婶婶起初半信半疑，更多的是心疼他一个人跑那么远、下海犯险，嘴上要数落，眼里是担心。药服下之后病势见好，婶婶的态度从担忧转成后怕与庆幸。（存疑：本场具体逐句台词未考证到可靠原文，以上为依据「求药—服药—痊愈」这条已确证的事件链所作的**内容转述**，不作台词实录使用。）

**4｜事件逐拍**
1. 逍遥把灵药交给婶婶／煎好端上。
2. 婶婶服药。
3. 病愈——这是逍遥闯岛、破阵、被逼成亲这一整趟的**唯一目的达成**。
4. 家里恢复了日常：客栈重新开门做生意。

**转折/伏笔**
本场是全章唯一的「圆满」，也是最短的一个圆满。婶婶的病治好了，但**为治这病所付出的真正代价还没到账**：他丢了一段记忆，仙灵岛马上要为此灭门。悲剧的账单是延后寄到的。
另：婶婶在本章末还有一次关键的「下令」（见 S3-11），所以她在这里必须被立起来——她不是背景，她是把逍遥推向苗疆的那只手。

**视觉扩写（创作用，非原作实录）**
- 药碗的热气 / 婶婶接过碗时那只枯瘦的手，与逍遥沾着水渍的少年手掌对照。
- 病愈后第一件事是她下床去擦柜台——一个「这家还在」的画面，专门为后面「这家没了」备下反差。

### S3-4 · 失忆之后的日常：他把最重要的一段活成了空白

**1｜场景描写**
客栈前堂与余杭镇街巷。市井烟火：条凳方桌、酒坛、进出的客人、街上的叫卖。光是白日的平光，热闹、俗气、安全——这一段的调子必须**明确地轻快**，才衬得出后面的塌。

**2｜人物出场描写**
逍遥恢复店小二身份：肩上搭布巾、端菜、算账、跟客人贫嘴，做他那个「当大侠」的白日梦。他身上没有任何「刚成过亲」的痕迹——因为他自己不知道。

**酒剑仙一线**：维基《李逍遥》条目记载，他「**因为给了酒剑仙一壶酒而学了蜀山仙剑派的剑术**」——这条线在余杭客栈这一段是活的：一个落魄的酒鬼常来赖酒，逍遥跟他斗嘴周旋，酒换来了御剑一脉的启蒙。（时序存疑：授艺发生在第一次出海之前还是失忆之后，多方叙述不一；结构上它是「余杭客栈期」的事，本章可以带一笔，也可归入 ch01。）

**3｜对白实录**
**转述**：这一段的对话是市井体——讨酒钱、招呼客人、吹牛说要仗剑走天涯。要害在于**它的"正常"本身就是戏**：观众已经看过仙灵岛那一夜，所以他每一句轻快的贫嘴，听着都像在替谁受着。（存疑：具体逐句台词未考证到可靠原文。）

**4｜事件逐拍**
1. 日子照常过。
2. 逍遥对仙灵岛毫无记忆——**注意分寸：他不是"记不清"，是"整段不存在"**；别人提起仙灵岛，他没有困惑，只有空白。
3. 与此同时，岛上的灵儿在等一个不会主动回来的人。

**转折/伏笔**
这是全章的静默炸弹段。所有「等」的戏都发生在画外（岛上），画内只有他若无其事地过日子——**平行剪辑的天然素材**。

**视觉扩写（创作用，非原作实录）**
- 平行对切：客栈里逍遥笑着给客人斟酒 ／ 岛上灵儿坐在莲池边看水面。
- 一个「差一点想起来」的瞬间：他擦桌子时看见水盆里自己的倒影，愣了半秒，然后被客人一嗓子叫走。（纯创作，非原作实录。）

### S3-5 · 苗人循线摸到余杭

**1｜场景描写**
客栈前堂／客房。夜或黄昏为宜。一群外乡人投宿——**玄黑为主的苗族装束**在江南的青灰木褐里非常扎眼（黑苗玄衣的族群色定义见 `scenes_source.md` §8）。屋里的光收窄，暖黄的灯照不到他们坐的那一角。

**2｜人物出场描写**
- **苗人头领（本章反派，游戏中有独立人物条目，务必当成一个具体的人来写，不要拍成一群面目模糊的黑衣人）**：游民星空《仙剑奇侠传历代人物介绍》「苗人头领」页给出的资料是——身份「**黑苗族使者**」「**拜月教小队长**」；外貌性格「**皮肤黝黑、庸碌粗鲁**」；剧情作为则是「**受命到中原寻找灵儿**」「**利用逍遥破解仙灵岛迷阵**」「**发动血洗水月宫**」，并被该页直接点名为「**杀害姥姥的凶手**」，亦参与掳走赵灵儿。
  - **人物分寸**：他不是那种阴森有魅力的大反派。官方给的形容词是「庸碌粗鲁」——**一个奉命办事、办得很脏很糙的中层执行者**。这反而更狠：毁掉灵儿一生的，不是什么盖世魔头，是一个上头派下来的小队长。这是「宿命」母题里最冷的一笔，MV 若要拍，越是把他拍得平庸，越有力量。
  - **外形锚点**：皮肤黝黑（与江南人的白净成对比）、体格粗壮、动作大而不讲究；黑苗玄衣一系（族群色见 `scenes_source.md` §8）。
- **随行黑苗武装**：一行数人，寡言，目的明确。他们的坐姿、看人的方式、对店小二的态度，都应该和普通客人不一样：**他们不是来住店的，是来找路的**。

**3｜对白实录**
**转述**：交涉的核心内容是「仙灵岛怎么去」。逍遥是唯一去过、并且**破过岛外迷阵**的人，因此是他们唯一的钥匙。这条因果链现已由两处来源坐实：游民星空「苗人头领」页写明其作为是「**利用逍遥破解仙灵岛迷阵**」，维基《赵灵儿》条目写作「李逍遥求药**被拜月教利用**，破阵后记忆尽消，导致水月宫遭灭门之灾」。也就是说——**他破的那个阵、他走通的那条水路，就是敌人上岛的通道**。
（存疑：具体是「先套问、再下药灭迹」还是「先下药、再由苗人循其路径上岛」，各来源叙述详略不一；本场逐句对白未考证到可靠原文，以上为事件层转述。）

**4｜事件逐拍**
1. 苗人头领（黑苗族使者／拜月教小队长）**受命到中原寻找灵儿**，一路查到余杭。
2. 锁定李逍遥——中原唯一破过仙灵岛迷阵的人。
3. **利用他破解仙灵岛迷阵**（问路／取其路径／借其已破阵的既成事实）。
4. 下药：按乙说，逍遥的失忆在此发生（维基《李逍遥》条目：「返回渔村后，李逍遥因黑苗族下的药而失忆」）。
5. 苗人离开余杭，直扑仙灵岛。

**转折/伏笔**
**因果闭环在此扣上**：逍遥为救婶婶闯的岛、破的阵，反过来成了灭岛的引路。这是全作「宿命」母题的第一次现形——**他做的每一件好事，都在给灾难铺路**。MV 若只取一个「宿命」意象，这一拍比后面任何一场大场面都更准。

**视觉扩写（创作用，非原作实录）**
- 苗人放在桌上的东西（一枚苗银饰、一柄短刃、一只蛊罐）作为「异质物」入画。
- 酒碗特写：碗沿的一圈光晕微微变了色——不点破，只让观众心里咯噔。
- 他们走后，桌上留下的银钱比该付的多——多得不正常。

### S3-6 · 再赴仙灵岛：同一条水路，第二次走

**1｜场景描写**
湖／海面 → 岛外洞窟水路。第一次走这条路时，洞窟是「奇观」：幽蓝钟乳石、水面倒影、未知的仙气；**第二次走，它是「甬道」**——同样的幽蓝，读出来的是压迫。若时间上苗人已先到，水面上可以有先行船只的痕迹（船影、油迹、漂浮物）。

**2｜人物出场描写**
逍遥再度出海。**关键表演分寸**：他不是「重返故地」，他是**第一次来**——因为记忆没了。所以他脸上不该有怀旧、不该有近乡情怯，只该有任务感与陌生感。这个错位是本章最难演也最值钱的一层。
（存疑：他第二次上岛的**直接动机**未考证到确切说法。可查证的只有结果——他在岛上遇到姥姥临终、并被托孤。常见叙述包括「受托／循苗人踪迹／再去道谢或送还物件」等，均未取到可直抓的原文佐证，剧本若要写这一拍须自行择一并标注为创作补足。）

**3｜对白实录**
（存疑：未考证到本场对白。）

**4｜事件逐拍**
1. 逍遥出海。
2. 穿峡谷、入洞窟水路。
3. 出洞——眼前不再是桃花与莲池。

**转折/伏笔**
「同路二次走」是本章的结构脊梁：**去时求药，回时忘人；再去时救人，回时带人。** 四趟水路把整章串成一个闭环。

**视觉扩写（创作用，非原作实录）**
- 洞窟出口的光作为分界：光的那头，上一次是仙境，这一次是浓烟。
- 第一次与第二次同一机位的水路镜头做叠化，色温从蓝青转向灰褐。

### S3-7 · 仙灵岛陷落：水月宫遭灭门之灾

**1｜场景描写**
这是本章的灾难现场，也是全章最需要「把美的东西打碎」的一场。仙灵岛原本的层次是：入岛水路 → 莲花池／灵池 → 桃树林 → 水月宫道观（素雅宫观、供奉女娲，见 `scenes_source.md` §2；关卡分析摘要形容岛上「鸟语花香，动态的鱼和蝴蝶」）。劫岛之后，每一层都要给出对应的破坏读数：
- **莲池**：水面浮着断茎残叶，池水浑了；原本的碧色被搅成泥色。
- **桃林**：花瓣不再是「花瓣雨」，是被踩进泥里的；树干有刀劈的白茬。
- **水月宫**：素白的观宇上有烟熏的黑、有断裂的梁柱；供奉女娲的神像（人首蛇身）或倾或损。
- **光与声**：原本的柔光薄雾换成烟色的浑光；鸟声鱼跃换成火声、兵刃声、脚步声，然后是更可怕的——**安静下来之后的余烬声**。

**2｜人物出场描写**
- **黑苗武装**：玄衣、成队、持械，行动是「清扫」式的，不是决斗式的。他们要的是女娲后人，不是打赢一场架。
- **姥姥（本章最被低估的角色，务必按游戏设定改写，勿沿用剧版慈祥老太印象）**：游民星空《仙剑奇侠传历代人物介绍》「姥姥」页给出的官方人设原文是——「**肥胖的凶恶老妇，十年前拼死保护少主逃出苗疆，强悍的苗族女豪杰，为防追兵，以药物改变自己的声音、容貌、体态，世间难寻的忠仆**」。这段话一次性推翻了三个常见误读：
  - ① 她**不是灵儿的血亲祖母**，是巫后（林青儿）身边的**侍女／忠仆**，「姥姥」只是灵儿从小的叫法（游民星空页与腾讯新闻互相印证）。
  - ② 她**不是慈眉善目的老太太**，官方定性是「肥胖的凶恶老妇」「强悍的苗族女豪杰」——**她本人就是个能打的苗人**。所以 S3-7 的抵抗不是老弱受戮，是一场硬仗；她被杀，是因为对方人多且有备而来。
  - ③ **她这张脸是假的。** 为躲追兵，她**用药物改了自己的声音、容貌、体态**——也就是说观众看到的这个胖老妪，是一个苗疆女豪杰十年伪装的结果。这条设定给分镜一个极强的可视化机会（见本场视觉扩写）。
  - ④ **时间线**：官方原文作「**十年前**拼死保护少主逃出苗疆」。灵儿今年十六，故她不是抱着婴儿上岛，而是**带着一个约六岁的孩子逃出来**、在孤岛上守了十年。（既有研究档与本文早稿里的「带婴／十六年」表述据此更正。）
  - ⑤ 剧版（2005）把她拍成清瘦持杖的慈祥老妪（见 `appearance_ref.md` §9），与游戏官方人设**不一致**。本 MV 若走游戏口径，须按「肥胖、凶悍、苗人底子」重做；若走剧版口径，须在文档里注明取的是剧版。
  - ⑥ 另注：游民星空该页称灵儿的生母实为《仙剑三》的紫萱——这是系列跨代的追溯设定，**仙剑一本篇口径下灵儿的母亲是巫后·林青儿**，本章不采用跨代说。
- **灵儿**：十六岁、身高 162、体重 48（游民星空「赵灵儿」页数据），随姥姥隐居岛上，设计上被赋予「莲花不染纤尘般的气质」（维基条目原词）。该页官设原文点出了本场最要紧的一层：她「自幼与世隔绝……跟随姥姥隐居仙灵岛修炼，**躲避仇人的追杀**。难以告人的神秘身世，让她逃不过命运的捉弄，注定在滚滚红尘中历尽千灾万劫」——**也就是说，这座岛从来就不是家，是藏身处；今天只是藏不住了**。
  - **她会打，而且带兵器**：官方资料明载灵儿的**兵器是双剑**。所以劫岛这一场不该把她拍成只会尖叫躲藏的花瓶——她应当拔剑，应当挡在姥姥身前或身后，然后**被压倒性的人数与武力打垮**。「徒劳的抵抗」比「全然的无助」更痛，也更符合她后段那种「明知不敌仍要挡」的性格底色。
  - **她这辈子第一次见血，就是在自己家里。** 另据腾讯新闻同文，灵儿的父母「均为拜月所害」——这层身世本章不揭，但下手的与当年害她父母的是同一股势力。

**3｜对白实录**
（存疑：劫岛交战过程中的具体对白未考证到可靠原文。可确证的只有事件层：条目原文称水月宫「遭灭门之灾」、赵灵儿「被掳走」，以及「在苗人利用设计下，姥姥身故」。）

**4｜事件逐拍**
1. 苗人头领带队，循逍遥破开的迷阵上岛。
2. **血洗水月宫**——游民星空「苗人头领」页原词即「发动血洗水月宫的行动」；维基《赵灵儿》条目作「水月宫遭灭门之灾」。两处措辞都指向**屠尽**，不是「打了一架」。这一层务必拍准：仙灵岛不是被攻陷，是被清空。
3. 姥姥迎战。她是苗族女豪杰出身、岛上唯一能打的人，但对方是有备而来的成建制武装。
4. 姥姥重伤——**苗人头领是直接凶手**（该页原文点名「杀害姥姥的凶手」）。
5. 灵儿被掳走（《赵灵儿》条目原文）。

**转折/伏笔**
仙灵岛不只是一个地图——它是灵儿「作为一个女孩」的全部世界（十六年、一座岛、一个亲人）。岛毁＝她的少女时代被一次性抹掉。此后她所有的「懂事」「不说破」「隐忍」，根都在这一天。

**视觉扩写（创作用，非原作实录）**
- 一组「同景别对切」：ch02 的莲池初见 ／ ch03 的莲池残荷，机位不动，只换内容。
- 女娲神像的一只手断落在阶前——伏笔女娲族的宿命本身也在这一天开始崩。
- 蝴蝶：岛上原有「动态的鱼和蝴蝶」，可让一只蝴蝶从烟里穿过，落在灰烬上。

### S3-8 · 姥姥临终托孤：把灵儿交到一个不记得她的人手上

**1｜场景描写**
水月宫前的石阶／殿内。烟未散，光是斜的、脏的。地上是打斗后的狼藉。空间关系要写死：**姥姥在低处（伤重伏地／倚柱），灵儿跪在她身侧，逍遥站在稍远处**——这个「远」很重要，他在情感上确实还是个外人。

**2｜人物出场描写**
姥姥：气息已断续，仍要把话说完。她这十六年的差事就是护住女娲这一支的血脉（她本是巫后的侍女，受托带婴上岛），此刻差事办砸了，她只剩最后一件事能做——**指定下一个护住灵儿的人**。表演上不该是慈祥老人的煽情告别，而应是**一个办事人在最后一刻做交接**：语速偏快、内容偏硬（去哪、找谁、交给谁），情绪压在底下。
灵儿：白衣上沾了灰与血，头发散了，整个人是懵的。她的世界在一天之内塌了两层：家没了，最亲的人要没了。

**3｜对白实录**
可确证的事件层是：**姥姥身故，临终将灵儿托付给李逍遥**（维基《仙剑奇侠传（游戏）》条目原文）。
**转述**：姥姥把灵儿的手交到逍遥手里，要他答应护她周全；同时把去向指明——去南诏（苗疆）找灵儿的生身母亲。逍遥当场应下了。（存疑：托孤的逐句台词未考证到可靠原文；姥姥是否在此刻当面点明「你们已成亲」或点明灵儿的女娲族身世，亦未考证到确切说法——**这一点对剧本极关键，须标为创作择定项**。）

**托孤这句话里藏着的三重信息（皆有据可查，编剧务必知道，哪怕不全说出口）**
1. **「少主」**——游民星空「姥姥」页原词是「拼死保护**少主**逃出苗疆」。在姥姥心里，灵儿从来不是孙女，是**主上**。她十年来的身份是护主的忠仆，不是养育者。这让托孤的语气应当带着一种奇怪的郑重：**她是在交还一份保管品，不是在交代家务事**。
2. **要去投奔的那个「娘」，处境极坏**——灵儿之母是**巫后·林青儿**：游民星空「巫后（林青儿）」页载其为「女娲族后裔，林业平与紫萱之女，**原为白苗族大祭司**」，「为爱愿以凡人之躯与巫王结连理，成为巫后，**一度平息了黑苗白苗二族的多年纷争**」，但「**遭到阴谋者拜月教主陷害**，最后为了封印水魔兽献身**化为石像**」，灵魂寄居石像上继续守护苗族。维基《李逍遥》条目则称逍遥是去找灵儿「**生死未卜**」的母亲。**两相对照即知：姥姥指的这条路，尽头未必有人在等。**
3. **十年前的逃亡与今天的屠杀是同一件事的两头**——当年拜月陷害巫后，姥姥才带着六岁的少主逃出苗疆、改容改声藏到孤岛；十年后拜月的人找上门，把这十年一笔勾销。姥姥临死时应当很清楚：**她输给的是同一个人。**

**4｜事件逐拍**
1. 逍遥赶到／打退当面的苗人。
2. 姥姥伤重，撑着交代后事。
3. 托孤：把灵儿托付给李逍遥。
4. 姥姥身故。
5. 逍遥应承——**他答应的是一个自己不记得的婚约里的责任**。

**转折/伏笔**
这是整章的**结构核心**：一个失忆的人，接过了一份他不知道自己早就欠下的责任。他以为自己是在做好事（顺手救个小姑娘），实际上他是在**归位**。后段「忘忧散失效、记忆回潮」之所以那么重——重就重在他会发现：**他一直在做对的事，只是不知道为什么对**。

**视觉扩写（创作用，非原作实录）**
- 三只手的特写：姥姥枯瘦的手把灵儿的手推进逍遥的手里；逍遥的手先是本能地缩了一下，然后握住。
- 姥姥断气后，灵儿没有立刻哭——她先看向逍遥，那一眼是「你回来了」；这一眼要在观众心里砸下去，因为观众知道他不认得她。

### S3-9 · 「夫君」归来却被认不出：全章的情绪心脏

**1｜场景描写**
承 S3-8，同一处废墟。此时打斗已停，只剩烟与灰。空间上把两人拉到一个**近而不亲**的距离：她想走近，他没有理由走近。

**2｜人物出场描写**
灵儿：她认得他。对她来说，眼前这个人是她此生唯一拜过堂的人——维基《赵灵儿》条目载，姥姥「强令李逍遥为赵灵儿负责，两人同日成婚并洞房」；对一个十六岁、从没下过岛的女孩，这就是全部的终身。
逍遥：他不认得她。他眼里的她，是一个刚死了亲人、需要人送去南诏的可怜姑娘。他会对她好——**但那是侠义，不是夫妻**。

**3｜对白实录**
**转述**：她唤他、认他，用的是只有那一夜之后才会用的称呼和语气；他的回应是客气的、陌生的、带点手足无措的——他不明白她为什么这样看他，只当她受了惊吓。她试着提仙灵岛、提许愿、提那一夜，他一片空白；她慢慢收住话头，**把最要紧的那句咽了回去**，改口只说请他护送自己去南诏。（存疑：本场逐句台词未考证到可靠原文。上述为依据「逍遥失忆」「二人已成婚」「灵儿随其离岛寻母」三条已确证事实所作的**内容转述**，非原作台词实录。）
> 唯一可直引的、与这段情感直接对位的原作文字，是游戏完结动画中赵灵儿的那首诗——「仙灵岛上别洞天，池中孤莲伴月眠。」（维基百科《赵灵儿》条目引；出现在结局，非本场，仅作 MV 旁白／字幕素材备选。）

**4｜事件逐拍**
1. 灵儿认人。
2. 逍遥不认。
3. 灵儿察觉他是真的忘了（不是装的、不是负心）。
4. 她选择**不说破**——这是她性格的定盘星：宁可自己吞，不肯让他为难。
5. 关系被重新定义为「护送者与被护送者」。

**转折/伏笔**
「他忘了、她记得、她还不说」——**三层叠起来，才是仙剑一前半部所有虐点的公式**。往后每一场逍遥与月如的斗嘴、每一次灵儿的沉默，利息都是从这一场开始算的。

**视觉扩写（创作用，非原作实录）**
- 她伸手要去拉他的袖子，中途停住，改成理了理自己的头发。
- 两人之间的空气里飘着灰；她在灰里，他在灰外。
- 声音设计：把 ch02 洞房那一夜的一记烛花／一声环佩，做成**只有她听得见**的画外音。

### S3-10 · 灵儿被掳与逍遥救人

**1｜场景描写**
（存疑：发生地点未考证到确切说法。）可确证的两条是：《赵灵儿》条目称水月宫灭门后「**赵灵儿被掳走**」，以及「**李逍遥救下被掳的赵灵儿后**，两人决定协助赵灵儿到苗疆寻母」。两条并列意味着**"掳"与"救"之间存在一段押解／追击**，它可能发生在岛上、也可能发生在返程水路乃至余杭一侧。

**2｜人物出场描写**
逍遥在此第一次以「保护者」的身份动手——他的武艺来自酒剑仙那一壶酒换来的蜀山剑术启蒙（维基《李逍遥》条目）。**分寸**：这时候他还不是高手，打法应是少年式的、拼命的、带运气成分的。

**3｜对白实录**
（存疑：未考证到本场对白。）

**4｜事件逐拍**
1. 苗人掳走灵儿。
2. 逍遥追上／截住。
3. 救人成功。
4. 二人决定同行南下。

**转折/伏笔**
这一拍把「托孤的承诺」立刻兑现了一次——承诺不是嘴上说的，是当场用命换的。也为后面漫长的护送之旅定了性质：**这一路是被追着走的**，不是游山玩水。

**视觉扩写（创作用，非原作实录）**
- 救下她的那一刻，两人第一次真正贴近；她本能地抓住他的衣襟，他本能地护住她的头——**身体比记忆诚实**。

### S3-11 · 婶婶之命：去南诏找她娘，顺带提亲

**1｜场景描写**
回到李家客栈。这一场把本章收在「家」里——木柜台、条凳、油灯，和 S3-3 同一空间，但人不同了：多了一个白衣的、无家可归的姑娘。

**2｜人物出场描写**
李大娘：病已痊愈，重新是那个当家的婶婶。她一眼就看出这姑娘的分量。
灵儿：客居他人屋檐，礼数周全，话少。
逍遥：夹在中间，说不清自己和这姑娘是什么关系——因为他确实不知道。

**3｜对白实录**
可确证的是维基《李逍遥》条目原文：他「**奉婶婶之命**与赵灵儿前往南诏找其生死未卜的母亲**提亲**」。
**转述**：婶婶拍板了两件事——第一，这姑娘不能不管，得送她去南诏找娘；第二，既然有了夫妻之实（或按婶婶的江湖规矩：既然把人家姑娘的事担下了），就得**上门向她母亲正式提亲**，把名分办明白。逍遥领命。（存疑：婶婶是从何得知二人成亲之事、以及她的逐句台词，均未考证到可靠原文。）

**4｜事件逐拍**
1. 逍遥带灵儿回客栈安顿。
2. 婶婶了解原委，下令：送她去南诏寻母，并向其母提亲。
3. 二人收拾行装。
4. 离开余杭镇，南下——按维基条目的地点顺序，**下一站是苏州**（林家堡·比武招亲，即 ch04）。

**转折/伏笔**
- 「提亲」这个词是本章最妙的一处反讽：**他要去替一段自己不记得的婚事提亲。**
- 灵儿母亲「生死未卜」（条目原词）为苗疆一线的巫后·青儿埋线。
- 婶婶在此的「下令」，也让她在后段的死变得更重——**是她亲手把逍遥推上这条路的**。

**视觉扩写（创作用，非原作实录）**
- 婶婶塞给逍遥一个包袱（干粮／碎银），又多塞了一样给灵儿的东西——一个「认了这个媳妇」的无声动作。
- 出镇的路口回望：客栈的灯、婶婶的身影、镇口的山神庙——为后段「家没了」的那一场先立好一张全景。

## 四、95 DOS 版 vs 98 柔情版差异（本章相关）

1. **阿奴登场时机——⚠ 未证实，勿直接采用。** 传闻称 98 柔情版将阿奴首次出场从苗疆前移到余杭镇码头（逍遥第一次自仙灵岛归来时）；此说仅见于版本对比文章的**搜索摘要间接引用**。而维基百科《阿奴》条目载其初登场为「**圣姑附近的神木林**」（误认逍遥为偷蛋贼），未提余杭码头。本次可直抓来源无一支持前移说，**故本库判定为待考，剧本采用前须另行坐实**。同时更正流传的族属错误：阿奴是**白苗少主、南蛮王之女**，非黑苗蛊后之女。
2. **画面与演出全面重制**——98 柔情版将人物、场景、迷宫全盘重画，并重制音乐、片头、剧情动画与片尾动画（Windows 化）。本章的仙灵岛陷落、姥姥托孤等段落在 98 版中演出规格更高。
3. **难度与迷宫简化**——维基百科条目载 98 版「降低仙术习得等级与敌方生命值，同时简化了部分迷宫」。对本章的直接影响是**仙灵岛洞窟水路的迷宫复杂度下降**，二次上岛的"路程感"被压缩。
4. **叙事密度**——98 版新增罗刹洞（梦境）等剧情迷宫、扩充最终战，整体叙事更丰满；但这些新增段落均不在本章范围内。
5. **本章事件骨架两版一致**——离岛失忆 → 余杭安顿 → 苗人劫岛 → 姥姥托孤 → 护送南下，这条链在两版中没有结构性差异。

## 五、可用于 MV 的画面记忆点

1. **归航回头**——少年在船尾回望雾中仙岛，岛影先在水里散掉，再在眼里散掉：记忆被拿走的那一秒。
2. **码头两拍对位**——同一座木栈桥：第一次他抱着药包快步上岸（暖光/晨雾），第二次他扶着满身灰烬的白衣少女下船（冷光/阴天）。
3. **药碗与枯手**——婶婶接过药碗，枯瘦的手被热气笼住；全章唯一的暖场，只有一个镜头那么长。
4. **玄衣入江南**——一群黑苗玄衣坐在青灰木褐的客栈角落里，桌上一枚苗银、一柄短刃；灯光照不到他们。
5. **莲池同机位崩坏**——ch02 的碧水白衣，硬切 ch03 的浑水残荷，机位一动不动。
6. **女娲神像断手**——素白道观烟熏成黑，人首蛇身的神像一只手断落石阶上。
7. **三只手托孤**——姥姥的手把灵儿的手推进逍遥的手里；他先缩了一下，然后握紧。
8. **认不出的那一眼**——她在灰里抬头看他，眼里是"你回来了"；他在灰外看她，眼里是"你是谁"。这一组正反打是全章的封面镜。
