# ch01 · 余杭镇 · 盛渔村客栈（开局）

> 流程位置：游戏最开头，从主角清晨被叫醒到首次登船出海（多数攻略归入「第一章／灵岛求仙」前半），外加与之因果闭环的「十里坡山神庙授剑」夜戏 ｜ 版本口径：1995 DOS 原版为主线，98 柔情版差异以「98版差异：」行内标注

## 流程校正（考证结论，与本任务原分工描述不符，下游请以此为准）

原分工把「酒剑仙醉中授剑／御剑术雏形」放在开局客栈段，考证后**不成立**。原作真实顺序是：

1. 开局客栈里，酒剑仙只是个**赖在门口讨酒的醉道士**。李逍遥拿一壶桂花酒给他，他一口灌光——**当场并没有授剑**，只留下一个口头约定：明晚三更，十里坡山神庙见。
2. 婶婶李大娘病倒 → 郎中束手 → 听说仙灵岛有仙药。
3. 出海上仙灵岛、遇赵灵儿、取得紫金丹。
4. 回客栈救活婶婶。
5. **当晚（即约定的「明晚三更」）才走十里坡去山神庙，正式学到御剑术，也才知道那醉道士就是名震江湖的酒剑仙。**

也就是说，「赠酒」与「授剑」被整段仙灵岛剧情隔开，是两场戏、两个地点、两个时段（白天客栈／深夜山神庙）。另外，**山神庙就在十里坡上**——十里坡不是与客栈无关的练级野地，它是客栈通往山神庙的那条夜路。本文件按真实顺序记录，并把山神庙授剑作为本章的收束场（场景九）一并写入，避免下游分镜误把授剑塞进开局清晨。

## 二、场景志

### 场景一 · 清晨的客栈楼上：被吼醒的伙计

**场景描写**
盛渔村在余杭县境内，是个临海讨生活的渔村；客栈就是李大娘一手撑起来的营生，李逍遥自幼父母双亡，就是在这栋房子里被婶婶拉扯大的。客栈是上下两层的木构小楼：楼上是主角自己的卧房和几间客房，楼下是待客的堂屋、柜台和后头的厨房，门口临街。时间是天刚亮的清早，海边渔村的清晨——潮气、鱼腥、灶下刚生起的烟火气。空间关系上，主角从楼上房间出门即是走廊，走廊连着客房，一道楼梯直落堂屋，堂屋往里通厨房，往外通街门；此外客栈里另有一条**密道**（后来夜赴山神庙走的就是它，见场景九）。

**人物出场描写**
- **李逍遥**：少年伙计，还在赖床的年纪与性子。开局形象即「客栈跑堂的半大孩子」，随手就能从房里摸出止血草、木鞋这类零碎家什——说明他房间是那种什么都往里塞的少年人窝棚。（外貌服色的确切考证见「存疑」标注）
- **李大娘（婶婶）**：中年妇人，客栈唯一的当家。出场方式是**声音先到人后到**——一嗓子把睡懒觉的侄儿吼起来。台面上永远是嫌弃、催促、指使的口气，骨子里疼他。多方评述都强调她「嘴上嫌弃、心里紧张」这一体质。

**对白实录**
婶婶开口就是催活儿：店里来了投宿的苗族客人，别躺着了，赶紧下来招呼。语气是那种当家人对不成器晚辈的连珠炮，不容还嘴。李逍遥这边照例是懒洋洋应付、心里嘀咕两句，动作上却还是老老实实爬起来干活——这一来一回把两人的关系一次性交代清楚：**没有一句亲热话，可这就是他俩过日子的方式。**

**事件逐拍**
1. 婶婶在楼下（或走廊）扬声叫人 → 主角被吵醒，游戏交出操作权。
2. 主角在自己房里翻检，可捡到止血草、木鞋等物 → 玩家学会「搜刮场景」这一基本操作。
3. 主角走出房门、下楼 → 进入客栈公共空间，剧情推向客房。

**转折／伏笔**
这是整个仙剑的第一个镜头：一个被婶婶吼醒的、没什么大志向的客栈伙计。它存在的唯一目的，是让后面「他成了御剑飞行的江湖人／他背上了整个天下的因果」显得足够残酷。**开局越平凡，结局越痛。**

**视觉扩写（创作用，非原作实录）**
晨光从木格窗棂斜切进来，照见空气里悬浮的灰尘；少年脸埋在枕头里，被子踢到地上；楼下婶婶的嗓门穿过木地板缝往上钻。窗外能看见半截桅杆与灰白的海。

### 场景二 · 客房：伺候苗人客人

**场景描写**
客栈二楼客房，陈设是渔村小店的水准：一张床、一张方桌、几条凳子，桌上摆着刚送上的酒菜。房里住的是一行**苗族客人**——衣饰、口音都与余杭本地人两样，这是全剧第一次把「异域」摆进画面。

**人物出场描写**
- **苗人客人（含首领）**：苗族装束，与江南渔村的市井气形成强烈对撞。他们是过路的旅人身份，态度谈不上热络，也谈不上恶意；首领在后面的场景七会正式说话并交出关键道具。
- **李逍遥**：端着托盘进屋，伙计的姿态——躬身、赔笑、上菜、退开。

**对白实录**
主角照客栈规矩招呼、上酒菜；苗人客人受用之后**打赏了他一笔钱**（数额各家攻略记载不一，见「存疑」）。整段对白信息量不大，作用是让玩家熟悉「对话—获得物品」的循环，同时把苗人这条线轻轻挂上。

**事件逐拍**
1. 主角进客房招呼客人 → 2. 客人满意，给赏钱 → 3. 主角揣钱下楼 → 4. 婶婶给出下一个差事（赶走门口的醉汉）。

**转折／伏笔**
苗人绝不是路人甲。**他们此刻的和气，和后面把赵灵儿装进麻袋扛走的那一伙，是同一批人。** 开局这场「主仆和睦」的戏，回头看是彻头彻尾的反讽——李逍遥亲手伺候的客人，正是要掳走他此生所爱的人。这是本章埋得最深的一颗雷。

**存疑**：赏钱数额，攻略间说法不一——有作「五百文」的，也有作「五百两」的；渔村客栈的量级上「五百文」更合常理。细节未考证到定论。

**视觉扩写（创作用，非原作实录）**
苗人首领坐在窗边逆光处，脸只露半边；银饰在昏暗客房里冷冷一闪。少年托盘上的酒壶随脚步轻晃。

### 场景三 · 客栈门口：一壶桂花酒，换一身本事

这是全游戏最著名的开场戏之一，也是李逍遥命运的真正扳道岔。

**场景描写**
客栈临街的门口／堂屋门槛处。一个醉汉赖在那儿不走，挡着做生意。婶婶嫌他晦气，指使侄儿去把人赶开。这场戏的空间是三段式：**门口（醉道士）→ 厨房（婶婶）→ 二楼客房（苗人）→ 再回门口**，主角在这条动线上跑一个来回，把「酒」这件道具传递到位。

**人物出场描写**
- **醉道士（即酒剑仙，本名司徒钟）**：攻略里一律称他「醉道士」——**他是道士装扮**，不是普通酒鬼；这一点对造型极其关键。资料记载其年岁在一代约四十七、身高一米七六，蜀山仙剑派出身，「于武学上极有天赋，唯独嗜酒如命，举止狂放，不在意任何规矩法度」。最要命的设定是：**他酒喝得越多越精神、没酒喝反而醉倒**——所以他此刻的「醉」，恰恰是因为没酒。出画入画方式：一个瘫在门边、看着彻底不像高手的人。
- **李逍遥**：来赶人的伙计，一路小跑穿堂过厨。

**对白实录**
1. 婶婶指派：门口那个醉汉赖着不走，去把他弄走。语气是嫌恶加不耐烦。
2. 主角上前赶人，醉道士不吵不闹，只提一个条件——**给口酒喝，喝完就走**。这句话把「驱赶」变成了「交易」。
3. 主角去厨房问婶婶，被顺手支使去给客人送酒菜；他端酒菜上二楼客房，苗人客人却**嫌这酒不合口**——于是那壶**桂花酒**没人要了，李逍遥把它揣进怀里。
4. 下楼，把桂花酒递给醉道士。对方**一口气把整壶灌了个精光**。多份攻略都用「豪饮整壶」形容这一下——他要的是「一口」，喝的是一整壶。
5. 醉道士自觉理亏，当场承诺赔他一套剑法，并撂下时间地点：**「明晚三更，十里坡山神庙。」**
6. 少年的反应是半信半疑——一个醉鬼道士张口就要教绝世剑法，谁会当真。

**事件逐拍**
1. 婶婶派活（赶人）→ 2. 醉道士开条件（要酒）→ 3. 主角进厨房被支使（送酒菜）→ 4. 客房里苗人嫌酒（酒变成无主之物）→ 5. 主角把桂花酒收入怀中 → 6. 下楼交酒 → 7. 醉道士一口喝干 → 8. 允诺授剑、约定「明晚三更·十里坡山神庙」 → 9. 剧情放行，主角回去继续跑腿。

**转折／伏笔**
这是全剧因果链的第一环，而且是**被动触发**的：李逍遥没有拜师之心，也没有行侠之志，他只是在完成婶婶交办的两件杂事，中间恰好接住了一壶别人不要的酒。**仙剑的宿命观在这里就立住了——改变一生的东西，往往长得像一件不值一提的小事。** 另一层伏笔在于「怀里揣着的那壶酒」：它本是端给苗人的，苗人不要，才轮到醉道士；而正是这一饮，让李逍遥后来有本事去救人、去杀妖、去和天意较劲。

**注意**：此处**没有**「醉中授剑」的动作戏。授剑发生在场景九。分镜时若要在开局给一个「剑」的意象，只能靠道具（道士腰间／背后的剑、酒葫芦）与眼神暗示，不能演成动作场面——那会与后面山神庙的戏撞车。

**视觉扩写（创作用，非原作实录）**
门槛外，醉道士靠着门框坐着，破旧道袍、乱发、赤脚，眼皮半睁；街上鱼贩挑担走过，没人多看他一眼。少年递酒时的犹豫、道士接过酒壶时手上骤然稳定的那一瞬间（唯一泄露身份的破绽）；喝完，他把空壶往地上一顿，抬眼看少年——那一眼不再是醉眼。

### 场景四 · 盛渔村渡口市集：买不到的鲜货

**场景描写**
从客栈出门就是**盛渔村的渡口市集**——码头与菜市连成一片：泊着渔船的渡口、支着摊子的市集、来往的挑夫与主妇、腥咸的海风。这是本章第一个真正的「外景」，也是全游戏第一次把「江南水乡小渔村」的市井全景铺开。

**人物出场描写**
- **卖鱼人**：市集摊贩，手边却没鲜货。
- **张四（张四哥）**：本村船夫，后来载李逍遥出海的就是他。他也是那条「仙灵岛有仙女」传闻的源头。（延伸考证：张四与丁香兰后来成了夫妻，李大娘晚年把客栈交给了他们夫妇——见「关键道具与线索」表下的注。）
- **李逍遥**：揣着婶婶给的铜钱，一家家问过去。

**对白实录**
主角奉命来买鲜货，可是**摊上没货**。卖鱼人和船夫张四给的是同一个理由：**这几天风浪太大，船出不去，鱼虾都打不上来。** 一个跑腿小任务被硬生生卡住——这正是设计意图：它逼着玩家在市集和码头之间来回搭话，从而撞上那句改变一切的闲言碎语。

**事件逐拍**
1. 婶婶给钱、交代买什么 → 2. 主角出客栈进市集 → 3. 问卖鱼人：无货 → 4. 问船夫张四：风浪大、出不了海 → 5. 任务受阻，主角继续在渡口打听 → 引出场景五。

**转折／伏笔**
「风浪大、出不了海」这句话有双重功能：它既是买不到鱼的理由，也是**为后面「张四竟肯冒着风浪送他去仙灵岛」这件事预先垫高了代价**——同村人肯为救李大娘拼一趟命，这份人情是渔村社会的底色。

**存疑**：婶婶给的钱数与要买的东西，攻略记载不一致——有作「二十文买鲜鱼」的，也有作「五十文买新鲜的虾」的。两说可能对应不同版本或不同攻略作者的记忆偏差，细节未考证到定论。分镜时建议用「几十文铜钱／买今天的鲜货」这类不写死的处理。

**视觉扩写（创作用，非原作实录）**
空荡荡的鱼摊，只剩湿漉漉的木案板和几只苍蝇；远处栈桥上的渔船被浪推得一下一下磕着桩子；少年攥着几枚铜钱，从这头走到那头，越走越慢。

### 场景五 · 码头：仙灵岛上有仙女

**场景描写**
渡口栈桥一带。海面因风浪泛白，渔船都拴着没出。这是全章的「传闻场」——信息不是被谁郑重告知的，是在码头闲人堆里飘过来的。

**人物出场描写**
- **水生叔**：村里的长辈渔人，码头上闲话的转述者。他不是当事人，他听来的——**消息源头是张四哥**。这个「二传手」结构很重要：传闻越经转述越像神话，正好对上「仙女」这个词。

**对白实录**
李逍遥向水生叔搭话打听。水生叔说起一桩奇事：**听张四哥讲，仙灵岛上出了仙女。** 语气是渔村老人讲海上传说时那种半信半疑、又乐于讲的味道——不是情报，是谈资。李逍遥此刻听着也就是听个新鲜，没往心里去。

**事件逐拍**
1. 主角在码头逢人便问（本意还是找鱼）→ 2. 水生叔顺口讲起张四哥传的仙灵岛仙女之说 → 3. 这条信息被登记进主角脑子里，暂时无用 → 4. 场景六一到，它立刻变成救命的唯一希望。

**转折／伏笔**
这是全剧结构上最精巧的一处**信息预埋**：赵灵儿的存在，是以「渔村闲话」的形式先于人物本身出场的。等婶婶一病倒，这句本来毫无用处的闲话瞬间变成李逍遥唯一能抓住的稻草。**先给钥匙，再给锁**——这是仙剑开局叙事最漂亮的一手。

**视觉扩写（创作用，非原作实录）**
老渔人蹲在缆桩边补网，说话时手不停；他抬下巴往海雾深处一指，那个方向什么也看不见，只有白茫茫一片。少年顺着看过去——镜头在此可以第一次给出「仙灵岛」的方位，却什么都不给观众看。

### 场景六 · 街上：香兰跑来报信

**场景描写**
市集／街道上，主角还在为买鱼发愁。节奏在这里被一记急刹车打断。

**人物出场描写**
- **香兰（丁香兰）**：村中女子，与李家客栈相熟。出场方式是**跑着来的**——喘、急、话不成句。她这一跑，把全章的气压从市井闲适压成了危急。

**对白实录**
香兰急着找到李逍遥，报的是一句最短也最重的话：**李大娘病倒了。** 少年整个人的状态在这一句上转向——前一刻还在为几文钱的鱼发愁，下一刻家就塌了一半。

**事件逐拍**
1. 香兰追上主角 → 2. 报信：婶婶病倒 → 3. 主角丢下买鱼的差事往回跑 → 4. 场景切回客栈。

**转折／伏笔**
本章的情绪拐点。此前所有戏（叫醒、上菜、赶醉汉、买鱼）都是**日常**，从这一句开始全部作废。日常越琐碎具体，被打断时越疼。

**视觉扩写（创作用，非原作实录）**
少年手里的铜钱撒在青石板上，他没去捡，人已经跑出画面。

---

### 场景七 · 客栈：郎中束手，小虎子提起仙灵岛

**场景描写**
客栈内，李大娘卧床。屋里挤着请来的郎中、街坊、和一个小孩。窗外仍是白天。这是本章唯一一场「病房戏」，全部张力集中在一张床和几张脸上。

**人物出场描写**
- **李大娘**：躺着，此前那个中气十足吼人的当家人，现在说不出整句话。**对比即是全部演技。**
- **洪大夫（郎中）**：被请来的本地郎中，诊过之后摇头。他的功能是「代表人间医术的上限」，然后宣布上限已到。
- **小虎子（李小虎）**：村里的小孩。全场最不该给出答案的人，偏偏是他给了答案。
- **李逍遥**：从街上跑回来，站在床边，第一次面对「无能为力」这四个字。

**对白实录**
1. 洪大夫诊毕，把话说死：**李大娘的病，他医不了。** 没有回旋余地，也没有安慰。
2. 满屋子沉默里，**小虎子**冒出一句孩子话——**仙灵岛上有仙女，去求仙药就能治好。** 大人们大概只当童言无忌；李逍遥却记起了刚在码头听过的同一件事。**两条信息在他脑子里对上了。**
3. 李逍遥当场就要去。这一步没有犹豫，也没有权衡——他不是被说服的，他是没有别的路可走。

**事件逐拍**
1. 主角奔回客栈进门 → 2. 郎中诊断、宣布无救 → 3. 小虎子说出仙灵岛仙药 → 4. 主角与码头传闻互相印证 → 5. 主角决意出海求药。

**转折／伏笔**
「郎中束手」是仙侠故事最经典的启程装置：**当尘世的办法全部用尽，主角才被推向仙的那一边。** 李逍遥求仙的动机干净得近乎笨拙——不是求道，不是修仙，是救婶婶。这个动机后来一路被稀释、被改写、被命运压垮，但它是全剧最初也最纯的那一点心气。

**视觉扩写（创作用，非原作实录）**
郎中收拾药箱的动作、街坊移开的目光、小孩不懂气氛的清亮嗓门；少年站在门口，逆光，肩膀先塌下去，然后猛地抬头。

### 场景八 · 苗人首领赠物 → 渡口登船

**场景描写**
先在客栈（苗人客房），再转到盛渔村渡口。天色仍是白日，海上风浪未平。**本章的空间在这里从「屋里」彻底走到「海上」。**

**人物出场描写**
- **苗人首领**：此刻是本章的「赠礼者」——他不但知道仙灵岛在哪，还知道岛上有**迷阵**、知道破阵的走法、手里现成有破阵的锤子和一味叫忘忧散的药。一个投宿的过路客对一座传说中的仙岛了如指掌，这本身就是最大的疑点。
- **张四哥**：风浪大到全村不出船的日子，他肯开船送他去。

**对白实录**
1. 苗人首领找上李逍遥，把话说得很实在：仙灵岛上有迷阵，他告知**走法**；并交给他一把**破天锤**用来破阵。
2. 同时让李逍遥**服下忘忧散**。这一味药的名字就是它的作用说明书——**忘忧，即忘却**。当时的语境是善意的、顺理成章的，李逍遥没多想就吃了。
3. 到渡口找张四哥，说明来意（救婶婶的命），张四哥答应载他出海。

**事件逐拍**
1. 苗人首领现身、交代迷阵走法 → 2. 给破天锤 → 3. 给忘忧散并让他服下 → 4. 主角赴渡口 → 5. 与张四哥交谈 → 6. 登船，驶向仙灵岛（本章终点）。

**转折／伏笔**
**忘忧散是全章最阴的一笔。** 它当场看起来像是一份好意，实际是苗人替李逍遥「删记忆」的手段——后来他从仙灵岛回来，救活了婶婶，却**记不起岛上发生过什么、记不起赵灵儿**。仙剑一整条「相识—遗忘—重逢」的爱情主线，源头就在这一口药上。观众重看开局时最毛骨悚然的一幕，就是少年毫无戒心地把它咽下去。
**破天锤**则是纯粹的钥匙道具：迷阵—石像—破阵，一锤子解决。
**苗人首领的「热心」**至此已经露出马脚：他们要的从来不是投宿，是仙灵岛上的那个人。

**视觉扩写（创作用，非原作实录）**
苗人递药时压低的声音与遮住半边脸的阴影；少年仰头吞药、喉结一动。渡口上，小船离桩，村子在船尾一点点缩小；风浪把船头拍得高高低低——这是李逍遥人生第一次离开余杭。

### 场景九 · 深夜 · 十里坡 → 山神庙：御剑术

> **时序提醒**：本场发生在**仙灵岛归来、用紫金丹救活婶婶之后**的那个夜里，即场景三所约的「明晚三更」。它不属于开局清晨，但它是场景三的兑现，所以并入本章记录。

**场景描写**
夜。李逍遥从**客栈的密道**出门，穿过**十里坡**——余杭镇外那片起伏的荒坡野径，也就是后世「十里坡剑神」典故里那块地方——抵达坡上的**山神庙**。庙是那种乡野小庙：破败、香火冷清、神像蒙尘，夜里只有虫声与风。三更时分，四下无人。

**人物出场描写**
- **醉道士／酒剑仙（司徒钟）**：早已在庙里等着。此刻他仍是那副落拓道士模样，但气场与白天在门口讨酒时完全是两个人。授艺完毕后，他**吟诗而去**——不告别，不解释，来去如风。
- **李逍遥**：半夜偷跑出门的少年，来的时候还半信半疑，走的时候已经身怀御剑之术。

**对白实录**
1. 少年在庙里找到那个醉道士，多半带着「你真在这儿」的错愕。
2. 醉道士履约传艺——**御剑术**。（原作此处配有一段动画演出，攻略称之为「精彩的动画」，是 DOS 时代难得的过场。）
3. 事毕，他**吟着诗离开**。少年这才知道：这个赖在自家门口讨酒的邋遢醉鬼，是江湖上赫赫有名的**酒剑仙**。
4. 值得注意的是人物设定层面的一笔：酒剑仙欣赏这少年的资质、也愿意传他本事，**却不肯正式收他做徒弟**——理由是不想让自己有所牵累。这是一段「有师徒之实、无师徒之名」的关系。

**事件逐拍**
1. 夜里从客栈密道出门 → 2. 穿越十里坡 → 3. 进山神庙寻到醉道士 → 4. 授艺过场动画 → 5. 学会御剑术 → 6. 酒剑仙吟诗离去 → 7. 身份揭晓。

**转折／伏笔**
这一场把开局那壶桂花酒的账**结清了**，也把李逍遥从「客栈伙计」正式改写成「有本事的人」。更重要的是它确立了酒剑仙在全剧中的位置：**一个在关键时刻出现、给完东西就走、从不居功的人。** 对 MV 而言，「白天讨酒的醉鬼／深夜授剑的仙人」这组同一人物的强烈反差，是本章最有戏的一对镜头。

**视觉扩写（创作用，非原作实录）**
密道口的一线月光；十里坡上没膝的野草被夜风推成一片一片的浪；山神庙残破的门轴响；神像背后走出那个人，手里还提着酒葫芦；剑光一起，庙里所有蛛网同时颤动。少年的脸被剑光照亮——这是他这辈子第一次看见「仙」。

## 四、95 vs 98 差异

本章相关的版本差异（按可考程度排列）：

- **画面呈现**：1995 DOS 原版（1995 年 7 月首发）与 1998 柔情版最大的差别在显示模式与美术规格——DOS 版分辨率与色彩受限，98 版是全屏精细图像模式，整体观感提升明显。
- **过场动画**：DOS 版的片头／片尾为静态图，98 柔情版增加了数段 AVI 动画。**这直接关系到本章场景九**——山神庙授艺那段过场，在 98 版是更完整的动画演出。
- **音乐**：DOS 版用 FM 音源（RIX 格式），98 版改为 MIDI，并新增了数首 CD 音轨。对 MV 而言这意味着「余杭客栈」主题在两版里的音色质感完全不同。
- **地图与迷宫**：98 版对部分地图做了简化，宝箱位置有改动，怪物数值经过调整。**十里坡这类野外地图的具体形状在两版间存在差异。**
- **剧情**：主线基本一致；98 版在若干场景的细节上有删减，同时增加了隐藏结局与结局微调。**开局余杭客栈段的主线事件顺序两版相同**（叫醒→招待苗客→赠酒→买鲜货→病倒→出海）。
- **存疑**：婶婶给的钱数与所买之物（二十文买鱼／五十文买虾）在不同攻略中记载不同，是否为版本差异所致，未考证到定论。

## 五、可用于 MV 的画面记忆点

1. **晨光里被吼醒的少年**——木格窗、飞尘、楼下传来婶婶的嗓门；一个不知道自己要去哪儿的人生开场。
2. **门槛上的醉道士**——破道袍、乱发、酒葫芦，赖在客栈门口挡着生意，全村没人拿他当回事。
3. **一壶桂花酒被一口灌尽**——空酒壶往地上一顿，抬起的那双眼睛突然不醉了。
4. **空荡荡的鱼摊与拍打栈桥的浪**——「风浪太大，出不了海」，江南渔村的日常在此刻显得格外结实。
5. **老渔人往海雾里一指**——「仙灵岛上有仙女」，镜头顺着指的方向看去，白茫茫什么也没有。
6. **郎中收起药箱、摇头**——一张床、一屋子沉默，和一个孩子清亮的「去求仙药呀」。
7. **仰头吞下忘忧散的喉结**——全剧最温柔也最残忍的一个特写。
8. **小船离桩，村子在船尾缩小**——少年第一次离开余杭，浪把船头抛起又摔下。
9. **深夜十里坡的野草浪**与**山神庙里骤起的剑光**——白天讨酒的醉鬼，夜里是仙；少年的脸第一次被剑光照亮。
