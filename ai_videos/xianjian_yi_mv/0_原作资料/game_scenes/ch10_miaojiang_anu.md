# ch10 · 苗疆 · 白苗一方与阿奴登场

> 流程位置：初代《仙剑奇侠传》**后半程**——锁妖塔崩塌、林月如殒身之后，李逍遥携身怀六甲的赵灵儿南下苗疆（圣姑家 → 灵山 → 神木林 → 大理城 → 火麒麟洞），阿奴在此段入队。**不是**游戏前半程的桥段。
> 版本口径：1995 DOS 原版为主线；98 柔情版差异以「98版差异：」行内标注。

> **重要范围修正（考证结论，先行标注）**：本章原拟题为「白苗寨与阿奴登场」，但经流程考证，初代游戏中**并不存在一个叫「白苗寨」的独立苗寨关卡**。白苗一方的据点是**大理城**（南蛮王阿蛮率大理城内苗民与汉人共同抵御黑苗入侵），黑苗一方的据点是**南诏国王城**（拜月教主所据）。此外，阿奴的登场与入队发生在**锁妖塔之后**的「圣姑家／灵山／神木林」段，而非「刚进苗疆就遇上」。详见文末 `scope_correction`。

## 二、场景志

（本节正在增量补写中——已落盘可用骨架与已考证段落，后续检索结果继续增补。）

### 场景 S1 · 圣姑家 —— 醒来、噩耗、与一纸药方

**1. 场景描写**
圣姑的居所在苗疆腹地、灵山山脚一带，是一栋独门独户的**房子**（攻略里以"圣姑的房子"为地标：出门往上走就是那片大树林／神木林）。这是整个苗疆线的**起点门户**，也是全游戏罕见的"停下来的地方"——前面刚刚过完锁妖塔的地狱，这里是喘口气的屋子，但屋子里等着的是更坏的消息。
苗疆段整体的地貌色温与中原截然不同：前半程的江南是青灰白墙、水汽氤氲；这里转为**浓绿、赭红、藤蔓与雾瘴**，房外就是望不到顶的树。（存疑：1995 DOS 版圣姑居所的具体内景陈设与摆件，多方来源仅把"圣姑家"记作一个可进入的场景与剧情点，细节未考证到。）

**2. 人物出场描写**
- **李逍遥**：这场戏他是**躺着出场**的——攻略明确写"李逍遥醒来后得知……"。他是被抬进来的伤员，不是走进来的英雄。
- **林月如**：**不出场，只留下结果**——她在锁妖塔重伤，**因伤重身亡**；攻略在此处标注"林月如永久离队"。她的死在这间屋子里被宣告，是李逍遥在苗疆做的所有事情的心理底色。
- **赵灵儿**：查出**有孕**；同处标注"赵灵儿离队"——也就是说，从这里开始的很长一段路，**李逍遥是一个人走的**（这正是他必须捡一个新队友的结构原因）。
- **圣姑（傀儡婆婆）**：女娲族的守护者，苗疆一方的长者。她是这一段的"下达任务的人"：诊出灵儿的身孕与虚弱，开出药方。

**3. 对白实录**（转述为主）
圣姑把两件事按在李逍遥头上。第一件是**噩耗**：月如伤得太重，没能撑住。第二件是**活路**：灵儿怀着孩子、母子皆虚，需要保胎药；而这副药的药引不在药铺里——她要李逍遥去取**凤凰蛋壳**和**麒麟角**这两味来给灵儿安胎（攻略原句作"圣姑乃告知逍遥去拿凤凰蛋壳及麒麟角来给灵儿安胎"）。
这两句话叠在一起的效果很残忍也很有效：**它不给他悲伤的时间**。一个刚死了同伴的人，被立刻推出门去为另一个人的孩子掏鸟窝、拔兽角。李逍遥从"逃亡者"被重新按回"必须往前走的人"的位置上——他不是来避难的，他是来当爹的。（存疑：圣姑此段的逐句台词文本未考证到，此处按可溯源事件要点转述，不作台词实录填充。）

**4. 事件逐拍**
1. **因**：锁妖塔崩、水魔兽脱困；月如重伤、灵儿有孕，一行人辗转投奔苗疆的圣姑。
2. 李逍遥在圣姑家**昏迷后醒来**。
3. 得知两件事：**灵儿怀孕**；**月如伤重不治**（永久离队）。
4. 圣姑开出**安胎药方**：需**凤凰蛋壳** ＋ **麒麟角**。
5. 灵儿留在圣姑家养胎（**离队**）→ 李逍遥**独自**出门。
6. 出门往上走，即是那片大树林——直接接 S2。

**转折/伏笔**
- 这是全剧的**"父亲线"起点**。李逍遥的动机从"救灵儿"升级为"救灵儿和孩子"，而这个孩子正是结局里唯一被留下的活口。
- **队伍归零**：月如死、灵儿离队，主角被剥到只剩一个人——这个"空位"是阿奴登场的结构理由。仙剑一在这里做了一次干净的换血。
- 药方的**两味药**是本章的动线引擎：凤凰蛋壳把人带进**神木林**，麒麟角把人带进**火麒麟洞**。

**视觉扩写（创作用，非原作实录）**
- 屋内：一盏昏灯，李逍遥睁眼，视线先落在空着的那张床上。
- 门口悬着风干的草药与骨串，风一过全部轻响。
- 他推门出去，屋外是压顶的巨树，人一下变得很小。

### 场景 S2 · 神木林 · 金翅凤凰窝 —— 阿奴登场（本章戏眼）

**1. 场景描写**
神木林是圣姑住处附近的一片**大树林**，在游戏里是一座**迷宫式场景**——树与树之间没有明路，走法要靠试，视野被树冠压得很低。林中有一处关键点位：**金翅凤凰的巢窝**，架在高树上；到窝前会触发一场战斗（金翅凤凰）。林子往西通到**灵山山脚**。
整体色调是苗疆特有的深绿加雾，光线是从树冠缝里漏下来的斑点光；"高"是这场戏的空间关键词——因为这场戏的转折发生在垂直方向上：**人从树上掉下来**。

**2. 人物出场描写**

**李逍遥**：此刻是个"来偷东西的人"。他手里握着圣姑给的药方，药方要**凤凰蛋壳**与**麒麟角**两味。他要拿到凤凰蛋壳，就必须**爬上高树、掏凤凰的窝**——一个从任何本地人角度看都百分之百像贼的动作。他不是恶意，但他确实在别人的地界上，爬别人的树，掏别人的鸟窝。

**阿奴**：
- **身份**：**白苗族长之女**、**南蛮王之女**，即**白苗少主**。
- **定性（可溯源原文措辞）**：条目对她的描述是"個性刁鑽活潑"，"**甫出場便將李逍遙耍得團團轉**"，"外表天真爛漫，施用巫術毒蠱手段卻叫人毛骨悚然"。这三句是她整个人设的骨架：**看着甜、手上狠、上来就把男主玩了一遍**。
- **本事**：**巫术毒蛊**。她的武器不是刀剑，是虫——这是她与中原队友（用剑的逍遥、用鞭的月如）在视觉上最大的分野。
- **感情线**：对李逍遥一见倾心；与大理城的汉人少年**唐钰**是青梅竹马。三角关系从登场这一刻就已埋好。
- （存疑：1995 DOS 版阿奴的具体服色、银饰件数、发式，文字资料未直接考证到；游戏内为苗族少女装束，具体配色需以实机截图/立绘为准。）
- ⚠️ **版本混淆警示**：2005 电视剧版把阿奴改写成"自幼师从圣姑修习仙法""因贪食触发圣姑惩戒法术"。**游戏原作不是这个设定**——游戏里的阿奴是白苗少主、南蛮王之女，与圣姑并非师徒。做本片时不要把剧版设定当原作实录用。

**3. 对白实录**（转述为主）
这场戏的全部戏剧张力来自一个**误会**：李逍遥要凤凰蛋壳入药，于是上树掏窝；阿奴撞见，**认定他是偷蛋贼**。她没有讲道理，也没有先问一句，直接动手——结果是**李逍遥从高高的树上摔了下来**。
之后的交涉是典型的"不打不相识"：一个满身泥的汉人少年在地上爬起来解释自己不是贼、是拿药救人；一个居高临下的苗家少女先不信、后半信、最后被"救人"两个字勾住。她跟上来了。（存疑：这场戏的逐句台词文本未考证到确切内容，此处按可溯源的事件要点与人物定性转述，**不作台词实录填充**。）

> 版本口径提示：网络流传的阿奴名句「对我来说呢，美食比美男啊，更重要。」出自**电视剧版**台词汇总（经搜索摘要间接引用，新浪），**不可作为 1995 游戏原作台词**使用。

**4. 事件逐拍**
1. **因**：圣姑诊出灵儿有孕体虚，开出安胎药方——需**凤凰蛋壳**＋**麒麟角**。
2. 李逍遥离开圣姑家，进**神木林**迷宫找金翅凤凰的窝。
3. 找到**金翅凤凰窝**，触发与金翅凤凰的战斗。
4. 李逍遥爬上高树掏蛋壳。
5. **阿奴出现，误认他为偷蛋贼**，出手——**李逍遥自高树摔落**（"耍得团团转"的第一记）。
6. 摔完、解释、化解误会。
7. 队伍继续西行，**在灵山山脚西侧，阿奴正式入队**（攻略标注的入队触发点）。
8. 药方还差一味**麒麟角** → 直接指向后段的**火麒麟洞**。

**转折/伏笔**
- **队伍替补**：仙剑一的三人组从"逍遥＋灵儿＋月如"换成"逍遥＋灵儿＋阿奴"。三角的形状保留，配方全换：月如是烈，阿奴是野。
- **摔树**这一拍是整个苗疆线的调性开关——前半程刚死过人（月如殒于锁妖塔），这里用一个滑稽的高空坠落把气压强行拉回来。仙剑一的苦味，从来是先给你笑再给你哭。
- **倾慕伏笔**：阿奴从这里开始爱李逍遥，一直爱到结局——灵儿死后，她在崖边独自**吹笛**，那支幽伤的笛曲是这条线唯一的收束，也是她一生未嫁的注脚。
- **药方两味**（凤凰蛋壳／麒麟角）是本章的动线引擎：一味把人带进神木林，另一味把人带进火麒麟洞。

**视觉扩写（创作用，非原作实录）**
- 仰角：树冠很高，逍遥的手刚够到窝边，一根金羽落下来。
- 反打：一个苗族少女站在斜下方的树杈上，银饰先响、人后到，眼睛亮得像刚发现好玩的东西。
- 坠落：三层叶影快速掠过镜头，人重重砸进腐叶堆，惊起一片虫子。
- 落地后的第一个正面：泥、叶、狼狈的少年，抬头；逆光里少女蹲在树杈上，双手托腮看他。

### 场景 S4 · 大理城（白苗一方的"寨"）

**1. 场景描写**（部分考证中）
大理城是**白苗一方的都城与战时据点**，城中并非纯苗，而是**苗民与汉人杂居**，共同抵抗黑苗的侵略。这一点很重要：它把"白苗＝我方"写成了一个多族共守的城，而不是一个封闭的寨子。

**2. 人物出场描写**
- **南蛮王（阿蛮）**：白苗族长，**女性**，阿奴之母。其夫战死之后**代夫出征**，率大理城中的苗民与汉人一同抵抗黑苗族的侵略。这是一位寡妇统帅——她的威望不是继承来的，是打出来的。
- **盖罗娇**：白苗将军，擅长**训练五毒兽**作战；大理国建立后成为**镇南大元帅**。她此前在汉地长期假扮店主潜伏。
- **唐钰**：大理城的**汉族**少年，与阿奴**青梅竹马**。（存疑：其"唐钰小宝"的称呼来源与初代具体戏份，未考证到确切段落。）

**3. 对白实录**（转述）
（考证中——大理城内主线对话的具体往来未考证到，暂不填充。）

**4. 事件逐拍**
1. 一行人抵达大理城，进入白苗战时状态的都城。
2. 与南蛮王一方接上头，黑白苗之争由"路上撞见的乱斗"升级为"有城、有军、有统帅的战争"。
3. 线索指向**火麒麟洞**。

**转折/伏笔**：整场黑白苗之争其实是被人做的局——是**拜月教主**长期**挑拨离间**黑白两苗的结果。大理城越是同仇敌忾，后面真相揭开时的反讽越重。

## 三、关键道具与线索

- **安胎药**（圣姑所托）——把李逍遥的动机从"救人"改写成"护家"。
- **毒蛊 / 五毒兽**——白苗一方的战法标识：阿奴用蛊，盖罗娇练五毒兽。
- **火麒麟洞的地道**——通往南诏王宫的物理通路，也是真相通路。
- **笛**——阿奴的情感载体（结局崖边吹笛）。
