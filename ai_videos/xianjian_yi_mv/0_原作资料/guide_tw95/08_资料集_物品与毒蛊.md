# 台版攻略本 — 資料集（武器／防具／道具／販售／毒蠱／解藥）

> 來源：`台版SS·WIN95版仙剑奇侠传攻略.pdf`，書頁 311–346 ／ PDF 頁 313–348。
>
> **抽取範圍聲明（不做無聲截斷）**：原章共 36 頁純數值表（每件物品含價格＋武術／靈力／防禦／身法／吉運加成＋可裝備者）。
> 本檔**完整轉錄「名稱體系 + 具敘事意義的說明文字」**（毒蠱、解藥、法寶、關鍵武器），**刻意不轉錄數值與價格**——那是遊戲平衡數據，對影像敘事無用。
> 具體地：武器表逐頁看過並取全部劍／刀名；防具表（書 318–327，10 頁）與販售品表（書 334–339，6 頁）只取**分類體系與代表品項**，未逐件列舉；毒蠱表與解藥表**全文轉錄**（這兩張是世界觀設定，不是數值）。

## 一、武器體系（書頁 312–317）

原書引言：
> 各角色可裝備的兵刃不一，在購買前請先確認。

每件武器標註四位主角誰能裝備（李／趙／林／奴），這構成了官方的**兵器歸屬體系**：

### 劍（李逍遙專系，部分趙靈兒可用）

木劍（$50）→ 鐵劍 → **仙女劍**（雙重刀劍攻擊）→ 越女劍 → 玄鐵劍 → 青鋒劍 → 雙龍劍 → **龍泉劍**（＝林天南佩劍）→ 玉女劍 → 金童劍 → 七星劍 → 磐龍劍 → 太極劍 → **無塵劍**（$32000，武術+200，全表最強劍）

### 刀（阿奴／林月如系）

短刀 → 大刀 → 紅纓刀 → 芙蓉刀（雙重刀劍攻擊）→ 戒刀 → 柳月刀（雙重刀劍攻擊）→ **苗刀**（阿奴專屬）→ 鬼牙刀 → 鳳鳴刀 → **玄冥寶刀**（雙重刀劍攻擊全體）→ **巫月神刀**（阿奴專屬，$28000）

> **對本劇的可用點**
> - **李逍遙的劍成長線**：木劍（$50，開場的破木劍）→ … → 無塵劍。**「木劍」是官方確認的起手兵器**，與既有 `props/p1_木剑` 道具卡完全吻合，且官方給了「武術+2、身法+3」的定位＝幾乎沒有攻擊力，純粹是少年的憧憬道具。
> - **阿奴專屬兵器＝苗刀 / 巫月神刀**（名稱帶苗疆與巫月色彩），與她「刀、法杖」的官方擅長兵器一致。
> - **龍泉劍**在敵角色表中是「可從林天南身上偷到」的物品 → 官方確認龍泉劍＝林天南佩劍，可作 `props/龙泉剑` 卡。
> - 「雙重刀劍攻擊」「雙重刀劍攻擊全體」是官方標註的特殊武器效果，設計打戲時可作為「一擊兩響／橫掃全場」的視覺依據。

## 二、防具體系（書頁 318–327）

原書引言：
> 依裝備部位，可將防具分成**五種類型**。

**類型一：頭戴** —— 「裝備在頭部的防具。如頭巾、髮飾、銀釵、皮帽等。」代表品：頭巾、髮飾、青絲巾、皮帽。
其餘四類為身穿／手戴／腳穿／飾品類（藤甲、披風、護肩、護腕、鐵護腕、木鞋、草鞋、鐵履等，見販售表）。

> **對本劇的可用點**：官方的服飾配件名（**頭巾／青絲巾／髮飾／銀釵／皮帽／披風／護腕／草鞋**）是古風造型描述的現成詞庫，寫 shot 的角色服裝欄時用這些原作詞比自創更貼。

### 補充體力
止血草 / 醃肉 / 行軍丹 / 觀音符 / 金創藥 / 蟠果 / **紫菁玉蓉膏**（全滿）/ 聖靈符 / **赤血蠶**（全滿）

### 補充真氣
鼠兒果 / 還神丹 / 龍涎草 / **靈蠱** / 靈山仙芝 / 雪蓮子 / **天仙玉露**

### 補充體力及真氣
水果 / 酒 / 糖葫蘆 / 蜂王蜜 / **靈葫仙丹** / **神仙茶**

### 復活
**還魂香**（10% HP）→ **贖魂燈**（30%）→ **孟婆湯**（50%）→ **天香續命露**（100%）

### 增強體力（永久提升）
金剛符 / 銀杏子（體力上限+3）/ 舍利子（真氣上限+3）/ **試煉果**（靈力+3）/ **八仙石**（防禦+2）/ **女媧石**（防禦+3）/ 雪蛤蟆 / **金蠶王**（$9000，**修行提升一級**）

### 輔助道具 —— **本章最有敘事價值的一組**

| 道具 | 官方功效 |
|---|---|
| **十里香** | 吸引怪物一分鐘（迷宮中） |
| **驅魔香** | **怪物定住一分鐘**（迷宮中） |
| **傀儡蟲** | **控制死者九回合**，使用對象＝**我方死者** |
| **引路蜂** | 以土遁術回到迷宮入口，在原野可回上一個城鎮 |
| **土靈珠** | 同上（回迷宮入口／上一城鎮） |
| **紫金葫蘆** | **收妖煉丹**，依葫蘆累積能量 |

原書對紫金葫蘆的完整註解：
> ※ **紫金葫蘆相傳為古茅山術士收妖煉丹之法寶**，若與仙術靈葫咒配合使用，即可將瀕死的妖物吸進葫蘆之中，**煉化其元神**。妖物的等級愈高，所產生的能量便愈大，依累積的能量大小，使用紫金葫蘆，可煉成不同的靈丹妙藥。

> **對本劇的可用點（重要）**
> - **傀儡蟲「控制死者」** —— 這正是專訪裡姚仙說的「聖姑要李逍遙去蒐集足夠的**傀儡蟲**來作藥」救月如的那件東西。官方道具說明是「控制死者九回合」，**指向月如的「死而未死」狀態**。這條物證讓月如復活線在本劇裡有可拍的實體：逍遙一隻隻蒐集傀儡蟲。
> - **紫金葫蘆＋靈葫咒**＝完整的收妖煉丹法寶體系（茅山術士出身、收瀕死妖物、煉化元神、等級越高能量越大）。可直接建 `props/紫金葫芦` 道具卡，是酒劍仙／逍遙的標誌性法寶。
> - **女媧石**（防禦+3，可從「石鬼頭」身上偷到）——女媧母題的實體遺物，可作道具符號。
> - **驅魔香**（$3000，令妖物定住）在密碼天地裡還有「行走中永遠擁有驅魔香效果」的作弊碼，說明它是本作標誌性消耗品。

## 四、販售品體系（書頁 334–339）

按**城鎮**分列店舖與售價，店舖類型固定為：**藥房 / 打鐵舖 / 木匠店 / 水果攤 / 當舖**（原註：「一覽表中所列出的當舖，指的是會收購主角身邊多餘物品的場所」）。

以起點城鎮 **餘杭縣** 為例：
- 藥房：雄黃、止血草、還神丹、還魂香、驅魔香
- 打鐵舖：短刀、護肩、披風、鐵履、護腕、鐵護腕
- 木匠店：**木劍**、藤甲、木鞋、草鞋、皮帽、髮飾
- 水果攤：水果

> **對本劇的可用點**：官方給出了**每個城鎮的商業街構成**——藥房／打鐵舖／木匠店／水果攤。做市井場景 shot（余杭客棧外的街市）時，這四類店舖招牌就是最正的美術細節；而「木劍在木匠店賣 $50」也坐實了逍遙那把木劍是市井雜貨，不是名器。

## 五、七大毒蠱（書頁 340–343）—— **完整轉錄，苗疆世界觀核心設定**

原書引言：
> **七大蠱毒相傳只有毒龍膽可解**，但毒龍膽非常罕有難尋，且本身帶有劇毒，**只有道行高深的煉蠱師能依毒性相剋之理，以毒攻毒將其化解，但若兩者毒性相沖，則有致命之虞，不可不慎！**

| 毒蠱 | 我方中毒 | 敵方中毒 | 解救道具 | **致命藥引** |
|---|---|---|---|---|
| **三屍蠱毒** | 潛伏三回合後即猛烈發作，損血 200 點 | 中毒三回合，依序損血 111／222／333 點 | 毒龍膽、斷腸草 | **血海棠** |
| **斷腸草毒** | 每回合損血 50，至死方休 | 每回合損血 100，至死方休 | 毒龍膽、血海棠 | **金蠶蠱** |
| **鶴頂紅毒** | 每回合損血 50，至死方休 | 每回合損血 100，至死方休 | 毒龍膽、金蠶蠱 | **孔雀膽** |
| **金蠶蠱毒** | 每回合損血 50，至死方休 | 每回合損血 100，至死方休 | 毒龍膽、孔雀膽 | **斷腸草** |
| **孔雀膽毒** | 每回合損血 50，至死方休 | 每回合損血 100，至死方休 | 毒龍膽、無影毒 | **鶴頂紅** |
| **血海棠毒** | 每回合損血 50，至死方休 | 每回合損血 100，至死方休 | 毒龍膽、鶴頂紅 | **三屍蠱** |
| **無影毒** | **立即發作，耗損一半體力** | 立即發作，耗損一半體力 | **無** | **無** |

> **對本劇的可用點（極高）**
> - 這是一個**完整的相生相剋環**：三屍蠱→血海棠→鶴頂紅→孔雀膽→無影毒／斷腸草→金蠶蠱→斷腸草…每種毒的「解藥」是另一種毒，「致命藥引」又是第三種毒。**以毒攻毒、一步走錯就死** ——這是現成的高張力劇情裝置，適合寫「解毒博弈」一場戲。
> - **無影毒無解**，且立即耗損一半體力 → 是七毒中的絕望牌，適合安排在生死關頭。
> - 「只有道行高深的煉蠱師能依毒性相剋之理化解」→ **聖姑（白苗族法力最強的蠱毒巫師）** 的專業能力在此得到官方定義。聖姑救月如的合理性、以及她「表面說沒救」的可信度，都建立在這條規則上。
> - 七毒之名（三屍蠱／斷腸草／鶴頂紅／金蠶蠱／孔雀膽／血海棠／無影毒）本身就是極好的台詞素材與集標題素材。

## 六、解藥一覽表（書頁 344）—— 完整轉錄

副標：**雄黃　九節菖蒲　毒龍膽**

原書引言：
> 每次戰鬥結束後，角色的體力、真氣會略為恢復，所中的毒、蠱、瘴魔及昏睡等狀態皆會自動解除。**若在平時誤食毒藥，毒性將潛伏在體內，遇到戰鬥時便會發作。**

| 解藥 | 功效 | 注意 |
|---|---|---|
| 雄黃 | 解赤毒 | — |
| 酒 | 解赤毒 | 補充體力、真氣各 15 點 |
| 雄黃酒 | 解赤毒、瘴毒 | — |
| **糯米** | **解屍毒** | — |
| **糯米糕** | 解屍毒 | 補充體力 25 點 |
| 淨衣符 | 解赤毒、屍毒、瘴毒 | — |
| 銀針 | 解定身、昏睡、瘴魔 | — |
| 靈心符 | 解定身、昏睡、瘴魔、咒封 | — |
| **鬼哭藤** | 解赤毒、屍毒、瘴毒、毒絲 | **以毒攻毒，身體略受損傷** |
| **九節菖蒲** | 解赤毒、屍毒、瘴毒、毒絲 | — |
| 九陰散 | 無解毒功效，但若先前已中毒則體力補滿 | **若事先沒有中毒，則服者立斃** |
| **毒龍膽** | **解七大毒蠱** | **若沒有中七大毒蠱者，服用毒龍膽會暴斃** |

> **對本劇的可用點**
> - **糯米解屍毒** → 直接解釋了角色介紹裡「駱員外趁殭屍作亂**哄抬糯米價格**賺不義之財」的整條白河村支線。這是本劇白河村段落的經濟邏輯，官方對得上。
> - **毒龍膽／九陰散「用錯即死」** ——「救命藥吃錯就是毒藥」是極好的懸念設計。
> - 官方明訂「平時誤食毒藥→潛伏體內→戰鬥時發作」，即**慢性毒**的設定，可用於埋伏筆。
