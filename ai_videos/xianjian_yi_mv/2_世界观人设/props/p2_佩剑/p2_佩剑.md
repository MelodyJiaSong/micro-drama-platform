# p2 · 佩剑（真剑·后期御剑之剑）

## 物件定位
贯穿 motif 第二形态：段3 起李逍遥的随身真剑，段7 蜀山御剑的座剑，段8 雪夜插于雪中、蝶落剑柄（全片终镜核心物）。motif 链：木剑(p1) → 佩剑(p2) → 御剑（段7 动作态）。

**原作校准**：逍遥的剑术来路是**酒剑仙**——他以一壶酒换得授剑之约，三更在十里坡山神庙破败神像下得传**万剑诀**一式（过场动画4），醉道士留下「你学此一招剑法，便可一生受用无穷，你我缘尽于此」后飘然而去。这一式的成色在原作被外人当场认出：姑苏擂台后林天南盛赞他「剑法精妙」，并认出他使的**像是蜀山仙剑派御剑术**，猜他是独孤剑圣弟子。故本剑的叙事定位＝「一招剑法撑起的江湖身份」，形制上是江湖游侠可得的实用青锋，**不是仙家法器、不刻门派徽记、不自带光效**；御剑态的剑光冷白属段7 释放期表现，非剑本身发光。段6 蒙尘态对应原作中他放下江湖、成家为父的阶段。
