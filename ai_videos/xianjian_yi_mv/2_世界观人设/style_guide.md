## 真实感强化条款（follow-up 015，2026-07-29 用户反馈「感觉图片真实感差一点，再加点真实感」）

「真人实拍 / photorealism」这几个词**不足以**把画面从「精修 CG 感」拉到「照片感」——模型默认会给到干净、对称、无瑕的皮肤与布料。真实感必须靠**具体的不完美**堆出来。

> **2026-07-29 二轮加严**：一轮只加了「质感形容词」，用户复评「真实感还是差一点」。**根因——形容词描述的是结果，模型需要的是过程**：要让它输出照片，得告诉它这张图**是用什么相机、什么镜头、什么光拍的**，并**显式否定「插画／概念稿」这条最强的竞争路径**。以下 ①′②′ 为新增的摄影层与反插画层，与原 ①② 并存。

**①′ 照片框定句（byte-identical，放在生成块最前的 `[摄影]` 段首句）：**
```
这是一张真实拍摄的照片，不是绘画、不是渲染图。
```

**①″ 摄影参数串（byte-identical，`[摄影]` 段 / `[风格]` 行）：**
```
全画幅相机实拍 · 85mm定焦人像镜 · f/2.0浅景深 · ISO400自然颗粒 · 真实白平衡轻微色偏 · 未修图直出
```
> 给出**具体的相机—镜头—光圈—感光度**比任何「photorealism」都有效：它把模型从「画一个人」切换到「拍一张照」。

**②″ 反插画负向组（byte-identical，追加进 `[负向]` / 外置反向提示词）：**
```
不要 插画 / 不要 概念设计稿 / 不要 数字绘画 / 不要 CG概念图 / 不要 游戏原画 / 不要 手绘感 / 不要 平涂 / 不要 边缘描线
```
> **这一组比「不要 CG 渲染感」更关键**——中文属性列表式的 prompt 天然把模型推向「游戏原画／概念设计」，必须点名否定。

**①″′ 背景改灰色无缝背景纸**：`纯白灰底` 读作产品图/3D 渲染；改写成 **`灰色无缝背景纸、有轻微光影不均`**，是真实影棚的样子。

**① 真实感串（byte-identical，每个人物/场景生成块的 `[风格]` 行尾整段追加）：**
```
35mm胶片颗粒 · 皮肤次表面散射与真实毛孔油光 · 布料纤维与磨损可辨 · 自然光柔和衰减与环境反射 · 轻微镜头畸变与浅景深 · 非完美对称的真实人脸
```

**② 反真实感负向组（byte-identical，每个生成块的 `[负向]` / 外置反向提示词整段追加）：**
```
不要 塑料感皮肤 / 不要 过度锐化 / 不要 蜡像感 / 不要 AI感网红脸 / 不要 完美对称 / 不要 3D渲染感
```

**③ 人物卡另须有 `面部细节:` 行**（皮相层，不改五官结构）——写**具体的不完美**：面部左右不对称、毛孔与角质分布、皮肤油光与透光并存、须发根根分明长短不齐、唇部纵向深纹、眼白细血丝、虹膜纹理、颈纹。角色年龄越大，这一行越要脏、越要具体。

**④ 判废线**：出图若见塑料皮肤、蜡像感、完美对称、AI 网红脸、布料无纤维质感，**或整体读作插画／概念设计稿** → 直接重出，不做后期补救。

## 气场/气质的四个杠杆（follow-up 015 二轮，2026-07-29）

「英雄气／威仪／仙气」这类**气场**类观感，一轮我只改了**面部细节**，效果不足。**第一眼决定气场的其实不是脸**——按效力排序：

| # | 杠杆 | 弱写法（读不出气场） | 强写法 |
|---|---|---|---|
| 1 | **姿态** | 斜倚、松斜、含胸、重心偏移 | **两脚分开与肩同宽、重心沉稳落在双脚之间、脊柱与颈笔直**；「松弛」只放在肩与手，**绝不放在骨架** |
| 2 | **构图/机位** | 平视 | **机位略低于视平线、微仰约 10 度**（拍出高度与压迫感）；反之要弱化气场就俯拍 |
| 3 | **光线** | 均匀柔和的正面平光 | **侧后轮廓光勾出肩背与发缘**——轮廓光是「气场」的**物理来源**，没有它再多形容词也白搭 |
| 4 | **道具入画** | 兵器背在身后/收在鞘中不可见 | **让身份道具进入画面并占据构图斜线**（如剑拎在手、剑尖斜指地面） |
| 5 | 面部细节 | —— | 眉宇/眼神/下颌，**排最后**，是前四项成立之后的加成 |

**执行**：凡人物卡 #2 写了气场类观感目标（英雄气／威仪／贵气／煞气…），其 ref 立绘块与 turntable 块**必须四项全配**，缺一即视为未落地。

> ### ⚠️ 铁律：气场不得用「视线移开」去换（follow-up 015c，2026-07-29）
> 追气场时很容易写成「目光越过镜头看向远处 / 望向画外 / 睥睨远方」——**这条路禁用**。
> **ref 立绘的首要功能是「供脸」**：它是 turntable 与全部 shot 的参考脸源。视线一移开、头一侧，模型拿不到干净的正面五官，整条角色一致性链就垮了。
> **正确写法**：**身体可取四分之三角度，但头必须转正、面部完整正对镜头、双眼直视镜头**；睥睨感由**下巴角度（微抬）＋ 眼神的定与锐 ＋ 微仰机位**共同承担，与视线方向无关。
> **配套负向（每张人物卡的 ref 立绘块与 turntable 块必带）**：`不要 侧脸 / 不要 转头 / 不要 低头 / 不要 仰头过度 / 不要 目光移开镜头 / 不要 眼神飘向画外`。
> *（同一条也适用于演员卡 `_actors/`——那边的模板本就写死「正脸正面平视镜头（绝不侧脸、不转头、不低头、不仰头）」，人物卡应对齐。）*

> 与 § 渲染样式串 的分工：渲染样式串管**成片镜头**的统一质感（shot 层），本条款管**参考图/立绘/turntable** 的皮相与材质精度（人物卡层）。二者不冲突、须并存。

## 人物服装色彩规范（follow-up 012，2026-07-28 用户反馈「色彩偏朴素一点，不用鲜艳的颜色」）

全片人物服装一律走**朴素、低饱和、做旧**的实拍质感，与「35mm 胶片颗粒 + 自然光影」的基调一致。这是**全局规范**，人物卡的配色串须落在此规范内：

- **饱和度**：所有衣料取同色系的**沉色/浊色**——靛蓝取洗旧暗靛蓝（近藏蓝）、紫取沉静葡萄紫—绛紫、绿取墨绿、黄取土黄褐、白取本白（微泛灰黄）。**禁**亮蓝/宝蓝/明黄/正红/艳紫/荧光色。
- **质感**：粗布、麻、洗白棉为主，**哑光无反射**；边角磨损、洗旧痕迹是加分项。**禁**绸缎亮面、崭新衣感。
- **装饰**：金银元素仅作**细窄一线的哑光暗金/素银**点缀（如月如短打滚边、阿奴银项圈），**禁**大面积织金、繁复绣纹、闪光镶边。
- **例外（唯二）**：① 拜月教主的玄黑教主袍与银灰月轮——反派的仪式感需要一点冷硬对比，但仍走暗哑不走亮面；② **阿奴筒冠两侧垂下的暗红串珠链与橙红长流苏穗、以及冠底一道橙红滚边**——苗饰的暖色点。（2026-08-03 follow-up 032 据用户提供的官方立绘图重定，见 c4 卡 #4。）（2026-08-02 follow-up 027 恢复：follow-up 024 曾把本条改成「深靛青衣上的窄条彩绣滚边」，其前提「青＝靛蓝」是误读，已作废。）
- **执行位**：写进每张人物卡的 #4 服装串 + `[细节] 材质` + `[风格]` 行 + 专属负向；shot 层由 `渲染样式:` 串的「布料低饱和做旧哑光」兜底。
