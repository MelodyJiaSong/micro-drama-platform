## 构成
- **人体**：MPFB（MakeHuman）真人底模 + 按角色卡调的 targets（男 / 年龄观感 52 / 亚洲面孔 / 171 cm / 清瘦但肩背宽阔 / 清癯长脸 / 颧骨突出双颊微陷 / 丹凤眼外眼角上扬 / 鼻梁高直鼻头略大 / 唇角微扬 / 法令纹），MPFB 增强 SSS 皮肤（middleage_asian_male 贴图 + 风霜暖调）；高模眼球（棕）、眉毛、睫毛、牙齿资产；下颌短须 + 唇上短髭 = 粒子毛发（纯黑）。
- **发型**：乌黑发帽 + 头顶偏后发髻 + 白色束髻布巾（带结与两条垂尾）。
- **服装**：青灰/灰蓝交领长袍 —— 四边形重网格布壳 → 布料模拟（Blender Cloth，碰撞人体）落成真实垂坠褶皱，腰部收束；交领 + 白色内衬领缘 + 白色中衣 V 形内衬；深褐/土黄布腰带（三圈 + 布结 + 两条垂带）；白裤自袍下露出；深色布鞋 + 鞋底。亚麻类材质为程序化织纹（经纬 wave + 噪声褪色 + bump）。
- **道具**：腰左侧赭褐色大葫芦（绳网 + 木塞 + 挂绳）、腰右侧施法小陶壶（麻绳）、背负长剑（黑漆鞘 + 古铜剑镖/鞘口/箍/剑格/剑首 + 缠绳剑柄 + 皮绳背带斜跨前胸）。
- **姿态 / 骨架**（v2，2026-08-16 21:10）：已加 MPFB 标准骨架 `JJX_Rig`（default 163 骨），手臂放下（上臂内收 27°、前臂后收 30°）并应用为静止姿态；袍子按此姿态重新布料模拟，袖筒垂坠、手自袖口露出、袖口白衬边。骨架保留在文件中，可继续摆姿势（改姿态后袍子需重跑布料）。

## 已知限制 / 后续可迭代
- 面部为参数化底模 + 程序化调整，非照片扫描；如需更贴主图脸型可继续调 MPFB targets 或雕刻。
- 发帽为网格壳（非逐根发丝）；胡须为粒子毛发。
- 手中未持葫芦/剑（主图为持物姿态；本模型为自然垂臂站姿）。
- 布料为一次性模拟结果（已应用为静态网格）；改姿态需重跑布料。
