## 本片的三条硬规则

1. **特效不按段落开闸，按事件本身的超自然性开闸**（`world.md § 二`，2026-08-02 改写）。原作有超自然性的场面一律按实拍特效大片尺度做满；原作是人间事的场面一律零法术。四级：T0 纯人间 / T1 灵异微光 / T2 术法显形 / T3 天地奇观。
2. **特效不算数，环境反应才算数。** 每个 T2/T3 镜必须写满至少两条环境反应（物理位移／光影投射／受体反应／同感视觉替身）。只写光不写反应＝贴图。
3. **hero 镜配额 10 个**，各自独占一个只在该镜出现的奇观元素，其余镜不得抢（见 `shotlist.md` § hero 镜配额）。

## 御剑三级递进（官方仙術层级，不自创招式视觉）

依据 `0_原作资料/guide_tw95/05_仙术与召唤.md`：**御剑术**（人立於地、劍化流光飛擊 → 段3 山神庙）→ **万剑诀**（密集剑芒/剑雨 → 素材池备选）→ **天剑**（一柄巨剑橫貫畫面）。段8a 的御剑飞行是「人立剑上破云」，与段3 的「剑离手贴地绕行」**视觉不得重复**。

## 3D previz（每镜必做 · 2026-08-22）

每个 shot 先出一份**等时长的 Blender 预演**，喂 Seedance 当动作与构图的权威参考。分工按信息层切：

- **3D 扛**：机位几何（焦段/高度/俯仰角/景别）、构图占画比、站位朝向、相对距离、尺度参照、遮挡关系、轨迹、时刻表、跨镜空间一致性。
- **Seedance 扛**：长相服装、面部表演与微表情、表演质感、次级运动（布料/头发/尘/水/烟）、材质光色氛围、特效形态、口型。

每镜落 `shots/shotNN/previz/previz_config.toml`——**这份声明式配置是本镜 3D 层的唯一真相**，改数值重跑即生效：

```
blender -b --factory-startup --python tools/previz/build_previz.py -- <配置路径>
```

`.blend` / `.mp4` / 帧序列都是派生物、不进版本库。分 A 档（布局解算，每镜必做）与 B 档（动作解算，只给轨迹镜/反常识状态镜），细则见 `agent_refs/project/ai_video.md` rule 12.16 §0。

**注意**：有场景 `.blend` ≠ 这个镜的那一处建了。s1 二层没建客房、s2 没建水下池心与桃林，这几镜用纯灰模 previz。
