# plot_0002 · 比武

有裁判、有观众、有明确判定的公开较量，主角以看起来不可能的方式取胜。
`plot_0001` 的武版骨架。**同剧可各用一次，但不要挨着放**——连着两场公开较量会疲。

## 功能位

| 位 | 作用 | |
|---|---|---|
| 被低估者 | 主角，战力被低估或被规则压制 | ✔ |
| 挑衅者 | 明面上碾压主角 | ✔ |
| 权威裁判 | 定规则宣胜负；**喊停的时机决定节奏** | ✔ |
| 起哄群众 | 声音层：赔率 / 嘘声 / 倒吸气 | ✔ |
| 懂行的旁观者 | 用一句话替观众看懂门道 | ✔ |

末位是武版比文版多出来的：**打斗的门道观众看不懂，没人说破，再精妙也只剩「打赢了」。**

## 节拍表（合计 32–50s）

| 拍 | 秒 | 内容 | 观众预期 | 这拍改变了什么 |
|---|---|---|---|---|
| 1 | 5–8 | 立规则 + 判定条件（点到 / 出圈 / 三招） | 有明确输赢 | 定死「怎么算赢」，后面才有空子 |
| 2 | 4–6 | 挑衅者亮实力，群众给赔率式反应 | 毫无悬念 | 把差距量化 |
| 3 | 3–5 | 主角提个不起眼的要求（只守三招 / 不用兵器） | 自找难看 | **埋反转**，后面兑现 |
| 4 | 10–15 | 挨打，只守不攻 | 撑不住了 | 把压抑堆满 |
| 5 | 3–5 | 一个动作定胜负，快到需要回看 | 刚才发生了什么 | **爽点** |
| 6 | 4–6 | 旁观者说破门道，裁判宣布 | 原来如此 | 把爽点从视觉翻成理解 |
| 7 | 3–5 | 收手，一句话或一个背影 | 他还藏着 | 下集钩子 |

**拍 4 是成败所在**：挨打不够长，拍 5 就不解气；挨打时必须让观众看见主角在**观察**
（视线落点、呼吸、脚下位移），否则挨打就只是挨打，不是蓄力。

## 爽点

爽的是**「原来他一直在等这一下」**，不是「他力气大」。
拍 3 的要求与拍 5 的取胜方式必须**严丝合缝对上**（说只守三招，就第三招结束时反打）；
拍 5 要**快**，慢动作会把「精妙」降级成「炫技」；拍 6 由旁人说破，主角全程不解释。

## 可替换变量

| 判定 | 点到为止 / 出圈 / 三招内 / 夺兵器 / 谁先落地 |
|---|---|
| 压制 | 境界差 / 禁用法宝 / 带伤 / 缚手 / 让对方先出手 |

| 彩头 | 入门名额 / 法器 / 替人出头 / 免罚 / 一个道歉 |
| 场地 | 擂台 / 演武场 / 山道 / 酒楼大堂 / 宗门广场 |
| 收场 | 对手再战 / 拜服 / 长辈叫停 / 主角伤势当场发作 |

## 坑

① 打太久——超 15s 纯打斗必须有信息增量（局势变化 / 台词 / 反应镜）
② 没有「懂行的旁观者」，门道无人说破 ③ 拍 3 伏笔与拍 5 取胜对不上（**最常见的写砸方式，写完回读这两拍**）
④ 慢动作展示取胜瞬间 ⑤ 群众给面孔 ⑥ 主角自己解释为什么赢
