# 仙侠通用桥段库 — 可复用的情节元件

诗文比试、比武这类小情节，抽掉人物 / 场景 / 具体世界观，只留结构，写新剧时当点缀填进去。
**只做仙侠**（含古装 / 武侠 / 玄幻近亲题材）；与同目录的 `parts/x*.md`（仙侠 canon 调研）互补——
canon 管**这个世界是什么样**，本库管**演什么**。

与 `ai_videos/_actors`（长什么样）· `_voices`（声音什么样）· `_performances`（怎么演）同属跨剧共用资产。

## 一条 entry 必须写满四样（缺一不算建好）

| | 内容 | 为什么 |
|---|---|---|
| 功能位 | 谁在场，只写作用不写人 | 套用时映射到本剧的人，一人可占两位 |
| 节拍表 | 每拍：秒数 · 内容 · 观众此刻的预期 · 这拍改变了什么 | 决定好看与否的是卡点，不是标题 |
| 爽点落点 | 爽的是哪一下，靠前面哪一拍憋出来 | 「他赢了」不是爽点，「所有人都以为他不识字」才是 |
| 可替换变量 | 比什么 / 彩头 / 羞辱形式 / 翻转手段 / 收场 | 变量越全，复用价值越高 |

## 布局与用法

`plots/plot_NNNN_{拼音}.md`，一条 entry 一个文件（挂了图才升级成目录）。
阶段 3 写大纲时**一存一取**：选中的注明 `桥段: plot_NNNN`，把功能位换成真人、变量填死
（填死的结果属于该剧，**不回写本库**）；这一轮新想出的通用小情节提炼成新 entry 存进来。

## 「哪条受欢迎」

只从 entry 末尾 `## 用例与反馈` 表派生，**不许在 entry 里写热度分数**。
别人的市场观察记 `## 出处`，与自有数据分开。
⚠️ 发布数据尚未回流，表全是空的——现在这个库只回答「有哪些元件可用」。
