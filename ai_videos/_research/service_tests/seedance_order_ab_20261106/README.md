# Seedance 写法 2×2 实测：镜头在前 × 方向以镜头为参照

2026-11-06，用户要求「实测一下，找一个好的案例」（ai_video_management follow-up 325，验证 follow-up 324）。调研与假设见 `.audit/adhoc_agents/2026-11-06/seedance-prompt-order/README.md`。

## 案例

`chuanyue_yiri` EP1 s1 st3（8 秒，跟拍）：Riley 背对镜头跟着牵骡子的挑夫走进城门洞，门洞左墙边有脚手架和递灰浆桶的工人；3–4 秒抬头看工人；4 秒停步转身对镜头说台词，镜头同时停住。选它的原因：一镜里同时有运镜要包住的动作（走 → 停 → 转身），也有只用东南西北写的方位（「由南向北」「往北走出画面」「西墙边」「另一头（北）」）。另一个会话当天用编译器 v12 出过一条 720p 正片（`baseline_v12_720p/`），脚手架被放在门洞外，抬头那一拍没拍出来。

## 结论

1. **镜头在前：本例没有看到好处，不改编译器。** 现行顺序的 A 两条和基线正片都是一条连贯的跟拍：镜头跟着走、4 秒同时停住、她原地转身，没有「拼出来」的割裂感。只把镜头提前的 O 两条反而最差：一条把整个空间拍反（走出城门到海边），一条把脚手架放到右侧；两条转身后都朝镜头走近或扑近，没有「原地停住」。n=2，不能说明镜头在前有害，但这一例没有支持「镜头在前更好」。这个假设要找现行写法确实出现割裂的镜头（复杂运镜、推拉环绕同时有动作）再测；仓库缺陷记录里目前没有这类问题。
2. **方向以镜头为参照：有弱支持，保留已写入的分镜规则。** 脚手架放在画面左侧：镜头参照（D、OD）4/4，东南西北（A、O）2/4；O 的两条都在这一项上出错。真正做到「门洞里面、左墙边」的只有 2 条（A 一条、OD 一条），两种写法打平。样本小，算方向一致的证据，不算定论。
3. **随机性大于写法差别。** 同一 prompt 的两条，门洞长短、明暗、骡子去向都完全不同；8 条都没让挑夫和骡子走出画面，「抬头看」只有 2 条做到。要稳定拿到这类空间关系，首帧图（仓库已有做法）比改写法更有效。
