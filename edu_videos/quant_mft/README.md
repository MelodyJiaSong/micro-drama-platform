# 系统化中频交易（quant_mft）

**Vision**：看完这个系列，观众能画出一个中频量化策略从数据到下单的完整流水线，说清楚它在中、美、欧、亚太各市场为什么要做得不一样，并能判断一类数据或一个机器学习模型值不值得用。
核心：每个概念都落到「它让预测更准、成本更低，还是风险更小」；用真实计算的小实验代替口号，不讲故事化的暴富，也不给任何投资建议。

- **受众**：有理工或金融本科基础、想了解量化交易的学生、转行者与初级研究员；会均值、方差、相关、线性回归。机器学习只需知道「训练 / 测试」，片中会带过；更深的先修链接到 [AI 高频词](../ai_terms/README.md)（如 t01 过拟合）与 [线性代数](../linear_algebra/README.md)（如 t15 PCA）。
- **语言**：中英两版同时出（`script.md` / `script.en.md`）。中文版英文术语第一次出现时中英对照（如「信息系数 IC」「另类数据 alternative data」），之后用行业通行说法。
- **时长**：每期 5–8 分钟，一期只讲一件事；内容多的拆成上下两期，不压语速。
- **画面**：纯黑舞台、频道统一包装与配色（`edu_videos/_shared/`）。流水线、市场结构、数据分类等概念图用 HyperFrames；收益曲线、IC 分布、成本曲线等数据图用 Manim，按真实计算出图（图表配色与标注照 `dataviz` 规范）。全球市场交易时段用一条 24 小时地球时钟贯穿第二单元。

## 节目模板（沿用频道包装 v2）

片头、本期内容、章节转场、片尾用频道共用模板；系列文字在 `_shared/package.json`，章节轨固定为下面六段。每期按本期主题改写章节标题（`package.json` 的 `chapters`），轨道名不变。

| 段 | 轨道名 | 要回答的问题 | 数据类期次 | 市场类期次 |
|---|---|---|---|---|
| ① 问题 | 问题 Question | 它在中频交易里解决什么问题、处在流水线哪一环 | 这类数据扮演什么角色 | 这个市场为什么值得单独讲 |
| ② 直觉 | 直觉 Intuition | 一个类比或一张图就能懂吗 | 生活里的类比 | 一句话画像 |
| ③ 机制 | 机制 Mechanics | 它具体怎么运作、有哪些类型 | **类型与特点**：频率、覆盖、历史长度、延迟、成本 | 交易所与时段、结算、涨跌停、做空、税费、对冲工具、参与者结构 |
| ④ 实验 | 实验 Experiment | 眼见为实 | 真实计算：这类数据做出的信号长什么样 | 真实计算：同一策略换市场规则后的变化 |
| ⑤ 难点 | 难点 Pitfalls | 哪里会出错、会骗人 | **难点**：清洗、对齐、时点、偏差、合规 | 规则限制、流动性陷阱、监管变化 |
| ⑥ 影响 | 影响 Impact | 对收益、容量、风险到底有多大影响；现实中出过什么事 | **影响力**：增量 IC、衰减速度、容量、拥挤 | 哪类 alpha 有效、容量多大、真实事件 |
| 片尾 | — | 一句话记住 + 下一期 | | |

## 知识点地图

`tNN` 是稳定编号；播放顺序以此表为准。

### 第一单元 地基：中频交易是什么

| 编号 | 知识点 | 核心画面 / 实验 | 工具 |
|---|---|---|---|
| t01 | 什么是系统化中频交易（**试点**） | 持仓周期对数轴：高频（微秒到分钟）、中频（小时到数周）、低频（数月以上）三段，各自比的是速度、预测还是耐心；「系统化」= 规则 + 数据 + 统计，与主观交易对照 | HyperFrames + Manim |
| t02 | 一个中频策略的流水线 | 数据 → 信号 alpha → 信号合成 → 风险模型 → 组合优化 → 执行 → 归因，按一个交易日的时钟循环一圈 | HyperFrames |
| t03 | Alpha 与信息系数 IC | 截面上几千只股票的预测与实际收益散点；IC 只有 0.03 也值钱：模拟主动管理基本定律 IR ≈ IC × √广度 | Manim（numpy 模拟） |
| t04 | 风险模型与中性化 | 收益拆成市场、行业、风格因子与残差；中性化前后的净值对比 | Manim |
| t05 | 交易成本与容量 | 价差、冲击（平方根律）与换手；成本曲线吃掉 alpha 的交点就是容量 | Manim |
| t06 | 回测会骗人 | 一千个随机策略里挑出「最好」的那个；前视偏差、幸存者偏差、多重检验与收缩后的夏普 | Manim（numpy 模拟） |

### 第二单元 市场：中国、美国、欧洲、亚太

每期都回答同一组问题：交易所与交易时段（含集合竞价）、结算制度、涨跌停与熔断、做空与融券、税费、可用的对冲工具、参与者结构（散户 / 机构）、监管对程序化交易的要求、可得数据；最后落到「对中频策略意味着什么」。

| 编号 | 知识点 | 核心画面 / 实验 | 工具 |
|---|---|---|---|
| t07 | 美国：最深也最拥挤的市场 | 碎片化的交易所与暗池、收盘竞价占比；做空方便但拥挤，alpha 衰减快 | HyperFrames + Manim |
| t08 | 中国 A 股：规则塑造的 alpha | T+1、涨跌停、融券受限、印花税、股指期货基差；散户占比高带来的反转与情绪信号；程序化交易监管新规 | HyperFrames + Manim |
| t09 | 欧洲：一个市场，多个国家 | 多国交易所与多边交易平台、多币种、多国金融交易税；收盘竞价与流动性集中 | HyperFrames |
| t10 | 亚太：日本、香港、韩国、台湾、澳洲、印度 | 午休、价格限制、做空制度各不相同；同一个反转信号在各市场的表现对比 | HyperFrames + Manim |
| t11 | 全球组合：时区、货币与假期 | 24 小时地球时钟上各市场依次开收盘；收盘价不同步、汇率对冲、假期错位怎么对齐 | HyperFrames |

## 本系列规则

- **不构成投资建议**：片尾卡与发布说明都写明「仅供教学，不构成投资建议」；不点名推荐具体股票、基金或策略，不展示可直接照抄的交易参数。
- **事实逐条核对**：市场规则（结算、涨跌停、税费、做空、程序化交易监管）变化频繁，每期写 `research.md`，逐条列官方或一手出处与核对日期，屏幕标注「截至 YYYY 年 MM 月」。本 README 只列话题，不写具体数字，数字以各期 `research.md` 为准。
- **案例有出处**：「⑥ 影响」里的真实事件（如 2007 年 8 月量化地震）用论文、监管公告或公开报告，原文怎么说就怎么讲，不演绎。
- **数据来源可商用**：实验优先用 numpy 合成数据；用真实数据只用许可允许公开展示的来源（如公开的因子收益库、央行与统计局数据），屏幕标注来源。不截图、不展示付费终端或数据商的原始数据。
- **机器学习实验诚实**：样本外结果才算数；展示「失败」与「虚高」和展示「有效」同样重要。
- 其余（配音、包装、审片、合成、AI 配音标注、外部服务审计）照 [edu_videos/README.md](../README.md)。
