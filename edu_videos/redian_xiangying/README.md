# 热点相迎（redian_xiangying）

**Vision**：每期用一个热点做开场，讲清它背后能留得住的道理——热度过去以后，这支片子仍然值得看。
核心：先大量检索、把事实摸清，再亮出我们自己的立场和一句话的认知精华；事实、观点、推测分开说，反方最强的论证也讲给观众听。

- **来源**：2026-11-14 用户发起；建议中采纳「定位、立场、素材版权、研究流程」四条，不采纳「Seedance 额外限制、固定片子结构、快慢两条线」（follow-up 见 `specs/edu_video/edu_videos/`）。
- **放在 edu_videos 下**：复用频道的网页场景、配音、包装和审稿工具；本系列的规则只写在本文件（系列级），跑通试点后再决定哪些升为共用。
- **与 edu_videos 大系列约定的差别**：画面可以用真实图片、视频节选和 Seedance 模拟视频，与 PPT 级网页场景穿插剪辑；配乐用 Suno。其余（配音、字幕、包装、请求日志、媒体不进 git）照大系列约定。
- **平台与语言**（用户 2026-11-14）：中英双语，B 站＋YouTube；中英两版同出，沿用 edu 的 `script.md` / `script.en.md` 对应规则。

## 一期的流程

用户给一个热点词 → 下面四步 → 剪辑出片。

### 1. 研究档案（`research/`）

大量检索最近一段时间与这个词有关的全部材料，按角度并行（可用 deep-research，多个子代理各查一个角度），每个角度一份 `research/angles/<角度>.md`，最后汇成 `research/dossier.md`（模板 `_shared/dossier_template.md`）。档案必须有：

1. **事件时间线**：每个节点有日期和出处。
2. **利益相关方**：谁、立场是什么、公开说过什么（原话＋出处）。
3. **原始材料与二手报道分开**：原文、公告、数据、判决书、财报等一手材料单列；媒体报道、评论、社交平台单列，并注明转述自哪里。
4. **别人已经讲过什么**：同类视频与文章的主要角度，找出我们独有的那个角度。
5. **一句话论点（认知精华）**＋它最强的反驳。

检索日期写在档案开头，片中说法一律以「截至某日」为准。

**搜索配额**（2026-11-14 实测）：Claude Code 每个会话的 WebSearch 上限为 200 次，主会话与所有子代理共用，约每小时恢复 100 次；不得用 curl、浏览器或第三方代理绕过。所以一次只跑一个话题的研究，每个角度约 20 次搜索；已知网址的一手来源（官方声明、SEC 文件、GAO 报告）直接用 WebFetch 读，不先搜。配额用完时在档案里标明哪些没查到，恢复后补查。档案写完交一位独立上下文的事实核查审过，再进讲稿。

### 2. 定位：热点开场，长期道理是正片

- 热点只用来开场。正片讲它背后的机制：这件事暴露了什么、为什么会发生、以后会怎样重演、对观众意味着什么。
- 一句话论点在研究阶段就定下，整支片子围绕它组织；与论点无关的材料再热闹也不放。
- 标题与开场可以借热点的热度，结尾落在长期能用的认知上。

### 3. 立场：事实、观点、推测分开

- 有自己的立场，但每个说法在讲稿里标明性质：**已证实** / **有争议** / **我们的判断**。观点要说「我们认为」，推测要说「可能」并说依据。
- 事实台账 `claims.json` 沿用 edu 格式：每条事实、数字、引语一条，写出处、原文原话和检索日期（字段 `as_of`）；带数字、百分比、引号的句子都要登记。
- 每期必须有一段讲**反方最有力的论证**，讲到对方本人听了也挑不出毛病，再说我们为什么仍然这样看。
- 涉及真实的人和机构，只引其公开、有记录的言行，不做无依据的动机推断。

### 4. 素材：版权分级与素材台账

**用户决定（2026-11-14，follow-up 022）**：本系列是热点类节目，官方新闻素材、新闻图片与视频节选**直接使用，不按网站条款或许可分级**；后果由用户承担。AI 工具本身的条款（`paid_services.md` § 商业用途）不受此影响。

每期的素材台账 `media_ledger.json`：每张图、每段视频一条，写原始链接、来源方、本片用了哪段（起止时间）、出现在第几段画面、下载时间与本地路径——用于片中标注来源，以及平台版权申诉时能快速定位、替换。原始下载放 `assets/source/`（不进 git）；没有台账条目的素材不进成片。
