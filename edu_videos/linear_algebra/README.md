# 线性代数（linear_algebra）

**Vision**：看完每一支，学生能在脑子里「看见」那个变换，而不只是会算。
核心：几何直觉先于计算——每个概念先给画面，再给公式，最后给算法。

- **受众**：大学低年级与自学者，会高中数学。
- **语言**：中文配音、中文字幕；记号用通行教材写法。
- **风格**：深色底、统一配色与字体（试点 t03 定稿后写进 `_shared/`）。
