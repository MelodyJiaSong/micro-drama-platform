## 损失函数是什么
- l05（5.2s / 停 0.3s）：模型每猜一次，跟真实答案总会差一点，差了多少，就叫误差。　〔画面：「差多少 = 误差」、图表〕
- l06（6.1s / 停 0.3s）：把一大堆误差汇成一个数，就是损失，也就是给模型这次表现打的分。　〔画面：「17.9」、「一堆误差 → 一个分」、图表〕
- l07（5.7s / 停 0.4s）：不过它跟考试分数反着来：分越低越好，零分最好，就是一点不差。　〔画面：「17.9」、「分越低越好」、图表〕
- l08（2.8s / 停 0.4s）：有点像打高尔夫，杆数越少越好。　〔画面：「17.9」、「分越低越好」、图表〕
- l09（7.2s / 停 0.4s）：有了这个分，机器就能自己比较：拧一下旋钮，分低了就是拧对了，分高了就拧回来。　〔画面：「8.6」、「拧一下，看分数」〕
- l10（4.8s）：所以训练说白了，就是一遍遍拧旋钮，把这个分压下去。　〔画面：「2.2」、「训练 = 把分压下去」〕

## 做个小实验
- l11（5.9s / 停 0.4s）：还是上一期那十二趟打车，横着是距离，竖着是车费，数据是示意的。　〔画面：图表〕
- l12（4.8s / 停 0.3s）：模型还是那条直线，两个旋钮：起步价，和每公里多少钱。　〔画面：「0」、「0」、图表〕
- l13（5.4s / 停 0.3s）：先试第一种拧法：起步价五元，每公里两元。这条线整个偏低了。　〔画面：「第一种拧法」、「5」、图表〕
- l14（6.3s / 停 0.3s）：拿五公里那趟来看：实际二十三元，模型猜十五元，差了八元，这就是误差。　〔画面：「第一种拧法」、「5」、图表〕
- l15（4.8s / 停 0.4s）：把误差平方一下，八乘八，六十四，就是图上这个红方块。　〔画面：「第一种拧法」、「5」、图表〕
- l16（5.0s / 停 0.4s）：十二趟都这么算，再取个平均，第一种拧法得了七十八分。　〔画面：「78」、「第一种拧法」、图表〕
- l17（6.1s / 停 0.4s）：第二种：起步价四元，每公里三块五。这回线太陡了，短途猜少，长途猜多。　〔画面：「第二种：太陡」、「4」、图表〕
- l18（6.5s / 停 0.4s）：要是不平方，直接平均误差呢？猜少是负的，猜多是正的，一正一负就抵消了。　〔画面：「第二种：太陡」、「4」、图表〕
- l19（4.1s / 停 0.3s）：平均下来只有负零点三元，看着好像几乎没错。　〔画面：「−0.33」、「第二种：太陡」、图表〕
- l20（5.2s / 停 0.3s）：这就是为什么要平方：平方以后全是正数，谁也抵消不了谁。　〔画面：「平方：全是正数」、「4」、图表〕
- l21（5.4s / 停 0.4s）：而且差得越多，罚得越狠：差两块只罚四，差八块就要罚六十四。　〔画面：「平方：全是正数」、「4」、图表〕
- l22（3.5s / 停 0.4s）：先平方再平均，第二种得了十三点四分。　〔画面：「13.4」、「平方：全是正数」、图表〕
- l23（4.6s / 停 0.3s）：这种打分法叫均方误差，是最常见的一种损失函数。　〔画面：「均方误差Mean squared error」、「4」、图表〕
- l24（6.7s / 停 0.3s）：第三种：起步价十元，每公里两块五。线贴着点走，方块都很小，只得二点一九分。　〔画面：「2.19」、「第三种拧法」、图表〕
- l25（3.0s / 停 0.3s）：三个分一比，第三种最低，拧得最好。　〔画面：「第三种拧法」、「10」、图表〕
- l26（7.2s / 停 0.3s）：可这才试了三种。把两个旋钮的所有拧法都算一遍，就能画出一张分数的地形图。　〔画面：「分数地形图」、「10」、图表〕
- l27（4.1s / 停 0.4s）：横着是起步价，竖着是每公里，颜色越深，分越高。　〔画面：「分数地形图」、「10」、图表〕
- l28（6.1s / 停 0.4s）：刚才那三种拧法，第一种在高处，第二种在半山腰，第三种快到谷底了。　〔画面：「分数地形图」、「10」、图表〕
- l29（5.9s / 停 0.3s）：最低的那个点，起步价大约十块二，每公里两块五四，分数一点九七。　〔画面：「1.97」、「分数地形图」、图表〕
- l30（4.8s）：这就是最好的拧法。训练要做的，就是找到这个最低点。　〔画面：「1.97」、「训练 = 找最低点」、图表〕

## 模型只认这个分
- l31（2.8s / 停 0.3s）：不过你注意，最低点也不是零分。　〔画面：「1.97」、「最低点 ≠ 0」、图表〕
- l32（5.9s / 停 0.3s）：车费里有堵车、绕路这些随机的波动，一条直线不可能每趟都猜中。　〔画面：「最低点 ≠ 0」、「堵车、绕路：随机波动」、图表〕
- l33（3.5s / 停 0.3s）：所以训练追求的不是零分，而是尽量低。　〔画面：「不求零分，求最低」、图表〕
- l34（5.4s / 停 0.4s）：还有更有意思的：模型根本不知道什么是打车，它只认这个分。　〔画面：「模型只认分数」、「不知道什么是打车」、图表〕
- l35（5.4s / 停 0.4s）：分怎么打，它就往哪学。比如我们用了平方，它就特别怕犯大错。　〔画面：「怎么打分，就怎么学」、「平方：特别怕大错」、图表〕
- l36（4.1s / 停 0.3s）：它宁可每趟都差一点，也不愿意有一趟差很多。　〔画面：「怎么打分，就怎么学」、「平方：特别怕大错」、图表〕
- l37（5.9s）：所以选什么样的损失函数，其实就是在告诉模型，什么才算「好」。　〔画面：「损失函数 / = 什么算「好」」、图表〕

## 大模型怎么打分
- l38（7.0s / 停 0.3s）：像 ChatGPT 这样的大语言模型，训练时也有个分，只是打分的对象换了。　〔画面：「大语言模型」、「训练时也有一个分」〕
- l39（5.2s / 停 0.3s）：它的任务是猜下一个词，比如「床前明月」后面该接什么。　〔画面：「床前明月光」〕
- l40（5.9s / 停 0.4s）：打分看的是，真正的下一个词，它给了多大把握：把握越小，罚得越多。　〔画面：「床前明月光」、「把握越小，罚得越多」〕
- l41（5.0s / 停 0.3s）：给正确的词九成把握，几乎不罚，只给一成，就罚得多得多。　〔画面：「床前明月光」、「把握越小，罚得越多」〕
- l42（6.5s / 停 0.3s）：这种打分叫交叉熵，英文是 cross-entropy，名字知道就行。　〔画面：「交叉熵」、「Cross-entropy」〕
