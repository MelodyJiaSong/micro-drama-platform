# t11 损失函数 Loss function（播放 1-3）

> 一句话：损失函数，就是给错误打个分，分越低越好；训练，就是把这个分压下去。

- **位置**：第 1 季第 3 期（`package.json` season 1 / episode 3）；前置 1-2 模型与参数（t10，开场一句话带过「模型 = 带旋钮的机器」）；下一期 1-4 梯度下降（t04）。片尾用「旋钮一多，地形图大得看不到边，该往哪边拧，才能一步步走到最低点？」接下一期，不讲怎么走。
- **旋钮画法**：照 t10 的全季画法在本期 `scenes/web/_lib.js` 的 `knob()` 里画了一份（白盘、细边、投影、270° 弧、已拧弧段琥珀、墨黑指针、读数在下）。
- **给 t04 的地形图**：`scenes/data.json` 的 `land`（横轴起步价 0–20 元、纵轴每公里 1–4 元，161×121 格，`z` 按行 = 每公里展开），等高线 2.5 / 5 / 10 / 20 / 40 / 80 / 160 / 320，颜色越深分越高（琥珀），最低点绿环；画法在 `_lib.js` 的 `makeLand()`。最低点 起步价 10.20、每公里 2.54、分数 1.97 = `_shared/s1_data.json` 的 best。三组拧法 ①（5, 2）78、②（4, 3.5）13.4、③（10, 2.5）2.19 都在图上。
