# t13 反向传播 Backpropagation（第 1 季第 6 期，播放 1-6）

> 一句话：反向传播，就是把错误从输出往回传，一层层分责任；倒着走一趟，每个旋钮该往哪拧、拧多少就全算出来了。

- **实验**（`scenes/data.py`，numpy 算、断言守住）：第一季打车数据里 5 公里、实付 23 元那一趟；两层小网络七个旋钮（A = 5×1+1 = 6，B = 5×0.4+2 = 4，猜 = 6×2 + 4×1 + 13 = 29）。倒着走一趟：最后一层责任 36、24、6，传回 A 12、B 6，第一层 60、12、30、6；按七个数拧一小步，29 → 23.88。挨个试拧数到正着算 8 遍，七个坡度与反向传播一致；1153 个旋钮的中号网络数到 1154 遍、坡度一致；十亿个旋钮挨个试 1,000,000,001 遍（一遍一秒约 31.7 年），反向传播约 3 遍正着的工夫（数乘法次数 2.89 倍）。
- **类比**：一串齿轮 ×2、×3，一路乘起来 6；倒着算每处只乘一次（链式法则只讲直觉、不点名）。
- **AI 例子**：Rumelhart、Hinton、Williams 1986《自然》论文（原文核对：「two passes」、隐藏单元学到特征）；PyTorch 官方教程：`loss.backward()` 自动求导即反向传播。限定语：类似算法更早已有人提出（Linnainmaa 1970、Werbos 1982）。出处见 `research.md`、`claims.json`。
