## 模型在学什么
- l09（7.9s / 停 0.3s）：过拟合，就是模型把练习题贴得太紧，连碰巧的细节也学了进去，一做新题反而变差。　〔画面：「过拟合」、「连碰巧的细节也学了进去」〕
- l10（5.2s / 停 0.3s）：就像把练习题背下来了，却没学会规律。我们用一个小实验来看看。　〔画面：「过拟合」、「连碰巧的细节也学了进去」〕
- l11（5.0s / 停 0.4s）：这十个点，是我们收集到的数据，叫训练数据，相当于练习题。　〔画面：「模型在学什么」〕
- l12（6.1s / 停 0.4s）：它们大致沿着某个规律分布，但每个点都有一点随机的偏差，这叫噪声。　〔画面：「模型在学什么」、「噪声：随机的偏差」〕
- l13（5.5s）：模型的任务，是从这些点里找出规律，好去预测没见过的新数据。　〔画面：「模型在学什么」、「找出规律 / → 预测新数据」〕

## 三种学法
- l14（7.9s / 停 0.4s）：第一种模型太简单，只会画直线。点离线越远，扣分越多；把扣分平均一下，就是误差。　〔画面：「同一组练习题，三种模型」、「误差」〕
- l15（4.1s / 停 0.3s）：直线连练习题的误差都压不下来，这叫欠拟合。　〔画面：「同一组练习题，三种模型」、「误差」〕
- l16（5.6s / 停 0.3s）：第二种，一条平缓的曲线。它没有穿过每一个点，但抓住了大的走势。　〔画面：「同一组练习题，三种模型」、「① 直线 / 0.53 / 欠拟合」〕
- l17（7.8s / 停 0.3s）：第三种，模型非常复杂，曲线拐来拐去，硬是穿过了每一个点。练习题上，它的误差是零。　〔画面：「同一组练习题，三种模型」、「① 直线 / 0.53 / 欠拟合」〕
- l18（3.5s）：先猜一下：换成新题，哪一种考得最好？　〔画面：「换成新题，谁考得最好？」、「① 直线 / 0.53 / 欠拟合」〕

## 考试
- l19（5.0s / 停 0.3s）：再拿六个新点，模型都没见过。这叫测试数据，相当于考试。　〔画面：「换成新题：考试」、「考题」〕
- l20（3.5s / 停 0.3s）：第二种曲线，离新点都不远，考得最好。　〔画面：「换成新题：考试」、「① 直线 / 0.53 / 0.54」〕
- l21（7.6s / 停 0.3s）：第三种曲线，在点和点之间乱拐，离有些新点很远。它的考试误差，是第二种的二十多倍。　〔画面：「③ 的考试误差：② 的 25 倍」、「① 直线 / 0.53 / 0.54」〕
- l22（7.5s / 停 0.3s）：它连噪声也一起背了下来，可噪声是随机的，到了新题不会重演。这就是过拟合。　〔画面：「③ 的考试误差：② 的 25 倍」、「噪声不会重演」〕
- l23（8.8s）：欠拟合好发现：练习和考试都差。过拟合难察觉：练习成绩可能好极了，像这里，练习误差是零。　〔画面：「欠拟合：两项都差，好发现」、「过拟合：练习好看，难察觉」〕

## 打个比方
- l24（7.6s / 停 0.3s）：有个学生，把练习册的答案全背了下来，连印错的几处也照背。练习册上，他次次满分。　〔画面：「100」、「连印错的也照背」〕
- l25（3.6s / 停 0.3s）：可一到考试，题目稍微换个样子，他就不会了。　〔画面：「题一变， / 就不会了」〕
- l26（11.0s / 停 0.4s）：放回实验里看：练习册是训练数据，印错的答案是噪声，考试是测试数据。死记硬背的学生，就是那条穿过每个点的曲线。　〔画面：「练习册 / → / 训练数据」、「印错的答案 / → / 噪声」〕
- l27（7.7s / 停 0.3s）：这个比方也有局限：学生知道自己在背，模型不知道。它只是足够复杂，连每个点都能记住。　〔画面：「学生知道自己在背」、「模型不知道」〕
- l28（7.1s / 停 0.4s）：还有一个相近、但不一样的毛病。教小朋友认猫，给他看的照片里，猫全都趴在沙发上。　〔画面：「猫，都在沙发上」〕
- l29（9.0s / 停 0.4s）：他学会的，可能是：沙发上的，就是猫。换成沙发上的小狗，他说是猫；草地上的猫，他反倒不认了。　〔画面：「他可能学到：沙发 = 猫」、「“是猫！”」〕
- l30（10.7s）：学生死背了答案，小朋友只见过沙发上的猫，两人都把眼前的例子当成了规律。小朋友这种毛病，叫捷径学习，后面还会说到。　〔画面：「死背答案」、「只见过沙发上的猫」〕

## 一张图看懂
- l31（8.2s / 停 0.3s）：回到实验。我们换三百组随机的点，每组都试一遍从简单到复杂的模型，看两种误差通常怎么变。　〔画面：「300」、「模型越复杂，误差怎么变？」、图表〕
- l32（4.6s / 停 0.3s）：练习误差一路往下走：模型越复杂，练习题做得越好。　〔画面：「300」、「模型越复杂，误差怎么变？」、图表〕
- l33（5.6s / 停 0.3s）：考试误差却先降后升。中等复杂的模型，预测新数据最准。　〔画面：「300」、「模型越复杂，误差怎么变？」、图表〕
- l34（5.2s / 停 0.4s）：所以，练习误差很低、考试误差却很高，就是过拟合的信号。　〔画面：「模型越复杂，误差怎么变？」、「练习误差低 / 考试误差高」、图表〕
- l35（10.0s）：那模型越简单越好吗？也不是。太简单，两种误差都高，就是左边的欠拟合。要找的，是两种误差都低的那一段。　〔画面：「模型越复杂，误差怎么变？」、「越简单越好？」、图表〕

## 学习就是压缩
- l36（3.4s / 停 0.3s）：换个角度想：学习，可以看成一种压缩。　〔画面：「学习 ≈ 压缩」〕
- l37（5.4s / 停 0.4s）：要原样记住这十个点，就得存下十个数字，也就是每个点的高度。　〔画面：「记住十个点，要几个数字？」、「原样记：10 个数字」〕
- l38（5.7s / 停 0.4s）：第二种曲线，只用四个数字，就能大致画出这些点，新点也估得准。　〔画面：「记住十个点，要几个数字？」、「原样记：10 个数字」〕
- l39（9.6s / 停 0.4s）：第三种曲线要十个数字，才能穿过全部十个点。十个数字记十个点，等于没压缩，连噪声也一起存了下来。　〔画面：「记住十个点，要几个数字？」、「原样记：10 个数字」〕
- l40（7.1s）：好的压缩，要留住规律、少记噪声；可压过了头，像那条直线，连规律也丢了。　〔画面：「留住规律，少记噪声」、「压过头：连规律也丢了」〕

## 现实里的代价
- l41（3.0s / 停 0.4s）：这类毛病，在现实里真的闯过祸。　〔画面：「它真的闯过祸」〕
- l42（6.4s / 停 0.4s）：谷歌流感趋势，曾用人们的搜索记录，估算去看病的人里，有多少是流感样症状。
- l43（5.9s / 停 0.4s）：它最初从五千万个搜索词里，挑出跟一千多个历史数据点最贴合的那些。　〔画面：「≫」、「Lazer 等 ·《Science》· 2014」〕
- l44（10.3s / 停 0.4s）：可挑的词远比数据点多，总有一些，只是碰巧在冬天搜得多。研究者说，这是过拟合：它既在测流感，也在测冬天。　〔画面：「“一部分在测流感， / 一部分在测冬天”」、「研究者：这是过拟合」〕
- l45（6.8s / 停 0.4s）：后来的版本还是不准：二零一一到二零一三年，一百零八周里，有一百周估高了。　〔画面：「100」、「/ 108」〕
- l46（7.0s / 停 0.4s）：医学影像里也有。一个看胸片诊断肺炎的模型，换到一家新医院，成绩就掉了下来。　〔画面：「换到新医院，成绩下降」、「Zech 等 ·《PLOS Medicine》·」〕
- l47（8.0s / 停 0.4s）：研究者另训了一个模型，专门看胸片认医院：在两家医院的片子上，准确率超过百分之九十九点九。　〔画面：「99.9%+」、「+」〕
- l48（10.0s / 停 0.3s）：而各家医院的片子里，标成肺炎的比例差得很远。所以肺炎模型的好成绩，很可能有一部分靠的是认医院，而不是认病。　〔画面：「34%」、「34% vs 1%」〕
- l49（11.1s / 停 0.4s）：还有个识别皮肤癌的系统。医生常在可疑的痣上画标记，它很可能把标记当成了线索：画了标记的良性痣，一半多被它判成了癌。　〔画面：「54%」、「画了标记的良性痣，被判成癌」〕
- l50（11.2s）：胸片和痣这两个例子，和认猫的小朋友一样，是捷径学习，过拟合的近亲。它们在熟悉的环境里也许考得不错，换个环境就可能失灵。　〔画面：「换个环境，就可能失灵」、「学到的线索，只在手头数据里成立」〕

## 怎么防
- l51（4.1s / 停 0.3s）：那该怎么发现和避免过拟合？常用的办法有三个。　〔画面：「三个常用办法」〕
- l52（9.3s / 停 0.3s）：第一，再留出一份数据当模拟考，叫验证集：用它来挑模型、及早发现过拟合，真正的考试留到最后。　〔画面：「三个常用办法」、「留一份模拟考」、图表〕
- l53（7.2s / 停 0.4s）：坦白一句：刚才为了演示，我们直接按考试成绩挑了模型；实际做项目，可不能这样。　〔画面：「三个常用办法」、「留一份模拟考」、图表〕
- l54（6.0s / 停 0.4s）：第二，收集更多、更多样的数据，噪声和巧合，就不容易被当成规律。　〔画面：「三个常用办法」、「留一份模拟考」、图表〕
- l55（9.1s）：第三，给模型立规矩：对过于复杂的曲线加惩罚，让它别去追着噪声跑。这类方法叫正则化。　〔画面：「三个常用办法」、「留一份模拟考」、图表〕
