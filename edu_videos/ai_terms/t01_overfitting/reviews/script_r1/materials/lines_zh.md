### s2 模型在学什么（章节 problem）
| 句号 | 中文 |
|---|---|
| l09 | 先给一句话：过拟合，就是把练习题背下来了，却没学会规律。下面用一个小实验看清楚。 |
| l10 | 这十个点，是收集到的数据，叫训练数据，相当于练习题。 |
| l11 | 它们大致沿着某个规律分布，但每个点都带着一点随机的偏差，也就是噪声。 |
| l12 | 模型的任务，是从这些点里找出规律，好去预测没见过的新数据。 |

### s3 三种学法
| 句号 | 中文 |
|---|---|
| l13 | 先说误差：就是点和曲线差得有多远，越小越好。第一种模型太简单，只会画直线，连练习题都对不上，这叫欠拟合。 |
| l14 | 第二种，一条平缓的曲线。它没有穿过每一个点，但抓住了大的走势。 |
| l15 | 第三种，模型非常复杂，曲线拐来拐去，硬是穿过了每一个点。练习题上，它的误差是零。 |
| l16 | 先猜一下：换成新题，哪一种考得最好？ |

### s4 考试
| 句号 | 中文 |
|---|---|
| l17 | 拿出六个模型从没见过的新点，这叫测试数据，相当于考试。 |
| l18 | 第二种曲线，离新点都不远，考得不错。 |
| l19 | 第三种曲线，在点和点之间乱拐，有的新点一下就差出去很远。它的考试误差，是第二种的二十多倍。 |
| l20 | 它把练习题里的噪声，也一起背了下来。这就是过拟合。 |
| l21 | 欠拟合的模型，一眼就能看出不行；过拟合更危险：在你手里的数据上，它看起来好极了。 |

### s5 打个比方（章节 analogy）
| 句号 | 中文 |
|---|---|
| l22 | 有个学生，把练习册的答案一字不落，全背了下来。练习册上的题，他次次满分。 |
| l23 | 可一到考试，题目稍微换个样子，他就不会了。 |
| l24 | 对上刚才的实验：练习册就是训练数据，考试就是新数据，背下来的答案，就是那条硬穿过每个点的曲线。 |
| l25 | 再比如，教小朋友认猫。给他看的照片里，猫全都趴在沙发上。 |
| l26 | 他学会的，可能是：沙发上的，就是猫。换成沙发上的小狗，他说是猫；草地上的猫，他反倒不认了。 |
| l27 | 两个例子是同一件事：记住了只在手头数据里成立的东西。不过类比也有不像的地方：模型不会偷懒，它只是被允许记得太多。 |

### s6 一张图看懂（章节 experiment）
| 句号 | 中文 |
|---|---|
| l28 | 回到实验。把它重复三百次，让模型从简单变到复杂，看两种误差怎么变。 |
| l29 | 练习误差一路往下走：模型越复杂，练习题做得越好。 |
| l30 | 考试误差却先降后升。中间那一段，才是真正学到了规律。 |
| l31 | 所以，练习误差很低、考试误差却很高，就是过拟合的信号。 |
| l32 | 那模型越简单越好吗？也不是。太简单，就是左边的欠拟合。要找的，是中间刚刚好的那一段。 |

### s7 学习就是压缩（章节 lens）
| 句号 | 中文 |
|---|---|
| l33 | 换个角度想：学习，其实是一种压缩。 |
| l34 | 这十个点，要原样记住，就得存下十个高度。 |
| l35 | 第二种曲线，只用四个数字，就把它们大致说清了，还能说中没见过的点。 |
| l36 | 第三种模型有十个数字，正好够把十个点原样存下来。它不用找规律，所以也就没找。 |
| l37 | 真正的理解，是用更少的东西，解释更多的事。 |

### s8 现实里的代价（章节 real）
| 句号 | 中文 |
|---|---|
| l38 | 这种毛病，在现实里真的闯过祸。 |
| l39 | 谷歌曾用人们的搜索记录估算流感。研究者指出，它从五千万个搜索词里，挑出最能贴合一千多个历史数据点的那些，这正是过拟合：它既在测流感，也在测冬天。 |
| l40 | 后来的版本也没好多少：2011到2013年，108周里，有100周估高了。 |
| l41 | 医学影像里也有。研究者发现，胸片里藏着医院的“指纹”：另训一个模型，几乎能百分之百认出片子来自哪家医院。看肺炎的模型，好成绩很可能有一部分就靠认医院，而不是认病；换到一家新医院，成绩就掉了下来。 |
| l42 | 还有一个识别黑色素瘤的系统：医生在皮肤上画的标记笔迹，让它把一半多的良性痣，都误判成了癌。 |
| l43 | 后两个例子，专业上叫捷径学习，是过拟合的近亲：在手里的数据上表现亮眼，学到的却是巧合，不是规律。 |

### s9 怎么防（章节 fix）
| 句号 | 中文 |
|---|---|
| l44 | 那该怎么发现和避免过拟合？常用的办法有三个。 |
| l45 | 刚才为了演示，我们直接拿考试挑了模型；实际该这样做。第一，再留出一份数据当模拟考，叫验证集：用它来挑模型、及早发现过拟合，真正的考试留到最后。 |
| l46 | 第二，收集更多、更多样的数据，噪声和巧合，就不容易被当成规律。 |
| l47 | 第三，限制模型的复杂度，别让它有本事把每个点都背下来。这类方法叫正则化。 |
