## 过拟合是什么
- l03（8.5s / 停 0.3s）：过拟合说白了，就是模型学得太死，连数据里碰巧出现的细节都记住了，换成新数据反而答不准。　〔画面：「过拟合」、「偶然的细节也学进去」〕
- l04（9.0s / 停 0.3s）：打个比方，有个学生把练习册的答案全背了下来，连印错的那几处也照着背，所以练习册他回回满分。　〔画面：「100」、「连印错的也照背」〕
- l05（3.5s / 停 0.3s）：可一到考试，题目稍微变一下，他就不会了。　〔画面：「题一变， / 就不会了」〕
- l06（6.2s / 停 0.4s）：这里的练习册，就是模型手里的数据，那几处印错的地方，就是数据里的噪声。　〔画面：「练习册 / → / 训练数据」、「印错的地方 / → / 噪声」〕
- l07（4.5s）：模型把噪声也当成规律记住了，这就是过拟合。　〔画面：「练习册 / → / 训练数据」、「印错的地方 / → / 噪声」〕

## 三种学法
- l08（5.9s / 停 0.4s）：你看，这里有十个点，是收集来的数据，叫训练数据，相当于练习题。　〔画面：「十个点：训练数据」〕
- l09（6.8s / 停 0.3s）：这些点大致有规律，但每个点又有点随机的偏差，这些偏差就是噪声。　〔画面：「十个点：训练数据」、「噪声：随机的偏差」〕
- l10（5.0s / 停 0.4s）：模型要做的，就是从这些点里找出规律，去预测没见过的新点。　〔画面：「十个点：训练数据」、「找出规律 / → 预测新点」〕
- l11（4.1s / 停 0.4s）：我们试三种模型。第一种太简单，只会画直线。　〔画面：「同一组练习题，三种模型」〕
- l12（4.2s / 停 0.3s）：点离线越远，扣分越多，平均扣多少，就是误差。　〔画面：「同一组练习题，三种模型」、「误差」〕
- l13（4.8s / 停 0.4s）：结果这条直线连练习题都做不好，这就叫欠拟合。　〔画面：「同一组练习题，三种模型」、「误差」〕
- l14（4.7s / 停 0.4s）：第二种是条平缓的曲线，没穿过每个点，但抓住了大走势。　〔画面：「同一组练习题，三种模型」、「① 直线 / 0.53 / 欠拟合」〕
- l15（7.3s / 停 0.4s）：第三种就复杂多了，曲线拐来拐去，硬是穿过了每一个点，所以它的练习误差是零。　〔画面：「同一组练习题，三种模型」、「① 直线 / 0.53 / 欠拟合」〕
- l16（4.5s）：你先猜一下，换成新题，这三种里哪一种考得最好？　〔画面：「换成新题，谁考得最好？」、「① 直线 / 0.53 / 欠拟合」〕

## 考试
- l17（5.7s / 停 0.4s）：我们再拿六个没见过的新点考考它们，这叫测试数据，就相当于考试。　〔画面：「换成新题：考试」、「① 直线 / 欠拟合 / 0.53 / 0.54」〕
- l18（3.1s / 停 0.3s）：第二种离这些新点都不远，考得最好。　〔画面：「换成新题：考试」、「① 直线 / 欠拟合 / 0.53 / 0.54」〕
- l19（4.4s / 停 0.3s）：第三种在练习点之间乱拐，离有些新点特别远。　〔画面：「换成新题：考试」、「① 直线 / 欠拟合 / 0.53 / 0.54」〕
- l20（3.0s / 停 0.4s）：它的考试误差，是第二种的二十多倍。　〔画面：「③ 的考试误差：② 的 25 倍」、「① 直线 / 欠拟合 / 0.53 / 0.54」〕
- l21（8.8s / 停 0.4s）：为什么会这样？因为它把噪声也背下来了。可噪声是随机的，到了新题里不会再来一遍，这就是过拟合。　〔画面：「噪声不会重演」、「① 直线 / 欠拟合 / 0.53 / 0.54」〕
- l22（4.1s / 停 0.4s）：欠拟合其实挺好发现的，它练习和考试都差。　〔画面：「欠拟合：练习考试都差，好发现」〕
- l23（6.6s）：过拟合就难发现了，练习成绩可能好得出奇，像这里练习误差是零。　〔画面：「欠拟合：练习考试都差，好发现」、「过拟合：练习成绩好，难发现」〕

## 学习就是压缩
- l24（3.7s / 停 0.3s）：咱们换个角度看，学习其实可以看成一种压缩。　〔画面：「学习 ≈ 压缩」〕
- l25（5.2s / 停 0.3s）：想原样记住这十个点，就得存十个数字，也就是每个点的高度。　〔画面：「记住 10 个点，要几个数字？」、「原样记：10 个数字」〕
- l26（7.9s / 停 0.3s）：第二种曲线只用四个数字就能画出来。它大致贴着这些点，新点也估得准，这就算压缩了。　〔画面：「记住 10 个点，要几个数字？」、「原样记：10 个数字」〕
- l27（3.5s / 停 0.4s）：第三种得用十个数字，才能穿过这十个点。　〔画面：「记住 10 个点，要几个数字？」、「原样记：10 个数字」〕
- l28（5.7s / 停 0.4s）：十个数字记十个点，等于根本没压缩，连噪声也一起存了下来。　〔画面：「记住 10 个点，要几个数字？」、「原样记：10 个数字」〕
- l29（8.4s）：所以好的压缩，是把规律留下、把噪声扔掉。可要是压过了头，就像那条直线，连规律也给丢了。　〔画面：「留住规律，少记噪声」、「压过头：连规律也丢了」〕

## 一个真实的例子
- l30（8.5s / 停 0.4s）：说个真事儿：谷歌做过个项目，叫流感趋势，想靠搜索记录，估一估看病的人里，症状像流感的占多少。　〔画面：「谷歌流感趋势」、「用搜索记录估流感」〕
- l31（5.5s / 停 0.3s）：一开始，它拿一千多个流感数据点，去五千万个搜索词里挑走势最像的。　〔画面：「远多于」、「Lazer 等 ·《Science》· 2014」〕
- l32（6.5s / 停 0.4s）：问题是，能挑的词比数据点多太多，难免挑中只是碰巧在冬天搜得多的词。　〔画面：「碰巧在冬天搜得多的词」、「Lazer 等 ·《Science》· 2014」〕
- l33（5.4s / 停 0.3s）：研究者说这就是过拟合，它一部分在测流感，一部分在测冬天。　〔画面：「“一部分在测流感， / 一部分在测冬天”」、「研究者：这是过拟合」〕
- l34（7.6s）：后来的版本也不准：从二零一一年到二零一三年，一百零八周里，有一百周它都估高了。　〔画面：「100 / 108 周」、「流感估计偏高」〕

## 怎么防
- l35（4.9s / 停 0.3s）：那过拟合怎么发现，又怎么防呢？常用的办法有三个。　〔画面：「三个常用办法」〕
- l36（5.2s / 停 0.3s）：第一，再留出一份数据来当模拟考，这份数据叫验证集。　〔画面：「三个常用办法」、「① 验证集：模拟考」、图表〕
- l37（4.8s / 停 0.4s）：拿它来挑模型、早点发现过拟合，真正的考试留到最后。　〔画面：「三个常用办法」、「① 验证集：模拟考」、图表〕
- l38（6.3s / 停 0.3s）：说实话，刚才演示时，我们是直接按考试成绩挑的模型，真做项目可不能这么干。　〔画面：「三个常用办法」、「① 验证集：模拟考」、图表〕
- l39（6.3s / 停 0.4s）：第二，多收些数据，越多样越好，噪声和巧合就不容易被当成规律了。　〔画面：「三个常用办法」、「① 验证集：模拟考」、图表〕
- l40（7.7s）：第三，给模型立点规矩，曲线太复杂就扣分，别让它追着噪声跑，这个办法叫正则化。　〔画面：「三个常用办法」、「① 验证集：模拟考」、图表〕
