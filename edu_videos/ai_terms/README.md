# AI 高频词（ai_terms）

**Vision**：每支讲透一个 AI 高频词，看完能用一句大白话跟别人解释清楚。
核心：先给生活里的类比，再看一个真实算出来的小实验，最后一句话带走；不用公式也能懂。

- **受众**：对 AI 好奇、没有机器学习背景的普通观众与学生。
- **语言**：中英两版同时出（`script.md` / `script.en.md`），各自配音、字幕；中文版英文术语第一次出现时中英对照。
- **画面**：纯黑舞台（`style.set_stage("#000000")`，与统一包装一致），频道统一风格（`edu_videos/_shared/style.py`）；类比插图用 Codex 出图（平面插画、频道配色）；实验图由真实计算生成，不手画数据。需要立体感的概念（如卷积的特征图）再试 three.js / Blender。

## 节目模板 v2（2026-11-08 起试用，t01 按此重做；follow-up 004 / 006）

时长：每期 3–5 分钟、一个概念讲透、例子宁少勿多，不放「本期内容」卡（2026-11-09 用户定，follow-up 012/013，取代 2026-11-08「时长不设上限」）。中英两版同时出。片头、章节转场、章节转场、片尾是全系列共用的包装：模板 `edu_videos/_shared/package/template.html`，系列文字 `_shared/package.json`，每期文字在知识点 `package.json`，`tools/edu_video.py package` 按时间轴渲（纯黑舞台、大字、青蓝紫渐变强调、留白）。
「⑤ 现实」的案例必须有原文出处、逐条核对数字（写进该期 `research.md`），屏幕标注来源；原文没说是过拟合的（如捷径学习）照原文说法讲。

| 段 | 内容 | 要回答的问题 |
|---|---|---|
| 片头（包装） | 系列名、期数、中英标题 | 这是哪一期 |
| 本期内容 | 本期四件事 + 建议先了解（链接到前置期） | 我要学什么、需要什么基础 |
| ① 问题 | 它要解决什么问题；不同情形（如欠拟合 / 刚好 / 过拟合）各有什么后果 | 为什么要关心 |
| ② 类比 | 生活里的类比与比喻 | 一句话能懂吗 |
| ③ 实验 | 真实计算的小实验 | 眼见为实 |
| ④ 视角 | 认知层面怎么看待它（如「学规律 vs 记数据」「模型是对世界的压缩」） | 我该怎么理解它 |
| ⑤ 现实 | 真实世界的影响案例，屏幕标注来源 | 现实中出过什么事 |
| ⑥ 对策 | 怎么发现、怎么避免 | 我能做什么 |
| 片尾（包装） | 一句话记住 + 下一期 | 带走什么 |

章节之间用统一转场卡（章节号 + 中英章节名 + 底部进度轨）。
