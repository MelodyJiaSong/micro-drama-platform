### s2 规则写不完（章节 problem）
| 句号 | 中文 |
|---|---|
| l09 | 先看传统的电脑程序：人把规则一条一条写好，电脑照着执行。 |
| l10 | 算工资、订机票，规则说得清清楚楚，这样做就够了。 |
| l11 | 可有些事，规则谁也说不清。比如，认出一个手写的数字三。 |
| l12 | 这些全是真人写的三：有的胖，有的瘦，有的歪。你一眼就能认出来。 |
| l13 | 可要把「怎么认」写成规则，就难了。上下两个弯？八也是。下半截开口朝左？五也是。 |
| l14 | 规则写得再多，也总有漏掉的写法，也总会把别的数字认成三。 |

### s3 换个做法
| 句号 | 中文 |
|---|---|
| l15 | 今天的 AI，大多换了一个做法：不写规则，给例子。 |
| l16 | 给电脑看成百上千张手写的数字，每一张都告诉它答案：这是三，这是七。 |
| l17 | 它自己从例子里找出规律。这种做法，叫机器学习。 |
| l18 | 学出来的东西，叫模型。以后来一张新图，模型就给出它的答案。 |
| l19 | 所以，AI 背后并不是程序员写好的一条条答案；它的本事，大多是从数据里学来的。 |

### s4 打个比方（章节 analogy）
| 句号 | 中文 |
|---|---|
| l20 | 这就像教小孩认数字。你不会给他一本说明书，写着：三，是两个半圆叠在一起。 |
| l21 | 你只是指着数字，一遍一遍地告诉他：这是三。看得多了，他就会认了，连没见过的写法也认得出。 |
| l22 | 小孩，就是模型；你指给他看的，就是带答案的例子。 |
| l23 | 不过有两点不像：模型要的例子，通常比小孩多得多；它学会的规律，常常连做它的人也说不清。 |
| l24 | 再比如做菜。一种厨师照着菜谱，一步一步做；另一种厨师尝过一千道菜，自己琢磨出了菜谱。 |
| l25 | 传统程序，是照菜谱做菜；机器学习，是从一千道菜里，自己总结出菜谱。 |

### s5 亲手做个实验（章节 experiment）
| 句号 | 中文 |
|---|---|
| l26 | 我们真的来做一次。这是一个公开的手写数字数据集，一共1797张，每张只有八乘八个格子。 |
| l27 | 先拿出三百张锁起来，训练的时候一张都不许看，留着当考试题。剩下的，是给它学的例子。 |
| l28 | 先猜一下：只给它看十个例子，考试能答对多少？ |
| l29 | 随便抽十个，往往有几个数字它一张都没见过，考试只答对了37%左右。比瞎猜的10%强，但还差得远。 |
| l30 | 给它看一百个例子，答对了88%。 |
| l31 | 看完全部将近一千五百个例子，答对了97%。 |
| l32 | 自始至终，没有人告诉它三长什么样。它见得越多，认得越准。相册认猫，也是同一个道理。 |
| l33 | 不过，三百道考题，它还是错了十道。有几张，连人看了都要犹豫。 |

### s6 一台预测机器（章节 lens）
| 句号 | 中文 |
|---|---|
| l34 | 换个角度想：今天的 AI，其实就像一台预测机器。 |
| l35 | 给它一样东西，它猜一个答案，还带着把握。比如这张图，它说：96%是三。 |
| l36 | 给它一张照片，它猜里面有没有猫；给它一段声音，它猜说的是哪几个字。 |
| l37 | 给它半句话，它猜下一个词；一个词接一个词地猜下去，就成了一段回答。能跟你聊天的大语言模型，核心本事就是这样猜，只是猜得非常非常好。 |
| l38 | 这几个词，是一个套一个的。AI 是最大的圈，人写规则的办法也算 AI；机器学习在它里面。 |
| l39 | 再往里是深度学习：用很多层简单计算叠起来的模型来学，这种模型叫神经网络。大语言模型，是深度学习的一种。 |
| l40 | 今天大家说的 AI，大多指的就是机器学习。 |

### s7 现实里的影响（章节 real）
| 句号 | 中文 |
|---|---|
| l41 | 这种从数据里学的本事，已经在改变现实。 |
| l42 | 蛋白质的形状，过去靠实验测，一个往往要好几年。AlphaFold 从已知的结构里学会了直接预测；带领研发它的两个人，因此分享了2024年诺贝尔化学奖的一半。 |
| l43 | ChatGPT 上线大约两个月，月活跃用户估计就过了一亿。 |
| l44 | 但它学到的不只有规律。据路透社报道，亚马逊曾想用 AI 筛简历；可这个 AI 学的，是公司过去十年收到的简历，大多来自男性。 |
| l45 | 结果，简历里只要出现「女子」这个词，英文是 women's，比如「女子国际象棋社社长」，就会被扣分。这个工具后来被放弃了。 |
| l46 | 数据里有什么，它就学什么，包括偏见。 |

### s8 用好它的三个提醒（章节 fix）
| 句号 | 中文 |
|---|---|
| l47 | 所以，用 AI 的时候，记住三点。 |
| l48 | 第一，它只会它学过的。我们给它看一个字母 A：它从没见过字母，又只能在零到九里挑一个，于是一本正经地说：92%是四。 |
| l49 | 第二，它给的是预测，不是真理。刚才那张写得很潦草的二，它有81%的把握说是一，还是错了。 |
| l50 | 第三，它的本事和毛病，都来自数据。判断一个 AI 靠不靠谱，先问它是从什么数据里学的。 |
