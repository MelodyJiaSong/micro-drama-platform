# 测验（不含答案）

**Q1** 下面哪件事，最需要让电脑「从例子里学」，而不是由人把规则写好？  
Which task most needs a computer to learn from examples, rather than follow rules people write?
- A 按税率计算个人所得税 / A Calculating income tax from tax brackets
- B 判断一段录音里的人是不是在生气 / B Telling whether the speaker in a recording is angry
- C 按出发时间给航班排序 / C Sorting flights by departure time
- D 把摄氏度换算成华氏度 / D Converting Celsius to Fahrenheit

**Q2** 一个识别鸟类的 App 能认出几百种鸟。它最可能是怎么做出来的？  
A bird-ID app can recognize hundreds of species. How was it most likely built?
- A 程序员为每种鸟写下羽毛、喙、体型的规则 / A Programmers wrote rules about feathers, beaks and size for each species
- B 给模型看大量标好鸟名的照片，让它自己找规律 / B A model was shown many photos labeled with species names and found the patterns itself
- C 把所有鸟的照片存起来，拍到一模一样的就报名字 / C It stores every bird photo and names an exact match
- D 让模型上网搜索每张照片 / D The model searches the web for each photo

**Q3** 小王训练了一个识别手写字母的模型。要知道它在真实使用中准不准，最好的检验办法是？  
Someone trains a model to read handwritten letters. What is the best way to find out how well it will do in real use?
- A 用训练时给它看过的字母考它 / A Test it on the letters it was trained on
- B 用一批训练时从没给它看过的字母考它 / B Test it on letters it never saw during training
- C 看它说出答案时的把握有多高 / C Check how confident it sounds
- D 数一数模型有多大 / D Count how big the model is

**Q4** 一个只学过猫狗照片的模型，看到一张兔子照片，说「狗，把握 90%」。这说明什么？  
A model trained only on cats and dogs is shown a rabbit and says "dog, 90% sure." What does this show?
- A 兔子长得确实像狗 / A Rabbits really do look like dogs
- B 模型坏了，需要重装 / B The model is broken and must be reinstalled
- C 它只能在学过的选项里挑，把握高也不代表对 / C It can only choose among what it learned, and high confidence doesn't mean it's right
- D 90% 说明它有九成可能是对的 / D 90% means it is probably right

**Q5** 下面哪句话是对的？  
Which statement is correct?
- A AI 就是指聊天机器人 / A AI just means chatbots
- B 机器学习包含 AI / B Machine learning contains AI
- C 大语言模型是深度学习的一种，深度学习属于机器学习 / C Large language models are a kind of deep learning, which is part of machine learning
- D 人写规则的程序不能算 AI / D Programs built from hand-written rules can't count as AI

**Q6** 一家医院用过去十年的病历训练 AI，而这些病人大多是城市居民。用到农村病人身上时，最该担心什么？  
A hospital trains an AI on ten years of patient records, mostly from city residents. What is the biggest worry when it is used on rural patients?
- A 不用担心，AI 是客观的 / A No worry, AI is objective
- B 它学到的规律可能不适合农村病人，甚至带着偏差 / B What it learned may not fit rural patients and may carry a bias
- C 病历太多，模型会算不过来 / C Too many records will overload it
- D 只要把握高就没问题 / D As long as it's confident, it's fine
