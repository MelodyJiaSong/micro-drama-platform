# 讲稿（中文）

### s0 冷开场（冷开场）
| 句号 | 中文 |
|---|---|
| l01 | 手机相册能从照片里认出你家的猫，可没人把认猫的规则，一条条写给它。 |
| l02 | 那它怎么会的？给它看大量例子，它自己学出了规律。这，就是今天的 AI。 |

### s2 规则写不完（章节 problem）
| 句号 | 中文 |
|---|---|
| l03 | 传统的电脑程序，是人把规则一条条写好，电脑照着执行。 |
| l04 | 算工资、订机票，规则清清楚楚，这样就够了。 |
| l05 | 可有些事，规则很难写全，比如认一个手写的三。人写的三有胖有瘦有歪，你一眼就认得出。 |
| l06 | 真要写成规则，就难了。说上下两个弯吧，八也是。说下半截开口朝左吧，五也是。 |
| l07 | 这样写，会漏掉一些三，也会把别的数字认成三。 |

### s3 换个做法
| 句号 | 中文 |
|---|---|
| l08 | 所以今天的 AI，大多换了个做法：不写规则，给例子。 |
| l09 | 给电脑看成百上千张手写数字，每张都告诉它答案：这是三，这是七。 |
| l10 | 它自己从例子里找出规律，这种做法叫机器学习。 |
| l11 | 它学出来的那套认法叫模型，来一张新图，模型就给出答案。 |
| l12 | 很多人以为，AI 的本事是程序员一条条写进去的。其实大多是从例子里学来的，这些例子就叫数据。 |

### s5 做个小实验（章节 experiment）
| 句号 | 中文 |
|---|---|
| l17 | 咱们真做一次。这是一套公开的手写数字图片，一共1700 多张，每张只有八行八列的小格子。 |
| l18 | 先拿出三百张锁起来当考试题，剩下的给它学。 |
| l19 | 看例子学习的过程叫训练，训练时考试题一张都不许看。 |
| l20 | 只有考没见过的题，才知道它是真会认了，还是只是记住了。 |
| l21 | 你先猜猜：只给它看十个例子，考试能答对多少？ |
| l22 | 随便抽十个，常常有几种数字一张都没抽到。 |
| l23 | 这样换着抽二十回，一般只答对37%左右，比瞎猜的10%强些，可还差得远。 |
| l24 | 给一百个例子，答对88%。把将近一千五百个例子全看完，答对97%。 |
| l25 | 从头到尾没人给它写认三的规则，只告诉它哪张是三。在这次实验里，例子越多，考得越好。 |
| l26 | 但三百道题，它还是错了十道，比如这张潦草的二，认成了一。 |

### s6 换个角度看（章节 lens）
| 句号 | 中文 |
|---|---|
| l27 | 刚才那个模型，其实就是在预测：看一张图，猜它是几。今天的 AI 就像一台预测机器，猜的不是未来，是答案。 |
| l28 | 咱们这个模型不光猜，还会说有几成把握。这张图，它有96%的把握说是三。 |
| l30 | 别的 AI 也一样。给语言模型半句话，它猜下一个词，一个接一个猜下去，就成了一段回答。 |
| l31 | 能跟你聊天的大语言模型，就是这么回答的。 |
| l32 | 它猜得很好，也从数据里学到很多知识，可话接得顺，不保证说得对。 |

### s7 一圈套一圈
| 句号 | 中文 |
|---|---|
| l33 | AI 包括机器学习，像大圈套小圈。最外圈是 AI，也叫人工智能，就是让电脑做看着要动脑子的事。 |
| l34 | 人写规则的下棋程序也算 AI，算工资的普通程序就不算。 |
| l35 | 机器学习在 AI 里面，再往里是深度学习。它用的模型叫神经网络，就是很多层简单的计算，一层叠一层。 |
| l36 | 深度只是说层数多，不是理解得深。大语言模型，就是用深度学习做出来的。 |
| l37 | 这期说的 AI，就是机器学习这一圈。 |

### s8 一个真实的例子（章节 real）
| 句号 | 中文 |
|---|---|
| l38 | 从数据里学，也可能学歪。路透社报道过，亚马逊想过用 AI 筛简历。 |
| l39 | 它学的是公司过去十年收到的简历，大多来自男性。 |
| l40 | 结果它等于自己学会了「男性候选人更好」。 |
| l41 | 简历里只要有英文 women's，也就是「女子的」，就会被扣分，比如「女子国际象棋社社长」。 |
| l42 | 这个工具后来没做下去。数据里的偏见，也可能被它一起学走。 |

### s9 用的时候记住三点（章节 fix）
| 句号 | 中文 |
|---|---|
| l43 | 所以用 AI 的时候，记住三点。 |
| l44 | 第一，没学过的东西它也会硬答。给这个只认数字的模型看一个字母 A，它只能在零到九里挑。 |
| l45 | 它说有92%的把握是四，其实只是说：在零到九里，这张图最像四。 |
| l46 | 小孩会说「这不是数字」，它不会。 |
| l47 | 第二，再有把握也会错。刚才那张潦草的二，它有81%的把握说是一，照样错了。 |
| l48 | 第三，它哪儿行、哪儿不行，跟它学的数据有关，也跟它怎么设计、怎么训练有关。 |
| l49 | 判断一个 AI 靠不靠谱，先看它是拿什么数据学的。 |
| l50 | 下次 AI 很有把握地回答你，就想一想：这种问题，它学过吗？ |
