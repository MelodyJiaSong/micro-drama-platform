# 探索（tansuo）

**系列**：两位固定主角带观众缩小、放大、走进平时看不见的地方，一个主题一季。第一季：**芯片**（用户 2026-11-14 定为探索系列，follow-up 029/030）。主角跨主题、跨系列复用。

**第一季 Vision（芯片）**：跟着两个人缩小进一颗芯片，看见上百亿个开关真实的样子和尺度；看完能跟朋友讲清楚芯片里面有什么、为什么难造。
核心：比例尺贯穿全片，每一级只讲这一级最值得看的东西；结构按真实尺寸来，画不出来的地方明说是示意、为什么只能示意。

- **来源**：2026-11-14 用户发起（follow-up 027）：虚拟人物缩小到芯片上看电路结构与纳米级晶体管、参观制造厂房；先 research 全部芯片细节，再创作 AI 视频；两个人物一问一答。目录原为 `edu_videos/chips/`，2026-11-14 改为 `tansuo/`。
- **受众**：好奇、没有专业背景的普通观众与学生。
- **语言与平台**：**一套画面、中英两版配音**（follow-up 029/030 用户采纳）：`script.md` / `script.en.md` 照 edu 对应规则，B 站＋YouTube。正脸说话的特写少用，必须用的少数镜头中英各出一条口型。
- **时长**：每期 3–5 分钟、一个概念讲透（edu 大系列约定）。

## 画风：电影写实（用户 2026-11-14 选定 S2，follow-up 028）

像在芯片里拍的纪录片：真人、真实材质（抛光的铜、灰色的硅、透明玻璃质的绝缘层、深钢灰的接触与栅极金属），电影感布光（柔和主光＋轮廓光、轻微雾气、浅景深）。样张 `_shared/style_options/B_cinematic.png`；同屏信息图与包装仍照频道设计规范。
写实画面最容易被当成「真的就长这样」，所以真实性角标和「示意」字幕不能省（见下节）。

### 特效：华丽，但每个特效都在讲一件真事（用户 2026-11-14，follow-up 032）

既然用 AI，特效要漂亮、敢想象：体积光、粒子、光迹、辉光、爆炸分解、尺度涟漪都可以用。约束只有三条：

1. **特效画的是真实存在的东西**：光（波长、干涉）、电信号（快）、电子（慢、成群漂移）、栅压形成的导电通道、原子与电子云、尺度变化、把结构剖开 / 分解。画法可以夸张，屏幕标「示意」。
2. **结构本身不改**：导线、栅极、纳米片、晶格的形状、层次、相对尺寸仍照研究档案；不画装饰性的假电路花纹、发光纹路、漂浮的界面文字。
3. **全系列固定的标志特效**：探索表启动时表盘泛起琥珀色的同心「刻度涟漪」（无数字），缩小 / 放大都用它，观众一看就知道「要变尺度了」。

固定配色：电信号 = 冷白蓝光迹；电子 = 暖琥珀色小光点；光波 = 柔和彩虹缎带；剖开的切面 = 微亮的白边。

## 与 edu 大系列约定的差别（系列级例外）

大系列约定「画面由程序算出、不用生成式视频出主体画面」。本系列要让人物站在芯片里，改为混合：

1. **结构准确的画面**（晶圆、die 地图、金属互连、FinFET / 纳米片晶体管、光刻步骤）用 Blender 或代码按研究档案的尺寸建模渲染；
2. **人物与氛围镜头**用 Seedance（Dreamina）出片，拿 Blender 渲染图或故事板图做首帧 / 参考，让人物站在准确的结构上；
3. **说明性画面**（比例尺、数字、标签）照频道网页场景与设计规范（`edu_videos/_shared/design/`），后期叠加；
4. 收费调用照 `CONVENTIONS.md`「外部服务请求审计」先记日志，**生成视频一律人点**；出图用 Codex（`tools/codex_image.py`）。

**诚实标注**：纳米尺度的画面都是示意。片中第一次进入纳米尺度时用一句话讲清为什么（可见光波长比晶体管大，这里本来就「看」不见），角落常驻「示意」小字；颜色、材质照研究档案「给画面的建议」；特效照上面「特效」一节（画真实现象、标示意，不画装饰性的发光电路纹）。

**不用的素材**：真实晶圆厂与设备的实拍、拆解机构的显微照片都有版权，只作建模参考，不进片；画面里不出现任何真实公司的品牌、标志。讲到真实公司只作事实引用，写出处。

## 一期的流程

1. **研究档案** `research/`：按角度并行检索（`research/angles/*.md`），汇成 `research/dossier.md`；每个数字进 `claims.json`（出处、原文原话、`as_of`）。交独立上下文事实核查后才进讲稿。搜索配额照 `redian_xiangying` 的说明，一次只跑一期。
2. **节拍** `beats.md`：每一拍的比例尺级别、要讲清楚的意思和事实、阿凯问什么（不写措辞）。
3. **故事板** `storyboard/`：每格一张图（Codex 出图，人物设定图做参考）＋这一格的台词草稿、比例尺读数、画面来源（Blender / Seedance / 网页场景）。用户 review 通过后再定每个镜头怎么出。
4. **讲稿**：照 edu「先说后写」，两个角色各由一位另起上下文的讲解员按节拍说出来，作者剪短、核事实；`lint` 后过台词审。
5. **出片**：Blender 结构镜头 → Seedance 人物镜头（人点）→ 网页场景叠加 → 配音 → `mux`；审片照 edu 三层审查。
