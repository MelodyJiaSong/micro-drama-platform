# t11 肝脏段动态预演 v4

五镜共40秒，无声。正式配音尚未校准；本产物用于审运动、构图和讲解顺序，不是最终成片。

| 镜头 | 秒数 | 镜内运动 |
|---|---:|---|
| V23 | 7 | 镜头接近肝脏定位模型，尺度涟漪扩展 |
| V24 | 7 | 他汀作用标记接近酶，合成产物出现间隔加长 |
| V25 | 9 | 沿膜移动，受体位点逐渐增多，LDL持续经过 |
| V26 | 7 | 跟随一颗LDL结合、膜内陷、囊泡分离 |
| V27 | 10 | 时间省略后拉远，较少颗粒仍在循环 |

成品为 `liver_motion_v4.mp4`；分镜使用五张 `Vxx_poster.png`，由对应动态帧提取。`Vxx.mp4`、`.blend` 与 `frames_eevee/Vxx/` 可追溯。旧 `frames/` 是早期Cycles试验，不进入当前视频。

深色环境、暖金LDL、青色膜、折叠曲线受体均是功能示意。肝脏定位与细胞尺度之间有剪辑省略；不把LDL放大到器官尺度。受体不是原子结构重建；V26前侧为剖切、囊泡线框代表包膜，实际细胞膜没有展示用的缺口。颗粒数量、颜色和时间均不作定量证据，V27也不表示所有脂质被清空。

本地Blender EEVEE渲染960×540、12个运动采样帧/秒，FFmpeg封装为24 fps。无外部收费生成请求。顶部短标题及功能图例用于识别，不使用机制流程卡替代运动。

重建：仓库根目录运行 `python edu_videos/tansuo/t11_inside_an_artery/storyboard/liver_motion/build.py render`，再运行同脚本 `concat`。`encode V24 V26` 可单独更新叠字。渲染器会跳过已存在的帧；改模型或动画后必须先将受影响镜头帧目录移到本目录内单独的历史目录，再重渲，不能将旧帧混入新版。

原预览入口不变。全片台词、知识口径与323秒估算不因本次美术改版改变。最终音频听审、正式科学模型质量与成片审查仍属于后续阶段。
