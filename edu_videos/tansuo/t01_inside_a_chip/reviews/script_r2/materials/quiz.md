# 测验（不含答案）

**Q1** 朋友拆开手机，指着主板上一块黑色方块说「这就是芯片」。更准确的说法是？  
A friend opens a phone, points at a black square on the board and says "that's the chip." What's more accurate?
- A 对，黑色那块就是芯片本身 / A Yes, the black block is the chip itself
- B 那是外壳，真正的芯片是里面一片薄硅 / B That's the package; the real chip is a thin slice of silicon inside
- C 芯片是那块绿色的电路板 / C The chip is the green circuit board
- D 芯片在黑块上面的金属盖里 / D The chip is in the metal lid on top of the black block

**Q2** 一座城市修路：要把电和货物从城外运到每家门口。照芯片导线的办法，路应该怎么修？  
A city has to bring power and goods from outside to every doorstep. Following how chip wiring works, how should the roads be built?
- A 只修一种宽度的路，铺满全城 / A One width of road everywhere
- B 上层修宽的干道跑远路，越靠近家门越细越密 / B Wide highways for long distances, getting narrower and denser closer to each door
- C 全修细小巷，越多越好 / C Only tiny alleys, as many as possible
- D 每家拉一条直通城外的专线 / D A private line from every home straight out of town

**Q3** 老式继电器开关靠一块铁片被吸过去接通。芯片里的晶体管没有任何会动的零件，它靠什么接通？  
An old relay connects when a piece of iron is pulled over. A chip's transistor has no moving parts. What makes it connect?
- A 里面有更小的铁片在动 / A Even tinier iron pieces move inside
- B 栅极电压用电场把硅里的电子聚成通道 / B The gate's voltage uses an electric field to gather electrons in the silicon into a channel
- C 电流从栅极直接流进硅里 / C Current flows straight from the gate into the silicon
- D 硅片受热膨胀，两头碰上 / D The silicon heats up and expands until the ends touch

**Q4** 如果把栅极和硅之间那层极薄的绝缘层拿掉，最可能出什么问题？  
If you removed the very thin insulator between the gate and the silicon, what would most likely go wrong?
- A 没问题，开关照样工作 / A Nothing; it still switches fine
- B 栅极的电会直接漏进硅里，开关控制不住 / B Current would leak straight from the gate into the silicon and the switch couldn't be controlled
- C 晶体管会变得更快 / C The transistor would get faster
- D 硅会变成金属 / D The silicon would turn into metal

**Q5** 有人说「只要光学显微镜倍数够大，就能拍清手机芯片里的晶体管」。为什么不行？  
Someone says "with enough magnification, an optical microscope could photograph a phone chip's transistors." Why not?
- A 芯片外壳挡住了 / A The package blocks the view
- B 光的波长比晶体管宽得多，再放大也是糊的 / B Light's wavelength is much wider than a transistor, so it stays blurry however much you magnify
- C 晶体管是透明的 / C Transistors are transparent
- D 晶体管动得太快 / D Transistors move too fast

**Q6** 一款手机芯片宣传「3纳米工艺」。下面哪句对？  
A phone chip is advertised as "3 nm." Which statement is right?
- A 里面每个晶体管都是3纳米大 / A Every transistor is 3 nm across
- B 栅极之间正好隔3纳米 / B Gates are exactly 3 nm apart
- C 「3纳米」是工艺代号，不直接对应某个物理尺寸 / C "3 nm" is a process name and does not directly correspond to a physical dimension
- D 导线宽3纳米 / D The wires are 3 nm wide

**讲回来**：看完请用三五句话给朋友讲：手机芯片里面有什么？晶体管这个开关是怎么通、怎么断的？ / In three to five sentences, tell a friend what's inside a phone chip, and how a transistor switches on and off.
