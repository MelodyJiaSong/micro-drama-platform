### s16 加电，通；撤电，断
| 句号 | 中文 |
|---|---|
| l59 | [林] 栅极和硅片之间，隔着一层极薄的绝缘层，它俩没贴在一起。 |
| l60 | [林] 现在，给栅极加上电压。看，电场穿过绝缘层，把硅里的电子吸到绝缘层附近。 |

| l62 | [林] 再把电压撤掉：电子散开，通道没了，又断了。 |
| l63 | [林] 从头到尾，没有一个机械零件在动。变化的，是电场和电子的分布。 |
| l64 | [凯] 等一下，中间隔着绝缘层，栅极碰都碰不着那些电子，凭什么能把它们拉过来？ |
| l65 | [林] 你玩过磁铁吧？隔着一张桌子，桌上的铁屑也会跟着磁铁走。这里也是隔着东西施力，只不过起作用的不是磁场，是电场。 |
| l66 | [凯] ……就这样？我还以为里头藏着什么小机关呢。 |
| l67 | [林] 就这样。加电，通。撤电，断。 |

### s18 零和一
| 句号 | 中文 |
|---|---|
| l71 | [凯] 来了来了，是我那一下！……可是一个开关通一下、断一下，跟我手机里的照片、消息有什么关系？ |
| l72 | [林] 数字电路里，常用高、低两种电压表示一和零。开关的通断，用来产生和传递这些信号。 |
| l73 | [林] 一个 N 型和一个 P 型晶体管配合，就能搭成常见的 CMOS 反相器：输入一，输出零。输入零，输出一。再把这样的电路组合起来，才能做判断、存照片、放视频。 |
| l74 | [林] 你看，你那一下到了：栅极亮了，通道通了，信号接着传给下一个开关。而手机芯片的时钟，一秒能走几十亿拍。 |
| l75 | [凯] 所以我刚才点那一下，就是从这儿亮起来的。……找到你了。 |
