# 频道设计规范 v1（教学视频 · edu_videos）

> 2026-11-08 用户从对比样张中选定：**S3 浅色舞台 · P3 暖琥珀 · F3 MiSans · I1 哑光陶土 3D**。
> 数值的唯一来源是 `tokens.json`；网页场景与包装用生成的 `web/tokens.css`，出图 prompt 取 `tokens.json` 的 `illustration.prompt`。
> 依据：`edu_videos/_shared/research/explainer_benchmark.md`（对标与学习科学）。定稿样张：`/character-review?path=edu_videos/_shared/design`（V01–V11）。

## 1. 气质

精修、克制、像一本好的精装书：浅色舞台、大字、留白、一个暖色强调。每一个画面都在讲概念，没有装饰。
刻意避开 B 站「黑底 + 发光 + 同款 BGM」的 AI 量产风（观众已审美疲劳）。

## 2. 颜色

| 角色 | 值 | 用在哪 |
|---|---|---|
| 舞台 | `#FBFBFD` | 全片背景 |
| 卡片 / 次级底 | `#FFFFFF` / `#F2F2F5` | 浮起的卡片、分组底 |
| 细线 | `#D9D9DE` | 分隔线、图表基线 |
| 文字 | 墨 `#1D1D1F` · 次 `#424245` · 辅 `#6E6E73` · 弱 `#AEAEB2` | 标题 / 正文 / 说明 / 未激活 |
| 强调 | 琥珀 `#D97706`（图形）· `#C2410C`（文字）· 渐变 `#F2A007 → #E0560F` | 每屏最多一处；渐变只用于标题关键词与片头片尾 |

**数据颜色全系列固定含义**（观众学会一次，每期都认得）：

| 含义 | 颜色 | 形状 |
|---|---|---|
| 练习题 / 训练数据 | 墨 `#1D1D1F` | 实心圆点 |
| 考题 / 测试数据 | 琥珀 `#D97706` | 空心圈 |
| 模拟考 / 验证数据 | 紫 `#7C6FD8` | 空心方 |
| 刚刚好 / 正确 | 绿 `#16A34A` | 只用于结论 |
| 过拟合 / 出问题 | 红 `#DC2626` | 只用于结论 |
| 被比较的次要对象 | 灰 `#A1A1A6` | 例：欠拟合的直线 |

## 3. 字体与字号

- 字体：**MiSans**（中英同一家族；免费商用，片尾与简介注明「字体：MiSans」）。数字用等宽数字（tabular）。
- 字号阶梯（1920×1080）只用六档：display 132 · h1 76 · h2 54 · body 38 · caption 28 · micro 22；最小 22px。
- 字重：标题 700、副标题 600、正文 500、说明 400。眉题（eyebrow）大写、字距 0.16em。
- 一屏最多三层字号；数字可以做主角（大数字卡）。

## 4. 版式

- 安全区：左右各 120px，上 96px，**底部 150px 留给字幕**，任何文字不进字幕带。
- 12 栏网格、栏距 32px；常用分割：左图 7 栏 + 右文 5 栏；或居中单栏。
- 圆角 28px；阴影极轻（`0 24px 60px rgba(29,29,31,.08)`）；不用描边框住内容。
- 图表：不画坐标框和网格，只留一条基线；**标签直接贴在所指之物旁，不用图例**；同屏不超过 3 条曲线。

## 5. 动效

- **一次只动一样东西**；动画只表现变化，没有变化就不动。
- 进场：缓出 `cubic-bezier(.22,1,.36,1)`，0.7 秒，上移 24px、去模糊；退场：缓入，0.45 秒。
- 画线 1.2 秒缓入缓出；数字滚动用于结论数字。
- 强调只用：变色、放大到 1.04、下划线画出。**禁用**闪光、抖动、画圈、弹跳、旋转入场、打字机特效。
- 画面跟着配音走：每个元素在讲到它的那句开口时出现（`EDU.t("lNN")`），讲完的元素退后（降低透明度）而不是突然消失。

## 6. 插图（I1 哑光陶土 3D）

- 只在类比、比喻段落用；能用排版或数据图讲清的不用插图。
- 统一风格见 `tokens.json` 的 `illustration.prompt`：暖白陶土、柔和棚拍光、`#FBFBFD` 无缝底、一处琥珀点缀、画面里无文字。
- 同一类比的角色与物件前后一致：后续出图用前一张做参考图。
- 入画时边缘用径向遮罩柔化到舞台色，不出现图片矩形边。

## 7. 包装

片头（系列名 + 期数 + 中英标题）、本期内容（四件事 + 先修）、章节转场（章节号 + 标题 + 进度轨）、片尾（一句话 + 下一期 + 「AI 配音 · 字体 MiSans」），模板 `edu_videos/_shared/package/template.html`，文字在系列与每期的 `package.json`。冷开场排在片头之前。

## 7.5 屏幕文字（PPT 式画面，用户 2026-11-08）

屏幕只列纲要：关键词、短语、关键数字、标签；解释交给口播，不把口播整句印上屏，也不出现口播没说过的说法。硬上限——中文：标题 ≤12 字、其余每块 ≤16 字、同屏 ≤4 块、一屏 ≤36 字；英文：标题 ≤6 词、每块 ≤9 词、同屏 ≤4 块、一屏 ≤22 词（不含页眉小标签、出处、图表刻度）。下一屏出现时，上一屏的说明要收走，不层层叠加。计数：页眉小标签、页签、出处、片尾署名不计；同构列表 / 表格行（每项 ≤8 字或 ≤6 词、≤6 项）合算 1 块；图里的区域名、曲线名、轴标题要计字数，整张图算 1 块，只有坐标刻度豁免（台词审第 2 轮裁决）。目录、章节卡、页眉的章节叫法与编号全片一致。中文短语不带句末句号；英文 sentence case、无句末句号、列表语法平行。

## 8. 字幕

字幕固定在底部字幕带，深色字、不加底框；中文每屏 ≤ 20 字，英文 ≤ 42 字符；断行在意群之间，不在虚词后断。

## 9. 怎么检查

- 程序：`tools/edu_web.py check`（文字出安全区、压字幕带、重叠、小于最小字号）、`tools/edu_review.py validate`。
- 人：审查机制里的「美术指导」角色按本规范逐条看（`edu_videos/_shared/review/roles.json`）。
