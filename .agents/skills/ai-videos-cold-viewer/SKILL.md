# 冷眼观众（只看屏幕）

所有别的审稿人都读了备注、人物卡、立项——作者知道的东西会自己把空白补上，于是看不出观众缺了什么。
本 skill 的审稿人**只拿观众拿得到的东西**。来源：shengji_zhilu follow-up 038（「shot5 的时候，观众怎么知道他们要去做什么任务，目的是什么」）。

## 1. 输入（只有这一份）

```bash
python tools/script_tools.py screen <集目录>/script.md <审计目录>/screen_only.md
```

它只留每镜的场景展示、画面动作与台词；备注、情绪说明、⚠ 制作注记、台词行尾的表演说明与中文意思一律拿掉。
外语咒词（技能口令，rule 45）全剧第一次出现时要有人把意思说出来，之后不要求听懂。

审稿子代理**只许读这一个文件**。画面动作里写的内心活动（「他想起…」「他以为…」）不算观众知道的；没交代过的专名只是一个音。

## 2. 逐镜写三行

| 行 | 写什么 |
|---|---|
| 正在做什么 | 主角此刻想干成什么 |
| 为什么 | 谁让干的 / 动机 / 不干会怎样——看不出就写「不知道」 |
| 没看懂 | 没说出来就冒出来的目标、没人应就接下的活、来路不明的奖赏或东西、跟不上的换地点与跳时间、看不出是谁的人、没见过铺垫的回收 |

最后理**目标线**（每件事：谁要、哪镜说出、谁接下、哪镜了结）与**本事线**（每个人会什么、哪镜学的、哪镜用出来；follow-up 039；每样学会的本事再问一句「他凭什么在这一刻学会？」——没有铺垫、成得莫名其妙就记一条，follow-up 045；入门课再问三句：「来得太容易吗（一问就会）？」「师父做给他看过吗、我能照着做一遍吗？」「这本事有什么用，我在画面里看见了吗？」——follow-up 046），标出没说清 / 没人接 / 没了结的；再反过来问一句「有没有台词在把我刚看见的东西再讲一遍？」——有就记一条（画面演得出就删那句，shengji_zhilu 051），并给**最严重的 5 处**与最小修法（一句台词、一个眼神、一个看得见的动作）。

### 2a. 首次进入世界 / 新场景

首集开场及首次进入重要新场景时，另核四项；连续场景沿用已建立的信息，不重复介绍：

| 项 | 只凭屏幕回答 | 证据 |
|---|---|---|
| 地点 | 这是哪类地方、此刻发生什么？专名尚未揭晓不等于看不懂 | 镜号 + 可见地标、活动或可听台词 |
| 空间 | 人物所在局部与场地怎样相连？后续行动依赖的入口、目标或障碍在哪里？ | 镜号 + 已展示的相对关系；不要求交代整张地图 |
| 世界与氛围 | 哪个具体环境、生活细节或事件建立了这个世界的特色与本段氛围？ | 镜号 + 具体画面或声音；场景代号和「宏大 / 唯美」不算证据 |
| 进入剧情 | 从环境到人物与事件的过渡能跟上吗？开场给了什么继续看的期待？ | 镜号 + 人物、异常、悬念或递进的空间揭示 |

每项写「已建立 / 缺失 / 有意暂隐 / 不适用」及依据，缺失落到首次需要该信息的镜。影响理解行动或辨认地点的缺失记 blocker；只影响氛围丰富度的不足记 warning。有意暂隐须指出屏幕上的悬念线索及预计揭晓位置，不能靠作者备注补空白。

最小修法优先补可见关系、环境细节或承接动作；不强制首镜全景、长镜头、旁白或世界观讲解。环境建立镜有明确的信息或体验增量即可成立，不因没有台词 / 任务推进判为废镜；停留是否过长交 `ai_videos__时长节奏`，实际吸引力交 `ai_videos__整集观感`。用户指定场地美感时，核对已有风格与具体景观是否写入画面，不把美丽作为所有题材的要求。

## 3. 目标账本（机检，`tools/goal_ledger.py`）

每集 `4_剧本/episodes/{ep}/goals.toml`，生成器 build 时查 G1–G6：说出 / 接下 / 了结真在那一镜的画面或台词里；别人交代的事有人接下；
了结在画面上或写明留到哪集；换地点或隔几镜再推进要有提醒词；奖赏不早于了结；每一镜至少推进一件事（或列进 breathers）。
冷眼观众理出的目标线要和账本对得上——对不上，改剧本或改账本，不许只改账本去迁就。

## 4. 修法

- 缺「为什么」：交代任务的那句里带上后果或原因（一句就够）。
- 缺「接下」：主角回一句（哪怕是抢答、嘴硬）。
- 缺「提醒」：换地点后第一镜，台词或画面里点一下在干什么。
- 缺「了结」：让观众看见交差、拿到报酬，或听见一句结果。
- 情感分量（父亲的锤、祖父的盾）屏幕上至少说出一次。
- 改完照常过 `script_tools check`、生成器闸门；台词改了还要过 `ai_videos__对白通读`。

## 5. 盖章

与对白通读共用指纹（`tools/dialogue_review.py`）：两道都读完、改完、复读后

```bash
python tools/gen_shots_{剧}_{ep}.py --viewer-stamp "冷眼观众 · 审稿人 · 备注"
```

台词、画面动作、情节任何一处再改，两枚章都失效。

## 边界

对话措辞与母语语感 → `ai_videos__对白通读`；剧情逻辑与因果 → `ai_videos__逻辑因果` / `ai_videos__剧情连贯`。本 skill 只问：**观众跟得上吗**。
