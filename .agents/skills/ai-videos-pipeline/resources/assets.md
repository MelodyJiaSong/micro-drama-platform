# 资产

独立管理人物、场景、物件、装备及声音，保留已有真实文件和来源。
环境资产使用background/（完整地点、空间布局与视觉参考，不限于二维底图）；剧情scene是某集中特定时空的一场戏，属于episode→scene→shot并引用环境资产。已迁移《魔兽世界》原资产scenes/为background/，bg编号保留；其他旧剧scenes/继续兼容读取，不批量改名。
资产描述与故事历史分开；已有图片不强迫新故事使用旧人物关系或情节。
长期事实在world_rules.md或对应人物/场景/物品卡维护；需要注明“截至哪集”才成立的位置、伤势、持有物、知识、关系和目标，记录在该集state_changes.md。
按当前分镜需要引用；生成服务、收费审计、人工授权和媒体索引遵共用契约。

## 目录与编号

资产根是剧目录下的 `2_世界观人设/`。编号只追加，分配后不重排、不复用；目录改名只改名字，不改号。一份东西只有一个出处，下游只读、只对账，不回写上游。

| 类 | 目录 | 编号出处 | 编译器读取 |
|---|---|---|---|
| 人物 | `characters/c{N}_{名}/c{N}_{名}.md`（怪物 `m{N}_{名}`）；换装阶段是卡内子目录 `c{N}-{M}_{造型}/` | 卡号按出场顺序手动追加（N 不补零） | 「## Shot prompt 外观」段 |
| 背景 | `background/{大陆}/{区}/bg{N}_{主体}/` 加同名 md；视图与状态变体是子目录 `bg{N}-{M}_{名}/` | `background/registry.toml` | 场次绑定的变体卡里的「Shot prompt 场景」段与图 |
| 道具 | `props/p{N}_{名}/` 加同名 md 与 `asset.toml` | `props/registry.toml`，由 `tools/props_lib.py` 的 `allocate()` 领号，不手填 | 「## Shot prompt 外观」段；锚点图 `{目录名}.png`，没有时回退 `p{N}-1_正面.png` |
| 装备 | `equipment/{大类}/{部位}/e{层级码}_{名}/`，例如 `e5103` 是 5 近战武器 · 51 主手 · 第 03 件 | `equipment/registry.toml`；`item.toml` 是唯一出处；谁穿什么只写 `equipment/loadouts/*.toml` | 换装阶段的三视图 |

## 人物

- **参考文件**：人物本身的放在卡目录的 `views/` 下，`{卡目录名}_front.png`、`_side.png`、`_back.png` 加声样 `{卡目录名}_audio.mp3`；换装阶段的放在自己的子目录里，`{造型键}_front/side/back.png`，声样沿用人物本身的。正侧背三张合成一张三视图 `{卡目录名}_views.png` 或 `{造型键}_views.png`（左正、中侧、右背），源图的 sha 变了，合图即视为过期。编译时每个出场人物上传三视图合图与声样。
- **生成链**：立绘 → 4 秒建立视频 → 抽正、侧、背 → 合图，声样另出。工具与步骤见 [人物资产](../../ai-videos-char-assets/SKILL.md)。缺文件或角色绑错算阻碍，不能用改名冒充某个方向。
- **颜色对比**：服装与常用背景的色调拉开对比，主角在画面里更容易被注意到，见[注意力引导](../modules/filming-attention.md)。
- **人物卡**：只写看得见的识别特征，不写五官；随镜变化的状态（一身泥、伤、手里拿的东西）写在分镜里，不写进外观段。需要长期区分的状态（例如「一身泥」）可以另立状态变体三视图，用不用由用户定。

## 背景

- **主体与变体**：同一套材质与光算一个主体；时段、天气、季节或损毁改变了外观，就另立状态变体子目录，不在同一张图上改。视图与变体按镜头需要才出，不预先建全套。
- **平面图**：每个背景主体解析到恰好一份场地平面图 `planning/blocks.toml`（块必填 `id`、`h_m`、`src`），overhead 与 previz 都从它取几何（见 [Overhead](../modules/prompts-overhead.md)）。平面图和白模渲染图不进生成参考。
- **背景图只画固定结构**，剧情道具归分镜；主光要有真实光源。

## 道具与装备

- **道具**：跨两镜以上且外观必须一致的剧情道具立卡出图；分镜 `props` 引用它的镜，锚点图会进参考行（见 [参考](../modules/prompts-references.md)）。手持、随身的剧情物件只出正面锚点图。**道具的可见状态每改变一次，画内都要有一个动作驱动它**，不能凭空出现、自己掉落或自己滑开。
- **装备**：prompt 不写游戏里的原名；灰、白、绿档不发光，蓝档以上发品质色光；换装只出正侧背三面图。

## 出图服务

| 资产 | auto 顺序 | 说明 |
|---|---|---|
| 所有图片：人物与怪物（立绘、派生视图、换装三视图）、道具、简单物件、装备三视图、背景（世界与场景锚点、视图、变体）、镜头图 | ElevenLabs → Codex 内置出图 | 2026-10-17 用户定：出图只有这两个选择（follow-up 270）；ElevenLabs（`gpt-image-2.5-sunburst`）作默认，**额度 / 套餐不够**才换 Codex（`tools/codex_image.py`，ChatGPT 订阅额度）（follow-up 275） |
| 即梦（Dreamina / Seedream） | **不出图** | 即梦只用于视频（Seedance）；图片不用即梦，失败也不退到即梦 |

ElevenLabs 只在额度 / 套餐不够时换 Codex（`image_engine.fallback_ok`），别的失败（拦截、参数错、超时）照实报出、不换家；显式 `--engine X` 只用 X；结果未知的不重提；两家都失败就报出来，不找第三家。路由实现在 `tools/image_engine.py`，图片可由代理直接重出，视频生成由用户决定。所有调用先写请求日志（见 [外部服务](../../../references/project/paid_services.md)）。
