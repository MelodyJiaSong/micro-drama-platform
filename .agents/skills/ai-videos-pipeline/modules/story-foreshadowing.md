# 伏笔

伏笔是先让观众看见、后来改变意义的东西。埋在哪一层、多久兑现，按[片种](story-formats.md)不同。

| 要点 | 做法 | 例子 |
|---|---|---|
| 埋看得见的东西 | 一个物件、一句话、一个习惯；只拍出来，不解释 | 《海贼王》第 1 话香克斯把草帽交给路飞，约好将来还 |
| 当场就要成立 | 伏笔在当集本身是一段完整的戏；以后接不上也不算白写 | 拉布在双子岬等一支海贼团（第 101–105 话），本身就是一段完整的故事；第 442 话布鲁克登场，第 487–488 话才接上 |
| 钉子宽，承诺窄 | 每颗钉子至少能接两种解释；台词里不许下具体承诺 | 《绝命毒师》第五季开场先拍了主角买机枪，编剧事后承认当时不知道怎么用，为此焦虑了几个月 |
| 分层揭开 | 每层回答一个问题，抛出更深的问题，并让旧场面换一种读法 | 《权力的游戏》琼恩的身世：第六季末先揭母亲，第七季末才揭父亲与合法身份 |
| 人物的过去在他的篇章揭 | 在最需要时揭开，并接上主线 | 罗宾第 114 话以反派登场，到司法岛篇才揭开奥哈拉的过去，接上空白的一百年 |
| 先答旧问题，再提新问题 | 小谜定期回收，不让谜越堆越多 | 《迷失》编剧林德洛夫：要提新问题，就得先回答一些旧问题 |
| 已拍出的就是事实 | 画面里出现过的细节记账，以后不能违背 | 斯内普在第一卷看似害哈利，七卷后揭开的真相仍与每一处旧细节相符 |

检查：每个重要角色至少一颗钉子；每颗钉子说得出两种以上接法；这一集有没有回收一颗旧的。
