# 故事创作

先写好故事，再考虑怎么拍。输入为明确选定 profile 的方向与资料；输出为本 run 的候选故事。

| 类别 | 阅读内容 | 指南 |
|---|---|---|
| A · 故事内容 | 人物与动机、目标与冲突、行动与因果、世界与边界、情绪与变化、结构与推进 | [故事内容指南](../../../references/project/story_guidelines.md) |
| B · 执行与验证 | 准备与冻结输入、创建与运行、分工与审稿、保存与溯源、验证与比较、选用与交接 | [独立创作 run 与输入规则](story-runs.md) |

- 新写或修改故事按内容指南组织；生成或重跑按执行指南冻结输入、创作、审稿与记录取舍，两类均适用。
- 长期事实来自资产库 `world_rules.md` 与明确选定资产卡，不把旧卡剧情自动当事实，不继承未选用的旧事件、关系或分集安排。
- 正文写人物、行动、冲突与结果，可包含对白和内心，暂不设计摄影；初稿先追求简单完整、动机与因果可理解的故事。
- 用户选用后载入 `episodes/epNN/story.json` 的 `brief` 与 `text`，仍为草稿；确定版本后再交给影视改编。

共享配置、状态承接、命令与版本交接的具体约定只在执行指南维护，不向历史 profile/run 补塞新规则。
