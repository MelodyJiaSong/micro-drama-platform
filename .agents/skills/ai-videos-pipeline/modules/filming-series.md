# 连续剧（集）

连续剧轮换导演、节奏快：一小时剧一集大约拍 8 天，后面的集要沿用第一集定下的风格。所以影视改编除了每一集，还要管住「跨集一致」。

## 风格由第一集定

试播集的导演定下整部剧的观感，后面每集的导演照这个模板拍，并收起一部分个人风格（DGA）。具体剧集会把它写成风格手册，细到每种景别配什么镜头和焦距。本剧以 EP1 为样板：EP1 定稿后，把光、色、常用景别和镜头习惯写进剧级风格说明，后面每集照做。

## 单集结构

一小时剧常见结构是：前导段或冷开场 + 4–5 幕 + 尾段。广播电视在进广告前的幕尾留悬念；流媒体不必每 10–15 分钟留一个，但仍要让观众点开下一集。本剧每集至少设计两个钩子镜头：开场钩住观众，集尾留悬念。「前情提要」可选；分镜里不要依赖它交代必要信息。

## 常驻场景与复用

常驻场景跨集反复用，第一集就要想清楚哪些场景要撑起整部剧（《体育之夜》搭成一个连通的大布景，方便边走边谈）。本剧的环境资产（bg）跨集复用，常驻场景的建立镜头也可以复用；但每次出现，按人物当时的心态换一种处理，避免单调（ASC）。

## 跨集连续性

服装、道具、陈设、发型妆容要逐镜逐场一致，并跟踪道具的状态和时间线。本剧按 `state_changes.md` 承接上一集的伤势、持有物与位置，分镜里写清当前状态。

## 节奏与覆盖

排期紧，覆盖以标准覆盖为主、效率优先，常用两机同拍过肩。本剧按集分配生成预算，关键对话场给标准覆盖，其余场用最少覆盖。

| 应该 | 不应该 |
|---|---|
| EP1 定稿后写下风格说明，后面每集照做 | 每集换一种光和镜头习惯 |
| 每集设计开场钩子镜与集尾钩子镜 | 集尾停在问题已经解决的地方 |
| 常驻场景复用环境资产，按心态换处理 | 每集重新设计同一个场景 |
| 按状态变化记录承接伤势与道具 | 让上一集的伤和道具在下一集消失 |
