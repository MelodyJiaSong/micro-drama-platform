# 片种

故事原则共用，见[故事结构](story-structure.md)；片种只改「结构放在哪一层、有多长」。片种页只写与共用原则不同的地方，不重抄原则。

| | 电影 | 连续剧 |
|---|---|---|
| 时长 | 90–150 分钟 | 每集几分钟到一小时，一季多集 |
| 三幕放在 | 整部片 | 一季（或一个大段落） |
| 主角 | 通常一个 | 多条线，各有主角 |
| 大转折 | 两次 | 按季安排，单集只给小反转 |
| 结尾 | 正面决胜，短尾声 | 单集留钩子；季末收束，再抛新问题 |
| 推进单位 | 一段几分钟 | 每集几段 |
| 详见 | [电影](story-film.md) | [连续剧](story-series.md) |

剧的 `workflow.json` 用 `format` 声明片种：`film` 电影、`series` 连续剧。故事创作读共用原则加本片种页。
