# 镜头

影片由段落组成，段落由[场](filming-scenes.md)组成，场由镜头组成。一个镜头由下面几项独立选择组合而成，各回答一个问题，可以任意搭配。

| 维度 | 回答的问题 | 子页 |
|---|---|---|
| 功能 | 这一镜让观众明白什么？ | [功能镜头](filming-functions.md)：建立、主镜头、插入 |
| 景别 | 主体在画面里多大，截到哪里？ | [景别](filming-sizes.md)：远景到大特写 |
| 取景 | 画面里有谁，是什么关系？ | [取景](filming-framing.md)：单人、双人、过肩、主观 |
| 角度与高度 | 观众用什么姿态看他？ | [角度与高度](filming-angles.md)：仰、俯、顶拍、倾斜，眼平到地面 |
| 焦点 | 观众的眼睛落在哪里？ | [焦点与景深](filming-focus.md)：深焦、浅焦、移焦等 |
| 运镜 | 镜头怎么动，带观众怎样进入？ | [运镜](filming-movement.md)：跟拍 |
| 注意力 | 以上各项加美术、光、声音，是否指向同一处？ | [注意力引导](filming-attention.md)：构图、视线、颜色、光、声音 |

例：「近景 · 脏单人 · 肩高 · 浅焦 · 固定机位」是五项各选一种。

## 选镜顺序

先定观众此刻必须知道什么 → 哪些内容必须同框 → 能装下它们的景别 → 用取景定关系 → 用角度定态度 → 用焦点定注意力，并让构图、视线、光、颜色指向同一处（见[注意力引导](filming-attention.md)）→ 需要时用运镜带观众进入。

## 写进分镜

`camera` 只写本镜需要的项：功能（如需要）、景别与裁切边界、谁在画内、机位高度与角度、焦点落在哪里、怎么动。
例：「近景，胸口至头顶；脏单人，前景留杜克的肩；肩高平视；浅焦，焦点在亚伦的手。」

## 通则

| 应该 | 不应该 |
|---|---|
| 每个选择都能说出叙事目的 | 为好看而套用；每场固定套齐所有类型 |
| 特写、低角、浅焦、倾斜这类强调手段留给真正要紧的时刻 | 反复使用，直到失去强调力 |
| 说清这一镜保留了什么、省略了什么，省略的信息观众是否已经知道 | 以为某种景别或角度会自动带来某种情绪；效果还取决于表演、光、声音与上下文 |
| 敢于不按预期选，但能说出理由 | 只因为「通常这么拍」 |
| 生成后对照画面核对：裁切、同框、角度、焦点是否真的出现 | 以为写进 prompt 就一定拍得出来 |
