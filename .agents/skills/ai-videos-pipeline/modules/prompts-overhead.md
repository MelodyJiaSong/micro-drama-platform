# Overhead

俯视站位图（overhead / camera plot）：从正上方看一个镜头——机位在哪、朝哪、焦距多少，每个人站在哪、面朝哪、几秒走到哪，屋子和陈设在哪。**每一镜都必须有**，并且是生成时的运动参考；默认不做 [Previz](prompts-previz.md)，单独要的镜才用它渲人偶视频。

## 是什么，用来做什么

片场用它让各部门共用一张空间图、提前检查设定能不能拍、少靠口头解释（多人对白、轨道或跟拍、多机位、打戏最常用）。本流程里它多两个用途：给 Seedance 当站位与机位参考；画的过程本身就是一次审查——散文里看不出的朝向反了、机位穿过人头、隔着墙拍，图上一眼就是。

| 应该画 | 不应该 |
|---|---|
| 墙、门、陈设与比例尺（来自场地平面图） | 只画静态站位、不画时间 |
| 人物起点与终点、走位箭头、到达秒数、面朝方向 | 漏画视线与朝向，对白像对空气说 |
| 机位、视野扇形、焦距、离地高；运镜路线与硬切 | 机位扇形与焦距对不上，构图到出片才发现不成立 |
| 180° 轴线两侧不越（要越写明理由） | 一张图塞进互相矛盾的几个镜头 |

## 写 overhead.toml

位置的唯一出处：`shots/stN/planning/overhead.toml`。坐标用该场环境资产所在的场地平面图（米，x 向东、y 向南）；环境资产没有自己的图时，`planning/plan.toml` 指向上级平面图（`plan = ".."`）。

```toml
[meta]
scene = "bg2-6"                 # 场的环境资产
view = [12, 40, 30, 60]         # 审阅图裁切范围（可选，米）
note = "两人隔长桌对站；机位在亚伦右肩后，不越轴"   # 为什么这样摆

[[camera]]                      # 路点：t 秒时机位在 xy、离地 h 米、瞄 look、焦距 lens
t = 0
xy = [21.22, 55.8]
h = 1.6
look = [21.0, 51.6]
lens = 60
subject = "c14_Brother_Sammuel" # 景别量谁（人物卡目录名）
# cut = true                    # 硬切到这个路点，而不是运镜走过来

[[actor]]                       # key＝人物卡目录名；path 每点 [t, x, y] 或 [t, x, y, 面朝点x, 面朝点y]
key = "c1_Aaron"
label = "亚伦"
path = [[0, 21.0, 55.0, 21.0, 51.6], [8, 21.0, 55.0, 21.0, 51.6]]

[[object]]                      # 平面图里没有、本镜才出现的东西；h 给 previz 用
label = "长桌"
xy = [21.0, 53.3]
size = [2.4, 0.9]
h = 0.78

[[pose]]                        # 姿态（previz 用）：从 t 起，名字见 build_previz 的姿态表（坐、伸手、低头……）
t = 3
who = "亚伦"
pose = "抬头"

[[beat]]                        # 时间轴提要，与分镜 beats 对齐
t0 = 0
t1 = 3
text = "萨缪尔读完信、对折"

[[carry]]                       # 带着的东西：t0–t1（缺省整镜）在手里（on = "手"）或背在身后（"背"）
who = "亚伦"
what = "锤"                     # 锤 / 斧 / 剑 / 镐 / 棒 / 叉 / 盾，与 [[hit]] 的 with 同一套
key = "p480"                    # 道具卡号（可选）
on = "背"
t1 = 2                          # 2 s 起从背上抽出来——再写一条 on = "手"、t0 = 2
```

打斗、施法、护人等另有 `[[hit]]`、`[[guard]]`、`shield`、`[[cast]]` 等键与机检，见 `tools/shot_overhead.py` 的 `KEYS`。键名拼错直接报错。每一下怎样编排见[动作戏](filming-action.md)。

`[[carry]]` 让 previz 人偶带上这件东西（[Previz](prompts-previz.md)）：手里的握法跟着那一刻 `[[pose]]` 里写的持物姿态（双手低握、前砸、扛肩R、靠腿、单手握R、前劈R、举手R），没写就用 `grip` 或该件的缺省；全长 `len` 缺省按件（锤 1.2 m）。手里的盾仍写 `[[actor]] shield`。机检：同一件同一时刻只在一处（不同时在两人身上、也不同时是地上的 `[[prop]]`——捡起 / 放下写进 prop 的 `gone` 与 carry 的 `t0` / `t1`）；用兵器出手的 `[[hit]]`（含落空）那一刻手里要有这件。

## 从分镜到 overhead

| 分镜字段 | overhead 里 |
|---|---|
| `cast` | 每人一个 `[[actor]]`，key 用人物卡目录名；两边必须一致，否则报错 |
| `blocking` | 起点、终点、面朝点；视线落在谁身上就让面朝点指向谁 |
| `beats` | 路点与姿态的时刻；`[[beat]]` 抄要点 |
| `camera` | 机位、焦距、离地高；运镜写成多个路点，硬切写 `cut = true` |
| 场的 `background` | `[meta] scene` |

**景别与距离**：画面高 ≈ 距离 × 20.25 ÷ 焦距（全画幅、16:9）。所以距离 ≈ 画面高 × 焦距 ÷ 20.25。

| 景别 | 画面高约 | 35 mm | 50 mm | 85 mm |
|---|---|---|---|---|
| 特写（脸） | 0.35 m | 0.6 m | 0.9 m | 1.5 m |
| 近景（头到胸） | 0.7 m | 1.2 m | 1.7 m | 2.9 m |
| 中景（腰以上） | 1.2 m | 2.1 m | 3.0 m | 5.0 m |
| 全景（全身） | 2.4 m | 4.1 m | 5.9 m | 10 m |

过肩镜：机位贴着前景人物的肩，偏出 0.2–0.3 m、后退 0.6–0.9 m，否则前景肩膀出画、过肩不成立。

## 画图与核对

```
python tools/shot_overhead.py <镜头目录>          # 一镜
python tools/shot_overhead.py --all <集目录>       # 整集，按播放顺序，外加 overheads.md 索引
python tools/overhead_previz.py <镜头目录> --force --stills   # 取景静帧（几十秒）
```

每镜出两张图和一个判定：`stN_overhead.png` 给人审（坐标、时间轴、侧栏）；`stN_overhead_ref.png` 给 Seedance（16:9、裁到本镜范围、只有图形与人名，没有标题、坐标、图例——图例由 prompt 的「参考用法」交代）；`previz.json` 记要不要 previz 与理由。

**场的走位图**（follow-up 271）：`python tools/scene_blocking.py <场目录>`（或 `--all <集目录>`）把本场每镜的 overhead 叠成一张俯视简图 `scenes/sN/planning/sN_blocking.png`：底图是场地简笔画，人＝彩色圆（群演卡＝三角）、物件＝方块，镜内移动＝虚线箭头标镜号；画单镜或 `--all` 时自动重画，管理 UI 影视改编的场页面显示它。给人看一场的站位与相互位置，不给模型。

overhead 看不出取景，所以**每镜都出一张静帧拼图核对**：主体景别对不对、前景人物在不在、有没有人被挡住或出画。试点 s4 第 2 镜画好 overhead 后，静帧两次发现取景错（机位太远成了全身；前景肩膀出画），改 overhead 后才对。

| 应该 | 不应该 |
|---|---|
| 改走位只改 overhead.toml 再重跑 | 手改 PNG |
| overhead 与分镜矛盾时回分镜改文字 | 让 overhead 与 blocking 各说各话 |
| 人站在实心体块里、机位扎进墙里，按报错改 | 忽略报错硬编译 |
