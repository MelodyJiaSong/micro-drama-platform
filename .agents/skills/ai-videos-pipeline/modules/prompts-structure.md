# Prompt 结构

一条 prompt 一个字段一行，顺序固定；人物与台词每项单独一行。编译器 v6（follow-up 228）起第一段是「参考：」一行，列出本镜上传的全部参考；v7（follow-up 229）写成 `` `key_id=>@` `` 占位，正文用 key_id 指认，资料包填上传编号；正文把人物外观、场景、本场目的、走位、分拍、镜头、光线、台词口型与负面词写足，上限 5000 字（本集 82 镜 1220–3261 字）。

| 行 | 内容 | 来自 | 作用 |
|---|---|---|---|
| 1 | 镜头 key，如 `ep1_s4_st2` | 集、场、镜编号 | 认镜：下载文件按它归位 |
| 2 | 声音：规则 | 固定；无对白镜追加一句 | 只保留对白、环境声、动作声 |
| 3–4 | 时长、比例 | shot.duration；剧 `prompt.ratio` | 生成长度与画幅 |
| 5 | 参考：`` `ep1_s4_st2_overhead=>@`、`c14_Brother_Sammuel=>@`、…、`bg2-6_武厅_兵器架=>@`、`c1_Aaron_audio=>@` `` | 见[参考](prompts-references.md) | 一行列全；`@` 是占位，资料包按上传顺序填成 @图片N / @视频N / @音频N |
| 6 | 参考用法 | 固定文字，按有哪些参考拼 | 每个参考只取什么、不取什么 |
| 7 起 | 人物：之后每人一行 `` 亚伦（三视图`c1-1_便服与父亲的锤`；声音`c1_Aaron_audio`；`ep1_s4_st2_overhead`里的蓝色圆点）：外观 `` | shot.cast + 人物卡「Shot prompt 外观」+ 颜色表 | 名字、三视图、声样、运动参考颜色与外观绑在一起 |
| 下一行 | 本场 | scene.purpose | 这场戏要做成什么，给表演定调 |
| 下一行 | 场景：地点 · 时间（`bg…`）：场景描写 | scene + 背景卡「Shot prompt 场景」 | 场景、时段与陈设 |
| 下一行 | 画面 | shot.action | 谁、在哪、做什么 |
| 下一行 | 走位（无人物的镜省略） | shot.blocking | 站位、朝向、视线、移动 |
| 下一行 | 动作 | shot.beats | 按秒分拍 |
| 下一行 | 镜头 | shot.camera | 景别、取景、角度、焦点、运镜 |
| 下一行 | 光线 | shot.lighting | 光源与性格 |
| 下一行起 | 台词：之后每句一行（缩进两格）＋「口型」；无对白写「台词：无」 | shot.dialogue | 说出口的话；字幕按这几行读回 |
| 下一行 | 风格 | 剧 `prompt.style` | 全剧统一画风 |
| 下一行 | 负面词 | 固定项 + 剧 `prompt.negatives` | 约束写进正文 |
| 倒数 2 | 要求：连续镜头、无字幕水印、不要分身、自然表演 | 固定 | 见[固定规则](prompts-rules.md) |
| 末行 | 声音：规则（重复第 2 行） | 固定 | 首尾各一次，减少被忽略 |

管理 UI 里每个镜头一页：只显示这一条，字段名高亮，可复制，下面按上传顺序列出参考文件，可点开看。

## 例：EP1 武器厅 s4 第 2 镜

```text
ep1_s4_st2
声音：仅保留本镜指定对白、自然环境声和动作声；不要背景音乐或配乐。
时长：8秒
比例：16:9
参考：`ep1_s4_st2_overhead=>@`、`c14_Brother_Sammuel=>@`、`c1-1_便服与父亲的锤=>@`、`bg2-6_武厅_兵器架=>@`、`c14_Brother_Sammuel_audio=>@`、`c1_Aaron_audio=>@`
参考用法：`ep1_s4_st2_overhead`是本镜的俯视站位示意图，不是画面：上方为北，彩色圆点是人物（尖角＝面朝，箭头＝走位路线，旁边数字＝到达秒数），红色机身与扇形是机位与视野，灰色方块是建筑与陈设。只按它安排机位、站位、朝向与走位先后；图里的颜色、线条、箭头和文字都不出现在画面中，人物颜色也不是服装颜色。每张人物三视图（`c14_Brother_Sammuel`、`c1-1_便服与父亲的锤`）是同一个人的正面、侧面、背面，不是三个人；只取这个人的长相、发型、体型与服装，不取图里的姿势、站位和机位，三视图的浅灰背景不入画。场景图`bg2-6_武厅_兵器架`只取材质、形制、陈设与色调，空间关系以`ep1_s4_st2_overhead`为准，光线与时段按「光线」一行，场景图里的光向不照搬。声音参考（`c14_Brother_Sammuel_audio`、`c1_Aaron_audio`）只取该人物的音色、音高与说话质感，不取内容；本镜不说话的人物不出声。
人物：
  萨缪尔修士（三视图`c14_Brother_Sammuel`；声音`c14_Brother_Sammuel_audio`；`ep1_s4_st2_overhead`里的黄色圆点）：四十出头的修士，偏瘦，肩窄，背很直，动作幅度很小；花白短发贴着头皮，鬓角先白，面颊瘦、颧骨明显，眼窝深，眼神很静；米灰色粗麻修士长袍，领口与袖口磨白，一条深栗色皮质绶带自右肩斜下至左腰；同色麻布长裤，袍摆过膝，平底硬皮短靴；腰间挂一枚拇指大小、被长期摩挲得发亮的黄铜圆形徽记；不带任何武器；接东西时两只手一起接，讲话前先把手里的东西放下。
  亚伦（三视图`c1-1_便服与父亲的锤`；声音`c1_Aaron_audio`；`ep1_s4_st2_overhead`里的蓝色圆点）：二十岁上下的西欧白人青年，中等个头，清瘦，肩背还没长开，前臂有握出来的线条；短栗棕发，自然微卷，额前碎发随手拨到一边，发梢参差；素颜，鼻梁与两颊有淡雀斑，颧骨晒出一点红；本白偏浅麻色的粗织亚麻长袖衬衣，前襟系带松松打结，袖子卷到小臂，衣摆散在胯外；腰上一条深褐窄旧皮带；同色系粗布长裤，膝部磨薄、有一块深色补丁，裤脚塞进短筒软底布靴；肩、头、胸、背、手、颈都空着，身上没有任何甲；神情认真、有点拘谨，说话前嘴唇先轻轻抿一下。
本场：全集第一场主对话戏：萨缪尔「暂时」收下亚伦，看见父亲的锤，教他第一次请圣光并立下规则；治安官派差事并发出禁令。冲突：亚伦想被认可，却只敢说「A little」；萨缪尔考他；杜克的轻蔑；治安官的区别对待。
场景：北郡修道院武器厅 · 早晨（`bg2-6_武厅_兵器架`）：修道院的武器厅，一间方正、比主厅矮小的石砌训练室：米灰色石灰岩粗砌墙，粗大的深色木梁横过低矮的木板顶；西墙高处两扇素面石框拱窗；东墙整面靠着一排深色木制兵器架，竖插着朴素的单手锤与双手锤、短剑与长剑、几支长矛，木柄被手磨得发亮，下层横放几面漆皮斑驳的圆木盾；北墙挂一排木挂钩与几副皮护腕，墙上一扇小木门；厅心偏南一张粗木长桌，桌上一只水罐、一卷折起的皮革、一块磨刀石；西墙下两张矮木长凳，门边一只装满沙土的木桶；石板地被反复踩出一圈浅色磨痕。
画面：萨缪尔修士（米灰麻袍栗色绶带，黄铜徽记磨亮）读完信，把信折好，抬眼看亚伦（清瘦青年，短栗棕发，麻衬衣布裤布靴；肩、头、胸都空着，身上没有任何甲；背上一条旧布裹着的长包，里面的锤不露出来）。前景是亚伦的肩和后脑。
走位：萨缪尔修士站在长桌北侧，面朝南看着亚伦；亚伦站在桌南、背对镜头面朝萨缪尔，两人隔着长桌约两米，整镜不换位置。
动作：0–3秒 萨缪尔读完信，把信对折；3–5秒 他抬眼看亚伦，说第一句；5–6秒 亚伦反问；6–8秒 萨缪尔重复「For now」，停半拍再问能不能打。
镜头：过肩：从亚伦右肩后看萨缪尔，萨缪尔近景；眼平；浅焦，焦点在萨缪尔。
光线：西墙高处两扇拱窗投下冷而柔的斜光，门口透进散射辅光；没有火把，没有暖色火光。
台词：
  萨缪尔：I've been given charge of your training. For now.
  亚伦：For now?
  萨缪尔：For now. Can you fight?
口型：画内说话的人嘴型与台词同步，正常语速与口型；每句只由标明的人说，其他人不开口。
风格：影视级实拍质感，35mm 胶片颗粒，浅景深，真实皮肤纹理与布料纤维，物理正确的材质反射；真人电影画面，不是游戏截图或三维动画
负面词：分身，双胞胎，同一人物出现两次，多出来的人，画面文字，字幕，水印，logo，背景音乐，绿幕，纯色人偶，示意图的圆点、箭头、线条与文字，人脸变形，五官漂移，畸形肢体，多余手指，夸张金光，人物自发光，瞳孔发光，现代服饰，现代建筑，现代器物，塑料感材质，游戏引擎渲染感，游戏截图质感，UI 界面，血条，头顶名牌，伤害数字，低模棱角，贴图拉伸，卡通渲染，三维动画感
要求：连续镜头，不要切镜。不要字幕或水印。画面中每个人物只出现一次，不要分身或双胞胎。人物按真人自然表演：走路有重心起伏和摆臂，发力有预备和惯性，不照搬参考里人偶的僵硬姿势。
声音：仅保留本镜指定对白、自然环境声和动作声；不要背景音乐或配乐。
```

prompt 写得好不好，由分镜字段、资产卡的外观与场景段、参考共同决定；编译只负责排好、补上规则。
