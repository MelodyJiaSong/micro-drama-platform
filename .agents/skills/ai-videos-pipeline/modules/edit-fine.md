# 精剪

逐个定切点：在哪一帧切、切到谁、声音和画面是否同时切。

## 切点的取舍顺序

Walter Murch 的六要素，顾不全时先放弃排在后面的：**情感 > 故事 > 节奏 > 视线 > 画面平面 > 三维空间**。轴线（空间）小毛病换来情绪成立，可以接受，登记为有意违例。

兑现前的停顿按观众的心理节奏卡：等观众心里的嘀咕说完再兑现，见[观众](story-audience.md)。

## 规则与检查方式

【自动】机器能测；【半自动】机器标出，人确认；【人判】只能人看。

| 规则 | 是什么 | 检查 |
|---|---|---|
| 切要有动机 | 每一刀说得出理由：新信息、反应、视线、动作或声音 | 事件「理由」字段不空【自动】；理由成不成立【人判】 |
| 不切在词中间 | 对白切在句间或词边界，留呼吸 | 切点离词距离【自动】 |
| 晚进早出 | 冲突开始才进，话落地就走 | 镜首镜尾无词无动作的空段超阈值即报【半自动】 |
| 反应镜头 | 冲击性的话落地时切到受冲击的人 | 关键台词标「反应承接人」，查话后是否出现此人【半自动】 |
| J / L 剪辑 | 下一人的声音先进（J），或说话声延续到听者画面（L）；避免乒乓对切；场间转场见[转场](edit-transitions.md) | 音画切点错开多少可测【自动】；该不该错开【人判】 |
| 动作中切 | 切在动作中途，两侧速度与方向接得上 | 切点两侧几帧光流方向与幅度【半自动】 |
| 不跳切 | 同一主体接下一镜，角度变约 30° 以上并换景别 | 同人同景别、切点两侧画面过于相似即报【自动】；有意跳切登记 |
| 轴线与视线 | 同场人物左右位置与视线方向一致；要越轴先过中性镜头 | 每镜标位置与朝向，相邻翻转即报【半自动】 |
| 说话人可见 | 一般看得见说话的人；不为很短的台词单独切 | 对齐结果 + 人脸可见【自动】 |
| 情绪越强越近 | 情绪推高时推近，回落时拉开；景别逐级变化 | 景别序列【半自动】 |
| 节奏 | 平均镜长、最长单镜、密度变化 | 统计【自动】；快慢是否合适【人判】 |

## 规则可以写成分数

计算剪辑研究把上表写成可加的代价：Leake 等（2017）把每句台词当一个状态，在各条之间选，用「先给全景」「说话人可见」「避免跳切」「情绪强时用近景」「不为短台词切」等十几条惯用法作起始、转移与单镜代价，再用 Viterbi 求整段最优，可先钉住某几刀再重解；Galvane 等（2015）加了切点连续项（屏幕位置、运动方向、视线、180°）和镜长节奏项（镜长按对数正态分布，均值由目标平均镜长定）。AI 生成片可再加：伪影风险、身份距离、接缝色差与光流。分数用来给候选切点排序、标违例，不替人拍板。

## 竖屏短剧的节奏

| 常见做法 | 用来 | 依据强度 |
|---|---|---|
| 前 3 秒给冲突画面或悬念台词，常把高潮提前 | 抓住划走前的注意力 | 创作者经验，窗口说法 3–7 秒不等 |
| 集尾停在一个本集不回答的问题上，结尾类型轮换 | 留到下一集 | 创作者经验 |
| 情绪爆点镜头多停一拍 | 让观众接住 | 教程口径 |

微短剧实测平均镜长约 1.5–4.2 秒，主要随导演风格变（《中国电视》2024 年第 2 期）；平台没有公开的剪辑规范。这些数字只作对照，本剧的目标镜长在剧级设定里定，不在这里定门槛。

| 应该 | 不应该 |
|---|---|
| 切点只从合法候选里挑，每刀写理由 | 为了「快」而把每镜剪到同样短 |
| 情绪戏留停顿，删的是无用的气口 | 机械删掉所有停顿 |
| 有意违例写明理由 | 违例不记，留给审稿去猜 |
