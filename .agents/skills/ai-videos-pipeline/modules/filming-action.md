# 动作戏

打斗、追逐、人兽、一对多这类以身体冲突为主的场（[好场的构成](filming-scene-anatomy.md)「冲突」身体）。本页管怎样编排动作、拆成镜头、写进分镜；机检见 [Overhead](prompts-overhead.md)，生成写法见 [Seedance 写法](prompts-seedance.md)。

整合自两份开源 skill（2026-10-17 调研）：fight-prompt-director（MIT）的动作设计表、结构骨架、镜头职责与单变量诊断；video-combat-skill（未声明许可，只取方法、不转抄正文）的接触分级、多人调度、镜头主体选择与关系变类时切。出处与取舍见 `.audit/adhoc_agents/2026-10-17/fight-skills/`。

| 原 skill | 本流程 |
|---|---|
| 一条 15 秒 prompt 打完一场，默认出高强度、中间、慢节奏三套 | 整场在影视改编里设计、拆成多镜，每镜单独生成、看不到前后镜；三套强度只在用户要比较时作为候选 |
| 编排直接写进 prompt | 编排写进分镜字段与 overhead；编译只做确定性转换，不加招式 |
| 只靠文字约束接触与站位 | 每一下命中、护人、反应时间在 overhead 里机检，previz 查兵器真的碰到目标 |

## 先定这场打什么

写进场级决策记录「动作设计」（见[决策记录](decisions.md)）。用户已定的胜负、招式、对白、结尾原样保留。

| 项 | 回答 |
|---|---|
| 完成条件 | 怎样算结束：击倒、逼退、脱身、抵达、护住、撑到时间；结尾画面怎样让观众看见 |
| 赌注 | 输了会怎样；怎样连着本场目的与 Vision |
| 打法档案 | 每个参战者：擅长距离、移动方式、主要攻击、防守与反制、兵器或资源、发力节奏、怎样收；任意两人至少在距离、移动、反制上不同 |
| 空间与路线 | 谁从哪开始、往哪走；出口、障碍、可借用的环境 |
| 资源 | 兵器件数、弹药、法术次数；用掉的不自动回来 |
| 主动权 | 谁在哪一拍拿到或失去优势，靠什么身体原因翻转 |

## 选结构

| 结构 | 骨架 | 常见错 |
|---|---|---|
| 双人攻防 | 各占优势距离 → 一方逼对方离开舒适距离 → 被压的一方借地形、兵器、假动作扭转 → 换位或换朝向 → 谁拿到空间或时间。变体：压迫（一方持续进逼）、反击（等对方落空再接）、同级升级（每轮推高距离、速度或环境中的一样） | 你一招我一招轮流出手 |
| 一对多 | 全景交代主角与每个敌人的位置 → 不同方向、不同节奏逼近 → 主角借一个人的位移挡另一个 → 倒下的人留在画里 → 收在剩几人、主角去哪；见「多人调度」 | 敌人排队上；主角站在中间原地转圈 |
| 人对兽、大体型 | 交代体型差与安全距离 → 兽一个大范围动作改变地面或遮挡 → 人从侧翼、高处或弱点拿到短暂破绽 → 兽换攻击方式形成反转 → 撤退、倒下、脱离或环境改变；见「人对兽」 | 兽的强只体现为把人撞得更远 |
| Boss 逐级 | 常规手段失效 → 对手显出更强的控制、力量或距离 → 主角换打法或借环境撬开一个窄口；每阶段只升一两样（距离、速度、冲击、控场、擒摔、高度） | 主角没有任何改变就突然一样强 |
| 突围、追逐 | 交代路线、出口与当前状态 → 威胁一次次换形态，逼主角换步法或高度 → 原路被封，借环境开新路 → 抵达、脱离或停在清楚的位置 | 威胁重复同一种 |
| 环境、狭窄、高低 | 交代可用的物件与地形 → 第一次接触改变路线或攻击线 → 破坏或位移造成新局面；物件要有用：踢空撞上桌沿、只得撑手，换来反击窗口 | 碰桌子只因为有桌子；坏了的东西下一镜复原 |
| 远程、施法 | 交代双方的释放条件 → 第一轮逼一方移动或改变场景 → 守方偏转、吸收或切断来源 → 改变路径或释放位置 → 落在看得见的目标或空地；来源、路径、落点、剩余资源都交代 | 能量凭空出现；远程角色无故贴身近战 |

片例：《老男孩》走廊一镜横移，窄走廊把一群人收成一次只上一两个，主角背上中刀仍往前推；《荒野猎人》熊袭一镜到底，体量完全压住人，没有反转就是纯压制；《卧虎藏龙》竹梢，高低地形本身就是招式。

## 每一拍：因果链

一拍＝谁出手 → 哪个部位、什么路线、打向哪 → 接触、格挡还是落空 → 对方身体怎样反应（架子、重心、脚下）→ 双方位置怎样变 → 留下的状态引出下一拍。下一拍从上一拍的结果来：距离变了、失衡、遮挡、资源用掉、环境损坏、露出空当。

| 接触 | 要写出 |
|---|---|
| 擦碰、试探 | 接触点；攻击线怎样偏 |
| 格挡 | 两边真的撞上、都减速；守方架子被压或卸开；攻方线路改变，留出下一个空当 |
| 实打 | 用什么打（拳面、掌根、胫骨）、打在哪（胸骨、肋侧、大腿）、受力方向；衣服与身体被压；肩、胯跟着变，脚下接住重心；攻方也减速、回弹或顺势跟进 |
| 重击（少用） | 上面整条力的传递，加环境反应：撞柱、折过栏杆、摔上桌面 |
| 落空 | 擦过的那条线；守方怎么躲；出手的肢体过伸、落地失衡或被带着转，变成对方的机会 |
| 借力 | 守方让开攻击线、轻轻一引，动能来自攻方自己：冲过头、转过头、落点变了；轻引不把人打飞 |

| 应该 | 不应该 |
|---|---|
| 先接触、后反应：拳到了对方才动；声音、尘土在接触那一刻 | 拳还差几厘米对方就往后仰 |
| 反应随打的位置变：胸口向后仰、肋侧侧弯、低踢打乱支撑腿、撞柱骤停再弹回 | 每一下都是同一种往后滑 |
| 轻重分层：小接触小反应，关键一下才给完整链条 | 每一下一样重 |
| 没人干等：被挡开或落空后双方都在新状态里接着动 | 出手、停、摆姿势、轮到对方 |
| 踢、扫、摔先有支撑脚与重心；落地站稳才接下一记重招 | 单腿踢看不出支撑腿；落地直接接重踢 |
| 背对威胁要有原因（转身、被打转、闪避），很快转回 | 无故背对对手 |
| 同一时刻一般只一人腾空 | 两人同步起跳 |
| 主角也会被擦中、失衡、被抓住，失败变成下一拍 | 主角全程毫发无伤 |

近景看得清脸时表情跟战况走：专注；发力时咬牙、短促呼气；险招时眯眼；受击后呼吸被打断，再重新盯住对手。不要空白脸、一直嘶吼、看镜头。

## 多人调度

| 规则 | 做法 |
|---|---|
| 同时出手 | 任一刻一个主攻，最多两人短暂重叠；三人以上同时全力进攻，短生成里会乱 |
| 交接 | 上一个还没退干净，下一个已经进来：A 被挡开还在恢复，B 从新方向进；主角换目标先转头、转身 |
| 其余的人 | 在逼近、绕行、恢复、堵出口、在画边露出；不摆等待姿势 |
| 路线先行 | 先定主角路线（绕柱、沿桌、穿门），用柱、门、桌、倒地的人收窄进攻线，把一对四压成局部的一对一、一对二 |
| 倒下的人 | 留在原地成为障碍；打退不等于淘汰，可沿看得见的路线重新加入，不能突然出现在主角身后 |
| 画外威胁 | 脚步、衣料、撞到家具的声音预告从哪来，方向与站位对得上 |
| 镜头 | 跟主角；当前攻击者看得清；下一个只露手臂、肩或剪影；大换位后用中全景重建空间 |

本剧限制：一镜超过 4 人容易人数错、出双胞胎（[Seedance 写法](prompts-seedance.md)「参考」），多人场面按进攻线拆镜，每镜只放正在交手的人和画边的下一个；每个敌人分别写身份与动作，不只写「四个守卫」。

## 人对兽

| 规则 | 做法 |
|---|---|
| 先立尺度 | 开场同框交代体型比例与安全距离（全景或低机位） |
| 各用优势 | 大的靠攻击范围、改变地形、冲势；小的靠站位、时机、高度、弱点 |
| 兽的大动作 | 一次大范围动作改变地面或遮挡（拍裂地面、扫倒树），之后每镜保留 |
| 反转 | 人的破绽只有一瞬；兽转身、甩尾或换目标把局面翻回去 |
| 兽也有朝向 | 出手前看得见它盯着谁、在蓄力（压低、后退、张口）；转向要时间，这就是人的窗口 |
| 结果 | 撤退、倒下、脱离或环境改变，看得见 |

overhead 已有对应机检：人与怪攻防接触自动要 previz；`[[react]]` 拦「一抬头狼已到一米外还来得及捡锤」；护人用 `[[guard]]`。

## 拆镜与镜头

每镜只担一个主要职责：

| 职责 | 画面回答 | 常用 |
|---|---|---|
| 建立空间 | 人、出口、障碍各在哪 | 大全景、俯拍、侧向全身 |
| 跟位移 | 谁往哪走、速度怎么变 | 平行跟、侧后跟、贴地跟 |
| 看清接触 | 打中没有、打在哪 | 侧向中景、短接触插入 |
| 反制 | 主动权怎样换手 | 反应近景、同侧切入、回到双人 |
| 失衡 | 受力方向与姿态 | 沿受力方向跟 |
| 弹道 | 释放者、路径、目标 | 过肩、长焦压缩、高位远景 |
| 结果 | 谁占了位置、环境怎么变 | 后拉、升镜、遮挡移开 |

| 应该 | 不应该 |
|---|---|
| 全身双人镜交代左右、距离、大换位和要全身才看得懂的踢摔；交代清楚后多用单人出手、单人闪避、前景肢体、接触点、脚下、环境结果 | 大部分时间停在双人全景；每轮交手后拉回全景证明两人都在 |
| 要看清、要显重时换更紧的镜头（拳与受击的躯干、前臂相撞、支点脚、破损），打斗保持实速 | 为了看清把两个人都放慢 |
| 关系变类时切：拳脚 → 擒腕 → 摔 → 压墙，切过去拍新的关键机制 | 每一招切一次；按固定秒数切 |
| 局部镜头的运动方向与已建立的左右一致；换边让观众看见交错，下一镜确认新位置 | 一切镜人物左右互换 |
| 袖子、身体、柱子、尘土扫过镜头时切，下一镜接同一动作相位 | 用尘土遮住瞬移 |
| 接触那一下镜头短促一震 | 持续摇晃冒充力量 |
| 慢动作默认不用；要用只给决定性的一下 | 慢动作拍完整个倒地 |
| 动作复杂时镜头简单，动作简单时镜头才花 | 运镜遮住身体动作 |

一镜 4–8 秒放一个完整的交手闭环，最多一次主动权翻转；接触多、精度要求高就拆镜。每镜写全左右位置、朝向、哪只手拿什么、件数、谁还能动、环境损伤、还在飘的尘土：编译后每镜独立，「同上」等于没写。每镜都是一次收费生成，覆盖档位按[覆盖](filming-coverage.md)「本剧用法」取舍。

## 写进分镜与 overhead

| 写在 | 写什么 |
|---|---|
| 场 `purpose` | 完成条件与本场的变化 |
| `action` | 每人身份、兵器与件数；本镜仍在的损伤与倒地的人 |
| `blocking` | 屏幕左右、朝向、路线，谁占哪条进攻线 |
| `beats` | 每拍一条因果链：谁、哪个部位、打哪、结果、新位置 |
| `camera` | 本镜职责加[镜头](filming-shots.md)各项 |
| `dialogue` | 交手中少而短，放在喘息的拍上 |
| overhead | 每一下 `[[hit]]`（谁、用什么、打谁、几秒、部位、结果；落空 `miss`、伤到 `hurt`）；护人 `[[guard]]`；察觉与来得及 `[[react]]`；看谁 `[[gaze]]`；兵器 `[[carry]]`；被打飞、拖走的东西 `[[prop]]`；施法 `[[cast]]`；入场离场 `enter` / `gone` |

速度不写「快速」，写结果（拖影、背景运动模糊、主体清晰，见[运镜](filming-movement.md)「写进分镜」）。Seedance 官方提示冲刺、翻滚、大跳容易崩：高爆发动作拆短，写清支撑与落地，一镜只放一个高难动作（[Seedance 写法](prompts-seedance.md)「动作与表演」）。

## 出片后对照

一次只改一类变量（动作 / 镜头 / 参考），改完再出；连续两轮没改善，回头查是不是分错了类。同一镜到重试上限就搁置，见[出片](prompts-generate.md)。

| 现象 | 先查 | 首选修正 |
|---|---|---|
| 两人各打各的 | 动作 | 补齐出手、接触、回应、位移、下一拍 |
| 看不清打中没有 | 镜头 | 侧向中景或短接触插入 |
| 人物左右互换 | 镜头 | 固定轴线，overhead 查越轴 |
| 动作被模型删掉 | 动作 | 删装饰描写，只留关键动作与结果 |
| 受击没力量 | 动作 | 写清接触部位、受力方向、位移与材质反应 |
| 身体粘连 | 参考 | 换轮廓分开、四肢完整的参考 |
| 兵器多出或变形 | 参考 | 完整兵器图，写明件数、长度、握法 |
| 法术凭空出现 | 动作 | 补蓄力与来源，交代路径和落点 |
| 损伤复原 | 动作 | 后续每镜重写损伤状态 |
| 镜头乱跳 | 镜头 | 少机位，一镜一职责 |
| 参考视频整条被照搬 | 参考 | 写明只取动作轨迹或运镜 |
