# 片种（幕 / 集）

这一层在场之上：电影按幕与段落规划，连续剧按集规划。场、覆盖与镜头的拍法电影和连续剧共用，见[场](filming-scenes.md)与[镜头](filming-shots.md)。片种只改三件事：视觉统一由谁来定、按什么单位规划、开头结尾怎么拍。片种页只写差异，不重抄共用页。

| | 电影 | 连续剧 |
|---|---|---|
| 视觉统一 | 一位导演定全片调子 | 第一集定风格，后面每集照做 |
| 规划单位 | 三幕与段落；奇观段落单独规划 | 每集：开场钩子 → 几段 → 集尾钩子 |
| 世界的建立 | 第一幕集中建立一次 | 第一集建立；后面只在换地点时建立，常驻场景可复用 |
| 开头与结尾 | 开场画面与结尾画面互相呼应 | 每集集尾的钩子镜头；季末收束 |
| 连续性 | 片内一致 | 跨集一致：服装、道具、伤势、陈设 |
| 详见 | [电影](filming-film.md) | [连续剧](filming-series.md) |

剧的 `workflow.json` 用 `format` 声明片种（与故事创作相同）；影视改编读共用页，再读本片种页。
