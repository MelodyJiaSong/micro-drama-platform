# 选条

每镜往往生成了好几条。选条要回答两件事：用哪一条，用它的哪一段。

## 先标注，再挑

每条进来先生成一份标注，后面的评分、切点、校验都读它，不重复看片。

| 标注 | 怎么得到 | 注意 |
|---|---|---|
| 台词实测起止（逐词） | 强制对齐：剧本已知，用对齐而不是自由转写 | 模型会漏说、改词、调语序，要标出来，不当作对齐成功 |
| 内切、闪帧、黑帧 | 镜头边界检测（PySceneDetect、TransNetV2） | 生成的单条一般没有硬切，检出的多半是模型自己插的内切 |
| 人脸与身份距离 | 逐帧人脸向量与人物资产参考图比余弦（InsightFace / ArcFace） | 阈值必须用本剧人物的同人 / 异人样本标定；风格化人物能否沿用未经验证 |
| 景别、人物左右位置、视线 | 人脸框占画面比例分档；位置与朝向 | 给精剪查跳切、轴线用 |
| 运动量 | 光流幅度（RAFT） | 动态程度与平滑度方向相反，按镜头类型分开设权重 |
| 画面描述与疑点帧 | VLM 逐段描述，按错误类型逐类问（手、脸、肢体、人数、道具） | 只作初筛和提示位置，见下 |
| 可用区间 | 去掉首尾不稳定帧与伪影段后剩下的起止 | 切点只能落在可用区间内 |

## 硬门与软分

**硬门**（一项不过即淘汰）：人数或人物不对；身份距离超阈值；出现内切或闪帧；该说的台词缺失；可用区间短于本镜需要的时长。

**软分**（加权排序，取前几名交人定）：

| 软分 | 衡量 | 局限 |
|---|---|---|
| 与 prompt 相符 | CLIP / SigLIP 余弦 | 对计数、否定、伪影都不敏感 |
| 画质与美感 | DOVER、VBench 的成像 / 美感维度 | 训练于普通视频，未声明适用 AI 生成片；美感分偏爱静止画面 |
| 运动平滑、主体一致 | VBench 对应维度 | 同上 |
| 台词完整度 | 对齐置信度、WER | 漏说的句子要么换条，要么剪掉 |
| 伪影风险 | VLM 疑点帧数量与位置 | 见下 |

## VLM 看片能到哪一步

用 Veo 3、Seedance 等生成片做的测试里，Gemini 2.5 Pro 定位错误的得分约为人的一半，模型还常把整段都标成有错；把检测拆给手、脸、肢体各自去问会好一些。所以 VLM 结论只用来排序和提示「看这几秒」，通过与否由人看片判定。

| 应该 | 不应该 |
|---|---|
| 每条都登记可用区间与疑点帧，选条结论绑定这条的 sha256 | 只记「这条能用」，不记哪一段能用 |
| 先过硬门，再按软分排序，最后人从前几名里定 | 只看一个总分挑第一名 |
| 全部不过就开单退回出片，写清原因；同一原因两次不过就换方案 | 硬门不过也勉强用，指望剪辑遮掩 |
| 模型、对齐器选可商用许可（如 ctc-forced-aligner 默认模型为非商用许可，不用） | 只看效果不看许可 |

**本剧用法**：现阶段每条生成都是人点的，条数不多（行业经验约五条出一条可用），所以选条先做好标注和硬门，省人眼；表演好坏、情绪对不对仍由人定。
