# 角色类别

每个具名角色都要帮助或阻碍主角追目标，并且都以为自己是主角：先问他这一刻想要什么（见[六个问题](story-questions.md)）；两者都不做的只是氛围人物，相当于道具，能删就删。类别不中途更换，但角色可以隐藏真实身份或意图。支线大多来自配角，能减轻主角与对手反复对打的压力。

| 阻碍 | 作用 | 例子 |
|---|---|---|
| 对手 | 最想阻止主角的人；全片只有一个，好在结尾正面决胜 | 《回到未来》Biff |
| 对手代理 | 替对手出手 | Biff 的帮派 |
| 独立麻烦制造者 | 自己制造麻烦，不听对手指挥 | 校长 Strickland、利比亚恐怖分子 |
| 守门人* | 先拦住主角，逼他证明自己，之后常转为盟友 | — |

| 帮助 | 作用 | 例子 |
|---|---|---|
| 导师 | 传授技能与智慧，年龄不限；关键时会为主角冒险 | Doc、《海底总动员》Gil |
| 帮手-追随者 | 跟着主角行动、出力 | Jennifer、舞会乐队、鹈鹕 Nigel |
| 跟班* | 主角身边的长期同伴 | — |
| 喜剧盟友* | 带来笑点，缓和紧张 | — |
| 对比盟友* | 与主角形成对照，映照他的选择 | — |
| 拉拉队盟友* | 鼓励、支持主角 | — |
| 希望救星* | 带来解救的希望 | — |

| 其他 | 作用 | 例子 |
|---|---|---|
| 主角 | 主动追目标的人 | Marty、Marlin |
| 爱情对象 | 必须与主角有冲突；没有冲突的恋人只算帮手 | 《黑客帝国》Trinity；Jennifer 因无冲突不算 |
| 受威胁的无辜者 | 需要主角保护，抬高赌注 | Nemo、E.T. |

用法：先定主角、对手和受威胁的无辜者，撑起主冲突；再按剧情需要补帮手和阻碍。每加一个配角，先问他在帮还是在阻、能带出哪条支线。

\* 作者原定义未取得，作用按名称推断。
