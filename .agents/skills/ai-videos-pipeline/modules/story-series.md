# 连续剧

电影的结构仍然适用，但要分层用：一季走完三幕，一集只是其中一段。

## 三幕放在哪一层

| 层级 | 用法 |
|---|---|
| 整部剧 | 定长期方向和最终问题；只定方向，不提前写死 |
| 一季（或一个大段落） | 完整三幕：平常世界 → 特殊世界 → 决战；两次大转折、中点都按季安排 |
| 一集 | 几段「短期目标 → 新消息」；开场快速钩住，中段升级，结尾留钩子 |

## 与电影的不同

| 电影做法 | 连续剧改法 |
|---|---|
| 一部片走完三幕 | 一季走完三幕；季末前一集放全季最大反转，最后一集收拾后果、铺下一季 |
| 一个主角 | 多条线并行：A 线是主冲突，B 线推动主线，C 线轻量串场；常见篇幅约 6:3:1 |
| 结尾正面决胜 | 单集结尾留钩子；季末收掉本季主冲突，同时抛出新问题 |
| 对手固定、主角成长 | 对手可以逐季更换；主角可以死、退步或改变立场 |

例《权力的游戏》：每季最大事件都在第 9 集——第一季 Ned 被斩首，第二季黑水河之战，第三季血色婚礼。Ned、Jon、Daenerys、Tyrion 各有一条线，一集里交替推进。

## 注意

| 注意 | 说明 |
|---|---|
| 每条线都套用故事结构 | 每条线的主角都要可同情，有具体目标和对手 |
| 节点按季算 | 不要求每一集都有大转折或中点 |
| 边写边拍 | 只把当前这一季写实，后面保留方向和原作锚点 |
| 集长不同 | 电视网一小时剧常分开场短戏加 4–5 幕，每幕结尾一个悬念；短剧集更短，就把每集当一到两段推进 |
| 集长上限 | 剧在 `workflow.json` 用 `episode_seconds` 声明每集成片时长 `[下限, 上限]` 秒，是硬规则：故事按这个篇幅构思（几场、几段），不先写长再砍；分镜总时长由[交稿前自检](decisions.md)拦。篇幅装不下转折就留给后面的集：mini ep 不必每集走完一段完整推进或常规单集结构，只要停在观众想看下一集的地方（2026-10-17 用户定） |

## 伏笔

| 电影做法 | 连续剧改法 |
|---|---|
| 片内埋、片内兑现 | 跨集跨季埋；每季至少兑现一颗旧钉子，同时埋新的 |
| 写之前想清楚全部 | 只定终局方向与主题；钉子宽，意义揭到哪层再定哪层 |
| 编剧心里有数即可 | 剧级维护伏笔账本：钉子、开放问题、候选方向、已在画面的事实 |

季内也可以埋：《绝命毒师》第二季第 1、4、10、13 集开场都是泳池里半焦的粉色小熊，季终两机相撞、小熊落进主角泳池，才揭开意义。
