# 焦点与景深

景深是画面里清楚的那一段范围。它是一条可以调的光谱：从全清楚、到只清楚一处、到哪里都不清楚，还可以在一镜之内移动。

| 类型 | 是什么 | 用来 | 不是 / 代价 | 片例 |
|---|---|---|---|---|
| 深焦 | 主体和背景都清楚 | 多人在不同远近同框；背景有要看的信息；前中后景同时有戏，让观众自己看 | 不引导视线，观众的眼睛自己剪辑 | 《地心引力》开场长镜头，从宇航员到地球都清楚；混乱爆发时所有动作都看得见 |
| 浅焦 | 只有一层清楚（焦平面），前景、背景或两者都虚；可出散景光斑 | 引导注意力；浪漫；赋予某物意义；孤立主体；暗示人物心境 | 不要滥用，留给真正要紧的时候 | 《月光男孩》母亲逼近喀戎，极浅焦加主观取景，显出她对他的控制 |
| 柔焦 | 画面没有一处完全清楚；靠镜头缺陷或柔光滤镜 | 梦境、回忆，或整部片的风格 | 过去用来美化女星，如今少见；要有明确目的 | 《卡萨布兰卡》英格丽·褒曼；《人工智能》全片柔焦加强光晕，像梦里的童话 |
| 移焦 | 一镜之内把焦点从一处移到另一处；是动作，不是形容词 | 精确指引视线；不切镜就揭示新东西或连起两者；快移能放大惊慌 | 复杂跟拍要持续精准地跟焦 | 《汉江怪物》偷溜出医院一场，焦点在江斗和弟妹之间来回，护士一喊，迅速移回江斗的近景 |
| 分屈光镜 | 前后两处同时清楚，中间是虚的 | 前后景都有关键信息又不想用深焦；两人在不同距离对话，不想移焦 | 人眼做不到，效果不自然，容易让观众出戏；很少用 | 《八恶人》前景昏迷的马尼克斯、背景无助的沃伦少校，两人最脆弱的时刻同框 |
| 移轴 | 只有极窄一条清楚，其余全虚 | 让真实场景像微缩模型；表现意识被改变 | 机会不多，但需要时无可替代 | 《社交网络》；《严肃的男人》成人礼上丹尼的恍惚 |

| | 应该 | 不应该 |
|---|---|---|
| 深焦 | 层次里每一层都安排了内容 | 背景杂乱，抢走主体 |
| 浅焦 | 先想清楚焦点给谁、虚掉的是什么 | 每镜都浅焦，最后什么都不突出 |
| 柔焦 | 用来标明梦、回忆或全片风格 | 画面糊了却没有理由 |
| 移焦 | 移动的时机跟着台词、反应或新信息 | 来回移却不带出新东西 |
| 分屈光镜 / 移轴 | 前后两处真的同样重要，或确实要扭曲感知 | 当作炫技 |
