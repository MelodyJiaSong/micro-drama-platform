# 观众

> **观众是主角，不是人物。** 人物逻辑、时间先后、交代顺序都让位于观众此刻的心理：观众知道什么、在想什么、在等什么，我会不会失去他。

这是本页最重要的一条，也是故事创作、影视改编、剪辑共同的第一原则；另外两条是它的推论——一切相连，是因为观众会记住并追问每个细节；按戏剧顺序排，是因为观众被钩住后会自己拼起来。三条原则电影与连续剧共用。

## 怎么用：观众轨

写故事、分场、排拍点、定切点时，旁边并行写一条「观众轨」：每场（拍点）一句，观众此刻**知道什么 → 在想什么 → 在等什么**，以及这一场是兑现、延迟还是颠覆这个期待。写不出来，说明这一场还没想清楚为谁而写。观众轨写进[决策记录](decisions.md)。

| 原则 | 是什么 | 不是 | 应该 | 不应该 |
|---|---|---|---|---|
| **观众是主角** | 好导演根据观众此刻的心理安排每一步，而不是人物的逻辑或事情的先后；问的是「观众为什么而来，我会不会失去他」 | 不是放弃人物逻辑；是人物逻辑让位于观众的节奏 | 每场想清观众在等什么；先让观众心里的嘀咕说完，等他们只剩下「来吧」，再兑现 | 只想「我得先交代什么」；人物照常理一步步做完，错过观众准备好的那一刻 |
| 一切相连 | 剧本里说过、拍过的每样东西都要和别处接上；像盖楼，一处没接牢，整栋会塌。小说可以第 1 页的事和第 158 页没关系，剧本不行 | 不是每个细节都要成为伏笔；是不许留下没交代的变化 | 每个物件、穿戴、台词都能说出它和哪里相连；看得见的变化都有原因，见[伏笔](story-foreshadowing.md)「已拍出的就是事实」 | 第一场戴红帽，第四场换蓝帽，之后帽子没了，却没有任何交代——观众散场后正会聊这种事 |
| 戏剧顺序 | 唯一要紧的是戏剧顺序；时间顺序、逻辑顺序、人物心理顺序都不是排场次的依据 | 不是随意打乱；前提是先把观众钩住 | 先钩住观众，之后往前跳、往后跳都可以，观众会自己拼起来；「十年后」「五年前」这类提示可以帮忙，但不必 | 为了时间或因果的顺序，把最抓人的东西往后放；先铺一堆交代 |

## 片例：《群鸟》阁楼

梅兰妮独自困在屋里，鸟刚试过从窗户闯进来；她听到阁楼有声响，偏偏一个人走上吱呀作响的楼梯。按人物逻辑这说不通，观众心里在骂：她怎么这么蠢、手电筒为什么不先试试。她走到半路，声响更大，她停下来听——停顿不是给人物的，是给观众的：让观众把嘀咕说完，要么起身离场，要么留下来。到最后一级前她又停住，此时观众心里已经空了，只剩「我花钱就是来被吓的」。观众准备好了，她才推门。

不懂这一点的人会让她一口气走上去，或者先试好手电，整场戏就散了。（讲者凭记忆复述，服装等细节与原片不尽相符；要点是停顿的位置和用途。）

## 先定体验，再找事件

**剧级一句话体验，即全剧 Vision（必备）**：每部剧在剧 README 开头写「## Vision（观众体验）」，用一句话说观众看这部剧要经历什么、带走什么感受——写感受，不写剧情；保持抽象，不点名具体人物、不写具体情节，给故事与分镜留出实现的灵活度；像公司的 vision，故事、分镜、剪辑、声音的取舍都围绕它。由用户定稿，代理可以起草候选，不能自行写定或改动；改了要说明理由并记入剧的决策记录。缺了就先问用户，不开写故事。所有模块创作与审查都对照它，见[决策记录](decisions.md)「对照 Vision」。

**核心：这部剧到底关于什么（必备）**：和 Vision 写在同一节，一行「核心：」，写这部剧唯一的、贯穿一切的那件事——通常是一个问题或一组内在冲突。Vision 回答观众**感受到什么**，核心回答故事**关于什么**；两者都抽象、都由用户定。

| | 是什么 | 例子 |
|---|---|---|
| 核心 | 一切都建在上面的那一件事；关于不止一件事，就等于什么都不关于 | 《电视台风云》：社会不再珍视人的生命时，人该怎样活；《广告狂人》：想做的事与必须做的事之间的冲突；《绝命毒师》：关于改变（第二场化学课上老师亲口说「化学是研究改变的学问」） |
| 不是 log line | log line 是推销工具，只讲主角的一条线；核心要罩住每个人物和每条副线 | 《绝命毒师》的 log line「好好先生变成疤面煞星」只说了沃尔特，罩不住斯凯勒和索尔 |
| 不是题材清单 | 东一块西一块地盖，最后只是几堆碎砖：小岛上只够盖一栋房子，就别一半盖海边、一半盖林子 | — |

| 应该 | 不应该 |
|---|---|
| 写之前先把核心想透，并把它当北极星：《电视台风云》的编剧花一年才想清楚，写在卡片上贴在打字机上方；《热天午后》的编剧四个月里用三个月想它、一个月写 | 带着几件「也很重要」的事开写 |
| 措辞要精确，一个词一个词地改，直到说得出、圈得住 | 用一句含糊的大话凑数 |
| 不得不拿掉核心时，知道它在每一场里：换一个新核心，整部顺着它改；主角的行动不分给两个人（Glenn Gers 把一个惊悚片的四人结构改成三人，让女主一人扛起整个故事，反而更强） | 只拆掉一处，其余照旧，留下一群人没有理由地追来追去 |
| 每个想法、每条故事线都问：它站在这块地上吗？不在，再好也不用——编剧室里很多好点子因此被放弃；雷德利·斯科特想出一个很爱的开场，发现它和核心接不上，当场放弃 | 卡住时抓住一个漂亮的解法，却不管它连不连得上核心 |

核心是最好的朋友，也是最大的敌人：知道它以后，什么该留、什么该删一目了然；但它会逼你放弃接不上它的好点子。

**集级体验（边拍边加）**：每集写故事时，在集级故事决策记录开头用一句话写本集体验，说明它怎样服务剧级体验；不要求预先给所有集写好。

观众是主角落到结构上的做法（讲者称为 plot casting）：不从「先发生这个，再发生那个」的大纲开始，先定观众要有什么体验，再找能造成这种体验的事件。像规划旅行：先问为什么去——蜜月、带孩子、一个人放空——想要的体验定了，才选地方，再定住哪、每天做什么。

| 步骤 | 做什么 | 要点 |
|---|---|---|
| 1. 体验地图 | 从剧级一句话体验往下，写观众在本集、每一段、每一场要有的体验 | 要的是表层情节之下的体验：观众说得出剧情和好不好笑，却常常意识不到自己正在经历什么；最好的编剧从这一层开始 |
| 2. 求量 | 围绕人物和世界，把可能发生的事尽量多地列出来 | 先不管顺序，也不先筛；编剧室就是这样工作的 |
| 3. 选事件 | 用体验地图从清单里挑：表层要成立（好看、好笑、有冲突），底下要给出那层体验 | 一场戏可以把全片的体验先浓缩演一遍，之后再展开、升级 |
| 4. 排顺序 | 按戏剧顺序（见上表）排选中的事件，再套[三幕](story-acts.md)等结构检查 | 大纲是最后一步，不是第一步 |

| 应该 | 不应该 |
|---|---|
| 先写体验地图，再找事件；事件写不出体验就换 | 一开始就锁进大纲，只见树木不见森林；件件有趣，加起来却不成东西 |
| 开场一场就让观众先经历全片（或全剧）的核心体验 | 开场只交代信息，体验留到以后 |
| 把这当作默认做法先走一遍；不适合时可以改，但说出理由 | 当成唯一正确的路；讲者自己也说上山的路不止一条 |

片例：

- **《伯德小姐》开车一场**：全片的体验是要从一个控制欲极强的母亲身边挣脱出来，痛得像撕开自己。车里两层冲突：克里斯汀想去东部读文学院（离萨克拉门托的妈妈越远越好），母亲说她会失败；更大的冲突是她要妈妈叫她自己取的名字「伯德小姐」，妈妈拒绝。她挣不开，就解开安全带跳出行驶中的车，摔伤了胳膊。全片的体验在这一场先演了一遍。
- **《欢乐酒店》试播集开场**：1980 年代初，电视网担心酒吧阴暗、危险，不适合合家观看。要的体验是「这间酒吧很安全，酒保是好人」。从一大堆可能的酒吧小事里，他们挑了：白天、店里没人，一个十四五岁的孩子来要啤酒；山姆没有羞辱他，开玩笑地查证件、拆穿他，再客气地送他走。没人看见，山姆也不会卖酒给孩子——好笑、有棱角，但心地好；白天拍、画面明亮。整个试播集都在做这件事：让观众觉得在这里安全、喜欢这些人、每周想回来。

## 落到下游

| 模块 | 做法 |
|---|---|
| 故事创作 | 先写体验地图，再求量、选事件、排顺序；开场先钩住，见[同情来源](story-sympathy.md)；场次按戏剧顺序排，不按时间顺序；连续剧每集开场快速钩住，见[连续剧](story-series.md) |
| 影视改编 | 关键兑现前在 `beats` 里留给观众追上的停顿，见[好场的构成](filming-scene-anatomy.md) |
| 资产与分镜 | 服装、道具的每次可见变化都有交代，见[资产](../resources/assets.md)的道具规则 |
| 剪辑 | 兑现前的停顿按观众的心理节奏卡，不按动作本身的时长，见[精剪](edit-fine.md) |
