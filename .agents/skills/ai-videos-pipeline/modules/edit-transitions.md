# 转场

镜头组成场，场组成段落；转场决定一场怎样接到下一场。每种转场都有自己的功能，选哪一种要说得出理由。内容整理自 StudioBinder《The Shot List》第 9 集「9 种剪辑转场」，片例沿用原课；「本剧用法」一栏是按 AI 出片条件做的取舍，不是原课结论。

## 九种转场

| 转场 | 是什么 | 用来 | 片例 |
|---|---|---|---|
| 切 | 一帧之内从一个镜头换到另一个镜头，或从一场换到下一场 | 最常用；切法本身也能带情绪，例如参差的切加重碎玻璃的暴力感 | 切的细节见[精剪](edit-fine.md) |
| 淡入淡出 | 画面渐变到纯色或从纯色渐出，通常是黑，少数是白 | 淡入开片，带观众进入；淡出收尾，像合上一本书；片中淡出像章节结束，刻意停住势头，让观众喘口气、回味 | 《1917》开场；《低俗小说》章节之间 |
| 黑场过渡 | 同一场内淡出再淡入（dip to black），一种风格选择 | 隔开同一场里的几个时刻 | 《消失的爱人》 |
| 白场 | 淡到白 | 进入梦境或死亡；也让结局悬而不决，不给出收束 | 《黑天鹅》结尾：她死没死，没有答案 |
| 叠化 | 渐变，但直接过渡到下一个镜头 | 表示比一刀切更长的时间流逝；或进入回忆、梦境 | — |
| 叠印 | 两个镜头叠化时，中途两幅画面同在一个画框里，形成第三个镜头 | 让两场、两个人互相对照 | 《教父 2》迈克尔叠到他父亲，两人生平的对照 |
| 匹配剪辑 | 用前一镜的元素对上后一镜的相似元素，瞬间相接：形状、构图、颜色、运动或声音 | 让观众下意识比较两场的异同；跨越时空；两张脸相接，默认是同一人的不同年纪 | 《2001 太空漫游》骨头接卫星；《加勒比海盗》小伊丽莎白接长大的她，一刀交代跳过多年和她仍迷恋海盗 |
| 匹配叠化 | 匹配剪辑加叠化 | 功能同匹配剪辑，把突兀的一刀磨圆 | 《玩具总动员 2》翠丝的脸叠成太阳 |
| 光圈 | 圆形开合，早年在摄影机里开合光圈做出 | 早期电影用来开片收片，今天已过时；现在作风格选择，像推近一样把整场聚焦到一个元素、一种情绪 | 《无间行者》：科林先被框成微小的一点，光圈打开露出警局大楼，世界向他敞开 |
| 划像 | 下一镜从某个方向（上、下、左、右、斜）把上一镜推出画面；也有星形、时钟形 | 复古风格；今天多是反讽或喜剧用 | 《星球大战》系列（致敬《飞侠哥顿》与黑泽明《战国英豪》）；《洛基恐怖秀》 |
| 遮挡过渡 | 移动的人或物经过画面，或镜头掠过一个物体，借遮挡进入下一场（pass-by） | 比划像更无缝，藏住剪辑点；配合声音设计，场与场的势头不断 | 埃德加·赖特的片子 |
| 甩镜 | 快速横向摇，画面拖成模糊（whip / swish pan） | 场中常用，也可作转场；要延续上一场的势头时最有用 | 《不羁夜》吸毒后一场场飞速掠过，一刀切出不了那种眩晕 |
| 硬切 | 两场之间突然一刀，画面和声音都强烈反差：静到吵、乱到定（smash cut） | 惊吓、震醒观众；角色从梦里惊醒；喜剧里用反差点题 | 《闪灵》；《禁闭岛》惊醒 |
| J 剪辑 | 下一场的声音先于画面进来（pre-lap）：观众还看着 A，已听到 B | 对白常用；也用来进入回忆、闪回 | 《拯救大兵瑞恩》先听到海浪，再见诺曼底 |
| L 剪辑 | 上一场的声音延续到下一场画面 | 常用于旁白 | 《敦刻尔克》结尾，丘吉尔演说压在后续画面上 |

J、L 的名字来自时间线上音轨与画轨错开的形状。它们真正的力量在于用声音和画面造出新语境：声音 A 加画面 B，意思比两者各自更复杂。原课另列推、变焦、亮度键、翻滚等，选项无穷，但以上是最常用的。

## 本剧用法

AI 出片里，转场分两类：剪辑里就能做的，和必须在拍摄阶段就设计进镜头的。后者剪辑做不出来，只能开单退回上游。

| 类 | 转场 | 在哪里定 | 说明 |
|---|---|---|---|
| 剪辑可做 | 切、淡入淡出、黑场、白场、叠化、叠印、硬切、J/L、光圈、划像 | [精剪](edit-fine.md)，确定性工具渲染 | 只从这份菜单里选，每次写理由；不让模型自由「加个转场」 |
| 要上游设计 | 匹配剪辑、匹配叠化、遮挡过渡、甩镜 | [影视改编](filming.md)写进分镜，[Prompt 编译](prompts.md)写进两镜的首尾 | 匹配要两镜的形状、构图、运动方向对得上；遮挡与甩镜要上一镜结尾和下一镜开头各有一段遮挡物或甩动，各自生成 |

**工具**：剪辑可做的这一类已做成菜单（`python tools/episode_cut.py menu`），集级剪辑决定只能从菜单里选，每次写理由；要挑的时候先用 `episode_cut.py gallery` 在那两场的交界出一条转场样片，看过再定。菜单里的「模拟甩镜」「推近转场」只是剪辑里的近似，真正的甩镜、匹配剪辑、遮挡过渡仍要上游设计。J/L 要用条里入点之前 / 出点之后的原声，条里不够就做不了（样片会跳过并说明）。

| 应该 | 不应该 |
|---|---|
| 场内默认用切；场与场之间也以切为主，其他转场要有功能 | 为了「有制作感」到处加转场 |
| 竖屏短剧开头和集尾的钩子用硬切或 J 剪辑，抢在观众划走前 | 集中间用淡出到黑，平白停掉势头 |
| 跳时间、进回忆用叠化或 J 剪辑，同一剧内用法固定，观众学一次就懂 | 同一种意思这次叠化、下次划像 |
| 遮挡过渡、甩镜、叠化可以顺带藏住 AI 接缝（见 [AI 素材的修补与遮掩](edit-ai-footage.md)）；遮挡和甩动本身也是生成的，先查有无穿帮 | 拿转场掩盖本该重生成的坏条 |
| 白场、光圈、划像只在剧级风格明确要时用，登记理由 | 把复古划像当默认 |
