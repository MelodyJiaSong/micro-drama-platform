# AI 素材的修补与遮掩

生成的每条都是独立出的：同一人物、同一场景在两条之间会走样。剪辑先选能用的段，再用剪辑手法遮掩，最后才修补；修补也不行就退回重生成。

## 常见问题与处理

| 问题 | 怎么发现 | 剪辑上的处理 |
|---|---|---|
| 首尾不稳定帧（糊、重复、走形） | 首尾若干帧的帧差突变、重复帧、模糊度 | 登记可用区间，切点落在区间内 |
| 人物身份漂移 | 逐秒身份距离对比人物资产参考 | 只用脸稳定的那一段；换条；切到反应、侧面或背面 |
| 跨镜色差 | 切点两侧亮度、色度直方图距离 | 同场按参考镜统一调色：用一张参考帧算出变换、整段套用，逐帧重估会闪 |
| 口型不同步 | 音画偏移（SyncNet 一类）；可察觉范围约声音超前 45 ms 到滞后 125 ms（ITU-R BT.1359） | L 剪辑切到听者；用侧面或背面镜头接话 |
| 运动伪影、手变形 | 疑点帧（见[选条](edit-selects.md)） | 在问题出现前切走；不要在两段运动之间插静止帧，最容易露接缝 |
| 首尾帧接缝跳变 | 接缝光流与 SSIM | 插 1–3 帧（RIFE、FILM）；大运动会出鬼影，源片运动本身不连续就重生成 |
| 覆盖不够、没有备用角度 | 粗剪时发现跳切、越轴无处过渡 | 用插入镜头（手、道具）、反应镜头、中性镜头遮掩；推近裁切要保证裁后像素不低于输出 |

## 修补顺序

裁切 → 调色 → 补接缝 → 稳定 → 最后超分。超分放最后：SeedVR2 在大运动处会失败、干净素材会过锐；Real-ESRGAN 逐帧处理会闪。

## 什么时候退回重生成

延长（Seedance、Kling 等）、文字局部重绘（Runway Aleph、Kling O1 等）比整镜重抽便宜，但它们都是**收费生成**：走[出片](prompts-generate.md)，用户决定，先记请求日志；改动内容要回到分镜或 prompt 说得清，不在剪辑里私下补画面。行业转述的数据是四到五成返工花在修穿帮上，所以源头少写多人同框、多用近景特写，比后期修更省（见[覆盖](filming-coverage.md)的本剧用法）。

| 应该 | 不应该 |
|---|---|
| 先剪掉、再遮掩、最后修补 | 一开始就插帧、超分硬救 |
| 修补后的文件另存并记来源与参数，可重做 | 覆盖原条 |
| 修补后重新跑身份、色差与接缝检查 | 修完只看一眼 |
