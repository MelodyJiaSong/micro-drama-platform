# 固定规则

编译器自动加入，分镜里不用写，也不能删。

| 规则 | 内容 | 为什么 |
|---|---|---|
| 镜头 key | 首行是完整 key：`ep1_s1_st1`。集号不补零；场、镜沿用稳定编号，不按列表位置重编 | 生成的文件靠 key 认领；调序不改号，文件不会认错镜 |
| 参考在前 | 「参考：」一行列出全部参考，格式 `` `key_id=>@` ``（运动参考 → 每人三视图 → 背景图 → 每人声样）；`@` 是占位，资料包按上传顺序填成 `@图片N` / `@视频N` / `@音频N`；正文用 key_id 指认参考（follow-up 229） | 没有参考，模型保持不住人物、场景、声音的一致；官方：越需要精确参考的素材越靠前写 |
| 运动参考用法 | overhead：「示意图，不是画面……颜色、线条、箭头和文字都不出现在画面中，人物颜色也不是服装颜色」；previz：「只参考机位、运镜、站位、朝向、走位和动作时刻，不参考人偶外形与颜色，不出现绿幕和人偶」 | 示意图、标记色、人偶外形会被当成画面内容渲染出来 |
| 人物、场景、声音用法 | 三视图是同一个人的正、侧、背三面，不是三个人，只取长相、发型、体型与服装；场景图只取材质、形制、陈设与色调，空间以运动参考为准、光按「光线」；声音只取音色，不说话的人不出声 | 防止参考图的姿势、机位、光向覆盖本镜设计；防三视图被读成三个人 |
| 口型 | 有台词时加「画内说话的人嘴型与台词同步……其他人不开口」 | 多人同框时防止错的人开口 |
| 负面词 | 固定项（分身、双胞胎、多出来的人、字幕水印、背景音乐、绿幕、人偶、示意图标记）＋ 剧 `workflow.json` 的 `prompt.negatives` | Seedance 没有单独负向参数，约束写进正文 |
| 声音 | 「声音：仅保留本镜指定对白、自然环境声和动作声；不要背景音乐或配乐。」放在 key 之后和末尾 | 配乐由后期单独设计；生成模型自带的音乐无法拆掉 |
| 无对白 | 对白为空的镜加「本镜没有人说话。」 | 防止模型给画面配上人声；不等于整镜静音 |
| 连续镜头 | 「要求：连续镜头，不要切镜。」 | 一个 shot 是一段连续画面；要切镜就在分镜里拆成多个镜头 |
| 无字幕水印 | 同一行「不要字幕或水印。」 | 字幕后期另加；模型画出的字常是乱码 |
| 防分身 | 「画面中每个人物只出现一次，不要分身或双胞胎。」；镜内有动物（m 键，如同一张狼卡的三只狼）时再加「动物（`m7_Wolf`）按「画面」写的数量出现，同一张三视图可以是几只同类。」 | 官方给的防双胞胎固定句；只约束人，同一张卡的几只动物不被压成一只（编译器 v9） |
| 自然表演 | 有人物时加「人物按真人自然表演……不照搬参考里人偶的僵硬姿势」 | 旧流程实测：白模人偶的僵硬会被照搬进成片 |
| 参考门禁 | 任何一镜缺 overhead、该有 previz 却没有、三视图或声样或外观段缺失、没有背景图或场景段，拒绝编译并列出 | 不能只用文字生成；参考缺失的 prompt 编号会错位 |
| 长度上限 | 超过 5000 字拒绝编译（即梦单条上限） | 细节写足，但不超过上限；超了拆镜或精简分镜 |
| 版本门禁 | 分镜未确定、或确定后又改动，拒绝编译；编译器版本更新后旧结果标「待更新」。每个编译场记 `source`（这一场的分镜指纹），资料包按场判断过期；单场编译不让整个 Prompt 模块变成最新（follow-up 259） | 保证 prompt 对应的是确定过的那一版分镜 |
| 确定性 | 同一分镜、同一批参考文件与编译器版本，结果逐字相同 | 可复现，可比较 |

| 应该 | 不应该 |
|---|---|
| 想改 prompt 的内容，回去改分镜或 overhead 再重新编译 | 直接手改 prompts.json 或 prompt.txt |
| 规则本身要变，改编译器并升级版本号 | 在个别镜头的分镜里写相反的规则（例如要求加字幕） |
| overhead、previz 或人物图换了，重新编译 | 以为旧 prompt 的参考清单会自动更新 |
| 出片后核对画面与声音是否真的守了规则 | 以为 prompt 写了就一定生效 |
