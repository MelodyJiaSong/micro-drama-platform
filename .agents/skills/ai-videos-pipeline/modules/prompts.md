# Prompt 编译

输入：已确定的分镜。输出：episodes/epNN/prompts.json。
编译结果保留scenes→shots结构，按场次及镜头列表顺序拼接时长、场次地点/时间、环境引用、动作、摄影和对白，固定补充连续镜头、无字幕及水印。
Seedance声音规则固定编译为「声音：仅保留本镜指定对白、自然环境声和动作声；不要背景音乐或配乐。」放在首行key之后及prompt末尾；无对白镜另加「本镜没有人说话。」不把无配乐理解为整镜静音。配乐由后期独立设计与混音，出片后试听确认，prompt限制不等于实际音轨已通过验收。
每个prompt首行必须是完整key：ep1_s1_st1。ep01等目录编号在key中不补零；s/st沿用稳定编号，不按列表位置重编号。
编译派生产物写episodes/epNN/scenes/sN/shots/stN/prompt.txt；媒体导入该镜renders/，保留原文件名。完整key优先于参考资产key；截断、未知或有歧义的key留在下载目录并报告，不猜测。
不调用模型增写剧情；同一分镜与编译器版本产生相同结果。
上游未确定或版本变化时拒绝编译；只写本模块，不回写故事和分镜。
当前是内容编译 POC；参考资产绑定和实际视频制作按后续需求增加。
