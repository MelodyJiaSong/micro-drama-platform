# 六个问题与写场

故事就是：一个人物想做成一件事，撞上帮他或挡他的人和事；**他面对阻碍做了什么，就是故事**。主角可以不止一个（甚至十一个），但每个主角都要从头跟到尾，各自答一遍下面的问题。

## 六个问题

任何层级都适用：全剧、一季、一集、一段、一场；一幕、三幕、二十七幕都一样。

| # | 问题 | 要答出 | 不算 |
|---|---|---|---|
| 1 | 关于谁？ | 具体的人物（或几个） | 「一群人」「这个世界」 |
| 2 | 他想要什么？ | 具体、对他要紧的一件事 | 要不要都无所谓：箱子被偷了，再买一个就是，那不成戏；箱子里有要紧的东西才成戏 |
| 3 | 为什么得不到？ | 真实的阻碍：别人、处境，或者他自己心里（怕吵的人得把箱子送上火车） | 没有阻碍，一做就成——故事很短也很无聊 |
| 4 | 他怎么办？ | 看得见的行动 | 只是想、只是感受 |
| 5 | 为什么没成？ | 行动失败或付出代价，逼出下一个行动 | 一路顺利 |
| 6 | 最后怎样结束？ | 得到或得不到；**结局来自他从没试过的做法**——试过的话，故事早就结束了 | 靠运气，或别人替他做成 |

和[故事结构](story-structure.md)的对应：1 是主角，2 是目标，3 是对手与阻碍，4–5 是推进，6 是结尾。六个问题是把一个感觉或想法变成故事的最短路径；结构页给的是更细的部件。

## 接着追问

答完六个问题，继续问谁、什么、为什么、哪里，尤其多问几次「为什么」：他是个水管工？哪里人？为什么怕高？为什么偏偏爱这个人？每个具体答案都让你离一场戏更近。

## 用场来想，用问题推进

先写一个占位的场：「他回到家，很痛苦。」再问：**观众怎样看见他痛苦？**——他从冰箱里拿出晚饭，摔在墙上。看见了，再补两句台词，进下一场。

这就是影视改编「用可见动作、反应和对白表达故事」的来路；答不出「怎样看见」的，就是只在文字里成立的东西。

## 每个角色都以为自己是主角

旅馆前台也在做他自己的事：主角来开房，在他眼里是来添乱的或来套近乎的。两个各自想要东西的人撞在一起，就是戏的基本单位。写配角时先问「他这一刻想要什么」，再看他怎样帮或阻主角，见[角色类别](story-characters.md)。

## 场：一切都落在场里

电影、连续剧、几集的短剧，结构可以千差万别，不变的是**影视在场里运作**。每个进场的人都带着自己的目的；场末他得到了，或者受挫了，带着新的目的进下一场。没有落进某一场的事——某个话题、某种感受——就不会出现在片子里。

## 大纲：场的清单

大纲就是把故事拆成场的清单，是编剧的主要工作量，常比写正文还久；清单完整、每场发生什么都清楚，才开始写。

| 要点 | 做法 |
|---|---|
| 每场的标题写核心动作 | 用主动句：谁对谁做了什么。「汤米不公平地解雇了玛雅」，不是「玛雅被解雇」；也不是地点或流水账 |
| 标题下面写问题和答案 | 为什么？观众怎样看见？把能想到的都写下，台词也可以先写在这里 |
| 先知道结局 | 「倒着写」：不知道结局，就不知道故事关于什么；知道了，每一场才看得出是障碍还是台阶（见[故事结构](story-structure.md)「构思」） |
| 大纲给自己用 | 它是工作台，不是给人看的成品；要给别人看，另写一份 |

## 台词是行动

**台词最后写。** 先定这场关于谁、他在做什么；场里只有一个人在行动，另一个人只是坐着听，这场就还没写好——给主角一个行动：求情、要求申诉、解释、反咬一口。

人物说话是为了让某件事发生：要东西、改变关系、让对方做什么。**只为让观众知道信息的台词演不出来**——人物得自己需要说出这条信息。短是常态，但不是铁律：长段台词要值得，要么在制造悬念，要么在立人物的风格（《拜金一族》）。

## 每个选择都有代价

写作就是不断做选择：选这个，就失去那个；有的东西因此掉了，别的东西因此更强。「能不能两样都要」是唯一不能做的事。拿不准时也要选，顺着它走，不对再换。

## 两种写：创作与修整

每篇东西都要两种写，来回切换：

| | 做什么 | 要点 |
|---|---|---|
| 创作 | 不加评判地想、地写，先把东西拿出来 | 在知道要达成什么之前，没有坏点子（见[观众](story-audience.md)「求量」） |
| 修整 | 站在读者和观众那边，删、改、重排，把好的露出来 | 批评是为了让它更像它想成为的样子，不是把它改成别的，也不是否定它 |

## 结构理论是工具

三幕、转折点的位置、各种范式都是工具箱里的工具，没有一套总是对的；三幕的固定节点很大程度来自影院一场放多长的生意。观众不是在找「激励事件」，他们在乎人物。按这部剧要的效果挑工具，可以从几套里各取一样；拆解喜欢的作品（看到不再享受、开始机械地看为止）比背术语有用。

## 喜欢一个人物，先要知道他想要什么

观众跟得住一个人物，是因为知道他想要什么、为了什么——哪怕他要的是坏事。不知道他要什么，观众就不把他当人物看。这是[同情来源](story-sympathy.md)的底层。

## 意见要翻译成场

别人（包括用户）给的意见大多是「这里不对」「太慢」，不会告诉你怎么改；把意见翻译成具体哪几场怎么改，是写的人的工作。遇到「能不能两样都要」，摆出二选一和各自的代价，请对方选。

## 不写转场

故事稿和分镜不写「切到」「叠化」「淡出」：怎么从一场到下一场是剪辑的决定。只有转场本身承担意义、需要两镜预先配合时，才写进分镜，见[转场](edit-transitions.md)。

## 应该与不应该

| 应该 | 不应该 |
|---|---|
| 每集写故事前把六个问题答一遍，写进集级故事决策记录；一段或一场卡住时，就对它再问一遍 | 当成要填满的表格，答完就不再回头 |
| 多主角时每个主角各答一遍 | 只答主角，配角没有自己想要的东西 |
| 答案具体到能拍：看得见的人、物、动作 | 「他很孤独」这类只能写不能拍的答案 |
| 卡住时先写占位场，再用问题把它变具体 | 等想清楚了才动笔 |
| 每场标题是主动句的核心动作；每场主角都有行动 | 场里只有一方在动，另一方只是听着 |
| 人物需要说才说 | 为交代信息写台词 |
