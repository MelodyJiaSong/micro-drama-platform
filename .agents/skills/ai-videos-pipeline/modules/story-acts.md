# 三幕

把三幕看成主角先后进入的三个世界：每换一个世界，目标更具体，人也更成熟。三幕放在哪一层随片种不同，见[片种](story-formats.md)。

| | 第一幕 · 平常世界 | 第二幕 · 特殊世界 | 第三幕 · 即兴决战 |
|---|---|---|---|
| 处境 | 主角原本的生活 | 从没经历过的处境，常常生死攸关 | 计划已毁，只剩自己和学到的东西 |
| 目标 | 笼统（Shrek：赶走童话生物） | 具体（去龙堡救公主） | 与对手决出胜负 |
| 行动 | 激励事件后开始追笼统目标 | 订计划、找盟友；计划不断被打乱又补上 | 即兴应对，正面决战 |
| 内心 | 情感上的「青春期」：有心结，不敢冒险 | 被逼面对心结：中点先试、失败，后段终于克服 | 成熟：带着改变后的自己去决战 |
| 结束于 | 大转折一：瞬间击中主角，人生回不去 | 大转折二：全剧最大反转，最黑暗时刻 | 正面决胜，加短尾声展示新的平衡 |

中点在第二幕正中，常有不可回头、倒计时开始、真相揭开；主角第一次试着改变自己。

例：《借刀杀人》Max 开出租车十二年，总说要开豪车公司却不敢冒险（平常世界）；被杀手挟持后，不敢冒险成了活过今晚的最大障碍（特殊世界）；最后为了救人，正面对决杀手（第三幕）。

| 变化 | 处理 |
|---|---|
| 幕长 | 随类型伸缩：惊悚片要尽快开动，《借刀杀人》第一幕只有 19 分钟 |
| 正向大转折二 | 第二幕结尾主角反而赢了（约 5–10% 的片子），第三幕就要很短 |
| 高潮递进 | 每一幕都冲向一次比上一次更高的高潮 |
