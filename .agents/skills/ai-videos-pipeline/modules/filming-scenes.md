# 场

段落由场组成，场由[镜头](filming-shots.md)组成。一场是同一地点、连续时间里的一段戏；在分镜里是 `scenes[]` 的一项。

## 一场要定什么

| 字段 | 写什么 | 注意 |
|---|---|---|
| id | s1、s2 等稳定编号 | 重排不改号；播放顺序看数组顺序 |
| background | 环境资产 bg 编号，未选可留空 | 同一背景可多场复用；当场的时间、天气和状态写在本场 |
| location、time | 地点、时间 | 每个镜头编译时都会带上 |
| purpose | 本场的目标与变化；开头一句用主动句写核心动作：谁对谁做了什么（见[六个问题与写场](story-questions.md)「大纲」） | 一场结束时，至少有一样东西和开场时不同 |
| shots | 本场的镜头列表 | 一个镜头是一段连续画面，要切镜就拆成多个镜头 |

| 子页 | 回答的问题 |

## 通则

| 应该 | 不应该 |
|---|---|
| 先写清这场的目的，再分镜头 | 先想酷镜头，再找戏去装 |
| 进入新地点或时段变化时建立；同一场里不重复建立 | 每一镜都重新交代环境 |
| 同一场的镜头保持人物站位、方向、天气与光线连贯 | 镜头之间站位、天气、光乱跳 |
| 每一镜仍写全人物和环境：编译后每镜是独立的 prompt | 依赖上一镜，写「同上」 |
