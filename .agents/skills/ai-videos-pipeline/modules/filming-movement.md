# 运镜

运镜说的是镜头怎么动。目前收录跟拍；推、拉、摇、移等其他运镜以后补充。

## 跟拍是什么

| | 是 | 不是 |
|---|---|---|
| 跟拍 | 摄影机自己移动，跟着一个或多个移动的人物 | 机身原地摇、俯仰，哪怕跟着人转也不算 |
| 推拉跟 | 镜头在人物前方或身后，前后方向跟着走 | 不取决于用了什么器材 |
| 横移跟 | 镜头在人物侧面，左右平移跟着走 | — |

名字来自早年机器笨重时铺的轨道；今天轨道车、稳定器、肩扛、无人机都能拍跟拍。

## 怎样决定它的效果

| 变量 | 选择与效果 | 片例 |
|---|---|---|
| 运动质感 | 轨道：极平稳、精确，像钟表一样规整 | 《光荣之路》刻板的军官；《法兰西特派》跟着人物带出警局的运转 |
| | 稳定器：流畅如漂浮，能穿过人群 | 《好家伙》穿过科帕卡巴纳夜总会，一切毫不费力，正是主角的巅峰 |
| | 升降、航拍：能上下移动，一镜之内从一个人移到另一个人 | 《大玩家》开场用升降镜头交代整个片场 |
| | 手持：注入能量与粗粝的真实感，也能带来即兴感 | 《人类之子》的战斗像真实战地影像；《精疲力尽》的对话戏，摄影师坐在轮椅上被推着走，避免晃得分心 |
| 镜头焦距 | 长焦压缩空间，让混乱更紧张；广角夸大运动，更有冲击 | — |
| 景深 | 浅焦把人物和世界隔开；深焦把人放回环境 | — |
| 景别 | 特写跟拍：极强调人物 | 《索尔之子》从背后的特写，令人窒息；《塔尔》近景看清情绪的层层变化 |
| | 中景跟拍：移动的双人，让对话不呆板，即「边走边谈」 | 《低俗小说》边走边聊；《木兰花》在几个人之间穿行，带出后台的忙乱 |
| | 远景跟拍：强调人物穿过的环境、大场面 | 《007：幽灵党》亡灵节游行；《荒野猎人》混战里多层动作同时发生 |
| | 一镜之内变换景别 | 《历劫佳人》开场：特写定下炸弹的悬念，远景交代边境小镇，再推成中景引出主角 |
| 角度 | 顶拍跟拍：交代动作的地理，也显出压迫 | 《少数派报告》 |
| 镜头位置 | 在人物身后：悬念，观众预感拐角后有东西 | 《闪灵》 |
| | 在人物前方：身体的力量感 | 《社交网络》 |
| | 侧向横移：奇观感，观众站得更远地旁观 | — |
| 速度 | 快：能量与混乱；慢：紧张 | 《拯救大兵瑞恩》；《隐形人》 |
| 多人调度 | 用走动的人把视线带到下一组人（视线引导） | 《不羁夜》派对：跟着走动的人一段段转到新的对话，显得热闹 |
| 时长与剪辑 | 长：不切镜，跟着多条路线，观众始终认得清空间 | 《丁丁历险记》追逐 |
| | 短：一闪而过的快速跟拍，叠出爆发力 | 《碟中谍2》 |
| | 混合：在几个跟拍之间切，最后落在主角身上 | 《血色将至》 |

| | 应该 | 不应该 |
|---|---|---|
| 目的 | 先定要观众有什么感受，再选器材质感、景别和位置 | 只因为跟拍「高级」就用 |
| 长镜头 | 不切镜是为了让观众留在空间里、跟住多条线 | 为炫技而长；长到没有新信息 |
| 走位 | 人物和镜头的路线一起设计，谁带着视线走、走到哪停 | 镜头动了，人物却原地站着说话 |
| 手持 | 要能量、真实、即兴时用 | 晃到观众看不清，或在需要稳定的戏里用 |
| 位置 | 身后、前方、侧面各有含义，按需要选 | 不想清楚镜头在人物哪一边 |

## 写进分镜

- 运镜只写在 `camera`，不写进 `action`。
- 按「起幅景别 → 运镜（方向、在人物哪一侧、速度）→ 落幅景别」写，景别变化用连续的说法（「从全景缓缓跟到近景」）。一镜一个主运镜，最多再叠一个修饰（如手持的轻微晃动）。
- 器材写成画面质感：「像在轨道上一样平稳」「手持的轻微晃动」。
- 速度不用「快速」：生成模型遇到会画面变差。用结果表达速度：拖影、背景的运动模糊、主体保持清晰。
- 单镜生成时长有限，长跟拍要按拍点拆成几个镜头，或交给剪辑衔接。
- 生成时的运镜词与失败规避见 [Seedance 写法](prompts-seedance.md)「时间与运镜」。
