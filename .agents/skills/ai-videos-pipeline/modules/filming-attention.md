# 注意力引导

每一镜先定观众此刻该看哪里，再让画面和声音把眼睛带过去。切到插入或特写是一种办法；不切镜，靠取景、美术、光和声音也能在一镜之内引导或转移注意力。这些手段通常叠着用：同一画面里各项指向同一处，全组都知道该看哪，观众才会先看那里。

## 手段

| 类别 | 手段 | 规律 | 片例 |
|---|---|---|---|
| 构图 | 居中、三分法、黄金比例 | 主体放在画面中心、三分线交点或黄金比例点；背景里的窗格等线条能加强这个网格 | 《猎杀本·拉登》玛雅在左上三分点，身后窗格像三分网格；《巴里·林登》用其他人的站位撑起黄金比例，指向巴里的儿子 |
| 调度 | 视线汇聚 | 画内的人都看向谁，观众就看谁；人物换视线，注意力在同一镜内跟着转 | 《天国与地狱》靠画内人物改变视线，焦点从一人转到另一人 |
| 调度 | 远近与朝向 | 离镜头最近的通常最抢眼；反过来，其余人背对镜头、只有她受光时，最远的人也成焦点 | 《双峰》黛安最远，却是唯一朝向镜头、受光最多的 |
| 焦点 | 浅焦、移焦、移轴 | 在焦的人比占画面大的人更抢眼；移焦在一镜内换焦点，见[焦点与景深](filming-focus.md) | 《怒火救援》克雷西的头占大半画面，注意力却在合焦的丽莎 |
| 运镜 | 推、变焦、摇移 | 推近或变焦收窄范围，先交代空间再落到一个人；运镜还能把焦点换给另一人，见[运镜](filming-movement.md) | 阿尔特曼常用变焦；《第六感》长镜头里，摇移让焦点从马尔科姆换到安妮 |
| 美术 | 颜色对比 | 一片青里黄色跳出，一片灰里红色跳出；最常用的是服装 | 《35杯朗姆酒》去饱和环境里的红大衣；《好莱坞往事》莎朗·塔特的黄衣在彩色人群中分出来 |
| 美术 | 引导线 | 建筑边角、地砖、窗格的线条汇向主体 | 《正午》三个反派站在建筑与山的交汇点；《恩惠的种类》《分手的决心》的墙角、地砖 |
| 美术 | 框中框 | 门窗等把主体框起来；还能表达隔阂 | 《美国朋友》；《诺斯费拉图》叠加窗格的光线；《人工智能》框住大卫，也把他和父母隔开 |
| 光 | 最亮者优先 | 画面里最亮的主体最抓眼，哪怕离得更远；自然光、实景灯都行，实景灯不必打在人脸上，周围亮就够 | 《视差》侧光打在弗雷迪脸上，近处的人在阴影里；《Janet Planet》阳光；《Seconds》两人聚在台灯旁 |
| 光 | 方向性 | 光越硬、越有方向，指向越明确；漫射光只给出一群人和氛围，不点名某人 | 《秘密会议》顶部漫射光只交代密谈；《三峡好人》硬光毫无疑问地指向一处 |
| 光 | 色光对比 | 主体的光色与背景相反 | 《密西西比风情画》黄光人物对绿色背景；《都是陌生人》红光对蓝天 |
| 光 | 缺光 | 亮背景前的剪影；暗处的门洞让人好奇里面是什么 | 《Weapons》亚历克斯家漆黑的门洞 |
| 声音 | 最响者优先 | 混音里把某人推到前面，焦点就跟过去 | 阿尔特曼的重叠对白，按混音让注意力在人群里轮换 |
| 声音 | 放大细节、抽掉其余 | 把一个细节放大到压过一切；或抽掉主体以外的声音，把观众放进人物脑子里 | 《拆弹部队》呼吸声几乎和爆炸一样响，呼吸停下时最紧；《爵士春秋》只听得见细节，听不见旁人说话 |
| 声音 | 画外声 | 声音与音乐把注意力引到画外 | 《女巫布莱尔》先听见尖叫后看见画面；《利益区域》远处的枪声与喊叫；《大白鲨》主题一响就转向画外的危险 |
| 声音 | 故意打散 | 对白、音乐、音效一起压上来，制造混乱与压力 | 《私恋失调》 |

## 写进分镜

不另加字段，注意力落在已有字段里：

| 字段 | 写什么 |
|---|---|
| `blocking` | 画内的人看向谁；谁离镜头最近、谁朝向镜头 |
| `lighting` | 最亮处、硬光或色光落在谁身上 |
| `camera` | 构图位置、焦点给谁、推或摇到谁 |
| `dialogue` / 动作声 | 生成时保留的画外声与动作声；混音与配乐的取舍归[声音与音乐](sound.md) |
| 资产 | 服装、背景的颜色对比在人物卡与背景卡里定，见[资产](../resources/assets.md) |

## 应该与不应该

| 应该 | 不应该 |
|---|---|
| 每镜先说清「此刻看谁」，再选手段 | 手段堆了一堆，说不出这一镜要看谁 |
| 构图、视线、光、颜色、焦点指向同一处 | 互相抢：焦点在甲，最亮处和视线却在乙 |
| 要转移注意力时，用视线、移焦、运镜或光的变化带过去，不必都切镜 | 只会切插入或特写 |
| 需要混乱时有意打散，并说得出理由 | 画面乱成一片，却不是设计出来的 |
| 生成后对照画面核对：视线、最亮处、合焦的人真的在设计的位置 | 以为写进 prompt 就一定出现；Seedance 对移焦、黄金比例站位、指定最亮处的执行尚未验证 |

Prompt 禁止背景音乐，靠音乐引导注意力（如《大白鲨》）只能在声音与音乐模块做。出处：StudioBinder「Directing the Eye」，见 `.audit/adhoc_agents/2026-10-11/directing-attention/`。
