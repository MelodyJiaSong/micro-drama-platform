# 好场的构成

一场戏是「一个小的故事单位，由同一时间和空间统一，包含一个行动，并以一个变化收尾」，变化要同时落在故事和人物上（Jim Mercurio）。可以把一场当成一部短片：有自己的开头、中段、结尾，由几个拍点——情绪上的小转变——推着走。场的好坏先取决于下面四个要素，摄影、剪辑在它们之上加工。拍点按观众的心理排：关键兑现前留出让观众追上的停顿，见[观众](story-audience.md)。

## 冲突

人物有一个目标，有东西挡着他。

| 类型 | 是什么 | 片例 |
|---|---|---|
| 身体 | 打、追、从 A 到 B | — |
| 言语 | 双方的目标互相妨碍，不论他们自己是否意识到 | 《心灵捕手》威尔一句句挑衅，越过底线后爆发；随着争吵升温，镜头越来越紧，直到两人同框贴近 |
| 环境 | 处境本身挡路 | 《寄生虫》的暴雨水淹，也点出阶层冲突 |
| 内心 | 双方表面一致，各自心里在挣扎 | 《迷魂记》希区柯克停在斯科蒂身上、放慢节奏，连吻都苦涩 |

为冲突而冲突不够：冲突要服务整条故事线，还要有赌注——输了会怎样。《被解放的姜戈》餐桌戏紧张，是因为观众见过加尔文有多残忍，也知道主角走到这一步付出了多少。

## 人物发展

好场要么立住人物是谁，要么让人物改变。人物没有被这场戏影响，这场可能就可以删。

- 《好家伙》「我哪里好笑」：每个拍点清清楚楚，汤米在逗乐和凶狠之间摇摆，一场戏立住两个人；回头看，汤米的暴躁和亨利的讨好正是他们日后的结局。
- 《盗火线》咖啡馆：警匪两人讲出各自的过去，观众明白他们为什么是这样的人、为什么终局必然对决。
- 《海边的曼彻斯特》：两个人物的弧线在这一场交汇，一个想和解，一个还远没走出来。

## 情节功能

每场都要在整部片里起作用，推动更大的情节线。作用有大有小：

| 作用 | 是什么 | 片例 |
|---|---|---|
| 轻推 | 只把情节往前推一点 | 《花样年华》一个眼神，两人慢慢靠近 |
| 段落高潮 | 比一般场带来更大的变化，收一个段落（McKee） | 《一个明星的诞生》车外最后一句，她被打动 |
| 幕高潮 | 对情节有重大影响：揭秘、反转 | 《第六感》「我看见死人」；《星球大战：帝国反击战》「我是你父亲」 |

幕高潮常用其他手段加以强调：《搜索者》在激励事件处用高反差光和推镜。McKee 说转折点有四重效果：意外、好奇加深、领悟、新方向。

## 调度

按讲义的用法，走位（blocking）指演员怎样移动，调度（staging）指摄影机放在哪、怎样动。人物不动，也可以靠调度让画面有戏。

| 做法 | 片例 |
|---|---|
| 用高低位置表现权力转移 | 《公民凯恩》撒切尔先居高临下，凯恩坐起、镜头推近、最后站着俯视对方：争吵谁赢，看走位就知道 |
| 让前后景同时有戏 | 《总统班底》分屈光镜让伍德沃德和背景里各忙各的同事同时清楚，再推近到他的反应 |
| 长镜头里靠走位和机位转移注意力 | 斯皮尔伯格常用；《雨中曲》镜头大多保持远景，跟着舞蹈走，关键时刻推近表情 |

《沉默的羔羊》初见同时用了四个要素：冲突是她要情报、他要进她的脑子；两人都在这场里被立住、也都在变；情节上这是第一幕的高潮；调度上他让她「走近点」，她坐下、他站着，她被俯拍、他对着镜头说话，最后两人隔着玻璃同框，合作关系成立。

| 应该 | 不应该 |
|---|---|
| 每场写清：谁要什么、被什么挡、输了会怎样、结束时什么变了 | 一场里没有冲突也没有变化，只是交代信息 |
| 让这场在段落或幕里的作用清楚：轻推、段落高潮还是幕高潮 | 把大揭秘和日常过场拍得一样平 |
| 用走位与机位表现关系和权力的变化 | 人物从头站到尾、镜头一成不变，却说关系变了 |
| 每个在场的人都带着自己的目的；主角在场里有行动；台词是行动，人物需要说才说（见[六个问题与写场](story-questions.md)「台词是行动」） | 一方行动、一方只是听；为交代信息写台词 |

**本剧用法**：分镜每场的 `purpose` 写明冲突、赌注、本场的变化与它在段落里的作用；走位写进 `action`，机位与运动写进 `camera`。故事创作写场时同样适用。
