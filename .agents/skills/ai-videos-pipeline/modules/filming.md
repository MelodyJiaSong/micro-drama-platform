# 影视改编

输入：已确定的故事；剧 README 的全剧 Vision（每场目的与镜头取舍对照它，见[决策记录](decisions.md)「对照 Vision」）。输出：episodes/epNN/filming.json 的 scenes。
每场写 id（s1等稳定编号）、background（bg环境资产key，未选可留空）、location、time、purpose（本场目标与变化）及 shots。
每镜写 id（本场唯一的st1等稳定编号）、duration、cast（出场人物资产键，如 `c1-1`、`c14`）、action、blocking（站位、朝向、视线、移动；方向以镜头为参照：画左 / 画右、朝镜头 / 背对镜头、走向镜头 / 走向深处，东南西北只点名地标，follow-up 324）、beats（按秒分拍，区间连续）、camera、lighting（光源与性格）、dialogue，可选 props（入画的剧情道具资产键，如 `p475`；道具锚点图进参考行，follow-up 231）与 background（本镜朝另一方向、场的场景图视角不对时，写这一镜要用的环境视角 bg 编号；它的图与描写替换场的，follow-up 261），以及 allow_negatives（这一镜放开的剧级负面词，如施法镜的「夸张金光」，follow-up 282）；时长为正整数秒，写法见[Prompt 编译与出片](prompts.md)「分镜要给什么」（follow-up 227）。一个shot是一段连续画面；需要切镜时拆成多个shot。
同一background可由不同集/场次复用；当场时空和状态在scene/shot保存。scene/st编号创建后不因重排而改变，列表顺序决定播放顺序。
用可见动作、反应和对白表达故事，设计能拍清它们的摄影：对每个情绪或信息问「观众怎样看见」（见[六个问题](story-questions.md)「用场来想」）。不写「切到」「叠化」，只有承担意义、要两镜配合的转场才写，见[转场](edit-transitions.md)。
指定本镜实际对白，无对白时留空。Seedance保留自然环境声与动作声，禁止背景音乐/配乐；编译模块固定加入声音规则，配乐意图留给后期设计。
按拍摄单位从大到小设计：剧 workflow.json `format` 对应的[片种](filming-formats.md)页（电影的幕 / 连续剧的集）→ [场](filming-scenes.md) → [覆盖](filming-coverage.md) → [镜头](filming-shots.md)。
每场写场级决策记录、每集写集级决策记录，见[决策记录](decisions.md)。
覆盖规划（每场的覆盖档位、每个镜头是主镜头还是某个角度、覆盖哪些拍点或台词）待设计。
先按[场](filming-scenes.md)定每场的目的、环境与镜头覆盖（打斗、追逐、人兽的场先按[动作戏](filming-action.md)定完成条件、打法与结构）；选择镜头按[镜头](filming-shots.md)：功能、景别、取景、角度与高度、焦点各自回答一个问题；在camera内写清本镜需要的项（裁切范围、同框内容、机位、焦点），一镜一种运镜；不另加字段或自动附加QC。
不新增故事事实或改写动机、结果；需要改故事时向上游提出请求。
同一场里地点、人物相同、动作连续的几镜，可以提议合成一个**镜组**一起生成（场下 `groups`，见 [Prompt 编译与出片](prompts-generate.md)「镜组」；由用户确认分组，剧级先试，follow-up 331）；动作、特效多、单镜就容易失败的镜头仍一镜一条。

**镜组只用在连贯比剪辑选择更重要的地方**（chuanyue_yiri follow-up 032）：镜组条里的切点、顺序和每镜长短都由模型定死，组内切点前后没有余量，也不能单换某一镜（EP01 第 2 版 32 个成组镜头在剪辑里几乎原样照用）。所以：
- **可以成组**：连续的对白往来、一个动作的分解、同一空间里的跟拍，每组 2–3 镜。
- **一律单拍**：反应镜、空镜与环境 B-roll、进场镜与收尾镜、喜剧节奏点（要停一拍再切的笑点）、情绪转折的那一镜，以及有道具手部动作、容易出物理错误的镜头。
- 单拍的镜头用镜组板或场故事板里对应那一格画首帧图（`planning/{stN}_first_frame.png`），保住连贯，同时有完整余量、能单独重出。
- 每个镜组在 filming 决策记录里写一句为什么成组；写不出理由就单拍。剪辑发现组内切点不合适，回上游拆组重出，不硬接。

确认行为能被镜头看见，动作与对白能放进时间内。beats 里人物对刺激（喊声、看见的事）当即反应：听到、看到的那一拍就停步、回头，不在刺激和反应之间留无动作的空等（2026-10-18 用户指出：EP1 s3 st2 拍点写成「0–3 秒喊、3–6 秒回头」，亚伦喊完还站着三秒才回头）。两人对话、一人扶住或救助另一人时，beats 写明谁看着谁：说话的人看着听的人（指方向可以一偏头，说完马上转回来），听的人看着说话的人并有回应（点头、应声、表情）；不给交谈中的人设定望向远处或画外的视线（2026-10-18 用户指出：EP1 s3 st3 分镜让维里说话时「朝北一偏头」看修道院方向，出片里亚伦架起他时他全程望着远处，和亚伦没有眼神交流）。**画面里的人不定格**（用户 2026-11-10，chuanyue_yiri follow-up 054）：beats 里画面里的每个人每一秒都在做事，不写「一动不动」「愣住」「就那样盯着看」「僵在那里」超过 1 秒——故意的喜剧定格最多 1 秒、只用一次；**别人说话超过 3 秒时，听的人要有手上的活**（继续干自己的活计：摆面包、擦罐子、赶驴……），并把反应钉在台词的具体词上（说到哪个词时抬眼、嘴角一动、憋笑、摇头），不能只写「看着她」——模型拿到空白段就让人站成摆件（EP1 s3 st4：Riley 9 秒独白里 Felix 没写动作，出片像「傻子一样僵在那里」）。**一个梗最多两镜、反应不超过 1.5 秒，同一个梗全集只用一次**，再用必须是有变化的回收（EP1 s2：裤子梗拆成「盯着看—往下摇腿—挑眉—台词」四镜约 30 秒，s1 结尾又用了一次，用户说「很僵硬」）。`python tools/filming_lint.py <集目录>` 机检：「一动不动 / 愣住 / 盯着…不动」类词、台词超过 3 秒而同镜其他人物在这段没写动作。保存后由用户确定版本。

**给剪辑留出进出与余量**（2026-11-07 chuanyue_yiri EP1，用户：转场太 sharp、整体太快）：①每场有进场和收尾：开头一镜交代「到了哪里」（抵达、走进、地点远景或环境插入），结尾一镜让这场落地（人物走开、回望、反应停留、空镜），不从第一句台词开始、也不在最后一句台词上结束；②有对白的镜头，beats 在第一句前和最后一句后各留 1–1.5 秒只有动作、反应或环境、没人说话的余量，剪辑才能停一拍、做叠化和 J/L；③沉浸、旅行、纪录类内容给观众看的时间：环境、细节与当地人的反应单独成镜（插入、空镜），不只拍主角说话。镜头按台词时长卡着写，剪辑里就没法补出停顿与过渡。

**镜与镜接得上**（用户 2026-11-10，chuanyue_yiri follow-up 056）：相邻两镜的接点，上一镜最后一拍的样子（位置、朝向、视线、手里的东西、情绪和音量）就是下一镜第 0 秒的样子；接不上就要有切的理由（跳过时间、换地点、反应插入、主观镜头），体现在下一镜第 0 秒的画面描述里——只写这一镜看得见的状态，**不在正文里提别的镜头**（「接上一镜」「下一镜她…」「交给 st10」都不写：模型只看得到这一镜，提别的镜头只会让它困惑；接点关系靠首帧和 `junctions.md` 保证，follow-up 067，`filming_lint` 报 [跨镜]）。①**谁在拍**：camera 第一句写明视角来源——自拍（她手里）、跟拍 / 架着的相机、主观；同一刻里来源切换，尤其她正对着一台相机说话、下一镜换成另一台时，要在画面里交代（拿起、放下、架好、递给），或符合本剧 bible 的视角约定。②**台词接着说**：同一个人跨镜头接着说话，下一镜第一句接住上一镜最后一句的情绪、音量和处境——不重新打招呼、不重复刚说过的地点和名字；情绪要换挡（小声惊叹 → 欢快开场）就给一句话或一个动作把它转过来，有意的重开要让人物说出来（EP1 s1 st1→st2：他拍全景里背身回望城门、低声说「That's Pompeii up there」，下一镜直接是自拍里欢快的「Good morning from Pompeii!」，用户说画面和台词都不搭；改成 st1 结尾她边说「Wait, wait — I gotta do this right.」边走向架着的相机、伸手拿起）。③写完一场，按接点把「上一镜最后一拍＋最后一句」和「下一镜第 0 秒＋第一句」连起来读一遍。`python tools/shot_junctions.py <集目录> [--scene sN] [--out junctions.md]` 列出全部接点并机检：⚠ 重新打招呼、重复专名、情绪跳变没交代（计入退出码），ℹ 视角来源切换没交代（按本剧视角约定判）。审查单的 `materials/junctions.md` 就是这张表。

**每镜写看点，画得出来，按真实速度演**（用户 2026-11-10，chuanyue_yiri follow-up 058）：①每镜加 `point` 字段，一句话写这一镜要观众看懂或感到什么（只给审查用，不进 prompt），并想清楚**画面里靠什么让人看懂**——关掉声音、没读过分镜的人也能说出来；靠台词点明的，台词要在本镜或紧接的下一镜。②撑起看点的东西写成看得见的具体样子，并且首帧里就要有：不写「一道浅浅的水」，写「满街一层浑浊的水从坡上往下流，漫过整条路面、在垫脚石边上分开，只有石头顶面露出来是干的」。③动作按真实速度写时长：迈一步约 0.5 秒、跨三块垫脚石约 2 秒；镜头比动作长时加别的内容（停下看、回头、环境），不把动作拉慢——拍点给得越宽，模型演得越慢。④效果要有来源：水花、溅泥、扬尘、影子、反光只出现在有来源的地方（踩在干的石头顶面不会溅水）。（EP1 s2 st1：要讲「庞贝的街就是排水沟，垫脚石让人脚不沾水」，分镜只写了一道浅水，首帧和成片都只是湿路面；她慢吞吞地走，踩在干石头上却溅起水花；出片审核写了「Vision：给出了」放行。用户：「我不清楚你想表达的 point 是什么」。）`python tools/filming_lint.py <集目录>` 报缺看点的镜头。

**动机来自人物，反应要克制，跨语言要说清**（用户 2026-11-14，chuanyue_yiri follow-up 062：EP1 s3 面包师被问路时「头也不抬、没有任何手势」——为让她猜不出方向硬写的，看着很走戏；她只问一个词「Garum?」，对方和观众都不知道她要什么；最后单独一镜面包师张嘴吸气想喊、摇头笑出声，表情很傻）：①**动机来自人物，不来自情节**：情节需要误会、迷路、错过时，先问「抛开剧情，这个人此刻为什么这么做」——被客人问话的面包师会抬头、会顺手一指；要让她猜错，就从人物身上找原因（手上端着满托板只能用下巴朝街上一努、指的方向含糊、她把手势看反了），不写「头也不抬、没有任何手势」这种只为情节成立的举动。②**反应要克制、合比例**：配角的反应写动作、写强度（「嘴角微微一动」「轻轻摇一下头」），不写大表情（张大嘴、张嘴吸气、瞪大眼、鼓起腮帮、笑出声）——视频模型会把写下的表情再放大一倍；一个反应能放在主镜里就不单独给一整镜，反应镜头要先过故事点清单的「抓人」一关，可有可无的删掉。「人不定格」要的是手上有活，不是脸上加戏。③**跨语言要说清**：Riley 对听不懂英语的人说话，要让对方和观众都看懂她要什么——说完整意图（「Garum? Where can I get garum?」）并配手势（指街上、比划吃、举起东西），对方的回答也要配动作，让观众看懂意思（朝哪边一指、摇头、点头）；只有一个词又没有手势的问句会让整段戏糊掉。`python tools/filming_lint.py <集目录>` 报 [动机]（对话里写了避而不看）、[过演]（配角的大表情）、[跨语言]（没有手势的一个词问句）。

**每个角色自己走一遍**（用户 2026-11-14，chuanyue_yiri follow-up 063：每一个动作、表情、语言都要站在角色的立场上审，贯穿全片）：一场写完，按出场的人逐个换位——「我是 Riley / 我是面包师 / 我是门口的路人」——按镜头顺序把这个人出现的每一拍过一遍：我面对的是谁、他懂不懂我的话、我此刻知道什么想要什么；我会怎么说（措辞、长短、语种、音量）、手和身体怎么动、什么表情多大、看谁、对方说话做动作时我怎么回应、多快。和分镜写的不一样就改分镜，不替人物找「剧情需要」的理由。拿不准一个人此刻会怎么说、怎么做时，用[人物即兴](../../ai-videos-character-sim/SKILL.md)让他在这个处境里自己开口。审查时每个有卡人物各有一位「角色立场」审稿人（review_roster `role`，V1–V6，材料 `materials/roles/<人物>.md`），出片后的表演审核也按出场人物每人一位审稿人代入。**跨集一致**（用户 2026-11-14，follow-up 064）：每个有卡人物的目录下有一份行为档案 `behavior.md`（说话方式、口头禅、对陌生人的态度、肢体习惯、表情分寸、不会做的事，每条带集与镜头编号）；角色立场审稿人拿它和「前几集的你」（`materials/roles/<人物>.md` 自动附上前几集他出现的每一镜）对照这一集（V7），审完把这一集新立住的行为写进「行为档案增补」，审查收轮后并进 `behavior.md`。

**镜头跟着台词，不让台词迁就镜头**（2026-11-08 用户）：语速保持正常（自然口语语速，约每秒 2.5 词，不为塞进镜头而说快）；台词按自然语速念完需要多久，镜长和节拍就给多久（再加前后余量）；审稿报「说不完」「语速超了」时，修法是延长镜头（到 30 秒上限）、加镜头、加场、重写镜头或整场、重排节拍——哪种都可以，按戏需要选；不删词、不改短句子，也不把一句话拆成碎句来凑时长。
