# 角度与高度

景别和取景决定看什么，角度决定观众怎么看他。机位高度与角度常常重合：膝高、地面机位只要往上仰，就同时是仰拍。

| 角度 / 高度 | 是什么 | 用来 | 片例 |
|---|---|---|---|
| 仰拍 | 机位低于主体视线，向上看 | 让主体显得强大，英雄反派皆可；程度可轻可重；非人主体同样有效 | 《狮子王》刀疤的仰拍让色彩、烟雾、暗与表情合成十足的反派感；《2001太空漫游》 |
| 俯拍 | 机位高于主体，向下看 | 让主体显得弱小、脆弱；常与仰拍同场配对，放大力量不平衡 | 《复仇者联盟》用极端俯拍，让巨大的威胁把英雄们比小 |
| 航拍 | 极端的俯拍 | 建立城市、地貌；表现人物穿行于更大的世界 | — |
| 顶拍（鸟瞰、上帝视角） | 机位在正上方，垂直向下 | 展示复杂的走位；暗示神性；冷静呈现现场 | 《大师》弗雷迪躺在船上众人之上，没有上下文，只见一个与一切脱节的人 |
| 倾斜（荷兰角） | 让画面水平线歪斜 | 不安、癫狂、恐惧、困惑；放大张力 | 《为所应为》种族冲突升温，倾斜也越来越大 |
| 眼平 | 与主体眼睛同高 | 最自然、最常用；不对人物下判断；照样可以很有力 | 《华尔街之狼》乔丹对镜头独白，眼平加打破第四面墙，让观众立刻与他和他的骗局建立联系 |
| 肩高 | 略低于眼睛 | 有一点仰的效果而不带分量；对话、过肩最常用；拉开身高即拉开权力；恋爱中略上扬的视线更显深情 | 《西部世界》的过肩戏用机位连接或分开人物 |
| 髋高 | 机位在腰胯高度 | 西部片的家：枪套就在这个高度，常和牛仔景别一起用 | 《黄金三镖客》在髋高的枪套镜头与眼平大特写之间来回切，又紧张又刺激 |
| 膝高 | 机位在膝盖高度 | 跟拍人物穿过环境；展示远景里会漏掉的细节；常兼作仰拍 | 《阿甘正传》「Run, Forrest, Run」的膝高镜头，让观众坐在第一排看他的胜利 |
| 地面 | 机位贴地，甚至略低于地面 | 有型地跟拍移动；捕捉场景里的细节；稍一上仰就是仰拍 | 《闪灵》跟着丹尼三轮车的长镜头，地毯花纹与声音让人着迷又发毛 |

| | 应该 | 不应该 |
|---|---|---|
| 仰 / 俯 | 用来标出这一刻的力量关系，并能说出谁强谁弱 | 当作默认的「帅」或「惨」；整场无变化地一直仰或一直俯 |
| 顶拍 | 走位或现场的整体形状本身有意义时用 | 只为奇观，却让观众看不清人物 |
| 倾斜 | 跟着情绪或张力逐步加重 | 当成装饰随手歪；在平静的戏里用 |
| 眼平 / 肩高 | 作为对话与日常的基准，衬出其他角度的变化 | 以为中性就等于平淡 |
| 髋高 / 膝高 / 地面 | 用来跟随动作、突出腰下或地面的细节 | 机位低却没有要看的东西 |
