# 景别

景别说的是主体在画面里有多大、身体截到哪里。中文叫法各体系不一，分镜写明具体裁切边界（如「膝上」「胸口至头顶」）消除歧义。

| 景别 | 是什么 | 用来 | 不是 / 省略 | 片例 |
|---|---|---|---|---|
| 远景 WS | 主体离镜头远，人和环境一起看 | 人与环境的尺度：迷失、孤独、被压倒；用距离、纵深、大小表态 | 不是建立镜头（建立管地点，远景管主体的尺度）；看不清表情 | 《魅影缝匠》结尾不切特写，用远景让两人在凌乱舞厅里相伴而与世隔绝 |
| 全景 FS | 从头到脚撑满画面上下 | 身体、姿态、服装；把人物完整地亮出来 | 不要求居中（虽然常居中）；脸的细节较弱 | — |
| 中全景 / 牛仔 | 头顶到腰下，得名于枪套的高度 | 自信、危险、对峙，尤其要拔武器时 | 不是西部片专用；不自动带来威胁；腿脚不完整 | 《宠儿》中萨拉夫人的牛仔镜头强硬、对抗 |
| 中景 MS | 腰上胸下截起，至头顶 | 中性、像日常交往的距离；兼顾表情、手势、道具和部分环境 | 不戏剧化也不疏远；不给全身 | 《寻梦环游记》米格看偶像的电影，中景同时装下神龛道具、电视画面和他的反应 |
| 近景 MCU | 胸口中段至头顶 | 减少干扰，突出人物与情节细节；亲近又不丢身体 | 不保证手在画内；环境和距离基本省略 | 《复仇者联盟4》近景里有手套，也有灭霸得意、再到失败的反应 |
| 特写 CU | 脸占主导，多为眼平 | 最强的情绪工具：变化、抉择、焦虑；让观众共情 | 不是每句重要台词都要特写；空间和身体被压缩 | — |
| 大特写 ECU | 隔离一个局部：眼、嘴、耳，最常是眼睛 | 最亲密、最戏剧、也最可能吓人的强调 | 不保留完整的脸、身体和空间 | 《杀死比尔》新娘被围时，在敌人来路与她慌乱的眼睛之间来回切 |

| | 应该 | 不应该 |
|---|---|---|
| 远景 | 确认动作在画面里仍可辨认 | 让观众靠看不清的脸猜关键情绪 |
| 全景 | 身体、走位、造型有叙事价值时用 | 把关键的脚部动作裁掉 |
| 牛仔 | 表情、手、武器同框 | 写了拔武器却把手和腰裁到画外 |
| 中景 | 需要人和物兼顾时作为自然距离 | 所有拍点都用中景，强调失去变化 |
| 近景 | 核对脸与关键动作能否同时读清 | 默认胸口以上一定有手 |
| 特写 | 留给值得强调的情绪转变或反应 | 用特写代替还没建立的行动关系；反复给没有变化的脸 |
| 大特写 | 让观众知道这个局部在哪、属于谁 | 塞进全身动作或多人站位 |
