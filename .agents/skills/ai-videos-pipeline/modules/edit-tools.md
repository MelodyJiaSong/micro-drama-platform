# AI 剪辑工具现状

调研于 2026-10-09，来源多为厂商发布与自媒体实测，独立评测很少；工具变化快，用前以官方说明为准。只记录能力，**登记不等于采用**：采用前核对商用条款，收费服务按[外部服务](../../../references/project/paid_services.md)走审计。

**总体**：机器已经能可靠地做「理解素材、组装第一版、包装」（转写、检索、按剧本拼时间线、字幕、混音）；选哪条、节奏、钩子位置、锁片仍是人做。国内 AI 短剧后期的主要成本在抽卡与修穿帮，不在剪辑软件。

## 按步骤

| 步骤 | 工具 | 自动化了什么 | 局限 |
|---|---|---|---|
| 选条 | Premiere Media Intelligence、Resolve IntelliSearch | 按画面内容、台词用自然语言搜素材 | 只是检索；没有找到独立评测 |
| 选条 | Cutback Selects、Eddie AI | 转写、去静音和坏条，出初排序列 | 厂商自述只覆盖剪辑之前 |
| 粗剪 | Resolve IntelliScript | 剧本与转写对齐，自动拼时间线，多条叠放 | 测试版反馈采用率低、调序段落丢失；无对白镜头基本无效 |
| 粗剪 | Adobe Firefly Quick Cut（测试版） | 按剧本或分镜表出可编辑时间线 | 不能导入 Premiere |
| 粗剪 | 剪映 Hub、火山剧创 | 剧本、生成、时间线在同一处 | 调位置不准、不能批量；节奏未证明可发布 |
| 粗剪 | Descript | 以文字稿为编辑面 | 适合口播，不适合电影化内容 |
| 精剪 / 修补 | Premiere Generative Extend | 镜头首尾各补约 2 秒画面 | 对白与音乐不延长；扣积分 |
| 精剪 / 修补 | Seedance、Kling、Runway Aleph | 延长、文字局部重绘（去路人、换光、换装） | 都是收费生成，单次几秒到十几秒 |
| 精剪 / 修补 | Premiere AI Object Mask、Resolve Magic Mask | 一键选物并跟踪，用于局部调色或打码 | — |
| 声音与字幕 | Resolve AI Audio Assistant、IntelliCut、Animated Subtitles；剪映 AI 字幕与卡点 | 自动混音、删静音、逐字字幕、按节拍卡点 | 属下游模块；剪映功能只见第三方教程 |
| 锁片 / 批处理 | Resolve 21.1 Studio 内置 MCP | Claude、Codex 等用自然语言整理媒体、批量渲染、按规则删短片段 | 能否从零搭时间线报道未说清 |
| 横转竖 | Smart Reframe、Auto Reframe | 自动跟主体改画幅 | 本剧原生 9:16，用处不大 |

## 对本剧的启示

| 做法 | 理由 |
|---|---|
| 先音后画：对白时长当主轴 | 配音与原生人声时长确定，适合自动排画面 |
| 剪辑决定留在仓库里的文本 | NLE 与一体化产品只当执行器或精修环境；需要时经 OpenTimelineIO 往返 |
| 生成与剪辑一体化产品只作参考 | 省导入导出，但节奏质量没有证据 |
| 多机位自动切换（Multicam SmartSwitch）不适用 | 本剧每个机位是独立生成的单条，不是同步多机位 |
