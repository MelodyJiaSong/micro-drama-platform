# 覆盖

覆盖在[场](filming-scenes.md)与[镜头](filming-shots.md)之间：一场戏决定拍哪些镜头、多少个，每个镜头本身怎么拍见镜头页。

## 怎样用镜头覆盖一场

| 做法 | 是什么 | 片例 |
|---|---|---|
| 先建立，再主镜头 | 建立镜头交代地点与时段，主镜头交代谁在场、彼此在哪；剪辑随时能切回整体 | 《教父2》餐桌戏，大半在主镜头里演 |
| 让空间说话 | 关系变了，画面里人与人之间的空间跟着变 | 《教父2》迈克尔说出参军后，他周围空了出来 |
| 取景随关系推进 | 单人、双人、过肩、群像的变化，推动这场戏的关系 | 《寄生虫》后院一段，用取景把一家人连在一起 |
| 跟着走动转场 | 一镜之内跟着走动的人，从一组对话转到下一组 | 《不羁夜》派对 |
| 多线交替，最后落点 | 一场里几条行动线交替推进，最后落在主角身上 | 《血色将至》油井一场 |
| 不切镜保住方位 | 复杂行动用连续跟拍，观众始终认得清空间 | 《丁丁历险记》追逐 |

## 覆盖多少

覆盖（coverage）是为一场戏拍下的全部镜头，剪辑用它们拼出成片。它和剪辑分不开：问的是「剪辑能用多少种方式把这场拼出来」。例：《惊爆点》的一场对话本可以用一个双人镜头拍完，导演又补了双方的过肩近景和特写，好在剪辑时控制对话节奏、在关键拍点推近。要多少覆盖，取决于戏的复杂度（追车几乎总要多个机位，静坐对话未必），也取决于时间和预算——每多一个机位都要花时间。

| 覆盖程度 | 是什么 | 用来 / 代价 | 片例 |
|---|---|---|---|
| 无画面 | 画面全黑，只有声音 | 让观众「注意听」；把画面留给想象 | 《利益区域》从黑场开始，先听见；《猎杀本·拉登》开场只有 9·11 的声音 |
| 固定单镜 | 一个不动的镜头拍完整场 | 剪辑无从下手，全靠构图与走位；让观众感到时间流逝，可能显得疏离、克制 | 罗伊·安德森《二楼传来的歌声》每场一个固定镜头，深焦里人物往远处走；香特尔·阿克曼《让娜·迪尔曼》 |
| 动态单镜 | 一个移动的镜头拍完整场，镜头自己在「剪辑」 | 有单镜的连续张力，又有多机位的错觉；做错就得整条重来 | 《塔尔》镜头跟着莉迪娅在教室里绕，像鲨鱼绕着猎物 |
| 最少覆盖 | 只多拍够用的几个镜头，不按常规角度补齐 | 经济，留一点剪辑余地，注意力留在表演上 | 侯麦《绿光》双人镜头里聊，偶尔切到太阳；伯格曼《假面》只用两人的特写 |
| 标准覆盖 | 先拍主镜头（多为远景，交代空间与人物），再给每人中景、每人特写 | 剪辑选择多，又不浪费；尤其适合对白戏，随戏剧化一步步靠近 | 《社交网络》；《愤怒的公牛》一个远景、两个中景、两个特写，火药味全在台词和表演里 |
| 额外覆盖 | 远超「够用」，收集大量角度 | 动作戏里多人多线需要切换；也能剪出频闪般的能量，或用细微的角度变化给新信息 | 《疯狂的麦克斯：狂暴之路》；《挑战星期天》；《十二宫》审讯戏切了十几个机位 |

同一场两人对话，覆盖不同，感觉完全不同：《黑客帝国》开场只闻其声，神秘；《爱在黎明破晓前》一个固定镜头拍完一段长对话，重点在两人的关系；《第六感》镜头随走位在两人之间移动；《大师》只用一个建立镜头和两个特写，亲密到喘不过气；《愤怒的公牛》标准覆盖，不靠运镜；斯派克·李《至高至低》用多角度额外覆盖，配合又抒情又对抗的对白。

| 应该 | 不应该 |
|---|---|
| 先想清楚剪辑需要哪些选择，再定拍几个镜头 | 把覆盖当作替代决定的手段：多拍不等于剪得更好 |
| 每个镜头都有目的 | 拍一堆用不上的镜头 |
| 单镜时用走位、深焦或运镜让画面保持变化 | 一个固定镜头里什么都不变 |

**本剧用法**：每个镜头都是一次收费生成，覆盖越多，花费和时间越多；同一场的几个机位是分开生成的，表演与光线难以严丝合缝，标准覆盖的「正反打」要在分镜里写清两边一致的站位、视线与光。单镜生成时长有限，长的单镜覆盖要按拍点拆开。
