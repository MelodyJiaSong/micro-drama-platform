# 剪辑

状态：设计稿，最小部分试行中（见下「试行实现」）。方法与规则已按调研整理（出处见审计 `.audit/adhoc_agents/2026-10-09/edit-module/`）。

| | |
|---|---|
| 输入 | Prompt 编译与出片生成的各镜头的条（renders/）；已确定的分镜与对白 |
| 输出 | 锁定的剪辑决定（时间线）与锁片版本；锁片后才开始声音与音乐、成片交付 |
| 上游关系 | 缺镜头（反应、插入、补角度）或条全不可用时开单退回影视改编、Prompt 编译与出片，不在剪辑里改故事和分镜 |

## 四步

| 步骤 | 定什么 | 机器做 | 人做 |
|---|---|---|---|
| [选条](edit-selects.md) | 每镜用哪条、可用区间 | 标注、硬门淘汰、软分排序、标出疑点帧 | 从前几名里定条；判表演 |
| [粗剪](edit-assembly.md) | 镜头取舍与顺序，场戏是否成立 | 按分镜顺序、按对白时长拼出第一版时间线 | 看结构；开缺镜单 |
| [精剪](edit-fine.md) | 逐帧切点、对白节奏、反应与 J/L | 只在合法切点里挑；按规则打分、标违例 | 判动机、情绪与节奏 |
| [锁片](edit-lock.md) | 冻结切点与镜头增删 | 回读质检、算指纹 | 独立审稿；用户批准 |

AI 素材特有的坏帧、身份漂移、跨镜色差与接缝，见 [AI 素材的修补与遮掩](edit-ai-footage.md)；各家 AI 剪辑工具能做到哪一步，见 [AI 剪辑工具现状](edit-tools.md)；场与场之间用哪种转场，见[转场](edit-transitions.md)。

## 原则

| 应该 | 不应该 |
|---|---|
| 选条、取舍与节奏都对照全剧 Vision；审稿第一问是成片是否满足它 | 只按技术指标剪，片子顺了却不是 Vision 要的体验 |
| 剪辑决定存成文本数据（进 git），每条带理由、依据与素材指纹；渲染只照它出 | 以 GUI 剪辑软件里的工程为出处，改了说不清改了什么 |
| 代理只在有限的操作菜单里决策，像素处理交给确定性工具 | 让模型自由发挥「加个转场」「补一段画面」 |
| 机器做能量化的（时长、切点离词、色差、身份距离），人判动机、情绪、钩子 | 拿模型打分当通过门 |
| 不够用就开单退回上游 | 在剪辑里改台词、改分镜、私下补生成 |

## 边界

- 延长、局部重绘、重生成都是收费生成：走[出片](prompts-generate.md)，由用户决定，先记请求日志（见[外部服务](../../../references/project/paid_services.md)）；只用条款允许商业用途的工具和模型。
- 锁片要用户批准；审稿要独立上下文，作者自审不算通过。

## 草稿剪辑与正片剪辑

两种剪辑分开做、分开放，不混用条：

| | 草稿剪辑 | 正片剪辑 |
|---|---|---|
| 用的条 | 各镜 `drafts/` 的 480p 草稿条 | 各镜 `renders/` 的 720p 正式条（草稿经用户「通过」后才出） |
| 用来 | 看结构、节奏、缺哪些镜头；发现的问题开单退回影视改编 / 出片 | 从粗剪一路剪到锁片，交给声音与音乐 |
| 缺镜 | 可以用写着分镜与台词的黑卡占位 | 不留占位；缺镜先补出正式条 |
| 锁片 | 不锁 | 锁片要用户批准 |

草稿剪辑定下的入出点与 J/L 只是参考：正式条是重新生成的，表演和时间会变，正片剪辑要按正式条重新标注、重新定切点。

## 试行实现

用户 2026-10-17 要求先把 EP1 s3、s4 的草稿剪出来（魔兽世界 follow-up 061），先实现了最小部分，数据格式随模块设计再定：

| 内容 | 位置 |
|---|---|
| 剪辑决定 | `{集}/scenes/{场}/edit/{draft\|final}/cut_v{N}.json`：stage（draft / final，须与目录一致）、phase（初接 / 粗剪 / 精剪 / 锁片）、version 与 base_version、status、events（条、sha256、入出点对齐到帧、可选声音区间做 J/L、理由、notes；缺镜占位）、有意违例、output（回读结果） |
| 标注 | 每条目录里的 `annotation.json`：逐词台词时间（faster-whisper，不喂剧本）、内切、冻帧、黑帧 |
| 工具 | `tools/scene_cut.py annotate / check / render`：check 查条 sha、入出点、切点离词、相邻台词相撞、内切与镜长；render 画面与声音分开铺，出干净版与标注版，回读时长、帧数与黑段 |
| 成片 | 同目录 `{场}_{draft\|final}_v{N}.mp4` 与 `_标注` 版（不进 git） |
| 集级与转场 | `{集}/edit/{draft\|final}/cut_v{N}.json`：接哪几版场剪辑（绑成片 sha）、每对相邻场的转场（菜单、时长、J/L、理由）、片头片尾；`tools/episode_cut.py menu / check / join / gallery`：gallery 在两场交界把菜单里每种转场各出一段带名字的样片，接成 `转场样片_{场}_{场}.mp4` 供挑选；join 回读并与应有切点对账（ai_video_management follow-up 277） |
| 界面 | 管理 UI「5_剪辑 → EP → 场次」：草稿剪辑 / 正片剪辑两个 tab，按版本看成片与时间线（ai_video_management follow-up 269） |
