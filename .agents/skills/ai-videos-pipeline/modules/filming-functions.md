# 功能镜头

功能说的是这一镜在叙事里做什么，和景别是两回事：同一镜可以既是远景又是建立镜头，插入镜头常用大特写，但「插入」说用途，「大特写」说大小。

| 类型 | 是什么 | 用来 | 不是 | 片例 |
|---|---|---|---|---|
| 建立镜头 | 介绍地点、时段、环境或世界条件的镜头，通常足够宽 | 场景开头定位；转到新地点；介绍陌生的世界 | 不是拍得宽就算建立；不负责交代人物关系 | 《银翼杀手2049》开场一串建立镜头，先给近未来地球城外的工业农场 |
| 主镜头 | 覆盖整场戏、交代谁在场、彼此在哪的镜头 | 看清人物位置与关系；给剪辑一个随时能切回的整体 | 不只是开场的一张群像；看不清微表情和小道具 | 《教父2》餐桌戏大半在主镜头里演，强调一家人亲密；迈克尔说出参军后，画面里他周围空了出来 |
| 插入镜头 | 单独拿出一个对叙事关键的物件或细节 | 强调线索、道具的功能、操作的结果 | 不只是「拍得很近」——信息怎么摆比占多大更重要；也不自动交代细节属于谁 | 可与主观镜头结合：第一人称看、第三人称看，或两者兼有 |

| | 应该 | 不应该 |
|---|---|---|
| 建立镜头 | 给后面行动需要的位置、时段或世界条件；第一次抵达一个有官方名字的地点时，在集级分镜记录「地点字幕」节登记地名、出现的镜头与时机（成片时叠加，见[成片交付](delivery.md)） | 只拍一张风景；已经清楚的地方反复重建；把地名写进 prompt 让模型画字 |
| 主镜头 | 让关键人物和关系一眼可读；用空间变化表达关系变化 | 人物互相遮挡还当作关系已交代 |
| 插入镜头 | 前后镜交代细节归谁、为什么出现、带来什么结果 | 为装饰插入无关物件；用插入掩盖动作原因或空间的缺失 |
