# 取景

景别定了大小，取景决定画面里放谁、怎么摆。任何取景都能和任何景别组合：单人可以是特写，也可以是远景。

| 取景 | 是什么 | 用来 | 不是 |
|---|---|---|---|
| 干净单人 | 画面里只有一个角色，别人一点也不露 | 突出这个人；表达孤立 | 不等于特写 |
| 脏单人 | 主体之外，露出另一人的一小部分（肩、后脑） | 突出一人，同时提醒对方在场 | 不是双人：被露的人不是焦点 |
| 双人 | 两人都在画内，两张脸都看得清 | 建立两人的关系：亲密、对立，甚至想象中的 | 朝向不限；看不清两张脸就不算 |
| 三人、四人……群像 | 人更多时依次叫三人、四人；再多就叫群像 | 同框即关系，人越多越是一群人的关系 | 不必逐个数到底 |
| 过肩 OTS | 从一人肩后看另一人；介于单人和双人之间 | 对话最常用；两边各一个反打，让观众觉得身在其中 | 焦点通常只在一人 |
| 主观 POV | 用某个角色的眼睛看：人、动物、摄影机、鬼魂、鲨鱼都可以 | 让观众体验他的视角；常配主观声音，看他所见、听他所闻 | 不是越晃越主观 |
| 插入 | 关键物件或细节的取景，见[功能镜头](filming-functions.md) | 信息怎么摆，比在画面里占多大更重要 | 可第一人称、第三人称或兼有 |

片例：《寄生虫》金家在朴家后院的一段，用超宽四人、倒酒插入、中景四人、过肩、脏单人、脏双人、摇镜从双人到三人、干净单人，最后回到宽四人——用取景把一家人在身体和观念上连在一起。

| | 应该 | 不应该 |
|---|---|---|
| 单人 | 想突出或孤立一个人时选干净；想保留对方存在时选脏 | 对话中一直干净单人，让人物像在对空气说话 |
| 双人 / 多人 | 先想清楚这一镜要建立什么关系 | 只因人多就全塞进来 |
| 过肩 | 两边反打的机位与轴线一致 | 前景的肩挡住主体的脸或关键动作 |
| 主观 | 视角主人明确；配合他能听到的声音 | 交代不清是谁在看 |
| 一场戏整体 | 想好这场要达成什么，再用取景的变化推着走 | 取景变来变去，却没有对应关系的变化 |
