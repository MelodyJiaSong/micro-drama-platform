# 同情来源

底层是观众知道他想要什么、为了什么，哪怕要的是坏事（见[六个问题与写场](story-questions.md)）。开场就让观众在乎主角：用行为和处境呈现，不靠旁白宣称。作者建议用到 6 种以上，越早越好；主角可以有缺点，但长处要多于短处。

| 来源 | 含义 | 写法 |
|---|---|---|
| 勇气 | 有胆量面对危险 | 压力来时主动迎上去，而不是被推着走 |
| 受不公 | 遭到不公平对待，因而被迫行动 | 让观众看清这份不公，再看他怎么反应 |
| 技能 | 无论做什么，都是行家 | 司机也要是最守时、车最干净的那一个 |
| 风趣 | 能让人笑的人更容易被喜欢 | 幽默来自性格与处境，不靠插科打诨 |
| 善良 | 心地好 | 一个对弱者的小善举就够 |
| 身处险境 | 迫近的伤害或损失 | 危险要具体、可见，就在眼前 |
| 被爱 | 已被亲友爱着 | 别人的关心让观众也获准在乎他 |
| 勤奋 | 肯下苦功 | 勤奋的人自带推动故事的能量 |
| 执着 | 一心追一个目标 | 把勇气、技能和勤奋都聚焦在一件事上 |

| 例子 | 来源 |
|---|---|
| 《回到未来》Marty 乐队试演落选，理由只是「太吵」 | 受不公 |
| 《借刀杀人》Max 是最守时、车最干净的出租车司机 | 技能 |
| 《黑客帝国》Neo 不只自保，还要护住船上所有人 | 勇气、身处险境 |

检查：写完开场，数一数主角已经用了哪几种来源；不到 6 种就补，优先补能用一个动作同时体现两三种的场面。

作者对照：《我是传奇》九种全有，《绿灯侠》一种也没有。这是作者举例，不是统计结论。
