# 故事结构

**观众是主角**：下面每一项都为观众服务；拿不准时先问观众此刻在等什么，见[观众](story-audience.md)。

下表的部件是工具，不是必须填满的格子：观众在乎的是人物，不是在找激励事件；按这部剧要的效果挑用（见[六个问题与写场](story-questions.md)「结构理论是工具」）。电影与连续剧共用这些原则；三幕放在哪一层、节点在哪、一段推进多长，按[片种](story-formats.md)调整。

| 要素 | 要点 |
|---|---|
| 六个问题 | 关于谁、想要什么、为什么得不到、怎么办、为什么没成、怎样结束；任何层级都先答一遍，见[六个问题](story-questions.md) |
| 主角 | 可同情且主动，见[九种同情来源](story-sympathy.md) |
| 目标 | 具体、可见、高风险 |
| 人物主目标 | 每个主要人物有一个贯穿全剧的主目标（例：亚伦要成为一名伟大的圣骑士），记在剧的 `2_世界观人设/series.md`；有了它，每个事件、每个人物对主角是正影响（推他靠近）还是负影响（让他远离）就判断得出。每集故事决策记录写「## 目标影响」表（2026-10-17 用户定） |
| 对手 | 最想阻止主角的人 |
| 配角 | 共 [14 类](story-characters.md)，每个都要帮或阻主角 |
| 构思 | 先定观众体验（体验地图，见[观众](story-audience.md)「先定体验，再找事件」）→ 结局 → 两次大转折 → 开场；事件从体验反推，大纲放最后 |
| 三幕 | 平常世界 → 特殊世界（定计划）→ 即兴决战，见[三幕](story-acts.md) |
| 大转折一 | 瞬间击中主角，目标变具体，人生回不去 |
| 中点 | 不可回头、倒计时、揭秘 |
| 大转折二 | 全剧最大反转，计划崩塌 |
| 结尾 | 与对手正面决胜，短尾声 |
| 推进 | 短期目标 → 新消息 → 下个目标，不重复 |
| 伏笔 | 先看见、后改变意义，见[伏笔](story-foreshadowing.md) |
| 台词 | 先让人物在这一刻自己开口（[人物即兴](../../ai-videos-character-sim/SKILL.md)），再挑、剪；观众需要的背景由有理由说的人在有理由说时说出来，见[观众](story-audience.md) |
| 观众 | 一切相连、按戏剧顺序排、观众是主角，见[观众](story-audience.md) |
| 人物都聪明、合逻辑 | 每个人物（含对手、龙套）按自己知道的信息做最合理的选择；观众一问「他为什么不……」就答得上。不靠谁犯傻推动情节；冒险要有理由和计划，并说出来（2026-10-17 用户定）。**站位与视线也算逻辑**：写下每个人此刻站在哪、朝哪；站位要符合他的职责与目的（守门的人站在看得见来人的地方，放哨的人看得见他要防的方向）；每个反应都要有他看得见、听得见的起因（隔着墙、背对着、压着嗓子隔一片坡都不算）；他想躲的人能不能看见他，也要反过来问一遍（2026-10-18 用户指出：门卫写在门里背对来路，进门的人走到他们中间才看得见）。**看得见的事不装作不知道**：不写人物对眼前明摆着的事先做错、再由别人纠正的戏（2026-10-18 用户指出：亚伦看见血从维里右臂流下，还先去扶右臂，再由维里说「Not that arm」——删掉，他直接从好的一边架人） |
| 每句台词想清楚 | 先问：说话的人此刻面对谁（亲人、上司、陌生人、以后不再打交道的人），为什么非说这句，他会怎么说。对陌生人与过场人物只说办成眼前这件事需要的话，不交代私事；说出口的词观众都要立刻听懂，不留要解释才懂、又没人解释的词。同一层意思不说两遍：说清了就停，不再补一句换个说法的解释（例：「是我爸的」之后不再接「他想让我拿着」）。现阶段一律大白话、明说；潜台词与含蓄表达是进阶，等之后精修个别片段再用（2026-10-17 用户定） |
| 明说，不含蓄 | 现在的生成与剪辑还表达不了隐晦的意思：此刻发生了什么、谁想要什么、为什么这样做、人物关系、这场的道理，由有理由说的人在有理由说时明说；不靠暗示、留白让观众自己拼。伏笔可以留开放问题，但当场的事必须清楚（2026-10-17 用户定） |
| 场 | 每场有冲突与赌注，结束时人物或情节有变化，见[好场的构成](filming-scene-anatomy.md) |
