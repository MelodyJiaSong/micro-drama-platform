# 故事结构

**观众是主角**：下面每一项都为观众服务；拿不准时先问观众此刻在等什么，见[观众](story-audience.md)。

下表的部件是工具，不是必须填满的格子：观众在乎的是人物，不是在找激励事件；按这部剧要的效果挑用（见[六个问题与写场](story-questions.md)「结构理论是工具」）。电影与连续剧共用这些原则；三幕放在哪一层、节点在哪、一段推进多长，按[片种](story-formats.md)调整。

| 要素 | 要点 |
|---|---|
| 六个问题 | 关于谁、想要什么、为什么得不到、怎么办、为什么没成、怎样结束；任何层级都先答一遍，见[六个问题](story-questions.md) |
| 主角 | 可同情且主动，见[九种同情来源](story-sympathy.md) |
| 目标 | 具体、可见、高风险 |
| 对手 | 最想阻止主角的人 |
| 配角 | 共 [14 类](story-characters.md)，每个都要帮或阻主角 |
| 构思 | 先定观众体验（体验地图，见[观众](story-audience.md)「先定体验，再找事件」）→ 结局 → 两次大转折 → 开场；事件从体验反推，大纲放最后 |
| 三幕 | 平常世界 → 特殊世界（定计划）→ 即兴决战，见[三幕](story-acts.md) |
| 大转折一 | 瞬间击中主角，目标变具体，人生回不去 |
| 中点 | 不可回头、倒计时、揭秘 |
| 大转折二 | 全剧最大反转，计划崩塌 |
| 结尾 | 与对手正面决胜，短尾声 |
| 推进 | 短期目标 → 新消息 → 下个目标，不重复 |
| 伏笔 | 先看见、后改变意义，见[伏笔](story-foreshadowing.md) |
| 观众 | 一切相连、按戏剧顺序排、观众是主角，见[观众](story-audience.md) |
| 场 | 每场有冲突与赌注，结束时人物或情节有变化，见[好场的构成](filming-scene-anatomy.md) |
