# 出片审片（Seedance 还回来的东西对不对）

文字闸门与 previz 自检管的是「给 Seedance 的东西对不对」；本 skill 管「它还回来的对不对」。来源：shengji_zhilu follow-up 042
（shot04 两个亚伦两个杜克、锤悬在肩上；shot05 见狼低头、锤变斧、锤没打到狼）。

## 1. 出素材

```bash
python tools/render_review.py <shot 目录> [视频.mp4]     # 不给视频就找本镜目录 / renders/ / 下载目录里带 shotNN_ 的最新即梦出片
```

产物在 `renders/review/{视频名前 40 字}.{sha256 前 12 位}/`：`sheet.png`（逐秒）、`beats.png`（每个 [[hit]] 前 0.2 s / 当下 / 后 0.2 s，跳切切前切后）、`checklist.md`（头部 `take_sha256:`）。

## 2. 派子代理看图逐项判

子代理只拿这三份 + 本镜 shot md（看锁定串与动作），逐项写 **通过 / 不通过 + 哪几秒 + 看见了什么**：

| # | 查什么 | 不合格信号 | 回到哪个闸门补 |
|---|---|---|---|
| R1 人数 | 每个具名角色每一帧最多一个 | 分身、双胞胎；跳切前新位置上先冒出一个 | `shot_overhead.ghost_errors`：让他从头就在画里 / 新位置切前不入画 / 拆镜 |
| R2 道具形制 | 与锁定串对得上 | 锤变斧、盾变形、颜色材质换了 | item.toml `confusable` + 锁定串；previz 代理件的剪影（方头锤不是一根棍） |
| R3 持物 | 扛 / 挎 / 背的东西有手或带子 | 悬在肩上、贴在背上没带子 | item.toml `[carry]` + `carry_gate`；previz `[[角色.持物]]` 把手摆上去 |
| R4 命中 | 打中那一下武器碰到身体、看得见受力 | 挥空、隔空倒地 | overhead `[[hit]]` 时刻与站位；previz 命中贴身检查 |
| R5 视线与脸 | 对着敌人 / 说话对象不低头不背对 | 看见狼就低头、说话只见后脑勺 | previz 烘焙对账（躯干前倾 vs 编排）；`说话人朝向` 闸门 |
| R6 其他 | 剧本里没有的人、物、字、特效 | 多出来的人、字幕、光效 | prompt 负面词 / 光源闸门 |
| R7 关键拍兑现 | 学会 / 用出本事、亮起 / 变暗 / 稳住这类变化看得见、时刻大致对 | 光一直亮着没变、演示埋在全景里 | rule 37：学会那一刻给特写、变化写到秒 |
| R8 镜尾收住（机测） | 最后 0.25 s 比前 2 s 低 ≥ 12 dB：环境声 / 台词在切点前收住（Seedance 不出音乐，ai_video.md 12.4-H2） | 环境声 / 台词在镜尾被切断 | rule 38：最后一句离镜尾 ≥ 0.8 s；仍不过就重出 |
| R9 施法回读（机测） | `tools/cast_readback.py`：每次施法手上 / 目标身上亮没亮、光起早晚、落没落反、串没串到旁人（castcheck.json）；「未查」的看图补判 | ✗ 行 | 排程闸门错开同色施法；只错一个人用 `tools/cast_repair.py` 局部重拍 |

结论写进同目录 `verdict.md`：首行以 `通过` 或 `不通过` 开头，下一行照抄 checklist.md 的 `take_sha256:` 行（剪辑校验 edl verify V1 经 `render_review.verdict_ok` 按它认 take，缺了或对不上＝没审过）。

## 3. 不通过怎么办

**先问是哪一层给错了**：previz 里就是这样（低头、没手、没碰到）→ 改 previz 那一层重渲；previz 对、文字对、Seedance 仍画错 →
加强那一项的文字锁（负面词、锁定串、命中行）或换机位让它更难画错。同一类错出现第二次，就是闸门缺了一条——补闸门，不只补这一镜。

## 边界

### 连续长镜与授权修复闭环

承诺一镜到底时增加R10：同一摄影机连续视差，无硬切、叠化、溶解、场景变形替换或遮挡藏切。单文件或淡入淡出不算一镜到底。运行 `tools/long_take_gate.py <视频> --output <本版审片目录>`；全帧差异排名与0.25秒联系表只提供候选，独立审稿人仍须实际看图判读接续。

扫描时间必须来自实际解码帧PTS，不由名义fps推算；发现候选时刻超出镜长或解码帧数不一致就撤销该扫描证据，修复后重建。镜尾全身要求须看末尾高清帧逐人确认头顶/腿脚/持物及停稳窗口，不能只看previz通过或镜头仍连续；出现继续推近时补终点距离、人物占画高、脚下留白和禁止终点后推近的约束再生成。

环境无法感知音频时，原生成音轨的无对白/无音乐内容记未审，不凭响度通过。无对白建立镜可替换为 `tools/post/nature_ambience.py` 的本地自然环境声：独立核合成代码/种子/无外部语音或音乐源、实际mux音轨回读SNR、画面码流未变及R8，再审新take。证据只证明可核对的声音内容与收尾，须明列“主观听感未听审”，不能冒称听过；含对白、需口型或有明确原声表演的镜不能用此方法绕过听审。

每轮先归因到输入/空间/持物/模型返回/声音后期，再改对应层；图文冲突先查世界卡和用户定稿依据，不靠负面词掩盖。冻结prompt/参考SHA、保留费用与任务ID，结论绑定实际take；重复原因改变方案，不能原样盲重试。用户已明确授权本范围自动重生成时继续迭代，不重复询问；无授权保留人工关卡，默认界限或当前用户覆盖见CONVENTIONS。声音淡出等局部后期可修时保留原片，生成派生take再审，不能沿用原片通过章。未审不能填通过，也不能为结束循环降低标准。

写给 Seedance 的文字与几何 → 各生成器闸门与 `ai_videos__审查总编排`；previz 本身 → `tools/previz/review.py`；本 skill 只看出片。
