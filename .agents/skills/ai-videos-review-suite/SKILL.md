# 审查总编排（review suite）

把 AI 短剧（`ai_videos/{name}/`）的各项审查**串成一道标准工序**，按作用范围分三层、按依赖定顺序逐个调用专项 skill，每步**当场 surgical 落地修改**，最后汇总审计。目标：让"每个 ep、每个 shot 出片前过完整套审查"成为默认动作，而不是临时想起来跑哪个。

本 skill 是 CONVENTIONS.md「改动剧本/台词后默认连贯性 check」+「全剧序列 review」+ `ai_video.md` rule 12.4-D + `.agents/references/validation/ai_video.md` move #9 的**编排执行版**。各专项审查的准则不在这里重复，本 skill 只负责**顺序、范围、聚合、审计**。

## 何时用
- 用户说"全面审一下 / 出片前过一遍 / 把检查都跑一遍 / review 整体"。
- 写完/重剪某集后的收尾；stage-6 每个 work-unit 出片前。

## 输入
- 范围：某 shot、某集（`episodes/epNN/`）、或整个 drama（默认按用户指定；未指定且改了某集 → 该集）。
- task_id（`{task_name}-{YYYYMMDD-HHmmss}`）用于审计目录。

## 调用顺序（机械先行 → 单镜审美 → 整集 → 全剧）

按依赖排序：先把格式/契约修干净（否则审美审查在坏结构上跑无意义），再单镜审美，再跨镜整集，最后跨集全剧。**每个 shot 走完单镜层再进下一镜；整集层在全镜单镜层完成后跑；全剧层最后跑。**

**命名约定**：专项正文用现有 `ai_videos__{中文维度}`；机械校验 = `ai_videos__格式契约`；编排 = `ai_videos__审查总编排`。Codex ASCII 入口查 `.agents/skill-aliases.json`，不恢复旧 `ai_video__*_master` 名称。

**缺失能力的处置**：本次必需 skill / 工具 / 独立审稿能力缺失时，记 `{维度}: 未审（原因）` + blocker；可继续其他检查，但不能发 `validation.pass` 或推进依赖此审查的阶段。条件不适用的项目记 `n/a` 并解释；工具名不同先按共用映射查能力。

## 工作流
1. **定范围 + 建审计**：确定 shot/ep/drama；在 `.audit/adhoc_agents/{date}/{task_id}/events.jsonl` 写本轮起始事件，记 `pre_reading_consulted`（读过的 playbook/ref，含 sha256）。
2. **逐层调用**：第 0 项先跑；逐镜跑单镜项 0b / 1 / 1b / 2–6b，按内容条件触发 4b / 6b，1e 在出片后跑；全镜完成后跑整集项 1c / 1d / 7 / 7b，再跑全剧项 8 和整集+全剧项 9。按表中作用范围归层，不使用过期的数字范围。
3. **每步落地**：专项审查提交 surgical 补丁。台词以 `script.md` 为源（ai_video.md rule 12.6-B）；有生成器的剧情 / 动作 / shot 先改对应源再重建，不分别手改派生物回喂上游。镜头 / 光色等设计字段按专项来源修改。本编排汇总补丁并确认派生物一致。
4. **冲突仲裁**：若两个 skill 对同一字段给出矛盾 patch（如 camera 要"偏头反打" vs blocking 要"正脸不背对"），**以 blocking/朝向硬约束优先**（防"对空气/背对说话"是底线），并记仲裁。
5. **聚合审计**：每个 shot/ep 一条 `validation.started`（levels=跑过的维度列表）；每个不合格项一条 `validation.issue.raised`（level=维度、severity、patch）；全清则 `validation.pass`，否则按 CONVENTIONS.md 迭代上限（默认 3 轮）处理，超限 `pipeline.halted`。
6. **复验**：shot 数 / 锁定串 / 零 hex / 比例 不被审美层破坏；blocker 清零；输出每 shot/ep 的维度通过矩阵。后续专项若再改剧情、台词或画面动作，须重新抽取 screen，由独立审稿人复读受影响信息及整集承接，按对白通读 / 冷眼观众的盖章要求绑定最终产物，不能沿用修改前的通过结论。

## 硬约束
- **顺序不可乱**：机械契约（0）必须先跑——在缺字段/带字幕的坏结构上跑审美审查浪费且易误判。
- **不重复准则**：各维度判定标准只存在于对应专项 skill / ref，本编排引用不复制；准则漂移在专项 skill 改，不在这里改。
- **审查流水写审计**：suite 事件写运行目录 `.audit/adhoc_agents/{date}/{task_id}/events.jsonl`，不往 shot 塞重复的 review 状态。专用 gate 规定的 `dialogue_review.toml`、`viewing/review.md` 等证据照常保存，绑定当前产物指纹。
- 迭代上限、circuit-break、`pipeline.halted` 遵 CONVENTIONS.md § Iteration bounds。

## 接入点（让它成为"每个 ep/shot 的一部分"）
- **stage-6 validation level #9**：由"短剧故事+台词大师"扩为调用本 suite，每个 shot/ep 出片前必过。
- **CONVENTIONS.md 连贯性 amendment**：改剧本/台词后的默认自检 = 跑本 suite（而非只跑台词）。
- **12.4-D**：D/S 准则拆进各专项 skill 后，12.4-D 退化为指向本 suite 与各 skill 的索引。

## 输出
- 维度通过矩阵（每 shot/ep × 各维度 = pass / patched / 跳过）+ 全部已落地 patch 汇总 + blocker/warning 计数 + 一句话总结论 + 审计事件落点。
