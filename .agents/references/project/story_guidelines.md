# 故事内容指南

版本：`story-guidelines-v1`（2026-10-04）。适用原创、原作改编、短篇、长片与滚动连载；按本次范围检查，不回溯重写旧剧。

本页定义**故事内容的标准**；运行命令、输入冻结、审稿记录及验证步骤见[执行与验证](../../skills/ai-videos-pipeline/modules/story-runs.md)。规则只在各自源文件维护；[研究与来源](../../../specs/ai_video/shengji_zhilu/findings/story-guideline-research-20261004.md)解释取舍。这些是项目创作契约，不是所有成功故事的普遍定律。

## 人物与动机

明确谁在经历问题、为什么在乎，以及他的选择如何影响故事。焦点人物不必是高尚英雄；群像可以分线。

| ID | 内容标准 | 通过条件／证据 |
|---|---|---|
| R03 | 明确当前焦点人物及其行动理由。 | 能指出谁在经历问题、为何现在在乎，以及一个暴露欲望/处境/价值的具体行为；群像可以分线，不强行单主角。 |
| R05 | 让人物的选择影响故事。 | 焦点人物至少一项选择改变行动方式或局部后果；受困、失败、见证历史均允许，不靠改写原作英雄功绩制造主动性。 |

## 目标与冲突

把愿望变成可辨认成败的目标，建立阻力与代价。阻力可以来自对手、制度、环境、关系或自身矛盾，不强制单一反派。

| ID | 内容标准 | 通过条件／证据 |
|---|---|---|
| R04 | 把愿望转成可辨认结果的短期目标，并给出相称代价。 | 说明要完成什么、怎样知道成败、失败影响谁；代价可为关系/信任/机会，不强制生命危险或倒计时。 |

## 行动与因果

用目标、行动、阻碍与变化推进故事；结果和解法有来源，转折经得起回看。

| ID | 内容标准 | 通过条件／证据 |
|---|---|---|
| R06 | 事件有因果，解决办法有来源。 | 主要结果能追到行动或已建立的外部原因；巧合可引入问题，关键解决不能全靠无铺垫的救援/能力。 |
| R08 | 用目标—行动—阻碍—变化组织推进。 | 每个主要目标段落有结果或新情况，影响下一步目标/策略/关系；重复行动至少一项实质条件改变。允许观察与反应，不要求每场反转。 |
| R10 | 揭示与转折须改变理解或行动，并经得起回看。 | 所称转折有前后差异及可追溯原因；若使用误导/谜底，旧证据在真相下仍成立；不靠人物忘记已知事实。没有反转可标不适用。 |

## 世界与边界

遵守选定事实、原作边界、人物知识与能力限制；不要把推测、未来计划或候选设定写成既成事实。

| ID | 内容标准 | 通过条件／证据 |
|---|---|---|
| R01 | 区分事实、推断、原创和草稿。 | 影响剧情的设定有来源/版本或原创标记；承接只用已确定前集。 |
| R02 | 改编沿原作主线推进，新增内容服从改编边界。 | 本集指向已选原作事件/矛盾或其必要前置、后果；关键结果、人物职责、时间顺序的改变均有明确授权。纯原创项目此项不适用。 |
| R07 | 连续承接状态与人物知识。 | 时间、位置、伤势、持有物、能力、关系与目标相容；重要信息有获得渠道，推断有线索；作者知道不等于人物知道。 |
| R11 | 能力、工具与制度按已建立的边界解决问题。 | 关键解法所需资源、技能与条件已建立；限制/代价继续有效。新设定先作为候选建立，不能在解围时临时取消限制。 |

**写前明确**：范围、篇幅、基调、人物动机、事实来源、已确定前集状态、阶段方向及可改边界。

- 当前明确指令与明确批准的改编偏离优先；其余同时满足选定原作和本剧已确定事实。
- 原作与剧内事实冲突时记录冲突及影响，不静默挑选或补造解释。
- 未指定事项采用最少新增且兼容输入的方案，标明假设；硬事实未知时避开依赖它的情节。
- 自主模式可裁定可逆创作选择，推测仍不能标成原作事实。

## 情绪与变化

用压力下的选择、对白与反应呈现情感和关系。人物可以成长、退步或坚持。

| ID | 内容标准 | 通过条件／证据 |
|---|---|---|
| R12 | 用压力下的选择及反应呈现人物与情绪。 | 所宣称的情感变化有行为/对白/反应依据；内心独白可补充。人物可以成长、退步或坚持，不强制每集克服一个弱点。 |

## 结构与推进

每段有功能，每集有进展；结尾兑现或转化当前问题，连载按长期方向、阶段落点、当前集滚动细化。

| ID | 内容标准 | 通过条件／证据 |
|---|---|---|
| R09 | 连载分长期方向、阶段落点、当前集三层，滚动细化。 | 当前集写实，当前阶段有暂定落点；后续只保留方向/原作锚点。未来计划不当作已发生事件，也不进入人物当前知识。非连载项目不适用。 |
| R13 | 每段内容有功能，篇幅服从本次容量。 | 段落服务事件、人物/关系、必要理解或项目要求的世界体验；重复说明可删则删。故事模块不锁摄影，时长可拍性由影视改编实测。 |
| R14 | 本集有真实进展，结尾兑现或明确转化当前问题。 | 能指出本集得到的结果/发现/选择/关系变化；未解决事项有明确当前处境。续集期待来自已有后果，不靠假危险、重置进度或突然无关新敌人。 |

**写作顺序**：

1. 明确故事条件；改编先选主线锚点和允许补写的空白。
2. 写一句集核心：谁因什么处境，要做什么，遇到什么阻碍，会付出什么代价。
3. 先定本集结果与阶段落点，再列目标段落；不固定幕数、序列数或转折时间。
4. 写因果骨架，再写正文：当前目标 → 行动／阻碍 → 结果或新情况 → 下一步。

**可选形式，不是通用硬规则**：固定三幕、6/12/18序列位置、20–23序列、3–7页、25–35分钟转折、前三秒／每20秒情绪点；单主角、人格高尚、行业顶尖、每集成长、每集两次惊天反转、持续升级到世界末日。仅在明确选用时适用。
