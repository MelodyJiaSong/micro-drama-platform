# AI Video 全局工作流与覆盖边界

Claude Code 与 Codex 共用此约定。会话结束后，以仓库里的当前源、规格和审计接续，不依赖聊天历史或私有 memory。

## 入口与维护

管理 UI「工作流」是跨剧规则的统一入口：`1_AI Video` 下分别为 `1.1_故事创作`、`1.2_影视改编`、`1.3_Prompt编译`，其余组管理创作、服务、制作验收和公共资源；`2_Claude Code与Codex` 管理代理声明与执行约定。

唯一目录为 [workflow_catalog.json](workflow_catalog.json)。源正文仍在原位置；UI 当前只读，改进工作流时由 agent 修改对应共用源，再刷新 UI。三级编号绑定 `scope:path` 身份，已有编号不重排、不复用；新源追加编号，不把编号写回历史冻结输入。模块编号与剧内 `2_故事 / 3_影视改编 / 4_prompt编译` 属于不同导航层级。

新增或修改影响 AI Video 的跨剧指南、配置、模板、默认值、编译逻辑或验收工具时，同时维护目录，并运行管理应用的 `test_global_workflow.py`。在「工作流 → AI Video → 工作流覆盖核对」刷新检查：新源待编号、无法解析、分类缺失、已存在的共用文档引用未登记、run 全局源未登记都必须说明或修复。未配置的可选用户设置不是运行失败；检查结果不自动补造配置。

## 应覆盖什么

| 影响面 | 工作流入口 | 生效条件与边界 |
|---|---|---|
| 故事规则、模块输入输出、镜头景别知识 | 三大模块与全局创作规则 | 按本次模块读取；镜头知识用于影视改编设计与比较，不强迫每场使用所有景别 |
| 专项 skills、摄影视线/表演/因果/节奏等指南 | 制作与验收规则 | 按任务选用；登记不表示三模块自动加载全部审查 |
| 模型、时长、尺寸、采样、环境覆盖名称、CLI/函数默认值 | 服务与模型设置、制作与验收规则 | 展示静态声明，不执行源码、不读取秘密环境值；实际调用可能被运行环境覆盖 |
| Prompt 模板、角色/声音描述池、编译器规则 | Prompt 编译、公共资源、全局创作规则 | 模板正文和编译实现也属于影响源，不能只登记模块级大写常量 |
| AGENTS/CONVENTIONS、Claude/Codex 配置、hooks、规则和共用 skill 入口 | Claude Code与Codex | 用户级设置仅代表当前电脑；两端工具、权限与已加载上下文不保证相同 |
| 公共演员、调研、表演参考、资产规则 | 调研与共享资产及既有资源页 | 资产正文在资源库，目录集中规则和入口；按选用关系进入 run |
| 剧/季/集的 README、workflow、世界设定、风格、人物、场景、故事方向和版本 | 既有剧导航、各模块输入与 run 冻结输入 | 属于局部输入，不复制为跨剧规则；系列共享资产也不自动变成所有剧的事实 |
| 外部服务请求与实际参数 | 请求日志与 run 记录 | 请求前审计，查询/失败/下载也留痕；「生成永远人点」等授权仍生效 |

## 是什么，不是什么；应该做什么

- 目录是共用源索引，**不是独立的第二份规则库**。编辑原文件并刷新；不在 `.claude/` 复制业务正文。
- 覆盖核对检查目录可读性、稳定编号、共用文档中的现存文件引用，以及已保存 run 的来源。它**不证明每个来源当次都加载**，也不保证发现所有隐式 Python 依赖、外部插件或新接入入口。接入者须显式登记影响源并补充检查。
- 静态默认值**不是运行实测参数**。AST 提取不执行表达式；环境变量只列名称。完整模板/编译逻辑以对应源码入口核对。
- 当前源和历史输入分别查看。历史输入有冻结正文与指纹；缺失的系统指令、父代理上下文、模型/采样参数不能由当前配置补证。
- 历史参考与只服务旧剧的脚本明确标历史；它们**不是 three-module-v1 的默认输入**，不得复活已移除的 legacy BGM 流程。
- 秘密凭据、auth、私有 memory 和 `.env` 正文不进入 UI。外部模型权重、提供方隐藏系统提示、插件内部状态、未保存的会话附加指令属于不可从本仓库穷举的影响，必须以实际会话/请求记录确认。

## 故事创作的内容与执行分类

`1.1_故事创作`下分A_故事内容与B_执行与验证，各六个主题；导航唯一声明为目录的`story_navigation`。内容标准在`story_guidelines.md`，命令、协作、审计、验证接口与交接在共用`modules/story-runs.md`；模块指南仅作入口。主题页读取原文对应章节，不另存正文；规则ID、源编号、路径及历史冻结输入保持身份，主题ID仅用于定位章节。分类不改变两类规则均适用的要求。
