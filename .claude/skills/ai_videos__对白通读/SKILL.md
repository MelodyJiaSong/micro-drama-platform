# 对白通读（全剧上下文 · 母语口语）

`台词大师` 逐句审措辞，`白话大师` 管中文白话；本 skill 管**对话**：一来一回接不接得上、放进整集整剧里对不对、母语者听着顺不顺。
台词是哪门语言，就按那门语言的母语者标准审（shengji_zhilu 是英文，给英语观众）。来源：shengji_zhilu follow-up 037。
**例外：技能口令**（技能卡 `[call] text`，rule 45）是锁定的咒词，可以是游戏里的语言（shengji_zhilu 圣光术念德莱尼语、火球术喊萨拉斯语）——不按 N2 / N8 审、不给改写；只看 N1 / N4 / N9：念的时机、对着谁、跟不跟得上蓄光。来源：shengji_zhilu follow-up 053。

## 1. 谁来读、读什么

**没写过这集的子代理**（fresh context），范围永远是整集，外加与前后集的交界。输入：

- 本集 `4_剧本/episodes/{ep}/script.md` 全文（画面动作 + 台词 + 情绪氛围 + 备注）
- 之前各集的 `dialogue.md`（全剧声口与称呼的来龙去脉）
- `1_立项/concept.md`（受众、语言、世界口吻的硬约束）
- 出场人物卡的声口行与 `## 人物灵魂`、`2_世界观人设/relationships.md`、`casting.md` 的音色与说话方式
- `4_剧本/episodes/{ep}/states.toml`（谁受了伤、带着什么）

## 2. 逐段对话过十问

| # | 问 | 不合格信号 |
|---|---|---|
| N1 接得上 | 每句是不是在回应上一句：问有答、答对题、话头有承接 | 两人各说各的；上一句的问题被跳过；答非所问却不是有意回避 |
| N2 母语者会这么说 | 用词、搭配、语序、缩写、省略是不是地道口语 | 直译腔（照中文语序或搭配硬译）、教科书句、书面腔、该省不省、该缩不缩 |
| N3 声口一致 | 同一个人全剧的用词层级、句长、口头禅、幽默方式一致；变了要有剧情原因 | 惜字如金的人忽然长篇说理；粗人突然文绉绉；两个人说话一个腔 |
| N4 分量对得上处境 | 台词的情绪与当下处境相称 | 刚挨了一镐轻松说笑（除非这正是他的性格，而画面给了咬牙）；生死关头说闲话 |
| N5 称呼与关系 | 怎么称呼对方随关系演进，跨镜跨集一致 | 初见就叫昵称；前一镜叫名字、后一镜叫头衔且没有原因 |
| N6 信息边界 | 只说这个人此刻知道的事（看见的、听见的、被告知的） | 提到他不在场时发生的事；叫出没人告诉过他的名字 |
| N7 呼应 | callback 在前面真的说过；签名句不滥用；同一个笑话不讲两遍 | 呼应一句前文没有的话；同一个梗三镜里用两次 |
| N8 世界口吻 | 没有现代俚语、网络梗、不属于这个世界的词；也不伪古 | "okay, cool, awesome" 式现代腔进了中世纪世界；thou / hath |
| N9 念得出来 | 一口气说得完、重音落在该落的词上、配音演得出；中文意思与原句对得上 | 长句绕口；重读词埋在句中；中文意思漏意或多意 |
| N10 不替画面解释 | 画面已经演出来的因果 / 机制，台词不再说一遍（师父教本事除外） | 人物把观众刚看见的事喊出来或讲一遍——"They're on you! Why're they on you?!"：光一亮苦力全扑过去，拍出来就懂（shengji_zhilu 051） |

## 3. 修法

- **改的是对话，不是单句**：换一句先想上下文的来回还接不接得上，必要时连改前后两句。
- 保留人物灵魂里的声口，不为了顺把所有人改成同一种腔。
- 只改 `script.md`（台词唯一出处）→ `python tools/script_tools.py gen/check`（逐窗念白闸门）→ 生成器重跑；
  连带检查这一句的时间窗、动作里的口型与表情描述、中文意思。
- 改完请同一个审稿子代理（或新开一个）复读改过的段落，确认没有引入新的不顺。

## 4. 盖章：任何修改都要重读

通读、改完、复读确认后：

```bash
python tools/gen_shots_{剧}_{ep}.py --dialogue-stamp "对白通读 · 审稿人 · 备注"
```

把本集「台词 + 画面动作 + 情节」的指纹记进 `4_剧本/episodes/{ep}/dialogue_review.toml`（`tools/dialogue_review.py`）。
之后这三样**任何一处再改**，生成器 build 时指纹对不上即 blocker——必须再通读一遍才能出 prompt。
同一个指纹还要 `ai_videos__冷眼观众` 的章（`--viewer-stamp`，follow-up 038）：两枚都对得上才出 prompt。

## 输出

每条 `{镜, 窗, 说话人, N#, 原句, 为什么不顺, 改写（原文 + 中文意思）, blocker | major | minor}`，外加「通读过、没问题的段落」一行一条。
审计写 `.audit/adhoc_agents/{date}/{task_id}/spawns/{worker_id}/`。

## 边界

单句措辞质量 → `ai_videos__台词大师`；中文白话 → `ai_videos__白话大师`；剧情与因果 → `ai_videos__剧情连贯` / `ai_videos__逻辑因果`；跨集宣告与签名句序列 → `ai_videos__全剧序列`。
