# 跨镜逻辑因果审查

`剧情连贯` 看情节链与动机，本 skill 看**物理与因果**：这一秒发生的事，前面几秒里有没有让它发生的东西，而且画面上看得见。
来源：shengji_zhilu follow-up 033（狼在一米外等人拿锤）/ 034（杜克走到房前就摔了，路上没见跑）。规则正文 `ai_video.md` rule 29 ④ / 31。

## 1. 机检（先跑，全过再人工看）

```bash
python tools/shot_overhead.py --all <ep 目录>      # 速度上限、扑咬距离内不干等、反应窗、护人格挡、人站进实心块
python tools/gen_shots_{剧}_{ep}.py                 # 生成器内调 beat_logic：L1 速度词 L2 结果有因 L3 状态账本 L3b 伤要登记
```

生成器报错就是 blocker，照报错改 overhead 路点或 `动作:` 文字，**不许为过闸门删掉原因词或把跑改成走**——改的是事实，不是措辞。
**也不许为过闸门往前补一个原因**：报「没有原因」时先按 §2b X1 问这个结果该不该有。

## 2. 人工清单（机器判不了的）

| # | 查 | 不合格信号 | 改法 |
|---|---|---|---|
| C1 | **原因在画里** | 原因只在台词里说、或在上上镜 | 把原因搬进本镜第一拍（瘸着、喘着、手上还卡着斧子） |
| C2 | **来得及** | 人抄家伙、转身、跑过去的时间 < 对手到达的时间 | 按 距离 ÷ 速度 倒推出发时刻；让对手先被发现在远处 |
| C3 | **谁知道什么** | 角色对没看见 / 没听见的事做出反应；或看见了却不反应 | 给他一个听见 / 看见的 beat，或删掉反应 |
| C4 | **道具有来处去处** | 东西凭空出现在手里、用完凭空消失 | 写出拿起 / 放下 / 递交那一下；跨镜的写进 `states.toml` |
| C5 | **旁人不冻结** | 打起来时旁边的人站着不动、不躲不叫 | 给一个反应（退、喊、护住谁），或让他出画 |
| C6 | **跳时间要说** | 镜内切后人换了位置却没交代 | 平面图有 `jump_cuts` 时生成器自动写；人工确认不是本该连续的走位 |
| C7 | **威胁有逻辑** | 野兽 / 敌人站着等、轮流上、见光不躲 | 扑完就退、找空子；怕什么就躲什么，前后一致 |

## 2b. 全集上下文通读（follow-up 035）

机检只认「有没有原因词」：034 往 S02 补一口没破皮的狼咬、写上「伤脚一软」，闸门就放过了敦实的杜克在三级台阶上自己扑倒。
这一步交给**没写过这集的子代理**（fresh context），**范围永远是整集**，不只看改动的那一镜。剧本阶段（stage 4 QC）和出片前（审查总编排 7b）都跑。

输入：`script.md` 全文、出场人物卡的外形行与 `## 人物灵魂`、怪物卡的定位、`states.toml`。逐拍问下面五个问题，答不上来就记 issue：

| # | 问 | 不合格例 |
|---|---|---|
| X1 必要 | 删掉这一拍，戏少了什么？ | 摔一跤只为让他趴着喊 "First!"——站着喊一样好笑 |
| X2 分量 | 原因配得上结果吗？ | 靴帮挡住、没破皮的一口 → 下一镜瘸着跑、脚一软扑倒 |
| X3 人物 | 对得上卡里的体型、出身、本事、性格吗？ | 从小扛麦袋、重心压得很低的人自己平地摔 |
| X4 世界 | 对手 / 野兽 / 旁人的反应对得上习性和上一拍吗？ | 刚被打跑的敌人没来由地又冲回来 |
| X5 铺垫 | 结果靠的原因，观众之前看见了、也当回事了吗？ | 一句「哎哟」带过的事，下一镜拿来当摔倒的理由 |

**修法顺序：先删改结果，再考虑补原因。** 结果不是主线必需的 → 删掉，或换一种不需要额外原因的演法（笑点挪到反应上）；
是主线必需的 → 补原因，而且原因要在前面的镜里被看见、被当回事、分量配得上，并登记 `states.toml`（severity 如实填）。
**为了让闸门通过往前补一个小原因，是反模式。**

子代理输出每条 `{镜, 拍, X1–X5, 现状, 改法, blocker|major|minor}`；审计写到 `.audit/.../spawns/{worker_id}/`。

## 3. 落地

- 改 `script.md`（人读）→ 生成器 `SHOTS`（`plot / action / ledger`）→ `overhead.toml` 路点 → `states.toml` 登记，四处一致后重跑生成器。
- 伤、破口、卡住的武器这类跨镜状态，**先登记账本再写镜**：`[[state]] who / what / severity / from / to / show`。
  severity 取值只在 `beat_logic.SEVERITY`：无碍（当场没事，to＝from）· 皮外 · 行动受限（只有这一档能瘸、腿软、自己摔）· 非伤（衣物 / 物件）。
- 审计：`validation.issue.raised`（`level = logic`）。

## 边界
- 动机可信、爽点、情节链 → `ai_videos__剧情连贯`；跨集 → `ai_videos__全剧序列`；招式本身 → `ai_videos__武打设计`；单镜动作密度 → `ai_videos__动作表演`。
