# 阶段 6 · 标准化 AI 分镜 Prompt — playbook

> 流程位置：阶段 5（分镜运镜设计）→ **阶段 6（本步）** → 整集 animatic 过审（ai_video.md rule 44）→ 出片（12.4-K）→ 后期 finish_ep（rule 42）→ 整集观感与观众回路（rule 43）。
> 产物：每镜 shot md 里的**设计稿**（全字段，给人和闸门）+ 生成器压出的**精简 Seedance prompt**（`## Seedance prompt`，rule 12.4-P，≤ 2000 字）+ 台词配音 prompt。
> **2026-09-28 起下文与 ai_video.md 冲突处以 ai_video.md 为准**：只走 Seedance（Kling 已退出）、单镜 3–30 s、负面词只留通用短清单、走位写画面左右、音频模式 native / tts_first（12.4-H2）。
> 阶段 5、6 **合一在同一份 `shotNN.md`**：阶段 5 写运镜设计字段，本步把它补成完整的五层标准化 prompt + 台词配音 + 过校契约。
> 交互默认 **interactive**：先用多选题问用户、用答案细化再生成（用户可说「这段自动」跳过提问）。

## 2. 内建提问清单（AskUserQuestion 多选，标默认）

> 锁定项已在阶段 1/2 定稿，本步主要**确认**，不重开。每题默认项加「（默认·推荐）」。

1. **音频模式**（写进 `seedance.toml` 的 `audio_mode`，rule 12.4-H2）：① **native（默认·推荐）**——画内台词用 Seedance 原生人声（entity 绑声样），画外 / 独白后期配；② tts_first——TTS 先出、作 @音频 上传对口型。出片模型固定 Seedance（即梦 2.5 全能参考），不再问。
2. **渲染风格**：**影视级真人写实仙侠 · 全剧统一渲染样式串（默认·推荐）**；或项目自定（须写进 style_guide 并全场景统一、记 divergence）。
3. **负面词**：只留通用短清单（画面文字 / 字幕 / 水印 / 分身 / 畸形肢体 / 人脸变形 / 渲染质感类），**不点名任何具体物件**——模型会把被点名的东西画出来（rule 12.4-P）。
4. **字幕**：prompt 零字幕（硬契约）；成片阶段 `tools/post/finish_ep.py` 出 SRT 与烧录版（中文竖屏默认烧录，rule 42）。

## 3. 五层标准化 Prompt 模板（核心）

把阶段 5 的运镜设计**重组并补全**为下面的五层结构。五层是**阅读 / 编写组织法**，落地仍是 rule 12.4 字段级 schema（参考/角色/情节/场景/镜头/走位/动作/台词/光线/节奏/渲染样式/比例/时长）——五层是这些字段的分组视图，缺任一字段 = stage-6 校验失败。

| 层 | 内容 | 对应 rule 12.4 字段 |
|---|---|---|
| 层1 · 场景 + bg 代号 | 固定 bg 代号 + 一句话场景锁定 | `参考:`（场景 token）+ `场景:` |
| 层2 · 锁定角色 | 复制人物卡锁定描述符 byte-identical；剪影/背影配角只写轮廓 | `参考:`（人物 token）+ `角色:` |
| 层3 · 剧情 + 分镜动作 | 情节承接 / 镜头 / 0–Xs 分段动作 / 台词标注（画面无字幕） | `情节:` `镜头:` `走位:` `动作:` `台词:` |
| 层4 · 光影色调 + 氛围 | 随情绪的光线色调；禁人物自发光、无多余金光、藏锋无外放 | `光线 / 色调:` `节奏:` |
| 层5 · 渲染统一参数 + 负面词块 | 全剧统一渲染串 + **负面词固定块（必填）** | `渲染样式:`（+ 负面词块） |
| — | 单镜时长（阶段 5 已定，本步透传） | `时长:` `比例:` |

**copy-ready 五层模板（落进 `## 视频 prompt` 的 ```text 块）：**

```text
{NN}集{NN}镜视
参考: `{本镜首帧=> ← 仅承接镜加、置最前；硬切镜删此项}, {人物1}=>, {人物2}=>, {bg代号}=>{, 本镜末帧=> ← 仅交接源镜加、置最后}`（帧 handle 一律短式 `本镜首帧=>`/`本镜末帧=>`，**禁** `(上一镜末帧)`/`(重生时上传)` 括注·K26⑤）
（**`参考分配:` 行已废除 · 2026-09-06**——它的职责是把 @图N 映射回角色/场景/首尾帧；`参考:` 现在只用裸 `=>@`、不带编号，槽位语义由项名自身承载，这一行没有存在意义。原本挂在它上面的通用叮嘱「保持角色服装/场景/光线一致、只生成本镜运动·不改造主体外观」移进 `参考用法:` 行。）
角色: `{人物1}: {角色识别标签·byte-identical 自人物卡第8行，造型可辨项无五官}; {剪影配角}: {只写从背面可见的轮廓·衣色/发型/体态，不给五官}`
角色识别 / 参考图: `{人物1}＝参考图(turntable/选角脸·见参考行); 多人物同框时逐个写死「参考图↔画面位置↔识别标签」绑定，如 画面左·{人物1}=参考图A·{标签}; 画面右·{人物2}=参考图B·{标签}（防 Seedance/Kling 串脸；脸由选角图承载，此处只做绑定消歧，不写五官，2026-06-18 选角供脸 rule 12.4-B）`
情节: `{承接上镜的小说原文/剧情·verbatim；具体角色名不用关系称谓}`
场景: `{bg代号} · {一句话场景锁定}`
镜头: `{景别} + {运动}（近景/特写注「背景浅景深虚化柔焦、主体清晰」；关键情绪瞬间用缓慢推近至面部）`
走位: `{每段机位下每个在画人物在画左 / 中 / 右、脸朝不朝镜头（生成器从 overhead 算，rule 32）；罗盘方位只留在平面图里}`
动作: `0–{a}s … / {a}–{b}s … / {b}–{X}s …（分秒 beat，beats 之和 = 时长）`
台词:（画面不显示文字、仅供口型与配音参考；逐条↓）
· {说话人}〔{正常台词 / 内心独白}·{语气·口型注：正常台词→口型对{说话人}；内心独白/画外/系统→嘴唇不动、不对口型}〕：{台词正文·纯文本不加引号}
光线 / 色调: `{随情绪的光影色调；藏锋无外放、人物不自发光、无多余金光；眼变化靠表演、不加发光特效}`
节奏: `{慢 / 中 / 快 / 顿挫·纯视觉节奏}`
渲染样式: 影视级真人写实 · 电影级唯美仙侠 · 电影质感 · 竖屏 · 浅景深特写 · 逆光描边 · 东方修真古风 · 工笔质感肤色白皙通透 · 三庭五眼东方面孔 · 精致纹样场景 · 淡仙气氛围 · photorealism · 画面不烧任何字幕文字（台词后期另加）。
负面词: 人脸变形 / 五官漂移 / 画面文字 / 字幕 / 水印 / 分身 / 畸形肢体 / 多余手指 / 卡通动画感（通用项，不点名具体物件）。
比例: 9:16
时长: {3–30}秒
```

> 注：
> - **`参考:` 行写法（2026-09-06 用户裁定）**：每项一律 `` `{项名}(类型)=>@` ``，**`@` 后留空**——那是用户上传时手填的占位，Claude 只写项名、不写编号。`@1` / `@图1` /「第一张图」全是错的。**槽位语义由项名自身承载**，不需要编号：`本镜首帧(上一镜末帧)=>@`＝首帧、`本镜末帧=>@`＝尾帧、`{角色}=>@`＝锁该角色、`{bg}=>@`＝场景、`{角色}声音=>@`＝音色源、`{角色}出场字卡=>@`＝字卡叠层、`系统=>@`＝系统 UI 叠层。**旧的 `参考分配:` 独立行已废除、不再写。** 那些原本挂在它上面的语义叮嘱（「出场字卡不入运动生成」「系统 UI 非实体·仅主角可见叠层」「黑影剪影纯黑无脸不可辨」「保持角色服装/场景/光线一致、只生成本镜运动·不改造主体外观」）改写进 `参考用法:` 行。`参考:` 与 `角色识别 / 参考图:` **两者并存**（前者＝上传清单/路由 handle，后者＝绑脸防串脸）。机械校验归 `格式契约` K27。
> - **跨镜首帧承接（ai_video.md 2026-06-21；完整 prompt 写法 + 正反例见 `agent_refs/project/ai_video_shouweizhen.md`）**：阶段 5 已在 `## Shot context` 写死 `衔接:` 字段（`承接 shot{NN} 末帧（首帧＝上一镜末帧）` / `硬切（独立首帧）`）。本步对**承接镜**补三处落点：① `参考:` 行**最前**加 `本镜首帧(上一镜末帧)=>`（进模型「首帧」槽、非普通参考图槽）；并在 `参考:` 下方按帧模式加结构化指令——**承接镜首次生成走「首帧单图」**（`首帧: 画面以首帧为起始、自首帧那一刻续起、起始不重新缩放/不重摆姿`），首+末双帧指令（`首末帧:…渐变至末帧`）**仅重生本镜锁末帧时**用（首次生成本镜末帧不存在、写双帧会让模型渐变到不存在的末帧致首帧不锁·漂几十帧·ai_video.md (H2)）；② `## Shot context` 的 `Reference uploads` 加「上一镜末帧（从 shot{NN} 成片截取最后一帧、作本镜首帧上传）」；③ 确认本镜 `动作:` 首拍 + `走位:` 起始与上一镜末拍续接（不跳变）。**硬切镜不挂承接帧**——`参考:` 不加该 handle、Reference uploads 不加末帧行。机械校验归 `格式契约` K26。**交接源镜（其后继是承接镜）补两处**（ai_video.md (G)）：① `## Shot context` 加 `尾帧锁定:` 行；② `参考:` 行**末尾**加 `尾帧锁定(本镜末帧·重生时上传)=>` handle（与承接镜首端 `本镜首帧=>` 对称、进模型尾帧槽）。语义：重生成本镜时把 `shotNN_lastframe.png` 作尾帧上传锁定末帧、保下游承接镜首帧参考有效、免连环重生（首次生成无需）。
> - **渲染样式串 + 负面词块全剧 byte-identical**——逐字复制 `style_guide.md`，每镜重贴同一串。
> - **负面词只留通用短清单**（rule 12.4-P 取代旧「负面词块必填」）：想压住的具体物件改成正面写实际有什么。
> - **每个字段值用反引号包裹**，帮模型分辨结构段边界。
> - **每镜自包含**：prompt body 严禁「承 shotNN / 见 shotNN / 下一镜」等跨镜引用（生成时每镜独立喂入）。
> - **字数（rule 12.4-P，2026-09-28）**：设计稿不设上限（给人和闸门读）；**上传的 `## Seedance prompt` ≤ 2000 字**，由 `tools/prompt_compact.py` 从设计稿压出，超限生成器 raise。官方示例 650–1400 字——过 1500 先考虑拆镜（打斗 / 多人互动按官方建议分段生成）或把动作写概括，不要逐拍复述参考视频已经给了的动作。

## 4. 台词配音 prompt 块（每个说话镜必补）

每个有台词的 shot 在 `## 视频 prompt` 之后追加独立 `## 台词配音 prompt` 段（**每个发声单元各一个 ```text 块**）。三声线解耦、后期 mux。

```text
{NN}集{NN}镜 · 台词配音
角色: {说话人}
音色(锁定·全剧复用 · {voice_id}): {声线描述·取自角色 bible}
情绪: {本镜情绪}
语速: {语速·按时长目标定}
类型: {正常台词 / 内心独白 / 系统提示音}
台词: {台词正文·阿拉伯数字改口语中文}
时长目标: {秒·各句之和 ≤ shot 时长}
```

- **音色一致性铁律**：同一角色全剧 / 跨集复用**同一 `voice_id`**，不同镜只改情绪 / 语速、不换音色。voice_id 与角色 bible / casting.md 对齐。
- **音频模式（rule 12.4-H2）**：native——画内台词是 Seedance 原生人声，本块只供字幕与画外 / 独白配音（`tools/indextts_dub.py --only post`）；tts_first——本块先出 `shotNN_tts_lip.wav` 作 @音频 上传对口型。**不许**文字驱动口型后再用另一段 TTS 覆盖。Seedance 不出音乐，BGM 在后期（finish_ep）。
- **画外 / OS / 系统句**：类型标 `内心独白 / 系统提示音`，配套视频 prompt 的 `台词:` 标「嘴唇不动、不对口型」「严禁对到在画人物嘴上」。
- **默剧 / 静默镜**：省略本段（或标「无台词」并注环境音）。

## 5. 生成步骤

1. 读全部输入（阶段 5 的 shotNN.md + 人物卡锁定串/voice_id + 场景档 + style_guide + script/dialogue）。
2. **逐镜把运镜设计补全成五层 prompt**：层1 填 bg 代号 + 场景锁定；层2 byte-identical 复制锁定描述符（剪影只写轮廓）；层3 补情节承接 + 透传镜头/走位/动作分秒 + 台词标注；层4 补随情绪光影、藏锋无外放；层5 重贴全剧统一渲染串 + 负面词块；透传时长/比例。
2b. **承接镜补首帧承接落点**（阶段 5 已写 `衔接:` 字段的镜）：值=承接的镜，`参考:` 行最前加 `本镜首帧(上一镜末帧)=>`、`Reference uploads` 加末帧上传行、确认 `动作:`首拍/`走位:`起始与上镜末拍续接；值=硬切的镜不挂承接帧。详见 §3 注 + ai_video.md 2026-06-21。
3. **每个说话镜补 `## 台词配音 prompt` 块**（每发声单元一块），voice_id 对齐 bible。
3b. **带显著情绪 beat 的镜引用演技库**（§9b + 2026-06-18 演技库 amendment）：按 情绪大类+强度+时长 在 `_performances/` 匹配 top-N，选中条目把锁定文本块**融入（不照抄）**该镜 `动作:`/表情，并加 `表演库参考: perf_NNNN (情绪·强度·风格·载体) — 用于 <角色> <beat>` 标注行。webapp 可推荐候选 + 多选 + 一键重生（`POST /api/regen-shot-prompt`）。
4. **生成全集汇编 `all_shot_prompts.md`**：它是**派生只读快照**（`shotNN.md` 是唯一真源），含每镜视频 prompt +（说话镜的）台词配音 prompt。**用脚本生成、禁手工维护/手抄同步**——`python tools/build_all_shot_prompts.py <epNN_dir>`（或 `--all <episodes_dir>` 批量）会从各 `shots/shotNN/shotNN.md` 聚合重建、保留人工撰写的头部（风格/元信息）、只重建每镜正文。**任何 shotNN.md 改动后跑一次该脚本重汇编**（不再逐处手改快照，杜绝 drift）。
5. **人物出场字卡（rule 11d · 标准步骤 · 图片合成）**：扫本集有无**重要角色首次登场**（主角/核心反派/关键长线配角；龙套·路人·系统不发卡，门槛见 ai_video.md 11d / style_guide §7）。有则 ① 该首登镜 `## Shot context` 加 `首登字卡:` 行（字卡文字**不入** `## 视频 prompt` ```text``` 块）；② 该集建 `episodes/epNN/intro_cards.md`（行式：`角色 | 首登shot | 出现点(秒) | 卡图 | 位置(右上/左上) | 显示时长(秒) | 宽度占比`）。**卡图＝用户用 Kling/即梦 做好的整张人物卡 PNG（透明底，含框+烫金名+身份），放本剧库 `2_世界观人设/intro_cards/`（中文同名：`{中文名}.md` 出图 prompt + `{中文名}.png` 成品）**（不程序化画图）；`卡图`列填裸中文名或路径。同角色全剧仅首登发一次——本集无重要新角色首登则**省此文件**。出现点=角色入场、显示时长 ≥3.5s（不够则加长其首句台词+beat）。后期由 webapp「🪧 人物卡」(`POST /api/burn-intro-cards`) 把卡图 fade 叠到镜头顶角 → 生成 `shot{NN}.mp4`（落 shot 根、不覆盖 `renders/` 原片、二次烧录可覆盖）。

## 6. 输出物

落点：`ai_videos/{name}/5_6_分镜与prompt/episodes/epNN/`。

- 各 `shots/shotNN/shotNN.md`——补全后的 canonical shot 文件（YAML envelope → 小说原文/Chapter excerpt → H1 → `## Shot context` → `## 视频 prompt`（五层单块）→ `## 台词配音 prompt` → `## previz prompt`（shot blend 生成指令，由生成器从 `planning/overhead.toml` + `动作:` 拼出，必须在末尾——闸门把第一个 text 块当 Seedance prompt；ai_video.md rule 4j 2026-09-25 第 5 条；**只有要 previz 的复杂镜带这一块**，免 previz 的镜 `参考:` 首位挂 `shotNN_overhead_ref.png`、`参考用法:` 写明平面图图例——rule 4j 修订第 6 条））。`## 起始帧` / `## 结束帧` 静帧块已废止，不得出现。带显著情绪 beat 的镜按 §9b + 2026-06-18 演技库 amendment 加 `表演库参考: perf_NNNN (情绪·强度·风格·载体) — 用于 <角色> <beat>` 标注行（不另立段）。

## 8. 避坑

- **特效严限「无外放威能 · 人物不自发光」**：力量靠体内暖流 + 表演，禁金光 / 瞳光 / 裂纹 / 威能光 show；眼神转锐靠瞳孔微缩 / 眼睑收紧 / 目光如刃（神态语言），**严禁写「眼睛发光 / 瞳孔发光 / 锐光 / 眼内光效」**（Kling 会字面渲染成射光）。
- **台词与画面剥离**：`台词:` 只留说话人 + 正文 + 类型 + 口型注，**画面零字幕**（禁字体 / 字号 / 位置 / 颜色 / 内嵌硬字幕 / 后期软字幕 / 字幕窗）；`台词:` 正文**绝不清空**（删了成片变哑），全员无口型镜用「画外配音 voice-over + 禁 lip-sync」而非删文。
- **剪影暗线只写轮廓禁五官**：黑影 / 暗线角色只给「纯黑剪影、按刀伫立、面目不可辨、不给辨识特征、不显形」，留待后续集显形。
- **多角色同框同角色只具名一次**：避免视频模型把同一人渲染成两个；≥2 个背影时逐一点明各自区分特征（衣色 / 发型）+「严禁雷同或都渲染成同一人」。
