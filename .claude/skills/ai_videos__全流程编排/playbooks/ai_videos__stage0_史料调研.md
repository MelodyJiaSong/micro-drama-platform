# 阶段 0 · 史料调研 — playbook（条件触发：史料驱动项目）

> 只对**声明「史料驱动」**的项目触发（历史 / 纪实 / 复原类——concept 或系列圣经写明；首个用例：《时空旅行》`ai_videos/shikong_lvxing/`，2026-09-13）。
> 它在 `1_立项` **之前**：dossier 不齐，不许写 concept、不许建资产、不许写台词。
> 输出规则的权威出处是 `agent_refs/project/ai_video.md` rule 17；本文只写「怎么做」。

---

## 1. 何时 / 输入

- **何时**：一部史料驱动的片子（或系列的一站）开工的第一步；或某站的 dossier 缺项要补。
- **输入**：时空坐标候选（城 + 年 + 哪一天）、系列级公共库（`_series/{sources.md, blacklist.md, glossary.md}`，没有就在本阶段建）。
- **目标**：`{片}/0_research/dossier.md` —— 一份**可机检、可引用、有人眼核过原文页**的事实清单，加上每个资产的历史参考图库。

## 2. 内建提问清单（interactive：先问后做）

| # | 题目 | 选项 |
|---|---|---|
| Q1 | 时空坐标 | 自由填：城 + 年 + **哪一天**（用正史年表找一个「有事发生」的日子当新闻由头）；无默认 |
| Q2 | 考据严格度 | **科普向娱乐**`(推荐)`：画面可截图指认的东西（服饰 / 建筑 / 器物 / 食物 / 货币 / 称谓）只允许 ✅ / ⚠️，❌ 只进纠错单元 / 纪录片级：全 ✅ / 宽松：允许 ⚠️ 进正片不口播 |
| Q3 | 公共库状态 | 系列已有 `sources.md / blacklist.md / glossary.md``(沿用)` / 本站新建 |
| Q4 | 参考图库门槛 | 每资产 ≥ 8 张`(推荐)` / ≥ 4 张（试拍） / 用户自定 |

## 3. 生成步骤（SOP，每站约 6–10 h；首站建库另加 2–3 天）

1. **定坐标（30 min）**：正史本纪 / 年表 → 一个有事发生的日子；写 dossier 第 1、11 节。
2. **读城市志原文（2 h）**：汴京《东京梦华录》对应卷、长安《唐两京城坊考》对应坊、临安《梦粱录》、罗马 Beard 对应章 + 涂鸦库……全部在 ctext / 维基文库 / 公开数据库可查。边读边填第 2 / 4 / 8 / 9 节，**每条贴原文 + 链接**。
3. **读断代专著补衣 / 住 / 物价（2 h）**：只读索引到的页（沈从文 / 孙机 / 程民生 / Mortimer / Carcopino…）。物价一律「篮子锚定」（一斗米 + 一日工钱两个锚），**禁止「一两银子 ＝ X 元」**。
4. **建参考图库（2–3 h）**：**每个场景 / 建筑 / 食物 / 服饰 / object 在写锚点 prompt 之前，先找 ≥ 8 张历史参考图**——`python tools/ref_fetch.py search "<关键词>" --source met,commons` 找候选，`pull <asset_dir> met:<id> commons:<pageid> --evidence <fact_id>` 下载到该资产的 `ref/` 并写 `refs.md`；无 API 的来源（故宫名画记 / 台北故宫 Open Data / 考古报告图版）手动下载后 `register`。许可非 CC0 / CC-BY 的图**只进 prompt 不入画**。
5. **过黑名单（30 min）**：`_series/blacklist.md` 从头过一遍，本站可能出现的写进第 13 节 + 每条 fact 的 `negative`。模型默认输出本身就是误传的浓缩（清宫剧「大人」、唐宋人物穿明代立领、罗马人满街托加）。
6. **写锁定串（1 h）**：模板 `{形制名词}（{材质}，{色名，零 hex}，{关键结构 2–3 处}），{穿着/使用方式}；不是 {最常见误传形制}`；每串回指 `fact_id`；**串里必须有一句「不是 X」**。
7. **顾问抽查（异步）**：带着具体 `fact_id` 去问（r/AskHistorians FAQ、简帛网、公开课教师、博物馆教育部门），不问开放题。

**AI 辅助的边界**：让 AI 建索引、交叉质询、起草 `prompt_string` 候选、翻译；**不让 AI** 做无源问答、决定 ✅/⚠️、直出剧本当史料、生成「当地人会怎么答」。**每条进 prompt 的事实必须有人眼看过的原文页**——`verified_by: ai_draft` 的条目不得进 prompt。

## 4. 输出物 + 模板

- `{片}/0_research/dossier.md` —— 固定 15 节，缺项写「未查」不删节（多路并行调研时，YAML 事实注册在 `0_research/parts/w{N}_*.md`，dossier.md 各节只写综合 + 表格 + `fact_id` 指针，不复制 YAML）：
  1 时空坐标 · 2 城市地图与街区（含记者 / 旅行者路线，每个停靠点对应一个 shot 组）· 3 衣（按阶层 × 性别 3–5 套，每套一个锁定串 + 参考图）· 4 食 · 5 住（坐具！）· 6 行 · 7 物价与货币（两锚 + 10 件商品，全换算成「几天工钱」）· 8 职业与社会阶层（6–8 种人，含 1 官吏 1 商贩 1 女性 1 底层）· 9 节令与习俗 · 10 语言与称谓（白名单 / 黑名单）· 11 当日大事时间线 · 12 可采访 / 可观察的人物（按项目形态：**采访型**＝真实 ≥ 2 只引原话、典型虚构 ≥ 3；**旁白型**＝当地人不开口，只列可观察的人与他们的一天，真实人物只远景——shikong_lvxing follow-up 008）· 13 常见误传（本站）· 14 未定与推测项（所有 ⚠️ 的汇总）· 15 参考来源（T0 / T1 / T2 分组）
- 每条事实一行 YAML（机检用）：

```yaml
- fact_id: kaifeng.food.007
  claim: 州桥夜市卖「旋煎羊白肠、鲊脯、㸇冻鱼头」等
  tag: ✅            # ✅ 史料确证 | ⚠️ 合理推测 | ❌ 民间误传
  source: 《东京梦华录》卷二「州桥夜市」
  source_url: https://ctext.org/wiki.pl?if=gb&res=712358
  tier: T0           # T0 一手 | T1 学术 | T2 严肃普及 | T3 百科媒体 | T4 影视/模型默认（只作反例）
  verified_by: human # human（用户看过原文页）| ai_read（Claude 抓到原文页并附 quote，待用户抽查后改 human）| ai_draft（凭记忆，不得进 prompt）
  used_in: []
  prompt_string: "夜市摊位上摆着切成段的煎羊肠、腌鱼干、冻鱼头，用粗陶碗盛放"
  negative: "辣椒、红油、玉米、番茄、土豆"
```

- 每个资产目录的 `refs.md`（由 `tools/ref_fetch.py` 生成 / 追加）：`ref_id / file / source_url / collection / accession / date / license / evidences / use`。
- 系列级公共库（首站建、逐站追加）：`_series/sources.md`（来源库）、`_series/blacklist.md`（误传黑名单 ＝ prompt 负向词库）、`_series/glossary.md`（称谓白名单 + TTS 专名读音表）。

## 5. QC 关卡（`ai_videos__格式契约` K34 + 人工）

- [ ] 15 节齐全，缺项显式「未查」
- [ ] ≥ 20 条 `verified_by: human` 或 `ai_read`（ai_read 条目须有 `quote` + `source_url`，并在 dossier §0 列出抽查清单；`ai_draft` 不计数、不得进 prompt）
- [ ] 画面可截图指认的类别（衣 / 住 / 器物 / 食物 / 货币 / 称谓）无 ❌ 之外的空档；❌ 只列在第 13 节
- [ ] 黑名单过完；每条 fact 的 `negative` 非空
- [ ] 每个要建的资产（bg / prop / 角色服饰 / 食物）有 `refs.md` 且 ≥ Q4 门槛张数；非开放许可的图标「只进 prompt 不入画」
- [ ] 物价节两个锚 + ≥ 10 件商品，全部「几天工钱」口径

任一缺失 ＝ blocker，不得进阶段 1。

## 6. 避坑

- **不要用模型「想象的古代」**：锚点 prompt 里每个形制词都要指得出是哪张参考图、哪条 fact。
- **「痕迹」不能写成「正在发生」**（`ai_video.md` 16.8）：烧过的石头写成「暗红褐色烧斑与细裂纹，早已冷透」。
- **称谓是最常翻车的一层**：中文版走「现代普通话 + 断代称谓白名单」；绝不生成古语（拉丁语 / 文言）。
- **画面里的文字**（招牌 / 涂鸦 / 铭文）禁止让模型「写字」；用核对过的真实铭文或无意义纹样。

## 7. 衔接

- **上游**：系列圣经（若有）。
- **下游**：阶段 1 `concept.md`（时空坐标 / 当天大事 / 可采访 / 可观察人物直接来自 dossier 第 1、11、12 节）→ 阶段 2 资产（锁定串与参考图库直接进 characters / scenes / props 卡）→ 阶段 5/6 每镜 `史实:` 行回指 `fact_id`（K34）。

## 8. 机制（贯穿）

- **每次 update 复核**：dossier 任何改动 → 受影响的锁定串 / 负向词 / shot `史实:` 行同步 + `specs/ai_video/{name}/changelog.md` 记一条。
- **反馈 → 进化**：观众 / 顾问的纠错 → 回写 dossier（改 tag 或加 fact）+ `_series/blacklist.md` 追加 + 本 playbook 记教训。
