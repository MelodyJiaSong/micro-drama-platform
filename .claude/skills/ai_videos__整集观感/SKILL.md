# 整集观感（想不想看下去）

别的审查都在问「对不对」。本 skill 只问：**刷到这集的普通观众，会在哪一秒划走**。
观众容忍画面小瑕疵，不容忍情绪空洞与拖沓；业内经验：前 3 秒钩子、每 20–30 秒一个情绪点、集尾留钩。

## 0. 分工

| skill | 问什么 | 看什么 |
|---|---|---|
| `ai_videos__冷眼观众` | 看不看得懂（目标、动机、任务线） | 剧本抽出的画面与台词 |
| `ai_videos__出片审片` | 单镜画对没有（分身、道具、命中） | 单镜逐秒拼图 |
| **本 skill** | 想不想看下去（钩子、情绪点、拖沓、笑点 / 泪点成不成立） | 整集视频的观片包 |

不重复另两个：看不懂的地方记一句「转冷眼观众」即止；画面缺陷只在它会让人出戏划走时才提。

## 1. 何时跑

- 出片前：`{ep}_animatic.mp4` 拼好——改结构最便宜的时候。
- 出片后：`{ep}.mp4` / `{ep}_final.mp4` 拼好。
- 用户说「好不好看」「节奏拖不拖」「会不会划走」「整集看一遍」。

## 2. 出观片包

```bash
python tools/viewing_packet.py <剧> <ep> [--video PATH]    # 默认 {ep}_final → {ep} → {ep}_animatic
```

| `{集目录}/viewing/` | 内容 |
|---|---|
| `sheets/shotNN.jpg` | 每镜联系表：每 1–2 s 一帧，帧上印成片时间码、镜内秒、此刻在说的台词；表头是意图与标签 |
| `transcript.md` | 成片时间码上的每句台词（角色 / 类型 / 台词 / 中文意思）、每镜意图 / 情绪标签 / 节奏、静音段 |
| `packet.json` | 视频路径 + sha256 + 镜边界 + 文件清单 |

视频只覆盖本集一段时（transcript 头会写明），只判这一段；集尾钩改判「这一段的收尾让不让人点下一段」。

## 3. 派子代理判读

审稿人：没写过、没审过这集的子代理，**只读 `viewing/`**——packet.json → transcript.md → sheets 按镜号全看。
不给剧本、人物卡、立项、shot md：作者知道的东西会替画面把空白补上。意图与标签只用来核对「说好的笑点 / 泪点兑现没有」，不许拿来替画面打分。
判 animatic 时：previz 卡每 1.5 s 翻一帧；previz 不渲光与法术，卡上印的动作写了闪光 / 光柱就按它在画面上算（shengji ep01 r4 把 S02 已有的「锤头一闪」判成没有）。

把自己当成刷到这条视频的普通观众：

| # | 判什么 | 怎么判 |
|---|---|---|
| V1 注意力曲线 | 每镜 0–10：10＝离不开眼，5＝还在看但手指在动，≤ 3＝大概率划走；写预计划走点（成片秒） | 画面有没有变化、台词有没有新信息 / 冲突 / 包袱；同一构图连着 3 帧以上没变化记「拖」 |
| V2 前 3 秒钩子 | 0–3 s 有没有让人停下的东西：异常、冲突、悬念、强画面、一句怪话 | 只有风景 / 走路 / 慢摇 ＝ 没钩子 |
| V3 情绪点密度 | 列每个情绪点（笑、紧、惊、暖、爽）的成片秒；相邻两点 > 30 s 记「空档」 | 要看得见 / 听得见，意图里写了不算 |
| V4 标签镜兑现 | 标了好笑 / 好哭/暖 / 紧张的镜：成立 / 半成立 / 不成立 + 哪一秒 + 为什么 | 包袱要有铺垫和落点，落点要有反应或停顿；泪点要看得见人的脸 |
| V5 集尾钩 | 最后 5–10 s 留没留一个问题 / 危险 / 期待 | 平收、只剩风景 ＝ 没钩 |
| V6 最该改的 3 处 | 按「能救回的观众最多」排序，每处落到镜号 + 成片秒 + 问题 + 改法方向 | 只给方向（剪短 / 提前 / 合并 / 加反应 / 换一句台词 / 前移钩子），**不直接改产物** |

## 4. review.md（格式固定，工具会读）

```markdown
# {ep} 整集观感
> 视频: `{packet.json 的 video.path}`（{kind}）· 视频 sha256: {packet.json 的 video.sha256，64 位}
> 审稿: {worker_id} · {日期} · 只读 viewing/
> 一句话: {想不想看下去，为什么}

## 注意力曲线
| 镜 | 成片时间 | 注意力 | 预计划走点 | 为什么 |
|---|---|---|---|---|
| shot01 | 00:00–00:29 | 6 | 00:12 | … |

## 钩子与情绪点
- 前 3 秒：… / 情绪点：00:05 好奇 · 00:41 紧 …；空档：… / 标签镜：shotNN 好笑 → 半成立（00:53 …） / 集尾钩：…

## 最该改的 3 处
1. **shotNN 00:mm–00:mm**：问题 → 改法方向
```

`视频 sha256:` 行与注意力表的前三列不许改：`--check` 与 `tools/audience.py` 按它读。**视频变了结论就作废**：

```bash
python tools/viewing_packet.py <剧> <ep> --check     # exit 1 ＝ 没审 / 审的是旧视频 / 视频在出包后变了
```

## 5. 之后

- 3 处改法交用户定；同意后按 CLAUDE.md「用户报问题：先提流程改进」走，落到对应 skill（节奏 → `时长节奏`，台词 → `台词大师` / `对白通读`，画面 → `奇观镜头` / `动作表演`，结构 → `剧情连贯`），改完重拼再审一轮。
- 同一类问题第二次出现（例如开场又是 20 s 风景），就是生成器缺一道闸门——补闸门，不只改这一集。

## 6. 观众回路（轻量）

```bash
python tools/audience.py log <剧> <ep> --platform youtube --url URL [--date YYYY-MM-DD]
python tools/audience.py ingest <剧> <ep> --platform youtube --retention 留存.csv [--comments 评论.txt] [--views N] [--avg-view-s S]
python tools/audience.py report <剧> <ep>            # 只按已收的数据重出报告
```

出 `{集目录}/audience_report.md`：每镜平均留存与镜内跌幅、跌得最狠的 3 镜、评论摘录，并把 review.md 的注意力分并排放——
**预估与实测对不上的镜，就是本 skill 口径该校准的地方**。末尾「候选 follow-up」只是草稿，落不落档由人定。
