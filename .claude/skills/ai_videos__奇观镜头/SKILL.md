# 奇观镜头大师（spectacle / watchability master）

把 `ai_videos/{name}/` 里每一个 shot 拿到**观众第一眼**的标准下问一句：**这 5–8 秒里到底"发生了什么好看的"？** 不合格就当场改写 `镜头/走位/动作/光线/情节` 并三处同步。

**为什么单列**：① `运镜` 管镜头语法**对不对**（轴线/视线匹配/景别节奏）；② `特效设计` 管超自然视觉**该不该有、边界在哪**；③ `动作表演` 管人物演得**真不真**；④ `时长节奏` 管秒数**够不够**。四个都通过、画面仍然**平**——这就是本 skill 的地盘：**精彩度**。一个镜可以字段齐全、逻辑自洽、零 blocker，同时毫无看头。

> **本 skill 的判读基准来自专业摄影/MV 制作实证**（StudioBinder 运镜与 match cut 词条、Filmmakers Academy 纵深分层、PremiumBeat haze/fog/焦段、No Film School「每镜当一幅画」、ASC《卧虎藏龙》摄影访谈、澎湃对国产仙侠"廉价感"的批评、Higgsfield/Kling/Seedance/Veo/Runway 官方 prompt 指南）。完整笔记与来源见 `.audit/adhoc_agents/2026-08-02/xianjian_yi_mv-20260802-mvcraft/spawns/{r1-mv-directing,r2-wuxia-camera,r3-ai-video-craft}/output.md`。

## 何时用
- 用户说：这镜不够精彩 / 太平 / 没看点 / 像幻灯片 / 像 PPT 翻页 / 拍得更好看 / 特效拉满 / 名场面要还原。
- 任何**新写或重写 shot prompt** 时（生成关，不是只在审查关）。
- `审查总编排` 单镜层的**第一道**——它决定这一镜值不值得存在；后面的专项才决定它对不对。

## 输入
- 被审 shot 的全部字段 + 它在音乐/剧情里的**位置**（前奏/主歌/副歌/高潮）与**相邻镜**。
- `style_guide.md`（调色/motif/特效尺度）、`world.md`（力量体系与特效分级）、structure/shotlist（这一镜承担什么叙事功能）。

## 审查标准（逐项过 Q1–Q14）

### Q1 · 单镜变化曲线：首帧 ≠ 末帧，且中间有一个决定性瞬间

**判读口径**：把 `情节:`／`动作:` 读完，写下"首帧画面"和"末帧画面"两句话。**如果这两句话几乎一样，这就是废镜。**

- 职业 MV 剪辑师的口径是「Every cut has to have an intention」——反过来，一个不切的镜**必须自己内部提供事件**。
- 可用的变化轴至少六条：① 景别变（推/拉）② 焦点变（rack focus，不切镜就换掉观众的注意对象）③ 光变（云过／灯亮／剑光扫过）④ 遮挡变（前景物移开露出主体）⑤ 空间位置变（人从背景走到前景）⑥ 生理外化变（呼吸从急促到屏住、下颌从松到咬紧）。

**反面写法**：`动作: 0–3s 他站在原地看着远方，神情复杂；3–6s 他继续看着远方，眼眶发红`
**正面改法**：给它一条轴。要么让**世界**动（风起／灯灭／门开），要么让**距离**动（推近到只剩眼睛），要么让**遮挡**动（前景的人走过、露出他）。

**决定性瞬间的位置**：落在镜头的**中后段（约 55%–75%）**，前面留蓄势、后面留余韵。开头就炸完＝后面全是废秒；结尾才炸＝观众还没反应就切了。

### Q2 · 纵深三层：前景 / 主体 / 背景各写一句

**判读口径**：`场景:`／`镜头:` 里能不能读出**三个不同深度平面**。只有"人 + 背景"＝两层＝平。

- 「dirtying the frame」＝故意在镜头前加物体**部分遮挡**画面，让观众"下意识被拉进场景里、有身在其中感"；前提是**主体仍然清晰可辨**。
- 遮挡（occlusion）制造悬念与纵深；「跟拍镜头如果觉得缺乏纵深，就该加更多物体来形成更锐利的遮挡效果」。
- 其余分层手段：框中框（门洞/窗/拱/另一个人的身体）、大气透视（远处更不锐更冷）、暖色前进冷色后退、前景细纹理 vs 背景平滑、引导线（路/走廊/透视汇聚）、纵深调度（把人物排在不同深度平面上，从背景走向前景＝叙事重心转移）、打光分离（逆光/轮廓光防止主体和背景糊成一片）。

**⚠ AI 模型对"前景"两个字反应极弱。** 必须写成**具体物件 + 具体位置 + 具体虚实 + 具体运动**：

**反面写法**：`前景有树枝`
**正面改法**：`画面左侧四分之一处有一根离镜头极近的竹枝，严重虚化成暗色块，随风轻晃，遮住人物左肩`

### Q3 · 大气介质：让画面"贵"的第一杠杆

**判读口径**：`光线:` 里有没有可见的**空气**。没有介质的画面，光是"贴"在物体上的，永远读作 CG。

- haze 是几乎所有现代好莱坞片场的标配。机理：光要穿过 haze 才到传感器、被扩散，**走过的扩散越多损失的颜色和锐度越多**——于是主体比背景锐，画面**自动分层**。
- **haze ≠ fog，混写会得到一团糊**：要**分层**写 haze（极薄悬浮雾气/浮尘/水汽）；要**遮挡与剪影**才写 fog（浓雾）。贴地爬行的写 ground fog。
- 体积光（丁达尔）＝光穿过介质本身可见，是"仙气"的物理载体，不是滤镜。

**可直接抄的句式**：`空气中有极薄的悬浮雾气，逆光穿过形成可见的窄光柱，远景比近景更灰更淡、更不锐`

### Q4 · 反射面：不加灯就加曝光

**判读口径**：夜戏/雨戏/水边/雪地/室内地砖——有没有把地面用起来。

- 夜外景行业经典「wet down」：把路面喷湿，把吸光的深灰面变成**镜面**，把灯的光反射回画面下半部，**等于不加灯就加曝光**，还给画面下部填上颜色与运动。
- 反射构图通法：**机位压到接近地面高度**，越低反射里装得下的场景越多（"一个小水洼能反射整栋摩天楼"）；玻璃同时反射身后街景 + 透出室内，形成双重曝光式叠层；风是镜面水的敌人。

### Q5 · 运镜要有动机、有起止点、有量化幅度——且和动作分家

**判读口径**：`镜头:` 里能不能读出「**一个**运镜 + 从哪到哪 + 多快 + 多大幅度」。

- 官方 prompt 指南三源一致：**一镜一个主导运动**。复合运动（急速环绕 + 变焦 + 甩）是崩坏与"循环动画"的头号来源。
- 运镜必须**服务这一镜的情绪**，不是默认值：推近＝拉近观众/暗示**内在**状态（反应、思考、内心冲突）；拉远＝揭示语境/孤立感；上摇＝建立体量与敬畏；环绕＝把静态场面变成动态、hero 镜的标配；变焦（只变焦距不动机位）＝"不自然"，恐怖惊悚才用；roll＝蓄意制造不适。
- **"缓推"是本仓最泛滥的默认值。** 一整段全是"缓推/静定"＝这一段没有镜头语言。

**反面写法**：`镜头: 中景·缓推`
**正面改法**：`镜头: 中全景起幅，机位压到脚踝高度由下向上仰拍；单机位连续升镜不切镜，随人物升起匀速上摇约三十度并轻微后拉；落幅收在悬空的人与脚下剑身；全程不切镜`

### Q6 · 气场四杠杆：姿态 > 机位 > 光 > 道具入画（脸排最后）

**判读口径**：凡这一镜的目标是"这个人很强/很美/很有威仪"，四项必须全配，缺一即未落地。

| # | 杠杆 | 弱写法 | 强写法 |
|---|---|---|---|
| 1 | 姿态 | 斜倚、含胸、重心偏移 | 两脚分开与肩同宽、重心沉稳落在双脚之间、**脊柱与颈笔直**；"松弛"只放在肩与手，绝不放在骨架 |
| 2 | 机位 | 平视 | **机位略低于视平线、微仰约 10 度** |
| 3 | 光 | 均匀柔和的正面平光 | **侧后轮廓光勾出肩背与发缘**——轮廓光是气场的物理来源，没有它再多形容词也白搭 |
| 4 | 道具 | 兵器收在鞘中不可见 | 让身份道具**进入画面并占据构图斜线**（剑拎在手、剑尖斜指地面） |

**焦段的心理学**：广角（14–24mm）＝包裹感、空间被拉开、近大远小夸张；35–50mm＝人眼自然；**长焦（85–135mm）＝压缩空间、主体从背景剥离、追逐戏的速度感**（《十面埋伏》竹林追杀即用长焦压缩透视造快节奏）。

### Q7 · 光要有源、有方向、有色温、有介质（ROI 最高的字段）

**判读口径**：`光线:` 四要素齐不齐——**光源实体 + 方向 + 色温/时段 + 介质**。

- 官方 prompt 指南实测口径：「添加具体光影描述产生的**每词质量提升超过任何其他提示词元素**」。
- 「光线应该有其存在依据——窗户、路灯、火光、月亮、灯笼。当光线拥有可信的光源时，整个场景会显得更具真实感。」
- 反面是「光线过于完美、每一帧都显得同等重要」。要有**对比度**，避免完全均匀打光。

**反面写法**：`光线: 唯美的电影感光线，气氛悲伤`
**正面改法**：`光线: 主光＝画左上方高悬的破窗漏下的冷白月光，色温偏蓝；人物右半边脸落进阴影只留一条轮廓光勾出下颌与发缘；空气里有可见的悬浮尘，月光穿过时形成一道窄光柱斜切画面`

### Q8 · 特效不算数，环境反应才算数

**判读口径**：一处特效只写了"光"、没写"世界对它做了什么反应"→ **观众读成贴图**，一律判不合格。

- 澎湃对国产仙侠剧廉价感的批评原话就是这个根因：演员"一掌打出后，一股特效光、特效风过去了"，"打完一套不仅没出汗，连头发丝都不曾乱一分"。**光有了，世界没变，于是廉价。**
- VFX 工业的空间轴是四层：**源头 → 传播 → 环境反应 → 受体反应**；时间轴是四拍：**蓄力 → 引导 → 释放 → 残留**。
- 每个特效镜必须写满**至少两条环境反应**：
  - **物理位移**：草伏／尘扬／水面炸开／碎石弹跳／布料被压得贴身／发丝被吹起且方向一致／灯焰被压歪
  - **光影投射**：这道光在地面、墙面、人脸上投出的**移动亮斑与影子**
  - **受体反应**：在场者被照亮的半边脸、被迫眯眼／偏头／后退半步
  - **同感视觉替身**：蛛网同时颤动、水面同心圆、梁上积尘簌簌落下
- **规模感靠"改变天体/地貌"，不靠加亮。**（《苍兰诀》"撕开月亮登场"被公认为把强大具象化的名场面。）

### Q9 · 飞行/凌空/轻功：重量三拍，不然就是"被吊着"

**判读口径**：凡有离地动作，`动作:` 必须拆出三拍，缺一即"飘"。

李安在《卧虎藏龙》竹林戏头三天素材全废，原话是"**演员看起来是被吊着，不是在飞**"。给重量的具体手段（有据）：

1. **起飞＝蓄势 → 离地 → 拔升**三拍。蓄势拍要有下蹲压腿 + 衣摆被气压下压 + 脚下细尘先动。
2. **地面必须给反作用**：起飞与落地在工业上是两个**被单独定型的镜头类型**（superhero takeoff / landing），各自拆成地面破坏层 + 尘与碎屑层。
3. **环境让路是最强的重量证据**：竹子"在她重量下弯曲摇摆"。飞行中要有**东西为他让开**（云被撕开、树梢压弯、水面被压出凹面）。
4. **落地＝冲击 → 下沉 → 起身**（"不是飘，是划弧、加速、带冲击落地"）。
5. **次级运动是分水岭**：布料、发丝、腰带必须**滞后于身体**运动，而不是和身体同步。
6. **身体代价痕迹**：喘息、汗、乱发、衣料位移——反面就是"打完一套连头发丝都不曾乱一分"。
7. **威亚不是为了失重，是为了给"另一种重量"**——重量感应当对应修为等级。

### Q10 · 规模与体量：给一个可视化参照物

**判读口径**：写了"巨大/高耸/漫天/千级"，画面里有没有**可比对的参照物**。模型不懂"巨大"，只懂"和什么比"。

**反面写法**：`巍峨的高塔`
**正面改法**：`塔基前站着的人只有塔门门钉那么高，塔身向上收窄十七层后没入云中，云在塔的三分之二处横切过去`

### Q11 · hero 镜配额：稀缺才是奇观

**判读口径**：全片 T3 级 hero 镜控制在 **8–12 个**（一支 4–6 分钟 MV）。多了就不稀罕。

hero 镜通常落在：副歌第一拍、身份揭示、法宝出鞘、御剑起飞、形态转换、最大的失去。hero 镜的 `镜头:` 里要同时写死三件事——① 一次性的环绕或大升降运动；② 主体被光**单独**打亮（轮廓光 + 体积光）；③ **只在这镜出现**的奇观元素（尘暴／雪幕／剑光轨迹／衣袂）。**其余镜位不得抢这三件事**，否则 hero 不 hero。

### Q12 · 节奏：镜长服务音乐，不是服务预算

**判读口径**：副歌区 4–6s 密集短切、主歌/间奏 6–12s 抒情长镜；奇观镜与动作镜集中在副歌。慢镜（升格）用在**情绪最重的一拍**，不要全片撒。

《卧虎藏龙》摄影指导原话：「我们经常在**每一步之间手动变速**来加快他们的动作，在不让人察觉的前提下增强动作。」——变速本身是动作设计的一部分。胡金铨《侠女》竹林歼敌**20 秒剪了 18 个镜头**，纯靠蹦床 + 剪辑打出媲美现代特效的冲击力。

### Q13 · 转场：用 motif 物件和图形匹配，不用花哨特效

段与段之间以**调色变化 + 一个 motif 物件**承接（本片：木剑／蝴蝶／纸伞／佩剑）。可用：match cut（动作接动作）、graphic match（形状/构图匹配）、whip pan 接whip pan、光比转场（亮到暗/暗到亮）。**禁**：闪白、翻页、粒子转场、任何"特效转场"。

### Q14 · AI 可执行性边界：写了也拍不出来的东西，等于没写

- **一镜一个主导运动**。矛盾运动语言（同时要求"缓慢电影感移动"与"快速激烈动作"）＝不自然动画/循环动画的直接成因。
- **状态变化必须是单向一次性过程**，带时间顺序。反复态措辞（`一阵…一阵…` / `忽…忽…` / `反复` / `交替`）会被渲染成 5s 内来回十几次的高频循环。
- **变身/形态转换要"在镜头内部连续发生"**，不是硬切。
- **禁抽象概念语**（"体现了喜悦的本质"）、**禁对话式措辞**（"能不能帮我加一只狗"）、**禁一条 prompt 里多场景切换**。
- **正文里的否定要改成正向措辞**（Runway Gen-4 官方明说不支持负面表述）；否定项一律移到专用的**反向提示词**框。
- **堆词稀释重点**：外部最佳实践是单镜 60–100 词。本仓硬顶已由 2000 上调至 5000（2026-08-03），**风险因此更大而非更小**——真正的风险从来不是超顶而是**把重点写没了**。密度靠**去重**，不靠堆词。
- **⚠ 分秒时间轴是分模型的**：Veo 系官方支持 `[00:00-00:02]`；即梦/Seedance 侧有"吃"与"不吃"两派说法且官方未定。本仓模板现用 `0–1.5s / 1.5–2.8s` 写法——**保留**，但若实测出现动作错位，第一个该改的就是它（改写成「先…接着…最后…」）。

## 廉价感反面清单（命中即改）

- 一股特效光 + 一股特效风过去了，世界没变
- 打完一套不出汗、头发丝不乱、衣服不皱
- 人站着做表情，5 秒内画面零变化
- 满屏发光粒子/星点/bokeh 光球当"仙气"
- 均匀柔和的正面平光，没有阴影也没有轮廓
- "缓推"包打全片
- 写了"巨大/漫天/千级"但画面里没有参照物
- 用形容词堆气氛（唯美的、震撼的、电影感的）而不写具体的光与物

## 工作流（judge → 改写 → 同步）

1. 读 shot 全字段 + 它在音乐/剧情里的位置 + 相邻镜。
2. **先答一句话**：「这一镜的看点是＿＿」。答不出来 → 这镜要么删、要么换场面，**不要在字段上修修补补**。
3. 逐项过 **Q1–Q14**，列不合格项（cite shot / 项 / 准则）。
4. **写进 shot**：`情节:`（决定性瞬间）+ `镜头:`（运动与起止点）+ `走位:`（纵深调度）+ `动作:`（重量三拍/次级运动/环境反应）+ `光线:`（四要素+介质+反射）。
5. **三处同步**（shot / shotlist / structure 对位表），并更新 `## Shot context` 的 `首末帧反差` 与 `尾帧锁定`。
6. 复验：首帧≠末帧、有决定性瞬间、三层纵深、有介质、运镜单一且量化、光四要素齐、特效带两条环境反应、hero 配额没被稀释。

## 硬约束

- **只管精彩度**：不改镜头语法对错（归 `ai_videos__运镜`）、不定超自然视觉边界（归 `ai_videos__特效设计`）、不改打斗招式（归 `ai_videos__武打设计`）、不改表演真实度（归 `ai_videos__动作表演`）、不改秒数（归 `ai_videos__时长节奏`）、不改台词（归 `ai_videos__台词大师`/`白话大师`）、不做机械校验（归 `ai_videos__格式契约`）。
- **不得为了精彩破坏既定契约**：全字符 ≤5000、平台合规（零 IP 名/零画面文字/敏感词按类清）、画幅、锁定描述符 byte-identical、特效审美下限（禁廉价金光/禁瞳孔发光/禁循环闪烁）。**精彩度不是豁免权。**
- **加强只能靠"换掉平庸的东西"，不能靠"再加一层"**。字数是零和的：每加一句具体的光，就要删一句形容词。
