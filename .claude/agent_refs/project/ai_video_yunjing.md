## 1. 镜头行八条铁律（写任何 `镜头:` 字段前先过）

1. **三段式：起幅景别 → 运镜（含速度）→ 落幅景别**。景别变化用**连续语态**（「从全景缓缓推至面部特写」），禁景别罗列句（「全景。特写。」＝Seedance 隐式分镜触发）；景别词取自五级阶梯（`ai_video_jingbie.md`）。（源 R1 官方推镜示例结构）
2. **一镜一主运镜 + 至多一个修饰层**。主运镜（推/拉/摇/移/跟/升降/环绕）只写一个；修饰层（手持呼吸感/荷兰角构图/浅景深）可叠一个。**禁指令冲突**（「固定镜头」+「推轨」互斥；荷兰角+推轨+环绕三件套必崩）。（源 R1 官方 2.0 避坑项 + R2/R3 同口径）
3. **情绪目标写进镜头行**（`（情绪目的：…）`括注）——运镜是情绪的手段（stage5 §3 映射表先定情绪再选机位，不变）。
4. **速度词白名单/黑名单**。白：缓慢、匀速、平稳、流畅、轻微；黑：**快速 / fast / 急速**（Seedance/Kling 双官方系指南同判头号降质词——运动模糊+时间不一致+噪声）。速度感靠**结果描述**：拖影、拉丝、风压、背景放射模糊+主体清晰锁定。（源 R1/R2/R3 三方一致）
5. **机位高度/角度用定性锚点，物理数值无效**。高度锚：贴地/脚踝高度/膝盖高度/腰部高度/半空/高空/云端（「机位0.3米」「高度50米」不被稳定解析，米数至多当档位词）。**判决无效**：快门数值（1/50秒）、光圈数值（f1.8）、变焦速度（每秒4.5米——单位本身错误）；度数（15度倾斜）与焦段（85mm 长焦压缩/24mm 广角）**可写、当程度词理解**，勿依赖精确执行。（源 R2/R3/R4 数字参数总裁定）
6. **防切镜三层**（Seedance 原生多镜头会被 prompt 内容触发切镜）：① `镜头:` 行带「**一镜到底不切镜**」声明（长镜/多 beat 镜必带）；② 禁切镜触发词——切至/切换/镜头1/镜头2/转场/蒙太奇/快切（＝S7 单镜单机位的词面层）；③ 负面词挂「镜头切换/转场/跳切」。⚠ **时间戳分段（0-3s…）是 Seedance 2.0 的多镜头分镜语法**——本工作流的 `动作:` 时间轴（A1 契约）保留不变，但**必须搭配本条三层防护**；若某镜反复渲出切镜，优先检查①②③再考虑把该镜 `动作:` 改「先…随后…最后…」连续语序 A/B 实测。（源 R1 官方切镜机制原文 + 防切五军规）
7. **运镜词只进 `镜头:` 字段，严禁夹进 `动作:`**（官方镜头内组织逻辑「运镜→主体动作」分写；混写相互污染）。（源 R1/R2）
8. **I2V 首帧前置 + 中英括注**。图生视频（我们主流程）**没有运镜控制面板，文本是唯一运镜通道**，且运镜从首帧构图出发演化——**首帧图必须先编码机位**（低机位跟拍→首帧即低机位构图；希区柯克变焦→首帧要有前中后景层次），首帧与文本运镜矛盾时运镜被忽略或跳变。中文术语后括注英文（「缓慢推进（dolly in）」）可提执行精度。（源 R2 Kling I2V 结论，Seedance 同理）

## 2. 官方运镜词表速查（平台差异）

**Seedance（即梦）官方词表**（火山引擎官方提示词指南原文，R1）：
- 基础运镜：推、拉、摇、移、环绕、跟随、升、降、变焦；2.0 强调词：缓慢推镜、平稳横移、固定镜头、全景侧拍、定格、拉远、跟拍、俯冲、过肩镜头。
- 视角：水下镜头、航拍镜头、高机位俯拍、低机位仰拍、微距摄影、**以xx为前景的镜头**（＝官方过肩写法，能指定前景是谁）。
- 技术报告点名：环绕跟踪、dolly-in、**希区柯克变焦**、横摇、跟拍。
- **负面词机制**：Seedance **无独立负面通道**——约束以禁止句写进 prompt 体内（我们的 `负面词:` 字段本就在体内，兼容；写短禁止句优于裸词）。
- API 级：`camera_fixed: true`（`--cf true`）锁**固定机位**（连运镜一起禁，只适合刻意锁机位镜）。

**Kling（可灵）**（R2）：
- 镜头控制面板（水平/垂直/推拉/摇/俯仰/滚转 六轴）与「大师运镜」预设**仅文生视频可用**；**图生视频唯一运镜通道＝文本提示词**（首帧 anchor 原则）。
- Kling 3.0 官方确认理解：tracking/POV/正反打（shot-reverse-shot）/**dolly zoom**/**rack focus（焦点转移）**/long take。
- 负面词框 5–8 个强负面词最优、堆砌反僵硬——光影/运镜防漂词**替换进集内而非无限追加**。
- 甩镜（whip pan）中文指南响应评级「良好」。

## 3. 技巧词库

### 3a. 基础运镜（tutorial 2 验证 + 官方词表）

| 技巧 | 锁定触发写法（直接可粘 `镜头:`） | 适用情绪/场景 | 失败模式 → 规避 | 平台注记 |
|---|---|---|---|---|
| **缓慢推进**（dolly in） | 「缓慢推镜（dolly in），从{起幅景别}匀速推至{落幅景别}」；关键情绪落点写死（推至眉眼/面部特写） | 内心震动/顿悟/压迫渐近/聚焦决意 | 推至特写时主体大幅转头转身＝崩脸 → 推近段动作收敛只留微表情；固定+推进互斥 | Seedance 官方词「推/缓慢推镜」；两平台皆优 |
| **缓慢拉远**（dolly out / pull back） | 「镜头缓慢拉远（pull back），从{近}渐变为{全/远}，人物渐小」+「主体始终居中」 | 孤立/渺小/判决落锤后的众生相/段落收束 | 跨度>3 档细节漂 → 叙事镜控制 2–3 档，大远景收尾给足 10s+；拉远新入画区必须被 `场景:` 覆盖（防穿帮） | Seedance 官方词「拉/拉远」 |
| **仰拍**（low angle） | 「低机位仰拍（low angle），镜头从脚部特写上摇（tilt up）至全身」／「低角度仰拍、广角透视、气势逼人」 | 权威/嚣张/威压/人物亮相 | 强广角怼近景脸＝五官畸变 → 透视强化只配全景全身；9:16 仰拍全身写「全身完整入画」防头出框；脚部起幅写标志物（靴/衣摆）防认错主体 | Seedance 官方词「低机位仰拍」 |

| **横移/环绕微弧**（lateral / orbit） | 「平稳横移（lateral tracking）掠过{对象}」／「缓慢环绕微弧（slow orbit）」 | 群像扫视/空间展示/凝视对象 | 环绕限幅：每 5s ≤ 约 30° 弧，超则变形（竖屏尤甚） | Seedance 官方词「移/环绕/平稳横移」 |
| **固定机位**（locked） | 「固定机位（locked shot），刻意凝滞（动机：{留白/压抑}）」 | 留白/凝滞/对峙僵持 | 纯静止须写动机（stage5 §3 铁律）；且守 M9 首末帧反差（靠主体姿态/光线造 delta） | API 可加 `--cf true` |

### 3b. 跟拍与氛围（tutorial 3 验证）

| 技巧 | 锁定触发写法 | 适用情绪/场景 | 失败模式 → 规避 | 平台注记 |
|---|---|---|---|---|
| **侧跟**（lateral tracking follow） | 「侧面跟拍（tracking shot），与主体平行移动，{景别}」 | 行进戏/离场/并肩同行——临场纪实感 | 快速跟拍＝空间扭曲背景拖影 → 写「缓慢/稳定」，烈度靠主体动作词；9:16 侧跟需前景掠过物（廊柱/灯笼/人群）才有速度感 | Kling 执行评级优秀；Seedance 官方词「跟随/跟拍」 |
| **后跟** | 「背后跟拍（follow from behind），保持固定距离」 | 跟随探索/背影叙事/悬念 | 同上；背影人物须给背面可辨特征（衣色/发型） | 双平台稳 |
| **前跟**（倒退跟拍） | 「镜头在前方倒退跟拍，正对主体面部」 | 情绪行进（边走边说/决意前行） | 同上 | 双平台稳 |
| **手持呼吸感**（修饰层） | 「手持镜头轻微呼吸感（subtle handheld），晃动幅度极小」——**叠在主运镜短语内**，如「侧面跟拍+轻微手持呼吸感」 | 纪实临场/不安/失从容 | 只写「手持/晃动」不带程度词＝晃过烈 → 必带「轻微/subtle」+负面词「剧烈晃动/画面抖动模糊」；高爆发动作（冲刺翻滚）改稳定跟拍 | 修饰层不算第二运镜；两平台皆验证 |
| **低机位贴地跟拍** | 「贴地低机位跟拍（low angle tracking），仰视主体前行」／「膝盖高度低机位，缓慢跟随，仰角全身」 | 强主角气场/坚定行进/仪式感 | **「机位0.3米」数值不可靠** → 定性锚（贴地/脚踝/膝盖高度）+「仰视」双保险；9:16 极限贴地易头顶出框 → 写「全身入画」或取膝盖高度；地面快移纹理扭曲 → 缓慢+写实材质（青石板/夯土） | I2V 须首帧即低机位构图（铁律 8） |
| **希区柯克变焦**（dolly zoom / 滑动变焦） | 「希区柯克变焦（dolly zoom），主体大小不变，背景被{拉伸后退/压缩逼近}」+ 主体近景表情剧变 | 认知崩塌/眩晕/世界观翻转/大惊变——**一部剧省着用** | 场景无前中后景分层必退化成普通推拉 → `场景:` 写明分层（前景{物}/中景主体/远景{物}）；双轴反向＝模型高难动作，绝不叠第三运动；4–6s 只够轻微效果，建议 6–10s；成功率天然偏低＝**抽卡镜**预留重试 | Kling 3.0 官方例句直接命名生效；Seedance 技术报告点名支持 |

### 3c. 特殊手法与速度感（tutorial 4+6 验证 + 补充）

| 技巧 | 锁定触发写法 | 适用情绪/场景 | 失败模式 → 规避 | 平台注记 |
|---|---|---|---|---|
| **荷兰角**（Dutch angle·构图修饰层） | 「固定荷兰角倾斜构图（Dutch angle），画面向{左/右}倾斜约15度，地平线倾斜」 | 失序/不对劲/黑化/刻薄狂态/心魔 | 不写「固定/保持」可能渲成滚转运动 → 写死「固定…构图·非滚转」；9:16 倾斜>20° 头脚出框 → 轻倾斜（10–15° 语义）+中景以上 | 官方词表外、模型语料内扩展词；Seedance/Kling 无官方背书、社区实例可用——按中风险用 |
| **第一人称 POV** | 「第一人称视角（POV），轻微呼吸晃动」**置镜头行最前** + 身体锚定：「{角色}右手自下入画{推门/摊开}」 | 主观代入/窥视/觉醒睁眼/灵识视角 | 无身体锚定＝镜头漂回第三人称 → 手/脚入画锚定；入画手做**简单动作**（推门/握物/抬手），复杂交互易崩手；POV 本人不得入画（锁定串只用于被看对象） | Veo 官方清单列 POV、Kling 3.0 官方确认、Seedance 社区专文六要素；竖屏适配最佳技巧 |
| **一镜到底**（one take·防切镜声明） | 「一镜到底，全程无镜头切换」（镜头行）+ 负面词「镜头切换/转场/跳切」 | **所有单镜的默认保险**；长调度/沉浸紧张感 | 动线过长（穿三空间）＝空间崩坏 → 15s 内 1–2 个空间节点；只写「长镜头」不写「无剪辑」仍可能被切 | 铁律 6 的正向落点；两平台皆需 |
| **甩镜**（whip pan） | 「甩镜（whip pan）向{右/高台方向}急甩，拖影中现出{对象+锁定描述符}」 | 惊觉回头/背后杀机/视线急转/双线转场 | 甩完换人＝甩丢主体 → 写死揭示对象及其锁定串；甩镜自含速度语义、禁再叠「快速」；9:16 水平甩行程短 → 可改竖甩/斜甩（甩向高台/天空） | Kling 中文指南评级「良好」；转场用法属衔接契约「运动承接」例外通道、须标 `衔接:` |
| **急速变焦**（crash zoom·高风险） | 「急速推镜（crash zoom），骤然推向{胸像/物件}特写」；**稳妥替代：两镜硬切模拟撞击（大远景→特写）** | 惊天发现/生理恐惧/骤然认出 | Seedance 官方系指南明示「避免急速变焦（易变形），用缓入缓出或焦点转移替代」；急推终点落面部＝崩脸高发 → 终点停胸像或物件；失败两次即降级硬切方案 | Seedance 高风险；Kling 可写「rapid」程度词——默认选替代方案 |
| **升格慢动作/变速**（slow motion / speed ramp） | 「升格慢动作（slow motion），{关键动作}毫厘毕现」／镜内变速：「常速{动作}，{命中一瞬}转慢动作，随即恢复」 | 武打命中/飞剑出鞘/尘土激荡/爆点回眸 | 变速点用**事件锚**（命中一瞬/落地刹那），禁秒数锚（时间码支持不稳）；整镜全慢拖节奏 → 慢动作只给 1–2 拍，或本镜纯慢+相邻镜常速；**慢动作镜原则上无台词或仅 OS**（口型灾难）；PA 折算：4s 慢动作≈1.5s 实际动作量 | AI 慢动作保真度**高于**快动作（天然友好）；Kling 官方模板直接用「以慢动作展现」 |
| **焦点转移**（rack focus） | 「焦点转移（rack focus）：焦点自{前景对象}移向{深处对象}，机位不动」 | 两层空间对话/发现/注意力引导——比运镜稳 | 前后景两对象都须在画且有锁定描述；一次转移一个方向，别来回拉 | Kling 3.0 官方能力清单内；Seedance 官方系指南推荐其替代急速变焦 |
| **延时摄影**（time-lapse） | 「延时摄影（time-lapse），云层飞速流动，{晨光→烈日→星河}轮转」；人物在场：「主体保持打坐静止，唯环境加速」 | 修炼时光流逝/伤愈七日/筹备昼夜 | 人物+延时同镜＝人被加速崩 → 主体近静止（打坐/站桩）只让环境加速；压缩比（一小时至15秒）是语义提示不校准；单镜日转夜光照可能断裂 → 重要镜拆两镜；给 10–15s 别塞 4s | Higgsfield 三变体佐证行业标准词；Kling 侧无专项实测（中档信心） |
| **高速跟拍+动态模糊** | 「高速跟拍锁定主体，背景放射状拉丝模糊，**主体面部清晰锐利**」 | 御剑疾飞/轻功追逐/疾驰突进 | **「1/50秒快门」无效** → 结果描述；模糊语义污染主体＝崩坏主因 → 每写背景模糊必成对写「主体清晰锁定」；负面词写「主体模糊」而非全局 blur；裸词「快速」禁用 → 疾驰/风压/拖影 | veed Seedance 指南标准负面「No motion blur on subject」；9:16 放射模糊聚两侧、竖屏友好 |
| **FPV 穿越/稳定航拍**（分开用） | 稳定航拍：「无人机贴地拉升至高空，揭示{全景}」；FPV：「FPV穿越机视角，掠过{檐角}俯冲向{对象}」——**路径动词（拉升/俯冲/掠过/穿过）最有效** | 史诗铺垫/大战俯瞰/开场定场（稳定航拍）；追击穿林/肾上腺素（FPV） | 「高度50米」当档位词弱有效 → 相对锚（贴地/离地丈许掠过/半空/云端）；裸写「无人机航拍」结果随机 → 必给路径动词+揭示对象；FPV 需密集参照物（门洞/林隙/檐角）否则显慢；航拍与人物特写不可同镜；**「大疆视角」品牌词无增益、不用** | Seedance 官方词「航拍镜头」（特殊镜里官方地位最高）；9:16 优先垂直维度调度（贴地拉升/正俯直下/垂直俯冲），少横扫地平线 |

## 4. 9:16 竖屏适配速查（R3）

- **荷兰角**：轻倾斜（10–15° 语义）+ 中景以上；全身镜慎用大角度。
- **航拍**：优先垂直维度（贴地拉升/正俯直下/垂直俯冲）；避免横扫大地平线；宏大靠**纵深**（长街纵深延伸/群山层叠远去）不靠横宽。
- **FPV**：选纵深密集路径（门洞/长街/檐角下坠），少横向蛇形。
- **甩镜**：水平行程短 → 竖甩/斜甩（甩向高台/天空异象）。
- **POV**：手自下方入画与竖屏天然吻合——竖屏适配最好的技巧。
- **延时**：天空占比大＝云层/星河效果放大。
- **高速动态模糊**：放射模糊聚于人物两侧、速度感更聚焦——竖屏友好。
- **横画幅例句移植**：「左右横移揭示」类优先改「纵深推进/垂直升降揭示」。
- **低机位/仰拍**：竖屏易头顶出框 → 「全身完整入画」或抬高到膝盖高度。

## 5. 在流程里的落点

- **stage5 分镜**：§3 情绪→运镜映射表扩充行（嚣张仰拍/失序荷兰角/惊觉甩镜/时光延时/希望金时逆光…）由本库支撑；每镜先情绪后机位不变；`镜头:` 按铁律 1 三段式落笔。
