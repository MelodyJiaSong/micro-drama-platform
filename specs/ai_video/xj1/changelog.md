实测并落进规则的事实:
- **即梦 image prompt 硬限 1600 原始字符（含换行）**，不是 2000。1627 字直接被拒
  （ret=1046 / limited len: 1600）。**被拒不扣积分**（210→210）。
  已改 `agent_refs/project/ai_video.md` rule 4e ⑤：窗口 1500–1600，并写明计法是含空白的原始字符
  （同段 prompt 去空白 1569 / 原始 1627，两种数法差 60 字，按去空白自检必踩线）。
- 单张 2k/5.0 = **3 积分**。本轮共出 5 张（含 1 张返工），210 → 195。
- ≥1500 下限只适用 **scenes/ 下零参考的自由生成锚点**；挂参考的派生锚点与 props/characters 锚点不适用
  （rule 4e ⑤ 的理由就是「唯一零参考的自由生成」）。已写进工具的 `is_free_anchor`。

两个真缺陷（都已修）:
1. **轮询失败会白烧积分**：bg2 首次提交返回 `get_history_by_ids failed: ret=1015`，工具丢掉了
   submit_id，但积分已扣（207→201）。即梦是**提交即扣费**，重新提交＝为同一张图付两次。
   工具改为：拿不到 URL 就保留 submit_id 重查（6 轮 × 20s），绝不重新提交。那张图已用
   query_result 捞回。
2. **主角道具不能写进场景锚点**：bg2 首版在场景 prompt 里写「床头斜靠自己削的木剑」，
   模型按「剑」的通用先验画成了**金属真剑**（西式护手 + 镶宝石柄）。改为道具独立成卡，
   场景卡只写地方，并把最可能画错的方向写进负面词（金属剑/护手剑格/西式长剑/镶宝石剑柄）。
   返工后木剑正确（柴刀削面、钝尖、麻绳缠横木护手）。

c1_李逍遥 卡的两段 prompt（2177 / 1922 字）超出 1600 新限，已用 `> gen:` 标注排除在自动批次外：
立绘块指向保留的成品图，turntable 块是视频 prompt 本就不该进出图工具。要重生必须先压到 ≤1600。
