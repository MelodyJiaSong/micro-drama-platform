# raw_prompt — 荒野造家

我们要拍摄一个新系列短剧，是野外盖房子的，主题是一个男子，到完全原始的环境中，比如雨林，森林里，自己搭建自己的避难所，吸引观众的点一个是纯野外的风景，自己搭建避难所，当面对雨天，躲在避难所里的安逸和外界的对比，还有你帮我想想其他此系列可能吸引人的要素，你可以问我问题，propose，然后我来回答，我们先选一个场景，拍摄这个系列的第一部短片，时长几分钟 16:9，发布是 youtube 和 tiktok 还有抖音。

## 阶段 1 立项问答（2026-09-06）

- **场景 / 生物群系**：东南亚热带雨林。
- **声音与解说形态**：纯环境音，全程无人声。
- **主角呈现**：不用担心一致性，按拍摄要求来，重点是要突出环境，还有野外住所等吸引人的地方。
- **第一集范围 / 时长 / 画幅**：约 4 分钟，只做 16:9，不出竖版。
