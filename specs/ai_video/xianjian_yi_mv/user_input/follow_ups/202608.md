### 四个会静默失效的坑（实测踩出，全部无报错）

1. **`--factory-startup` 会关掉 MPFB**。MPFB 依赖用户偏好里注册的扩展，报错是 `MPFB_CONTEXTUAL_INFORMATION` 为 None。**代价：带 MPFB 的 previz 不能用 `--factory-startup`**，而 A 档引擎正是靠它保证跨机器可复现。要么放弃这条确定性保证，要么把 MPFB 产物一次性导出成固化网格资产。
2. **顶点组是绑骨之后才生成的**。绑骨前只有 152 个 MakeHuman helper 组，绑骨后才有 291 个含 `head` / `breast.L/R` / `pelvis.L/R` / `neck01-03` 的权重组。绑骨前按名字找组 → 静默找不到、后处理全部跳过。
3. **体型是 shape key 驱动的**。直接改基础网格顶点会被 shape key 盖回去——不报错、不变形，只是没效果（身高一模一样即证据）。任何网格后处理必须先烘焙（`shape_key_add(from_mix=True)` 后删光所有键）。
4. **中性化必须「删除+替换」，不能「形变」**。把头部顶点整体投到椭球上会把口腔、眼窝、耳朵等内部结构一起拍到表面，产生自交与破洞，比原样更糟。正确做法：`bmesh` 删掉头部顶点，另挂一个光滑椭球并 **parent 到身体**（不 parent 的话身体摆位后头会留在原地）+ 单独赋同色材质。
