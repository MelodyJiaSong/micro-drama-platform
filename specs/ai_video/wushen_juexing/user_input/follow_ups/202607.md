1. **脸色/肤色变化不是可用的表演手段——一律不写。** 模型渲染不了细腻的生理性血色变化；任何"脸色变白/涨红/血色褪去"指令，即使写成带时间轴的单向一次性过程，成片仍会被放大成变色特效。prompt body 一切肤色措辞清零，情绪 100% 由非颜色层承载（肌肉紧绷 + 呼吸 + 眼神 + 身体），并显式写死「面部肤色全程恒定不变」+ `光线:` 禁改变肤色的光 + `负面词` 逐条封死。
2. **锁定描述符必须从角色卡复制粘贴，禁凭印象手写。** 手写的简写「语义上像、字面上全错」，跨集造型就此漂移；且这种形态**人眼审读必然漏**（读着都对），必须靠逐字 diff 的机械校验兜底，并在新集分镜完成 + 出片前各跑一次全剧。
