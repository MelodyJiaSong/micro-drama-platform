# 魔兽世界 · 三模块 POC

从头开始 EP1。旧剧情、分镜、prompt、创作访谈与旧阶段文档退出并删除。
保留 Research 和人物、场景、物件等资产，独立于创作主线。
故事创作 → 影视改编 → Prompt 编译；每个模块最初只保留必要输入输出。
一次只改善一个模块；固定输入、比较标准与版本，下游不能自行改上游。
UI用三个模块展示内容与状态；Research和资产独立导航，不再显示0–6阶段。
从简单小型POC开始，逐步增加经过验证的改进。故事方向与篇幅待本轮用户选择。
左侧导航固定为0_research、1_资产库、2_故事、3_影视改编、4_prompt编译；没有“EP1 创作”独立入口。2/3/4为可展开stage，当前暂按stage→EP1组织；点击stage仅展开，选择子项进入具体内容。
