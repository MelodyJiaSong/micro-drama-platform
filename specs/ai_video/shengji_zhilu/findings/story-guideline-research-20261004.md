# 连载与原作改编：AI 剧情规则研究

日期：2026-10-04。目标：把用户提供的Eric Edson讲课转成适用于《魔兽世界》及其他剧的简练创作规则；支持边拍边扩展、原作主线和适度补写。
执行：主代理检索、读原文与综合；本次是规范研究，不生成EP、不启动软件六阶段、不声称独立观众验收。规则唯一正文在[共用指南](../../../../.agents/references/project/story_guidelines.md)。

## 结论与讲课适用范围

按上一条摘要的8组统计：3组保留基本机制，4组调整适用方式，1组不作硬规则。7/8是分组计数，不是科学适用率。

| 原摘要组 | 裁定 | 连载应用 |
|---|---|---|
| 结构组织情感 | 保留 | 用因果、期待与兑现组织内容；不宣称某结构必然感动所有观众。 |
| 主角、目标、对抗 | 调整 | 可群像；目标须可辨认结果；代价可很小，对抗可来自人、环境、制度或内在冲突。 |
| 行为表现内心 | 保留 | 正文可有内心；重要人物变化准备好行为依据，影视改编再转成可见/可听内容。 |
| 先定结尾及支点 | 调整 | 定当前集结果及当前阶段暂定落点；长期只锁原作关键锚点，无需先写全剧终局。 |
| 三幕与成长 | 调整 | 作为可选组织法；转折可跨集，人物不必每集由幼稚变成熟。 |
| 诱发事件与两次大转折 | 调整 | 区分启动问题与改变推进方式；按阶段需求设置，允许安静揭示，无固定每集数量。 |
| 主角目标序列 | 保留 | 采用短期目标—行动—新情况；新情况也可为结果/代价，不固定页数。 |
| 固定序列数量 | 不采用为通则 | Edson本人限定单主角商业美国电影；检索到的是作者方法及示范，未发现支持跨媒介普遍必然性的验证。 |

上述对Edson的范围判断来自[作者本人对方法的定义](https://www.thestorysolution.com/character-writing/)。讲课称通常3–7页；当前作者网页称通常2–8页，进一步说明不应把页数当连载硬门槛。

## 研究角度与推导

### A. 结构究竟约束什么

《诗学》要求情节联系与转折来自事件自身，适用对象主要是古希腊戏剧，不宜把其中所有规定当现代题材通则。[情节与转折](https://classics.mit.edu/Aristotle/poetics.1.1.html)、[人物与解决](https://classics.mit.edu/Aristotle/poetics.2.2.html)。
Screen Australia把故事文件用于不同媒介，讨论问题、选择、递进、揭示与反转，明确没有统一格式。[官方指南](https://www.screenaustralia.gov.au/wp-content/uploads/2025/08/Story-Documents-Drama-1.pdf?v=1775615762)。
**本次推导**：保留因果与结果检查，放弃固定幕数、固定页数及“持续最大冲突”。紧张与舒缓按内容交替。
未研究：没有做全体成功电影统计，不能验证固定数量或结构与票房之间的因果关系。

### B. 连载怎样边做边写

Mittell讨论累计叙事以及单集故事与跨集线索并存；BBC《Doctors》编辑介绍单集事件如何结合持续人物线。[Complex TV原著章节](https://mcpress.media-commons.org/complextelevision/complexity/)、[BBC编辑访谈原文](https://downloads.bbc.co.uk/academy/academyfiles/Writing_TV_Drama_BBC_Academy_Podcast_Transcript_%5B230217%5D.pdf)。
**本次推导**：区分长期方向、阶段落点和单集推进；细化当前范围，后续保留空间。用当前结果承接下一集，既不无限拖延，也不要求每集解决全部问题。
未研究：尚无本项目真实观众反馈，不能规定最佳集长、反转频率、伏笔期限或每季集数。

### C. 游戏怎样转为观看故事

Blizzard设计师回顾区域故事、连通的世界、线性任务限制与动态目标；Kaplan说明任务如何带玩家穿行世界。[Kosak官方回顾](https://worldofwarcraft.blizzard.com/en-us/news/4488899/cataclysm-post-mortem-quest-design-with-dave-fargo-kosak)、[Kaplan本人访谈约01:57](https://lexfridman.com/jeff-kaplan-transcript)。
Jenkins区分空间体验、局部事件、环境线索及更大的目标，指出游戏有自身的叙事组织方式。[作者MIT原文](https://web.mit.edu/~21fms/People/henry3/games%26narrative.html)。
**本次推导**：保留任务背后的矛盾、人物职责、关键结果和区域联系；把操作循环改写为选择与后果。原创人物可以影响局部事件，不必取代原作英雄。世界辨识度来自设定参与因果，不能只贴地点名。
未研究：本次未逐项复核魔兽任务、NPC与时间线；上述设计访谈不是Classic具体剧情证据。GDC2009页面仅读到会议信息，未观看演讲，不以其内容作论据。

### D. 奇幻、能力和反转怎样保持可信

Sanderson本人说明其方法是经验指南：解围能力应让读者有理解基础；限制与代价提供冲突；优先深化已有设定。[第一法则](https://www.brandonsanderson.com/blogs/blog/sandersons-first-law)、[第二法则](https://www.brandonsanderson.com/blogs/blog/sandersons-second-law)、[第三法则](https://www.brandonsanderson.com/blogs/blog/sandersons-third-law-of-magic)。
Writing Excuses区分发生事情与朝承诺推进，并用具体写作例子讨论结尾兑现与前置铺垫。[进展感](https://writingexcuses.com/writing-excuses-10-31-how-do-i-control-the-readers-sense-of-progress/)、[兑现承诺](https://writingexcuses.com/writing-excuses-5-19-fulfilling-promises-to-your-readers/)。
**本次推导**：关键解法必须有资源与条件，揭示须有依据；新敌人、新能力与更大危机不是续集的默认燃料。死亡、复活、传送等按选定世界规则处理，不把玩家重复操作直接当剧情事实。
未研究：不证明软魔法、偶然性、开放结局或实验叙事无效；这些需项目明确选择其表达方式。

### E. AI怎样持续写且不混淆事实

Re3用计划、当前故事状态、续写选择和一致性修订改善长文本生成；论文报告特定实验条件下的改善，并非保证所有模型有效。[EMNLP2022论文与全文入口](https://aclanthology.org/2022.emnlp-main.296/)。
补读2025–2026研究的作者摘要：STORYTELLER以事件节点和实体状态组织生成；ConStory-Bench检测长文一致性并要求文本证据，报告事实与时间维度的突出问题。[STORYTELLER](https://aclanthology.org/2025.findings-acl.1071/)、[Lost in Stories](https://arxiv.org/abs/2603.05890)。
中英小说评测研究报告AI与人类作品差异，自动评测与人评仅达到中等相关；另一项续写重排序实验未发现所比较评分法在人评一致性上的显著总体差异。[文学评测](https://aclanthology.org/2025.findings-acl.1114/)、[评分方法对照](https://aclanthology.org/2025.in2writing-1.10/)。这些结果不能直接推算本项目的改进比例。
**本次推导**：每次显式提供选定事实与已确定状态，先写骨架再正文，检查附证据。事实、推断与原创分开；候选不自动进入世界事实。
未研究：没有在本项目做模型对照实验，未验证新版规则优于旧规则；语义审查需要判断，不能宣称自动检查或逐字确定。

## 魔兽世界的最小落地

| 输入 | 本项目裁定 |
|---|---|
| 游戏主线 | 用户已明确：以游戏剧情为主线，允许适当改变与增加；适用于之后剧情创作。 |
| 版本 | 现有W02资料声明Vanilla/Classic Era、1.12口径；作为后续选资料的暂定候选，不等于用户确认，也不自动采纳其旧剧情建议。 |
| 长期锚点 | 从选定原典提取事件/矛盾、关键人物职责、结果及先后依赖；以相关原典来源核验后写入新输入。 |
| 可补写空间 | 过渡行动、普通人视角、对白、关系与局部冲突；补写保留原作核心因果。 |
| 需明确记录的偏离 | 关键人物生死、重大胜负、阵营关系、标志事件归属、主线顺序等改变；不将“适当增加”解释为全面改写。 |
| 暂定实现方式 | 先定当前区域阶段落点，再按实际内容分EP；不预设全剧集数，不沿用旧救援剧情或当前候选角色。 |

旧W02只作为已有资料的范围依据：[现有北郡资料](../../../../ai_videos/shengji_zhilu/0_research/parts/w02_北郡新手谷.md)。其知识尚未因本次研究转为已接受事实。
纯改名字测试：若删去专名后整段矛盾、行动条件和结果都不变，检查是否只有世界皮肤；这是一项诊断启发，不能单凭它淘汰普遍人性情节。
