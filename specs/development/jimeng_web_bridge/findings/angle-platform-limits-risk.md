# Angle: platform-limits-risk — 即梦网页版的上限、成本与账号风险

> 调研日期 2026-09-13。2026-02 到 2026-08 之间，即梦的价格和档位至少改了 4 次，所以下文每个数字都带日期。
> 标注：〔社区〕= 媒体或社区实测、非官方；〔第三方〕= API 聚合商文档；〔摘要〕= 只见于搜索摘要、原页没能打开核对。

## 1. 本 angle 覆盖范围

队列、预检、积分预估和暂停逻辑必须写进去的平台事实，包括：
- 会员档位与积分定价
- 网页端生成上限：时长、分辨率、参考素材、并发
- 人物主体
- 输出与保留
- 协议条款与风控触发点
- 网页版和火山方舟 API 的每秒价差（这是本项目立项的动机）

## 2. 关键发现

### 2.1 会员与积分（子问题 1）

| 项 | 数值 | 日期 / 来源 |

| 每月积分（04-08 调整后） | 725 / 2210 / 6160（调整前 1080 / 4000 / 15000） | 2026-04 [S3][S4] |
| 首年年费（04-08 后，6 折） | 379 / 1449 / 3099 元；续费价更高 | 2026-04-20 [S3]；续费翻倍 [S6] |
| 免费用户每日赠送 | 66 积分，当日失效 | [S7]〔社区〕；当日有效见付费协议 4.2.2(2) [S2] |
| 订阅积分有效期 | 每 30 日一个周期，下个周期发放时清零 | 付费协议 4.2.2(1)，2026-08-10 生效 [S2] |
| 充值积分 | 1 元 = 10 积分，有效期 2 年 | 汇率 [S27]〔摘要〕；2 年有效见 4.2.2(3) [S2] |

**折算单价**：每积分约 0.04 元（首年年付，按上表推算）到 0.10 元（充值或月付）。

| 视频模型 / 通道（网页） | 积分 | ≈积分/秒 | 日期 / 来源 |
|---|---|---|---|
| Seedance 2.0 标准版 720p | 5s≈40；15s≈90；免费档 8s=64 | 6–8 | 2026-06-16 [S7]、2026-08-25 [S8]〔社区〕 |
| Seedance 2.0 VIP 通道（免排队） | 5s=70；15s=210 | 14 | 2026-04 起 [S3][S9] |
| Seedance 2.0 Mini | 5s=45（比标准版还贵，原文如此，存疑） | 9 | 2026-06-16 [S7]〔社区〕 |
| Seedance 2.5 720p | 5s=130；15s=390；30s=780 | 26 | 2026-07-31 记者实测 [S9]〔社区〕 |

- **2026-03 到 04 连续涨价**：一条 15s 视频从 45 涨到 120 积分；VIP 加速从 45 涨到 210 积分。有报道称计费向上取整，"5 秒按 9 秒计" [S3]〔社区〕。
- **图片积分**：即梦图片 4.5 一组 4 张 2K，免费用户扣 2 积分，会员免费（约 2025-12，数据偏旧）[S24]〔社区〕。**没有找到** Seedream 5.0 在网页端的积分数字。
- **生成失败或审核不通过是否退积分：没有找到官方说明。**
  - 付费协议 5.4 只写"原则上不支持无理由退款"，只有"系统故障导致重复扣款"等情形可以申请 [S2]。
  - App Store 评论里有人抱怨"生成失败，积分也不退" [S28]〔摘要，孤例〕。

### 2.2 网页端生成上限（子问题 2）

| 项 | Seedance 2.0 | Seedance 2.5 |
|---|---|---|
| 时长 | 4–15 s，整数 [S12] | 单段最长 30 s；另有长视频模式，最长 3 min [S14][S15] |
| 分辨率 | 480p / 720p / 1080p；1080p 仅标准版，Fast / Mini 最高 720p [S12] | 480p / 720p，**没有 1080p** [S15] |
| 比例 | 16:9、4:3、1:1、3:4、9:16、21:9、adaptive [S12] | 没有单独查到 |
| 参考素材数量 | 图 ≤9、视频 ≤3、音频 ≤3，合计 ≤12；视频和音频 ≤15 s [S25][S13] | 图 ≤30、视频 ≤10、音频 ≤10 [S9][S14] |
| 单文件限制 | 图 <30 MB（另一份第三方写 10 MB，来源冲突）；视频 <50 MB；音频 <15 MB；jpeg/png/webp、mp4/mov、mp3/wav；图片边长 300–6000 px，宽高比 0.4–2.5 [S13][S12] | 没有找到 |
| 帧率 | 24 fps [S12] | 24 fps [S15] |

- **@ 引用写法**：教程统一用 `@图片1 / @视频1 / @音频1`，按上传顺序编号 [S25]〔社区〕。
- **Prompt 长度**：第三方 API 文档写"中文 ≤500 字 / 英文 ≤1000 词"[S12]〔第三方〕。**网页端的硬上限没有找到**。仓库规则"≤5000 字"找不到任何平台出处。
- **并发**：2026-03-03 即梦发通知"限制最大并行任务数"，但**具体数字没有公开** [S5]。
- **排队**：
  - 2026-02 到 04 普遍要排 3–11 小时 [S6]；个别报道到 68 小时 [S11]。
  - 业内说法是"工作日排队、周末不排" [S4]。
- **API 侧**：结果 URL 24 小时后失效，任务记录只能查最近 7 天 [S23]。

### 2.3 人物主体（子问题 3）

- **功能存在**："创建主体 / 添加主体"。教程写法是上传正面清晰图（可以多角度），把"角色细节匹配度"调到 80–100% [S18]〔摘要〕。
- **真人限制**：2026-02-09 起网页端"暂不支持输入真人图片或视频作为主体参考"。真人出镜要在 App 里录本人形象和声音，做活体校验 [S17]。
- **写实人脸**：审核很严，AI 生成的写实人像也可能被拦 [S13]〔社区〕。
- **没有找到**：是否需要 turntable 视频、审核时长、数量上限、命名规则、能否与全能参考同时使用、prompt 里怎么引用主体。

### 2.4 输出（子问题 4）

- **水印**：会员权益包含"生成/下载作品去除品牌水印"（付费协议 4.1.1(1)）[S2]。免费用户带水印，最高 720p [S19]〔社区〕。
- **AI 标识**：《人工智能生成合成内容标识办法》2025-09-01 起施行，下载文件必须带隐式标识（元数据），禁止删除或篡改 [S20]。
- **编码与网页端历史保留期**：**没有找到公开说明**。

### 2.5 条款与风控（子问题 5）

- **用户服务协议**（2025-08-25 更新，2025-09-01 生效）[S1]：
  - **5.1** "不得……使用任何自动化程序、软件或类似工具接入即梦AI"。这是**直接禁止**，不属于灰色地带。
  - **5.3(4)** 禁止"模拟下载"。
  - **3.5** 账号仅限本人使用，禁止出借或出租。
  - **7.1** 处罚最重到"永久关闭账号、禁止重新注册"。
- **付费服务协议**（2026-08-10 生效）[S2]：
  - **6.5(1) + 8.2** 用机器人、爬虫、刷屏软件获得的权益可以作废，账号可冻结或永久封禁。
  - **4.1.2(3)** 限制同时在线的终端数量。
- **内容权利**：
  - 9.2 生成内容的知识产权归用户。
  - 9.3 / 9.4 用户授予字节全球、免费、可再许可的权利，可以用输入和生成内容"优化产品服务及模型" [S1]。
- **封号案例**：**没有找到**因浏览器自动化被封号的公开案例。逆向 API 项目 jimeng-free-api 自己在 README 里提示有封号风险 [S21]。
- **可观察的拒绝提示**：
  - 敏感词会提示"输入的文字不符合平台规则，请修改后重试" [S22]。
  - 写实人脸素材上传会被拒 [S13]。
  - 验证码或风控弹窗的公开描述**没有找到**。

### 2.6 官方 API 价格与价差（子问题 6）

Token 计算公式：(输入视频时长 + 输出时长) × 宽 × 高 × 24 / 1024 [S16]。按这个公式，720p 16:9（1248×704）约 20,592 tokens/秒；15s 共约 30.9 万 tokens，与 [S26] 的数字一致。

| 模型 | API 单价（不含视频输入 / 含视频输入） | API ≈元/秒 | 网页 ≈元/秒（积分/秒 × 0.04–0.10 元） |
|---|---|---|---|
| 2.0 720p | 46 / 28 元每百万 tokens（2026-03-04）[S26][S8] | ≈0.99 | 标准排队 0.24–0.80；VIP 0.56–1.40 |
| 2.0 1080p | 51 / 31 元每百万 tokens [S8] | ≈2.48（与 [S12] 的 5s ¥12.39 一致） | 没有找到 1080p 的积分数 |
| 2.5 720p | 70 / 42 元每百万 tokens（2026-08）[S15][S16] | ≈1.51 | 1.04–2.60 |
| Seedream 图片 | 约 0.2–0.3 元/张 [S29]〔第三方 / 摘要〕 | — | 会员约 0 元（4.5，偏旧） |

- **第三方横评**：腾讯新闻 2026-04-25 实测，即梦最高档约 1.38 元/秒，在 7 款工具里最贵 [S10]。bianews 称 4 月调价后网页端约 1.1 元/秒，**已高于 API 的约 1 元/秒** [S11]〔社区〕。
- **官方价格页没能直接核对**：火山方舟的"模型价格"页是 JS 渲染，WebFetch 读不到数字，所以上表 API 价格来自媒体转述的官方公告。2.0 Fast 的 API 单价各来源说法冲突，没有列入。

## 3. 对 spec 的影响

1. **"网页比 API 便宜得多"只在部分条件下成立**（依据 2.6 的推算）。
   - 成立：2.0 标准通道排队 + 年付，约便宜 1.2–4 倍；会员生图基本不花钱。
   - 基本持平：VIP 免排队通道。
   - 持平或更贵：2.5 720p。
   - spec 应把这一点写成**待用户按实际档位确认的假设**。service 要按 job 记录实际扣的积分，算出真实的元/秒。
2. **积分预估以页面自报为准**。页面自己显示或网络响应里的预估积分是权威值。静态价目表放在带 `as_of` 日期的配置文件里，只在预检阶段兜底；确认环节同时展示两个值，偏差大时提示。
3. **预检按模型查表，不写死一个值**。
   - 2.0：时长 4–15 s 整数，1080p 只有标准版。
   - 2.5：时长 ≤30 s，最高 720p。
   - 参考素材数量、单文件大小、格式按所选模型校验。
   - Prompt 上限做成可配置。网页端实测前，超过 500 中文字先告警，**不要照搬 5000 字**。
4. **"质量优先 + 最高分辨率"本身有冲突**：16–30 s 的镜头只能用 2.5，而 2.5 最高 720p。spec 必须写死决策顺序。建议（属个人意见）：先看时长能否放下 → 再选模型 → 最后取该模型允许的最高分辨率，并在确认环节显示选择结果。
5. **VIP 免排队通道是成本开关**：同样时长积分约为标准通道的 2.3 倍。默认关闭，按次开启，并在确认环节单独列出。
6. **积分退还规则未知**，按"不退"设计：
   - 每次提交前后和任务结束时都读一次积分余额，写进 job 记录，用实测结果回填退积分规则。
   - 结果状态不明的提交**绝不自动重提**，要先查历史记录确认。
   - 审核拒绝记为单个 job 失败，不自动改写 prompt 重提。
7. **超时按"小时"计**：排队几小时是常态。等待超时建议 ≥12 小时；服务重启后恢复轮询，而不是重新提交。
8. **并发上限未知**：默认 1，可配置。页面提示"并行任务已达上限"时视为背压，等待再提交，不按错误处理。
9. **暂停规则分两级**：
   - 暂停**整个队列**并弹 toast：登录失效、验证码或风控弹窗、积分不足、页面结构对不上。
   - 只让**单个 job** 失败、交人处理：审核拒绝、真人素材被拒。
10. **账号风险要显式接受**：用户协议 5.1 明文禁止自动化工具接入。spec 应写明这是用户知情接受的风险，并尽量减小暴露面：
    - 单账号，单台机器上一个持久化浏览器 profile（协议限制在线终端数）。
    - HTTP / MCP 只绑定 127.0.0.1。开放给他人使用，可能落入 3.5 / 6.2 的"许可他人使用账号"。
    - 按人的节奏间隔提交，设每日积分预算上限。
    - 不轮换账号，不做任何对抗检测。
11. **人物主体素材**：写实风角色立绘可能被当作真人拒绝，预检发现不了。收到拒绝后走人工处理；README 提醒角色图尽量非照片级写实。
12. **下载**：保留原始字节，不剥离元数据（标识办法要求隐式标识）；记录是否带水印（取决于会员状态）。README 注明上传素材按协议 9.3 授权字节用于优化模型。

## 4. 未解问题

- 网页端各档位的**并发 / 同时生成数**具体是多少？
- 审核拒绝或生成失败后**积分会不会退**？
- 网页端 **prompt 长度硬上限**：是 500 字还是更多？超长时是截断还是拦截？
- 人物主体：
  - 输入只要图片，还是需要 turntable 视频？
  - 审核要多久？数量上限、命名规则？
  - 能否在 2.5 和全能参考中使用？prompt 里怎么 @ 主体？
- 2.0 1080p 和 Seedream 5.0 在网页端各扣多少积分？
- 网页端历史保留多久？下载链接会不会过期？
- 用户实际是哪一档、月付还是年付？这决定价差动机是否成立。
- 页面的预估积分和余额能否从网络响应里被动读取？交给 page-anatomy angle 确认。
- 火山方舟官方价格页没能直接核对，API 单价来自媒体转述，落地前应由人工再核一遍。
