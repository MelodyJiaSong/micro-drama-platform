# 系统与集成验证

这是待执行的验证设计，`complete` 表示清单完成，不表示下载实测通过。同一工人同时负责紧密关联的 unit_tests 层。

## 环境与证据

使用项目自己的 .venv、真实 yt-dlp、FFmpeg/ffprobe、受支持的 JS 运行时和真实 Tk。记录版本、测试命令、退出码、最终文件路径、ffprobe JSON、任务 PID 及清理结果；运行事件由主代理按 validation playbook 写入。可用 pip 运行，不能只依赖 uv。Windows 上直接验证原生进程控制；仅 POSIX 的信号测试明确标记跳过。

## 场景

| 编号 | 设置与动作 | 用户契约断言 |
|---|---|---|
| SYS-01 本机视频下载 | FFmpeg 生成带声音的短 MP4，再生成分离音视频的 DASH 小片；真实本地 HTTP 服务提供素材，调用下载适配器的集成入口、真实 yt-dlp 和 FFmpeg。 | 合并后文件存在；ffprobe 可读取视频和音频；容器为 MP4；报告路径指向最终文件。HTTP 测试只验证下载边界，不放宽 GUI/CLI 的 YouTube 域名校验。 |
| SYS-02 MP3 | 同一 HTTP 素材通过真实下载适配器选择 MP3 并执行后处理。 | 最终文件为 .mp3，ffprobe 的音频 codec_name 为 mp3、无视频流；下载结束后仍显示转换状态，转换完成才报告成功。 |
| SYS-03 上限与文件保护 | 测试素材提供至少两档高度；选定上限下载。第一次生成完整输出，记录 SHA-256，再以相同输入重复下载。 | 最终视频高度不超过所选上限；没有符合格式时报真实错误；既有完整文件哈希、长度不变，不用空文件替代；任何跳过或另存行为如实显示。 |
| SYS-04 真实取消树 | 限速 HTTP 提供较长素材，确认任务与分片已出现后取消；再覆盖 FFmpeg 后处理期间取消。旁边启动一个独立无关进程。 | 本任务及子进程全部退出，无关进程仍存活；已产生的分片保留且不继续增长；不出现完成状态。重复下载可复用分片；恢复失败保留真实错误。 |
| SYS-05 Tk 主流程 | 真实 Tk 事件循环启动窗口，驱动粘贴、选择目录/质量、启动、进度、取消、重试及关闭。可用测试应用层替身产生事件，另以真实集成任务覆盖下载路径。 | 窗口持续处理事件；下载时不能启动第二任务；控件更新只发生在创建 Tk 的主线程；工作线程不会直接修改控件；取消不阻塞事件循环；关闭不遗留本任务进程。错误/成功终态后按钮恢复。 |
| SYS-06 CLI | 启动真实 CLI：有效 YouTube 链接、非法链接、含 list 的单视频链接；在活动下载中发送 Ctrl+C。 | 非法链接启动下载前失败且无网络调用；list 不触发列表下载；取消返回非零并清理本任务进程；GUI/CLI 共用的选项行为一致。 |
| SYS-07 失败链 | 隔离依赖路径分别移除 FFmpeg、ffprobe、JS 运行时；使用不可写目录和产生网络/后处理失败的 HTTP 素材。 | 缺失项有具体安装提示；权限与真实进程错误可见；下载进度 100%、退出码 0 但最终文件缺失均不能显示完成；失败不改已有文件。 |
| SYS-08 配置与登录 | 在隔离的用户配置目录放置改变输出/列表行为及执行哨兵命令的 yt-dlp 配置；默认下载一次，再显式选择浏览器下载一次。 | 用户配置未生效且哨兵未执行；默认无 cookies 读取；显式选择才传递浏览器读取选项；浏览器失败不被吞掉。凭据与 HTTP 密钥不进入测试证据。 |
| SYS-09 真实 YouTube | 在用户可访问网络中使用获授权的公开视频，经 GUI/CLI 验证视频与 MP3；不自动使用账号、代理或绕过限制。 | 成功时保存 ffprobe 与界面终态证据；失败时保存脱敏错误、版本和阶段，标记“真实 YouTube 未通过/环境阻断”。本地 HTTP 通过不能代替此项。不能把站点限制记为成功或声称所有链接可下载。 |

## 判定与人工项

契约断言失败是 blocker；未启动、Tk 回调异常及无任务可用的启动故障阻止验收。涉及凭据泄露或越界终止的安全问题交 security 层按 critical 处理。真实 YouTube 环境阻断单独记录，允许说明本地集成通过，但不能盖端到端下载通过章。缺少依赖/Tk/真实环境必须标记未执行及原因。

自动化后仍需 `validation.requires_manual_walkthrough`：中文文本、目录选择、进度可读性、键盘焦点、实际响应感受，以及用户网络中的下载。规格明确没有 Web/API 运行模式，故以真实 Tk 与 CLI 两种入口替代浏览器验收；频道/整个列表和受限内容成功下载不纳入承诺，失效错误仍验证。
