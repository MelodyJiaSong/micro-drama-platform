# 单元验证

这是测试设计，尚未执行；同一真实工人负责 system_tests 与 unit_tests。以用户输入和任务状态契约为断言，不复制实现分支作期望值。

| 名称 | 输入与边界 | 期望 |
|---|---|---|
| URL 接受与规范化 | watch、Shorts、live、embed、youtu.be 合法 11 字符 ID；watch 带 list；前后空白。 | 得到同一单视频标识；list 不扩大范围；只输出批准的规范链接。 |
| URL 拒绝且无调用 | youtube.com.evil.example、用户密码 URL、非 HTTP(S)、纯播放列表/频道、缺失/过短/非法字符 ID。 | 类型明确的校验错误；下载适配器、浏览器 cookies 读取和网络边界调用次数为零。 |
| 参数契约 | 最佳、各档高度上限、MP3、带中文和空格的目录及标题；默认与显式 Chrome/Edge/Firefox。 | 参数数组无 shell；单视频和配置隔离始终生效；质量筛选约束所有回退分支；默认无浏览器读取；显式选择只使用对应浏览器。 |
| 完成判定 | 成功码+存在文件；非零+文件；成功码+缺失文件；仅下载 100%；转换阶段错误。 | 只有成功码且最终文件存在才完成；其余保持处理中或失败。最终路径来自后处理结果，不凭标题/扩展名猜测。 |
| 状态与一次一任务 | 空闲→解析→下载→后处理→完成/失败；处理中重复启动；各阶段取消、重复取消；前次任务迟到事件。 | 活动任务不可被第二任务覆盖；取消幂等且不能转完成；前次事件不污染新任务；终态恢复可启动。 |
| 事件消费与 Tk 边界 | 工作线程送进度/错误/最终路径事件；异常字段、未知进度值；真实日志样本含 Unicode 和控制字符。 | 主线程消费事件并更新展示；缺失 ETA/速度显示未知而不崩溃；错误日志保留原因；解析不把普通日志伪装成成功。真实日志样本从 SYS-01/02 的输出收集，避免只用手写上游文本。 |
| 取消归属 | 本任务 PID、其子进程、无关 PID、已退出 PID；下载与后处理的取消事件。 | 只生成本任务的清理请求；不使用全局按进程名终止；已退出进程不造成重复失败。真实进程是否停止由 SYS-04 验证，单元替身不作为清理成功证据。 |
| 输出与依赖错误映射 | 已存在完整文件、仅分片、目录不可写、缺失各依赖、浏览器读取错误。 | 完整文件受保护，分片可重试；准确指出错误项；依赖/登录/网络/格式错误不统一改写为“请登录”。实际写保护由 SYS-03/07 验证。 |

## 执行边界

领域逻辑使用纯数据；应用层通过依赖注入替换 I/O 边界。真实下载、FFmpeg、文件覆盖、进程树、Tk 事件循环和 YouTube 网络能力交系统层，不能用 mock 结果冒充通过。平台不支持的专用用例显式 skip 并写原因；核心 Windows 行为不因 POSIX 不兼容而跳过。
