# YouTube 下载工具规格

## Goal
Windows 用户粘贴 YouTube 单视频链接，选择保存目录和清晰度，下载到本机。用户已选择本机窗口版，同时提供便于调试的命令行入口。

## Out of scope
不集成已有管理平台、不部署服务器、不下载整个频道或播放列表。不承诺下载私密、删除或当前账号无权限的视频。

## User roles & primary flows
单个本机用户启动窗口 → 粘贴链接 → 选择目录、清晰度或 MP3 → 下载 → 查看进度和最终文件路径。可取消，保留分片供重试续传。需要登录时由用户显式选择浏览器。

## Functional requirements
1. 仅接受 YouTube watch、Shorts、live、embed 和 youtu.be 单视频链接；拒绝伪装域名、非 HTTP(S)、账号密码 URL、纯播放列表、频道与缺失/无效视频 ID。
2. 支持最佳、2160、1440、1080、720、480 高度上限及 MP3。视频保存 MP4；上限不是保证分辨率，实际取可用格式。
3. 默认不读取浏览器 cookies；可显式选择 Chrome、Edge 或 Firefox，失败时保留错误。
4. 显示下载进度、速度、剩余时间、后处理日志和最终路径。只有进程成功且最终文件存在才显示完成。
5. 点击取消或关闭窗口终止本任务及其子进程；不终止其他会话。分片保留，重复下载不覆盖现有文件。
6. 缺少 FFmpeg/ffprobe 或 JS 运行时则给出安装提示；隔离 yt-dlp 用户配置，避免意外下载列表或执行用户配置命令。
7. 命令行同样验证链接，支持 Ctrl+C 取消并返回非零状态。

## Non-functional requirements
网络下载在工作线程，Tk 主线程只消费事件，不阻塞窗口；一次一个任务。子进程使用参数数组，不通过 shell。项目依赖安装到自己的 .venv。

## Acceptance criteria summary
非法链接无网络调用；下载文件可由 ffprobe 读取；音频仅 MP3；清晰度上限生效；取消停止本任务、保留分片；已存在文件保持不变；失败不显示成功。

## Open questions
无阻塞问题。用户已确认本机窗口版。

## 项目规则适用说明
原生 Tk 桌面窗口没有浏览器、API 或 React；development.md 的真实浏览器验收替换为真实 Tk 事件循环和实际下载进程集成验收。命令行与窗口均验证；人工视觉与用户网络环境仍需用户试用确认。无独立 Web 运行模式。
