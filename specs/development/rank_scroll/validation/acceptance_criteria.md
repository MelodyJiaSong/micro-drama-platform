# Acceptance criteria · rank_scroll

- AC1 `validate` 对 ep01、ep02 输入通过；对缺字段 / 错图标 / 超长文本 / 缺图的 fixture 报出对应错误。
- AC2 时间线：第 N 名卡第一个进入画面；冠军卡在冠军停留段中心 x 偏差 ≤ 2 px；洞察卡位置正确。
- AC3 匀速段相邻帧位移为整数像素。
- AC4 输出 1920×1080、60 fps、H.264、yuv420p、含 AAC 音轨；时长与时间线一致（±0.1 s）。
- AC5 同输入同帧哈希一致。
- AC6 关键帧看图：文字不出框，国旗与国家一致，徽章 / 标签 / 名次可读（手机尺寸缩到 33% 仍可读名称与数值）。
- AC7 `render_manifest.json` 记录输入哈希与参数。
- AC8 1080p60 6 分钟片渲染 ≤ 15 分钟。
